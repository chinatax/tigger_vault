# 财税〔2016〕36号（营改增试点通知）

## Description

《财政部 国家税务总局关于全面推开营业税改征增值税试点的通知》（财税〔2016〕36号），2016 年发布，是
**营业税改征增值税**全面推开的核心规范性文件。它不是单一文本，而是一个**文件组**，由正文与四个附件构成：

| 部分 | 内容 |
|---|---|
| 正文 | 《营业税改征增值税试点实施办法》 |
| 附件 1 | 《营业税改征增值税试点实施办法》（实体规则，含税率、销售额、简易计税等） |
| 附件 2 | 《营业税改征增值税试点有关事项的规定》（差额征税、不征税项目、预缴等） |
| 附件 3 | 《营业税改征增值税试点过渡政策的规定》（免税项目，如学历教育服务） |
| 附件 4 | 《跨境应税行为适用增值税零税率和免税政策的规定》 |

引用时须区分引的是哪一部分——**同一文号下的不同附件，规则可能完全不同**，这是实务与考试中的高频陷阱。

## Key Contributions

- 终结了营业税与增值税并行的格局，将**建筑、房地产、金融、生活服务**四大行业纳入增值税链条。
- 确立了差额征税、预缴、不征税项目、跨境零税率与免税等**至今仍在沿用**的规则框架。
- 附件 3 与附件 4 确立了免税与零税率的正列举清单，是判断"某项服务是否免税"的首要依据。
