# 全国人民代表大会常务委员会

## Description

全国人民代表大会常务委员会（NPC Standing Committee）：**税收法律的制定机关**，
也是本库中**效力层级最高的税收法源**的来源。

⚠ **三个容易混的点**：

1. **法律由「全国人民代表大会」或其「常务委员会」通过**——库内 14 部税收法律中，
   **2 部由全国人大（全体会议）通过**，其余由常委会通过；引用时不可一概写成「人大常委会通过」。
2. **公布须国家主席签署主席令**，且**以全国人大常委会公报上的法律文本为标准文本**。
3. **常委会同时是备案的收受机关**——国务院依授权确定的标准（如增值税起征点）、
   省级依授权作出的决定，均须**报全国人大常委会备案**。这与「国务院制定标准」是一对配套动作，
   参见 [[state-council]]。

## Key Contributions

- **制定税收法律**：
  - 《中华人民共和国税收征收管理法》——**1992 年制定、1995 年修正**，
    2001-05-01 起施行的现行文本**经 2013、2015 年修正**。
  - 《中华人民共和国增值税法》——**2024-12-25 由第十四届全国人民代表大会常务委员会
    第十三次会议通过**，**自 2026-01-01 起施行**。
  - 《中华人民共和国车辆购置税法》等。
- **把增值税从行政法规上升为法律**——《增值税法》的通过与施行，是本库「**暂行条例上升为法律**」
  这一立法沿革主线上的关键事件；它同时**改变了增值税的核心术语体系**，
  使 2026 年前后产生的材料在表述上分属两套体制。
- **通过税法修正案**——库内记有：**2025-10-28 第十四届全国人大常委会第十八次会议**通过
  《关于修改〈环境保护税法〉的决定》，**正式启动对挥发性有机物（VOCs）征收环境保护税的试点**。
- **收受备案**——见上「Description」第 3 点。
