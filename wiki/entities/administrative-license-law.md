# 中华人民共和国行政许可法

## Description

《中华人民共和国行政许可法》：**规范行政许可的设定与实施的基本法律**。
在本库中，它是**税务行政许可**的上位依据——如增值税专用发票最高开票限额审批
一类由税务机关实施的许可事项，其设定权限与程序须合乎本法。

⚠ **与概念层的分工**：本页只做「**指向**」；许可的设定、实施程序与监督等规则
在各概念专页，不在此复述。

## Key Contributions

- ⚠⚠ **第 2 条——行政许可的法定定义**：
  **「行政机关根据公民、法人或者其他组织的申请，经依法审查，准予其从事特定活动的行为」**。
  库内以该条为行政许可概念的起点，并据此归出**四个要点**：
  ①依申请的行政行为；②**是一种经依法审查的行为**（⚠ 审查结果**可能准予、也可能不予许可**）；
  ③**准予从事特定活动**；④要式行为。参见 [[administrative-license]]。
- ⚠ **第 3 条第 2 款——不适用情形**：**有关行政机关对其他机关或者对其直接管理的事业单位的
  人事、财务、外事等事项的审批**，**不适用本法**。
- **确立信赖保护原则**——库内将该原则列为行政许可领域的核心原则之一。
