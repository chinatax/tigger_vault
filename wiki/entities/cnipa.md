# 国家知识产权局

## Description

国家知识产权局（China National Intellectual Property Administration，CNIPA）：
国务院直属机构，主管专利、商标、地理标志等知识产权工作。

⚠ **在本库中的位置特殊**：它是**唯一一个与税收无直接关系、却因统计语料而入库的机构**。
入库缘于 [[cnipa-patent-statistics-yearbooks]] 这一来源——该来源是
《专利统计年报》／《知识产权统计年报》**2015–2025 年数据的汇编**，
由使用者从**国家知识产权局官网年报原文逐年抓取**后整理成表。

⚠⚠ **一处必须随行提示的口径问题**：来源页记有「**国新办发布会**与**国家知识产权局年报**
对同一指标给出不同数值」——引用其数据时须指明取自哪一方。

⚠ **本页不主张任何因果**：来源页中「专利退场」「个人退场」一类判断，是**读取者基于统计表所作的推论**，
**不是国家知识产权局的表述**（来源页已明确声明，此处照录）。

## Key Contributions

- **发布《专利统计年报》／《知识产权统计年报》**——本库中该机构唯一的数据出处，覆盖 2015–2025 年。
- 其年报原文是 [[cnipa-patent-statistics-yearbooks]] 来源页的原始依据。
