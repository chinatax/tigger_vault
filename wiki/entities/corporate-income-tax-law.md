# 中华人民共和国企业所得税法

## Description

《中华人民共和国企业所得税法》：**自 2008-01-01 起施行**，
是**企业所得税的实体法依据**——库内 42 个概念页提及该法。

⚠ **一法与一条例并行的结构**：该法本身定框架，具体口径由**《企业所得税法实施条例》**细化。
⚠ 引用时须分清二者——**法律的条文号与实施条例的条文号不可混引**（库内多处出现
「法第 N 条／条例第 M 条」的并列引法，即为此结构）。

⚠ **与概念层的分工**：本页只做「**指向**」；具体的所得额计算、扣除、优惠等规则
在各概念专页，不在此复述（参见枢纽页 [[corporate-income-tax]]）。

## Key Contributions

⚠ **库内由本件衍生出的概念族**（对照 CLAUDE.md 的「平行命名家族」表）：

| 分支 | 概念页 |
|---|---|
| **总纲** | [[corporate-income-tax]]（纳税人、所得来源地、视同销售、税率、应纳税额计算、纳税地点与期限） |
| **扣除** | [[corporate-income-tax-deduction-limits]]（扣除项目与限额） |

| **优惠** | [[corporate-income-tax-preferences]] · [[corporate-income-tax-exempt-and-non-taxable-income]]（不征税收入与免税收入） |
| **征管** | [[corporate-income-tax-assessed-collection]]（核定征收） |

- **确立「法人所得税制」**——以法人为纳税主体，与个人所得税的二元结构相配套。

  参见 [[ministry-of-finance]]。
