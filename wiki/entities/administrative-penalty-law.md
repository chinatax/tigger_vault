# 中华人民共和国行政处罚法

## Description

《中华人民共和国行政处罚法》：**规范行政处罚的设定与实施的基本法律**。
在本库中，它是**税务行政处罚**的上位依据——税务机关的罚款、没收等处罚措施，
其种类、设定权限与程序均须合乎本法。

⚠ **与概念层的分工**：本页只做「**指向**」；处罚的种类、程序、无效与撤销等规则
在各概念专页，不在此复述。

## Key Contributions

⚠ **库内已落点的主要条文**：

| 条文 | 库内落点 |
|---|---|
| **第 29 条** | ⚠ **「一事不二罚」**——对当事人的同一个违法行为，**不得给予两次以上罚款的行政处罚** |
| **第 38 条** | ⚠ **行政处罚无效的两种情形**——**没有依据**，或**实施主体不具有行政主体资格** |
| **（证据规则）** | **证据先行登记保存**——库内将其与《行政强制法》的强制措施并列对比 |

- **确立处罚法定与处罚适当原则**——是库内「税收行政责任」一侧的判断基准，
  参见 [[administrative-penalty]]。
- ⚠ **一处与行政强制的接口**：**依《行政处罚法》规定行使相对集中行政处罚权的行政机关**，
  可以实施**与行政处罚权有关**的行政强制措施，参见 [[administrative-coercion-law]]。
