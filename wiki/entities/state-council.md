# 国务院

## Description

国务院（State Council）：**最高国家行政机关**，在本库的税收法源中承担两类角色。

**一、行政法规的制定与公布主体。** 凡以「**国务院令**」形式公布的税收行政法规均出自国务院。
库内典型两部：《中华人民共和国增值税暂行条例》（国务院令第 691 号修订）与
《中华人民共和国消费税暂行条例》。⚠ 前者**自 2026-01-01 起因《增值税法》施行而让位**
（该条例已被 [[vat-law]] 第 38 条废止）。

**二、税收法律内部的授权对象。** 多部税收法律不直接定标准，而是把确定权授予国务院，
并要求**报全国人大常委会备案**——由此形成「**法律定框架、国务院定标准、人大常委会收备案**」的三方结构。

⚠ **与 [[state-taxation-administration]] 的分工须分清**：**国务院发的是「行政法规」（国务院令），
国家税务总局发的是「税务规范性文件」（公告／税总发／税总函）**——两者效力层级不同，不可混称。
参见 [[tax-normative-document]]。

## Key Contributions

- **制定税收行政法规**：以「国务院令」形式公布《增值税暂行条例》《消费税暂行条例》等。
- **承接法律授权并确定标准**（三处库内实例）：
  - **小规模纳税人起征点**——「标准由国务院规定并报全国人大常委会备案」；
    2026-01-01～2027-12-31 为月 **10 万元**／季 **30 万元**。
  - **个人携带或者寄递进境物品**的增值税计征办法——「由国务院制定、报全国人大常委会备案」。
  - **消费税纳税人范围**含「**国务院确定的**销售应税消费品的其他单位和个人」。
- **审批跨省汇总申报**——跨省汇总申报由**国务院财政税务主管部门**批准，省内跨县由省级批准。
- **特定优惠的批准权**——如重点贫困县城镇土地使用税的降幅，须经**国务院和省人民政府**批准，
  且降低额不得超过规定最低税额的 **30%**。
