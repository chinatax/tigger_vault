# 中华人民共和国行政复议法

## Description

《中华人民共和国行政复议法》：**行政救济的基本法律**。
在本库中，它是**税务行政复议**的上位依据——纳税人与税务机关的争议，
**先经复议、再可诉讼**，其程序框架由本法与《行政诉讼法》共同提供。

⚠ **与概念层的分工**：本页只做「**指向**」；复议范围、管辖、申请与审理等规则
在各概念专页，不在此复述。

## Key Contributions

- ⚠ **第 23 条——五类复议前置事项**（库内明记）：**对当场作出的行政处罚决定不服**等
  五类情形**应当先申请行政复议**，对复议决定不服再可提起诉讼。
  参见 [[administrative-reconsideration]]。
- **确立「确认无效复议决定」**——⚠ 库内将其与《行政诉讼法》的「确认无效判决」并列对照，
  作为行政救济中的同一制度在两条程序上的对应形态，参见 [[administrative-act]]。
- ⚠ **与《行政诉讼法》的分工（库内须分清）**：本法定**复议**程序、
  《行政诉讼法》定**诉讼**程序；两者**并非二选一**，而是**复议在先、诉讼在后**的衔接关系。
  ⚠ 库内另记：**《行政复议法》《行政诉讼法》已将行政协议争议纳入法定受案范围**。
- **为判定行政行为是否合法提供标准**——库内表述为：以本法与《行政诉讼法》的相关规定
  「为判定行政行为是否合法提供了基本标准」。
