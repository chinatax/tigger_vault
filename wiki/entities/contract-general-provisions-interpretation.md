# 最高人民法院关于适用《民法典》合同编通则若干问题的解释

## Description

《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》：
**法释〔2023〕13 号**，是**民法典合同编通则部分的司法解释**。

⚠ **在本库中的位置**：它是**民法典之下的第二层法源**——
民法典定规则，本解释定**规则在审判中怎么用**。库内大量合同类概念页
**直接以本解释的条文号为落点**，而非引民法典原文。

⚠ **与概念层的分工**：本页只做「**指向**」；各条文的具体口径在各概念专页，不在此复述。

## Key Contributions

⚠ **库内已落点的主要条文**（举例，非全部）：

| 条文 | 库内落点 |
|---|---|
| **第 3 条** | 合同成立的认定——「能够确定当事人姓名或者名称、标的和数量的，一般应当认定合同成立」 |
| **第 6 条** | 认购书、订购书、预订书等**预约合同**的三种情形 |
| **第 20、21 条** | **法定代表人／负责人越权订约**、**工作人员越权订约**的效力 |
| **第 31 条** | 履行抗辩——以对方未履行**非主要债务**为由拒绝履行主要债务的，不予支持 |
| **第 42 条** | **「明显不合理的低价」**的量化判据——未达交易时交易地市场价或指导价的 **70%** |
| **第 52 条** | 协商解除时未处理违约责任、结算清理的后果 |
| **第 57 条** | 不得抵销的债务类型（人身权益损害赔偿等） |
| **第 65 条** | 违约金过高的判据——**超过造成损失的 30%** 一般可认定过分高于损失 |
| **第 67、68 条** | **定金罚则**——未约定定金性质的留置金／保证金／押金等不适用；双方均违约时不支持 |

- **提供合同规则的「可操作阈值」**——⚠ 本解释是库内**少有的给出量化判据**的法源
  （70% 低价线、30% 违约金线），对涉税合同审查有直接价值。
- ⚠ **一处库内已记的识别缺陷**：来源页记有 OCR 将该解释中
  「构成表见代表的，依《民法典》第 X 条处理」的条号**误识为「第 5 条」**
  （语义上应为第 504 条），⚠ **待核对原书**——引用该处时须核对。
