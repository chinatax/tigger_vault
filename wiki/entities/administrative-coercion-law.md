# 中华人民共和国行政强制法

## Description

《中华人民共和国行政强制法》：**规范行政强制措施与行政强制执行的基本法律**。
在本库中，它是**税收保全与税收强制执行**的上位依据——税务机关的查封、扣押、冻结、
从存款中扣缴等，其设定与实施须合乎本法。

⚠ **与概念层的分工**：本页只做「**指向**」；强制措施与强制执行的种类、设定权限、
实施程序等规则在各概念专页，不在此复述。

## Key Contributions

- ⚠⚠ **强制措施的设定权限（库内明记）**：
  - **限制公民人身自由**——**只能由法律设定**；
  - **扣留（冻结）邮政汇款**——**只能由法律设定**。
  参见 [[administrative-coercion]]。
- **「行政强制适当原则」**——⚠ 也称「**合理性原则**」，是库内归纳的行政强制核心原则之一。
- ⚠⚠ **两项禁止（时间与方式）**：**行政机关实施行政强制执行，不得在夜间或者法定节假日实施**
  （⚠ 情况紧急的除外），且**不得以停止供水、供电、供热、供燃气等方式迫使当事人履行**。
- ⚠⚠ **行政强制措施实施不得委托**——库内将此列为行政强制的主体规则之一。
- ⚠ **法律的适用规则是「程序从新」**——库内明记，与实体规则的「从旧兼从轻」相区别。
- ⚠ **与行政处罚的接口**：《行政处罚法》规定的**证据先行登记保存**，
  与《行政强制法》的强制措施在库内并列对比；另，**依《行政处罚法》行使相对集中行政处罚权的
  行政机关**，可实施与行政处罚权有关的行政强制措施，参见 [[administrative-penalty-law]]。
