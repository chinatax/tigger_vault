# 国家税务总局

## Description

国家税务总局（State Taxation Administration，STA）：国务院主管税收工作的直属机构，
负责税收政策制定、征收管理与税务稽查。在本知识库的税务来源中，它是**绝大多数规范性文件与
公告的发布主体**——凡以"国家税务总局公告 YYYY 年第 N 号""税总发""税总函""税总货便函"等形式
出现的文件，均由其或其内设司局印发。

其发文形式的层级差异值得注意：

| 形式 | 层级 |
|---|---|
| 与财政部联合发布的"财税〔〕号" | 部门规范性文件，常涉及税收实体政策 |
| "国家税务总局公告〔〕号" | 税务规范性文件，常涉及征管与执行口径 |
| "税总发""税总函" | 内部管理文件，多涉及工作规程、时限、岗责 |
| "税总货便函"等司局函 | 具体业务司局的工作通知 |

## Key Contributions

- 制定并解释增值税、消费税、车辆购置税等税种的征管规则（如《增值税一般纳税人登记管理办法》
  《异常增值税扣税凭证处理操作规程》《全国税务机关出口退（免）税管理工作规范》）。
- 主管增值税发票管理制度，包括最高开票限额审批、票种核定、红字发票、反向开票等具体规程。
- 组织出口退（免）税的分类管理与风险防控。
