# 中华人民共和国宪法

## Description

《中华人民共和国宪法》：**国家的根本法**，在本库中是**税法效力层级的顶端**——
所有税收法律、行政法规、规范性文件均以其为依据。

⚠ **库内对宪法的定位很明确**：它是**税收的唯一根本依据**，但不直接规定税收制度细节；
它提供的是**纳税义务的正当性来源**与**立法权限的划分框架**。

⚠ **与概念层的分工**：本页只做「**指向**」；宪法与税法的关系内容在各概念专页，不在此复述。

## Key Contributions

- ⚠⚠ **第五十六条——纳税义务的宪法依据**：
  **「中华人民共和国公民有依照法律纳税的义务」**。
  ⚠ 库内对本案有专门记注：**教材给出了完整条号与条文**（属库内少见的「条文完整」情形），
  参见 [[tax-law-and-related-branches]]、[[taxpayer-rights-duties-and-liability]]。
- **宪法中的税收内容（库内归纳为四项）**：
  ①**征税的基本法源**；②**税收立法权限的划分**；③**税收立法的基本程序**；
  ④**公民依法纳税的义务**。
- **确立税收立法权的归属**——库内明记：「在我国，**划分税收立法权的直接法律依据
  主要是《宪法》与《立法法》**」，并给出**《宪法》第五十八条、第六十二条、第一百条、
  第一百四十条**与**《立法法》第十一条、第十二条**的条文序号，参见 [[legislation-law]]。
- **税法与宪法的关系**——库内表述为：「与宪法相比较，**税法只是用来调整税收法律关系、
  主要规范国家税务机关征税和纳税人缴纳税收的法律**」，
  参见 [[tax-legal-relationship]]。
