# 中华人民共和国立法法

## Description

《中华人民共和国立法法》：**规范立法权限与立法程序的基本法律**，
在本库中是**「税收法定原则」的直接法律依据**。

⚠ **它的作用不是规定税收怎么征，而是规定「税收的规则由谁来定」**——
库内「税收立法权」「税法适用原则」两条线都以它为据。

⚠ **与概念层的分工**：本页只做「**指向**」；立法权划分与法律适用规则的具体内容
在各概念专页，不在此复述。

## Key Contributions

- ⚠⚠ **第十一条——「税收基本制度」属法律保留事项**：
  **「税种的设立、税率的确定和税收征收管理等税收基本制度，只能由法律规定」**。
  这是库内**税收法定原则**的法条出处，参见 [[tax-law-basic-principles]]、[[tax-law-operation]]。
  ⚠ 该条共列 **11 个方面**的事项，**教材未逐一列举、本库亦不补列**。
- **第十二条——授权立法**：第十一条规定的事项**尚未制定法律的**，
  全国人大及其常委会有权作出决定，**授权国务院**根据实际需要先制定行政法规。
  ⚠ 授权决定须明确**目的、事项、范围、期限**及应遵循的原则；**授权期限不得超过 5 年**。
  ⚠ **库内由此解释了一处立法现象**：消费税、土地增值税等**仍以暂行条例为依据**，
  与「落实税收法定、加快暂行条例上升为法律」的政策方向**并行存在**。
- **法律解释权属于全国人大常委会**——库内明记，且区分两种情形：
  ①**需要进一步明确具体含义的**；②**法律制定后出现新情况需要明确适用依据的**。
  ⚠ 机关依据参见 [[npc-standing-committee]]。
- **法律适用原则**——库内以《立法法》为据确立两条：
  **新法优于旧法**、**特别法优于一般法**（均适用于**同一机关**制定的规范之间），
  参见 [[tax-law-application-principles]]。
