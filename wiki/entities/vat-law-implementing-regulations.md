# 中华人民共和国增值税法实施条例

## Description

《中华人民共和国增值税法实施条例》：**行政法规**，
**国务院令第 826 号**——**2025-12-19 国务院第 75 次常务会议通过**，**2025-12-25 发布**。

⚠ **「法律 ＋ 实施条例」配套结构的最新样本**：其上位法《增值税法》**2024-12-25 通过**、
**2026-01-01 施行**；本条例随新法同步出台，是《增值税法》落地的主要细则依据。

⚠ **库内引用密度极高**：约 **54 个概念页**提及本条例，且**多处条文在库内属首次出现**——
库内已明确登记：「本库**未获本条例全文**，仅记教材所引要点」。⚠ **故引用本条例条文时
须核对原文**，不可据库内转述径行引用。

⚠ **与概念层的分工**：本页只做「**指向**」；各条文的具体口径在各概念专页，不在此复述。

## Key Contributions

⚠ **库内已落点的主要条文**（据库内记载，非全文）：

| 条文 | 库内落点 |
|---|---|
| **第十六条** | 「销售额和增值税税额合并定价」的换算公式 |
| **第十九条** | **非正常损失**、用途改变或专用于五类不允许抵扣项目的进项税额**转出** |
| **第二十二条** | **「不得抵扣非应税交易」**的认定条件 |
| **第二十五条** | 长期资产进项税额抵扣（与《长期资产进项税额抵扣暂行办法》配套） |
| **第四十四条** | 向主管税务机关申报纳税的程序 |
| **（新增概念）** | 不得抵扣项目的**两个并列条件**（库内标注为「本条例新增概念」） |

- **把《增值税法》的框架条文落成可执行的细则口径**——库内多处「法第 N 条 ＋ 条例第 M 条」
  的并列引法即由此而来，参见 [[vat-law]]。
- ⚠ **一处立法时间差值得留意**：本条例发布于 2025-12-25，而**上位法 2024-12-25 已通过**——
  两者相隔整一年，库内记此为「法律 ＋ 实施条例」出台节奏的实例。
