# 中华人民共和国民法典

## Description

《中华人民共和国民法典》：**自 2021-01-01 起施行**，是**本知识库中被引用次数最高的具名法源**
（库内约 **209 次**，居全库第一）。

⚠ **本库内容的主干之一**：它虽非税法，却是涉税服务中**民事法律关系认定**的基本依据——
纳税主体资格、合同的效力与履行、财产权属、婚姻家庭与继承，都直接影响税收处理。

⚠ **与概念层的分工**：本页只做「**指向**」——记该法是什么、库内由它衍生出哪些专页；
**具体规则内容留在各概念专页**，不在此复述（参见枢纽页 [[civil-law]]）。

⚠ **一处立法技术特征（库内已记）**：《民法典》**未设债法总则**，而是把债法规范
**分散规定在合同编与侵权责任编**中——合同编 3 个分编、29 章、526 条；侵权责任编 10 章、95 条。
此外总则编第五章对民事权利作专章「顶层设计」，故该法被本库记作「**权利法典**」。

## Key Contributions

⚠ **库内由本件衍生出的专页，按 [[civil-law]] 的分支排列**：

| 分支 | 专页 |
|---|---|
| **民法总论** | [[civil-law-basic-principles]]（基本原则）· [[civil-law-subjects]]（民事主体）· [[civil-legal-act]]（民事法律行为） |
| **物权** | [[property-law-general]]（物权总论）· [[security-interest]]（担保物权）等 |
| **债与合同** | [[law-of-obligations]]（债法总论）· [[contract-law]]（合同）· [[tort-liability-law]]（侵权责任） |
| **婚姻家庭与继承** | [[marriage-family-law]] · [[inheritance-law]] |

- **取代《合同法》**——库内记有：《合同法》**自 2021-01-01 起由《民法典》取代**，
  代位权与撤销权现见民法典第五百三十五条、第五百三十八至五百四十二条。
  ⚠ **由此产生一处立法滞后**：《税收征收管理法》第 50 条仍引《合同法》，
  **该引用已陈旧**（本库采取「照录条文原文、不代改，但显式登记」的处置）。
