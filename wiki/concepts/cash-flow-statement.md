# 现金流量表

## Definition

现金流量表（Cash Flow Statement）：反映企业一定会计期间**现金和现金等价物**流入与流出的报表，按**经营活动、投资活动、筹资活动**三类分别列报。

本考点的核心是**分类判断**——同一笔现金收付归入哪一类，几乎每年都考；其次是**补充资料**中「将净利润调节为经营活动现金流量」的方向判断。

## Key Points

- **现金及现金等价物的范围与总额变动**（第 515 题）：
  - ⚠ 用银行存款购买 **1 个月到期的债券** → 该债券属**现金等价物**，
    此项业务是**现金与现金等价物之间的转换**，**不引起现金及现金等价物总额变动**
  - ⚠ 用**库存商品抵偿债务**、购固定资产（未付现）→ **无现金流量变动**
  - 用银行存款**清偿债务** → 引起总额变动
- **直接法与间接法**（第 516 题，⚠ 两者的「便于」常被互换）：
  - **直接法**：一般以利润表中的**营业收入**为起算点，调节与经营活动有关的项目的增减变动；
    便于分析企业经营活动现金流量的**来源和用途**
  - **间接法**：以**净利润**为起算点，调整不涉及现金的收入、费用、营业外收支等项目，
    剔除投资活动、筹资活动的影响；便于将**净利润与经营活动产生的现金流量净额进行比较**
- **三类活动的分类判断**（第 518、523、530、532、533、537 题）：

  | 业务 | 归属 |
  |---|---|
  | 因违反《价格法》而支付的**罚款** | **经营活动** |
  | 支付**应由在建工程负担**的职工薪酬 | **投资活动** |
  | 支付**应由无形资产负担**的职工薪酬 | **投资活动** |
  | 处置**所属子公司**所收到的现金净额 | **投资活动** |
  | 全额支付用于生产的**机器设备价款**、固定资产**报废**取得的现金 | **投资活动** |
  | 为购置存货而发生的借款**资本化利息** | **筹资活动** |
  | 支付**非短期租赁和低价值资产**租赁的租金 | **筹资活动** |
  | 经营租赁收到的租金、收到购入设备的**留抵退税款** | **经营活动** |
  | 收到**返还的增值税税款**、流动资产损失中由**个人赔偿**的现金 | **经营活动** |
  | 支付**离退休人员**的职工薪酬 | **经营活动**（「支付其他与经营活动有关的现金」） |
  | 因**水灾**造成设备损失而收到的**保险赔款** | **投资活动** |
  | **分期付款购建固定资产以后各期**支付的现金 | 「**支付其他与筹资活动有关的现金**」 |
  | 为购建固定资产支付的**耕地占用税** | 投资活动「购建固定资产…支付的现金」 |
  | 为购建固定资产而支付的**应予资本化的借款利息** | 筹资活动「**分配股利、利润或偿付利息支付的现金**」 |
  | **为发行股票直接支付的审计费用** | 「**支付其他与筹资活动有关的现金**」 |
  | 购买股票时支付的**证券交易印花税和手续费** | 投资活动「**投资支付的现金**」 |

- **补充资料「将净利润调节为经营活动现金流量」**（第 519、524 题）：
  - 调节思路：**资产、收益类的增加调减；负债、费用类的增加调增**
  - ⚠ **递延所得税资产减少** → 会增加所得税费用、减少净利润，但**无现金流量** → 应**调增**
  - ⚠ 应**调增**的项目：当期计提的各类**资产减值准备**、**公允价值变动损失**
  - ⚠ 应**调减**的项目：**固定资产报废净收益**、**经营性应收项目**（应收账款）的增加、
    **存货**的增加
  - 例（第 524 题）：净利润 600 − 固定资产报废净收益 50 − 存货增加 10 − 应收账款增加 50
    − 应付职工薪酬减少 30 + 预收账款增加 30 + 计提减值准备 50 + 公允价值变动损失 40 = **580 万元**
- **「不涉及现金收支的重大投资和筹资活动」的披露**（第 534 题）：
  - ✅ 包括：「**债务转为资本**」项目、「**一年内到期的可转换公司债券**」项目、「**新增使用权资产**」项目
  - ⚠ **不属于**：处置子公司的净资产、摊销无形资产、交易性债券投资

  经营活动现金流量的间接推算见 [[solvency-and-cash-flow-ratios]]；
  政府补助涉及的现金流入见 [[government-grants]]
