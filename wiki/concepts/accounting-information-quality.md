# 会计信息质量要求

## Definition

会计信息质量要求（Accounting Information Quality）：对企业财务报告所提供的会计信息应具备的基本特征的规定，共**八项**——可靠性、相关性、可理解性、可比性、实质重于形式、重要性、谨慎性、及时性。

它的考查方式是**给一个具体会计处理，判断体现哪一项要求**。因此每项要求都需要绑定若干「标志性事项」才能作答；单看定义几乎无法区分。

## Key Points

- **八项要求及其标志性事项**（第 164、165、167、175、176 题）：

  | 要求 | 含义要点 | 标志性事项 |
  |---|---|---|
  | **可靠性** | 内容真实、数字准确、资料可靠 | —— |
  | **相关性** | 在确认、计量和报告过程中充分考虑使用者的**决策模式和信息需求** | 资产负债表按流动/非流动分别列报 |
  | **可理解性** | 清晰明了，便于财务报告使用者理解和使用 | —— |
  | **可比性** | 同一企业**不同时期**相同或类似交易采用**一致**的会计政策，不得随意变更（确需变更应在附注中说明）；不同企业**同一期间**采用规定政策，口径一致、相互可比 | 符合一定条件时可变更核算方法并披露；**资本公积转增股本时对各列报期间每股收益重新计算** |
  | **实质重于形式** | 按交易或事项的**经济实质**而非法律形式核算 | **融资性售后回购**取得的价款不确认收入；**债务重组中债权人以股东身份**进行的交易作权益性交易处理；**控制判断不以持股比例为准** |
  | **重要性** | 区分重要程度——重要的必须按规定方法处理并充分准确披露，不重要的可适当简化 | **不重要的前期差错不进行追溯重述**；避免出现提供会计信息的**成本大于收益** |
  | **谨慎性** | 不高估资产或收益、不低估负债或费用 | 对售出商品**很可能发生的保修义务**确认预计负债；**递延所得税资产**只在有确凿证据表明未来期间很可能获得足够应纳税所得额时确认 |
  | **及时性** | 对已发生的交易或事项**及时**确认、计量和报告，**不得提前或延后** | —— |

- **易错辨析**（第 165、175 题，⚠ 定义互换是典型陷阱）：
  - ⚠ **可理解性**要求的是「清晰明了、便于理解使用」；**可靠性**要求的是「内容真实、数字准确、资料可靠」
    ——第 175 题把两者互换作干扰项
  - ⚠ 「只要是相同的交易或事项就应采用相同的会计处理方法」**不完整**——可比性还包含不同企业同一期间的可比，
    且表述「只要是……就应当」过于绝对
  - ⚠ **折旧、摊销**属会计分期假设的运用，不是质量要求
- **两项反向陷阱**（第 167 题）：
  - ⚠ 在**物价持续上涨**期间采用**先进先出法**计量发出存货的成本，会导致**期末存货和当期利润虚增**，
    **不能**体现谨慎性要求
  - ⚠ 「只有存在确凿证据表明未来期间很可能获得足够的应纳税所得额用于抵扣可抵扣暂时性差异，
    才确认相关的递延所得税资产」——这**是**谨慎性的体现（不是相关性、不是重要性）
