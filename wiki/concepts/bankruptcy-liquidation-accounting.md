# 企业破产清算会计

## Definition

企业破产清算会计（Bankruptcy Liquidation Accounting）：破产企业在**非持续经营**前提下，以**破产资产清算净值**与**破产债务清偿价值**为计量基础，对清算期间的资产处置、债务清偿与费用发生进行的会计确认、计量与报告。

它与常规财务会计的根本差别在于**基本假设失效**——持续经营不再成立，因此会计报告的**目标、种类、格式、基本内容与报告需要者**都发生了变化。

## Key Points

- **非持续经营的原因**（第 546 题）：
  - ①传统财务会计的**基本假设**对破产清算会计**不再适用**
  - ②破产清算会计**超越**了传统财务会计的一些**基本原则和要求规范**
  - ③会计报告的**目标、种类、格式、基本内容**以及报告的需要者发生较大变化
  - ⚠ 「破产清算会计**不属于财务会计的范畴**」**不是**原因
- **科目体系的两大类**（第 539 题，⚠ 区分点）：
  - **清算损益类**：「**其他收益**」「**债务清偿净损益**」「**破产资产和负债净值变动净损益**」
    「**资产处置净损益**」「**破产费用**」「**共益债务支出**」
  - **清算净值类**：「**清算净值**」——⚠ 它**不属于**清算损益类科目
- **各项业务的科目归属**（第 540、547、548、550 题）：

  | 业务 | 科目 |
  |---|---|
  | **出售固定资产等实物资产**、**处置存货**、**出售投资性房地产** | **资产处置净损益** |
  | 收回应收票据、应收款项类债权／投资，收回款项与账面价值的差额 | **资产处置净损益** |
  | 以**非货币性资产清偿债务**产生的净收益 | **债务清偿净损益** |
  | 支付所欠**职工的工资、医疗、伤残补助、抚恤费用** | **债务清偿净损益** |
  | 支付所欠**税款** | **债务清偿净损益** |
  | 债权人依法**行使抵销权** | **债务清偿净损益** |
  | 卖出方继续履行尚未履行完毕的合同，应收金额大于转让资产账面价值与相关税费的差额 | **其他收益** |
  | 依法**追回**相关破产资产 | **其他收益** |
  | 划拨土地使用权被**国家收回**而取得的补偿款 | **其他收益** |
  | 收到的**利息、租金、股利**等孳息 | **其他收益** |
  | **破产清算终结日**，剩余破产债务不再清偿 | **其他收益**（借记负债、贷记其他收益） |
  | 重新计量破产报表日的资产和负债项目产生的差额 | **破产资产和负债净值变动净损益** |
  | 通过**债权人申报**发现的**未入账债务** | **其他费用** |
  | 处置破产资产时发生的**评估、拍卖费用** | **破产费用** |

  - ⚠ 三个高频干扰：处置**存货**的差额记「**资产处置净损益**」（干扰项写「其他收益」）；
    **终结日剩余债务不再清偿**记「**其他收益**」（干扰项写「破产费用」）；
    **盘盈**取得的资产按取得时的**破产资产清算净值**初始计量、差额计入**清算损益**
    （干扰项写「记入其他收益」）
  - ⚠ 处置资产缴纳的**增值税**应记「**应交税费**」科目（**不是**清算费用）
  - ⚠ **补缴以前年度的**企业所得税税款时，「**所得税费用**」应当**仅反映破产企业当期应缴的所得税**
- **共益债务与破产费用的区分**（第 549 题）：
  - **共益债务**：
    - ①因管理人或者债务人**请求对方当事人履行双方均未履行完毕的合同**所产生的债务
    - ②债务人财产受**无因管理**所产生的债务
    - ③因债务人**不当得利**所产生的债务
    - ④为债务人**继续营业**而应当支付的**劳动报酬和社会保险费用**以及由此产生的其他债务
    - ⑤管理人或者相关人员**执行职务致人损害**所产生的债务、债务人财产致人损害所产生的债务
  - **破产费用**：**管理、变价和分配**债务人资产的费用；**破产案件的诉讼费用**
- **确认与计量**（第 541、544 题）：
  - 破产企业被法院宣告破产的 → 按**破产资产清算净值**对**破产宣告日的资产**进行**初始确认计量**
  - 破产清算期间的资产 → 按**破产资产清算净值**进行**后续计量**
  - 破产清算期间**新承担**的债务 → 按**破产债务清偿价值**进行初始确认计量
  - ⚠ 破产清算期间发生的各项**费用**应当**直接计入清算损益**
- **破产清算财务报表的编报**（第 542、543、545 题）：
  - **清算损益表**至少应当单独列示：**资产处置净收益（损失）**、**债务清偿净收益（损失）**、
    **破产资产和负债净值变动净收益（损失）**、**破产费用**、**共益债务支出**、**所得税费用**
    - ⚠ **清算净值**属于「**清算资产负债表**」列示的项目，**不在**清算损益表
  - **债务清偿表**：债务应按「**有担保的债务**」和「**普通债务**」**分类设项分别列示**
  - ⚠ **清算资产负债表**中的「**借款**」项目应根据「短期借款」和「长期借款」科目余额的
    **合计数**填列，**不按有无担保分类列示**（干扰项称「按有无担保分类列示，但不再区分长短期」）
  - **清算现金流量表**中，**支付所得税费用**的现金应**单独列示**
  - **三种情形下的编报组成**（⚠ 高频）：

    | 情形 | 应编制的报表 |
    |---|---|
    | 法院**宣告**企业破产 | **清算资产负债表**及相关附注 |
    | 法院或债权人会议等**要求**提供清算财务报表 | 清算资产负债表、清算损益表、清算现金流量表、债务清偿表及相关附注 |
    | **向法院申请裁定破产终结** | **清算损益表、债务清偿表**及相关附注（⚠ **不含**清算资产负债表） |
