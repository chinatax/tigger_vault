# 固定资产后续支出与处置

## Definition

固定资产后续支出与处置（Fixed Asset Subsequent Expenditure and Disposal）：固定资产投入使用后发生的修理、更新改造等支出的处理，以及报废、毁损、出售、盘亏等退出环节的核算。

处置环节的关键是**科目分流**：「固定资产清理」归集**主动处置**，「待处理财产损溢」归集**盘亏**，二者不可混用。

## Key Points

- **后续支出的资本化与费用化**（第 236、263 题）：
  - 发生的符合固定资产**确认条件**的后续支出 → 计入**固定资产成本**
  - 计入成本时，应当**终止确认被替换部分的账面价值**
  - ⚠ 更新改造**转入在建工程**时，**不应将原计提的固定资产减值准备转出**（第 236 题以此为错误项）
  - **日常修理费**的处理分两种：
    - 与**存货的生产和加工相关**的固定资产日常修理费用 → 按**存货成本确定原则**处理（计入产品成本）
    - 其他固定资产的日常修理费用 → 计入**当期损益**
- **更新改造后成本与折旧的计算**（第 240 题，⚠ 两步都要算对）：
  - 改造后成本 = **原值 − 累计折旧** + 改造支出 − **被替换部分的账面价值**
  - ⚠ **被替换部分的累计折旧 = 被替换部分原值 ÷ 固定资产原值 × 固定资产累计折旧**
    - 例：原值 6000、累计折旧 2400、被替换部分原值 800
      → 被替换部分账面价值 = 800 − 2400/6000×800 = 480
      → 改造后成本 = 6000 − 2400 + 112 + 888 − 480 = **4120 万元**
  - 改造当年折旧 = **改造前**按旧参数计算的折旧 + **改造后**按新参数计算的折旧
    - 改造后折旧 = 4120 × 2/16 × 3/12 = 128.75；改造前折旧 = 6000/20 × 5/12 = 125
    - 合计 = **253.75 万元**
- **「固定资产清理」科目**（第 232、267 题）：
  - **通过**该科目核算：固定资产**毁损**、**抵偿债务**、**换入股权**、出售、报废
  - ⚠ **不通过**该科目核算：固定资产**盘亏**（通过「**待处理财产损溢**」科目核算）
  - **影响**固定资产清理净损益的项目：
    - 毁损固定资产取得的**赔款**
    - 报废固定资产的**原值**和已计提的**累计折旧**
    - 转让厂房应缴纳的**土地增值税**
  - ⚠ **不影响**清理净损益的项目：
    - 出售固定资产的**增值税销项税额**
    - **盘盈**固定资产的重置成本（盘盈应借记「固定资产」、贷记「**以前年度损益调整**」，
      不经过固定资产清理）
- **固定资产减值测试**（第 250 题，⚠ 与折旧**共同**影响当年损益）：
  - 当年对损益的影响 = **折旧影响**（按对外销售比例）+ **资产减值损失**
  - ⚠ 产品**未全部对外销售**时，折旧只有**已销售部分**才影响当期损益
    - 例：2024 年折旧 5320 元，当年产品对外销售 60%，年末减值 1830 元
      → 对损益影响 = 5320 × 60% + 1830 = **5022 元**
  - 减值损失金额 = 账面价值 − 可收回金额（见 [[asset-impairment]]）
