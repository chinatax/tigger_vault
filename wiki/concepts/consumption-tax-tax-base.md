# 消费税计税依据

## Definition

消费税计税依据（Consumption Tax Tax Base）：计算应纳消费税额所依据的基数，按应税消费品性质分为**从价定率**（销售额）、**从量定额**（销售数量）和**复合计税**（两者并用）三种。

与增值税的关键区别：消费税的销售额**同样不含增值税**，但价外费用的范围与处理规则另有规定，且存在**最低计税价格**这类反避税安排。

## Key Points

- **价外费用的范围**（《消费税暂行条例实施细则》第 51 号令）：价外向购买方收取的手续费、补贴、基金、集资费、返还利润、奖励费、违约金、滞纳金、延期付款利息、赔偿金、代收款项、代垫款项、包装费、包装物租金、储备费、优质费、运输装卸费以及其他各种性质的价外收费。
- **须计入的具体项**：高档化妆品的**品牌使用费**应计入计税销售额；**违约金**应计入。
- **从价定率的销售额不包括增值税**，也不包括符合条件代为收取的行政事业性收费、未逾期的高档化妆品包装物押金。
- **兼营与成套销售的税率规则**：纳税人兼营不同税率的应税消费品应分别核算；**未分别核算**或**将不同税率的应税消费品组成成套消费品销售**的，**从高适用税率**。
- **从量定额的销售数量认定**：
  - 销售应税消费品 → **销售数量**
  - 自产自用 → **移送使用数量**
  - 委托加工 → 纳税人**收回**的应税消费品数量
  - 进口 → 海关核定的进口征税数量
- **白酒最低计税价格**（税总函〔2017〕144 号、国税函〔2009〕380 号）：由白酒生产企业**自行申报、税务机关核定**，依据**最终一级关联销售单位**对外销售价格核定；核定比例自 2017-05-01 起由 50%–70% **统一调整为 60%**；生产企业计税价格高于销售单位对外销售价格 **70%（含）以上**的，暂不核定最低计税价格；实际销售价格高于核定最低计税价格的，按实际销售价格申报纳税。
- **成品油从量定额税额**：汽油、石脑油、溶剂油、润滑油单位税额 **1.52 元/升**；柴油、航空煤油、燃料油 **1.2 元/升**（航空煤油继续**暂缓征收**）。
- **自产汽油生产乙醇汽油**：按生产乙醇汽油所**耗用的汽油数量**申报纳税（而非乙醇汽油的销售数量）。
- ⚠ **视同销售的价格选择是两条分岔**（必刷550题补充）：
  - 用于**换取生产资料或消费资料、投资入股、抵偿债务**（"换投抵"）→ 按同类应税消费品的
    **最高销售价格**计税
  - 其他视同销售（职工福利、赠送、广告样品等）→ 按**平均价格**（有同类售价时）或组成计税价格计税
- **通过自设非独立核算门市部销售**自产应税消费品的，按**门市部对外销售额或销售数量**计税。
- **以旧换新（含翻新改制）销售金银首饰**：按**实际收取**的不含增值税全部价款计税
  （不是按新首饰售价）。修理、清洗金银首饰**不征收**消费税。
- **带料加工金银首饰**：视同零售征收消费税；有同类售价按同类售价，无同类售价按组价
  =（材料成本 + 加工费）÷（1 − 金银首饰消费税税率）。
- **啤酒的单位税额划分**（必刷550题补充）：以出厂价格（**含优质费、手续费、单独核算的包装物押金**）
  划分档次——每吨出厂价 **≥3000 元的 250 元/吨**，**<3000 元的 220 元/吨**；
  但**重复使用的塑料周转箱押金不包括**在内。
  关联销售时，以**生产企业出厂价格与关联销售单位对外销售价格孰高者**确定税额标准。
- **包装物押金**：一般应税消费品押金在 1 年内又未逾期的**不征收**消费税；
  酒类产品（**啤酒、黄酒除外**）押金**无论是否逾期，收取时**即征收消费税；
  **啤酒、黄酒**从量计征，其包装物押金**不征收**消费税（逾期也不征）。
- **代垫运输费用不计入销售额**的条件：①承运部门将运输发票**开具给购买方**；②纳税人将该发票**转交给购买方**。
  两项同时符合才不属于价外费用。

### 教材第四节的系统性补充（2026-09-23）

**（1）销售额的构成**

- **销售额** ＝ 纳税人销售应税消费品向购买方收取的**全部价款和价外费用**。
  - **销售** ＝ **有偿转让**应税消费品的**所有权**；**有偿** ＝ 从购买方取得**货币、货物或者其他经济利益**。
  - **价外费用** ＝ 价外向购买方收取的**手续费、补贴、基金、集资费、返还利润、奖励费、违约金、滞纳金、
    延期付款利息、赔偿金、代收款项、代垫款项、包装费、包装物租金、储备费、优质费、运输装卸费**
    以及其他各种性质的价外收费。
- ⚠ ⚠ **白酒生产企业向商业销售单位收取的「品牌使用费」**：是随着应税白酒的销售而向购货方收取的，
  **属于应税白酒销售价款的组成部分**，故**不论企业采取何种方式、以何种名义收取价款，
  均应并入白酒的销售额**中缴纳消费税。
- ⚠ **电子烟的销售额**：纳税人生产电子烟的，按**生产销售电子烟的销售额**计算纳税；
  ⚠ **采用代销方式的**，按**经销商（代理商）销售给电子烟批发企业的销售额**计算纳税。
- ⚠ ⚠ **不属于价外费用的两项**（同时符合条件才排除）：
  1. **代垫运输费用**：①承运部门的运输费用发票**开具给购买方**；②纳税人**将该项发票转交给购买方**；
  2. **代为收取的政府性基金或者行政事业性收费**：①由**国务院或者财政部**批准设立的**政府性基金**、
     由**国务院或者省级人民政府及其财政、价格主管部门**批准设立的**行政事业性收费**；
     ②**收取时开具省级以上财政部门印制的财政票据**；③**所收款项全额上缴财政**。

**（2）含税销售额的换算**

- **销售额不包括**应向购买方收取的**增值税税款**。
- ⚠ 如果应税消费品的销售额中**未扣除增值税税款**，或者**因不得开具增值税专用发票而发生价款和增值税
  税款合并收取**的，在计算消费税时应当换算：

  **应税消费品的销售额 ＝ 含增值税的销售额 ÷（1 + 增值税税率或征收率）**

**（3）⚠ 包装物销售收入及押金收入（四种情形，本页最易错处）**

| 情形 | 处理 |
|---|---|
| **随同包装物销售**的应税消费品 | ⚠ **无论包装物是否单独计价、也无论在会计上如何核算**，**均应并入**销售额征税 |
| **不作价随同销售、而是收取押金**的 | 收取时**不并入**；⚠ **但对逾期未收回不再退还的、或者已收取时间超过 12 个月的押金**，**应并入**销售额按适用税率征收 |
| **既作价随同销售、又另外收取押金**的 | ⚠ **凡在规定的期限内没有退还的**，**均应并入**销售额按适用税率征收 |
| ⚠ ⚠ **酒类产品**（**啤酒、黄酒除外**）的包装物押金 | **无论押金是否返还及会计上如何核算**，**均应并入**酒类产品销售额中征收 |

**（4）啤酒的「每吨出厂价」争议规则**

- ⚠ **啤酒生产企业销售的啤酒**，应当以**生产企业出厂价格**与**关联销售单位对外销售价格**
  **孰高者**作为确定消费税税额的标准，并依此确定该啤酒的**消费税单位税额**。

**（5）外币折合率**

- 纳税人销售的应税消费品以**人民币以外的货币**结算销售额的，其销售额的人民币折合率**可以选择**
  销售额发生的**当天**或者**当月 1 日**的人民币汇率中间价；
- ⚠ 纳税人应在**事先确定**采用何种折合率，**确定后 1 年内不得变更**。

**（6）⚠ 从量定额的计量单位换算标准（《消费税暂行条例实施细则》，9 项）**

| # | 应税消费品 | 换算标准 |
|---|---|---|
| 1 | **黄酒** | **1 吨 = 962 升** |
| 2 | **啤酒** | **1 吨 = 988 升** |
| 3 | **汽油** | **1 吨 = 1388 升** |
| 4 | **柴油** | **1 吨 = 1176 升** |
| 5 | **航空煤油** | **1 吨 = 1246 升** |
| 6 | **石脑油** | **1 吨 = 1385 升** |
| 7 | **溶剂油** | **1 吨 = 1282 升** |
| 8 | **润滑油** | **1 吨 = 1126 升** |
| 9 | **燃料油** | **1 吨 = 1015 升** |

- ⚠ **销售数量的四种确定**（与上文一致，此处补齐口径）：**销售**应税消费品 → 销售数量；
  **自产自用** → **移送使用数量**；**委托加工** → 纳税人**收回**的应税消费品数量；
  **进口** → **海关核定**的应税消费品进口征税数量。
- ⚠ **复合计征的计税依据**：**卷烟、白酒**采用复合计征。
  **纳税人生产销售**卷烟和白酒，从量定额计税依据为**实际销售数量**、从价定率计税依据为**销售额**；
  ⚠ **进口、委托加工、自产自用**卷烟、白酒，从量定额计税依据**分别为海关核定的进口数量、
  委托加工收回数量、移送使用数量**。

**（7）⚠ 计税依据的八项特殊规定**

1. ⚠ **卷烟最低计税价格的核定**（《卷烟消费税计税价格信息采集和核定管理办法》，**国家税务总局令第 26 号**）：
   - **核定范围** ＝ 卷烟生产企业在**生产环节销售的**所有**牌号、规格**的卷烟；
   - **核定与发布主体**：由**国家税务总局**核定并发布；
   - **核定公式**：**某牌号、规格卷烟计税价格 ＝ 批发环节销售价格 ×（1 − 适用批发毛利率）**；
   - **批发环节销售价格**按税务机关采集的**所有卷烟批发企业**在价格采集期内销售的该牌号、规格卷烟的
     数量、销售额**加权平均**：
     **批发环节销售价格 ＝ Σ各采集点的销售额 ÷ Σ各采集点的销售数量**；
   - ⚠ **未经国家税务总局核定计税价格的新牌号、新规格卷烟**，生产企业应按**卷烟调拨价格**申报纳税；
   - ⚠ **已核定的**：实际销售价格**高于**计税价格的 → 按**实际销售价格**确定适用税率；
     **低于**计税价格的 → 按**计税价格**确定适用税率。
2. ⚠ **白酒最低计税价格的核定**（国税函〔2009〕380 号）：
   - **核定范围**：白酒生产企业**销售给销售单位**的白酒，生产企业消费税计税价格为
     **销售单位对外销售价格（不含增值税）70% 以下**的，税务机关**应核定**消费税最低计税价格；
     ⚠ 纳税人将**委托加工收回**的白酒销售给销售单位、且计税价格为对外销售价格 **70% 以下**的，**也应核定**。
   - **销售单位** ＝ **销售公司、购销公司**以及**委托境内其他单位或个人包销**本企业生产白酒的**商业机构**；
     ⚠ **销售公司、购销公司**是指**专门购进并销售**白酒生产企业生产的白酒、
     并与该生产企业**存在关联性质**的公司；**包销**是指销售单位依据**协定价格**从生产企业购进白酒，
     **同时承担大部分包装材料等成本费用**，并负责销售白酒。
   - **核定标准**：⚠ **≥70%（含）的，暂不核定**；**<70% 的，核定比例统一确定为 60%**。
   - ⚠ **新产品规则**：白酒新产品（未核定过最低计税价格的白酒产品，**含购进、委托加工收回**的）——
     生产企业销售给**关联销售单位**的：**出厂价格高于**关联销售单位当月对外销售价格 **60%** 的
     → 按**出厂价格**确定申报计税价格；**低于 60%** 的 → 按**关联销售单位当月对外销售价格的 60%** 确定；
     ⚠ **关联销售单位此前未发生对外销售**的 → **暂按出厂价格**确定。
     销售给**非关联销售单位**的 → 按**出厂价格**确定申报计税价格。
     （⚠ 「关联销售单位当月未发生对外销售」时，**按其最近一次发生对外销售月份的对外销售价格 60%** 计算。）
   - ⚠ **重新核定**：已核定最低计税价格的白酒，**销售单位对外销售价格持续上涨或下降时间达到 3 个月以上、
     累计上涨或下降幅度在 20%（含）以上**的，税务机关**重新核定**最低计税价格。
   - **核定程序与主体**：由**白酒生产企业自行申报**，**省、自治区、直辖市和计划单列市税务机关核定**。
   - ⚠ **适用规则**：已核定最低计税价格的白酒，**实际销售价格高于**最低计税价格的 → 按**实际销售价格**
     申报纳税；**低于**的 → 按**最低计税价格**申报纳税。
     ⚠ 生产企业**未按规定上报**销售单位销售价格的，主管税务机关应**按销售单位销售价格**征收消费税。
3. ⚠ **啤酒计征消费税**（**国家税务总局公告 2026 年第 8 号**，**自 2026-04-01 起**）：
   以**生产企业出厂价格**与**关联销售单位对外销售价格**「**孰高者**」作为确定消费税税额的标准。
   - **关联销售单位** ＝ 按《税收征管法实施细则》**第五十一条**和《国家税务总局关于完善关联申报和
     同期资料管理有关事项的公告》（**国家税务总局公告 2016 年第 42 号**）**第二条**认定的单位和个人。
   - ⚠ **两个价格均按「牌号、规格分别计算的加权平均价格」**：
     **出厂价格 ＝ 生产企业当月销售额 ÷ 生产企业当月销售数量**；
     **对外销售价格 ＝ 所有关联销售单位当月对外销售额合计 ÷ 所有关联销售单位当月对外销售数量合计**。
4. ⚠ **自设非独立核算门市部销售**：纳税人通过**自设非独立核算门市部**销售的自产应税消费品，
   应当按照**门市部对外销售额或者销售数量**计算征收消费税。
5. ⚠ ⚠ **用于「换投抵」方面**：纳税人自产的应税消费品用于**换取生产资料和消费资料、投资入股和
   抵偿债务**等方面，应当按纳税人**同类应税消费品的最高销售价格**作为计税依据计算消费税。
6. ⚠ **套装产品**：纳税人将**自产的应税消费品**与**外购或自产的非应税消费品**组成套装销售的，
   以**套装产品的销售额（不含增值税）**为计税依据。
7. ⚠ **电子烟代加工业务的计税**：电子烟生产环节纳税人**从事电子烟代加工业务**的，
   应当**分开核算**持有商标电子烟的销售额和代加工电子烟的销售额；⚠ **未分开核算的，一并缴纳**消费税。
8. ⚠ **计税价格的核定权限（三级）**：
   - **卷烟、小汽车**的计税价格由**国家税务总局**核定，**送财政部备案**；

## Contradictions

**「品牌使用费」的举例对象两个来源不同（非分歧，属举例差异，已判定：规则一致）**：

| 来源 | 举例 |
|---|---|
| [[freight-and-labour-tax-line-2025]]（货劳条线，旧口径） | **高档化妆品**品牌使用费应计入计税销售额 |
| [[cta-550-tax-law-1-questions]]（2026 版）与 [[cta-tax-law-1-textbook]] | **白酒生产企业**向商业销售单位收取的「品牌使用费」应并入销售额 |

- **判定：两者不冲突。** 「品牌使用费属于价外费用、应并入销售额」这条规则**对各类应税消费品普遍适用**，
  两个来源只是**各取一例**——⚠ 货劳条线取高档化妆品，教材与 550 题取白酒（并明确其**立法理由**：
  该费随应税白酒销售而收取、**属于销售价款的组成部分**）。
- ⚠ **本页原仅记「高档化妆品的品牌使用费」**，**该表述未删除**，且已**补入白酒品牌使用费**；
  引用时**两类均可举例**，**不必择一**。
