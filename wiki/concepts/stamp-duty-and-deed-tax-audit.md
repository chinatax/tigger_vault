# 印花税与契税纳税审核

## Definition

⚠ **本页是《涉税服务实务》第三章第三节之「三、其他税种的纳税审核方法」的
「（一）土地增值税、印花税、契税的审核方法」的第二、第三个目**——
即 **「2. 印花税纳税审核方法」** 与 **「3. 契税纳税审核方法」**。

⚠⚠ **两税的审核共性（**本库归纳**）**：
⚠ **印花税与契税都是「「行为税」」——都围绕「一份凭证（合同·书据）」展开**，
⚠ **故审核的落点都是「「凭证的性质认定 → 计税依据 → 适用税率 → 完税手续」」这一条链。**

⚠ **边界**：
- ⚠ **印花税的征税范围与计税依据**见 [[stamp-duty]]；**契税**见 [[deed-tax]]；
- ⚠ **土地增值税侧**见 [[land-appreciation-tax-audit]]；**房产税与城镇土地使用税侧**见
  [[real-estate-and-urban-land-use-tax-audit]]。

## Key Points

### ⚠⚠ 一、印花税的审核——（1）应税凭证的审核

#### ① 应税合同审核要点

> **「印花税应税合同是指纳税人在经济活动和经济交往中书立的各类合同或
> 具有合同性质的凭证。」**

| # | ⚠ 审核项 | ⚠ 内容（**教材原句要点**） |
|---|---|---|
| **A** | ⚠⚠ **审核「征税范围」** | **「「鉴别所书立的凭证是否具有合同性质，是判别征免的主要标准」」**——**「在有关部门掌握凭证书立情况后，应根据有关政策规定，对照纳税人的有关凭证从其「「内容、性质等方面」」进行审核」**；⚠ **例如「审核纳税人有无「「错划凭证性质」」，将应税凭证划为非应税凭证，或因对政策规定理解有误，而将应税凭证作为免税凭证，造成「「漏纳印花税」」的问题」** |
| **B** | ⚠⚠ **审核应税合同的「计税依据」** | ⚠⚠ **见下「两是一目」的分表（本项最易考）** |
| **C** | ⚠⚠ **审核应税合同的「适用税率」** | ⚠⚠ **四种误用**：**一是「将按「「比例税率」」和按「「定额税率」」计征的凭证相互混淆」**；**二是「将载有「「多项不同性质经济业务」」的经济合同误用税目税率」**（**例如一份合同中分别记载有「承揽合同」和「买卖合同」的经济内容，纳税人未分别按各自的税目税率计税贴花，而全部套用「买卖合同」税目税率计税贴花**——**对此类合同的审核，应当注意「「签订合同双方单位的性质、经营范围以及合作内容」」，借此发现问题**）；**三是「将「「性质相似的凭证」」误用税目税率」**；**四是「「技术合同、租赁合同」等，「「在签订时因无法确定计税金额而暂时按每件 5 元计税贴花」」的，「「是否在结算实际金额时按其实际适用的比例税率计算并补贴了印花」」」** |

**⚠⚠ B 项「计税依据」的两是一目（**须成对记**）**：

| 层次 | ⚠ 情形 | ⚠ 口径（**教材原句要点**） |
|---|---|---|
| ⚠ **一是** | ⚠ **计税依据的「完整性」** | **a. 「金额是否完整」——审核合同所列的「「价款、报酬、租金、使用费等全部金额」」，是否全部计入计税依据**；⚠ **「例如，合同中可能包括「「设备价款、安装费、培训费、延期付款利息、违约金」」等条款，需判断相关金额是否应计入计税基础」**；**b. 「价税分离是否正确」——「「如果合同分别列明了价款（或报酬等）和增值税税款，计税依据仅为价款部分」」；「「如果合同价款与增值税未分别列明，则以合同总额（含税价）为计税依据」」」** |
| ⚠⚠ **二是** | ⚠ **「特殊情形」下计税依据的确定** | **a. 价款结算与调整**（**见下「与 e 重复」的提示**）：**「对于某些合同（如建设工程合同），最终结算金额可能与合同所列金额不一致。根据印花税法规定，应税合同所列金额与实际结算金额不一致的，「「不变更应税凭证所列金额的，以所列金额为计税依据；变更应税凭证所列金额的，以变更后的所列金额为计税依据」」。「「已缴纳的印花税多不退、少不补」」」**；**b. 外币折算**——**「计税依据为外币的，应按照「「书立应税凭证当日的人民币汇率中间价」」折合人民币计算应纳税额」**；**c. 多项内容混合合同**——**「同一应税凭证载有两个以上税目事项「「并分别列明金额的，应分别计算应纳税额；未分别列明金额的，从高适用税率」」」**；**d. 两个以上纳税人的**——**「同一应税合同、应税产权转移书据中涉及两方以上纳税人，「「且未列明纳税人各自涉及金额的」」，是否以纳税人「「平均分摊」」的应税凭证所列金额（「「不包括列明的增值税税款」」）确定计税依据」**；**e. 实际执行与合同不一致**——**「变更后所列金额「「增加的」」，纳税人是否就增加部分的金额「「补缴」」印花税；变更后所列金额「「减少的」」，纳税人是否就减少部分的金额向税务机关「「申请退还或者抵缴」」印花税」** |

⚠⚠ **须注意一处「教材自身的重复」（**见 Contradictions 一**）**：
**B 项下的「a. 价款结算与调整」与「e. 实际执行与合同不一致」讲的是同一件事**
（**所列金额与实际结算金额不一致时的处理**），⚠ **且两处给出的结论「相互补充而非完全相同」**
（**a 处强调「多不退、少不补」，e 处强调「增加补缴、减少可退抵」**）。

#### 教材「例 3-10」——银行租赁协议未贴印花税

⚠ **案情**：**税务师受托对某银行进行纳税审核，「实地观察该银行办公地点在某大厦某层至某层」，
并在审核其有关费用账目时发现有租金支出；询问财会人员了解到该银行办公地系「「租用某大厦的财产」」，
即要求该银行出示「「租赁协议文书」」，并对租赁协议进行审核，「「发现协议未贴印花税票」」。**
⚠ **租赁协议的约定（金额 OCR 多处残缺）**：**办公楼某层至二层年租金、租每年递增 5%、
第十年不递增；第三层年租金等；一层至某层租期十年**。

⚠⚠ **税务师的结论与处理**：
- ⚠ **性质认定**：**「该企业租赁协议未贴印花税票，「「违反了《中华人民共和国印花税法》第二条的规定」」，
其行为属「「未按规定缴纳税款」」」**；
- ⚠⚠ **补税计算（**本句内自证**）**：**「要求企业补贴印花税票（租赁协议总金额）× 1‰ ＝「「82 172.20（元）」」」**
  ——⚠ **该式与同段给出的租赁协议总金额（82 172 200 元）互为印证**（**82 172 200 × 1‰ ＝ 82 172.20**）；
- ⚠ **调账分录**：**「借：预付账款（或者待摊费用）——待摊印花税　贷：银行存款」**。

#### ② 其他凭证的审核要点

| # | ⚠ 审核项 | ⚠ 内容（**教材原句要点**） |
|---|---|---|
| **A** | ⚠⚠ **营业账簿的计税情况** | ⚠ **三个层次**：**「首先，审核企业有无「「错划核算形式，漏缴印花税」」的问题——例如，采用「「分级核算形式」」的纳税人，「「仅就财会部门本身设置的账簿计税贴花」」，对设置在「「二级核算单位和车间的明细账」」未按规定计税贴花的情况」**；**「其次，审核营业账簿计税情况是否正确——例如，企业「「『实收资本』和『资本公积』两项合计金额大于已贴花资金的」」，「「是否按规定就增加部分补缴印花税」」」**；⚠ **「最后，审核「「其他账簿」」是否错误计税贴花——「「除营业账簿以外的账簿，包括日记账簿和各明细分类账等，无须按件贴花」」」** |
| **B** | ⚠⚠ **产权转移书据、权利许可证照的计税情况** | **「首先，了解和掌握纳税人在经济活动和经济交往中都「「书立、领受了哪些产权转移书据」」。其次，审阅产权转移书据的内容，并与「「『固定资产』『无形资产』」等账户发生额核对」」，核实其实际发生的计税金额；同时「「按规定的税率验算其应纳税额」」，并与产权转移书据上「「粘贴的印花税票」」核对，看是否存在「「错算或少缴印花税」」的问题」**；⚠⚠ **「注意「「商品房销售按产权转移书据贴花，不按购销合同贴花」」」** |

#### 教材「例 3-11」——电器厂实收资本未足额贴花

⚠ **案情（**金额多处残缺**）**：**某电器厂系街道办集体所有制企业，主要从事变压器制造业务；
税务代理人员对企业某年度纳税情况进行审核，发现如下问题：该企业于当年 3 月成立，
由街道办投入资金与个人投资合计（**金额见下**），「「实收资本未贴印花税票」」；
⚠ **「该企业将投资记入『应付账款』科目，只在账本贴印花税 5 元」」。**

⚠⚠ **税务师的结论与处理（**算术链自证**）**：
- ⚠ **性质**：**「企业的行为属于「「未足额缴纳印花税款」」」**；
- ⚠⚠ **计算**：**「根据税法规定，该企业应就实收资本「「117 600 元」」的「「0.25‰」」
  贴印花税「「29.40 元」」」** → ⚠ **故「企业应补贴印花税「「24.40 元」」」**
  （**117 600 × 0.25‰ ＝ 29.40；29.40 − 5（账本已贴）＝ 24.40**）；
- ⚠ **调账分录**：**「（1）「「调增实收资本」」：借：应付账款　贷：实收资本 117 600；
  （2）「「补缴印花税」」：借：税金及附加　贷：银行存款 24.40」**。

### ⚠ 三、契税的审核——（1）（2）（3）三项

| # | ⚠ 审核项 | ⚠ 内容（**教材原句要点**） |
|---|---|---|
| **（1）** | ⚠ **征税范围的审核** | **① 「审核纳税人有无发生「「承受土地、房屋权属」」的行为，是否如实申报缴纳了契税；应税项目是否与免税项目相互混淆」**；**② 「审核承受土地、房屋权属的「「协议或者合同」」，是否「「真实反映了承受土地、房屋权属的内容」」」** |
| **（2）** | ⚠ **税率的审核** | **「核对纳税人有无「「错用税率」」的情况，有无「「不按当地政府规定，任意变动适用税率」」的情况」** |
| **（3）** | ⚠⚠ **计税依据的审核** | **① 「审核纳税人计算契税的依据是否正确，有无「「人为调整计税依据」」的情况」**；**② 「审核「「自行申报缴纳的税款是否正确，有无隐瞒支付金额」」——审核时，应将纳税人「「自行申报数与相关的账簿、凭证记载金额核对」」」** |

#### 教材「例 3-12」——购进厂房的契税与账务处理

⚠ **案情**：**某公司（增值税一般纳税人）某年 10 月「「购进厂房一栋」」，取得增值税专用发票，
支付不含增值税价款（**金额 OCR 残缺**），已办完各种相关手续，「「契税税率为 4%」」。**

⚠⚠ **两个知识点（**教材借例演示**）**：
① ⚠ **契税的计算**：**「公司应缴纳契税 ＝（不含增值税价款）× 4%」**；
② ⚠⚠ **会计处理**：**「公司缴纳的契税应「「计入其固定资产的价值中」」；「「取得增值税专用发票上注明
增值税税额可以作为当期进项税额予以抵扣」」」**——**「借：固定资产——厂房、应交税费——应交增值税
（进项税额）；贷：银行存款、应交税费——应交契税。上缴契税时：借：应交税费——应交契税　
贷：银行存款」**。

### ⚠ 四、本页的「要点密集区」（**复习提示**）

| 要点 | ⚠ 所指 |
|---|---|
| ⚠⚠ **「是否具有合同性质」是征免的主要标准** | **印花税征税范围审核的判据** |
| ⚠⚠ **计税依据两是一目** | **一是完整性（金额是否完整 + 价税分离）；二是特殊情形（五类）** |
| ⚠⚠ **「价税分离」的两个分支** | **分别列明→仅价款；未分别列明→含税总额** |
| ⚠⚠ **「未列明各自金额 → 平均分摊」** | **两个以上纳税人时的计税依据，且「不包括列明的增值税税款」** |
| ⚠⚠ **「外币按书立当日汇率中间价」** | **而非结算日或入账日** |
| ⚠⚠ **税率误用的四种** | **比例与定额混淆／多项业务误用／性质相似凭证误用／技术合同与租赁合同「先按 5 元贴花、结算时补贴」** |
| ⚠ **「商品房销售按产权转移书据贴花，不按购销合同」** | **本目最易错的一处定性** |
| ⚠⚠ **「实收资本与资本公积增加 → 补缴」** | **营业账簿的审核落点；⚠ 其他账簿「无须按件贴花」** |
| ⚠⚠ **例 3-10 与例 3-11 的处理** | **未贴花 → 补贴；未足额 → 补差；且都走「税金及附加（或待摊）＋银行存款」** |
| ⚠ **契税「计入固定资产价值」** | **且专票的增值税额可作进项抵扣——两笔互不影响** |

## Contradictions

**⚠ 一、⚠⚠ 一处「教材自身的重复」（**同项内两处讲同一件事**）**：

⚠⚠ **印花税「计税依据」的「二是特殊情形」项下，a 与 e 的落点重复**：

| ⚠ 位置 | ⚠ 教材原句要点 |
|---|---|
| **a.「价款结算与调整」** | **「应税合同所列金额与实际结算金额不一致的，不变更的以所列金额为计税依据；变更的以变更后金额为计税依据。「「已缴纳的印花税多不退、少不补」」」** |
| **e.「实际执行与合同不一致」** | **「所列金额与实际结算金额不一致，不变更的以所列金额为计税依据；变更的以变更后金额为计税依据。已缴纳印花税的应税凭证，「「变更后所列金额增加的，就增加部分补缴；减少的，就减少部分申请退还或者抵缴」」」** |

⚠⚠ **本库处置（**照录两处、并显式标注其关系**）**：
① ⚠ **两处的「框架句」完全相同**（**不变更→按所列金额；变更→按变更后金额**）；
② ⚠⚠ **差异在「已缴税款的处理」**——**a 处作「多不退、少不补」**，
**e 处作「增加补缴、减少可退还或抵缴」**；
