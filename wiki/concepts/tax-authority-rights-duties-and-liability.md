# 税务机关的权利、义务及法律责任

## Definition

⚠ **本页是教材第二章第五节「征纳双方权利、义务及法律责任」的「税务机关一侧」**——
⚠ **教材以「一、税务机关的权利、义务及法律责任」为一级目，
下设「（一）权利」「（二）义务」「（三）税务机关和税务人员的法律责任」三个二级目。**

⚠ **边界**：
- ⚠⚠ **「纳税人一侧」见 [[taxpayer-rights-duties-and-liability]]**——
  **两页为「征纳双方」的对称两半，⚠ 合起来才是完整的第五节**；
- **税务检查**见 [[tax-inspection-and-major-case-review]]；
- ⚠ **「税款征收的保障措施」（保全·强制执行等）的实体规则**见
  [[tax-collection-guarantee-measures]]——⚠ **本页只从「税务机关享有什么职权」的角度记它们**；
- **本章总纲与入口指针**见 [[tax-collection-and-administration]]。

⚠ **本页承载教材第二章第五节的前半**（**书页 87–88 上／txt 92–93 上**，约 2 页）。

## Key Points

### 一、⚠ （一）税务机关的权利（**七项**）

| # | ⚠ 权利 | ⚠ 要点 |
|---|---|---|
| **（1）** | **税收法律、行政法规的建议权，税收规章的制定权** | — |
| **（2）** | ⚠ **税收管理权** | **有权对纳税人进行「税务登记管理、账簿和凭证管理、纳税申报管理」等** |
| **（3）** | ⚠⚠ **税款征收权** | ⚠⚠ **「这是税务机关在税款征收管理过程中享有的「最主要的职权」」**——**含四个子项，见下** |
| **（4）** | ⚠⚠ **批准税收减、免、退、延期缴纳税款权** | **有权在法律、行政法规规定的权限内，对纳税人的减免税申请予以审批**；⚠⚠ **「但不得违反法律、行政法规的规定，「擅自作出减税免税的规定」」**；⚠ **延期缴纳税款须「经省、自治区、直辖市税务局批准」，且「最长不得超过 3 个月」** |
| **（5）** | ⚠ **税务检查权** | ⚠⚠ **「这是税务机关查处税收违法行为的职权」，包括「查账权、场地检查权、询问权、责成提供资料权、存款账户核查权」等** |
| **（6）** | **处罚权** | **即对税收违法行为进行「行政处罚」的权力，如罚款等权力** |
| **（7）** | **国家赋予的其他权力** | （**兜底**） |

#### ⚠⚠ 「税款征收权」的四个子项（**本目最易考**）

| 子项 | ⚠ 要点 |
|---|---|
| ⚠ **依法计征权** | **税务机关可以根据「各税种的不同特点和征纳双方的具体条件」，「依法确定计算征收税款的方式和方法」** |
| ⚠ **核定税款权** | ⚠ **有权对「确无记账能力」或「虽有记账能力但管理混乱而导致税务机关难以查账征收税款」的纳税人，「按照一定方式核定其应纳税额」** |
| ⚠ **税收保全和强制执行权** | ⚠ **「经县以上税务局（分局）局长批准，税务机关可以采取税收保全措施和强制执行措施，征收税款」** |
| ⚠⚠ **追征税款权** | ⚠⚠ **三档追征期，见下专表** |

##### ⚠⚠ 追征税款权——三档追征期（**与旧记完全一致，本项是枢纽页 B 组「追征期」的出处**）

| 原因 | ⚠ 追征期 | ⚠ 滞纳金 |
|---|---|---|
| ⚠ **因「税务机关的责任」**，致使纳税人、扣缴义务人未缴或者少缴税款的 | **税务机关在「3 年内」可以要求纳税人、扣缴义务人补缴税款** | ⚠⚠ **「但是不得加收滞纳金」** |
| ⚠ **因「纳税人、扣缴义务人计算错误等失误」**，未缴或者少缴税款的 | ⚠ **税务机关在「3 年内」可以追征税款、滞纳金**；⚠⚠ **「有特殊情况的，追征期可以延长到 5 年」** | **加收** |
| ⚠⚠ **对「偷税、抗税、骗税」的** | ⚠⚠ **税务机关追征其未缴或者少缴的税款、滞纳金或者所骗取的税款，「可以无限期追征」** | **加收** |

> ⚠⚠ **本表解答了上一批（第三节）留下的一个归属问题**：
> ⚠ **「追征期」不在第三节「税款征收」**，⚠⚠ **而在第五节「税务机关的权利」之「追征税款权」下**——
> ⚠ **其视角是「税务机关的一项权利」，而不是「征收程序的一个环节」**，
> ⚠⚠ **这一编排差异正是它「看似属于第三节、实际属于第五节」的原因**（⚠ 详见 Contradictions 节）。

### 二、（二）税务机关的义务（**七项**）

| # | ⚠ 义务 |
|---|---|
| **（1）** | **宣传、贯彻、执行税收法规的义务** |
| **（2）** | ⚠ **为「检举人」保密的义务** |
| **（3）** | **为纳税人依法依规办理税务登记、发给税务登记证件的义务** |
| **（4）** | **受理减、免、退税申请及延期缴纳税款申请的义务** |
| **（5）** | **受理税务行政复议的义务** |
| **（6）** | ⚠ **保护纳税人合法权益的义务** |
| **（7）** | **国家规定的其他义务**（**兜底**） |

> ⚠ **与「税务机关的权利」的对照**：**（3）（4）两项与权利中的「税收管理权」「批准减免退税权」
> 互为镜像**——⚠⚠ **同一件事，从机关侧看是「权利」，从相对人侧看是机关的「义务」**；
> ⚠ **本页与 [[taxpayer-rights-duties-and-liability]] 需并读才能看出这层镜像关系。**

### 三、⚠⚠ （三）税务机关和税务人员的法律责任（**七项**）

| # | ⚠ 情形 | ⚠ 责任 |
|---|---|---|
| **（1）** | ⚠ **税务人员与纳税人、扣缴义务人「勾结，唆使或者协助」其犯罪的** | **依照《刑法》关于「共同犯罪」的规定处罚**；⚠ **未构成犯罪的，给予「行政处分」** |
| **（2）** | ⚠ **税务人员利用职务上的便利，收受或者索取纳税人、扣缴义务人财物的** | **构成犯罪的，依照《刑法》「受贿罪」追究刑事责任**；⚠ **未构成犯罪的，给予行政处分** |
| **（3）** | ⚠ **税务人员玩忽职守，不征或者少征应征税款，致使国家税收遭受重大损失的** | **依照《刑法》「渎职罪」追究刑事责任**；⚠ **未构成犯罪的，给予行政处分** |
| **（4）** | ⚠ **税务人员滥用职权，故意刁难纳税人、扣缴义务人的** | ⚠ **「给予行政处分」**；⚠ **构成犯罪的，依照《刑法》渎职罪追究刑事责任**（⚠ **注意本项的顺序与前三项相反：以行政处分为主、刑事为兜底**） |
| **（5）** | ⚠⚠ **税务人员违反法律、行政法规的规定，「擅自决定税收的开征、停征或者减税、免税、退税、补税」的** | ⚠ **除按《税收征收管理法》的规定「撤销其擅自作出的决定」外，「补征应征未征税款，退还不应征而征收的税款」，并追究「直接责任人员的行政责任」** |
| **（6）** | ⚠ **税务人员「私分扣押、查封的商品、货物或者其他财产」的** | **情节严重、构成犯罪的，依法追究刑事责任**；⚠ **尚不构成犯罪的，依法给予行政处分** |
| **（7）** | ⚠⚠ **调查税收违法案件时，查询「案件涉嫌人员的储蓄存款」** | ⚠⚠ **须「经设区的市、自治州以上税务局（分局）局长批准」**（⚠ **注意：本项是「权限规定」，与其余六项的「责任规定」性质不同，但教材列于此处**） |

> ⚠⚠ **第（7）项与库内的呼应**：**「查询案件涉嫌人员的储蓄存款」须经「设区的市、自治州以上」局长批准**，
> ⚠ **与「查询存款账户」须经「县以上」局长批准，构成**两级审批**的对照**——
> ⚠ 该对照的**检查侧表述**见 [[tax-inspection-and-major-case-review]]；
> ⚠ **本页从「税务机关的权利/责任」角度记它**，⚠ **两处须能互相印证。**
>
> ⚠⚠ **第（5）项与库内的呼应**：**「擅自决定税收的开征、停征或者减税、免税、退税、补税」**这一表述，
> ⚠ **正是 [[tax-collection-administration-overview]] 中**税收法定原则**那一句（「任何机关、单位和个人
> 不得违反法律、行政法规的规定，擅自作出……」）在**责任层面的落点**——
> ⚠⚠ **「总则里的禁止 + 本节里的后果」构成完整的一条链**，⚠ 两页须并读。

> ⚠⚠ **一处「与《刑法》的衔接」的边界**：⚠ **本页的第（1）—（4）项与第（6）项都指向《刑法》罪名**
> （**共同犯罪、受贿罪、渎职罪**），⚠ **而库内《刑法》侧的专页是「涉税犯罪」视角**
> （见 [[tax-evasion-crimes]]、[[invoice-crimes]]、[[tax-related-duty-crimes]]）——
> ⚠⚠ **本页讲的是「税务人员一侧的责任」，⚠ 与「纳税人一侧的涉税犯罪」是两个方向，勿混**。

## Contradictions

> ⚠ **本页无来源间冲突**——⚠ **题库旧记在本节只有「追征期」一条与本页对应，且经比对完全一致**
> （⚠ 见下）。⚠ **其余各条为归属说明与编排说明。**

**✅✅ 一、一处「积压待核项落地」——「追征期」的归属至此确定（**连续两批的悬案）**：

⚠⚠ **经过**：
- ⚠ **第三节（税款征收）摄入时**，本库发现**枢纽页 B 组的旧记条目名为「税款优先与追征期」，
  但教材第三节只讲「税款优先」、并无「追征期」**，⚠ **当时判定「不迁移、待第五节核实」**；
- ✅✅ **本批复核结论：教材把「追征期」放在第五节的「税务机关的权利」之「追征税款权」下**
  （**书页 87／txt p92**）——⚠⚠ **其视角是「税务机关的一项权利」，不是「征收程序的一个环节」**。

⚠ **另附**：**同一页（书页 87）也给出了「多缴税款退还」的对应权利**——
⚠ **它同样在第五节**，⚠⚠ **位于「纳税人一侧」的「申请退还多缴税款权」**（见 [[taxpayer-rights-duties-and-liability]]）。
⚠ **故枢纽页 B 组的「税款优先与追征期」一条，至此**完全拆清**：**
- ⚠ **「税款优先」** → 第三节 → ✅ 已迁入 [[tax-collection-guarantee-measures]]；
- ⚠ **「追征期」** → 第五节「税务机关的权利」 → ✅ 已迁入本页；
- ⚠⚠ **「多缴税款退还」** → 第五节「纳税人的权利」 → ✅ 已迁入 [[taxpayer-rights-duties-and-liability]]。

**✅ 二、与题库旧记「一致」的一条（**属强化，已自枢纽页 B 组迁入**）**：

| 项 | 题库旧记 | ⚠ 教材 2026 版 | 判定 |
|---|---|---|---|
| **追征期的三种情形** | **税务机关的责任 3 年内补缴、不得加收滞纳金；纳税人计算错误等失误 3 年内追征、特殊情况延长至 5 年；偷税抗税骗税无限期追征** | ⚠ **同（三档完全一致）** | ✅ **一致** |

**⚠ 三、一处「结构编排」的说明（**非分歧，但影响检索**）**：
⚠⚠ **本页第（三）项下的七条中，六条是「税务人员的法律责任」，
唯独第（7）项「查询案件涉嫌人员的储蓄存款须经设区的市、自治州以上局长批准」是「权限规定」**——
⚠ **教材把它列在「法律责任」之下，属编排上的归类**（⚠ **可能是把它视为「违法行使会发生责任的权限边界」**）。
- ⚠ **本库照录教材的编排位置，并在正文该项处显式标注这一性质差异**；
- ⚠ **若按内容性质归档，该项更接近「税务检查权」的行使条件**——
  ⚠ **故本页在正文中给出了与 [[tax-inspection-and-major-case-review]] 的交叉指针**，
