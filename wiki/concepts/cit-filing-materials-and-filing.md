# 企业所得税年度申报：申报表与备案（留存备查）资料的准备与报送

## Definition

⚠ **本页是《涉税服务实务》第五章《纳税申报代办服务》第二节之「一、企业所得税纳税申报代办」
「「（五）申报表与备案（留存备查）资料相关事项」」**（书页 332–333 中，txt 337–338 中）——
**即年度申报表填制完成前后的「资料准备」与「报送」两个收尾环节**。

⚠ **边界**：
- ⚠ **申报要求与资料收集**见 [[cit-filing-requirements-and-materials]]；
  **纳税调整的专业判断**见 [[cit-filing-adjustment-review]]；
  **申报表的填制**见 [[cit-filing-return-preparation]]（**同批**）；
- ⚠ **「优惠事项资料留存备查」的实体口径**见 [[corporate-income-tax-preferences]]；
  **「资产损失留存备查资料」**见 [[asset-loss-deduction]]；
- ⚠ **「纳税调整报告」**是本页独有的业务成果（⚠ **增值税／消费税侧的业务成果清单中无此项**）。

## Key Points

### 一、⚠⚠ 申报表填制与备案资料准备（**七项**）

| # | ⚠ 内容（**教材原句要点**） |
|---|---|
| **（1）** | ⚠ **按业务协议书是否约定「代理特定事项」分两种走法**——**约定了的**：「涉税专业服务机构应当根据具体情况**辅导纳税人调整账务，作出纳税调整**」；**未约定的**：「应当**向纳税人获取管理当局申明书，经纳税人书面签署确认后**，有针对性地进行填报」 |
| **（2）** | ⚠ **应当取得纳税人「上年度纳税申报表」**，了解其上**弥补亏损、结转以后年度扣除等数据对本年度申报表数据的影响**；⚠ **并关注**纳税人**被纳税评估、稽查、审计、会计信息质量抽查而作出行政处理或者被其他部门行政处罚、刑事处罚，对本年度申报的影响** |
| **（3）** | **应当按照企业所得税年度纳税申报表「填报说明」的要求和口径填报** |
| **（4）** | ⚠⚠ **填报时应特别关注的「三类关系」**：**表内逻辑关系、申报表及附表表间关系；备案（留存备查）事项相关资料间关系等** |
| **（5）** | ⚠ **填报收入时的三个维度**：**① 收入的范围与划分**（**A. 应税收入**：**征税收入与免税收入；会计核算收入与视同销售收入等**；**B. 不征税收入**）；**② 收入的金额**（**公允价值与非公允价值；实际收入与同类产品收入**）；**③ 收入实现时间的确定**（**权责发生制与收付实现制（如接受捐赠收入）；分期确认与延期确认、暂不确认等**） |
| **（6）** | ⚠ **填报扣除项目时的三个维度**：**① 扣除的范围与划分**（**允许扣除与不得扣除；与应税收入相关的支出和与不征税收入相关的支出；财务成本与视同销售成本**）；**② 扣除金额**（**据实扣除与限额扣除、比例扣除、加计扣除；公允价值与非公允价值；实际成本与同类产品成本**）；**③ 扣除的时间**（**当期扣除（如符合规定的期间费用）与分期扣除（如符合规定的成本）、结转以后年度扣除**） |
| **（7）** | ⚠ **签章要求**：**「涉税专业服务机构须加盖代理申报机构公章，并填报经办人及其资格证件号码」** |

> ⚠⚠ **（5）（6）是本节最具「填报方法论」价值的一段**——
> **它把「收入」与「扣除」各拆成「范围／金额／时间」三维度**，
> ⚠ **与 [[cit-filing-adjustment-review]] 按申报表项目大类铺开的清单互为经纬**：
> **一处按「项目」铺、一处按「维度」收**。

### 二、申报表与备案资料报送（**两项**）

| # | ⚠ 内容（**教材原句**） |
|---|---|
| **（1）** | ⚠ **出具报告**：「涉税专业服务机构开展企业所得税年度申报代办业务，**完成约定服务事项后，由项目负责人根据约定出具「「纳税调整报告」」**」 |
| **（2）** | ⚠ **报送与更正**：「应当**依据合同的约定，按照税法的规定和纳税人主管税务机关的要求向其申报纳税**；**汇算清缴期内，发现已申报的当年度数据有误的，可在汇算清缴期内「「重新办理申报」」**」 |

> ⚠ **与增值税／消费税侧的对照**：**两税侧的业务成果是「五项清单」**（**申报表·扣缴税款报告表、
> 代办业务报告、其他纳税资料、留存备查资料、其他相关报告**，见 [[vat-filing-procedure]]）；
> ⚠ **企业所得税侧则突出一份具名的「纳税调整报告」**，且**明确了「更正申报」的窗口＝汇算清缴期内**
> （**对照：增值税侧的表述是「办理更正申报或者补充申报」**）。
