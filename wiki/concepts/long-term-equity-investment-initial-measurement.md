# 长期股权投资的初始计量

## Definition

长期股权投资的初始计量（Long-term Equity Investment Initial Measurement）：确定长期股权投资的**初始投资成本**，并进一步确定其**入账价值**。

判断链条分三步：**持股比例是否形成控制**（区分同一控制/非同一控制/不形成合并）→ **后续用成本法还是权益法** → **入账价值是否需要按可辨认净资产公允价值份额调整**。

## Key Points

- **控制的三项基本要素**（第 302 题）：
  - ①投资方拥有对被投资方的**权力**
  - ②因参与被投资方的相关活动而享有**可变回报**
  - ③**有能力运用**对被投资方的权力**影响其回报金额**
  - ⚠ 「投资方拥有被投资方 **50% 以上**的股权」「将被投资方**纳入合并财务报表**」**不是**基本要素
- **重大影响的判断情形**（第 305 题，五项）：
  - ①在被投资单位的**董事会或类似权力机构中派有代表**
  - ②参与被投资单位的财务和经营政策**制定过程**，**包括股利分配政策等的制定**
  - ③与被投资单位之间发生**重要交易**
  - ④向被投资单位**派出管理人员**
  - ⑤向被投资单位提供**关键技术资料**
- **初始投资成本总表**（解析给出的归纳，本考点最有价值的记忆框架）：

  | 情形 | 初始投资成本 |
  |---|---|
  | **同一控制**下企业合并（持股 > 50%） | 合并日所取得的**被合并方所有者权益在最终控制方合并财务报表中的账面价值 × 持股比例**<br>⚠ 与付出对价账面价值（或原投资账面价值 + 新付出对价账面价值）的差额，**倒挤入资本公积（资本溢价或股本溢价）**；资本公积不足冲减的，依次冲减**盈余公积、未分配利润** |
  | **非同一控制**下企业合并——**一次交易** | 付出对价的**公允价值** |
  | **非同一控制**下企业合并——**金融资产增资** | 原股权投资的**公允价值** + 新股权付出对价的公允价值 |
  | **非同一控制**下企业合并——**权益法增资** | 原股权投资的**账面价值** + 新股权付出对价的公允价值 |
  | **不形成企业合并**（20% ≤ 持股 ≤ 50%） | 付出对价的**公允价值 + 相关交易费用** |
  | **入账价值（权益法）** | 初始投资成本与**应享有被投资单位可辨认净资产公允价值份额**中的**较高者** |

- **三类费用的归属**（⚠ 极易混淆，三条互不相同）：
  - **企业合并**（同一控制与非同一控制）发生的**审计、评估、法律咨询等中介费用** → 计入**管理费用**
  - **不形成企业合并**的长期股权投资，其**相关交易费用** → 计入**投资成本**
  - **发行股票**支付的**手续费、佣金**（如支付给证券承销机构） → **冲减资本公积——股本溢价**
- **同一控制下企业合并的典型结构**（第 297 题）：
  - 定向增发 3000 万股（面值 1 元、公允 4 元）取得 70% 股权；
    A 公司所有者权益在最终控制方合并财务报表中的账面价值 10000 万元、可辨认净资产公允价值 15000 万元
    → 初始投资成本 = 10000 × 70% = **7000 万元**
  - ⚠ **用「最终控制方合并报表中的账面价值」，不是可辨认净资产公允价值**
    （用 15000 × 70% = 10500 就错了）
  - 分录：借「长期股权投资」7000、贷「股本」3000、贷「资本公积——股本溢价」4000；
    另借「资本公积——股本溢价」80、贷「银行存款」80（承销商佣金冲减资本公积）
- **非同一控制下以非货币性资产投资**（第 280 题）：
  - 初始投资成本 = **付出对价的公允价值 − 取得股权中已宣告但尚未发放的现金股利**
  - 付出资产的账面价值与公允价值之差计入**资产处置损益**
  - 例：无形资产原值 2000、累计摊销 600、减值 80、公允价值 1550，取得 60% 股权中含应收股利 50
    → 初始投资成本 = 1550 − 50 = **1500 万元**；资产处置损益 = 1550 − (2000 − 600 − 80) = 230 万元
- **以存货为对价**（第 298 题）：
  - 初始投资成本 = 存货的**公允价值 ×（1 + 增值税税率）+ 相关税费**
  - 例：库存商品公允 750、税率 13%、相关税费 2.5 → **850 万元**
- **后续计量方法的选择**：
  - **控制**（持股 > 50%）→ **成本法**
  - **共同控制或重大影响** → **权益法**（见 [[long-term-equity-investment-equity-method]]）
  - 成本法下被投资方实现净利润**不做账务处理**，宣告分派现金股利时**确认投资收益**（不影响长投账面价值）
