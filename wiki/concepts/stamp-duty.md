# 印花税

## Definition

印花税（Stamp Duty）：对在中国境内**书立应税凭证、进行证券交易**，
以及在境外书立在境内使用的应税凭证的单位和个人课征的**行为税**。
它以**书立凭证的行为**为征税对象，因此**纳税义务发生在书立（签订）当日**，
⚠ 这与"合同是否实际履行"无关。

## Key Points

### 一、征税范围（正列举 + 负面清单）

- **应税凭证**（正列举）：**借款合同、融资租赁合同、买卖合同、承揽合同、建设工程合同、
  运输合同、技术合同、租赁合同、保管合同、仓储合同、财产保险合同**（十一类合同）；
  **产权转移书据**；**营业账簿**；**证券交易**。
- ⚠ **不属于**征税范围的凭证（负面清单）：
  - **人民法院的生效法律文书、仲裁机构的仲裁文书、监察机关的监察文书**
  - **县级以上人民政府**及其所属部门按行政管理权限**征收、收回或补偿安置房地产**书立的合同、协议
  - **总公司与分公司、分公司与分公司之间**书立的作为**执行计划**使用的凭证
  - **电网与用户**之间签订的**供用电合同**
  - **个人书立**的**动产买卖合同**
  - 在**融资性售后回租**业务中，承租人、出租人因**出售租赁资产及购回租赁资产**所签订的合同
  - **土地经营权转移书据**

### 二、纳税人与计税依据

- **纳税人**：在中国境内书立应税凭证、进行证券交易的单位和个人。
  ⚠ **不包括**应税合同的**担保人、证人、鉴定人**。
  ⚠ **证券交易印花税**对**证券交易的出让方**征收，**不对受让方**征收（**单边征收**）。
- **计税依据的通用规则**：为**合同所列的金额**，
  ⚠ **不包括**列明的**增值税税款**；⚠ 未列明金额的，按**实际结算的金额**确定。
- **各类凭证的计税依据**：

| 凭证 | 计税依据 |
|---|---|
| 租赁合同 | **租金收入** |
| 承揽合同 | **加工或承揽收入** |
| **运输合同** | **取得的运费收入**（⚠ **不包括**所运货物的金额、装卸费和保险费） |
| 技术合同 | **合同所载金额**（⚠ **研究开发费用不作为**计税依据） |
| 营业账簿 | 账簿记载的**实收资本（股本）+ 资本公积**合计金额 |
| **证券交易** | **成交金额**；⚠ 无转让价格的按**前一个交易日收盘价**；无收盘价的按**证券面值** |
| 建设工程合同 | 合同金额（⚠ **总包与分包合同都需要贴花**） |
| 融资租赁合同 | **收取或支付的租金** |

- **产权转移书据**的范围：⚠ **专利权转让、专利实施许可**所书立的合同属于**产权转移书据**；
  ⚠ **非专利技术转让合同**按"**技术合同**"计征；⚠ **土地经营权转移**不属于征税范围。
- ⚠ **同一应税合同**涉及两方以上纳税人且**未列明各自金额**的，
  以纳税人**平均分摊**的所列金额确定计税依据。

### 三、主要免税与不征

- **免征**：**无息、贴息借款合同**；**国际金融组织向我国政府及国家金融机构提供优惠贷款**的借款合同；
  **农牧业保险合同**；**与高校学生签订的高校学生公寓租赁合同**；
  **中国人民解放军、中国人民武装警察部队**书立的应税凭证；
  **财产所有人将财产赠给政府、社会福利单位、学校**所书立的产权转移书据；
  附有县级以上人民政府**抢险救灾物资运输证明文件**的运费结算凭证；
  **应税凭证的副本或者抄本**；**个人出租住房**签订的租赁合同（暂免）。
- ⚠ **同一投资主体内部**划转土地使用权、房屋等建筑物和构筑物所有权、股权书立的产权转移书据
  **免征印花税**——"同一投资主体内部"包括**母公司与其全资子公司之间、
  同一公司所属全资子公司之间、同一自然人与其设立的个人独资企业、一人有限公司、
  个体工商户之间**。
- ⚠ **金融机构与小型、微型企业**签订的借款合同**免征**印花税
  （⚠ **"小型、微型企业"不等同于"小型微利企业"**）。
- **证券交易印花税**：自 **2023-08-28** 起**减半征收**；⚠ **不享受"六税两费"减半优惠**。

### 四、征收管理

- ⚠ **纳税义务发生时间**：纳税人**书立应税凭证或者完成证券交易的当日**
  （证券交易印花税**扣缴义务发生时间**为**证券交易完成的当日**）。
- **纳税地点**：单位纳税人向**机构所在地**申报；个人纳税人向**应税凭证书立地或居住地**申报；
  ⚠ **不动产产权发生转移**的，向**不动产所在地**主管税务机关申报。
- **扣缴义务人**（证券交易）：**证券登记结算机构**，向其**机构所在地**主管税务机关申报解缴。
- **申报期限**：应税合同、产权转移书据可以**按季或者按次**申报缴纳；
  实行**按季、按年**计征的，自季度、年度**终了之日起 15 日内**申报缴纳；
  ⚠ **证券交易印花税按周解缴**（扣缴义务人自**每周终了之日起 5 日内**申报解缴）。
- **已缴纳印花税的凭证变更**：⚠ **所列金额增加的**，应就**增加部分补缴**；
  ⚠ **减少的**，可就**减少部分**申请**退还或抵缴**。
- ⚠ **未履行的**应税合同、产权转移书据，**已缴纳的印花税不予退还及抵缴税款**
  （因纳税义务已在签订时产生）。
- ⚠ **多贴印花税票**者，**不得**申请退还或抵缴。
- ⚠ 已缴纳印花税的**营业账簿**，以后年度记载的实收资本（股本）、资本公积合计金额比
  已缴纳的**增加**的，按**增加部分**计算应纳税额。
- ⚠ **纳税人转让股权**的印花税计税依据，按产权转移书据所列金额
  （⚠ **不包括**列明的**认缴后尚未实际出资权益部分**）确定。

### 五、境外书立在境内使用的应税凭证

应当缴纳印花税的情形：①标的为**不动产**的，该不动产**在境内**；
②标的为**股权**的，该股权为**中国居民企业**的股权；
③标的为动产或商标专用权、著作权、专利权、专有技术使用权的，其**销售方或者购买方在境内**，
⚠ **但不包括**境外单位或个人向境内单位或个人销售**完全在境外使用**的动产或上述权利；
④标的为**服务**的，其**提供方或接受方在境内**，
⚠ **但不包括**境外单位或个人向境内单位或个人提供**完全在境外发生**的服务。

### 教材补充（CTA《税法（二）》教材 2026 版第四章）

**（一）⚠ 征税范围的四块**

- ⚠ **应税凭证** = 《印花税法》所附《印花税税目税率表》列明的**合同、产权转移书据和营业账簿**
- ⚠ **证券交易** = 转让在**依法设立的证券交易所、国务院批准的其他全国性证券交易场所**交易的
  **股票和以股票为基础的存托凭证**
- ⚠ **我国印花税只对依法订立的书面合同征收**

**1. 合同的 11 大类**（比照《民法典》的部分合同）：

| # | 合同 | 界定要点 |
|---|---|---|
| 1 | **借款合同** | ⚠ **银行业金融机构、经国务院银行业监督管理机构批准设立的其他金融机构**与借款人（**不包括同业拆借**）的借款合同。⚠ **非上述金融机构与借款人签订的借款合同不属于应税合同** |
| 2 | **融资租赁合同** | 出租人根据承租人对**出卖人、租赁物的选择**，向出卖人购买租赁物提供给承租人使用、承租人支付租金 |
| 3 | **买卖合同** | ⚠ **动产**买卖合同（**不包括个人书立的动产买卖合同**）；还包括各**出版单位与发行单位**之间订立的图书、报纸、期刊、音像制品的**征订凭证**（含**订购单、订数单**） |
| 4 | **承揽合同** | 加工、定作、修理、复制、测试、检验合同等 |
| 5 | **建设工程合同** | 工程**勘察、设计、施工**合同 |
| 6 | **运输合同** | **公路、水路、航空、铁路货物运输合同和多式联运合同**（⚠ **不包括管道运输合同**） |
| 7 | **技术合同** | 技术**开发、许可、咨询、服务**合同 |
| 8 | **租赁合同** | 房屋租赁合同和其他租赁合同 |
| 9 | **保管合同** | 保管人有偿或无偿为寄存人保管物品，并在约定期限内或应寄存人请求返还 |
| 10 | **仓储合同** | 保管人储存存货人交付的仓储物，存货人支付仓储费 |
| 11 | **财产保险合同** | 财产、责任、保证、信用等保险合同，⚠ **不包括再保险合同** |

**2. 产权转移书据的四类**：①**土地使用权出让**书据；②**土地使用权、房屋等建筑物和构筑物
所有权转让**书据（⚠ **不包括土地承包经营权和土地经营权转移**）；
③**股权转让**书据（⚠ **不包括应缴纳证券交易印花税的股权转让书据**）；
④**商标专用权、著作权、专利权、专有技术使用权转让**书据
—— ⚠ 上述**转让包括买卖（出售）、继承、赠与、互换、分割**

**3. 营业账簿**：⚠ 目前**只对资金账簿反映「实收资本」和「资本公积」的金额**征收，
**对其他营业账簿不征收**

**（二）⚠ 纳税人五类**

| 纳税人 | 界定 |
|---|---|
| **立合同人** | 签订应税合同的当事人，是**对应税合同负有直接权利义务关系**的单位和个人。⚠ **不包括**应税合同的**担保人、证人、鉴定人**；⚠ **当事人的代理人有代理纳税的义务，与纳税人负有同等的税收法律义务和责任**<br>⚠ **委托贷款**方式书立的借款合同纳税人，为**受托方和借款人，不包括委托人**<br>⚠ 按买卖合同缴纳印花税的**拍卖成交确认书**纳税人，为**拍卖标的的产权人和买受人，不包括拍卖人** |
| **立据人** | 产权转移书据的当事人。⚠ 按产权转移书据税目缴纳印花税的**拍卖成交确认书**纳税人，同样为**产权人和买受人，不包括拍卖人** |
| **立账簿人** | **设立并使用**营业账簿的单位和个人 |
| **证券交易人** | 在境内进行证券交易的单位和个人。⚠⚠ **证券交易印花税对证券交易的出让方征收，不对受让方征收** |
| **使用人** | ⚠ **在境外书立在境内使用**的应税凭证的单位和个人，其**纳税人是使用人** |

- ⚠ **同一应税凭证**，凡由**两方或两方以上当事人共同书立并各执一份**的，
  **原则上其当事人各方都是**印花税的纳税人
- ⚠ **纳税人为境外单位或个人**：在境内**有代理人**的，以**其境内代理人为扣缴义务人**；
  **没有代理人**的，纳税人应当**自行申报**缴纳

**（三）⚠⚠ 境外书立在境内使用的四种情形**

| 应税凭证的标的 | 境内的理解 | 特殊情况 |
|---|---|---|
| **不动产** | **不动产在境内** | —— |
| **股权** | **中国居民企业的股权** | —— |
| **动产、商标专用权、著作权、专利权、专有技术使用权** | **销售方或者购买方在境内** | ⚠ **不包括**境外单位或个人向境内单位或个人**销售完全在境外使用**的动产或商标专用权、著作权、专利权、专有技术使用权 |
| **服务** | **提供方或者接受方在境内** | ⚠ **不包括**境外单位或个人向境内单位或个人**提供完全在境外发生**的服务 |

**（四）⚠ 五处具体情形**

1. ⚠ **企业之间**书立的**确定买卖关系、明确买卖双方权利义务的订单、要货单等单据**，
   且**未另外书立买卖合同**的 → 应当**按规定缴纳**印花税
2. ⚠ **发电厂与电网之间、电网与电网之间**书立的**购售电合同** →
   按**买卖合同**税目缴纳；⚠ **电网与用户之间**签订的**供用电合同不属于**列举征税的凭证，**不征收**
3. ⚠ 在**融资性售后回租**业务中，对承租人、出租人因**出售租赁资产及购回租赁资产**所签订的合同，
   **不征收**印花税
4. ⚠ **不属于征收范围的三种凭证**：①**人民法院的生效法律文书，仲裁机构的仲裁文书，
   监察机关的监察文书**；②**县级以上人民政府及其所属部门按照行政管理权限征收、收回或者
   补偿安置房地产**书立的合同、协议或者行政类文书；③**总公司与分公司、分公司与分公司之间**
   书立的**作为执行计划使用**的凭证
5. ⚠ **以电子形式签订**的各类应税凭证**均应按规定征收**印花税

**（五）⚠⚠ 五档比例税率**

现行印花税采用**比例税率**，分 **5 档**：**0.05‰（万分之零点五）、0.3‰（万分之三）、
1‰（千分之一）、0.5‰（万分之五）、0.25‰（万分之二点五）**。

| 税率 | 适用税目 |
|---|---|
| ⚠ **0.05‰** | **借款合同、融资租赁合同**（计税依据分别为**借款金额**、**租金的万分之零点五**） |
| ⚠ **0.3‰** | **买卖合同、承揽合同、建设工程合同、运输合同、技术合同**；**商标专用权、著作权、专利权、专有技术使用权转让书据**（计税依据依次为**价款的万分之三、报酬的万分之三、价款的万分之三、运输费用的万分之三、价款/报酬/使用费的万分之三、价款的万分之三**） |
| ⚠ **1‰** | **租赁合同、保管合同、仓储合同、财产保险合同、证券交易**（计税依据依次为**租金的千分之一、保管费的千分之一、仓储费的千分之一、保险费的千分之一、成交金额的千分之一**） |
| ⚠ **0.5‰** | **土地使用权出让书据、土地使用权/房屋等建筑物和构筑物所有权转让书据、股权转让书据**（均为**价款的万分之五**） |
| ⚠ **0.25‰** | **营业账簿**（**实收资本（股本）+ 资本公积合计金额的万分之二点五**） |

**（六）⚠ 计税依据的十二项基本规定**

1. ⚠ **借款合同**（五种形态的计税方法）：
   - 一是一项信贷业务**既签订借款合同又一次或分次填开借据**的 → **只以借款合同所载金额**计税贴花；
     ⚠ **只填开借据并作为合同使用**的 → 应以**借据所载金额**计税贴花
   - ⚠ 二是**流动资金周转性借款合同**（按年/期签订、规定最高限额、限额内随借随还）→
     **只以其规定的最高限额**为计税依据，**在签订时贴花一次**；
     ⚠ **在限额内随借随还不签订新合同的，不再另贴印花**
   - ⚠ 三是**以财产作抵押**取得抵押贷款的合同 → 应按**借款合同**贴花；
     ⚠ 在借款方**无力偿还而将抵押财产转移给贷款方**时，应**再就双方书立的产权书据**
     按产权转移书据计税贴花
   - ⚠ 四是**银团贷款**（银团各方均承担一定贷款数额）→
     **借款方与贷款银团各方应分别在所执的合同正本上，按各自的借款金额**计税贴花
   - ⚠ 五是**基本建设贷款**（按年度用款计划分年签订合同、最后一年按总概算签订总合同）→
     **应按分合同分别贴花**；⚠ **最后签订的总合同，只就借款总额扣除分合同借款金额后的余额**计税
2. **融资租赁合同** → **收取或支付的租金**
3. **买卖合同** → **合同记载的价款，不得做任何扣除**；⚠ **以物易物的易货合同**
   是反映既购又销双重经济行为的合同，计税依据为**合同所载的购、销合计金额**
4. ⚠ **承揽合同**（两种情形）：
   - 由**承揽人提供原材料**的加工、定做合同：**分别记载**加工费金额和原材料金额的 →
     **分别按承揽合同、买卖合同**计税；⚠ **未分别记载**的 → **就全部金额依照承揽合同**计税
   - 由**定做人提供主要材料或原料**、承揽人只提供辅助材料的加工合同 →
     ⚠ **无论是否分别记载**，均以**辅助材料与加工费的合计数**依照**承揽合同**计税；
     ⚠ **对定做人提供的主要材料或原料金额不计税贴花**
5. **建设工程合同** → **合同约定的价款**
6. ⚠ **运输合同** → **取得的运费收入**，⚠ **不包括所运货物的金额、装卸费和保险费**等
   - ⚠ **境内货物多式联运**：**起运地统一结算全程运费**的 → 以**全程运费**为计税依据，
     由**起运地运费结算双方**缴纳；**分程结算**的 → 以**分程的运费**为计税依据，分别由各结算方缴纳
   - ⚠ **国际货运**：**由我国运输企业运输**的 → **运输企业所持**凭证以**本程运费**为计税依据；
     **托运方所持**凭证按**全程运费**为计税依据。
     ⚠ **由外国运输企业运输进出口货物**的 → **外国运输企业所持凭证免纳**印花税；
     **托运方所持**凭证以**运费金额**为计税依据
   - ⚠ **国际货运运费结算凭证在国外办理**的 → 应在**凭证转回我国境内时**依法缴纳
7. ⚠ **技术合同** → **合同所载的价款、报酬、使用费**；
   ⚠ **对技术开发合同，只就合同所载的报酬金额计税，研究开发经费不作为计税依据**；
   ⚠ **但合同约定按研究开发经费一定比例作为报酬**的 → 应按**一定比例的报酬金额**贴花
8. **租赁合同** → **租金收入**
9. **保管合同** → **收取（支付）的保管费**
10. **仓储合同** → **收取的仓储费**
11. ⚠ **财产保险合同** → **支付（收取）的保险费**，⚠ **不包括所保财产金额**
12. **产权转移书据** → **书据所列的金额**，⚠ **不包括列明的增值税税款**
13. ⚠ **营业账簿** → 「**实收资本**」与「**资本公积**」**两项合计金额**；
    ⚠ **已缴纳印花税的营业账簿，以后年度记载的实收资本（股本）、资本公积合计金额
    比已缴纳时增加的，按照增加部分计算应纳税额**
14. ⚠ **证券交易** → **成交金额**；⚠ **无转让价格**的，
    按**办理过户登记手续时该证券前一个交易日收盘价**计算；⚠ **无收盘价**的，按**证券面值**计算

**（七）⚠ 计税依据的九项具体规定**

1. ⚠ **同一应税合同、产权转移书据涉及两方以上纳税人且未列明各自涉及金额**的 →
   以纳税人**平均分摊**的应税凭证所列金额（**不包括列明的增值税税款**）确定计税依据
2. ⚠⚠ **所列金额与实际结算金额不一致**：**不变更**凭证所列金额的 → **以所列金额**为计税依据；
   **变更**的 → 以**变更后的所列金额**为计税依据
   - ⚠ 已缴纳印花税的凭证，**变更后所列金额增加**的 → 就**增加部分补缴**；
     **减少**的 → 可就**减少部分申请退还或抵缴**
3. ⚠ 因**列明的增值税税款计算错误**导致计税依据增减的 → 应调整列明的增值税税款、
   **重新确定**计税依据；⚠ 已缴纳的，**增加补缴、减少可退或抵缴**
4. ⚠ **转让股权**的计税依据 = 产权转移书据所列的金额
   （⚠ **不包括列明的认缴后尚未实际出资权益部分**）
5. ⚠ **金额为人民币以外的货币**的 → 按**凭证书立当日**的人民币汇率中间价折合
6. ⚠ **未列明金额**的 → 按**实际结算**的金额确定；⚠ 仍不能确定的 →
   按**书立时的市场价格**确定；**依法应执行政府定价或政府指导价**的，按国家有关规定确定
7. ⚠ **未履行**的应税合同、产权转移书据，**已缴纳的印花税不予退还及抵缴**
8. ⚠ 纳税人**多贴的印花税票，不予退税及抵缴**
9. ⚠ **同一应税凭证载有两个以上税目事项并分别列明金额**的 → 按**各自适用的税目税率分别**计算；
   ⚠ **未分别列明金额**的 → **从高适用税率**

**（八）⚠ 基本免税八项**

1. **应税凭证的副本或者抄本**
2. 依照法律规定应当予以免税的**外国驻华使馆、领事馆和国际组织驻华代表机构
   为获得馆舍书立**的应税凭证
3. **中国人民解放军、中国人民武装警察部队**书立的应税凭证
4. ⚠ **农民、家庭农场、农民专业合作社、农村集体经济组织、村民委员会
   购买农业生产资料或者销售农产品**书立的**买卖合同和农业保险合同**
   —— ⚠ **家庭农场**的具体范围为以**家庭为基本经营单元**、以**农场生产经营为主业**、
   以**农场经营收入为家庭主要收入来源**，从事**农业规模化、标准化、集约化**生产经营，
   **纳入全国家庭农场名录系统**的家庭农场
5. ⚠ **无息或者贴息借款合同**、**国际金融组织向中国提供优惠贷款**书立的借款合同
6. ⚠ **财产所有权人将财产赠与政府、学校、社会福利机构、慈善组织**书立的产权转移书据
   —— ⚠ **学校**范围为经县级以上人民政府或其教育行政部门批准成立的**大学、中学、小学、幼儿园**，
   实施学历教育的**职业教育学校、特殊教育学校、专门学校**，以及经省级人民政府或其人力资源
   社会保障行政部门批准成立的**技工院校**；⚠ **社会福利机构**范围为依法登记的**养老服务机构、
   残疾人服务机构、儿童福利机构、救助管理机构、未成年人救助保护机构**；
   ⚠ **慈善组织**范围为依法设立、符合《慈善法》规定、**以面向社会开展慈善活动为宗旨**的
   非营利性组织
   - ⚠⚠ **易错提示**：**财产所有权人将财产赠与企业**书立的产权转移书据**不能**享受免税
7. ⚠ **非营利性医疗卫生机构采购药品或者卫生材料**书立的买卖合同
   —— 范围为经**县级以上人民政府卫生健康行政部门批准或者备案设立**的非营利性医疗卫生机构
8. ⚠ **个人与电子商务经营者订立的电子订单**

- ⚠ **授权立法**：根据国民经济和社会发展的需要，**国务院**对**居民住房需求保障、企业改制重组、
  破产、支持小型微型企业发展**等情形可以规定减征或者免征印花税，**报全国人大常委会备案**

**（九）计税与征管的五组要点**

- ⚠ **应纳税额 = 应税凭证和证券交易计税金额 × 适用税率**
- ⚠ **纳税义务发生时间** = 纳税人**书立应税凭证或者完成证券交易**的当日；
  ⚠ **证券交易印花税扣缴义务发生时间**为**证券交易完成**的当日
- ⚠ **纳税期限**：**按季、按年或者按次**计征
  - ⚠ **按季、按年**计征的 → 自**季度、年度终了之日起 15 日内**申报缴纳
  - ⚠ **按次**计征的 → 自**纳税义务发生之日起 15 日内**申报缴纳
  - ⚠ **应税合同、产权转移书据**印花税可**按季或者按次**申报；
    **应税营业账簿**印花税可**按年或者按次**申报；⚠ **具体纳税期限由各省、自治区、直辖市、
    计划单列市税务局结合征管实际确定**
  - ⚠ **境外单位或个人**的应税凭证印花税可**按季、按年或者按次**申报，具体期限同由省级税务局确定
  - ⚠⚠ **证券交易印花税按周解缴**：扣缴义务人应当自**每周终了之日起 5 日内**申报解缴税款
    以及银行结算的利息
  - ⚠ **未列明金额、后续实际结算确定金额**的 → 纳税人应当于**书立后的首个纳税申报期**
    申报**书立情况**，在**实际结算后下一个纳税申报期**以**实际结算金额**计算申报缴纳
- ⚠ **纳税地点**：纳税人为**单位**的 → **机构所在地**；为**个人**的 →
  **应税凭证书立地或者纳税人居住地**；⚠ **不动产产权转移**的 → **不动产所在地**
  - ⚠ 纳税人为**境外单位或个人且在境内没有代理人**的 → **自行申报**；
    可向**资产交付地、境内服务提供方或者接受方所在地（居住地）、
    书立应税凭证境内书立人所在地（居住地）**主管税务机关申报；
    ⚠ **涉及不动产产权转移的，应当向不动产所在地**主管税务机关申报
- ⚠ **源泉扣缴**：纳税人为**境外单位或个人且在境内有代理人**的 →
  以**其境内代理人为扣缴义务人**，向**境内代理人机构所在地（居住地）**主管税务机关申报解缴；
  ⚠ **证券登记结算机构**为**证券交易印花税**的扣缴义务人，向其机构所在地主管税务机关申报解缴
  **税款以及银行结算的利息**
- ⚠ **减免税管理**：实行「**自行研判、申报享受、有关资料留存备查**」的办理方式；
  ⚠ 对应税凭证适用减免优惠的，**书立该应税凭证的纳税人均可享受**，
  明确特定纳税人适用减免优惠的除外
