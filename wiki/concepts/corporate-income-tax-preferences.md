# 企业所得税税收优惠

## Definition

企业所得税税收优惠（Corporate Income Tax Preferences）：降低企业所得税实际负担的制度安排，
按作用方式分为**税率式**（减低税率）、**税基式**（加计扣除、减计收入、加速折旧）、
**税额式**（税额抵免、减免税）三类。

⚠ **本页是总纲**。四类优惠中体量最大、计算最繁的四项已各自独立成页，
本页保留入口并承载**其余各项**（免税收入、免征减征、减计收入、创业投资抵扣、
区域优惠、特定行业优惠）：

| 独立子页 | 承载内容 |
|---|---|
| [[high-tech-enterprise-tax-preference]] | 高新技术企业（15%）、技术先进型服务企业（15%） |
| [[small-micro-profit-enterprise-tax-preference]] | 小型微利企业（20% 税率 + 减按 25% 计应纳税所得额） |
| [[research-and-development-expense-super-deduction]] | 研发费用加计扣除（100%／集成电路与工业母机 120%）、基础研究、残疾人工资 |
| [[corporate-income-tax-accelerated-depreciation]] | 加速折旧、一次性税前扣除 |
| [[tax-investment-credit]] | 专用设备投资额抵免（10%）、数字化智能化改造、境外投资者再投资抵免 |

## Key Points

### 一、税率式优惠

| 对象 | 优惠 |
|---|---|
| **高新技术企业** | **15%**（资格期满当年、重新认定前暂按 15% 预缴）→ [[high-tech-enterprise-tax-preference]] |
| **技术先进型服务企业** | **15%** → [[high-tech-enterprise-tax-preference]] |
| **小型微利企业** | **减按 25% 计入应纳税所得额，按 20% 税率**缴纳（实际税负 **5%**）→ [[small-micro-profit-enterprise-tax-preference]] |
| **西部大开发** | 西部地区（含**比照执行**的湖南湘西、湖北恩施、吉林延边、江西赣州）**鼓励类产业企业** **15%** |
| **海南自由贸易港** | 注册并**实质性运营**的鼓励类产业企业 **15%** |
| **污染防治第三方企业** | **15%**（2019-01-01 至 2027-12-31） |
| **上海临港新片区** | 集成电路、人工智能、生物医药、民用航空关键领域核心环节企业，自**设立之日起 5 年内** **15%** |
| **上海浦东新区特定区域**公司型创业投资企业 | 转让持有 **5 年以上**股权所得占年度股权转让所得总额比例超 **50%** → 按年末个人股东持股比例**免征**；**3 年以上**的为**减半** |
| **非居民企业**（未设机构场所或所得无实际联系） | 法定 **20%**、**减按 10%** 征收 |

### 二、免征与减征优惠

#### （一）农、林、牧、渔业项目

**免税项目（8 项）**：①**蔬菜、谷物、薯类、油料、豆类、棉花、麻类、糖料、水果、坚果**的种植；
②**农作物新品种的选育**；③**中药材**的种植；④**林木的培育和种植**；⑤**牲畜、家禽的饲养**；
⑥**林产品的采集**；⑦灌溉、农产品初加工、兽医、农技推广、农机作业和维修等**农、林、牧、渔服务业**项目；
⑧**远洋捕捞**。

**减半征收项目（2 项）**：①**花卉、茶以及其他饮料作物和香料作物**的种植；②**海水养殖、内陆养殖**。

⚠ **口径归类的三处规定**：

- **猪、兔的饲养**按「牲畜、家禽的饲养」处理；**饲养牲畜、家禽产生的分泌物、排泄物**同样按此项目处理
- **观赏性作物的种植**按「花卉、茶以及其他饮料作物和香料作物的种植」处理
- **「牲畜、家禽的饲养」以外的生物养殖项目**按「海水养殖、内陆养殖」处理

⚠ **其余细则**：

- 「农作物新品种选育」的免税所得指企业对农作物进行品种和育种材料选育形成的成果，
  以及由这些成果形成的**种子（苗）等繁殖材料的生产、初加工、销售一体化**取得的所得
- 「林木的培育和种植」的免税所得包括企业通过**拍卖或收购**方式取得林木所有权并经过一定生长周期、
  对林木进行再培育取得的所得
- **受托初加工**：企业根据委托合同受托对规定农产品进行初加工服务，**所收取的加工费**
  可按农产品初加工的免税项目处理
- ⚠ **对外购茶叶进行筛选、分装、包装后销售的所得，不享受**农产品初加工优惠
- **远洋捕捞**：取得**农业农村部**颁发的「远洋渔业企业资格证书」并**在有效期内**的远洋渔业企业，
  从事远洋捕捞业务取得的所得**免征**
- ⚠ **购入农产品再种植、养殖**：将购入的农林牧渔产品在自有或租用场地进行**育肥、育秧**等再种植、养殖，
  **经过一定生长周期使其生物形态发生变化**，且**并非由于本环节加工而明显增加使用价值**的，
  可视为农产品的种植、养殖项目享受优惠
- ⚠ **委托与受托均可享受**：企业**委托**其他企业或个人从事规定农林牧渔项目取得的所得可享受优惠；
  企业**受托**从事取得的收入**比照委托方**享受
- ⚠ **购买农产品后直接销售的贸易活动产生的所得不能享受**
- ⚠ 同时从事适用不同政策规定项目的应**分别核算**；**核算不清**的可由税务机关按
  **比例分摊法或其他合理方法核定**

#### （二）国家重点扶持的公共基础设施项目

- 范围：《公共基础设施项目企业所得税优惠目录（2008 年版）》规定的**港口码头、机场、铁路、公路、
  城市公共交通、电力、水利**等项目
- ⚠ **三免三减半**：自项目取得**第一笔生产经营收入**所属纳税年度起，
  **第 1 至第 3 年免征**，**第 4 至第 6 年减半**征收
- ⚠ **不得享受**的情形：企业**承包经营、承包建设和内部自建自用**上述项目的
- ⚠ **一次核准、分批次建设**（如码头、泊位、航站楼、跑道、路段、发电机组等）的，
  同时符合以下**三个条件**可按**每一批次为单位**计算所得并享受优惠：
  ①不同批次在**空间上相互独立**；②**每一批次自身具备取得收入的功能**；
  ③以**每一批次为单位进行会计核算**、单独计算所得并合理分摊期间费用
- ⚠ **农村饮水安全工程新建项目**同样适用三免三减半
- ⚠ 「**第一笔生产经营收入**」指公共基础设施项目**建成并投入运营（包括试运营）后**
  所取得的**第一笔主营业务收入**
- ⚠ 同时从事**不在目录范围**的生产经营项目的，应与享受优惠的项目所得**分开核算**并合理分摊期间共同费用；
  **没有单独核算的不得享受**。分摊比例可按投资额、销售收入、资产额、人员工资等参数确定，
  **一经确定不得随意变更**，特殊情况需改变的**报主管税务机关核准**
- ⚠ **转让**：在**减免税期限内**转让且受让方承续经营的，
  受让方**自受让之日起在剩余优惠期限内**享受；**减免税期限届满后**转让的，
  受让方**不得就该项目重复享受**
- **电网新建项目**（自 2013-01-01 起）：可依法享受三免三减半。⚠ **核算方法**：
  - 对**能独立核算收入**的 330 千伏以上跨省及长度超 200 千米的交流输变电新建项目
    和 500 千伏直流输变电新建项目 → 按项目营业收入、营业成本等**单独计算**应纳税所得额
  - 对**不能独立核算收入**的其他新建输变电项目 → 先依税法计算企业应纳税所得额，
    再按**项目投运后的新增输变电固定资产原值占企业总输变电固定资产原值的比例**计算减免额
  - 2013-01-01 **前**的电网新建项目：已享受优惠的**不再调整**；未享受的**可享受剩余年限**

#### （三）环境保护、节能节水项目

- 范围：**公共污水处理、公共垃圾处理、沼气综合开发利用、节能减排技术改造、海水淡化**等
  （具体见《环境保护、节能节水项目企业所得税优惠目录（2021 年版）》，自 2021-01-01 起施行）
- ⚠ 同为**三免三减半**：自项目取得第一笔生产经营收入所属纳税年度起，
  第 1 至第 3 年免征，第 4 至第 6 年减半征收
- ⚠ 在**减免税期限内转让**的，**受让方自受让之日起在剩余期限内**享受；
  期限届满后转让的，受让方**不得重复享受**

#### （四）符合条件的技术转让所得

- ⚠ **一个纳税年度内**，居民企业技术转让所得**不超过 500 万元**的部分**免征**；
  **超过 500 万元**的部分**减半**征收
- **五项条件**：①主体为**居民企业**；②技术转让属于财政部、国家税务总局规定的范围；
  ③**境内**技术转让经**省级以上科技部门**认定；④**向境外**转让技术经**省级以上商务部门**认定；
  ⑤国务院税务主管部门规定的其他条件
- **技术范围**：专利技术、计算机软件著作权、集成电路布图设计权、植物新品种、生物医药新品种等。
  ⚠ **技术转让**指转让其拥有符合范围技术的**所有权**或 **5 年以上（含 5 年）全球独占许可使用权**
- ⚠ **所得计算**：**技术转让所得 = 技术转让收入 − 技术转让成本 − 相关税费**
  - **技术转让收入**不包含销售或转让**设备、仪器、零部件、原材料等非技术性收入**；
    ⚠ **不属于与技术转让项目密不可分**的技术咨询、技术服务、技术培训等收入**不得计入**
    （可计入的须满足：在技术转让合同中**约定**、与该技术转让**相关**、与项目收入**一并收取价款**）
  - **技术转让成本** = 转让的无形资产的**净值**（计税基础减除已按规定计算的摊销扣除额后的余额）
- ⚠ **不得享受的关联方**：**直接或间接持有股权之和达到 100% 的关联方**取得的技术转让所得，
  **不享受**减免企业所得税优惠政策
- ⚠ 应**单独计算**技术转让所得并合理分摊期间费用；**没有单独计算的不得享受**
- **非独占许可使用权**（自 2015-10-01 起）：全国范围内居民企业转让 **5 年（含）以上
  非独占许可使用权**取得的技术转让所得，**纳入**享受优惠的范围
  - ⚠ 限于其**拥有所有权**的技术（技术所有权权属由**国务院行政主管部门**确定）
  - ⚠ 所得计算口径不同：
    **技术转让所得 = 技术转让收入 − 无形资产摊销费用 − 相关税费 − 应分摊期间费用**
  - 技术许可使用权转让收入应按协议约定的**许可使用权人应付许可使用权使用费的日期**确认收入实现

#### （五）其余免征与减征事项

| 事项 | 规定 |
|---|---|
| **深港通** | 内地企业投资者通过深港通投资香港联交所上市股票取得的**转让差价所得**，计入收入总额依法征税；**股息红利所得**同样计入收入总额计征，⚠ 但内地居民企业**连续持有 H 股满 12 个月**取得的股息红利**依法免征**。⚠ H 股公司对内地企业投资者**不代扣**股息红利所得税款，由企业**自行申报**；对**非 H 股**上市公司已代扣代缴的股息红利所得税可依法**申请税收抵免** |
| **内地与香港基金互认** | 内地企业投资者通过基金互认买卖香港基金份额取得的**转让差价所得**和从香港基金**分配取得的收益**，均计入收入总额依法征收企业所得税；**ETF** 纳入互联互通机制后适用现行基金互认税收政策 |
| **文化事业单位转制** | **2027-12-31 前**，经营性文化事业单位转制为企业，自**转制注册之日起 5 年内**免征；在 2027-12-31 享受不满 5 年的可继续享受至 5 年期满。⚠ 2022-12-31 前转制的，自转制注册之日起**至 2027-12-31** 免征 |
| **重点群体创业就业** | 2023-01-01 至 2027-12-31，企业招用**脱贫人口**及**登记失业半年以上**且持《就业创业证》或《就业失业登记证》人员，签 **1 年以上**劳动合同并依法缴纳社保的，自签订劳动合同并缴社保**当月起**，在 **3 年（36 个月）**内按实际招用人数**定额依次扣减**增值税、城市维护建设税、教育费附加、地方教育附加和企业所得税。⚠ 定额标准**每人每年 6000 元**，最高可**上浮 30%**；**当年扣减不完的不得结转下年** |
| **铁路债券利息** | 对企业投资者持有 **2023—2027 年发行**的铁路债券取得的利息收入**减半**征收。铁路债券指以**中国国家铁路集团有限公司**为发行和偿还主体的债券，包括中国铁路建设债券、中期票据、短期融资券等 |
| **生产和装配伤残人员专门用品** | 至 2027-12-31，对符合条件的企业**免征**。**六项条件**：①生产装配且在民政部《中国伤残人员专门用品目录》范围内；②以销售该用品为主，年度该项销售收入（**不含出口**）占**收入总额 60% 以上**；③**账证健全**，能准确完整提供纳税资料且该项收入能**单独准确核算**；④拥有假肢／矫形器制作师资格证书的专业技术人员**不少于 1 人**（生产人员超 20 人的，不少于全部生产人员的 **1/6**）；⑤具有相适应的生产装配**专用设备和工具**；⑥具有独立的接待室、制作室和功能训练室，**使用面积不少于 115 平方米** |
| **节能服务公司（合同能源管理）** | ⚠ 同为**三免三减半**，自项目取得第一笔生产经营收入所属纳税年度起，**第 1 至第 3 年免征**，**第 4 至第 6 年按 25% 的法定税率减半**征收。⚠ 签订**节能效益分享型合同**、分享期**短于 6 年**的，**按实际分享期**享受。用能企业按合同**实际支付给节能服务公司的合理支出均可扣除**，不再区分服务费用与资产价款；合同期满后节能服务公司转让资产按**折旧或摊销期满的资产**进行税务处理 |
| **证券投资基金** | ①对基金从证券市场中取得的收入（买卖股票债券的差价收入、股权的股息红利收入、债券利息收入及其他收入）**暂不征收**；②对**投资者从基金分配中取得的收入**暂不征收；③对**基金管理人运用基金买卖股票、债券的差价收入**暂不征收；④对**公募基金转让创新企业 CDR** 取得的差价所得和**持有 CDR 取得的股息红利所得**暂不征收 |
| **保险保障基金** | 2008-01-01 至 2027-12-31，对**中国保险保障基金有限责任公司**依《保险保障基金管理办法》取得的六项收入免征：①境内保险公司依法缴纳的**保险保障基金**；②依法从**撤销或破产**保险公司清算财产中获得的受偿收入和向有关责任方**追偿所得**，以及依法从保险公司**风险处置**中获得的财产转让所得；③**接受捐赠**收入；④**银行存款利息**收入；⑤购买政府债券、中央银行、中央企业和中央级金融机构发行债券的**利息**收入；⑥国务院批准的其他资金运用取得的收入 |

### 三、减计收入优惠（按 90% 计入收入总额）

- **综合利用资源**：企业以《资源综合利用企业所得税优惠目录》规定的资源作为**主要原材料**，
  生产国家**非限制和禁止**并符合国家和行业相关标准的产品取得的收入，**减按 90% 计入**收入总额。
  ⚠ 原材料占生产产品材料的比例**不得低于**目录规定的标准
- **社区养老、托育、家政服务**：自 **2019-06-01 至 2025-12-31**，取得的收入减按 90% 计入收入总额
- **金融机构农户小额贷款利息收入**：**2027-12-31 前**减按 90% 计入收入总额
  - ⚠ **农户**指长期（**一年以上**）居住在**乡镇（不包括城关镇）**行政管理区域内的住户，
    还包括长期居住在**城关镇所辖行政村**范围内的住户和户口不在本地而在本地居住**一年以上**的住户、
    国有农场的职工和农村个体工商户
  - ⚠ **不属于农户**：位于乡镇（不含城关镇）区域内和城关镇所辖行政村范围内的**国有经济的机关、
    团体、学校、企事业单位的集体户**；有本地户口但**举家外出谋生一年以上**的住户
    （**无论是否保留承包耕地**）
  - ⚠ **小额贷款**指**单笔且该农户贷款余额总额在 10 万元（含本数）以下**的贷款
  - ⚠ 应**单独核算**符合条件的农户小额贷款利息收入，**不能单独核算的不得适用**
- **保险公司农业保险保费收入**：**2027-12-31 前**，为**种植业、养殖业**提供保险业务取得的保费收入
  减按 90% 计入。⚠ 保费收入 = **原保险保费收入 + 分保费收入 − 分出保费**
- **小额贷款公司农户小额贷款利息收入**：自 **2017-01-01 至 2027-12-31**，
  对经**省级地方金融监督管理部门批准成立**的小额贷款公司取得的农户小额贷款利息收入
  减按 90% 计入。⚠ 小额贷款口径同上（单笔且该农户贷款余额总额 **10 万元（含）以下**）

### 四、创业投资企业抵扣应纳税所得额（70%）

⚠ 四种情形，**共同要素**是「**股权投资方式** + **投资满 2 年（24 个月）** + **按投资额 70% 抵扣**
+ **当年不足抵扣可结转**」。

| # | 投资主体 | 被投对象 |
|---|---|---|
| 1 | **创业投资企业** | 未上市的**中小高新技术企业** |
| 2 | **有限合伙制创业投资企业的法人合伙人** | 同上 |
| 3 | **公司制创业投资企业** | 符合条件的**初创科技型企业** |
| 4 | **有限合伙制创业投资企业的法人合伙人** | 同上 |

- ⚠ **抵扣时点**：在**股权持有满 2 年的当年**抵扣该创业投资企业（或法人合伙人从该企业分得）的
  **应纳税所得额**；当年不足抵扣的可在**以后纳税年度结转抵扣**
- ⚠ **有限合伙制**下：投资额按有限合伙制创业投资企业对中小高新技术企业的**实缴投资额**
  × **合伙协议约定的法人合伙人出资比例**计算确定（出资比例按**实缴出资额**口径计算）；
  ⚠ 且**法人合伙人对该有限合伙制创业投资企业的实缴出资也应满 2 年**
- **未上市中小高新技术企业的标准**：须通过认定取得**高新技术企业资格**，
  同时符合**职工人数不超过 500 人**、**年销售（营业）额不超过 2 亿元**、
  **资产总额不超过 2 亿元**；「**未上市**」指未通过证券交易所**首次公开**向投资者发行股票募集资金
  - ⚠ 中小企业接受创业投资之后经认定符合高新技术企业标准的，
    **应自其被认定为高新技术企业的年度起**计算创业投资企业的投资期限
- **初创科技型企业的五项条件**：①在中国境内（不含港澳台）注册成立、实行**查账征收**的居民企业；
  ②接受投资时**从业人数不超过 300 人**，其中**具有大学本科以上学历的从业人数不低于 30%**，
  **资产总额和年销售收入均不超过 5000 万元**；③接受投资时**设立时间不超过 5 年（60 个月）**；
  ④接受投资时以及接受投资后 **2 年内未在境内外证券交易所上市**；
  ⑤接受投资当年及下一纳税年度**研发费用总额占成本费用支出的比例不低于 20%**
- ⚠ **公司制创业投资企业**须为在中国境内（不含港澳台）注册成立、实行**查账征收**的居民企业，
  且**不属于**被投资初创科技型企业的**发起人**
- ⚠ **投资后 2 年内，创业投资企业及其关联方持有被投资初创科技型企业的股权比例合计应低于 50%**
- ⚠ **仅限于**通过向被投资初创科技型企业**直接支付现金**方式取得的股权投资，
  **不包括受让其他股东的存量股权**；投资额按**实缴投资额**确定
- ⚠ 法人合伙人投资于**多个**符合条件的合伙创业投资企业，**可合并计算**其可抵扣的投资额和分得的所得

### 五、集成电路产业和软件产业优惠（自 2020-01-01 起）

| 对象 | 优惠 |
|---|---|
| 国家鼓励的集成电路**线宽小于 28 纳米（含）**且**经营期在 15 年以上**的生产企业或项目 | 第 **1 至第 10 年免征** |
| 集成电路**线宽小于 65 纳米（含）**且**经营期在 15 年以上** | 第 **1 至第 5 年免征**，第 **6 至第 10 年**按 25% 法定税率**减半** |
| 集成电路**线宽小于 130 纳米（含）**且**经营期在 10 年以上** | 第 **1 至第 2 年免征**，第 **3 至第 5 年**按 25% 法定税率**减半** |
| 国家鼓励的集成电路**设计、装备、材料、封装、测试企业**和**软件企业** | 自**获利年度**起第 **1 至第 2 年免征**，第 **3 至第 5 年**按 25% 法定税率**减半** |
| 国家鼓励的**重点**集成电路设计企业和软件企业 | 自**获利年度**起第 **1 至第 5 年免征**，接续年度**减按 10%** 的税率征收 |

- ⚠ **优惠期起算点的分野**：按**集成电路生产企业**享受优惠的 → 优惠期自**获利年度**起计算；
  按**集成电路生产项目**享受优惠的 → 自**项目取得第一笔生产经营收入所属纳税年度**起计算
  （⚠ 项目需**单独会计核算、计算所得**并合理分摊期间费用）
- ⚠ 国家鼓励的**线宽小于 130 纳米（含）**的集成电路生产企业，属于国家鼓励的集成电路生产企业
  清单**年度前 5 个纳税年度**发生的**尚未弥补完的亏损**，准予向以后年度结转，
  总结转年限**最长不得超过 10 年**
- ⚠ 清单管理：已列入清单的企业如需享受新一年度优惠，**需重新申报**；
  列入清单的企业在下一年度**预缴申报**时**可自行判断**，符合的可先行享受；
  年度汇算清缴时如**未被列入**下一年度清单，按规定**补缴税款，依法不加收滞纳金**

### 六、其余行业（地区）优惠

- **西部大开发**（**2021-01-01 至 2030-12-31**）：对设在西部地区的**鼓励类产业企业**减按 **15%** 征收
  - **适用范围**：内蒙古、广西、重庆、四川、贵州、云南、西藏、陕西、甘肃、青海、宁夏、新疆
    和新疆生产建设兵团；⚠ 此外**湖南湘西土家族苗族自治州、湖北恩施土家族苗族自治州、
    吉林延边朝鲜族自治州和江西赣州市**可**比照**执行
  - ⚠ **鼓励类产业企业**指以《西部地区鼓励类产业目录》规定的产业项目为**主营业务**，
    且其**主营业务收入占企业收入总额 60% 以上**的企业
    （⚠ 2011-01-01 至 2020-12-31 期间该比例为 **70%** 以上，是**已废止的旧口径**）
  - ⚠ 企业在**优惠区域内、外分别设有机构**的，**仅就设在优惠区域内的机构的所得**适用 15%
- **污染防治第三方企业**（2019-01-01 至 2027-12-31）：符合条件者减按 **15%**。
  ⚠ 指受**排污企业或政府委托**，负责**环境污染治理设施运营维护**的企业。
  **七项条件**：①境内依法注册的居民企业；②具有 **1 年以上**连续从事环境污染治理设施运营实践
  且能保证设施正常运行；③具有**至少 5 名**环保相关专业**中级及以上**技术职称的技术人员，
  或者**至少 2 名**环保相关专业**高级及以上**技术职称的技术人员；
  ④环保设施运营服务年度营业收入占总收入比例**不低于 60%**；⑤具备**检验能力、拥有自有实验室**；
  ⑥保证设施正常运行，污染物排放指标能**连续稳定达标**；
  ⑦**近三年内纳税信用等级未被评定为 C 级或 D 级**
- **上海临港新片区**（自 2020-01-01 起）：符合条件的企业自**设立之日起 5 年内**减按 **15%** 征收
- **海南自由贸易港**（2020-01-01 至 2027-12-31）：
  - 注册在海南自由贸易港并**实质性运营**的**鼓励类产业企业**减按 **15%**
    - ⚠ **鼓励类产业企业** = 以《海南自由贸易港鼓励类产业目录》规定的产业项目为**主营业务**，
      且**主营业务收入占企业收入总额 60% 以上**
    - ⚠ **实质性运营** = 企业的**实际管理机构设在海南自由贸易港**，并对企业生产经营、人员、
      账务、财产等实施**实质性全面管理和控制**；**不符合实质性运营的企业不得享受**
    - ⚠ **总机构**设在海南自贸港的企业 → **仅就**设在自贸港的**总机构和分支机构的所得**适用 15%；
      **总机构设在自贸港以外**的企业 → **仅就**设在自贸港内的符合条件**分支机构的所得**适用 15%
  - ⚠ 对在海南自贸港设立的**旅游业、现代服务业、高新技术产业**企业**新增境外直接投资**取得的所得
    **免征**企业所得税。**条件**：①从境外**新设分支机构**取得的营业利润，
    或从**持股比例超过 20%（含）**的境外子公司分回的、与新增境外直接投资相对应的股息所得；
    ②**被投资国（地区）的企业所得税法定税率不低于 5%**
  - ⚠ 新购置（含自建、自行开发）**固定资产或无形资产**：单位价值**不超过 500 万元（含）**的
    允许**一次性**扣除；**超过 500 万元**的可缩短折旧摊销年限或加速折旧摊销

### 七、非居民企业税收优惠

- 非居民企业减按 **10%** 的税率征收企业所得税。
  ⚠ 此处的非居民企业指在中国境内**未设立机构、场所**，或者虽设立机构、场所但取得的所得
  **与其所设机构、场所没有实际联系**的企业
- ⚠ 该类非居民企业取得下列所得**免征**企业所得税：
  ①**外国政府**向中国政府提供贷款取得的利息所得；
  ②**国际金融组织**向中国政府和居民企业提供**优惠贷款**取得的利息所得；
  ③经**国务院批准**的其他所得
