# 交易性金融资产

## Definition

交易性金融资产（Trading Financial Assets）：以**公允价值**计量且其变动计入**当期损益**的金融资产，是企业为近期内出售而持有的投资。

它与其他金融资产类别的三条分界线是：**交易费用进损益不进成本**、**公允价值变动进损益不进权益**、**不计提减值**。

## Key Points

- **初始计量**（第 196 题）：
  - 按**取得时的公允价值**作为初始确认金额
  - ⚠ 相关的**交易费用**在发生时计入**当期损益**（**投资收益**），**不计入**初始成本
  - ⚠ 取得时支付价款中包含的**已宣告但尚未发放的现金股利**（或已到付息期但尚未领取的利息），
    应当作为**应收项目**单独列示
  - 取得时的**入账价值** = 购买价 − 买价中包含的已宣告未发放现金股利/已过付息期未领取利息
    − 交易费用（若交易费用**另行支付**则不减去）
- **后续计量**（第 215 题）：
  - 资产负债表日，公允价值**高于**其账面余额的差额计入**当期损益**（公允价值变动损益）
  - 对于**债权性质**的交易性金融资产，企业可通过「交易性金融资产——**公允价值变动**」科目
    **汇总反映包含利息**的公允价值变化
- **处置**：
  - 处置时确认的**投资收益** =（售价 − 相关税费）− **上期末的公允价值**
  - **累计对利润的影响** = −取得时交易费用 + 持有期间宣告分配的现金股利或计提的利息
    + [（售价 − 相关税费）− **取得时的入账价值**]
  - ⚠ 注意区分「处置当期确认的投资收益」与「自取得至处置累计影响利润的金额」两种问法
- **不涉及减值**（第 215 题）：
  - ⚠ 交易性金融资产**不计提减值**（不计提坏账准备、也不计提资产减值准备）
  - ⚠ 持有期间发生的**公允价值变动损失**计入**公允价值变动损益**，
    **不是**「信用减值损失」
- **分类与指定的限制**（第 183 题）：
  - 在初始确认时，企业可以将**非交易性权益工具投资**指定为以公允价值计量且其变动计入其他综合收益的金融资产，
    但该指定**一经作出，不得撤销**
  - 在初始确认时，如果能够**消除或显著减少会计错配**，企业可以将金融资产指定为
    以公允价值计量且其变动计入当期损益的金融资产
  - ⚠ 在**非同一控制下企业合并**中确认的**或有对价**构成金融资产的，
    应当分类为以公允价值计量且其变动计入**当期损益**的金融资产，
    **不得**指定为以公允价值计量且其变动计入其他综合收益的金融资产
  - ⚠ 以**固定数量的自身权益工具**交换**固定金额**的现金或其他金融资产的**衍生工具合同**，
    **不是**金融资产（属权益工具）
- **与外币业务的衔接**：外币交易性金融资产属**外币非货币性项目**，
  其公允价值变动与汇率变动的影响**一起**计入公允价值变动损益（见 [[foreign-currency-translation]]）
