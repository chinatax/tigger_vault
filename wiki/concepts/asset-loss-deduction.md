# 资产损失税前扣除

## Definition

资产损失税前扣除（Asset Loss Deduction）：企业实际发生的资产损失，在**按规定程序向主管税务机关申报**后，准予在企业所得税税前扣除的制度。

两条主线：**损失分「实际」与「法定」两类**（决定追补扣除还是当期扣除），以及**申报分「清单」与「专项」两种方式**（决定手续繁简）。

## Key Points

- **资产的范围**：企业拥有或者控制的、用于经营管理活动相关的资产
  - **货币性资产**：现金、银行存款、**应收及预付款项**（含应收票据、各类垫款、企业之间往来款项）
  - **非货币性资产**：存货、固定资产、无形资产、**在建工程**、生产性生物资产等
  - **债权性投资和股权（权益）性投资**
- **⚠ 两类资产损失的分野**（本考点的枢纽）：

  | | **实际资产损失** | **法定资产损失** |
  |---|---|---|
  | 含义 | 企业在**实际处置、转让**上述资产过程中发生的合理损失 | 虽**未实际处置、转让**，但符合规定条件**计算确认**的损失 |
  | 扣除年度 | 可**追补至该项损失发生年度**扣除 | 应在**申报年度**扣除 |
  | 追补期限 | ⚠ **一般不得超过 5 年**；因**计划经济体制转轨遗留**、**企业重组上市中因权属不清出现争议**未及时扣除、**承担国家政策性任务**形成、**政策定性不明确**形成等特殊原因，经**国家税务总局批准**后可适当延长 | —— |

  - 因以前年度实际资产损失未在税前扣除而**多缴**的税款 → 可在**追补确认年度**应纳税款中**抵扣**，
    不足抵扣的**向以后年度递延抵扣**
  - 追补扣除后**出现亏损**的 → 应**先调整资产损失发生年度的亏损额**，
    再按弥补亏损的原则计算以后年度多缴的税款
- **准予扣除的金额口径**（⚠ 逐类各不相同）：

  | 损失类型 | 可扣除金额 |
  |---|---|
  | 现金短缺 | 减除**责任人赔偿**后的余额 |
  | 存款损失 | 存入法定具有吸收存款职能的机构，因该机构**依法破产、清算**或政府责令停业、关闭等原因**确实不能收回**的部分 |
  | **盘亏**固定资产或存货 | 固定资产**账面净值**或存货**成本**减除**责任人赔偿**后的余额 |
  | **毁损、报废**固定资产或存货 | 减除**残值、保险赔款和责任人赔偿**后的余额 |
  | **被盗**固定资产或存货 | 减除**保险赔款和责任人赔偿**后的余额 |

  - ⚠ **进项税额可一并扣除**：因存货盘亏、毁损、报废、被盗等原因**不得从增值税销项税额中抵扣的
    进项税额**，可以**与存货损失一起**在计算应纳税所得额时扣除
  - 已扣除的资产损失在以后纳税年度**全部或部分收回** → 其收回部分应**作为收入计入收回当期**的应纳税所得额
  - ⚠ **境内、境外营业机构的资产损失应分开核算**；境外营业机构因资产损失产生的**亏损
    不得在计算境内应纳税所得额时扣除**
- **坏账损失的 6 个条件**（**除贷款类债权外**的应收、预付账款）：
  - ①债务人依法宣告**破产、关闭、解散、被撤销**，或被依法**注销、吊销营业执照**，其清算财产不足清偿
  - ②债务人**死亡**，或依法被宣告**失踪、死亡**，其财产或遗产不足清偿
  - ③债务人**逾期 3 年以上**未清偿，且有确凿证据证明已无力清偿
  - ④与债务人达成**债务重组协议**或法院批准**破产重整计划**后无法追偿
  - ⑤因**自然灾害、战争**等不可抗力导致无法收回
  - ⑥国务院财政、税务主管部门规定的其他条件
- **贷款类债权**损失：**12 个条件**（借款人和担保人破产/关闭/解散/被撤销并终止法人资格、借款人死亡或失踪、
  遭受重大自然灾害或意外事故且无法获得保险补偿、借款人触犯刑律、诉诸法律强制执行后无财产可执行、
  达成和解或重整协议后无法追偿的剩余债权、依法取得抵债资产的差额、**信用证垫款**、**银行卡透支**、
  **助学贷款**、经国务院专案批准核销等）
- **股权投资损失**的 5 个条件：①被投资方破产/关闭/解散/被撤销/被注销吊销营业执照；
  ②被投资方财务状况严重恶化、累计巨额亏损、**已连续停止经营 3 年以上**且无重新恢复经营改组计划；
  ③对被投资方**不具有控制权**，投资期限届满或**已超过 10 年**，且被投资单位因**连续 3 年经营亏损**导致资不抵债；
  ④被投资方财务状况严重恶化、累计巨额亏损、已完成清算或**清算期超过 3 年**；⑤其他
- **申报管理的两条铁律**：
  - ⚠ 企业发生的资产损失，应按规定程序和要求**向主管税务机关申报后方能扣除**——
    **未经申报的损失不得在税前扣除**
  - 自 **2017 年度**汇算清缴起，申报扣除资产损失**仅需填报**《资产损失税前扣除及纳税调整明细表》，
    **不再报送**资产损失相关资料，资料由**企业留存备查**
- **清单申报的 5 类**（以**清单**方式申报，只需报告损失总额）：
  - ①正常经营管理活动中，按**公允价格**销售、转让、变卖非货币资产的损失
  - ②各项存货发生的**正常损耗**
  - ③固定资产达到或超过**使用年限而正常报废清理**的损失
  - ④生产性生物资产达到或超过使用年限而**正常死亡**的损失
  - ⑤按市场公平交易原则，通过各种交易场所、市场等买卖**债券、股票、期货、基金以及金融衍生产品**等发生的损失
- **专项申报**：除上述 5 类以外的资产损失（逐项或逐笔报送申请报告）
  - ⚠ 企业**无法准确判别**是否属于清单申报的 → **可以采取专项申报**的形式
- **跨地区经营汇总纳税企业**的资产损失申报：
  - 总机构及分支机构各自向当地主管税务机关申报，⚠ 各分支机构**同时还应上报总机构**
  - 总机构对各分支机构上报的损失，除另有规定外，应以**清单申报**形式向当地主管税务机关申报
  - 总机构将跨地区分支机构所属资产**捆绑（打包）转让**发生的损失 → 由总机构**专项申报**
- **商业零售企业存货损失**（三个申报口径）：
  - **正常损失**（零星失窃、报废、废弃、过期、破损、腐败、鼠咬、顾客退换货等）→
    按会计科目归类汇总，以**清单**形式申报，同时出具**损失情况分析报告**
  - **非正常损失**（风、火、雷、震等**自然灾害**，仓储、运输失事，**重大案件**等）→ 以**专项申报**
  - ⚠ **存货单笔（单项）损失超过 500 万元**的，**无论何种因素**形成，均应以**专项申报**
- **确认证据的两类**：
  - **具有法律效力的外部证据**：司法机关的**判决或裁定**；公安机关的**立案结案证明**；
    市场监管部门的**注销、吊销及停业证明**；企业的**破产清算公告或清偿文件**；行政机关的公文；
    专业技术部门的**鉴定报告**；具有法定资质的中介机构的**经济鉴定证明**；仲裁机构的**仲裁文书**；
    保险公司对投保资产出具的**出险调查单、理赔计算单**等保险单据
  - **特定事项的企业内部证据**：会计核算资料和原始凭证；**资产盘点表**；相关经济行为的**业务合同**；
    企业内部技术鉴定部门的鉴定文件；内部**核批文件**及有关情况说明；
    对责任人由于经营管理责任造成损失的**责任认定及赔偿情况说明**；
    **法定代表人、企业负责人和企业财务负责人对特定事项真实性承担法律责任的声明**
- **四处具体的量化证据门槛**：
  - **逾期 3 年以上**的应收款项，会计上已作为损失处理的 → 可作为坏账损失，但应说明情况并出具**专项报告**
  - **逾期 1 年以上**，且**单笔数额不超过 5 万元**或**不超过企业年度收入总额万分之一**的应收款项，
    会计上已作为损失处理的 → 可作为坏账损失，但应说明情况并出具**专项报告**
  - 金融机构应清算而**未清算超过 3 年**的 → 可将该款项确认为资产损失，
    但应有**法院或破产清算管理人出具的未完成清算证明**
  - ⚠ 损失数额较大的界定：占企业该类资产**计税成本 10% 以上**，或减少当年应纳税所得、
    增加亏损 **10% 以上**
- ⚠ **不得作为损失扣除的股权和债权**（6 项）：
  - ①债务人或者担保人**有经济偿还能力**，未按期偿还的企业债权
  - ②违反法律、法规的规定，以各种形式、借口**逃废或悬空**的企业债权
  - ③**行政干预**逃废或悬空的企业债权
  - ④企业**未向债务人和担保人追偿**的债权
  - ⑤企业发生**非经营活动**的债权
  - ⑥其他不应当核销的企业债权和股权
