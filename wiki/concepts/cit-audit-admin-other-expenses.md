# 企业所得税纳税审核：管理费用的其他项目

## Definition

⚠ **本页是《涉税服务实务》第三章第三节之（一）企业所得税的纳税审核的
「2. 税前准予扣除项目」之「（3）期间费用及支出的审核」之「〇管理费用的审核」的
第七至第九个目（G／H／I）＋该目的「其余项目」总括段**——
即 **G. 固定资产租赁费／H. 补充养老保险费与补充医疗保险费／I. 业务招待费**
＋ **「管理费用的审核要点（除前面有关项目的内容外）」**。

⚠⚠ **本页四块的性质差异（**须注意**）**：
**G、H 是「有专门规则的费用项目」，I 是「限额与范围最易错的项目」，
末段则是「管理费用其余项目的兜底审核要点」**——⚠ **四者共同构成「管理费用」的收尾。**

⚠ **边界**：
- ⚠ **业务招待费、补充保险的限额（**实体规则**）见 [[corporate-income-tax-deduction-limits]]**
  （**该页由《税法（二）》教材与题库建成**）；
- ⚠ **租赁费按经营租赁与融资租赁分别处理**的规则亦见该页；
- ⚠ **本页与同批的 [[cit-audit-fixed-asset-depreciation]]、
  [[cit-audit-repairs-amortization-and-provisions]]、[[cit-audit-research-and-development-expense]]
  同属「管理费用的审核」。**

## Key Points

### ⚠ 一、G. 固定资产租赁费的审核要点

> ⚠ **税法规定（**教材原句**）**：**「纳税人因生产、经营需要租入固定资产所支付的租赁费
> 可以于税前扣除。」**——⚠⚠ **但「这里所指的固定资产租赁费用是指以「「经营租赁」」方式
> 租入固定资产而发生「「可以列入管理费用账户核算」」的租赁费」。**

⚠⚠ **审核的第一步是「分流」（**本目最易考**）**：
> **「在审核「「管理费用」」账户时，对其中的固定资产租赁费用明细账，
> 「「首先要区分是否有将融资性租赁支出列入其中的情况」」。」**

- ⚠⚠ **判据与后果**：**「由于我国企业会计准则规定，对以「融资租赁」形式租入的固定资产
  应「视同承租企业自有的固定资产」进行管理，并按规定「计提折旧计入成本」，
  所以如果管理费用中的固定资产租赁费中计入了融资性租赁支出，
  一般是企业「「扩大了当期期间费用，偷逃税款」」。」**
- ⚠ **另两项核对**：**审核企业的「实际支出是否同合同金额相符」，以及「记账的原始凭证是否完整」。**

### ⚠ 二、H. 补充养老保险费、补充医疗保险费的审核要点（**a／b 两块**）

#### a. 注意现行政策的规定

| # | ⚠ 依据 | ⚠ 口径 |
|---|---|---|
| **1** | **《企业所得税法实施条例》** | **企业为投资者或者职工支付的补充养老保险费、补充医疗保险费，「在国务院财政、税务主管部门规定的「范围和标准」内」，准予扣除** |
| **2** | ⚠⚠ **财税〔2009〕27 号** | **自 2008-01-01 起**，**企业根据国家有关政策规定，为「在本企业任职或者受雇的「全体员工」」支付的补充养老保险费、补充医疗保险费，「分别在不超过职工工资总额 5% 标准内」的部分，在计算应纳税所得额时准予扣除；「超过的部分，不予扣除」** |

#### b. ⚠⚠ 注意财税〔2009〕27 号中「工资总额」的口径如何掌握（**易错点**）

> **「《企业所得税法》及其实施条例中「「没有『工资总额』一词」」，而是「「工资、薪金总额」」，
> 因此，财税〔2009〕27 号文件中的「工资总额」应该理解为与《企业所得税法》及其实施条例中的
> 「工资、薪金总额」等同。」**

⚠⚠ **「工资、薪金总额」的申报表落点（**教材给出精确指引**）**：
**按《国家税务总局关于发布〈中华人民共和国企业所得税年度纳税申报表（A 类，2017 年版）〉的公告》
（国家税务总局公告 2017 年第 54 号）的规定**，
**计算「职工福利费支出、职工教育经费支出、工会经费支出」所用的「工资、薪金总额」的概念
「均是《职工薪酬纳税调整明细表》第 1 行『一、工资薪金支出』第 5 列『税收金额』」**，
⚠⚠ **而这里的「税收金额」是指「纳税人「按照税收规定允许税前扣除」的工资、薪金」，
「而不是实际列支的金额」**（**具体可参照国税函〔2009〕3 号规定**）。

### ⚠ 三、I. 业务招待费的审核要点

#### （一）定义与范围

> **「业务招待费，是指企业在生产、经营等业务中，「「合理需要而接待应酬」」而支付的费用。」**

- ⚠ **税务机关通常界定的支付范围**：**餐饮、住宿费、香烟、食品、礼品、正常的娱乐活动、
  安排客户旅游等项目**；
- ⚠ **《企业所得税法实施条例释义》的解释**：**「招待客户的住宿费和景点门票可以作为业务招待费核算」**。

#### （二）⚠⚠ 两个扣除标准（**须「同时」满足**）

> **《企业所得税法实施条例》第四十三条**：
> **「企业发生的与生产经营活动有关的业务招待费支出，按照「「发生额的 60%」」扣除，
> 但「「最高不得超过当年销售（营业）收入的 5‰」」。」**
> ⚠ **「也就是说，业务招待费的税前扣除，应同时满足以上两个标准。」**

#### （三）⚠ 两个特殊主体的「计算基数」

| # | ⚠ 情形 | ⚠ 口径（**教材原句要点**） |
|---|---|---|
| **1** | ⚠⚠ **从事股权投资业务的企业**（**国税函〔2010〕79 号第八条**） | **包括集团公司总部、创业投资企业等，其「从被投资企业所分配的股息、红利以及股权转让收入」，可以按规定的比例计算业务招待费扣除限额**；⚠⚠ **两点提示**：**一是「从事股权投资业务的企业」是指从事股权投资业务的「各类」企业，不仅限于专门从事股权投资业务的企业**（**这个政策口径国家税务总局已多次明确，并在申报监控中体现**）；**二是「企业从「合伙企业」取得的投资收益，不是从被投资企业取得的股息红利和股权转让收入，不得作为计算业务招待费的基数」**；⚠ **教材另注**：**该规定比较原则，实际工作中掌握也可能出现差异，建议考生可以一般了解，实际工作中需要遵从主管税务机关的意见** |
| **2** | ⚠ **筹建期间（**总局公告 2012 年第 15 号**）** | **企业在筹建期间发生的与筹办活动有关的业务招待费支出，「可按实际发生额的 60% 计入企业筹办费」**，并按有关规定在税前扣除；⚠ **「发生的广告费和业务宣传费，可按「实际发生额」计入企业筹办费」**（⚠ **与招待费的 60% 打折不同**） |

#### （四）⚠⚠ 税务师审核业务招待费时「重点关注」的八个方面（**a–h**）

| # | ⚠ 关注点（**教材原句要点**） |
|---|---|
| **a** | **将属于业务招待费的项目计入其他费用，「将可能影响企业所得税、增值税、个人所得税」** |
| **b** | ⚠ **将与生产经营活动无关的业务招待费计入与生产经营活动有关的业务招待费，即「将全额不得扣除的项目按限额扣除」** |
| **c** | **取得「不合规的业务招待费票据」，仍在税前扣除** |
| **d** | ⚠ **将不属于业务招待费的计入业务招待费**——**比如，公司召开年度「会议费中包含的餐费」计入业务招待费**，⚠ **上述费用「本可全额扣除」** |
| **e** | ⚠ **未实际发生的业务招待费，按照税法规定标准「计提」并在税前扣除** |
| **f** | **业务招待费「计算基数适用不准确」，可能导致税前扣除不准确** |
| **g** | ⚠ **用于招待，「未代扣代缴个人所得税」** |
| **h** | **业务招待费「未单独核算」，导致不能准确确定金额** |

#### （五）⚠ 「五点注意」（**最容易混同的五个「不等于」**）

> **「所有的「「餐费」」不等于业务招待费、「「业务宣传费」」不等于业务招待费、
> 「「职工福利费」」不等于业务招待费、所有「「差旅费」」不等于业务招待费、
> 所有「「会议费」」不等于业务招待费。」**

### ⚠ 四、管理费用的「其余项目」审核要点（**兜底段**）

> **「管理费用的审核要点，除前面有关项目的内容外，还有一些其他费用项目，
> 其检查主要是「「根据列支的项目对照制度规定，结合原始凭证」」，
> 审核其「「真实性、合法性、合理性及列支时间」」——**
> **「应在本期列支的，是否在以后期间列支；不应在本期列支的，是否提前列支。」**
> ⚠⚠ **「同时要划分「「资本性支出和收益性支出」」的界限，
> 防止将应计入「固定资产、在建工程」的资本性支出作为管理费用列支在当期一次性扣除。」**

### ⚠ 五、本页的「要点密集区」（**复习提示**）

| 要点 | ⚠ 所指 |
|---|---|
| ⚠⚠ **租赁费「先分流」** | **管理费用中的租赁费只能是「经营租赁」；混入「融资租赁」即为扩大期间费用、偷逃税款** |
| ⚠⚠ **补充保险 5% + 「全体员工」** | **职工「工资总额」5% 以内；且须为全体员工** |
| ⚠⚠ **「工资总额」＝「工资、薪金总额」** | **申报表落点：《职工薪酬纳税调整明细表》第 1 行第 5 列「税收金额」（按税收规定允许扣除的，**不是**实际列支的）** |
| ⚠⚠ **60% 与 5‰ 同时满足** | **两者取小；基数为当年销售（营业）收入** |
| ⚠ **筹建期两者不同** | **招待费按 60% 计入筹办费；广宣费按实际发生额计入** |
| ⚠⚠ **八个关注点** | **含「计提未实际发生」「会议费餐费误入」「计算基数不准」「未代扣个税」「未单独核算」** |
| ⚠⚠ **五个「不等于」** | **餐费／业务宣传费／职工福利费／差旅费／会议费，均不等于业务招待费** |
| ⚠ **资本性与收益性支出的界限** | **兜底段的核心判据：不得把固定资产·在建工程的支出作管理费用当期一次性扣除** |

> ⚠ **申报代办视角**（**业务招待费·广告费·捐赠·利息·佣金等扣除类项目在申报表填报时的关注内容**）见 [[cit-filing-adjustment-review]]（**第五章批 4，2026-10-08**）。
