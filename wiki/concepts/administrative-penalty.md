# 行政处罚

## Definition

行政处罚（Administrative Penalty）：**行政机关依法对违反行政管理秩序的公民、法人或者其他组织，
以减损权益或者增加义务的方式予以惩戒的行为**。

⚠ 制度的核心是**「罚什么、谁来罚、按什么程序罚、罚错了怎么办」**四问；
⚠ 本题材的考点分布极广，但**最集中的三处**是：**处罚法定原则的四项内容**、
**一事不二罚原则**、以及**不予处罚/从轻减轻的法定情形与追究时效**。

## Key Points

### 一、⚠ 行政处罚的四个基本特征

1. ⚠ **实施主体**只能是**依法享有行政处罚权的行政机关或法律、法规授权的组织**
2. ⚠ **作出时必须严格依据法定的权限，在其职能范围内行使，不能超越**
3. ⚠ **对象**是**实施了违反行政管理秩序行为、应当给予处罚的行政相对人** ——
   ⚠ **不同于行政处分**
4. ⚠ **目的**是**教育行政相对人自觉守法并纠正行政违法行为**

### 二、⚠⚠ 行政处罚的六项基本原则

| 原则 | 内涵 |
|---|---|
| ⚠⚠ **处罚法定原则** | ⚠ **最基本的行政处罚原则**，也是**合法性原则这一依法行政要求在行政处罚领域的具体体现**<br>⚠ **四方面内容**：①**处罚设定权法定**——**哪些法律规范可以设定行政处罚及其设定哪些种类必须按照法律规定进行**；②⚠ **行政处罚依据法定**——**凡法律、法规、规章没有规定予以处罚的行为，均不受处罚**；**处罚必须有法律法规或规章依据，否则行政处罚是违法的，应属无效**；③**行政处罚主体法定**——**除法律法规规章规定有处罚权的行政机关及法律法规授权的组织外，其他机关或者组织不得行使**；④⚠ **行政处罚程序法定**——**违反法定程序的，人民法院判决撤销并可以责令被告行政机关重新作出行政处罚决定** |
| ⚠ **处罚公开、公正、过罚相当原则** | ⚠ **公开**：①**处罚的依据要公开**（作为处罚依据的规定应当是**事先公布**的）；②**执法过程要公开**（如**依法表明执法身份、公开举行听证会听取意见、处罚的事实和理由公开、处罚决定内容公开**）<br>⚠ **公正**：①**实行调查制度**，**防止偏听偏信**；②**使当事人了解其违法行为的性质并给予其陈述、申辩的机会**；③**防止自查自断，实行查处分开、审执分开制度**——⚠ 如税务机关实行「**征、管、查**」分离以及**稽查局实行「四分离」**<br>⚠ **过罚相当**：**立法所设定的违法行为与行政处罚相适应**，**作出行政处罚必须以事实为根据，与违法行为的事实、性质、情节及社会危害程度相当，处罚轻重适度** |
| ⚠ **处罚与教育相结合原则** | ⚠ 目的是**纠正违法行为、减少和消除违法行为、教育当事人自觉守法**——**处罚只是手段而不是目的**<br>⚠ 行政机关实施行政处罚时**应当责令当事人改正或者限期改正违法行为**；**对情节轻微的违法行为也不一定都要实施行政处罚**<br>⚠⚠ **但行政机关未责令当事人改正或者限期改正违法行为即作出行政处罚的，虽然违反行政处罚的法律原则，但并不直接导致行政处罚程序违法，不会导致行政处罚行为的无效或撤销**<br>⚠ **既非意味着可以以罚代刑，也不意味着可以以教代罚**<br>⚠ **行刑衔接**：**税收违法行为涉嫌犯罪的案件**，税务机关**除依法进行行政处理（处罚）外**，要严格执行《**行政执法机关移送涉嫌犯罪案件的规定**》（国务院令第 310 号，第 730 号修订），**及时移送公安机关** |
| ⚠ **保障相对人权益原则** | ⚠ 相对人享有**陈述权、申辩权**；**不服有权依法申请行政复议或者提起行政诉讼**；**因违法给予行政处罚受到损害的，有权依法提出赔偿要求**<br>⚠ **因此该原则又被称为「无救济即无处罚」原则** |
| ⚠ **监督制约、职能分离原则** | ⚠ 防止「**暗箱操作**」和**滥用处罚权**。⚠ **三项分离**：①**调查与审理分离**；②**作出罚款决定的机关与收缴罚款的机构分离**；③**听证主持人与调查检查人员分离**<br>⚠ 此外，**执法人员当场作出的处罚决定向所属行政机关备案**的规定也体现该原则 |
| ⚠⚠ **一事不二罚（款）原则** | ⚠ **基本内涵**：对违法行为人的**同一个违法行为**，**不得以同一事实和同一依据给予两个（次）以上的同类（罚款）处罚**<br>⚠⚠ **《行政处罚法》第 29 条**：**对当事人的同一个违法行为，不得给予两次以上罚款的行政处罚**；⚠ **同一个违法行为违反多个法律规范应当给予罚款处罚的，按照罚款数额高的规定处罚**<br>⚠ **目的**：**防止法律规范之间的设定冲突，防止重复规定处罚和滥施处罚，维护行政相对人的权益** |

### 三、⚠⚠ 行政处罚的种类

**（一）法定种类（第 9 条，六类）**：

1. ⚠ **警告、通报批评**
2. ⚠ **罚款、没收违法所得、没收非法财物**
3. ⚠ **暂扣许可证件、降低资质等级、吊销许可证件**
4. ⚠ **限制开展生产经营活动、责令停产停业、责令关闭、限制从业**
5. ⚠ **行政拘留**
6. ⚠ **法律、行政法规规定的其他行政处罚**

**（二）⚠ 理论分类（四种）**：

| 类型 | 内涵 | 形式 |
|---|---|---|
| ⚠ **人身自由罚** | 对违反行政法律规范**情节严重**的公民的**人身自由在短期内予以限制或剥夺** | ⚠⚠ **限制人身自由的行政处罚权只能由公安机关和法律规定的其他机关行使** |
| ⚠ **行为罚**（也称「**能力罚**」） | 对相对人**限制或剥夺其特定行为能力或资格** | **暂扣许可证件、降低资质等级、吊销许可证件、限制开展生产经营活动、责令停产停业、责令关闭、限制从业** |
| ⚠ **财产罚** | **剥夺违法相对人财产权利** | ⚠ **罚款和没收**两种形式 |
| ⚠ **精神罚** | 对实施**轻微违法行为**的当事人作出**警示、批评**，同时**予以告诫** | ⚠ **警告、通报批评**；⚠ **一般适用于情节比较轻微、未造成具体损害结果但又应予处罚的违法行为人** |

### 四、⚠⚠ 行政处罚的设定（层级对比）

| 规范位阶 | 设定权限 |
|---|---|
| ⚠ **法律** | **可以设定各种行政处罚**。⚠⚠ **限制人身自由的行政处罚只能由法律设定** |
| ⚠ **行政法规** | **可以设定除限制人身自由以外**的行政处罚<br>⚠ **法律已作规定**的 → **必须在法律规定的行为、种类和幅度范围内**规定；⚠ **法律未作规定**的，行政法规**为实施法律可以补充设定** |
| ⚠ **地方性法规** | ⚠ **可以设定除限制人身自由、吊销营业执照以外**的行政处罚<br>⚠ **法律、行政法规已作规定**的 → **必须在其规定的行为、种类和幅度范围内**规定；⚠ **未作规定**的，**为实施法律、行政法规可以补充设定** |
| ⚠ **国务院部门规章** | ⚠ **在法律、行政法规规定的行为、种类和幅度范围内**作出具体规定<br>⚠⚠ **尚未制定法律、行政法规的**，可以对违反行政管理秩序的行为**设定警告、通报批评或者一定数额罚款**——⚠ **罚款的限额由国务院规定** |
| ⚠ **地方政府规章** | ⚠ **在法律、法规规定的行为、种类和幅度范围内**作出具体规定<br>⚠⚠ **尚未制定法律、法规的**，可以设定**警告、通报批评或者一定数额罚款**——⚠ **罚款的限额由省、自治区、直辖市人民代表大会常务委员会规定** |
| ⚠⚠ **其他规范性文件** | ⚠⚠ **除法律、法规、规章外，其他规范性文件不得设定行政处罚** |

> ⚠ **与行政许可、行政强制的设定权限对照是教材提示的比较学习法**：
> 许可的「**其他规范性文件一律不得设定**」、处罚的「**其他规范性文件不得设定**」是一致的；
> ⚠ 但**许可**没有「限制人身自由」这类专属法律的保留，**处罚**则有。

### 五、⚠ 实施主体与管辖

**（一）⚠⚠ 行政机关实施行政处罚的四个条件**：

1. ⚠ 必须是**依法行使国家行政权，按照法律、法规、规章的规定管理国家行政事务**的行政机关
2. ⚠ **须具有外部管理职能** —— ⚠ **不具有独立主体资格、不能以自己的名义独立地行使职权、
   承担法律责任的内部行政机构就不能成为行政处罚的实施主体**
3. ⚠ **必须取得特定的行政处罚权** —— ⚠ **具有外部管理职能的行政机关虽然享有管理社会事务的权力，
   但并不必然地享有行政处罚权，必须经法律、法规和规章的明确授权**
4. ⚠ **必须在法定的职权范围内实施** —— **越权则无效**

- ⚠ **综合行政执法制度**：国家在**城市管理、市场监管、生态环境、文化市场、交通运输、应急管理、农业**
  等领域推行建立**综合行政执法制度，相对集中行政处罚权**；
  ⚠ **国务院或者省、自治区、直辖市人民政府可以决定一个行政机关行使有关行政机关的行政处罚权**

**（二）法律法规授权的组织**：具有管理公共事务职能的组织，
**可以在法定授权范围内**实施行政处罚

**（三）⚠ 受委托的组织（第 20、21 条）**：

- ⚠ **行政机关依照法律、法规、规章的规定，可以在其法定权限内书面委托**符合条件的组织实施；
  ⚠⚠ **行政机关不得委托其他组织或者个人实施行政处罚**
- ⚠ **委托书应当载明委托的具体事项、权限、期限等内容**；
  ⚠ **委托行政机关和受委托组织应当将委托书向社会公布**
- ⚠ **委托行政机关对受委托组织实施行政处罚的行为应当负责监督，并对该行为的后果承担法律责任**
- ⚠ **受委托组织在委托范围内，以委托行政机关名义实施行政处罚；不得再委托**
- ⚠⚠ **受委托组织必须符合的三个条件**（第 21 条）：①**依法成立并具有管理公共事务职能**；
  ②**有熟悉有关法律、法规、规章和业务并取得行政执法资格的工作人员**；
  ③**需要进行技术检查或者技术鉴定的，应当有条件组织进行相应的技术检查或者技术鉴定**

**（四）⚠ 管辖**

- ⚠ **地域管辖**：**由违法行为发生地的行政机关管辖**（法律、行政法规、部门规章另有规定的从其规定）
- ⚠ **级别管辖**：**由县级以上地方人民政府具有行政处罚权的行政机关管辖**（法律、行政法规另有规定的从其规定）
- ⚠ **乡镇街道承接**：**省、自治区、直辖市**根据当地实际情况，
  可以决定将**基层管理迫切需要的县级人民政府部门的行政处罚权**交由**能够有效承接的乡镇人民政府、
  街道办事处**行使，并**定期组织评估**；**决定应当公布**
- ⚠ **两个以上行政机关都有管辖权**的 → **由最先立案的行政机关管辖**
- ⚠ **管辖争议**：应当**协商解决**；协商不成的，**报请共同的上一级行政机关指定管辖**；
  ⚠ 也**可以直接由共同的上一级行政机关指定管辖**
- ⚠ **行刑衔接**：**违法行为涉嫌犯罪的，行政机关应当及时将案件移送司法机关**；
  ⚠ **对依法不需要追究刑事责任或者免予刑事处罚，但应当给予行政处罚的，
  司法机关应当及时将案件移送有关行政机关**

### 六、⚠⚠ 行政处罚的适用

**（一）四个适用条件**：①**必须已经实施了违法行为，且该违法行为违反了行政法规范**；
②**行政相对人具有责任能力**；③**行政相对人的行为依法应当受到处罚**；④**违法行为未超过追究时效**

**（二）⚠⚠ 行政处罚无效的两种情形**：①**行政处罚没有依据或者实施主体不具有行政主体资格的**；
②**违反法定程序构成重大且明显违法的**（⚠ 如**符合听证条件当事人要求听证不举行听证的，处罚无效**）

**（三）⚠ 从旧兼从轻原则**：实施行政处罚，**适用违法行为发生时的法律、法规、规章的规定**；
⚠⚠ **但作出行政处罚决定时，法律、法规、规章已被修改或者废止，
且新的规定处罚较轻或者不认为是违法的，适用新的规定**

**（四）⚠ 折抵规则**：

- ⚠ **行政拘留折抵刑期**：违法行为构成犯罪，人民法院判处**拘役或者有期徒刑**时，
  行政机关已经给予当事人**行政拘留**的，应当依法**折抵相应刑期**
- ⚠ **罚款折抵罚金**：人民法院判处**罚金**时，行政机关已经给予当事人**罚款**的，
  应当**折抵相应罚金**；⚠ **尚未给予罚款的，不再给予罚款**

**（五）⚠⚠ 不予处罚的情形（六种）**：

1. ⚠ **不满 14 周岁**的未成年人有违法行为的
2. ⚠ **精神病人、智力残疾人在不能辨认或不能控制自己行为时**有违法行为的
3. ⚠ **违法行为轻微并及时纠正，没有造成危害后果**的
4. ⚠ **初次违法且危害后果轻微并及时改正**的 —— **可以**不予行政处罚
5. ⚠ **违法行为在 2 年内未被发现**的，不再给予行政处罚；
   ⚠ **涉及公民生命健康安全、金融安全且有危害后果的，该期限延长至 5 年**
6. ⚠ **当事人有证据足以证明没有主观过错**的

- ⚠ **对当事人的违法行为依法不予行政处罚的，行政机关应当对当事人进行教育**

**（六）⚠ 从轻或减轻处罚的六种情形**：

①**已满 14 周岁不满 18 周岁**的未成年人有违法行为的；②**主动消除或减轻违法行为危害后果**的；
③**受他人胁迫或者诱骗**有违法行为的；④**主动供述行政机关尚未掌握**的违法行为的；
⑤**配合行政机关查处违法行为有立功表现**的；⑥**法律、法规、规章规定其他应当从轻或者减轻**的

- ⚠ **可以从轻或者减轻**的情形：**尚未完全丧失辨认或者控制自己行为能力的精神病人、
  智力残疾人**有违法行为的
- ⚠⚠ **从轻与减轻的分野**：**从轻**指在**法定种类和法定幅度内**，
  适用**较轻的种类**或者**依照处罚的下限或略高于下限**给予处罚，
  ⚠ **但不能低于法定处罚幅度的最低限度**；⚠ **减轻**指**在法定处罚幅度的最低限以下**给予处罚

**（七）⚠⚠ 追究时效（追罚时效）**

| 规范 | 时效 |
|---|---|
| ⚠ **一般** | **2 年** —— 违法行为发生后 **2 年内未被行政机关发现**的，不再给予行政处罚 |
| ⚠⚠ **涉及公民生命健康安全、金融安全且有危害后果** | **延长至 5 年**（法律另有规定的除外） |
| ⚠⚠ **税收** | ⚠ **《税收征管法》规定：违反税收法律、行政法规应当给予行政处罚的行为，
在 5 年内未被发现的，不再给予行政处罚** |
| ⚠⚠ **治安管理** | ⚠ **违反治安管理行为在 6 个月内没有被公安机关发现的，不再处罚** |

- ⚠⚠ **起算点**：**从违法行为发生之日起计算**；
  ⚠ **违法行为有连续或者继续状态的，从行为终了之日起计算**
  - ⚠ **连续状态** = **行为人基于同一个违法故意，连续实施数个行政违法行为**
  - ⚠ **继续状态** = **同一违法行为在时间上的延续**

### 七、⚠ 行政处罚的决定程序

**（一）一般规定（要点）**

- ⚠ **公示义务**：**处罚的实施机关、立案依据、实施程序和救济渠道**等信息**应当公示**
- ⚠ **查明事实**：**违法事实不清、证据不足的，不得给予行政处罚**
- ⚠⚠ **电子技术监控设备**（利用其收集固定违法事实的）：
  ①**应当经过法制和技术审核**，确保**符合标准、设置合理、标志明显**，
  **设置地点应当向社会公布**；②**记录违法事实应当真实、清晰、完整、准确**；
  ③**应当审核记录内容是否符合要求；未经审核或者经审核不符合要求的，不得作为行政处罚的证据**
- ⚠ **执法人员**：**应当由具有行政执法资格的执法人员实施**；⚠⚠ **执法人员不得少于两人**（法律另有规定的除外）
- ⚠ **回避**：**与案件有直接利害关系或者有其他关系可能影响公正执法**的应当回避；
  ⚠ **当事人有权申请回避**；⚠ **由行政机关负责人决定；决定作出之前，不停止调查**
- ⚠⚠ **告知与陈述申辩**：作出决定前**应当告知当事人拟作出的行政处罚内容及事实、理由、依据**，
  并告知其**依法享有的陈述、申辩、要求听证等权利**；
  ⚠ **行政机关必须充分听取意见，对当事人提出的事实、理由和证据应当进行复核；成立的应当采纳**
  ⚠⚠ **行政机关不得因当事人陈述、申辩而给予更重的处罚**
- ⚠⚠ **证据的八种法定种类**：**①书证；②物证；③视听资料；④电子数据；⑤证人证言；
  ⑥当事人的陈述；⑦鉴定意见；⑧勘验笔录、现场笔录**
  - ⚠ **证据必须经查证属实**，方可作为认定案件事实的根据
  - ⚠⚠ **以非法手段取得的证据，不得作为认定案件事实的根据**
- ⚠ **全过程记录**：应当以**文字、音像**等形式，对**启动、调查取证、审核、决定、送达、执行**
  等进行**全过程记录，归档保存**
- ⚠⚠ **公开与撤回**：**具有一定社会影响的行政处罚决定应当依法公开**；
  ⚠ **公开的行政处罚决定被依法变更、撤销、确认违法或者确认无效的，
  行政机关应当在 3 日内撤回行政处罚决定信息并公开说明理由**
- ⚠ **突发事件从重**：发生**重大传染病疫情等突发事件**，为了**控制、减轻和消除突发事件引起的
  社会危害**，行政机关对**违反突发事件应对措施的行为，依法快速、从重处罚**
- ⚠ **保密**：对知悉的**国家秘密、商业秘密或者个人隐私**应当依法予以保密

> ⚠ **程序的两大类型**：**简易程序**与**普通程序**；⚠ **听证程序是普通程序中的特殊环节**。

**（二）⚠ 简易程序（当场处罚程序）**

- ⚠ **适用条件（同时符合）**：**违法事实清楚**；**有法定依据**；
  ⚠⚠ **数额较小的罚款 —— 对公民处 200 元以下、对法人或其他组织处 3000 元以下的罚款 —— 或者警告处罚**
  （法律另有规定的从其规定）
- ⚠ **五个要求**：①**表明身份**；②**确认违法事实**；③**说明处罚理由和依据**；
  ④**制作行政处罚决定书**（**预定格式、编有号码**，载明**当事人的违法行为或事项、处罚依据、
  罚款数额、时间、地点及行政机关名称〔印章〕**，并由**执法人员签名或盖章**）；
  ⑤**当场交付**行政处罚决定书（⚠ **当事人拒绝签收的，应当在行政处罚决定书上注明**）
- ⚠ **备案**：**执法人员当场作出的行政处罚决定，必须报所属行政机关备案**

**（三）⚠ 普通程序（六步）**：

1. ⚠ **立案** —— 应当填写**立案审批表或立案决定书**，由**行政首长批准**，
   并**指派专人承办**；⚠ **除特别规定或法律另有规定外，对于在 2 年以内未发现的行政违法行为，
   不予立案追究**
2. ⚠ **调查** —— 应当**主动向当事人或者有关人员出示执法证件**；
   ⚠⚠ **执法人员不出示执法证件的，当事人或者有关人员有权拒绝接受调查或者检查**；
   **询问或者检查应当制作笔录**
3. ⚠⚠ **审查与法制审核**（**第 58 条**）—— **有下列情形之一，在行政机关负责人作出决定之前，
   应当由从事行政处罚决定法制审核的人员进行法制审核；未经法制审核或者审核未通过的，不得作出决定**：
   - ⚠ **涉及重大公共利益**的
   - ⚠ **直接关系当事人或者第三人重大权益，经过听证程序**的
   - ⚠ **案件情况疑难复杂、涉及多个法律关系**的
   - ⚠ 法律、法规规定应当进行法制审核的其他情形
4. ⚠ **告知和说明理由** —— ⚠ **说明理由是行政机关在实施行政处罚过程中必须履行的程序性义务**；
   ⚠ **告知权利的内容**包括**有权申请执法人员回避，有权为自己辩解、陈述事实并提出证据，
   有权依法要求举行听证**等
5. ⚠⚠ **听取当事人陈述和申辩** —— ⚠ **如拒绝听取，该行政处罚决定不成立**（当事人放弃的除外）
6. ⚠ **制作处罚决定书** —— ⚠⚠ **行政机关应当自行政处罚案件立案之日起 90 日内作出行政处罚决定**
   （法律、法规、规章另有规定的从其规定）
   - ⚠ **决定书应当载明的六项事项**：①**当事人的姓名或者名称、地址**；
     ②**违反法律、法规、规章的事实和证据**；③**行政处罚的种类和依据**；
     ④**行政处罚的履行方式和期限**；⑤**申请行政复议、提起行政诉讼的途径和期限**；
     ⑥**作出行政处罚决定的行政机关名称和作出决定的日期**
7. ⚠ **送达** —— 应当在**宣告后当场交付**；⚠ **当事人不在现场的，
   行政机关应当在 7 日内**依照民事诉讼法有关规定送达；
   ⚠ 当事人**同意并签订确认书**的，可以采用**传真、电子邮件**等方式送达

**（四）⚠⚠ 听证程序**

- ⚠ **五个特征**：①**由行政机关主持，有关利害关系人参加**；②**公开进行**（除涉及国家秘密、
  商业秘密或者个人隐私外）；③**只适用于特定案件**；
  ④⚠ **以当事人申请为前提**；⑤⚠ **组织听证是一定条件下行政处罚实施机关的法定程序义务**
  —— **只要特定案件当事人依法要求听证，行政机关必须履行组织听证这一法定程序义务**
- ⚠⚠ **适用范围（六项）**：①**较大数额罚款**；②**没收较大数额违法所得、没收较大价值非法财物**；
  ③**降低资质等级、吊销许可证件**；④**责令停产停业、责令关闭、限制从业**；
  ⑤**其他较重的行政处罚**；⑥法律、法规、规章规定的其他情形
- ⚠ **六个步骤**：
  1. ⚠ **听证权告知** —— 行政机关依法应当**先行告知**当事人具有听证的权利
  2. ⚠ **听证申请的提出** —— 当事人要求听证的，应在**行政机关告知后 5 日内**提出
  3. ⚠ **听证通知** —— 应当在**举行听证的 7 日前**将时间、地点通知当事人及有关人员
  4. ⚠ **听证的主持与参与** —— ⚠ **应由行政机关指定非本案调查人员主持**；
     ⚠ 当事人认为主持人与本案有**直接利害关系**的**有权申请其回避**；
     ⚠ **当事人可以亲自参加，也可委托 1、2 人代理参加**
  5. ⚠ **组织听证** —— ⚠ **当事人及其代理人无正当理由拒不出席或者未经许可中途退出的，
     视为放弃听证权利，行政机关终止听证**
  6. ⚠⚠ **制作听证笔录** —— 交当事人**审核无误后签字或盖章**；
     ⚠ **听证结束后，行政机关应当根据听证笔录**依照有关规定作出决定；
     ⚠ **听证笔录应与有关证据材料一并归档入案**
- ⚠ **当事人的七项权利**：①**使用本民族的语言文字**参加听证；②**申请或者放弃听证**；
  ③**申请不公开听证**；④**委托律师或者其他人员为听证代理人**参加听证；
  ⑤**进行陈述、申辩、举证和质证**；⑥**查阅听证笔录，并进行修改和签字确认**；
  ⑦**依法申请听证主持人、听证员、记录员回避**

### 八、⚠ 行政处罚的执行程序

- ⚠ **不停止执行**：当事人申请行政复议或提起行政诉讼的，
  **除法律另有规定外，行政处罚不停止执行**
  - ⚠ **限制人身自由**的行政处罚决定 → 当事人可**向作出决定的机关提出暂缓执行申请**；
    **符合法律规定情形的，应当暂缓执行**
  - ⚠⚠ **加处罚款的限制**：**当事人申请行政复议或者提起行政诉讼的，
    加处罚款的数额在复议或者行政诉讼期间不计算**

**（一）⚠ 处罚机关与收缴罚款机构分离（原则 + 两种例外）**

- ⚠ **原则**：**除规定可以当场收缴的罚款外，作出处罚决定的行政机关及其执法人员不得自行收缴罚款**
- ⚠ **缴纳期限**：当事人应当**自收到行政处罚决定书之日起 15 日内**，
  到**指定的银行或者通过电子支付系统**缴纳罚款；**银行应当收受罚款，并将罚款直接上缴国库**
- ⚠⚠ **可以当场收缴的两种情形**：①**依法给予 100 元以下的罚款**的；
  ②**不当场收缴事后难以执行**的
- ⚠⚠ **第三种情形（需当事人提出）**：在**边远、水上、交通不便地区**，
  当事人到指定银行或通过电子支付系统缴纳**确有困难**的，**经当事人提出**，
  行政机关及其执法人员可以当场收缴
- ⚠ **票据**：**必须向当事人出具省、自治区、直辖市财政部门统一制发的罚款收据**；
  ⚠⚠ **不出具的，当事人有权拒绝缴纳罚款**
- ⚠ **交款时限**：执法人员**应当自收缴之日起 2 日内**交至行政机关；
  ⚠ **在水上当场收缴的，应当自抵岸之日起 2 日内**交至行政机关；
  ⚠ **行政机关应在 2 日内**将罚款缴付指定的银行

**（二）⚠ 强制执行措施（四项）**

当事人**逾期不履行**行政处罚决定的，作出决定的行政机关可以采取：
1. ⚠ **加处罚款**：**到期不缴纳罚款的，每日按罚款数额的 3% 加处罚款**，
   ⚠⚠ **加处罚款的数额不得超出罚款的数额**
2. ⚠ 根据法律规定，将**查封、扣押的财物拍卖、依法处理或者将冻结的存款、汇款划拨抵缴**罚款
3. ⚠ 根据法律规定，采取**其他行政强制执行方式**
4. ⚠ 依照《行政强制法》**申请人民法院强制执行**

- ⚠ **延期或分期**：当事人**确有困难**需要延期或者分期缴纳罚款的，
  **经当事人申请和行政机关批准，可以暂缓或者分期缴纳**
  - ⚠⚠ **申请人民法院强制执行的期限，自暂缓或者分期缴纳罚款期限结束之日起计算**
- ⚠⚠ **税收的特别规定**（《税收征管法》第 88 条第 3 款）：
  **只有当事人对税务机关的处罚决定逾期不申请行政复议也不向法院起诉、又不履行的**，
  作出处罚决定的税务机关**才可以**采取强制执行措施或者申请法院强制执行
  —— ⚠ **这就意味着，在法定的复议和诉讼期内，税务机关不得对处罚决定实施强制执行**

**（三）⚠ 严格实行收支两条线**

- ⚠ **依法没收的非法财物**（除依法应予销毁的物品外）→ **必须按照国家规定公开拍卖或者按有关规定处理**
- ⚠⚠ **罚款、没收违法所得或者没收非法财物拍卖的款项，必须全部上缴国库**；
  **任何行政机关或者个人不得以任何形式截留、私分或者变相私分**
- ⚠⚠ **财政部门不得以任何形式向作出行政处罚决定的行政机关返还上述款项**

### 九、⚠ 行政执法机关移送涉嫌犯罪案件程序

- ⚠ **直接的法律依据**：《行政处罚法》**第 27 条**（违法行为涉嫌犯罪的，
  行政机关应当**及时将案件移送司法机关**）
- ⚠ 国务院《**行政执法机关移送涉嫌犯罪案件的规定**》（**自 2020-08-07 起施行**）
  主要规定了**移送时间、移送材料、异议解决、法律责任**等问题
- ⚠⚠ **移送的时间要求**：行政执法机关对应当向公安机关移送的涉嫌犯罪案件，
  **应当立即指定 2 名或 2 名以上行政执法人员组成专案组专门负责**，
  核实情况后提出**书面报告**，报经**本机关正职负责人或者主持工作的负责人审批**
  - ⚠ **正职负责人或主持工作的负责人应当自接到报告之日起 3 日内**作出批准或不批准的决定
  - ⚠ **决定批准的，应当在 24 小时内向同级公安机关移送**；
    决定不批准的，应当将不予批准的理由**记录在案**
- ⚠ **应附的五类材料**：①**涉嫌犯罪案件移送书**；②**涉嫌犯罪案件情况的调查报告**；
  ③**涉案物品清单**；④**有关检验报告或者鉴定意见**；⑤其他有关涉嫌犯罪的材料
- ⚠ **公安机关一侧**：**应当在移送书的回执上签字**；
  ⚠ **不属于本机关管辖的，应当在 24 小时内转送有管辖权的机关**并书面告知移送机关；
  ⚠ **应当自接受移送之日起 3 日内**进行审查，**决定立案的书面通知移送机关**；
  ⚠ **不予立案的应当说明理由并书面通知，相应退回案卷材料**
- ⚠⚠ **异议解决**：行政执法机关接到**不予立案通知书**后，认为依法应当立案的，
  ⚠ **可以自接到通知书之日起 3 日内提请作出不予立案决定的公安机关复议**，
  ⚠ **也可以建议人民检察院依法进行立案监督**
  - ⚠ 公安机关**应当自收到提请复议的文件之日起 3 日内**作出决定并书面通知；
  - ⚠ 对复议决定**仍有异议**的 → **自收到复议决定通知书之日起 3 日内建议人民检察院立案监督**
- ⚠ **不得以罚代刑**：**行政执法机关对应当向公安机关移送的涉嫌犯罪案件，
  不得以行政处罚代替移送**；⚠ **移送前已作出的警告、责令停产停业、暂扣或吊销许可证件、
  暂扣或吊销执照的行政处罚决定，不停止执行**
- ⚠ **折抵**：移送前已依法给予当事人**罚款**的，**人民法院判处罚金时，依法折抵相应罚金**

### 十、⚠⚠ 税务行政处罚

**（一）⚠ 税务行政处罚的四种类型**

⚠ 税务机关依照法律、法规和规章的规定，对纳税主体违反税务行政管理秩序的税务违法行为，
**以减损权益或者增加义务的方式予以惩戒**。⚠ **主要包括四种**：
**①罚款；②没收违法所得；③停止出口退税权；④吊销税务行政许可证件**

**（二）⚠⚠ 三种「看似处罚、实则不是」的措施（本考点的高频陷阱）**

| 措施 | 性质 |
|---|---|
| ⚠⚠ **责令限期改正** | ⚠ **不是税务行政处罚，而是一种行政命令**（⚠ **不同于警告**）<br>⚠ **两点区别**：①**内容不同**——**行政处罚是一种制裁**，是对税务违法行为人**财产权利的一种限制或剥夺，形成一种震慑**；**责令限期改正是对税务违法行为的后果及其行为本身的纠正**，要么**停止违法行为**，要么**消除违法行为的后果**；②**形式不同**——**行政处罚**主要有上述四种形式，**责令限期改正**形式包括**责令停止税收违法行为、责令改正税收违法行为、责令限期进行纳税调整**等 |
| ⚠⚠ **收缴或者停售发票** | ⚠ **不是税务行政处罚，而是一种执行罚性质的间接强制执行措施**<br>⚠ 当事人有违反《税收征管法》规定的违法行为，税务机关依法作出处理，**当事人拒不接受处理的**，税务机关**有权收缴或停售发票**<br>⚠ **虽有制裁因素，但性质上属于税务机关以间接方式强制当事人履行税务处理内容的重要手段**；⚠ **在理论上属于特别法规定的间接强制执行类型** |
| ⚠ **其他税务行政行为** | **通知有关部门阻止出境、取消一般纳税人资格登记、收缴税务登记证、停止抵扣**等 **均不属于**税务行政处罚 |

**（三）⚠ 税收违法行为及其处罚（四组）**

| 违法行为 | 处罚 |
|---|---|
| ⚠ **违反日常税收管理**（**五项**：未按期申报办理税务登记变更或注销登记；未按规定设置保管账簿或保管记账凭证和有关资料；未按规定将财务会计制度或处理办法和会计核算软件报送备查；未按规定将全部银行账号报告；未按规定安装使用税控装置或损毁擅自改动税控装置） | **责令限期改正**，**可以处 2000 元以下**的罚款；⚠ **情节严重的，处 2000 元以上 1 万元以下** |
| ⚠⚠ **偷税**（**伪造变造隐匿擅自销毁**账簿记账凭证，或**在账簿上多列支出或不列少列收入**，或**经税务机关通知申报而拒不申报或进行虚假的纳税申报**，不缴或少缴应纳税款） | **追缴**其不缴或少缴的**税款、滞纳金**，并处**不缴或少缴税款 50% 以上 5 倍以下**的罚款；构成犯罪的依法追究刑事责任<br>⚠ **扣缴义务人**采取偷税手段不缴或少缴**已扣、已收**税款的，同样处罚 |
| ⚠ **逃避追缴欠税**（欠缴应纳税款的纳税人，**采取转移或者隐匿财产的手段，妨碍税务机关追缴**） | **追缴**欠缴的**税款、滞纳金**，并处**欠缴税款 50% 以上 5 倍以下**的罚款 |
| ⚠⚠ **骗税**（以**假报出口或者其他欺骗手段**，骗取国家出口退税款） | **追缴**其骗取的**退税款**，并处**骗取税款 1 倍以上 5 倍以下**的罚款；⚠ **税务机关可以在规定期间内停止为其办理出口退税** |
| ⚠ **抗税**（以**暴力、威胁方法**拒不缴纳税款） | **除追缴其拒缴的税款、滞纳金外，依法追究刑事责任**；⚠ **情节轻微未构成犯罪的**，追缴拒缴的税款、滞纳金，并处**拒缴税款 1 倍以上 5 倍以下**的罚款 |
| ⚠ **非法印制发票**（《税收征管法》第 71 条） | **销毁**非法印制的发票，**没收违法所得和作案工具**，并处 **1 万元以上 5 万元以下**的罚款 |
| ⚠⚠ **发票违法**（《发票管理办法》） | ⚠ **对虚开、伪造、变造、转让发票违法行为的罚款上限由 5 万元提高为 50 万元**，对违法所得**一律没收**；⚠ **知道或者应当知道**是私自印制、伪造、变造、非法取得或者废止的发票而**受让、开具、存放、携带、邮寄或者运输**的，以及**介绍假发票转让信息**的，分别处**1 万元以上 5 万元以下**、**5 万元以上 50 万元以下**的罚款，违法所得一律没收<br>⚠ **对违反发票管理规定两次以上或者情节严重**的单位和个人，税务机关**可以向社会公告**<br>⚠ **处罚决定权**：**由县级以上税务机关决定**；⚠ **罚款额在 2000 元以下的，可由税务所决定** |

**（四）⚠ 税务行政处罚裁量权的七项原则**

①**合法原则**（在法律法规规章规定的种类和幅度内，依照法定权限、遵守法定程序）；
②**合理原则**（**符合立法目的，考虑相关事实因素和法律因素，与违法行为的事实、性质、情节、
社会危害程度相当，与本地的经济社会发展水平相适应**）；
③**公平公正原则**（**基本相同的违法行为所适用的处罚种类和幅度应当基本相同**）；
④**公开原则**；⑤**程序正当原则**（**依法保障当事人的知情权、参与权和救济权**）；
⑥⚠ **信赖保护原则**（**非因法定事由并经法定程序，不得随意改变已经生效的行政行为**）；
⑦**处罚与教育相结合原则**

**（五）⚠⚠ 税务行政处罚裁量基准**

- ⚠ **性质**：是税务机关为**规范行使行政处罚裁量权**而制定的**细化量化标准**，
  ⚠ **实际上是一种解释性、指导性规则**，与一般意义上的税收法律规范或者税法规则**不同**
- ⚠ **应当包括四项内容**：**违法行为、处罚依据、裁量阶次、适用条件和具体标准**
- ⚠ **制定要求（四项对应）**：①**规定可予以处罚**的 → 明确**是否予以处罚**的适用条件和具体标准；
  ②**规定可以选择处罚种类**的 → 明确**不同种类**的适用条件和具体标准；
  ③**规定处罚幅度**的 → 根据**违法事实、性质、情节、社会危害程度**等因素确定适用条件和具体标准；
  ④**规定可以单处也可以并处**的 → 明确**单处或者并处**的适用条件和具体标准
- ⚠ **制定程序（三步）**：①**确认行政处罚裁量依据**；②**整理、分析行政处罚典型案例**；
  ③**细化量化**税务行政处罚裁量权，拟定裁量基准
- ⚠ **发布形式**：应当**以税务规范性文件形式发布**，并结合税收行政执法实际**及时修订**
- ⚠⚠ **引用限制**：**税务机关在实施行政处罚时，应当以法律、法规、规章为依据，
  并在裁量基准范围内作出相应的行政处罚决定，不得单独引用税务行政处罚裁量基准作为依据**
- ⚠ **区域化裁量基准**：2025 年 12 月有多个区域化处罚裁量基准向社会公开并施行
  （**西北五省（区）、东北区域、西南区域、中南区域、华北区域、华东区域**税务行政处罚裁量基准）；
  ⚠ **税务总局将分类逐步推进税务行政处罚裁量基准事项在全国范围内统一**

**（六）⚠⚠ 税务行政处罚「首违不罚」**

- ⚠ **法定基础**：**《行政处罚法》**规定，税务机关对于当事人**首次违反且危害后果轻微，
  并在税务机关发现前主动改正的或者在税务机关责令限期改正的期限内改正**的，
  **可以不予行政处罚**
- ⚠ **第一批清单**（《税务行政处罚「首违不罚」事项清单》，国家税务总局公告 2021 年第 6 号，
  **自 2021-04-01 起施行**）**九项**：①纳税人未按规定将其**全部银行账号**向税务机关报送；
  ②纳税人未按规定**设置、保管账簿或者保管记账凭证和有关资料**；
  ③纳税人未按规定**期限办理纳税申报和报送纳税资料**；
  ④纳税人使用税控装置开具发票，未按规定期限向主管税务机关**报送开具发票的数据且没有违法所得**；
  ⑤纳税人未按规定**取得发票，以其他凭证代替发票使用且没有违法所得**；
  ⑥纳税人未按规定**缴销发票且没有违法所得**；
  ⑦扣缴义务人未按规定**设置、保管代扣代缴、代收代缴税款账簿或者保管记账凭证及有关资料**；
  ⑧扣缴义务人未按规定期限**报送代扣代缴、代收代缴税款有关资料**；
  ⑨扣缴义务人未按《税收票证管理办法》规定**开具税收票证**；
  ⑩境内机构或个人向非居民发包工程作业或劳务项目，未按规定向主管税务机关**报告有关事项**
- ⚠ **第二批清单**（国家税务总局公告 2021 年第 33 号，**2021-12-30 发布**）**四项**：
  ①纳税人使用**非税控电子器具**开具发票，未按规定将使用的软件程序说明资料**报主管税务机关备案
  且没有违法所得**；②纳税人未按规定办理**税务登记证件验证或者换证手续**；
  ③纳税人未按规定**加盖发票专用章且没有违法所得**；
  ④纳税人未按规定将**财务、会计制度或者处理办法和会计核算软件报送税务机关备查**

**（七）⚠ 税务行政处罚的五项其他适用规则**

1. ⚠ **责令限期改正的期限一般不超过 30 日**（法律、法规、规章另有规定的除外）
2. ⚠ **对当事人的同一个税收违法行为不得给予两次以上罚款**；
   ⚠ **当事人同一个税收违法行为违反不同行政处罚规定且均应处以罚款的，
   应当选择适用处罚较重的条款**
3. ⚠ **违反税收法律、行政法规应当给予行政处罚的行为在 5 年内未被发现的，不再给予行政处罚**
4. ⚠ **告知义务**：在作出行政处罚决定前，应当告知当事人**作出决定的事实、理由、依据及拟处理结果**，
   并告知依法享有的权利；⚠ **涉及法定回避情形的，应当依法告知当事人享有申请回避的权利**
5. ⚠ **集体审议**：对**情节复杂、争议较大、处罚较重、影响较广或者拟减轻处罚**等税务行政处罚案件，
   **应当经过集体审议决定**
6. ⚠ **说明理由**：税务机关按照一般程序实施行政处罚，
   **应当在执法文书中对事实认定、法律适用、基准适用等说明理由**

**（八）⚠⚠ 税务行政处罚听证程序的三个数**

- ⚠ **适用范围**：税务机关对**公民作出 2000 元以上（含本数）罚款**，
  或者对**法人或者其他组织作出 1 万元以上（含本数）罚款**的行政处罚之前，
  **应当向当事人送达《税务行政处罚事项告知书》**，告知**已经查明的违法事实、证据、
  行政处罚的法律依据和拟将给予的行政处罚**，并告知**有要求举行听证的权利**
  - ⚠ 一般限于**较大数额的罚款案件、没收较大数额违法所得案件以及吊销税务行政许可证件**的案件；
    ⚠⚠ **停止办理出口退税等案件不适用听证程序**
- ⚠ **申请期限**：当事人提出听证要求的，应当在**被告知听证权之日起 5 个工作日内**提出；
  ⚠ **逾期不提出的，视为放弃听证权利**
- ⚠ **举行时限**：税务机关应当在**收到当事人听证申请后 15 日内举行**听证，
  并在**举行听证的 7 日前**将《**税务行政处罚听证通知书**》送达当事人
- ⚠⚠ **不予听证的三种情形**：①**申请人不是本案当事人或者其代理人**的；
  ②**未在法定期限内提出**听证申请的；③**不属于税务行政处罚听证范围**的
- ⚠⚠ **不组织听证的后果**：**对应当进行听证的案件，税务机关不组织听证，行政处罚决定不能成立**
  （当事人放弃听证权利或者被正当取消听证权利的除外）
- ⚠ **听证终止的两种情形**：①当事人或其代理人**无正当理由不出席**的 → 视为放弃听证权利，
  听证应当终止；②**听证过程中无正当理由中途退出**的 → 听证终止
