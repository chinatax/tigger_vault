# 应收款项与坏账准备

## Definition

应收款项与坏账准备（Receivables and Bad Debt Provision）：应收款项按**摊余成本**计量，期末通过**坏账准备**反映其可收回性，减值损失计入**信用减值损失**。

考查集中在两处**口径分岔**：一是各明细科目该用「应收账款」还是「其他应收款」；二是**应收账款账面价值**在各种业务下是增、是减、还是不变。

## Key Points

- **应收账款的初始确认金额**（第 225 题）：
  - ✅ 包括：销售商品的**价款**、**增值税销项税额**、应收取的**代垫运杂费**
  - ⚠ **不包括**：应收**出租包装物**的租金（→ 其他应收款）；
    **实质上具有融资性质**的销售商品的债权（→ 长期应收款）
- **其他应收款的内容**（第 211 题）：
  - ①应收的各种**赔款、罚款**；②应收**出租包装物**的租金；③应向**职工**收取的各种垫付款项；
    ④**备用金**（向企业各职能科室、车间等拨付）；⑤**存出的保证金**（如租入包装物支付的**押金**）；
    ⑥其他各种应收、暂付款项
  - ⚠ **预付的购货款** → 通过「**预付账款**」核算；**代垫的已销商品运杂费** → 通过「**应收账款**」核算
- **预付账款与其他应收款的性质**（第 219 题）：
  - ⚠ **预付账款不是金融资产**——其产生的未来经济利益是**商品或服务**，不是收取现金或其他金融资产的权利
  - **其他应收款属于金融资产**，其减值应按**金融工具准则**的规定处理；
    其他应收款是企业按照**摊余成本**计量的其他各类应收款项
  - 预付账款不多的企业，可**直接通过「应付账款」科目**核算
- **坏账准备的核算**（第 182、195、204 题）：
  - 应有余额 = 期末应收款项余额 × 计提比例
  - **本期应计提金额 = 应有余额 − 已有余额**（已有余额为**负数**时应相加，即补提更多）
  - **计提**：借「**信用减值损失**」、贷「坏账准备」
  - **转回多计提**：借「**坏账准备**」、贷「信用减值损失」
    （⚠ 这是「坏账准备」账户**借方**的唯一常见登记情形）
  - **实际核销**坏账：借「坏账准备」、贷「应收账款」
  - **收回已核销**的坏账：**贷记「信用减值损失」**（因此会增加当期**利润**）
  - 组合方式计提的应收款项收回时：借「银行存款」、贷「应收账款」
- **应收款项减值的测试规则**（第 220 题）：
  - **单项金额重大**的应收款项 → **单独**进行减值测试
  - **单项金额非重大**的应收款项 → 采用**组合**方式进行减值测试
  - ⚠ 经单独测试后**未发生减值**的单项金额重大的应收款项，**仍需**采用组合方式分析判断是否发生减值
  - ⚠ 减值损失计入「**信用减值损失**」，**不是**「资产减值损失」
  - ⚠ 折现应采用**应收款项发生时的初始折现率**计算未来现金流量的现值，**不是即期折现率**
- **减值的客观证据**（第 212 题）：
  - ✅ ①发行方或债务人发生**重大财务困难**；②债务人**违反合同条款**不能按期偿付利息和本金；
    ③债权人出于与债务人财务困难有关的经济或合同考虑，**给予债务人让步**；④债务人**很可能破产**或进行其他财务重组
  - ⚠ 债务人将设备以明显低于市场价格的价格出售给**关联方**，属关联方之间的交易，**不能**表明存在减值因素
- **应收账款账面价值的变动判断**（第 217 题，⚠ 高频，账面价值 = 账面余额 − 坏账准备）：

  | 事项 | 对账面价值的影响 | 原因 |
  |---|---|---|
  | 结转**到期不能收回的应收票据** | **增加** | 应收票据转入应收账款 |
  | **计提**坏账准备 | **减少** | 坏账准备增加 |
  | **发生坏账**（核销） | **不变** | 借坏账准备、贷应收账款，两者同减 |
  | **收回已转销**的应收账款 | **不变** | 简化处理下先恢复再冲回 |
  | **转回多提**的坏账准备 | **增加** | 坏账准备减少 |

- **应收票据贴现**（第 189、194 题）：
  - ⚠ 计算贴现天数的规则是「**算头不算尾**」——持有天数 = 出票日至贴现日的天数
  - **贴现期 = 票据期限 − 持有天数**
  - 票据**到期值** = 面值 ×（1 + 票面年利率 × 期限 ÷ 360）
  - **贴现息** = 到期值 × 年贴现率 × 贴现期 ÷ 360
  - **贴现额** = 到期值 − 贴现息
  - 若贴现业务**不符合**金融资产终止确认条件，收到的款项作**短期借款**处理
