# 可转换公司债券

## Definition

可转换公司债券（Convertible Bonds）：兼具**负债**与**权益**双重性质的复合金融工具，初始确认时须将**负债成分**与**权益成分**分拆，分别计入「应付债券」与「其他权益工具」。

它的分拆逻辑是「**先算负债、倒挤权益**」——负债成分按**不附转换权**的类似债券的市场利率折现确定，余额即权益成分。

## Key Points

- **性质与分拆**（第 363、370 题）：
  - 属于**复合金融工具**，初始确认时应当将**负债成分和权益成分进行分拆**
  - **负债成分**的公允价值 = 未来现金流量的现值，按**不附转换权**的类似债券的**市场利率**折现
  - **权益成分** = **发行价格 − 负债成分公允价值** → 计入「**其他权益工具**」
  - **利息调整** = 债券面值 − 负债成分公允价值
  - 例：面值 1000、票面 4%、4 年期、每年末付息、发行价 1020、无转股权市场利率 6%
    - 负债成分 = 1000×4%×（P/A,6%,4）+ 1000×（P/F,6%,4）= 40×3.465 + 1000×0.792 = **930.6 万元**
    - 其他权益工具 = 1020 − 930.6 = **89.4 万元**
    - 利息调整 = 1000 − 930.6 = **69.4 万元**
- **交易费用的分摊**（第 363 题）：
  - 发行时发生的交易费用，应当在**负债成分和权益成分之间**按照各自**相对应的公允价值**
    进行分摊（⚠ 不是全部计入损益，也不是全部冲减权益）
- **后续计量**：
  - 按**负债成分的摊余成本和实际利率**确认实际利息
    - 例：2025-12-31 财务费用 = 930.6 × 6% = **55.84 万元**；
      贷「应付债券——应计利息」40（票面）、贷「利息调整」15.84
  - ⚠ 「其他权益工具」在持有期间**不重新计量**
- **转股时的处理**（第 363、372 题，⚠ 涉及的科目是本考点的核心）：
  - 借「应付债券——可转换公司债券（**面值**）」、借「**其他权益工具**」
  - 贷「应付债券——可转换公司债券（**利息调整**）」【尚未摊销的余额】
  - 贷「**股本**」【按转股价格计算的股数 × 面值】、贷「**资本公积——股本溢价**」【差额】
  - 如用现金支付不可转换股票的部分，还应贷记「银行存款」等
  - 例：借「应付债券——面值」1000、借「其他权益工具」89.4；
    贷「利息调整」53.56、贷「股本」100、贷「资本公积——股本溢价」**935.84**
- **两个反向的「涉及/不涉及」判断**（第 363 题）：
  - ⚠ 发行可转换公司债券时**不涉及**「**其他综合收益**」科目
  - ⚠ 转股时**涉及**「**其他权益工具**」科目
  - 常考干扰项正是把这两句反过来说
- **与相关概念的衔接**：负债成分的摊余成本递推同 [[long-term-liabilities]] 与
  [[debt-investment-amortized-cost]]；「其他权益工具」的核算范围见
  [[capital-reserve-and-retained-earnings]]
