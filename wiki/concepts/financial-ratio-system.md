# 财务指标体系与分类

## Definition

财务指标体系与分类（Financial Ratio System）：把企业财务指标按**反映的经济内容**归入五类——偿债能力、资产质量状况、盈利能力、经济增长状况、获取现金能力，从而形成对企业绩效的结构化评价。

这一分类本身即是考点：题目常给定指标名称要求判断归属，**指标名的后缀往往就是分类线索**。

## Key Points

- **五类指标的划分与记忆线索**（第 135、150、153 题）：

  | 反映内容 | 记忆线索 | 包含的指标 |
  |---|---|---|
  | **偿债能力** | —— | 流动比率、速动比率、现金比率、现金流动负债比率、资产负债率、产权比率、已获利息倍数、带息负债比率 |
  | **资产质量状况** | **××周转率** | 应收账款周转率、存货周转率、流动资产周转率、总资产周转率 |
  | **盈利能力** | **××利润率／收益率／保障倍数** | 营业利润率、总资产收益率、净资产收益率、成本费用利润率、资本收益率、盈余现金保障倍数 |
  | **经济增长状况** | **××增长率／积累率／投入比率** | 营业收入增长率、总资产增长率、营业利润增长率、**资本保值增值率**、资本积累率、技术投入比率 |
  | **获取现金能力** | —— | 销售现金比率、每股营业现金净流量、全部资产现金回收率 |

- **易错归属**（第 135、150、153 题，⚠ 全部考过）：
  - **资本保值增值率**属**经济增长状况**，不属盈利能力
  - **资本收益率**属**盈利能力**（不是经济增长）
  - **盈余现金保障倍数**属**盈利能力**（尽管带「现金」二字）
  - **总资产周转率**、**应收账款周转率**属**资产质量状况**
  - **资产现金回收率**属**获取现金能力**，不属资产质量
  - **成本费用利润率**属**盈利能力**
- **国资委《中央企业综合绩效评价实施细则》的财务绩效基本指标**（第 156 题）：
  - 净资产收益率、总资产报酬率、总资产周转率、应收账款周转率、
    资产负债率、已获利息倍数、销售（营业）增长率、资本保值增值率
  - ⚠ **成本费用利润率**属「盈利能力状况的**修正指标**」，**不是**基本指标
- **指标的具体计算**分别见 [[dupont-analysis]]、[[eps-and-market-ratios]]、
  [[solvency-and-cash-flow-ratios]]
