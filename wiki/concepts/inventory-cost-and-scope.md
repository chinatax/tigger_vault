# 存货范围与成本确定

## Definition

存货范围与成本确定（Inventory Cost and Scope）：界定哪些资产属于存货，以及哪些支出应当计入存货成本。

两道边界的判据都是**「是否使存货达到目前场所和状态」**——达到的计入成本，未达到的（非正常损耗、入库后仓储费）计入当期损益；不属本企业控制的（来料加工原材料）则根本不是存货。

## Key Points

- **存货的范围**（第 191、213 题）：
  - **属于**存货：在库的**接受外来原材料加工制造的代制品**、在库的**为外单位加工修理的代修品**、
    准备降价出售的**残次商品**、**委托其他单位加工**的物资、
    房地产开发企业**用于在建商品房的土地使用权**、持有以备出售的**数据资源**
  - ⚠ **不属于**存货：**已霉烂变质**的商品（无法为企业带来经济利益，应作损失处理）、
    **接受来料加工**的原材料（属**外单位**的存货）
- **存货成本的三个组成部分**：
  - **采购成本**：购买价款、相关税费、运输费、装卸费、保险费、**运输途中的合理损耗**、入库前的**挑选整理费**
    - ⚠ **合理损耗计入**成本，且不减少入库数量对应的总成本（金额由实收数量分摊，
      因此会**提高单位成本**）；**非正常损耗不计入**成本
  - **加工成本**：加工过程中实际发生的**人工成本**和按一定方法分配的**制造费用**
  - **其他成本**：使存货达到目前场所和状态所发生的其他支出
- **应当计入存货成本的典型项目**（第 180、222、224 题）：
  - 外购原材料时发生的**消费税**（属「相关税费」，⚠ 增值税一般纳税人可抵扣的不计）
  - **为达到下一生产阶段所必需的仓储费用**
  - 确认为存货的**数据资源**在其加工过程中发生的**数据脱敏、整合**等支出
  - **为特定客户设计产品**的设计费用
  - ⚠ **季节性停工损失**——属于**制造费用**的核算内容，**计入存货成本**
- **不应计入存货成本的项目**（第 180、222 题）：
  - **非正常消耗**的直接材料、直接人工和制造费用（如外购途中因**突发暴雨**造成的损失）→ 计入**当期损益**
  - **入库后**发生的仓储费用 → 计入**管理费用**
  - **新产品研发人员**的薪酬 → 费用化部分计入当期**管理费用**，资本化部分计入**无形资产**成本
- **委托加工物资的成本**（第 202 题，⚠ 消费税的处理是核心）：
  - 成本构成：发出加工物资的**实际成本** + **加工费** + 往返**运杂费**（+ 按规定应计入成本的消费税）
  - **消费税的处理分两种**：
    - 收回后**以不高于受托方的计税价格**出售的 → 消费税**计入**委托加工物资成本
    - 收回后**用于连续生产应税消费品**的 → 消费税记入「**应交税费——应交消费税**」**借方**，
      **不计入**委托加工物资成本
  - **计划成本法**下发料：发出材料的实际成本 = 计划成本 ×（1 + **月初**材料成本差异率）
    （委托加工按月初差异率结转，因当月差异率月末才算出）
