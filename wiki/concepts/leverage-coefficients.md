# 杠杆系数

## Definition

杠杆系数（Leverage Coefficients）：衡量**某一变量变动引起利润（或每股收益）变动幅度**的放大倍数，包括经营杠杆系数（DOL）、财务杠杆系数（DFL）和总杠杆系数（DTL）。

三者均大于 1，且全部通过**息税前利润**这一个节点串联起来——这是记忆三个公式的关键线索，也是快速换算的计算通道。

## Key Points

- **三个杠杆的公式**（解析给出的记忆框架）：
  - **经营杠杆系数 DOL** = 边际贡献 ÷ 息税前利润 =（息税前利润 + 固定性经营成本）÷ 息税前利润
    = 1 + 固定性经营成本 ÷ 息税前利润
  - **财务杠杆系数 DFL** = 息税前利润 ÷（息税前利润 − 利息费用）= 1 + 利息费用 ÷（息税前利润 − 利息费用）
  - **总杠杆系数 DTL** = DOL × DFL =（息税前利润 + 固定性经营成本）÷（息税前利润 − 利息费用）
    - 也写作 DTL = **基期边际贡献 ÷ 基期利润总额**
    - 或 DTL = **普通股每股收益变动率 ÷ 产销量变动率**
    - ⚠ 由最后一条可得：**每股收益增长率 = 总杠杆系数 × 产销量变动率**
- **经营杠杆的成因与影响因素**（第 79 题，高频易错）：
  - 利润对销售量的敏感系数**等于**经营杠杆系数
  - ⚠ 只要存在**固定性经营成本**（而非固定性资本成本）就存在经营杠杆效应，DOL 总是**大于 1**
    （选项「只要企业存在固定性资本成本，就存在经营杠杆效应」错误）
  - 基期固定性经营成本**越大** → DOL 越大 → 经营风险越大
  - 基期销售量**越大** → 基期息税前利润越大 → DOL **越小** → 经营风险越小
    （⚠ 选项「基期息税前利润越大，经营杠杆系数越大」错误——是**越小**）
- **降低杠杆的途径**：
  - **降低经营杠杆系数**：减少固定成本、减少单位变动成本、增加单价、增加销售量
  - **降低财务杠杆系数**：减少利息、减少固定成本、减少单位变动成本、增加单价、增加销售量
  - ⚠ **既能降低经营杠杆系数、又能降低财务杠杆系数的措施**：减少固定成本、减少单位变动成本、
    增加单价、增加销售量（第 70 题的正确项是**降低固定性经营成本**）
  - ⚠ 降低**利息费用**只能降低财务杠杆系数，**不能**降低经营杠杆系数；
    降低**销售量或单价**会使两个杠杆系数**同时变大**
- **与每股收益无差别点分析的关系**：预计息税前利润大于无差别点时，选择财务杠杆效应较大的方案，
  此时 DFL 更大、每股收益对息税前利润的变动更敏感
