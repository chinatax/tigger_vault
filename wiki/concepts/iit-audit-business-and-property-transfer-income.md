# 个人所得税纳税审核：经营所得与财产转让所得

## Definition

⚠ **本页是《涉税服务实务》第三章第三节之「（二）个人所得税的纳税审核方法」的
「2. 经营所得的审核方法」与「3. 财产转让所得的审核方法」**——
⚠⚠ **两个目合为一页（**拆页经用户选定**），因其均为「「按年计算、需核定原值与费用」」
的所得项目审核。**

⚠ **边界**：
- ⚠ **经营所得的规则（五级超额累进、成本费用扣除、核定征收、减半征收）**见
  [[business-income-individual-tax]]；
- ⚠ **财产转让所得（含股权转让、限售股、非货币性资产投资）**见
  [[individual-property-income-tax]]、[[equity-transfer-individual-tax]]；
- ⚠ **本页与 [[iit-audit-special-additional-deductions]]、
  [[iit-audit-comprehensive-income-transition-rules]] 同属同批的个税审核页群。**

## Key Points

### ⚠ 一、「2. 经营所得的审核方法」——四项内容

#### （1）审核「取得经营所得的主体」（**四类情形**）

> **「个体工商户业主、个人独资企业投资者、合伙企业个人合伙人、承包承租经营者个人
> 以及其他从事生产、经营活动的个人取得经营所得。」**

| # | ⚠ 情形（**教材列举**） |
|---|---|
| **a** | **个体工商户从事生产、经营活动取得的所得；个人独资企业投资人、合伙企业的个人合伙人「来源于境内注册的」个人独资企业、合伙企业生产、经营的所得** |
| **b** | **个人依法从事「办学、医疗、咨询以及其他有偿服务活动」取得的所得** |
| **c** | **个人对企业、事业单位「承包经营、承租经营以及转包、转租」取得的所得** |
| **d** | **个人从事其他生产、经营活动取得的所得** |

#### （2）审核「经营所得的计算」

> ⚠ **「经营所得，以每一纳税年度的「「收入总额减除成本、费用以及损失后的余额」」，
> 为应纳税所得额。」**

| ⚠ 口径 | ⚠ 内容（**教材原句要点**） |
|---|---|
| ⚠ **成本、费用** | **生产、经营活动中发生的各项「直接支出」和「分配计入成本的间接费用」以及「销售费用、管理费用、财务费用」** |
| ⚠ **损失** | **生产经营活动中发生的「固定资产和存货的盘亏、毁损、报废损失」「转让财产损失」「坏账损失」「自然灾害等不可抗力因素造成的损失」以及其他损失** |
| ⚠⚠ **财产原值的确定（**五类**）** | **① 有价证券——为「买入价以及买入时按照规定缴纳的有关费用」；② 建筑物——为「建造费或者购进价格以及其他有关费用」；③ 土地使用权——为「取得土地使用权所支付的金额、开发土地的费用以及其他有关费用」；④ 机器设备、车船——为「购进价格、运输费、安装费以及其他有关费用」；⑤ 其他财产——「参照上述第①至④项规定的方法确定」**；⚠⚠ **「纳税人未提供完整、准确的财产原值凭证，不能按照上述规定的方法确定财产原值的，由「「主管税务机关核定财产原值」」」** |
| ⚠ **合理费用** | **「是指卖出财产时按照规定支付的有关税费」** |
| ⚠ **核定征收** | **「从事生产、经营活动，「「未提供完整、准确的纳税资料」」，不能正确计算应纳税所得额的，由主管税务机关「「核定应纳税所得额或者应纳税额」」」** |
| ⚠⚠ **减除费用与扣除的「择一申报」** | ⚠⚠ **「同时取得综合所得和经营所得的纳税人，可在「综合所得或经营所得」中申报减除费用 6 万元、专项扣除、专项附加扣除以及依法确定的其他扣除，但「「不得重复申报减除」」。」** |

#### （3）审核「适用税率」

⚠ **「经营所得，适用 5%~35% 的超额累进税率（见表 3-2）。」**

| ⚠ 级数 | ⚠ 全年应纳税所得额 | ⚠ 税率 |
|---|---|---|
| **1** | **不超过 30 000 元** | **5%** |
| **2** | **超过 30 000 元至 90 000 元的部分** | **10%** |
| **3** | **超过 90 000 元至 300 000 元的部分** | **20%** |
| **4** | **超过 300 000 元至 500 000 元的部分** | **30%** |
| **5** | **超过 500 000 元的部分** | **35%** |

⚠ **注（**教材原句**）**：**「本表所称全年应纳税所得额是指依照《个人所得税法》第六条的规定，
以每一纳税年度的收入总额减除成本、费用以及损失后的余额。」**
⚠⚠ **本表数字在 OCR 中受损严重，已获库内互证**（见 Contradictions 二）。

#### （4）审核「取得经营所得的纳税申报」

| # | ⚠ 环节 | ⚠ 期限与表单（**教材原句要点**） |
|---|---|---|
| **a** | ⚠ **预缴** | **「按年计算个人所得税，由纳税人在「「月度或季度终了后 15 日内」」，向「「经营管理所在地」」主管税务机关办理预缴纳税申报，并报送《个人所得税经营所得纳税申报表（A 表）》」** |
| **b** | ⚠ **汇算清缴** | **「在取得所得的「「次年 3 月 31 日前」」，向经营管理所在地主管税务机关办理汇算清缴，并报送《个人所得税经营所得纳税申报表（B 表）》」** |
| **c** | ⚠⚠ **两处以上取得** | **「从「「两处以上」」取得经营所得的，选择向「「其中一处」」经营管理所在地主管税务机关办理「「年度汇总申报」」，并报送《个人所得税经营所得纳税申报表（C 表）》」** |

### ⚠⚠ 二、「3. 财产转让所得的审核方法」——两项内容

#### （1）审核「纳税人财产转让收入的确认」（**三步查法**）

| # | ⚠ 查法（**教材原句要点**） |
|---|---|
| **a** | ⚠ **「结合「「实地调查法」」，到「「财产管理部门」」（如房管部门、证券交易所、车辆管理部门等）了解纳税人的财产拥有情况，与纳税人提供的「「财产转让原始凭证、资产评估部门的评估文件、交易合同或契约」」等资料相互核对，看内容有无不符情况。」** |
| **b** | ⚠⚠ **「对于销售对象为「「企业单位」」的，还应检查受让单位的「「固定资产、无形资产、在建工程、长期投资、短期投资、实收资本和资本公积」」账户内容及原始凭证，并审核受让单位的《代扣代缴个人所得税报告表》，看纳税人有无「「少报应税收入」」，或将用于「「捐赠、投资、偿债或分配」」的财产「「瞒报、未报」」等现象。」** |
| **c** | ⚠⚠ **「如果纳税人取得了债务人用于「「抵债」」的实物资产，应注意分析审核是否存在纳税人将「「利息收入混入财产转让收入」」，「「降低税率计税」」的现象。」** |

#### （2）审核「纳税人转让财产的扣除项目」（**按财产种类分别处理**）

⚠ **「财产转让成本与费用的扣除范围，因财产种类不同而有所区别，审核时应注意分别处理。」**

| # | ⚠ 财产种类 | ⚠ 扣除口径（**教材原句要点**） |
|---|---|---|
| **①** | ⚠⚠ **转让有价证券** | **「应审核其财产成本和费用的扣除是否真实，计算是否准确」**；**公式**：**一次卖出某一种类债券允许扣除的买入价和费用 ＝（购进的该种类债券买入价和买进过程中缴纳的税费总和 ÷ 购进的该种类债券总数量）× 一次卖出的该种类债券数量 ＋ 卖出该种类债券过程中缴纳的税费**；⚠ **审核时除按公式核查外，「还应审查纳税人提供的「买卖证券的交易证明文件、支付税费的原始凭证」，与「证券交易所的原始记录」进行比对，看纳税人提供的申报数据是否存在「虚报」现象」** |
| **②** | ⚠⚠ **转让不动产** | ⚠ **分「建筑物」与「土地使用权」两种**：**一是转让建筑物**——**允许扣除的成本费用是指「纳税人为建造该固定资产发生的「建造费用」，或取得该项资产时发生的「受让价值及其他费用」」**；⚠ **若转让的房产属于「商品房、经济适用房（含集资合作建房）、安居工程住房、已购公有住房、城镇拆迁安置住房」的，其允许税前扣除的成本费用应包括「纳税人购房时支付的「买价」、按规定「上缴单位的部分」以及「相关税费」」**；⚠ **审核时主要注意能否提供费用支付的原始凭证，检查纳税人列入扣除范围的「已纳增值税、土地增值税、印花税、城市维护建设税与教育费附加」金额计算是否正确，能否提供税务部门开具的「有效的完税凭证」**；**二是转让土地使用权**——**应注意「取得土地使用权所支付的费用、发生的土地开发费用、取得及转让土地使用权时缴纳的「契税、增值税、土地增值税、城市维护建设税与教育费附加」等金额计算是否正确，能否提供税务等部门开具的「有效的支付凭证」」** |
| **③** | ⚠ **转让动产** | **「包括转让机器、设备及车船等财产的行为」**——**审核时主要注意纳税人提供的「财产购买发票、合同、评估文件」等内容是否真实**；⚠ **「如果所转让的动产属于「增值税的征税范围」，还应审核纳税人是否按规定缴纳了「增值税、城市维护建设税与教育费附加」，税前扣除金额是否正确，所提供的「纳税凭证是否有效」等。」** |

### ⚠ 三、本页的「要点密集区」（**复习提示**）

| 要点 | ⚠ 所指 |
|---|---|
| ⚠⚠ **经营所得的四类主体情形** | **个体工商户·独资·合伙／办学医疗咨询等有偿服务／承包承租转包转租／其他生产经营** |
| ⚠⚠ **财产原值确定的五类** | **有价证券／建筑物／土地使用权／机器设备车船／其他（参照）** |
| ⚠⚠ **未提供原值凭证 → 核定原值** | **与「未提供完整准确纳税资料 → 核定应纳税所得额或应纳税额」并记** |
| ⚠⚠ **6 万元与专项扣除「不得重复减除」** | **同时取得综合所得与经营所得时的择一申报** |
| ⚠ **申报三个时限与三张表** | **月/季度终了后 15 日内（A 表）／次年 3 月 31 日前（B 表）／两处以上汇总申报（C 表）** |
| ⚠⚠ **「结合实地调查法」+ 财产管理部门** | **房管部门·证券交易所·车辆管理部门——收入确认的第三方核对路径** |
| ⚠⚠ **受让方七个账户** | **固定资产·无形资产·在建工程·长期投资·短期投资·实收资本·资本公积 + 《代扣代缴个人所得税报告表》** |
| ⚠⚠ **「利息混入财产转让收入以降低税率」** | **以物抵债情形的典型错弊（财产转让 20% vs 利息股息红利 20%——⚠ 教材此处的落点是「混同项目、定性错误」）** |
| ⚠⚠ **有价证券公式** | **按「数量比例」分摊买入价与买进税费，再加卖出环节税费** |
| ⚠ **不动产的两类扣除** | **建筑物（建造费或受让价值；五类房改房另加买价与上缴单位部分）／土地使用权（支付金额 + 开发费 + 四类税费）** |
