# 土地增值税纳税审核

## Definition

⚠ **本页是《涉税服务实务》第三章第三节之「三、其他税种的纳税审核方法」的
「（一）土地增值税、印花税、契税的审核方法」的第一个目**——
即 **「1. 土地增值税纳税审核方法」**，含 **（1）转让房地产收入的审核** 与
**（2）扣除项目金额的审核** 两条主线。

⚠⚠ **本目的两条主线（**本库归纳**）**：
⚠ **土地增值税的应纳税额 ＝（转让收入 − 扣除项目金额）× 适用税率**——
⚠ **故审核天然分为「「收入端」」与「扣除端」两半**，
⚠ **且两端的错弊方向相反**：**收入端是「少报、瞒报、不及时入账」，扣除端是「多列、虚增、扩大范围」。**

⚠ **边界**：
- ⚠ **土地增值税的征税范围·纳税人·税率**见 [[land-appreciation-tax]]；
  **扣除项目**见 [[land-appreciation-tax-deduction-items]]；
  **清算**见 [[land-appreciation-tax-liquidation]]；
  **优惠与计算**见 [[land-appreciation-tax-preferences]]、[[land-appreciation-tax-computation]]；
- ⚠ **本页是本批（第三章收尾块）的第一页**，⚠ **同批另两页为
  [[stamp-duty-and-deed-tax-audit]]、[[real-estate-and-urban-land-use-tax-audit]]。**

## Key Points

### ⚠⚠ 一、（1）转让房地产「收入」的审核（**五项**）

| # | ⚠ 审核项 | ⚠ 内容（**教材原句要点**） |
|---|---|---|
| **①** | ⚠ **应税收入的审核** | **「纳税人转让房地产取得的收入，应包括转让房地产的「「全部价款及有关的经济收益」」。从收入的形式来看，包括「「货币收入、实物收入和其他收入」」」**；⚠ **「审核「「收入明细账」」，并与房地产转让合同、记账凭证、原始凭证相核对，分析企业是否存在「「隐瞒房地产收入、收入不及时入账」」等情况」** |
| **②** | ⚠⚠ **价格明显偏低的审核** | **「审阅有关转让合同、协议、评估报告，审核『主营业务收入』『其他业务收入』『固定资产清理』『银行存款』等科目，向「「房产、土地管理部门及购买方」」核实收入是否真实准确、完整，有无少报收入的情况」**；⚠⚠ **「在审核房地产转让收入时，「「成交价格明显低于评估价格，又无正当理由的，可以用评估价格来计算征税」」」** |
| **③** | ⚠⚠ **视同销售行为的审核** | ⚠ **发生情形**：**「纳税人将「「开发产品」」用于「「职工福利、奖励、对外投资、分配给股东或投资人、抵偿债务、换取其他单位和个人的非货币性资产」」等，「「发生所有权转移时应视同销售房地产」」」**；⚠⚠ **视同销售收入的「确认方法与顺序」**：**「a. 按本企业在「「同一地区、同一年度」」销售的同类房地产的「「平均价格」」确认；b. 由税务机关参照「「当地当年、同类房地产的市场价格或评估价值」」确认」**；⚠ **审核方法**：**「主要通过审核『开发产品』『固定资产』『无形资产——土地使用权』等明细账，结合对合同协议的审查，核实企业是否发生了视同销售行为；对发生视同销售行为的，主要审核「「账务处理和收入核算是否准确，是否按规定申报纳税」」」** |
| **④** | ⚠ **非货币收入的审核** | **「主要审阅销售合同、转让协议，了解取得「「非货币性资产的市场价格」」，核实非货币收入是否「「全额记入」」『主营业务收入』『其他业务收入』等账户，入账的「「评估价格是否合理」」」** |
| **⑤** | ⚠⚠ **转让收入完整性的审核** | **「主要从『主营业务收入』『存货』『固定资产清理』等明细账入手，认真核对合同协议书、评估报告等关联资料，同时对「「已售商品房实地查看」」，逐项「「账实核对」」，分别从「「数量上、金额上」」核实商品房销售收入的准确性」** |

### ⚠⚠ 二、（2）「扣除项目金额」的审核（**五项**）

#### ① 取得土地使用权所支付的金额与土地征用及拆迁补偿费

> ⚠ **口径来源（**教材原句**）**：**「按照《企业产品成本核算制度（试行）》（「「财会〔2013〕17 号」」）
> 等规定，房地产企业一般设置「「『土地征用及拆迁补偿费』」」成本项目，核算为取得土地开发使用权
> （或开发权）而发生的各项费用。」**

⚠⚠ **该项包含的内容（**教材列举十二类**）**：**土地买价或出让金、大市政配套费、契税、
耕地占用税、土地使用费、土地闲置费、农作物补偿费、危房补偿费、土地变更用途和超面积
补交的地价及相关税费、拆迁补偿费用、安置及动迁费用、回迁房建造费用等**，
⚠ **在「「开发成本」」科目中核算。**

⚠⚠ **审核的三条做法 + 一条专项**：

| # | ⚠ 做法（**教材原句要点**） |
|---|---|
| **a** | **「审核『开发成本』账户，应与「「土地使用权转让合同」」和有关会计凭证等相互核对，审核开发成本的「「分配与结转」」是否正确」** |
| **b** | **「查阅和土地交易有关的证明文件及原始凭证，核实「「土地坐落位置和开发项目是否相符」」」** |
| **c** | ⚠ **「到「「财政、土地部门」」了解国家有关收费政策，正确计算开发项目的缴费金额，核实「「土地成本归集项目是否真实、完整」」」** |
| **d** | ⚠⚠ **返还土地出让金的专项审核**：**「若有「「返还土地出让金」」政策的，应审核企业『银行存款』『开发成本』等明细账户，「「确定是否存在不入账加大扣除项目金额」」的情况」** |

⚠⚠ **分期开发项目的「分摊」审核**：
> **「分期、分批开发、分块转让，其取得土地使用权时所支付的金额就需要在
> 「「已开发转让、未开发转让的项目中进行分摊」」，「「仅就对外转让部分计入扣除」」，
> 审核时应根据『开发产品』『分期收款开发产品』『经营成本』明细账进行核实，
> 核查已销售房产「「土地成本的分摊金额是否正确」」。」**

#### ② 房地产开发成本

⚠ **构成（**教材原句**）**：**「房地产开发成本通过『开发成本』账户核算，主要包括
「「前期工程费、基础设施建设费、建筑安装工程费、公共配套设施费、开发间接费」」等。」**

| # | ⚠ 审核对象 | ⚠ 查什么（**教材原句要点**） |
|---|---|---|
| **A** | ⚠ **「开发成本」明细账** | **与有关会计凭证相核对——看「「成本核算是否真实、准确」」，「「有无将不属于开发房地产的成本、费用记入『开发成本』」」；有关成本费用在「「各成本核算对象之间的分配和结转有无差错」」，「「有无多转『开发产品』成本」」」** |
| **B** | ⚠⚠ **「开发间接费用」明细账** | **「看「「有无不属于开发产品的费用计入了开发间接费用」」之中；已发生的开发间接费用在「「各成本核算对象之间的分配与结转」」是否合理、正确；有无「「多计应税项目费用而少计非应税项目费用」」的情况；「「开发间接费用中是否列支了期间费用应该核算的内容」」」** |
| **C** | ⚠ **「开发产品」等明细账** | **与房地产转让合同、会计凭证相核对——看「「成本结转办法是否正确」」，「「有无虚列、多转房地产销售成本」」的情况」** |

#### ③ 房地产开发费用（**含「利息」的两条硬约束**）

> ⚠ **「房地产开发费用是指与房地产开发项目有关的「「销售费用、管理费用和财务费用」」；
> 这三项费用作为「「期间费用」」，「「直接计入当期损益，不按成本核算对象进行分摊」」。」**

⚠⚠ **借款利息的两条「不允许扣除」**：
**「审核企业借款情况，看其借款利息支出能否按转让房地产项目计算分摊：
一是「「利息的上浮幅度要按国家的有关规定执行，超过上浮幅度的部分不允许扣除」」；
二是「「对于超过贷款期限的利息部分和加罚的利息不允许扣除」」。」**

#### ④ ⚠⚠ 与转让房地产有关的税金（**本项含「账户路径」与「范围防错」**）

| # | ⚠ 税（费）种 | ⚠ 账户与口径（**教材原句要点**） |
|---|---|---|
| **a** | **营业税（全面营改增之前项目）、城市维护建设税、教育费附加** | **在「「『税金及附加』『应交税费』」」账户核算** |
| **b** | ⚠ **印花税** | ⚠ **「缴纳的印花税在「「『管理费用』」〔或『税金及附加』（全面营改增后）〕账户中核算」」；⚠⚠ 「纳税人因转让房地产缴纳的印花税，「「在申报土地增值税时计入『与转让房地产有关的税金』扣除」」」** |
| **c** | ⚠ **地方教育附加** | **「因转让房地产缴纳的地方教育附加，「「视同税金予以扣除」」」** |

⚠⚠ **本项的两条审核要求**：
① **「审核时，应注意与「「财产和行为税纳税申报表」」相核对，看其申报抵扣的税金是否正确」**；
② ⚠⚠ **「审核企业是否「「扩大印花税扣除的范围」」，将不属于因转让房地产缴纳的印花税
也列入税金扣除范畴」**——⚠ **即「只认与本次转让直接相关的印花税」。**

#### ⑤ 其他扣除项目——「加计 20%」

> **「对从事房地产开发的纳税人，可按「「取得土地使用权所支付的金额与房地产开发成本
> 计算的金额之和」」，「「加计 20% 扣除」」。」**

⚠⚠ **审核要求**：**「审核时，应在「「核实取得土地使用权所支付的金额和房地产开发成本」」的基础上，
按规定的扣除比例「「重新计算核实」」，看企业申报扣除的金额有无差错，
「「并关注是否存在取得土地后未开发即转让、取得土地后将生地变为熟地转让的特殊情形」」。」**

### ⚠ 三、本页的「要点密集区」（**复习提示**）

| 要点 | ⚠ 所指 |
|---|---|
| ⚠⚠ **收入端五项 / 扣除端五项** | **应税收入·价格偏低·视同销售·非货币收入·完整性 ／ 土地成本·开发成本·开发费用·税金·加计 20%** |
| ⚠⚠ **「成交价格明显低于评估价格、又无正当理由 → 按评估价格征税」** | **《土地增值税暂行条例》既有规则在审核中的落点** |
| ⚠⚠ **视同销售的「确认顺序」** | **先「本企业同一地区·同一年度同类房地产平均价格」，再「税务机关参照当地当年同类市场价或评估价」** |
| ⚠⚠ **返还土地出让金** | **不入账即「加大扣除项目金额」——查「银行存款」与「开发成本」** |
| ⚠ **分期开发的分摊** | **仅就「对外转让部分」计入扣除；查三个明细账** |
| ⚠⚠ **开发间接费用的四个「有无」** | **不属于开发产品的费用／分配结转不合理／多计应税少计非应税／列支了期间费用** |
| ⚠⚠ **利息的两条禁扣** | **超过上浮幅度的部分／超过贷款期限的利息与加罚利息** |
| ⚠⚠ **印花税的「两处出现」** | **日常在「管理费用」（营改增后或为「税金及附加」）核算，但申报土增税时计入「与转让房地产有关的税金」扣除——须防「扩大范围」** |
| ⚠⚠ **加计 20% 的基数** | **「取得土地使用权所支付的金额」＋「房地产开发成本」之和** |

> ⚠ **申报代办视角**（**土地增值税申报的「专业判断关注事项」：收入 A–E／扣除 A–M／应纳税额 A–D**）见 [[land-appreciation-tax-filing-judgment]]（**第五章第三节批 6，2026-10-08**）——⚠⚠ **本页是第三章「审核视角」，该页是第五章「申报视角」，两页并存互指、不合并**。

> ⚠ **鉴证视角**（**土地增值税「清算鉴证」：四项关注事项（含扣除项目九项专项关注）与三类鉴证证据**）见 [[land-appreciation-tax-liquidation-certification]]（**第六章批 2，2026-10-08**）——⚠⚠ **土增清算在本库现同时拥有「实体规则」「第三章审核」「第五章申报」「第六章鉴证」四支，四者并存互指、不合并**。
