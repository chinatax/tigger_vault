# 城镇土地使用税

## Definition

城镇土地使用税（Urban Land Use Tax）：对在城市、县城、建制镇、工矿区范围内
**使用土地**的单位和个人，按**实际占用土地面积**课征的财产税。
⚠ **按年计算、分期缴纳**；⚠ **采用地区差别定额税率**（不是比例税率）。

它与房产税**在同一不动产上并存**——同一栋自用房产既缴房产税（从价）又缴城镇土地使用税。

## Key Points

### 一、征税范围与纳税人

- **征税范围**：**城市、县城、建制镇和工矿区**的土地
  （⚠ **不包括农村**）——无论国家所有还是集体所有。
- **纳税人**：
  - 拥有土地使用权的**单位或个人**
  - ⚠ 土地使用权**出租**的，以**出租方**为纳税人（⚠ 不是承租人）
  - ⚠ 土地使用权**共有**的，以**共有各方**为纳税人
  - ⚠ 土地使用权属**未确定**的，以**实际使用人**为纳税人
  - ⚠ **纳税单位无偿使用免税单位**的土地，**纳税单位**应照章缴纳
- **税额**：⚠ 经济发达地区可适当**提高**适用税额标准，但须报经**财政部**批准；
  ⚠ 经济落后地区可适当**降低**，但降低额**不得超过规定最低税额的 30%**。

### 二、纳税义务发生时间（高频，易错）

- **购置新建商品房** → 自房屋**交付使用之次月**起缴纳
- **购置存量房** → 自办理房屋权属转移、变更登记手续、
  房地产权属登记机关**签发房屋权属证书之次月**起缴纳
- **以出让或转让方式有偿取得土地使用权** → 应由**受让方**从**合同约定交付土地时间的次月**起；
  ⚠ **合同未约定交付时间**的，从**合同签订的次月**起
- ⚠ **通过招标、拍卖、挂牌方式取得的建设用地**（不属于新征用的耕地）→
  从**合同约定交付土地时间的次月**起；合同未约定的从**合同签订的次月**起
- ⚠ **新征用的耕地** → 自批准征用之日起**满 1 年**时开始缴纳
- ⚠ **新征用的非耕地** → 自批准征用**之次月**起缴纳
- **房产出租** → 自**交付出租房产次月**起

### 三、主要免税

- **国家机关、人民团体、军队自用**的土地
- **由国家财政部门拨付事业经费的单位自用**的土地
- **宗教寺庙、公园、名胜古迹自用**的土地
  （⚠ 但公园、名胜古迹中**附设的营业场所**，如影剧院、饮食部、茶社、照相馆等用地**应征收**）
- **市政街道、广场、绿化地带等公共用地**
- **直接用于农、林、牧、渔业的生产用地**
  （⚠ 指直接从事种植、养殖、饲养的**专业用地**；
  **农副产品加工厂占地**和从事农林牧渔业生产单位的**生活、办公用地不包括在内**）
- **企业办的学校、医院、托儿所、幼儿园**其**自用**的土地
- ⚠ **企业厂区（包括生产、办公及生活区）以内的绿化用地** → **照章征收**（不免）
- **城市轨道交通系统运营用地**；**城市公交站场**占地
- **非营利性老年服务机构**自用土地（暂免）
- **核电站**：对**核岛、常规岛、辅助厂房和通讯设施**用地（**不包括地下线路用地**）、
  生活、办公用地按规定征收；**其他用地免征**；
  ⚠ **基建期内减半**征收
- **电力行业**：**供电部门变电站用地、输电线路用地**免征；
  ⚠ **火电厂厂区围城外**的**铁路专用线用地、输油管道用地**免征；
  ⚠ **水电站的发电厂房用地**（含坝内、坝外式厂房）、生产、办公、生活用地**应征收**
- **民航机场**：**停机坪、滑行道、场内通信导航设施、场外道路**用地免征；
  ⚠ **机场工作区**（含候机楼、停车场）、**生活区、绿化用地**应征收
- **港口**：⚠ **码头（泊位）用地免征**；港口的**其他用地应征收**
- **水利设施及其管护用地**（水库库区、大坝、堤防、灌渠、泵站等）免征
- **盐场**的**盐滩**用地；**盐矿的矿井**用地
- **保障性住房项目建设用地**免征；对**公租房**建设期间及建成后占地免征
- ⚠ **单独建造的地下建筑用地** → **暂按应征税款的 50%** 征收
- ⚠ **物流企业**自有或承租的**大宗商品仓储设施用地** →
  2027-12-31 前**减按所属土地等级适用税额标准的 50%** 计征

### 四、征收管理

- ⚠ 由**土地所在地**的税务机关负责征收
- ⚠ **纳税期限**由**省、自治区、直辖市人民政府**确定（不是市级）
- ⚠ 纳税人使用的土地**不在一地**的，由纳税人**分别向土地所在地**税务机关申报缴纳
- ⚠ **尚未核发土地使用证书**的，应由纳税人**据实申报**土地面积（不是税务机关核定）

### 教材补充（CTA《税法（二）》教材 2026 版第八章）

**（一）⚠ 纳税人四类（与房产税近似）**

- ⚠ **由拥有土地使用权的单位或个人**缴纳
- ⚠ **拥有土地使用权的纳税人不在土地所在地**的 → 由**代管人或实际使用人**纳税
- ⚠ **土地使用权未确定或权属纠纷未解决**的 → 由**实际使用人**纳税
- ⚠ **土地使用权共有**的 → 由**共有各方分别**纳税

> ⚠ 提示：上述规定与**房产税近似**，因为土地和房屋都是资产，
> **出现特殊情况时，资产的实际持有人或使用人是判断两者的基本标准**。

**（二）⚠⚠ 四级幅度税额**

| 城市规模 | 每平方米年税额 |
|---|---|
| ⚠ **大城市** | **1.5 元至 30 元** |
| ⚠ **中等城市** | **1.2 元至 24 元** |
| ⚠ **小城市** | **0.9 元至 18 元** |
| ⚠ **县城、建制镇、工矿区** | **0.6 元至 12 元** |

- ⚠ **大、中、小城市以城区常住人口为标准**：
  ⚠ **城区常住人口 100 万以上 500 万以下**的城市为**大城市**；
  ⚠ **50 万以上 100 万以下**的为**中等城市**；⚠ **50 万以下**的为**小城市**
- ⚠ **两级确定**：省级人民政府在法定税额幅度内，根据**市政建设状况、经济繁荣程度**等条件，
  确定所辖地区的**适用税额幅度**；⚠ **市、县人民政府**根据实际情况将本地区土地**划分为若干等级**，
  在省级确定的幅度内**制定适用税额标准**，报省级人民政府**批准执行**
- ⚠⚠ **两处调整**：**经济落后地区**的适用税额标准可适当**降低**，
  但**降低额不得超过规定的最低税额的 30%**；
  ⚠ **经济发达地区**的适用税额标准可适当**提高**，
  但**须报经财政部批准**

**（三）⚠ 计税依据与两处特殊规则**

- ⚠ 以纳税人**实际占用的土地面积（平方米）**为计税依据
- ⚠ **实际占用的土地面积**指由**省、自治区、直辖市人民政府确定的单位组织测定**的土地面积；
  ⚠ **尚未组织测量**的 → 以**纳税人持有政府部门核发的土地使用证书所确认的土地面积**为准；
  ⚠ **尚未核发土地使用证书**的 → 应由**纳税人据实申报**土地面积
- ⚠⚠ **单独建造的地下建筑用地**：
  - **已取得地下土地使用权证**的 → 按**土地使用权证确认的土地面积**为准
  - **未取得**地下土地使用权证，或**证上未标明土地面积**的 →
    按**地下建筑垂直投影面积**计算应征税款
  - ⚠⚠ **对上述地下建筑用地暂按应征税款的 50% 征收**城镇土地使用税
- ⚠ **共有土地使用权** → 由共有各方**按照各自实际使用的土地面积占总面积的比例**
  分别计算缴纳
- ⚠ **公式**：**年应纳税额 = 计税土地面积（平方米）× 适用税额**

**（四）⚠ 基本免税的七项**

1. **国家机关、人民团体、军队自用**的土地（**本身的办公用地和公务用地**）
2. **由国家财政部门拨付事业经费的单位自用**的土地
   - ⚠ **由国家财政部门拨付事业经费的单位**指由国家财政部门拨付经费、
     **实行全额预算管理或差额预算管理**的事业单位；
     ⚠⚠ **不包括实行自收自支、自负盈亏的事业单位**
   - ⚠ **事业单位自用的土地**指这些单位本身的**业务用地**
3. **宗教寺庙、公园、名胜古迹自用**的土地
   - ⚠ **宗教寺庙自用的土地**指举行宗教仪式等的用地和**寺庙内的宗教人员生活用地**
   - ⚠ **公园、名胜古迹自用的土地**指**供公共参观游览的用地**及其**管理单位的办公用地**
   - ⚠ 公园、名胜古迹中**附设的营业场所**（如**影剧院、饮食部、茶社、照相馆**等）用地 → **应征收**
4. ⚠ **市政街道、广场、绿化地带等公共用地**
   - ⚠⚠ **非社会性的公共用地不能免税**，如**企业内的广场、道路、绿化**等占用的土地
5. ⚠ **直接用于农、林、牧、渔业的生产用地**
   - ⚠ 指**直接从事种植、养殖、饲养的专业用地**
   - ⚠⚠ **农副产品加工厂占地**和**从事农、林、牧、渔业生产单位的生活、办公用地** **不包括在内**
6. ⚠ **开山填海整治的土地**
   - ⚠ **自行开山填海整治的土地和改造的废弃土地**，
     从**使用的月份起免缴 5 年至 10 年**
   - ⚠ **「开山填海整治的土地」指纳税人经有关部门批准后自行填海整治的土地**，
     ⚠ **不包括**纳税人通过**出让、转让、划拨**等方式取得的**已填海整治**的土地
7. 由**财政部另行规定**免税的**能源、交通、水利用地**和其他用地

**（五）⚠ 其余优惠的四组要点**

**1. 免税单位与纳税单位之间无偿使用土地（⚠ 不对称）**：

- ⚠ **免税单位无偿使用纳税单位的土地**（如**公安、海关等单位使用铁路、民航等单位**的土地）→
  **免征**
- ⚠⚠ **纳税单位无偿使用免税单位的土地** → **纳税单位应照章缴纳**

**2. 企业厂区内外之分（三组对照）**：

| 项目 | 厂区（含生产、办公及生活区）**以内** | **厂区以外** |
|---|---|---|
| ⚠ **铁路专用线、公路等用地** | **照章征收** | ⚠ **与社会公用地段未加隔离**的 → **暂免征收** |
| ⚠ **绿化用地** | **照章征收** | ⚠ **公共绿化用地和向社会开放的公园用地** → **暂免征收** |

**3. ⚠ 特定行业的用地区分（六组）**：

| 行业 | **免征/暂免** | **照章征收** |
|---|---|---|
| ⚠ **盐场、盐矿** | **盐滩、盐矿井井用地** | **生产厂房、办公、生活区用地**；其他用地由省级税务局确定 |
| ⚠ **矿山企业** | **采矿场、排土场、尾矿库、炸药库的安全区，采区运矿及运岩公路、尾矿输送管道及回水系统用地**；**采掘地下矿造成的塌陷地在未利用之前** | **其他生产用地及办公、生活区用地** |
| ⚠ **电力行业** | ⚠ **火电厂**：厂区**围墙外**的**灰场、输灰管、输油（气）管道、铁路专用线**用地；⚠ **水电站**：**发电厂房（含坝内、坝外式厂房）、生产、办公、生活用地以外的其他用地**；⚠ **供电部门**：**输电线路用地、变电站用地** | ⚠ **火电厂**：厂区**围墙内**用地、**围墙外其他用地**；⚠ **水电站**：**发电厂房、生产、办公、生活用地** |
| ⚠ **水利设施** | **水利设施及其管护用地**（如**水库库区、大坝、堤防、灌渠、泵站**等用地） | **生产、办公、生活用地**。⚠ 兼有发电的比照电力行业 |
| ⚠ **港口** | **码头**（即**泊位**，包括**岸边码头、伸入水中的浮码头、堤岸、堤坝、栈桥**等）用地 | **其他用地** |
| ⚠ **民航机场** | **飞行区**（**跑道、滑行道、停机坪、安全带、夜航灯光区**）用地、**场内外通信导航设施用地**、**飞行区四周排水防洪设施**用地；⚠ **场外道路**用地 | ⚠ **工作区**（办公、生产和维修用地及**候机楼、停车场**）用地、**生活区用地、绿化用地**；⚠ **场内道路**用地 |
| ⚠ **核电站** | **核岛、常规岛、辅助厂房和通讯设施用地以外的其他用地** | **核岛、常规岛、辅助厂房和通讯设施用地**（⚠ **不包括地下线路用地**）、生活、办公用地。⚠ **应税土地在基建期内减半征收** |

**4. 其余十项（要点）**：

- ⚠ **企业办的学校、医院、托儿所、幼儿园自用**的土地 → **免征**
- ⚠ **防火、防爆、防毒等安全防范用地**（各类**危险品仓库、厂房**所需）→
  可由**省级税务局确定暂免**；⚠ **但对仓库库区、厂房本身用地，应依法征收**
- ⚠ **棚户区改造**：**改造安置住房建设用地**免征；⚠ **配套设施**的按**建筑面积占比**免征
- ⚠ **农产品批发市场、农贸市场**专门用于经营农产品的土地 → **暂免**（执行至 2027-12-31）；
  ⚠ 同时经营其他产品的，按**其他产品与农产品交易场地面积的比例**确定征免
- ⚠ **供热企业**（「三北」地区）：**为居民供热所使用的厂房及土地**免征；
  ⚠ **专业供热企业**按**向居民供热取得的采暖费收入占全部采暖费收入的比例**计算免征；
  ⚠ **兼营供热企业**：**可区分的**按上述比例免征，**难以区分的**按
  **向居民供热采暖费收入占其营业收入的比例**计算免征
- ⚠ **物流企业大宗商品仓储设施用地** → **减按所属土地等级适用税额标准的 50%** 计征
  —— ⚠ **仓储设施用地**包括仓库库区内的各类**仓房（含配送中心）、油罐（池）、货场、晒场（堆场）、
  罩棚**等储存设施和**铁路专用线、码头、道路、装卸搬运区域**等物流作业配套设施的用地；
  ⚠ **物流企业的办公、生活区用地及其他非直接用于大宗商品仓储的土地应按规定征收**
- ⚠ **安置残疾人就业单位**：在一个纳税年度内**月平均实际安置残疾人就业人数占单位在职职工总数的
  比例高于 25%（含 25%）且实际安置残疾人人数高于 10 人（含 10 人）**的单位 →
  可**减征或免征**该年度城镇土地使用税
- ⚠ **由省级税务局确定征免税的情形**：**个人所有的居住房屋及院落用地**、
  房产管理部门在**房租调整改革前经租的居民住房用地**、**免税单位职工家属的宿舍用地**、
  **集体和个人举办的各类学校、医院、托儿所、幼儿园用地**等
- ⚠ **「六税两费」减半**：对**增值税小规模纳税人、小型微利企业和个体工商户**减半征收
  （执行至 2027-12-31），⚠ **已依法享受其他优惠的可叠加享受**
- ⚠ **抵债不动产**：各地可根据《房产税暂行条例》授权和本地实际，
  对**银行业金融机构、金融资产管理公司持有的抵债不动产**减免

**（六）⚠⚠ 纳税义务发生时间（七类，与房产税口径不同）**

| 情形 | 起算时点 |
|---|---|
| ⚠ **购置新建商品房** | 自**房屋交付使用之次月起** |
| ⚠ **购置存量房** | 自**办理房屋权属转移、变更登记手续，房地产权属登记机关签发房屋权属证书之次月起** |
| ⚠ **出租、出借房产** | 自**交付出租、出借房产之次月起** |
| ⚠ **以出让或转让方式有偿取得土地使用权** | 应由**受让方**从**合同约定交付土地时间的次月起**缴纳；⚠ **合同未约定交付时间**的 → 从**合同签订的次月起** |
| ⚠⚠ **征收的耕地** | 自**批准征收之日起满 1 年时**缴纳 |
| ⚠⚠ **新征用的非耕地** | 自**批准征用次月起**缴纳 |
| ⚠ **通过招标、拍卖、挂牌方式取得的建设用地** | ⚠ **不属于新征用的耕地** → 从**合同约定交付土地时间的次月起**缴纳；⚠ **合同未约定交付时间**的 → 从**合同签订的次月起** |

- ⚠ 提示：**免税单位出借土地给纳税单位使用的，纳税单位应从出借次月起缴纳**城镇土地使用税
- ⚠ **纳税期限**：**按年计算，分期缴纳**，缴纳期限由**省级人民政府**确定；
  ⚠ 各省税务机关结合当地情况，一般分别确定**按月、季、半年或 1 年**等不同期限
- ⚠ **纳税地点**：**土地所在地**，由土地所在地的税务机关负责征收；
  ⚠ **纳税人使用的土地不在一地**的 → 由纳税人**分别向土地所在地**的税务机关申报缴纳

### ⚠⚠ 地方口径补充（**安徽 · 合肥，2026-09-29 新增**）

> ⚠ 本节为**省级/市级落地实例**——⚠ 教材只写到「**省级政府定幅度、市县政府分等报批**」；
> ⚠ **数值只适用于安徽/合肥**，**不得外推**。⚠ 上位概念见 [[local-tax-implementation-authority]]。

**（一）⚠ 省级实施办法（[[anhui-urban-land-use-tax-implementation-measures]]）**：

- ⚠ **计税依据**：**以纳税人实际占用的土地面积为计税依据**；
  ⚠⚠ **面积确定**：**土地使用证书确认的面积**为先，**尚未核发证书的以纳税人据实申报、
  经地方税务机关核实的面积为准**（⚠ 与教材三级顺位不同，见 Contradictions 一）；
- ⚠⚠ **四级幅度**：**大城市 1.5–30／中等 1.2–24／小城市 0.9–18／县城·建制镇·工矿区 0.6–12**（元/㎡·年）；
- ⚠⚠ **分等程序**：**市县将本地区土地划分若干等级、在省定幅度内制定适用税额标准、报省政府批准执行**；
- ⚠ **重点贫困县**：可适当降低，**降低额不得超过最低税额的 30%**；
- ⚠ **减免**：**按《条例》执行，不另设地方事项**（⚠ 与房产税侧不对称，见 Contradictions 三）；
- ⚠ **纳税期限**：原为「**按年计算、分期缴纳，期限由市、县地方税务机关确定**」，
  ⚠⚠ **自 2021-01-01 起被 [[anhui-property-and-behaviour-tax-filing-2020]] 统一为按季**。

**（二）⚠⚠ 市级等级税额实例（[[hefei-urban-land-use-tax-grades-2023]]）**——**合肥市区四等**：

| 等级 | 年税额（元/㎡） | 范围 |
|---|---|---|
| 一等 | **18** | **一环路以内** |
| 二等 | **14** | **一环路以外、二环路以内** |
| 三等 | **9** | **二环路以外** |
| 四等 | **5** | **高新区、经开区、新站高新区、庐阳、蜀山、包河、龙岗等开发区** |

⚠⚠ **同市内最高与最低档相差 3.6 倍（18 ÷ 5）**——
⚠ 这正是本税种**审核实务中「不分地段、一律适用同一单位税额」这一典型错弊**
（教材例 3-14）的现实土壤，见 [[real-estate-and-urban-land-use-tax-audit]]。
