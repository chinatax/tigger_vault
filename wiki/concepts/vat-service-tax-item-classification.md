# 销售服务的税目归类

## Definition

销售服务的税目归类（VAT Service Classification）：把一笔服务业务**归入哪个增值税税目**的判断。
税目决定适用税率，也决定征免与优惠待遇，因此**归类错误会一路传导**到税额结果。

判断的困难不在大类，而在**易混边界**——同一笔业务换个说法就可能落到不同税目（如租赁与运输、
建筑与物流辅助）。教材为此专门配了大量"提示"作辨析。

## Key Points

### 六大类服务

**交通运输服务、邮政服务、电信服务、建筑服务、金融服务、生产生活服务。**

### 交通运输服务

陆路运输（铁路运输、其他陆路运输——公路、缆车、索道、地铁、城市轻轨）、水路运输、航空运输、管道运输。

- **程租、期租**（水路运输） → 属于**水路运输服务**
- **湿租**（航空运输） → 属于**航空运输服务**
- **航天运输服务** → 按**航空运输服务**缴纳增值税
- **无运输工具承运业务** → 按**交通运输服务**（经营者以承运人身份收取运费并承担承运人责任，
  再委托实际承运人完成）
- **已售票但客户逾期未消费**取得的运输逾期票证收入 → 按**交通运输服务**
- 出租车公司向使用本公司自有出租车的司机收取的**管理费用** → 按**陆路运输服务**

### 建筑服务

工程服务、安装服务、修缮服务、装饰服务、其他建筑服务。

- 固定电话、有线电视、宽带、水、电、燃气、暖气等经营者向用户收取的
  **安装费、初装费、开户费、扩容费** → 按**安装服务**

### 金融服务

贷款服务、直接收费金融服务、保险服务、金融商品转让。

- **各种占用、拆借资金**取得的收入（保本收益、报酬、资金占用费、补偿金、金融商品持有期间利息、
  信用卡透支利息、买入返售金融商品利息、融资融券利息，以及**融资性售后回租**、押汇、罚息、
  票据贴现、转贷等） → 按**贷款服务**
- 以货币资金投资收取的**固定利润或保底利润** → 按**贷款服务**
- ⚠ **融资性售后回租不按"租赁服务"**，按**贷款服务**

### 生产生活服务（15 个子目）

研发和技术服务、信息技术服务、文化创意服务、物流辅助服务、租赁服务、鉴证咨询服务、
广播影视服务、商务辅助服务、文化体育服务、教育医疗服务、旅游娱乐服务、餐饮住宿服务、
居民日常服务、**加工修理修配服务**、其他生产生活服务。

### ⚠ 高频易混辨析（教材"提示"汇编）

| 业务 | 归类 |
|---|---|
| 水路运输的**程租、期租**；航空运输的**湿租** | **交通运输服务** |
| 水路运输的**光租**；航空运输的**干租** | **有形动产经营租赁** |
| 装卸搬运、仓储、收派（含快递）服务 | **物流辅助服务** |
| 出租**带宽** | **基础电信服务** |
| **融资性售后回租** | **贷款服务** |
| 宾馆、度假村等经营性住宿场所提供**会议场地及配套服务** | **会议展览服务** |
| 游览场所经营**索道、摆渡车、电瓶车、游船** | **文化服务** |
| **车辆停放服务、道路通行服务**（过路费、过桥费、过闸费） | **不动产经营租赁服务** |
| 将建筑物/构筑物、飞机/车辆等**广告位出租**用于发布广告 | **经营租赁服务** |
| **翻译服务、市场调查服务** | **咨询服务** |

## Contradictions

**大类名称随新法调整，归类实质未变（已判定）**：[[freight-and-labour-tax-line-2025]]（题库，旧法）
第 67 题载明"纳税人在游览场所经营**摆渡车**取得的收入，按照'**文化体育服务**'缴纳增值税"，
同时载明"宾馆等提供会议场地及配套服务按'会议展览服务'""将建筑施工设备出租并配备操作人员按'建筑服务'"。
本概念来源（教材第三节，新法）在多数归项上**一致**（会议展览服务、文化服务等），
但将"游览场所经营索道、摆渡车、电瓶车、游船"归入**文化服务**（新法将原"文化体育服务"细化表述）。
**判定：归类实质未变，仅大类名称表述随新法调整。** 差异记录于此，不取平均。
