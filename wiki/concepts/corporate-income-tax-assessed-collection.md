# 企业所得税核定征收

## Definition

企业所得税核定征收（Assessed Collection of Corporate Income Tax）：因纳税人**账簿不健全、
难以查账**，由税务机关**核定应税所得率或应纳所得税额**计算征收企业所得税的方式。

⚠ 它与**查账征收**是**平行的两种征收方式**——判断分岔在**账簿与核算是否健全**，
而不是纳税人规模。核定征收下**不得享受多数税收优惠**（见「不适用」清单）。

## Key Points

### 一、适用核定征收的六种情形

纳税人具有下列情形**之一**的，核定征收企业所得税：

1. 依照法律、行政法规的规定**可以不设置账簿**的
2. 依照法律、行政法规的规定**应当设置但未设置账簿**的
3. **擅自销毁账簿或者拒不提供纳税资料**的
4. 虽设置账簿，但**账目混乱**或者**成本资料、收入凭证、费用凭证残缺不全，难以查账**的
5. 发生纳税义务，**未按照规定期限办理纳税申报**，经税务机关**责令限期申报、逾期仍不申报**的
6. **申报的计税依据明显偏低，又无正当理由**的

### 二、⚠ 不适用核定征收的六类纳税人

**特殊行业、特殊类型的纳税人和一定规模以上的纳税人不适用**核定征收办法：

1. ⚠ 享受《企业所得税法》及其实施条例和国务院规定的**一项或几项企业所得税优惠政策**的企业
   —— **但两类除外**：①**仅享受第二十六条规定的免税收入优惠政策**的企业；
   ②**第二十八条规定的符合条件的小型微利企业**
2. **汇总纳税企业**
3. **上市公司**
4. ⚠ **金融企业**：银行、信用社、**小额贷款公司**、保险公司、证券公司、期货公司、
   信托投资公司、金融资产管理公司、融资租赁公司、担保公司、财务公司、典当公司等
5. ⚠ **经济鉴证类社会中介机构**：会计、审计、资产评估、税务、房地产估价、土地估价、
   工程造价、律师、价格鉴证、公证机构、基层法律服务机构、专利代理、商标代理等
6. 国家税务总局规定的其他企业

- ⚠ **另有一条硬性排除**：**专门从事股权（股票）投资业务**的企业，**不得**核定征收企业所得税

### 三、核定办法的两条路

**路径一：核定应税所得率**（下列情形之一）

1. 能正确核算（查实）**收入总额**，但**不能**正确核算（查实）**成本费用总额**的
2. 能正确核算（查实）**成本费用总额**，但**不能**正确核算（查实）**收入总额**的
3. 通过合理方法能**计算和推定**收入总额或成本费用总额的

⚠ 纳税人**不属于**以上情形的 → 核定其**应纳所得税税额**。

**核定方法**（可采用其一；一种不足以正确核定的可**同时采用两种以上**）：

1. 参照当地同类行业或者类似行业中**经营规模和收入水平相近**的纳税人的**税负水平**核定
2. 按照**应税收入额或成本费用支出额定率**核定
3. 按照**耗用的原材料、燃料、动力**等推算或测算核定
4. 按照其他合理方法核定

- ⚠ 采用两种以上方法测算的应纳税额**不一致**时，可按测算的应纳税额**从高核定**

### 四、各行业应税所得率幅度

| 行业 | 应税所得率 |
|---|---|
| 农、林、牧、渔业 | **3%–10%** |
| 制造业 | **5%–15%** |
| 批发和零售贸易业 | **4%–15%** |
| 交通运输业 | **7%–15%** |
| 建筑业 | **8%–20%** |
| 饮食业 | **8%–25%** |
| 娱乐业 | **15%–30%** |
| 其他行业 | **10%–30%** |

### 五、计算公式

> **应纳所得税税额 = 应纳税所得额 × 适用税率**
>
> **应纳税所得额 = 应税收入额 × 应税所得率**
> **＝ 成本（费用）支出额 ÷（1 − 应税所得率）× 应税所得率**

- ⚠ **应税收入额 = 收入总额 − 不征税收入 − 免税收入**
  （收入总额为企业以货币形式和非货币形式从各种来源取得的收入）
- ⚠ **经营多业**的，**无论其经营项目是否单独核算**，均由税务机关根据其**主营项目**确定适用的应税所得率
  - **主营项目** = 纳税人所有经营项目中，**收入总额、成本（费用）支出额、耗用原材料燃料动力数量**
    三者中**所占比重最大**的项目
- ⚠ 纳税人的生产经营范围、主营业务发生**重大变化**，或者应纳税所得额／应纳税额
  **增减变化达到 20%** 的，应及时向税务机关**申报调整**已确定的应纳税额或应税所得率

### 六、征收管理

- **鉴定程序**（⚠ 三个工作日的数字易考）：
  1. 纳税人应在收到《企业所得税核定征收鉴定表》后 **10 个工作日内**填好并报送
     （⚠ 未按期填列报送的，税务机关**视同已报送**，按程序复核认定）
  2. 主管税务机关应在受理后 **20 个工作日内**分类逐户审查核实、提出鉴定意见，
     报县级税务机关复核认定
  3. 县级税务机关应在收到后 **30 个工作日内**完成复核、认定工作
- ⚠ 税务机关应在每年 **6 月底前**对上年度实行核定征收的纳税人进行**重新鉴定**；
  重新鉴定完成前可**暂按上年度**方式预缴，完成后按结果调整
- 主管税务机关应当**分类逐户公示**核定的应纳所得税税额或应税所得率；
  纳税人有异议的应提供**合法有效的相关证据**，税务机关核实后调整
- **核定应税所得率方式的申报**：由主管税务机关根据应纳税额大小确定**按月或按季**预缴
  （⚠ **小型微利企业统一按季度预缴**），年终汇算清缴；**预缴方法一经确定，
  一个纳税年度内不得改变**。按实际数额预缴有困难的，经同意可按上年度应纳税额的
  **1/12 或 1/4** 预缴。填报《企业所得税月（季）度预缴纳税申报表（**B 类**）》
- **核定应纳所得税税额方式的申报**：税额未确定前可暂按上年度税额的 **1/12 或 1/4** 预缴；
  确定后减除当年已预缴的税额，余额按**剩余月份或季度均分**；
  年度终了后按规定时限按**实际经营额或实际应纳税额**申报
  ——⚠ 申报额**超过**核定额的按**申报额**缴纳；申报额**低于**核定额的按**核定额**缴纳

### 七、两处专门规定

- **专门从事股权（股票）投资业务的企业**：**不得**核定征收（见上「不适用」）
  - ⚠ 依法按**核定应税所得率**方式核定征收的企业，取得的**转让股权（股票）收入等转让财产收入**，
    应**全额计入应税收入额**，按照**主营项目（业务）**确定的应税所得率计算征税；
    若**主营项目发生变化**，应在**当年汇算清缴时**按变化后的主营项目**重新确定**适用的应税所得率
- **跨境电子商务综合试验区零售出口企业**（自 2020-01-01 起）：
  - 三项条件同时符合者试行核定征收：①在综试区注册，并在注册地跨境电子商务线上综合服务平台
    **登记出口货物**日期、名称、计量单位、数量、单价、金额；②出口货物通过**综试区所在地海关**
    办理电子商务出口申报手续；③出口货物**未取得有效进货凭证**，其增值税、消费税**享受免税**政策
  - ⚠ 应准确核算**收入总额**，采用应税所得率方式核定，**应税所得率统一按 4% 确定**
  - ⚠ 符合**小型微利企业**条件的可享受小微优惠；取得的收入属于**免税收入**的可享受免税收入优惠

### 八、企业转让上市公司限售股

- ⚠ **纳税义务人**：转让限售股取得收入的企业（包括**事业单位、社会团体、民办非企业单位**等）
- **代个人持有的限售股**（股权分置改革造成原由个人出资而由企业代持）：
  - 企业转让取得的收入应**作为企业应税收入**计算纳税；
    **限售股转让所得 = 转让收入 − 限售股原值 − 合理税费**
  - ⚠ 企业**未能提供完整、真实的原值凭证**、不能准确计算原值的 →
    主管税务机关**一律按该限售股转让收入的 15%** 核定为该限售股**原值和合理税费**
  - ⚠ 完成纳税义务**后的余额转付给实际所有人时不再纳税**
  - ⚠ 依**法院判决、裁定**等原因，通过证券登记结算公司将企业代持的个人限售股
    **直接变更到实际所有人名下**的，**不视同转让**限售股
- **解禁前转让限售股**：企业应按**减持在证券登记结算机构登记的限售股**
  取得的**全部收入**计入当年度应税收入计算纳税；
  ⚠ 已签协议转让但**未变更股权登记、仍由企业持有**的，企业**实际减持**取得的收入
  纳税后**其余额转付给受让方的，受让方不再纳税**
