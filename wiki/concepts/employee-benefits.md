# 职工薪酬

## Definition

职工薪酬（Employee Benefits）：企业为获得职工提供的服务或解除劳动关系而给予的各种形式的报酬或补偿，按**受益对象**计入相关资产成本或当期损益，同时确认「应付职工薪酬」负债。

它的判断主线有两条：**这笔支出是否属于职工薪酬的范围**，以及**该计入哪个受益对象的成本或费用**——其中**辞退福利不区分受益对象、一律计入管理费用**是唯一的例外。

## Key Points

- **范围边界**（第 325 题）：
  - ⚠ **职工个人储蓄性养老保险属于个人行为，与企业无关，不属于**职工薪酬的核算范围
- **分类**（第 342 题）：
  - **短期薪酬**：✅ **住房公积金**、✅ **工伤保险**、✅ **职工教育经费**、医疗保险费、工会经费等
  - **离职后福利**：⚠ **失业保险属于离职后福利**（**不是**短期薪酬）；
    **基本养老保险、失业保险**均属于**设定提存计划**
- **短期利润分享计划**（第 329 题）：
  - 应作为**费用**处理（按受益对象分担，或按规定作为资产成本的一部分），
    ⚠ **不能作为净利润的分配**（不得借记「利润分配」）
  - 例：净利润 1600 万元 × 5% = 80 万元 → 借「**管理费用**」80、贷「应付职工薪酬——利润分享计划」80
- **带薪缺勤**（第 344 题）：
  - 对于当期**已行使权利**的累积带薪缺勤，**不必额外作**相应的计量
  - 与**未行使**的短期累积带薪缺勤权利相关的职工薪酬，
    应以**累积未行使权利而增加的预期支付金额**计量
  - **短期非累积**带薪缺勤相关的职工薪酬，应在职工**实际发生缺勤**的会计期间确认
- **辞退福利与内部退休**（第 344、353 题）：
  - ⚠ **辞退福利不区分受益对象，应全部计入「管理费用」**
  - 补偿额**超过一年支付**的辞退计划，应选择适当的折现率，以**折现后**的金额计入当期管理费用
    - 例：50 人 × 10 万元 ×（P/A,6%,5）= 50×10×4.2124 = **2106.2 万元**；
      贷「应付职工薪酬」2500、借「**未确认融资费用**」393.8
  - **职工内部退休计划**：职工**正式退休之前**比照**辞退福利**处理，
    **正式退休之后**按**离职后福利**处理
- **通过「应付职工薪酬」科目核算的项目**（第 345 题）：
  - ✅ 为职工缴纳的**住房公积金**、无偿提供给职工使用的**租赁住房的租金**、
    应由**在建工程**负担的在建工程人员薪酬
  - ⚠ **不通过**该科目：以**权益结算的股份支付**（确认为**资本公积**）；
    按国家规定需要缴纳的**残疾人就业保障金**（缴纳时直接记入「**管理费用**」）
- **非货币性福利**（第 351 题，⚠ 计量口径各不相同）：
  - 将**拥有的房屋**无偿提供给职工使用 → 按该住房**每期计提的折旧**计入相关资产成本或当期损益
  - 将**租赁**的住房供职工无偿使用 → 按**每期应付的租金**计入
  - 以**自产产品**作为非货币性福利发放 → ⚠ 按产品的**公允价值和相关税费**计入
    （**不是**账面价值），同时确认收入并结转成本
  - **难以认定受益对象**的非货币性福利 → 直接计入当期损益
- **受益对象的划分**（第 353 题）：
  - **生产部门直接生产人员** → 生产成本；**生产部门管理人员** → 制造费用
  - **管理部门人员** → 管理费用；**销售部门人员** → 销售费用
  - ⚠ 计提医疗保险费、住房公积金、工会经费、职工教育经费时，**同样按上述受益对象分摊**
  - 例：工资总额 840（生产 350 + 车间管理 180 + 管理 100 + 销售 210），
    另按 10%、8%、2%、8% 计提四项费用
    → 计入**期间费用**的金额 =（100 + 210）×［1 +（10%+8%+2%+8%）］= **396.8 万元**
    （⚠ 生产人员与车间管理人员的部分计入生产成本与制造费用，**不影响期间费用**）
