# 企业所得税纳税审核：财务费用与支出类

## Definition

⚠ **本页是《涉税服务实务》第三章第三节之（一）企业所得税的纳税审核的
「2. 税前准予扣除项目」的末尾三块**——
即 **「（3）期间费用及支出的审核」的第三块「〇财务费用的审核」、
第四块「〇营业外支出的审核」、第五块「〇其他业务成本的审核」**，
⚠⚠ **以及「（4）税金及附加的审核要点」**。

⚠⚠ **须注意「（4）」是新的一级子目（**教材的编号**）**：
> ⚠ **「2. 税前准予扣除项目」在教材中分为「（1）税前扣除凭证的审核／（2）主营业务成本的审核／
> （3）期间费用及支出的审核／「「（4）税金及附加的审核要点」」」**——
> ⚠⚠ **本页因此同时承载「期间费用的尾块」与「独立的（4）」两段。**

## Key Points

### ⚠ 一、C. 财务费用的审核

#### A. 利息净支出的审核

⚠⚠ **「利息支出」方面的六个审核点（**教材原句要点**）**：

| # | ⚠ 审核点 |
|---|---|
| **1** | ⚠ **是否将「资本性利息支出」作为生产经营期间的利息支出列入财务费用**——**如购建固定资产在尚未完工交付使用前发生的利息费用不计入固定资产价值，而列入财务费用** |
| **2** | **列入财务费用的利息支出金额是否超出规定的「准予列支标准」** |
| **3** | ⚠ **有无「利息收入不抵减利息支出」的** |
| **4** | **长期借款利息有无「人为调节利润而不按期限均衡提取」的** |
| **5** | ⚠⚠ **对于「投资者投资未到位」而发生的利息支出，是否按税法规定计算出「不得扣除的金额」在税前予以调整**——**凡企业投资者在规定期限内未缴足其应缴资本额的，该企业对外借款所发生的利息，相当于投资者实缴资本额与在规定期限内应缴资本额的「差额应计付的利息」，「不属于企业合理的支出，应由企业投资者负担，不得在计算企业应纳税所得额时扣除」** |
| **6** | ⚠ **注意发行「永续债」的企业支付的永续债利息支出在企业所得税税前扣除是否符合税法规定，相应投资方收到的永续债利息收入是否依法纳税** |

⚠⚠ **「不得扣除的利息」的计算（**教材给出公式与计算期**）**：
> **「应以企业一个年度内每一账面「实收资本」与「借款余额」保持不变的期间作为一个「计算期」，
> 每一计算期内不得扣除的借款利息，按该期间借款利息发生额乘以该期间企业未缴足的注册资本
> 占借款总额的比例计算。」**

**公式**：**企业每一计算期不得扣除的借款利息 ＝ 该期间借款利息额 × 该期间未缴足注册资本额 ÷ 该期间借款额**；
⚠ **「企业一个年度内不得扣除的借款利息总额，为该年度内每一计算期不得扣除的借款利息额之和。」**

⚠ **审核方法（**三步**）**：
- ⚠ **对「财务费用」账户明细账的「借方发生额」，对照原始凭证「逐笔」审核**——
  **看列支的利息支出是否「超范围」；对「集资」的利息支出看是否有「政府相关文件」；
  计算一下金额是否正确；对不符合规定的列支金额应剔除，「调增利润」**；
- ⚠ **通过审核「财务费用」明细账「贷方」，看企业的「利息收入是否在本账户进行了全额反映」**；
- ⚠ **以「借款合同或有关协议书」为依据，核实「生产期贷款利息的预提」是否正确**。

#### B. 汇兑损益的审核

⚠⚠ **四项审核点**：**① 汇兑损益的「计算方法是否正确」；② 企业是否「按规定时间确定」汇兑损益；
③ 所用「汇率是否正确」；④ 对于「从筹建期间汇兑损益转人（入）的」，其「摊销方法在前后期
是否保持一致，摊销金额是否正确」。**

⚠ **审核方法**：**对「财务费用——汇兑损益」明细账「逐笔」进行核实，翻阅有关原始凭证
检查其核算的正确性。**

### ⚠⚠ 二、D. 营业外支出的审核

#### A. 对营业外支出的审核内容（**三类**）

| # | ⚠ 问题（**教材原句要点**） |
|---|---|
| **a** | ⚠ **有无「扩大营业外支出范围」的**——**如将应记入「在建工程」的基建费用、应从税后利润支出的「非公益救济性捐赠」、和各项「罚款、滞纳金」，以及违反财经纪律的支出列入营业外支出，在计税时未作剔除** |
| **b** | ⚠⚠ **有无「不按规定要求支出」的**——**如有些企业「停工损失的界限混淆」，将「季节性和修理性停工损失」列入营业外支出**；**对「公益救济性捐赠超支部分」，在计税时未作剔除**——⚠ **税法规定：纳税人当年发生的以及以前年度结转的公益性捐赠支出，在「年度利润总额 12% 以内」的部分，准予在计算应纳税所得额时扣除** |
| **c** | ⚠ **有无「擅自列支固定资产净损失和非常损失」的** |

#### B. 审核方法（**三类**）

| # | ⚠ 方法（**教材原句要点**） |
|---|---|
| **a** | **根据「营业外支出」明细账「借方发生额」，对「摘要栏」内容进行「逐笔」审核，对金额较大、登记摘要不明的，应重点审核记账凭证和原始凭证所反映的经济内容，鉴别、分析是否应列入营业外支出** |
| **b** | ⚠⚠ **对一些「有列支标准」的项目，要审核是否符合规定的标准**——**如将营业外支出账上列支的公益救济性捐赠数额，与按规定的标准和计算办法计算出的「法定限额」对照，对超支部分应在计税时剔除并「调增应纳税所得额」**；⚠⚠ **结转规则**：**超过限额的部分「准予结转以后 3 年内」在计算应纳税所得额时扣除，「结转年限自捐赠发生年度的次年起计算，最长不得超过 3 年」**；⚠ **计算扣除时，「应先扣除以前年度结转的捐赠支出，再扣除当年发生的捐赠支出」**；⚠ **企业当期发生的公益救济性捐赠「不足年度利润总额 12% 的部分应据实扣除」** |
| **c** | ⚠⚠ **对于一些「规定有审批手续」的营业外支出项目，要检查是否有「留存备查资料」**——**如非正常损失必须根据损失金额大小，「扣除过失人和保险赔款后」列入营业外支出**；⚠ **自 2017 年度及以后年度企业所得税汇算清缴，企业向税务机关申报扣除资产损失，「仅需填报」企业所得税年度纳税申报表《资产损失税前扣除及纳税调整明细表》，「不再报送」资产损失相关资料，「相关资料由企业留存备查」**；**企业应当完整保存资产损失相关资料，保证资料的真实性、合法性** |

⚠⚠ **两类固定资产损失的具体查法（**教材给出账户路径**）**：
- ⚠ **固定资产「盘亏」**：**要根据「待处理财产损溢——待处理固定资产损溢」账户，结合
  「固定资产明细账」，看「核销的盘亏固定资产是否已经查明原因、有无批件、盘亏固定资产
  是原值还是净值、已提折旧是否冲减」**；
- ⚠ **报废、毁损固定资产的「净损失」**：**应审核「固定资产清理」账户和固定资产明细账，
  看「转入清理的固定资产是净值还是原值、已提折旧是否转入、变价的价款是否冲减损失」**；
- ⚠ **此外**：**还要注意对照「本年利润」账户，看期末结转的金额是否一致。**

### ⚠ 三、E. 其他业务成本的审核

| # | ⚠ 审核点 |
|---|---|
| **A** | **审核「其他业务成本」是否符合「配比原则」，有无少计、多计或不计成本费用的现象** |
| **B** | ⚠ **审核其「成本结转的计算方法」是否正确**——**对于材料物资出售结转成本，可采用「先进先出法、加权平均法」等计算其支出成本** |
| **C** | **审核「其他业务成本」是否有「余额」**——**审核时，应依据「其他业务成本」账户的「借方发生额」进行，对「偏高的月份」进行重点审核，并审核「本年利润」账户，看其「期末结转」是否正确、「其他业务成本」有无余额** |

### ⚠⚠ 四、（4）税金及附加的审核要点（**教材的一级子目**）

⚠⚠ **界定（**教材原句**）**：
> **「税金包括「消费税、城市维护建设税、资源税、土地增值税」等。附加是指国家为了
> 「筹集教育经费，支持教育事业的发展」，按企业实际缴纳的「消费税、增值税」税额的
> 一定比例计提的「教育费附加」。」**

⚠ **审核的总方向**：**「主要从税金及附加的「预提、缴纳、结算」几（三）个方面进行，
看有无「多提少缴或不缴」的情况。」**

| # | ⚠ 子项 | ⚠ 审核内容（**教材原句要点**） |
|---|---|---|
| **1** | ⚠ **预提税金及附加的审核** | **应在核实「销售收入和适用税率」的基础上，认真查阅「应交税费」账户，看「贷方发生额」与「纳税申报表上填写的税金及附加」是否一致，不一致则要查明原因**；⚠⚠ **「防止将「耕地占用税、税收罚款」等记入『税金及附加』账户中核算，减少本期利润」** |
| **2** | ⚠ **缴纳税金的审核** | **企业缴纳税金在「应交税费」明细账户「借方」反映，应审核「税款所属期限、实际缴纳期限是否正确，缴纳的税额是否与计提数一致」，并要「审阅各税完税凭证」**；⚠⚠ **分析缴纳税金的情况有无「提而不缴」，或将「错提、多提的税金从『应交税费』账户借方非法转入其他账户」的情况** |
| **3** | ⚠⚠ **结算税金的审核** | **年度终了，企业对缴纳各税的情况应进行「汇算清缴」，及时办理补退手续**；⚠⚠ **「由于年度税务检查一般是在年度决算后的次年进行的，企业应补或应退的产品销售税金及附加，「应在『以前年度损益调整』账户结算」」**；⚠ **「而有的企业将查补上年的税款记入本年『税金及附加』账户中，抵减了本年利润，审核时要认真核实有无上述问题。」** |

### ⚠ 五、本页的「要点密集区」（**复习提示**）

| 要点 | ⚠ 所指 |
|---|---|
| ⚠⚠ **资本性利息不得列财务费用** | **购建固定资产未完工交付使用前的利息应资本化** |
| ⚠⚠ **利息收入必须抵减利息支出** | **查「财务费用」贷方是否全额反映** |
| ⚠⚠ **投资未到位的利息公式** | **以「每一账面实收资本与借款余额保持不变的期间」为一个计算期；年度总额为各期之和** |
| ⚠ **永续债** | **支付方能否扣除、投资方是否依法纳税——两头都要看** |
| ⚠ **汇兑损益四项** | **方法／时点／汇率／筹建期转入的摊销一致性** |
| ⚠⚠ **营业外支出的三个「有无」** | **扩大范围／不按规定（停工损失界限、捐赠超支）／擅自列支固定资产净损失与非常损失** |
| ⚠⚠ **捐赠的「12% + 3 年结转」与顺序** | **先扣以前年度结转的，再扣当年发生的** |
| ⚠⚠ **资产损失申报方式（2017 年度起）** | **仅需填报《资产损失税前扣除及纳税调整明细表》，不再报送资料，留存备查** |
| ⚠⚠ **「税金及附加」不得混入的项目** | **耕地占用税、税收罚款——计入即减少本期利润** |
| ⚠⚠ **查补上年的税款走「以前年度损益调整」** | **记入本年「税金及附加」即抵减本年利润，属错弊** |

> ⚠ **申报代办视角**（**利息支出、不得税前扣除项目等在申报表填报时的关注内容**）见 [[cit-filing-adjustment-review]]（**第五章批 4，2026-10-08**）。
