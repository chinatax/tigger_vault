# 增值税一般纳税人申报算例（例 5-2）

## Definition

⚠ **本页是《涉税服务实务》第五章第一节之「（四）1 代理填制一般纳税人增值税及附加税费申报表
及其附列资料」所附的「「例 5-2」」的完整留档**（书页 305 末–310，txt 310 末–315）——
**一个「制造业高新技术企业 + 先进制造业加计抵减 + 出口免抵退税 + 期末留抵退税 + 省外不动产预缴」

|---|---|---|
| **（一）** | **企业基本情况** | **制造业高新技术企业，增值税一般纳税人，纳税缴费信用等级 A 级**；**生产的货物和生产用的材料适用税率均为 13%**；**出口货物适用免抵退税办法，出口货物退税率 13%**；**城市维护建设税适用税率 7%**；⚠ **经省工业和信息化主管部门会同同级科技、财政、税务部门确定，纳入 2025 年度享受增值税加计抵减政策的先进制造业企业名单** |

### 二、⚠⚠ （三）业务清单的结构（**只录结构**）

> ⚠⚠ **以下只列「科目的种类与逻辑」，涉及的**具体金额一律以「〔金额受损〕」代过**——
> **不推补、不臆测**（**第三档**）。

#### 1. 收入方面（**境内销售货物·服务 6 项 + 出口货物 1 项**）

| # | ⚠ 业务 | ⚠ 结构要点 |
|---|---|---|
| **(1)** | **境内销售货物、服务** | ⚠ 含**四个销售方式**：**以直接收款方式**（分「开具电子发票（增值税专用发票）」「开具电子发票（普通发票）」「未开具发票」三类）；**以分期收款方式**（**以前月份发出货物 + 本月可收款 + 实际收款 + 因故未收且未开票部分**）；**以预收款方式**（**本月收取预收款、货物尚未发出** vs **以前月份已收预收款、当月发出**，含**质量保证金暂未收取**与**收取余款**） |
| **②** | **销售返利** | ⚠ **对 2024 年度采购货物较大的购货方按协议给予返利，价税合计〔金额受损〕，并按规定开具红字发票**——⚠ **分「红字电子发票（增值税专用发票）」与「红字电子发票（普通发票）」两笔**（**后者仅税额 19500 元可辨**） |
| **③** | **收回欠款及利息** | ⚠ **收到某购货方 2023 年和 2024 年拖欠的购货款合计〔金额受损〕，并经协商另收取货款的利息 169500 元，并向其开具收款收据** |
| **④** | **省外出租办公用房** | ⚠ **协议收取 2025 年 4—12 月的房屋租赁费价税合计〔金额受损〕，未开具发票**；**已向办公用房所在地税务机关填报《增值税及附加税费预缴表》并预缴税款〔金额受损〕，取得完税凭证**——⚠ **这是本算例「预缴抵减」的来源** |
| **⑤** | **食堂浴室专用设备出售** | ⚠ **职工食堂和浴室升级改造，将食堂和浴室专用的设备出售共收款〔金额受损〕，按规定选择按 3% 征收率减按 2%，并开具带有「普通发票」字样的数电发票（金额〔受损〕、税额 2000 元）**——⚠ **这是本算例「简易计税减征」的来源** |
| **(2)** | **出口货物** | ⚠ **出口销售货物离岸价（人民币）合计〔金额受损〕，均开具零税率的增值税普通发票** |

| # | ⚠ 事由 | ⚠ 可辨要素 |
|---|---|---|
| **(1)** | **非正常损失** | **一批生产用材料因管理不善造成非正常损失**；**损失材料的金额〔受损〕、税额〔受损，算式自证 6 500 元〕**；**按企业内部制度由责任人赔偿〔受损〕**；⚠ **经审核确认该批材料的进项税额于 2024 年 12 月申报抵扣，并加计 5% 抵减税额** |
| **(2)** | **退货填开红字信息确认单** | **2026 年 1 月购进的一批辅助材料存在质量问题，向供货方退货**；**按原购进时取得电子发票（增值税专用发票）的金额〔受损〕、税额〔受损，算式自证 7 800 元〕填开《红字发票信息确认单》并上传**；⚠ **辅助材料已退还供货方，尚未取得红字发票，也未收到退货款** |
| **(3)** | **增量留抵退税办理** | **申请退还的增量留抵税额经主管税务机关审核确认，已办理退税〔金额受损〕**——⚠ **这是（四）6（3）进项税额转出的第三笔** |

#### 4. 其他情况（**4 项，均为计算的前提条件**）

| # | ⚠ 条件 |
|---|---|
| **(1)** | **当期开具的增值税发票都已按规定进行报税，取得的增值税抵扣凭证已按税务机关要求进行用途确认** |
| **(2)** | ⚠ **经审核确认，企业购进的材料销售方均不是该企业的总分机构或同一控制下的企业，也没有发生将原材料、半成品销售给另一企业加工为半成品或者产成品后回购的情形**——⚠ **这排除了加计抵减的两项「不得计提」情形（见 [[vat-filing-general-taxpayer-return]] 特殊业务⑪）** |
| **(3)** | ⚠ **当期生产用材料、设备等的进项税额中，出口货物与内销货物能够区分，其中出口货物对应的进项税额为〔受损〕、内销货物对应的进项税额为〔受损〕，其他进项税额无法划分出口货物不得加计抵减额的进项税额**——⚠ **这是（四）9（2）出口货物对应进项税额的直接取数** |
| **(4)** | **企业上月的免抵退税申报已获得税务机关审核确认，增值税应退税额与企业申报一致，为〔金额受损〕** |

### 三、⚠⚠ （四）应纳增值税额的**十三步计算链**（**结构照录**）

> ⚠⚠ **本节的「计算步骤与勾稽关系」是本算例最可复用的部分**——**金额一律〔受损〕**。

| 步 | ⚠ 步骤 | ⚠ 勾稽关系（**结构**） |
|---|---|---|
| **1** | **境内销售货物的销售额和销项税额** | 按**开具专票／开具普票／未开具发票**三档分别算：**销售额 = 各销售方式的价税合计／含税数额，扣除红字返利后 ÷（1 + 13%）**；**销项税额 = 销售额 × 13%**；**再合计** |
| **2** | **省外出租不动产的销售额和销项税额** | ⚠ **「收取租赁费未开具发票，已于 4 月开始提供租赁服务，应就收到的全部价款缴纳增值税」**；**销售额 = 含税租赁费 ÷（1 + 9%）**；**销项税额 = 销售额 × 9%** |
| **3** | **简易计税方法的销售额及应纳增值税额** | **应纳增值税额 = 销售额 × 3%**（**食堂浴室设备出售，3% 减按 2%**）；**可减征税额 = 销售额 ×（3% − 2%）= 销售额 × 1%** |
| **4** | **出口销售货物的销售额** | **免抵退税出口销售额** |
| **5** | **可以抵扣销项税额的进项税额** | ⚠ **五档相加**：**① 增值税专用发票注明的可抵扣进项税额**（**算式列出「材料 + 劳务派遣 + 广告费 + 水费 + 电费 + 通信费 + 通行费相关 + …」多项之和**）；**② 海关进口增值税专用缴款书注明的**（**= 1 560 元，自证**）；**③ 收费公路通行费电子发票注明的**（**= 150 + 100 = 250 元，自证**）；**④ 境内旅客运输费用计算可抵扣的**（**= 1 238.53 + 铁路部分 + 721 ÷（1+3%）× 3%，算式自证 = 1 821 元**）；**⑤ 异常凭证转入可抵扣的**；⚠ **再合计** |
| **6** | **进项税额转出** | ⚠ **三笔**：**① 非正常损失进项税额转出**；**② 《红字发票信息确认单》进项税额转出**；**③ 增值税留抵退税**（**对应（三）3（3）**）；**再合计** |
| **7** | **免抵退应退税额** | **税务机关审核确认增值税免抵退应退税额** |
| **8** | **一般计税方法计算未加计抵减前的应纳增值税额** | ⚠ **应纳增值税（未加计抵减前）= 销项税额合计 + 省外不动产销项税额 − 可抵扣进项税额合计 − 免抵退应退税额** |
| **9** | ⚠⚠ **加计抵减税额**（**本例的核心**） | **(1) 加计抵减期初余额**；**(2) 计提加计抵减额**——⚠ **先剔除两项**：**① 异常凭证转入的进项税额为 2022 年发生的，因 2022 年度尚未实施先进制造业加计抵减政策，不能加计抵减；② 出口货物对应的进项税额不得计提**（**按出口销售额占全部销售额的比例分摊计算**）→ **可计提加计抵减的进项税额 = 可抵扣进项税额合计 − 异常凭证转入 − 出口货物对应进项**；**计提加计抵减额 = 可计提进项税额 × 5%**；**(3) 加计抵减调减额**——⚠ **「留抵退税后作进项税额转出时，不需要调减加计抵减额」**，**故仅就非正常损失与退货两笔转出**计算调减额；**(4) 可加计抵减额 = 期初余额 + 计提额 − 调减额**；**(5) 实际加计抵减额**——⚠ **按一般计税方法计算的应纳增值税额（第 8 步）大于可加计抵减额时，可全部加计抵减**；**(6) 实际加计抵减额**；**(7) 加计抵减额期末余额** |
| **10** | **应纳增值税额合计** | **① 一般计税方法加计抵减后的应纳增值税额 = 第 8 步 − 第 9 步实际加计抵减额**；**② 简易计税方法应纳增值税额**；**合计** |
| **11** | **本期应补增值税额** | ⚠ **省外出租不动产已预缴的税款（对应（三）1④）可以在当期应纳税额抵减**；**本期应补增值税额 = 应纳增值税额合计 − 已预缴税款** |
| **12** | **出口销售货物免抵税额**（**企业当月申报**） | **免抵税额 = 免抵退税出口销售额 × 13%（退税率）** |
