# 税制导论

## Definition

税制导论（Introduction to Tax Systems）：对各国税收制度按**课税对象**所作的分类与比较，为学习具体税种提供概念框架。

它的价值不在计算，而在**提供判断题的依据**——例如「我国个人所得税属于哪一类所得税制」「居民公司如何认定」这类不查条文就要靠常识判断的问题。

## Key Points

- **所得税的两大类**：
  - **个人所得税**：对自然人课征，包括综合收入、专项收入、权利金收入，以及无住所又不居住或居住不满规定天数的**非居民个人**取得的上述收入
  - **公司所得税**（我国称为**企业所得税**）：对企业的**经营利润、资本利得**以及**非居民企业**的上述收入课征
- **个人所得税制的三种类型**（⚠ 高频判断题）：

  | 类型 | 特征 | 采用国家 |
  |---|---|---|
  | **综合所得税制** | 征税所得为个人**全年各项所得的总额**，减除法定宽免额和扣除额后的净所得，依统一的**超额累进税率**征收 | 美国、比利时、加拿大、意大利、墨西哥、挪威、法国 |
  | **分类所得税制** | 对不同来源、不同性质的所得项目规定**不同税率**，采用**源泉控制**征收；通常对劳动所得征税轻、对投资所得适中 | **英国**最典型 |
  | **混合所得税制** | 融合两者之长：既对特定所得项目单列税率与征税办法（便于源泉扣缴与区别对待），又对其余所得**综合计税**（体现量能负担） | 日本、韩国；⚠ **我国当前开征的个人所得税亦属混合所得税制** |

  - **个人所得的扣除项目两大类**：①为取得收入**必须支付**的有关费用（差旅费、利息支出、维修费、灾害保险费等）；
    ②**生计费用**（基本生活费、赡养费、教育支出、医疗费、人寿保险费、退休金等）
  - 扣除形式可以是**据实扣除、限额扣除或限率扣除、定额扣除**，以及限额内自负、超限额部分允许扣除等
- **公司所得税**：
  - 税基 = **收入总额 − 不征税收入 − 免税收入 − 法定扣除项目**
  - 应税收入项目通常包括：销售收入、特许权使用费收入、前期已支付费用的补偿收入（如保险收入）、
    利息、股息收入、财产租赁收入、财产变价收入、佣金及不必偿还的债务收入、其他收益（如营业外收入）
  - 扣除的基本原则：**只允许扣除与取得应税收入有关的那一部分必要费用支出**——
    因此要区别业务支出与个人支出、营业性支出与非营业性支出、**收益性支出与资本性支出**
- **居民与非居民公司的纳税义务**（通行的国际惯例）：
  - **居民公司**承担**全面纳税义务**，就来源于**世界范围**的所得向公司管辖国政府纳税
  - **非居民公司**仅负**有限纳税义务**，只就来源于**收入来源国境内**的所得向该国政府纳税
- **居民公司的认定标准**（⚠ 各国做法不一致，三点要能对上国家）：

  | 标准 | 含义 | 采用国家 |
  |---|---|---|
  | **登记注册标准** | 凡在本国**登记注册**的公司即为本国居民公司 | 美国、加拿大 |
  | **总机构标准** | 公司的**总机构**设在本国境内即为本国居民公司 | 意大利 |
  | **管理中心标准** | 公司的**实际控制或实际管理中心**设在本国境内即为本国居民公司 | 英国、德国、新加坡 |

- **公司所得税的税率结构**：⚠ 与个人所得税相反，**公司所得税多为单一税率**；
  少数国家（危地马拉、巴拿马、沙特阿拉伯、苏丹、巴拉圭）采用**多级累进税率**
- **社会保险税**：
  - 税基是**企业雇员的工资和薪金额**，通常**没有税前扣除规定**，
    但规定有**税基的最高限额**——对个人超过限额的那一部分工薪所得**不予征税**
  - 税率一般实行**分项比例税率**（按退休、失业、伤残、医疗、抚恤等项目分别设置）
  - 一般由**雇主和雇员分担**缴纳；应由雇员缴纳的税款由雇主**直接从其工薪所得中扣缴**，个体业主自行申报
- **财产税的分类**（⚠ 两套分类标准）：

  | 分类依据 | 类别 |
  |---|---|
  | 按**征税范围** | **一般财产税**（也称综合财产税，对纳税人的**全部财产合并计税**；**美国**最具代表性）<br>**个别财产税**（对各项财产**单独征税**，包括土地税、房屋税、不动产税） |
  | 按 **OECD 国际税收协定范本**标准 | **不动产税**（也称房产税，属**持有税**，按评估价值征税，主要为**地方税**）<br>**财产净值税**（或称财富税，对产权人或使用人**不论是否取得收益**按财产价值课征；欧洲的荷兰、德国、瑞士、挪威较流行）<br>**财产转移税**（对出售资产取得的收益和转移财产征收，如**资本利得税、遗产税、赠与税**） |

  - **土地税**按税基分两类：**财产性质的土地税**（以土地的**数量或价值**为税基，如从量计征的**地亩税**、
    从价计征的**地价税**）与**收益性质的土地税**（以土地的**收益额或所得额**为税基）
- **遗产税的三种类型**（⚠ 要能对上国家）：

  | 类型 | 含义 | 采用国家 |
  |---|---|---|
  | **总遗产税** | 不论继承人多少及其与死者的亲疏关系，按**分配、继承前的遗产总额**累进征收 | 美国、英国、新加坡、南非 |
  | **分遗产税**（也称**继承税**） | 根据**继承人分得的遗产**课税，税负轻重往往与继承人之间的亲疏关系有关 | 日本、德国、法国、保加利亚、波兰 |
  | **总分遗产税**（混合遗产税制） | **先对遗产总额征税，再对继承人分得的遗产征税** | 加拿大、意大利、伊朗、菲律宾、爱尔兰 |

  - **赠与税**：对财产所有人**生前赠与他人**的财产征收，征税目的主要是**防止财产所有人为逃避死后的遗产税
    而在生前以赠与方式转移财产**；它与遗产税**配套**，是辅助税种
- **行为税**：以纳税人的**特定行为**作为课税对象；通常将不属于货物劳务税、所得税、财产税的其他税种归于此类
  - 四个特点：①**征税对象的选择范围广泛而灵活**，既可广集财政收入，又可体现国家政策；
    ②包括的**税种较多**，各税种具体课税对象差异甚大，征税制度与办法也有很大不同；
    ③大多数是国家根据**一定时期的需要**、尤其为**限制某种特定行为**而开征，因此
    ⚠ **除印花税税负较轻之外**，其他行为税税负一般比较重、**税源不够稳定**；
    ④税源零星、征收范围有限、**征收管理难度较大**
  - 因此行为税**大多为地方税**，在一国税制体系中作为**辅助税种**存在
