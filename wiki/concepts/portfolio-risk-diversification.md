# 证券组合风险与分散

## Definition

证券组合风险与分散（Portfolio Risk and Diversification）：证券资产组合的风险由各组成资产自身的风险**及其相互之间的相关性**共同决定，因此组合风险并不等于各资产风险的简单加权平均。

该概念的核心结论是：**非系统风险可以通过分散化消除，系统风险不能**——这构成了资本资产定价模型只对系统风险定价的理论基础。

## Key Points

- **两类风险的区分**（第 19、28 题的辨析对象）：
  - **非系统风险**（可分散风险、公司特有风险）：**可以**随着资产种类的增加而**降低甚至消除**
  - **系统风险**（市场风险、不可分散风险）：**不能**随着资产种类的增加而分散
  - ⚠ 选项「系统风险对所有资产及所有企业有相同的影响」错误——尽管绝大部分企业和资产都不可避免地受系统风险影响，但**影响程度并不相同**
  - ⚠ 选项「可以通过资产多样化达到完全消除风险的目的」错误——系统风险无法通过分散消除
  - ⚠ 本教材把「**企业会计准则改革**」列入**系统风险**（第 28 题 C 选项按正确答案处理），此归类与常见理解不同，引用时需注意
- **相关系数 ρ 与风险分散**（第 19 题的核心表格）：

  | 相关系数 | 关系 | 组合标准差 | 风险分散功能 |
  |---|---|---|---|
  | ρ = 1 | 完全正相关：收益率变化方向与幅度完全相同 | σ = w₁σ₁ + w₂σ₂（**最大**） | **不能降低任何**风险 |
  | ρ = −1 | 完全负相关：变化方向相反、幅度相同 | σ = w₁σ₁ − w₂σ₂（**最小**） | **能最大限度地降低**风险 |
  | −1 < ρ < 1 | 不完全相关 | 0 < σ < w₁σ₁ + w₂σ₂ | 能分散风险，但**不能完全消除** |

  - ⚠ 只要相关系数**小于 1**，组合风险就**低于**各资产风险的加权平均值
  - ⚠ 第 19 题 C 选项「相关系数**大于零**时组合风险小于加权平均数」被判定为**错误**——「大于零」包含 ρ = 1（此时相等而非小于），正确表述必须是「相关系数**小于 1 大于 −1**」
- **组合 β 系数**：组合 β = Σ(各资产**权重** × 各资产 β)
  - 权重按各资产的**市场价值**（如每股市价 × 股数）占比计算，不是按股数或账面价值
- **组合必要收益率** = 无风险收益率 + 组合 β × 市场风险溢酬
- **组合风险收益率** = 组合 β × 市场风险溢酬
