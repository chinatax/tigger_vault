# 发出存货的计价方法

## Definition

发出存货的计价方法（Inventory Costing Methods）：把期初存货成本与本期购入成本在**发出存货**与**期末存货**之间进行分配的方法，包括先进先出法、月末一次加权平均法、移动加权平均法、个别计价法，以及适用于特定企业的计划成本法、售价金额法、毛利率法。

考点集中在三种「简便法」的**分母口径**上——它们都是用一个比率把售价或计划成本还原为实际成本，而比率的分母常被记错。

## Key Points

- **基本计价方法**：
  - **先进先出法**：假定先入库的先发出
  - **月末一次加权平均法**：加权平均单位成本 =（期初结存成本 + 本期购入成本）÷（期初数量 + 本期购入数量），
    月末一次计算，**全月发出与期末结存用同一单价**
  - **移动加权平均法**：每次**购入**后即重新计算加权平均单价，发出时按当时的平均单价计价
  - **个别计价法**：逐一辨认发出与结存存货的实际成本
- **计划成本法**（第 199、223 题）：
  - **材料成本差异率** =（期初结存差异 + 本期入库差异）÷（期初结存计划成本 + 本期入库计划成本）× 100%
  - 发出材料的**实际成本** = 发出计划成本 ×（1 + 材料成本差异率）
  - ⚠ 计算差异率时须**剔除月末暂估入账**的计划成本——暂估部分尚未形成实际成本，不产生差异
  - ⚠ **超支**差异（实际 > 计划）为正，**节约**差异为负；分母也要相应扣除暂估金额
  - 「**材料成本差异**」科目**借方**核算范围：登记材料**实际成本大于计划成本**的差额（超支）、
    结转节约差异额、调整减少计划成本；**贷方**核算：登记节约差异、结转超支差异、调整增加计划成本
    - ⚠ 「已收到发票账单但尚未验收入库的在途材料」的采购成本**不涉及**材料成本差异的核算
- **售价金额法**（商业零售企业，第 186、208 题）：
  - **进销差价率** = 月末分摊前「商品进销差价」科目余额 ÷ 100%
    其中分母 =「**库存商品**」月末余额 +「**发出商品**」月末余额 +「**委托代销商品**」月末余额
    + 本月「**主营业务收入**」科目贷方发生额
  - 销售商品的**实际成本** = 售价 ×（1 − 进销差价率）
  - **存货项目列示金额** =（库存商品 + 发出商品 + 委托代销商品）− 三者合计 × 进销差价率
  - **公式的推导**（解析给出的记忆法）：
    - 分子 = 期初商品的进销差价 + 本期增加商品的进销差价（即月末分摊前的余额）
    - 分母 = 期初售价 + 本期增加售价 = 本期销售售价 + 期末剩余售价
    - 其中「本期销售售价」= 主营业务收入贷方发生额，「期末剩余售价」= 库存商品 + 发出商品 + 委托代销商品
- **毛利率法**（第 209 题）：
  - 销售**净额** = 销售收入 − **销售退回**（⚠ 必须先扣减退回）
  - 销售成本 = 销售净额 ×（1 − 毛利率）
  - 期末存货成本 = 期初存货成本 + 本期购入成本 − 本期销售成本
  - 毛利率可用上期实际毛利率或本期计划毛利率

> ⚠ **审核视角**（**按加权平均法·先进先出法·移动平均法结转销售成本的审核**，及计划成本下「产品成本差异」的结转）见 [[cit-audit-manufacturing-cost-and-carryover]]；⚠ **发出材料的计价与材料成本差异率**见 [[cit-audit-material-and-consumable-costs]]。
