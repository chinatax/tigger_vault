# 契税

## Definition

契税（Deed Tax）：在**土地、房屋权属转移**时，向**承受方**（受让方）课征的财产税，
实行 **3%~5% 的幅度税率**。⚠ 其最大特点是与印花税**相对**——
**印花税对交易双方（书立人）征收，契税只对"承受方"单方征收**。

判断的核心永远是：**谁是承受方**（契税纳税人）、**权属是否真的转移了**（征税前提）。

## Key Points

### 一、纳税人与税率

- **纳税人**：在境内**承受**土地、房屋权属转移的单位和个人（**受让方**）。
  ⚠ **转让方不是**契税纳税人。
- **税率**：**3%~5%** 的幅度税率。具体适用税率由**省、自治区、直辖市人民政府**
  在规定幅度内提出，报**同级人民代表大会常务委员会决定**，并报全国人大常委会和国务院备案。

### 二、计税依据

- **土地使用权出让、出售，房屋买卖** → **土地、房屋权属转移合同确定的成交价格**，
  ⚠ **包括**应交付的**货币以及实物、其他经济利益对应的价款**
- **土地使用权互换、房屋互换** → **互换价格差额**（⚠ **等价互换不需要缴纳**）
- **土地使用权赠与、房屋赠与**及其他**没有价格**的转移行为 →
  由税务机关**参照市场价格依法核定**
- ⚠ **承受已装修房屋**的，应将**装修费用**计入承受方应交付的总价款
- ⚠ **计税依据不包含增值税**
- ⚠ **不得因减免土地出让金而减免契税**——对承受国有土地使用权应支付的土地出让金，
  **应计征**契税
- **土地使用权出让**的计税依据包括：土地出让金、**土地补偿费、安置补助费、地上附着物和青苗补偿费、
  征收补偿费、城市基础设施配套费**、实物配建房屋等

### 三、先划拨后转让的规则（易错对比）

- 先以**划拨**方式取得土地使用权，后经批准转让房地产：
  - ⚠ 划拨土地性质**改为出让**的 → 承受方应**分别**以**补缴的土地出让价款**和
    **权属转移合同确定的成交价格**为计税依据缴纳契税
  - ⚠ 划拨土地性质**未发生改变**的 → 承受方以**权属转移合同确定的成交价格**
    为计税依据缴纳契税

### 四、主要免税

- **国家机关、事业单位、社会团体、军事单位**承受土地、房屋权属用于**办公、教学、医疗、
  科研、军事设施**
- **非营利性的学校、医疗机构、社会福利机构**承受土地、房屋权属用于**办公、教学、医疗、
  科研、养老、救助**
- **承受荒山、荒地、荒滩**土地使用权用于**农、林、牧、渔业生产**
- **婚姻关系存续期间夫妻之间**变更土地、房屋权属；
  **因离婚**办理房屋产权过户
- **法定继承人**通过继承承受土地、房屋权属
- ⚠ **个体工商户经营者**将其个人名下的房屋、土地权属**转移至个体工商户名下**，
  或个体工商户将其名下的房屋、土地权属**转回原经营者个人名下**——**免征**
- ⚠ **合伙企业的合伙人**将其名下的房屋、土地权属**转移至合伙企业名下**，
  或合伙企业将其名下的房屋、土地权属**转回原合伙人名下**——**免征**
- ⚠ **同一投资主体内部**所属企业之间土地、房屋权属的划转
  （包括**母公司与其全资子公司之间**、同一公司所属全资子公司之间）——**免征**
- **银行业金融机构、金融资产管理公司接收抵债资产**——免征
- **公租房经营单位**购买住房用于公租房
- **保障性住房经营管理单位**回购保障性住房继续作为保障性住房房源
- ⚠ **金融租赁公司售后回租**：承受承租人房屋权属的**照章征税**；
  ⚠ **售后回租合同期满、承租人回购原房屋权属**的**免征**

### 五、个人购房的差别化税率（高频）

自 **2024-12-01** 起：

| 情形 | 面积 ≤140 ㎡ | 面积 >140 ㎡ |
|---|---|---|
| **家庭唯一住房** | 减按 **1%** | 减按 **1.5%** |
| **家庭第二套住房** | 减按 **1%** | 减按 **2%** |

- ⚠ **个人首次购买 90 平方米以下改造安置住房** → 按 **1%** 税率计征
- ⚠ **个人购买经济适用住房** → 在法定税率基础上**减半**征收
- ⚠ **个人购买保障性住房** → 减按 **1%** 税率征收

### 六、纳税义务发生时间与征收管理

- ⚠ **纳税义务发生时间**：纳税人**签订土地、房屋权属转移合同的当天**，
  或者纳税人**取得其他具有土地、房屋权属转移合同性质凭证的当天**
  - ⚠ 因**人民法院、仲裁委员会的生效法律文书或者监察机关的监察文书**发生权属转移的，
    为**法律文书等生效当日**
  - ⚠ 因**改变土地、房屋用途**等情形应缴纳已减征、免征契税的，
    为**改变用途等情形的当日**
- ⚠ **申报期限**：纳税人应当在**依法办理土地、房屋权属登记手续前**申报缴纳契税
  - ⚠ 按规定**不再需要办理**土地、房屋权属登记的，
    自纳税义务发生之日起 **90 日内**申报缴纳
- **纳税地点**：**土地、房屋所在地**的税务机关
- **可申请退税**的情形（四项）：
  ①在依法办理权属登记**前**，权属转移合同或合同性质凭证**不生效、无效、被撤销或者被解除**的；
  ②因**人民法院判决或者仲裁委员会裁决**导致权属转移行为无效、被撤销或被解除，
  **且权属变更至原权利人**的；
  ③在**出让土地使用权交付**时，因**容积率调整或实际交付面积小于合同约定面积**
  需退还土地出让价款的；
  ④在**新建商品房交付**时，因**实际交付面积小于合同约定面积**需返还房价款的

### 教材补充（CTA《税法（二）》教材 2026 版第七章）

**（一）⚠ 征税范围的三类**

- ⚠ 契税的征税对象为**我国境内发生土地使用权和房屋所有权权属转移**的土地和房屋
- ⚠ **具体范围**：①**土地使用权出让**；②**土地使用权转让**（包括**出售、赠与和互换**）；
  ③**房屋买卖、赠与、互换**
- ⚠⚠ **两条边界**：
  - **土地使用权转让**包括出售、交换、赠与的方式，
    ⚠ **但不包括土地承包经营权和土地经营权的转移**
  - ⚠ **以作价投资（入股）、偿还债务、划转、奖励等方式转移土地、房屋权属**的 →
    **应当依法征收**契税

**（二）⚠⚠ 纳税人的三种特殊情形**

- ⚠ 在境内**转移土地、房屋权属**，**承受的单位和个人**为纳税人
- ⚠ **下列情形发生权属转移的，承受方应当依法缴纳契税**：
  1. **因共有不动产份额变化**的
  2. **因共有人增加或者减少**的
  3. ⚠ **因人民法院、仲裁委员会的生效法律文书或者监察机关出具的监察文书**等因素，
     发生土地、房屋权属转移的
- ⚠⚠ **提示（易错）**：通过转移土地、房屋权属**偿还债务**的，
  承受方（**债权人**）是纳税人

**（三）⚠ 税率**

- ⚠ **契税税率为 3%–5%**
- ⚠ **具体适用税率由省、自治区、直辖市人民政府在规定幅度内提出，
  报同级人民代表大会常务委员会决定，并报全国人大常委会和国务院备案**
- ⚠ 省级可依照规定对**不同主体、不同地区、不同类型的住房的权属转移**确定**差别税率**

**（四）⚠⚠ 计税依据（十项）**

⚠ 契税的计税依据**不包括增值税**。

1. ⚠ **土地使用权出让、出售，房屋买卖** → 为**土地、房屋权属转移合同确定的成交价格**，
   **包括应交付的货币以及实物、其他经济利益对应的价款**
2. ⚠ **土地使用权互换、房屋互换** → 为**互换土地使用权、房屋价格的差额**
3. ⚠ **土地使用权赠与、房屋赠与以及其他没有价格的转移** →
   为税务机关**参照土地使用权出售、房屋买卖的市场价格依法核定的价格**
   - ⚠ 纳税人申报的**成交价格、互换价格差额明显偏低且无正当理由**的 →
     由税务机关依照《税收征管法》的规定**核定**
4. ⚠ **以划拨方式取得的土地使用权，经批准改为出让方式重新取得**该土地使用权的 →
   应由该土地使用权人**以补缴的土地出让价款**为计税依据缴纳契税
5. ⚠ **先以划拨方式取得、后经批准转让房地产，划拨土地性质改为出让**的 →
   承受方应**分别以补缴的土地出让价款和房地产权属转移合同确定的成交价格**为计税依据
6. ⚠ **先以划拨方式取得、后经批准转让房地产，划拨土地性质未发生改变**的 →
   承受方应**以房地产权属转移合同确定的成交价格**为计税依据
7. ⚠ **土地使用权及所附建筑物、构筑物等**（**包括在建的房屋、其他建筑物、构筑物和其他附着物**）
   转让的 → 计税依据为**承受方应交付的总价款**
8. ⚠⚠ **土地使用权出让的计税依据**：包括**土地出让金、土地补偿费、安置补助费、
   地上附着物和青苗补偿费、征收补偿费、城市基础设施配套费、实物配建房屋**等
   **应交付的货币以及实物、其他经济利益对应的价款**
   - ⚠ 对承受国有土地使用权应支付的土地出让金，**应计征**契税
   - ⚠⚠ **不得因减免土地出让金而减免契税**
9. ⚠ **房屋附属设施**（包括**停车位、机动车库、非机动车库、顶层阁楼、储藏室及其他房屋附属设施**）：
   - 与房屋**为同一不动产单元**的 → 计税依据为**承受方应交付的总价款**，
     并**适用与房屋相同的税率**
   - 与房屋**为不同不动产单元**的 → 计税依据为**转移合同确定的成交价格**，
     并按**当地确定的适用税率**计税
10. ⚠ **承受已装修房屋**的 → 应将**包括装修费用在内的费用**计入承受方应交付的总价款

- ⚠ **公式**：**应纳税额 = 计税依据 × 适用税率**

**（五）⚠⚠ 基本免税的六项**

1. ⚠ **国家机关、事业单位、社会团体、军事单位**承受土地、房屋权属用于**办公、教学、医疗、
   科研、军事设施**
   - ⚠ **用途的具体口径**：**办公** → 限于**办公室（楼）以及其他直接用于办公**的土地、房屋；
     **教学** → 限于**教室（教学楼）以及其他直接用于教学**的；**医疗** → 限于**门诊部以及
     其他直接用于医疗**的；**科研** → 限于**科学试验的场所以及其他直接用于科研**的；
     **军事设施** → 限于**直接用于《军事设施保护法》规定的军事设施**的土地、房屋
2. ⚠ **非营利性的学校、医疗机构、社会福利机构**承受土地、房屋权属用于**办公、教学、医疗、
   科研、养老、救助**
   - ⚠ 限于上述三类单位中**依法登记为事业单位、社会团体、基金会、社会服务机构等的
     非营利法人和非营利组织**
   - ⚠ **用于养老**的 → 限于**直接用于为老年人提供养护、康复、托管等服务**的；
     **用于救助**的 → 限于**直接为残疾人、未成年人、生活无着落的流浪乞讨人员提供养护、康复、
     托管等服务**的
3. ⚠ **承受荒山、荒地、荒滩土地使用权用于农、林、牧、渔业生产**
4. ⚠ **婚姻关系存续期间夫妻之间变更**土地、房屋权属
5. ⚠ **法定继承人通过继承**承受土地、房屋权属
6. ⚠ 依照法律规定应当予以免税的**外国驻华使馆、领事馆和国际组织驻华代表机构**承受权属

- ⚠ **省级可决定免征或减征的两种情形**：①因土地、房屋被**县级以上人民政府征收、征用**，
  重新承受权属；②因**不可抗力灭失住房**，重新承受住房权属
  —— ⚠ **具体办法由省级人民政府提出，报同级人大常委会决定，
  并报全国人大常委会和国务院备案**

**（六）⚠ 其余优惠的四组**

**1. 售后回租与权属不转移的四项**：

- ⚠ **金融租赁公司开展售后回租业务，承受承租人房屋、土地权属**的 → **照章征税**；
  ⚠ **但售后回租合同期满、承租人回购原房屋、土地权属**的 → **免征**契税
- ⚠ **单位、个人以房屋、土地以外的资产增资**，相应扩大其在被投资公司的股权持有比例，
  **无论被投资公司是否变更市场主体登记**，其**房屋、土地权属不发生转移，不征收**契税
- ⚠ **个体工商户的经营者**将其个人名下的房屋、土地权属**转移至个体工商户名下**，
  或个体工商户将其名下的**转回原经营者个人名下** → **免征**
- ⚠ **合伙企业的合伙人**将其名下的房屋、土地权属**转移至合伙企业名下**，
  或合伙企业将其名下的**转回原合伙人名下** → **免征**

**2. 住房交易的四项**：

- ⚠ **保障性住房**（自 2023-10-01 起）：**经营管理单位回购**保障性住房继续作为房源的 → **免征**；
  ⚠ **个人购买**保障性住房 → **减按 1%** 的税率征收
- ⚠ **城镇职工按规定第一次购买公有住房** → **免征**；
  ⚠ **个人购买经济适用住房** → 在**法定税率基础上减半**征收
- ⚠⚠ **家庭唯一住房**（自 2024-12-01 起；⚠ **家庭成员范围包括购房人、配偶以及未成年子女**）：
  **面积 140 平方米及以下 → 减按 1%**；**140 平方米以上 → 减按 1.5%**
- ⚠⚠ **家庭第二套住房**（⚠ 指**已拥有一套住房的家庭购买的第二套**）：
  **140 平方米及以下 → 减按 1%**；**140 平方米以上 → 减按 2%**
  - ⚠ 2024-12-01 **前**个人销售、购买住房涉及的契税**尚未申报缴纳**的，**可按此执行**

**3. 棚户区改造的三项**：①**经营管理单位回购已分配的改造安置住房继续作为改造安置房源**的 →
**免征**；②⚠ **个人首次购买 90 平方米以下改造安置住房** → 按 **1%** 计征；
**购买超过 90 平方米但符合普通住房标准**的 → 按**法定税率减半**计征；
③⚠ 因房屋被征收而**取得货币补偿并用于购买改造安置住房**，
或**进行房屋产权调换并取得改造安置住房**的 → 按有关规定**减免**

**4. ⚠⚠ 企业、事业单位改制重组的九项**（自 2024-01-01 至 2027-12-31；
⚠ **符合规定但已缴纳契税的，可申请退税**）：

| # | 情形 | 处理 |
|---|---|---|
| 1 | ⚠ **企业改制**（整体改制，**原企业投资主体存续**且在改制后公司中所持股权**比例超过 75%**，且改制后公司**承继原企业权利、义务**） | ⚠ 对改制后公司承受原企业土地、房屋权属 → **免征** |
| 2 | ⚠ **事业单位改制**（原投资主体存续并在改制后企业中**出资比例超过 50%**） | 对改制后企业承受原事业单位土地、房屋权属 → **免征** |
| 3 | ⚠ **公司合并**（**原投资主体存续**） | 对合并后公司承受原合并各方权属 → **免征** |
| 4 | ⚠ **公司分立**（分立为与原公司**投资主体相同**的公司） | 对分立后公司承受原公司权属 → **免征** |
| 5 | ⚠⚠ **企业破产** | **债权人（包括破产企业职工）**承受破产企业**抵偿债务**的权属 → **免征**；<br>⚠ **非债权人**承受的：与**原企业全部职工**签订服务年限**不少于三年**的劳动用工合同的 → **免征**；与**超过 30%** 的职工签订**不少于三年**合同的 → **减半征收** |
| 6 | ⚠ **资产划转** | 承受**县级以上人民政府或国有资产管理部门**按规定进行**行政性调整、划转**国有土地、房屋权属的单位 → **免征**；<br>⚠ **同一投资主体内部**所属企业之间的划转（**母公司与其全资子公司之间、同一公司所属全资子公司之间、同一自然人与其设立的个人独资企业、一人有限公司之间**）→ **免征**；<br>⚠ **母公司以土地、房屋权属向其全资子公司增资，视同划转** → **免征** |
| 7 | ⚠ **债权转股权** | 经**国务院批准**实施债转股的企业，对**债转股后新设立的公司**承受原企业权属 → **免征** |
| 8 | ⚠⚠ **划拨用地出让或作价出资** | 以**出让方式或国家作价出资（入股）方式**承受原改制重组企业、事业单位**划拨用地**的 → ⚠ **不属于上述免税范围，对承受方应按规定征收** |
| 9 | ⚠ **公司股权（股份）转让** | 单位、个人**承受公司股权（股份）**，**公司土地、房屋权属不发生转移，不征收**契税 |

- ⚠ **三个术语的口径**：**投资主体存续** —— 企业改制重组的，指**原改制重组企业的出资人
  必须存在于改制重组后的企业**；事业单位改制的，指**履行国有资产出资人职责的单位
  必须存在于改制后的企业**；⚠ **出资人的出资比例可以发生变动**。
  **投资主体相同** —— 指**公司分立前后出资人不发生变动**，**出资比例可以发生变动**

**（七）⚠ 征管的四组要点**

- ⚠ **纳税义务发生时间**：
  - ⚠ 一般为**纳税人签订土地、房屋权属转移合同的当日**，
    或者纳税人**取得其他具有权属转移合同性质凭证的当日**
  - ⚠ 因**人民法院、仲裁委员会的生效法律文书或者监察机关出具的监察文书**等发生权属转移的 →
    为**法律文书等生效当日**
  - ⚠ 因**改变土地、房屋用途**等情形应当缴纳已经减征、免征契税的 →
    为**改变有关土地、房屋用途等情形的当日**
  - ⚠ 因**改变土地性质、容积率**等土地使用条件需补缴土地出让价款、应当缴纳契税的 →
    为**改变土地使用条件当日**
  - ⚠⚠ 发生上述情形、且**按规定不再需要办理土地、房屋权属登记**的 →
    纳税人应自**纳税义务发生之日起 90 日内**申报缴纳
- ⚠ **纳税期限**：纳税人应当在**依法办理土地、房屋权属登记手续前**申报缴纳契税
  - ⚠⚠ **退税情形**：在依法办理权属登记**前**，**权属转移合同、权属转移合同性质凭证
    不生效、无效、被撤销或者被解除**的 → 纳税人可向税务机关**申请退还已缴纳的税款**
- ⚠ **纳税地点**：契税在**土地、房屋所在地**缴纳
- ⚠ **四种可申请退税的情形**：①办理权属登记前，合同或合同性质凭证**不生效、无效、被撤销
  或被解除**的；②因**人民法院判决或仲裁委员会裁决**导致权属转移行为**无效、被撤销或被解除**，
  且**权属变更至原权利人**的；③在**出让土地使用权交付**时，因**容积率调整或实际交付面积
  小于合同约定面积需退还土地出让价款**的；④在**新建商品房交付**时，因**实际交付面积
  小于合同约定面积需返还房价款**的
- ⚠⚠ **「先税后证」**：纳税人办理土地、房屋权属登记，**不动产登记机构应当查验契税完税、
  减免税凭证或者有关信息**；⚠ **未按照规定缴纳契税的，不动产登记机构不予办理**权属登记
