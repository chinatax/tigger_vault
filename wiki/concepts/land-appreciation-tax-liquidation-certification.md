# 土地增值税清算鉴证服务

## Definition

⚠ **本页是《涉税服务实务》第六章《涉税鉴证与纳税情况审查服务》第六节「土地增值税清算鉴证服务」**
（书页 381–383 中，txt 385 末–388 中）。

> ⚠ **教材原句（业务定义）**：「**土地增值税清算鉴证**，是指鉴证人接受委托，依照税收法律法规和相关标准，
> 按照一定的程序和方法，对被鉴证人的**土地增值税清算的真实性、合法性、准确性**进行鉴定和证明，
> 并出具鉴证报告的活动」。

⚠ **三个评价维度的界定（教材原句）**：

| ⚠ 维度 | ⚠ 界定 |
|---|---|
| **真实** | **被鉴证人与清算相关的房地产项目以及土地使用权的「收入、扣除项目」客观、真实，相关资料真实、完整** |
| **合法** | **相关会计核算符合会计准则和相关会计规范；「计算土地增值税的收入总额、扣除项目金额、增值额的计算过程符合税法规定」** |
| **准确** | **「收入总额、扣除项目金额、增值额、适用税率、应缴税额、已缴税额和应补（退）税额」等金额计算准确** |

⚠ **清算业务的行为定义（教材原句）**：**「土地增值税清算是纳税人在符合土地增值税清算条件后，
依照税收法律法规及土地增值税有关政策规定，计算房地产开发项目或转让土地使用权应缴纳的土地增值税税额，
并填写「财产和行为税纳税申报表」，向主管税务机关提供有关资料，办理土地增值税清算手续，
结清该房地产项目应缴纳土地增值税税款的行为」**。

⚠ **三方界定**：**被鉴证人**是土地增值税清算的行为主体，即**纳税人**；**鉴证人**是受托提供鉴证服务的
涉税专业服务机构及人员；**鉴证事项**包括**房地产开发项目和转让土地使用权的收入、扣除项目、增值额、
应纳税额的计算**，⚠ **核心是「被鉴证人财产和行为税纳税申报表以及相关资料的审核」**。

⚠⚠ **边界（本页是「三方关系」的第三支）**：
- ⚠ **通用程序**见 [[tax-certification-basic-provisions]]；
- ⚠ **实体规则**见 [[land-appreciation-tax]]（及 [[land-appreciation-tax-deduction-items]]、
  [[land-appreciation-tax-liquidation]]、[[land-appreciation-tax-computation]]）；
- ⚠ **第三章的「纳税审核」视角**见 [[land-appreciation-tax-audit]]；
- ⚠ **第五章的「申报代办」视角**见 [[land-appreciation-tax-filing-judgment]]（**其（二）的关注事项与本页同源**）；
- ⚠⚠ **即：土增清算在本库现同时拥有「实体规则」「第三章审核」「第五章申报」「第六章鉴证」四支**——
  **四者并存互指、不合并**。

## Key Points

### 一、⚠⚠ 「关注事项」（**四项 + 鉴证方法**）

| # | ⚠ 关注项 | ⚠ 内容（**教材原句要点**） |
|---|---|---|
| **（一）** | **清算项目是否真实、合法、准确** | **清算项目及其范围是否客观、真实；不同期间、不同项目「收入确认、成本归集」是否符合会计和税法规定；「普通住宅、非普通住宅的划分」是否合理；「清算起止时间」是否符合税法规定；有免税项目的，「与征税项目划分是否清晰准确」** |
| **（二）** | ⚠⚠ **收入总额是否真实、合法、准确** | **清算收入确认是否客观真实、是否符合税法规定**；⚠ **按清算项目设立的「预售收入备查簿」记载的「项目合同签订日期、交付使用日期、预售款确认收入日期、收入金额」等是否准确**；**销售退回、销售折扣与折让业务是否真实发生、内容完整手续合法、金额计算与会计处理是否正确；与关联方的销售折扣与折让是否合理**；**以土地使用权投资开发的项目是否按规定进行税务处理；按揭款收入是否申报纳税、有无挂在往来账不作销售收入申报**；**以房地产换取土地使用权，在房地产移交使用时是否视同销售不动产申报缴纳税款**；**采用「还本」方式销售商品房和以房产补偿给拆迁户时是否按规定申报纳税**；⚠ **「经有关部门实际测量的销售面积与合同约定的销售面积不符，除在销（预）售合同约定的误差范围内不作退补款外，其他发生退补款情形而导致收入变化的，是否按照税法规定处理」**；**应退款而不退款、抵顶物业管理费的，税务处理是否符合税法规定**；⚠ **非直接销售和自用房地产的收入确认是否合法准确**（**开发产品用于职工福利、奖励、对外投资、分配给股东或投资人、抵偿债务、换取其他单位和个人的非货币性资产等**） |
| **（三）** | ⚠⚠ **扣除项目金额是否真实、合法、准确**（**本目最大**） | **① 该清算扣除项目金额与收入总额是否「配比」；② 所归集的各项成本和费用是否「实际发生」；③ 实际发生的支出是否取得「合法凭据」；④ 扣除项目金额是否在各扣除项目中「准确归集」；⑤ 分期开发或同时开发多个项目、或同一项目中建造不同类型房地产的，是否按「受益对象合理分摊」共同的成本费用** |
| **（四）** | **应纳税额计算是否合法准确** | **关注「收入总额、扣除项目金额、增值率」计算是否准确；⚠「对于多个项目同时建设、预售（销售）的，是否准确划分计算清算项目的预缴税额」** |

#### ⚠⚠ （三）项下的「九项专项关注」（**教材逐项列出，与第五章申报页同一清单**）

| # | ⚠ 项目 | ⚠ 关注要点（**教材原句**） |
|---|---|---|
| **1** | **取得土地使用权支付金额** | **同一宗土地有多个开发项目或分期分批开发的，其「分摊方法是否合理、金额计算是否准确」；是否将房地产开发销售费用、管理费用、财务费用记入；是否与市场价格存在明显差异；⚠「土地闲置费等不得扣除项目是否已经剔除」** |
| **2** | **土地征用及拆迁补偿费** | **实际支出金额与概（预）算是否存在明显差异；拆迁补偿费是否实际发生；「由政府或者他人承担已征用和拆迁好的土地等相关扣除项目是否符合税法规定」** |
| **3** | ⚠ **前期工程费、基础设施费** | **实际支出额与概（预）算是否存在「明显异常」，是否存在「虚列」情形；是否将开发项目的销售费用·管理费用·财务费用记入；多个（或分期）项目共同发生的，是否按项目合理分摊** |
| **4** | ⚠ **建筑安装工程费** | **是否与「决算报告、审计报告、工程结算报告、工程施工合同」记载的内容相符；「自购建材费用是否重复扣除」；单位定额成本是否存在异常；自行施工建设有无「虚列、多列施工人工费·材料费·机械使用费」等情况；⚠「是否取得项目所在地税务机关监制的建筑安装发票」** |
| **5** | **公共配套设施费** | **界定是否准确、产权是否明确、是否真实发生、有无预提；是否将销售费用·管理费用·财务费用记入；多个（或分期）项目共同发生的是否按项目合理分摊；是否含有其他企业的费用** |
| **6** | **开发间接费用** | ⚠ **「是否将企业行政管理部门（总部）为组织和管理生产经营活动而发生的管理费用记入开发间接费用」**；是否真实发生、凭证是否合法有效；多个开发项目是否分项目核算或分摊；是否含有其他企业的费用；有无预提 |
| **7** | ⚠ **利息支出** | **据实申报时是否将利息支出「从开发成本中调整至开发费用」；分期或同时开发多个项目的一般性贷款利息支出是否「按项目合理分摊」；「利用闲置专项借款对外投资取得的收益是否冲减利息支出」；借款合同相应条款是否符合规定；是否超过按「商业银行同类同期贷款利率」计算的金额；「超过贷款期限和挪用贷款的罚息」是否扣除；是否剔除「借款手续费、咨询费、顾问费等利息支出以外的费用」；⚠「对不能按转让房地产项目计算分摊利息支出或不能提供金融机构证明的，计提利息是否符合税法规定」** |
| **8** | **与转让房地产有关的税金** | **扣除范围和金额计算是否符合税法有关规定、是否与收入相关·配比、企业是否缴纳；是否扣除「不属于清算范围、不属于转让环节发生」的税金；「印花税扣除是否符合规定」** |
| **9** | **加计扣除项目** | ⚠ **三项「不得加计」的情形（取得后未进行任何形式的开发即转让的土地使用权；取得后仅进行土地开发未建造房屋即转让的土地使用权；取得后未进行任何实质性改良或开发即再行转让的房地产产权）其扣除项目金额是否符合税法规定；是否「将代收费用作为加计扣除的基数」；是否「将已计入开发成本的利息支出计入加计扣除的基数」** |

#### ⚠ 「应纳税额计算」的鉴证方法（教材以「收入与扣除项目金额」为例列出一组方法）

**获取或编制「房地产转让收入、扣除项目明细表」，并与会计资料、税务资料核对；
了解清算项目有关的「销售合同执行、商品房销售发票开具、有关部门实际测绘」等情况；
审核「销售明细表、房地产销售面积与项目可售面积的数据关联性」，以核实应计入增值额的收入；
查明收入的确认原则、方法，注意「会计规定与税法规定以及不同税种在收入确认上的差异」；
正确划分「预售收入与销售收入」，防止影响清算数据的准确性；
利用「有资质的专业机构对销售价格进行评估」，判断有无价格明显偏低情况；
审核清算项目的收入总额，可通过「实地查验」，确认有无少计、漏计收入事项；
销售合同所载商品房面积与有关部门实际测量面积不一致、在清算前已发生补退房款的，是否在计算
土地增值税时予以调整；取得相关合同和项目概（预）算资料并审核其执行情况和成本·费用支出情况；
实地查看、询问调查和核实，「剔除不属于清算项目所发生的开发成本和费用」**。

### 二、⚠⚠ 鉴证证据（**三类，各分「事实/会计/税收」三层**）

| ⚠ 类别 | ⚠ 证据（**教材原句要点**） |
|---|---|
| **鉴证项目有关材料** | **房地产开发项目「立项、用地、规划设计、开发、施工、销售、关联方交易、融资、竣工验收、工程结算、税款缴纳」等相关材料** |
| ⚠ **收入总额** | **事实方面**：**商品房购销合同统计表、销售发票、销售合同（含房管部门网上备案登记资料）、商品房销售（预售）许可证、房产销售分户明细表、捐赠合同、投资合同、企业管理当局批件或者决议、外部批文**等；**会计方面**：**总分类账、明细分类账、会计分录以及对财务报表予以调整或抵销但未在账簿中反映的其他分录、银行进账单**等；**税收方面**：**销售明细表、房地产销售面积与项目可售面积的数据证据及三者关联性分析的自制资料，销售合同所载商品房面积与有关部门实际测量面积数据资料，发生补·退房款的收入调整情况资料；对销售价格进行评估并判断有无价格明显偏低情况形成的资料** |
| ⚠ **扣除项目金额** | **事实方面**：**成本合同统计表，土地合同、拆迁补偿项目所需的拆迁合同和补偿费签收花名册、工程建造合同、竣工结算报告，公共配套设施建成后产权属于全体业主所有或者建成后无偿移交给政府·公用事业单位用于非营利性社会公共事业的相关证明资料，借款合同及借款利息结算通知单**；**会计方面**：**总分类账、明细分类账、会计凭证以及对财务报表予以调整或抵销但未在账簿中反映的其他会计分录**等信息和资料；**增值税发票或财政票据、银行结算凭证、缴税付款凭证**等信息和资料；⚠ **分期开发项目或同时开发多个项目、或同一项目中建造不同类型房地产的，按「受益对象、分摊共同成本费用」的合理分配方法说明** |

### 三、鉴证报告

⚠ **发表结论时应关注**：**被鉴证人的土地增值税清算的真实性、合法性，以及作出上述判断的证据是否
确实充分，适用法律依据是否准确**；
⚠ **「应以工作底稿为基础，按照《涉税鉴证业务指引（试行）》要求的内容，编制土地增值税清算鉴证报告」**
——**「报告的核心是对被鉴证人「土地增值税清算结果」予以评价」**；**报告应按要求进行信息沟通、签字盖章**。
