# 企业所得税税前扣除凭证

## Definition

企业所得税税前扣除凭证（Pre-tax Deduction Vouchers）：企业（居民企业和非居民企业）在计算应纳税所得额时，**证明与取得收入有关的、合理的支出实际发生**，并据以税前扣除的各类凭证。

依据《企业所得税税前扣除凭证管理办法》（国家税务总局公告 2018 年第 28 号），自 **2018-07-01** 起执行。它的核心是「**凭什么扣**」——支出要扣除，必须先有合规的凭证。

## Key Points

- **三性原则**（凭证管理的总纲）：
  - **真实性**：凭证反映的经济业务真实，且**支出已经实际发生**
  - **合法性**：凭证的**形式、来源**符合国家法律法规等相关规定
  - **关联性**：凭证与其反映的支出**相关联且有证明力**
- **取得时限**：企业应在**当年度企业所得税法规定的汇算清缴期结束前**取得税前扣除凭证
- **留存备查资料**：与凭证相关的**合同协议、支出依据、付款凭证**等应留存备查，以证实凭证的真实性
  - ⚠ 这类资料**不属于**税前扣除凭证，但属于**能证明凭证真实性**的资料，仍应履行保管责任
- **内部凭证与外部凭证**：
  - **内部凭证**：企业**自制**用于成本、费用、损失和其他支出核算的**会计原始凭证**；
    其填制和使用应符合国家会计法律法规
  - **外部凭证**：企业从**其他单位、个人**取得的、用于证明其支出发生的凭证，包括但不限于
    **发票（纸质与电子）、财政票据、完税凭证、收款凭证、分割单**等
- **境内支出的凭证规则**（按是否属增值税应税项目分流）：

  | 情形 | 应取得的凭证 |
  |---|---|
  | **应税项目**，对方为**已办理税务登记**的增值税纳税人 | **发票**（含按规定由税务机关代开的发票） |
  | **应税项目**，对方为**依法无须办理税务登记**的单位，或从事**小额零星经营业务**的个人 | 税务机关代开的**发票**，**或**收款凭证**及内部凭证**<br>⚠ 收款凭证应载明收款单位名称、**个人姓名及身份证号**、支出项目、收款金额等信息 |
  | **非应税项目**，对方为**单位** | 对方开具的**发票以外**的其他外部凭证 |
  | **非应税项目**，对方为**个人** | **内部凭证** |

  - ⚠ **小额零星经营业务**的判断标准：个人从事应税项目经营业务的销售额**不超过增值税相关政策规定的起征点**
  - 非应税项目虽不属于应税项目，但**按国家税务总局规定可以开具发票**的 → **可以发票**作为扣除凭证
  - 从**境外**购进货物或劳务发生的支出 → 以对方开具的**发票或具有发票性质的收款凭证、相关税费缴纳凭证**
- **不合规凭证的处理**：
  - **不合规发票**指：私自印制、伪造、变造、作废、开票方非法取得、虚开、填写不规范等
  - ⚠ 不合规发票与不合规其他外部凭证**不得**作为税前扣除凭证
  - 应当取得而未取得、或取得不合规凭证的，若**支出真实且已实际发生**，应在**当年度汇算清缴期结束前**
    要求对方**补开、换开**；补换开后符合规定的可以扣除
- **因对方特殊原因无法补开、换开**（对方注销、撤销、依法被吊销营业执照、被税务机关认定为非正常户等）
  时，可凭以下资料证实支出真实性后扣除：

  | # | 资料 | 是否必备 |
  |---|---|---|
  | ① | 无法补换开原因的证明资料（市场主体注销、机构撤销、列入非正常经营户、破产公告等） | ⚠ **必备** |
  | ② | 相关业务活动的**合同或者协议** | ⚠ **必备** |
  | ③ | 采用**非现金方式支付**的付款凭证 | ⚠ **必备** |
  | ④ | 货物运输的证明资料 | —— |
  | ⑤ | 货物**入库、出库内部凭证** | —— |
  | ⑥ | 企业会计核算记录及其他资料 | —— |

- **时限的两个关键数字**：
  - **汇算清缴期结束后**，税务机关发现并告知企业的 → 企业应自**被告知之日起 60 日内**补开、换开
    （因对方特殊原因无法补换开的，同样在 60 日内提供上述资料）
  - ⚠ **逾期未补换开且未提供资料的** → 相应支出**既不得在发生年度税前扣除，
    也不得在以后年度追补扣除**
  - **追补扣除 5 年**：除上述情形外，以前年度应取得而未取得、且该年度**主动没有**税前扣除的支出，
    在以后年度取得合规凭证后可**追补至该支出发生年度**扣除，
    ⚠ 追补年限**不得超过 5 年**（前提是企业在该支出发生年度**主动没有**进行税前扣除）
- **共同接受劳务的分摊**：
  - 共同接受**应纳增值税劳务**（应税劳务）采取分摊方式的，应**按独立交易原则分摊**：
    本企业以**发票和分割单**为扣除凭证；**其他**共同接受应税劳务的企业以本企业**开具的分割单**为凭证
  - 共同接受**非应税劳务**采取分摊方式的：本企业以**发票外的其他外部凭证和分割单**为凭证；
    其他企业以本企业**开具的分割单**为凭证
  - ⚠ **母公司的辅助生产车间为各下属子公司提供辅助生产服务不属于共同接受劳务**：
    属应税项目的，子公司应以母公司开具的**发票**为扣除凭证；不属增值税项目的，
    应以母公司开具的**发票以外的其他外部凭证**为凭证
- **租用资产的水电等费用**：企业租用（含作为**单一承租方**租用）办公、生产用房等资产发生的
  **水、电、燃气、冷气、暖气、通讯线路、有线电视、网络**等费用 ——
  出租方作为应税项目**开具发票**的，以**发票**为凭证；出租方采取**分摊方式**的，
  以出租方开具的**其他外部凭证**为凭证
- **「劳务」的口径**：《企业所得税税前扣除凭证管理办法》所称「劳务」是**相对宽泛**的概念，
  原则上包含**所有劳务服务活动**，**不能等同于**增值税相关规定中的「销售服务等」
- **与相关概念的衔接**：扣除项目的范围与限额见 [[corporate-income-tax-deduction-limits]]；
  「以前年度应扣未扣支出」的追补规则见 [[tax-loss-carryforward]]

#### ⚠⚠ 补记（2026-10-09）：**「凭证不实」的两种典型情形与后果**

> ⚠ **来源**：[[one-person-company-tax-case-study]]（《中国税务报》税案研究，2026-05-15，
> 风险提示三）。⚠ **该件案例为文章自设示例，非真实案例**。

- ⚠ **情形一：个人消费包装成公司经营支出**——
  **将个人家庭旅游、奢侈品消费、吃穿娱乐等发票，以「差旅费」「业务招待费」「办公用品」
  等名义计入公司成本**；⚠⚠ **后果：相关支出不得在企业所得税税前扣除**。
- ⚠⚠ **情形二：购买虚开发票列支**——
  **通过非法渠道购买虚开的「咨询服务费」「办公费」「加油票」等发票，
  用于抵扣增值税进项税额并在企业所得税税前扣除**；
  ⚠ 其依据为 **《发票管理办法》第二十一条、第二十二条**——
  **不得让他人为自己开具与实际经营业务情况不符的发票**。
- ⚠⚠ **后果的层级**：**不仅违反发票管理法规、构成偷税，
  情节严重的还将触犯刑法中的虚开增值税专用发票罪或逃税罪**
  （⚠ **罪名细则见 [[invoice-crimes]]**）；⚠ **税务机关将依法追缴增值税、
  企业所得税及滞纳金，并处以罚款**。
- ⚠ **合规要求**：**确保货物流（或服务流）、资金流、发票流和合同流「四流一致」**；
  **大额支出应保留合同、验收单、物流单据等佐证材料备查**。
- ⚠ **与本节的关系**：⚠ **本节原有内容讲「什么样的凭证可以扣除」**，
  **本补记讲「凭证不实的两种典型情形及其后果」**——⚠ **两者互补，不可互相替代**。
