# 税款征收措施

## Definition

**税款征收的措施**，是指**税务机关为保障税款得以征收而采取的各项手段的总称**——
⚠ **教材在「二、税款征收的措施」下列出「八项」**：
**核定应纳税额、关联企业纳税调整、欠税公告、税收保全、强制执行、税款优先、信息报告、
代位权和撤销权**。

⚠⚠ **本页英文 slug 的说明（2026-09-24 经用户裁定）**：
**教材原标题为「税款征收的措施」，若径直译作 `tax-collection-measures`，
将与本节另一页 `tax-collection-methods`（税款征收方式）「仅一词之差」、检索极易拿错**——
⚠ **故本页取 `tax-collection-guarantee-measures`（「保障税款征收的措施」），
⚠ 既避开近形、又更准确地反映本页八项手段的共性（保全·强制执行·优先·代位权等
本质上都是「保障税款得以征收」）**；⚠ **代价是与教材原标题略异，⚠ 已在 aliases 保留中文原名。**

⚠ **边界**：
- ⚠ **税款征收的「方式」（七种）**见 [[tax-collection-methods]]；
- ⚠ **「追征期」与「多缴税款退还」不在本节**——⚠ 它们是**纳税人权利**，
  ⚠⚠ **教材把它们放在第五节**（**书页 87「追征税款权」、书页 89「申请退还多缴税款权」**）；
- **本章总纲与入口指针**见 [[tax-collection-and-administration]]。

⚠ **本页承载教材第二章第三节的「二、税款征收的措施」（八项）**
（**书页 82 上–85 中／txt 87 上–90 中**，约 3 页）。

## Key Points

### 一、（一）核定应纳税额

#### 1. ⚠ 税务机关「有权核定」的六种情形（**须记全**）

| # | ⚠ 情形 |
|---|---|
| **①** | **依照法律、行政法规的规定「可以不设置账簿」的** |
| **②** | **依照法律、行政法规的规定「应当设置但未设置账簿」的** |
| **③** | ⚠ **「擅自销毁账簿」或者「拒不提供纳税资料」的** |
| **④** | ⚠ **虽设置账簿，但「账目混乱」或者「成本资料、收入凭证、费用凭证残缺不全，难以查账」的** |
| **⑤** | ⚠ **发生纳税义务，「未按照规定的期限办理纳税申报」，经税务机关责令限期申报，「逾期仍不申报」的** |
| **⑥** | ⚠⚠ **「纳税人申报的计税依据明显偏低，又无正当理由」的** |

#### 2. ⚠⚠ 对「未办理税务登记的纳税人及临时从事经营的纳税人」的特别程序（**四步**）

⚠ **适用对象**：**「未按照规定办理税务登记的从事生产、经营的纳税人以及临时从事经营的纳税人」**。

> **① 由税务机关「核定其应纳税额」，「责令缴纳」**
> → ⚠ **② 不缴纳的，税务机关可以「扣押其价值相当于应纳税款的商品、货物」**
> → ⚠ **③ 扣押后缴纳应纳税款的，税务机关「必须立即解除扣押，并归还」所扣押的商品、货物**
> → ⚠⚠ **④ 扣押后仍不缴纳的，「经县以上税务局（分局）局长批准，依法拍卖或者变卖」
> 所扣押的商品、货物，「以拍卖或者变卖所得抵缴税款」**

⚠ **注意与（四）税收保全的分界**：**本项的「扣押」以「未办税务登记」为触发，
不另需「逃税嫌疑」的前提**——⚠⚠ **但在「批准层级」上与税收保全一致（县以上局长批准）。**

### 二、（二）关联企业纳税调整

> ⚠ **「纳税人与关联企业业务往来时，应当按照「独立企业之间的业务往来」收取或者支付价款、费用；
> 不按照独立企业之间的业务往来收取或者支付价款、费用，而「减少其应纳税的收入或者所得额」的，
> 税务机关「有权进行合理调整」。」**

⚠ **三个要件**：**① 主体是「关联企业」；② 违背「独立企业之间的业务往来」原则；
③ 后果是「减少其应纳税的收入或者所得额」。**

> ⚠ **与库内相关页的衔接**：**特别纳税调整的「实体规则」**
> （**转让定价方法、成本分摊协议、预约定价安排、资本弱化、受控外国企业**）
> 见 [[special-tax-adjustment]] 及其相关页；**一般反避税**见 [[general-anti-avoidance-rule]]。
> ⚠ **本页只承载征管法层面的这一条概括性规定**，⚠ **不重复实体规则。**

### 三、⚠⚠ （三）欠税公告（**本页条目最密的一目**）

#### （〇）目的与公告机关

⚠ **目的（五句）**：**规范税务机关的欠税公告行为，保护纳税人的合法权益，
督促纳税人自觉缴纳欠税，防止新的欠税的发生，保证国家税款及时足额入库。**

⚠ **适用前提**：**对于纳税人「超过税收法律、行政法规规定的期限」或者
「纳税人超过税务机关依照税收法律、行政法规规定确定的纳税期限」未缴纳的税款**。

⚠⚠ **公告机关：「县级以上税务局（分局）」。**

#### 1. 欠税公告范围

⚠ **一项「一并公告」与一项「更新」**：
- ⚠ **税务机关对纳税人的欠税及税款滞纳金数额应当「及时核实」，「已缴纳欠税对应形成的
  欠缴税款滞纳金一并公告」**；
- ⚠ **纳税人已缴清公告所列税款、税款滞纳金，或者因登记信息变更等导致欠税公告内容发生变化的，
  公告机关于「次月」发布欠税公告时「更新相关内容」。**

⚠⚠ **范围（五项，共性是「未在税款缴纳期限内缴纳」）**：
1. **办理纳税申报后，纳税人未在税款缴纳期限内缴纳的税款**；
2. **经批准延期缴纳的税款期限已满，纳税人未在税款缴纳期限内缴纳的税款**；
3. **税务检查已查定纳税人的应补税额，纳税人未在税款缴纳期限内缴纳的税款**；
4. **税务机关核定纳税人的应纳税额，纳税人未在税款缴纳期限内缴纳的税款**；
5. **纳税人的其他未在税款缴纳期限内缴纳的税款**（**兜底**）。

#### 2. 欠税公告内容（**按主体三类，项目各有增减**）

| 主体 | ⚠ 公告项目 |
|---|---|
| ⚠ **企业或者单位** | **名称、纳税人识别号、「法定代表人或者负责人姓名」、证件类型、证件号码、经营地点、欠缴税费种、欠税所属期、欠税金额、已缴纳欠税对应形成的欠缴税款滞纳金金额、欠缴日期、公告机关** |
| ⚠ **个体工商户** | **个体工商户名称、「经营者姓名」、纳税人识别号、证件类型、证件号码、经营地点、欠缴税费种、欠税所属期、欠税金额、已缴纳欠税对应形成的欠缴税款滞纳金金额、欠缴日期、公告机关** |
| ⚠⚠ **个人（不含个体工商户）** | ⚠ **姓名、证件类型、证件号码**（⚠ **无纳税人识别号、无经营地点**）、**欠缴税费种、欠税所属期、欠税金额、已缴纳欠税对应形成的欠缴税款滞纳金金额、欠缴日期、公告机关** |

> ⚠⚠ **三类的差异在「名称/姓名」与「纳税人识别号、经营地点」两项上**——
> ⚠ **个人（非个体户）因无登记信息，故不公告识别号与经营地点**，
> ⚠⚠ **这是本项唯一的「分类逻辑」，记住即可不再逐项背。**

#### 3. ⚠⚠ 欠税公告确认（**四个期限，须分清 3 与 5**）

| 环节 | ⚠ 期限 |
|---|---|
| ⚠ **公告前的确认** | **公告机关应当在公告前将拟公告内容推送至纳税人进行确认，纳税人应当在「3 个工作日内」予以确认** |
| ⚠ **纳税人的异议（公告前）** | **纳税人认为拟公告内容存在「信息录入、计算错误」的，可以在「3 个工作日内」向公告机关提出异议处理，并提供有关证明材料** |
| ⚠ **公告机关的核实（公告前）** | **公告机关「自收到异议之日起 3 个工作日内」核实并反馈；异议成立的，及时更正** |
| ⚠ **予以公告的条件** | **纳税人在期限内确认、「逾期未确认」或者异议处理完成的，公告机关按规定予以公告** |
| ⚠⚠ **公告「发布后」的异议** | ⚠ **纳税人认为欠税公告内容与其实际情况不符，或者「欠税公告程序违法」的，可以「书面」向公告机关提出异议，并提供有关证明材料**；⚠⚠ **公告机关「自收到异议之日起「5 个工作日内」」核实（核实对象为「欠税数据来源、公告流程」）并反馈；异议成立的，及时更正** |

> ⚠⚠ **「3 个工作日」与「5 个工作日」的分界（易考）**：
> **公告「前」的确认与异议 → 3 个工作日；公告「后」的异议 → 5 个工作日。**

#### 4. 欠税公告方式

- ⚠ **公告机关应当「按月」在「行政执法信息公示平台」公告纳税人的欠税情况**；
- ⚠ **根据需要，可以在「电子税务局、办税场所、新闻媒体」等渠道公告**；
- ⚠ **各省（自治区、直辖市、计划单列市）税务机关在官方网站提供其管辖范围内的
  「欠税公告查询服务」**；
- ⚠⚠ **「视情节轻重，省级以上税务机关可以对部分纳税人欠税情况予以「曝光」。」**

#### 5. ⚠ 不予公告的情形（**四项，前三项均与破产相关**）

| # | ⚠ 情形 |
|---|---|
| **（1）** | ⚠ **破产程序中，税务机关「依法受偿但尚未入库」的税款、税款滞纳金** |
| **（2）** | ⚠ **已宣告破产、解散或者依法被吊销营业执照、责令关闭、被撤销的，「经法定清算后，被依法注销其法人资格企业」的税款、税款滞纳金** |
| **（3）** | ⚠⚠ **破产重整、和解程序中，税务机关在依法受偿后，「依据重整计划或者和解协议未获清偿」的税款、税款滞纳金** |
| **（4）** | ⚠ **欠税情况涉及「国家秘密」等其他不宜公告的情形，「经省级税务机关批准」，不予公告** |

> ⚠⚠ **第（3）项与库内破产法侧的口径一致**：**「重整、和解中未受偿的部分不影响信用修复与迁移注销」**
> （⚠ 见 [[tax-collection-and-administration]] 的「旧记全文」节之九，
> ⚠ **该块来源于《税法（二）》教材，归属待判定**）。

### 四、（四）税收保全

#### 1. ⚠ 触发链条（**三步**）

> ⚠ **① 税务机关「有根据认为」从事生产、经营的纳税人有「逃避纳税义务行为」的，
> 可以在「规定的纳税期前」责令纳税人「限期缴纳」应纳税额**
> → ⚠ **② 在限期内发现纳税人有明显的「转移、隐匿其应纳税商品、货物以及其他财产或者应纳税收入」
> 的迹象的，税务机关「可责成纳税人提供纳税担保」**
> → ⚠⚠ **③ 税务机关责令纳税人提供纳税担保而纳税人「拒绝提供纳税担保或无力提供纳税担保」的，
> 「经县以上税务局（分局）局长批准」，税务机关可以采取税收保全措施**

#### 2. ⚠ 两项税收保全措施

1. ⚠ **「书面通知纳税人开户银行或者其他金融机构「冻结」纳税人的金额相当于应纳税款的「存款」」**；
2. ⚠ **「「扣押、查封」纳税人的价值相当于应纳税款的商品、货物或者其他财产」**。

⚠⚠ **两种处置后果**：
- ⚠ **纳税人在规定的限期内缴纳税款的，「税务机关必须立即解除税收保全措施」**；
- ⚠⚠ **限期期满仍未缴纳的，「经县以上税务局（分局）局长批准」**，税务机关可以：
  **① 书面通知其开户银行或者其他金融机构「从其冻结的存款中扣缴税款」；
  ② 或者「依法拍卖或者变卖」所扣押、查封的商品、货物或者其他财产，「以拍卖或者变卖所得抵缴税款」。**

#### 3. ⚠⚠ 「不在范围内」的财产（**三个层次的界定，很易考**）

⚠ **总规则**：**「个人及其所扶养家属维持生活必需的住房和用品，不在税收保全措施的范围之内。」**

| 层次 | ⚠ 内容 |
|---|---|
| ⚠ **「个人所扶养家属」的定义** | **「与纳税人共同居住生活的配偶、直系亲属以及无生活来源并由纳税人扶养的其他亲属」** |
| ⚠⚠ **「维持生活必需的住房和用品」「不包括」的四类** | ⚠ **机动车辆、金银饰品、古玩字画、豪华住宅或者「一处以外的住房」** |
| ⚠⚠ **一个数额门槛** | ⚠⚠ **「税务机关对「单价 50 元以下」的其他生活用品，不采取税收保全措施和强制执行措施」**（⚠⚠ **该数额与题库旧记不符；⚠⚠ 行政法规原文（[[national-tax-collection-administration-implementing-rules]] 第 59 条）作「5000 元」，与旧记一致——见 Contradictions 节二**） |

### 五、⚠⚠ （五）强制执行（**含「阻止出境」**）

#### 1. 阻止出境（**本目下的第一项，非「强制执行措施」本身**）

> ⚠ **「欠缴税款的纳税人或者其法定代表人，在出境前未按照规定「结清应纳税款、滞纳金
> 或者提供纳税担保」的，税务机关可以通知出入境管理机关「阻止其出境」。」**

- ⚠ **适用对象（两类）**：**欠缴税款的「纳税人」或者「其法定代表人」**；
- ⚠ **前提（三选一未满足）**：**结清应纳税款 / 结清滞纳金 / 提供纳税担保**；
- ⚠⚠ **一项操作细节**：**「阻止出境包括「布控、撤控」。」**

#### 2. ⚠ 强制执行措施（**两项措施 + 三个细节**）

⚠ **适用对象与前提**：
> **「从事生产、经营的纳税人、扣缴义务人未按照规定的期限缴纳或者解缴税款，
> 「纳税担保人」未按照规定的期限缴纳所担保的税款，由税务机关「责令限期缴纳」，
> 「逾期仍未缴纳」的，「经县以上税务局（分局）局长批准」，
> 税务机关可以采取下列强制执行措施。」**

⚠ **两项措施**：
1. ⚠ **「书面通知其开户银行或者其他金融机构「从其存款中扣缴税款」」**；
2. ⚠ **「「扣押、查封、依法拍卖或者变卖」其价值相当于应纳税款的商品、货物或者其他财产，
   「以拍卖或者变卖所得抵缴税款」」**。

⚠⚠ **三个细节（须记全）**：
- ⚠⚠ **「税务机关采取强制执行措施时，对上述所列的纳税人、扣缴义务人、纳税担保人
  「未缴纳的滞纳金同时强制执行」。」**
- ⚠ **「个人及其所扶养家属维持生活必需的住房和用品，不在强制执行措施的范围之内。」**
- ⚠⚠ **一处「社保费」的特别规定**：**「用人单位未足额缴纳社会保险费且未提供担保的，
  「社会保险费征收机构」可以「申请人民法院」扣押、查封、拍卖其价值相当于应当缴纳社会保险费的财产，
  以拍卖所得抵缴社会保险费。」**（⚠ **注意：此处是「申请法院」，不是税务机关自行扣押**）

#### ⚠⚠ 3. 「税收保全 vs 强制执行」的四维对照（**本页最核心的一组对比**）

| 维度 | ⚠ 税收保全（**预防**） | ⚠ 强制执行（**补救**） |
|---|---|---|
| ⚠ **对象** | ⚠ **从事生产、经营的纳税人**（⚠ **不含扣缴义务人、纳税担保人**） | ⚠⚠ **从事生产、经营的纳税人、「扣缴义务人、「纳税担保人」** |
| ⚠ **前提** | ⚠ **有逃税嫌疑**，责令限期缴纳 → **发现转移隐匿迹象** → **拒绝或无力提供纳税担保** | ⚠⚠ **「告诫在先」**：**责令限期缴纳，逾期仍未缴纳** |
| ⚠ **措施** | **冻结存款**；**扣押、查封**（⚠ **不含拍卖变卖**） | ⚠ **从存款中扣缴税款**；**扣押、查封、依法拍卖或者变卖** |
| ⚠ **审批** | **县以上税务局（分局）局长** | **县以上税务局（分局）局长** |

> ⚠⚠ **两组差异的判据**：
> - ⚠ **对象差异**：**保全针对「还没确定要收的钱」，故只限纳税人本体；
>   强制执行针对「已经确定要收的钱」，故扩及扣缴义务人与纳税担保人**；
> - ⚠ **前提差异**：**保全讲「嫌疑 + 迹象 + 不担保」；强制执行讲「告诫在先」**。

### 六、（六）税款优先

⚠⚠ **三层优先规则（须记全，各有条件）**：

| # | ⚠ 规则 | ⚠ 条件 |
|---|---|---|
| **1** | **税收「优先于无担保债权」** | ⚠ **「法律另有规定的除外」** |
| **2** | ⚠⚠ **税收「先于抵押权、质权、留置权执行」** | ⚠⚠ **前提：「纳税人欠缴的税款发生在纳税人以其财产设定抵押、质押或者纳税人的财产被留置「之前」」**（⚠ **即「欠税在先、担保在后」**） |
| **3** | ⚠ **税收「优先于罚款、没收违法所得」** | **前提：纳税人欠缴税款，「同时」又被行政机关决定处以罚款、没收违法所得** |

⚠ **两项配套义务**：
- ⚠ **「税务机关应当对纳税人欠缴税款的情况「定期予以公告」。」**（⚠ **与（三）欠税公告呼应**）；
- ⚠⚠ **「纳税人有欠税情形而以其财产设定抵押、质押的，「应当向抵押权人、质权人说明其欠税情况」。
  「抵押权人、质权人可以请求税务机关提供有关的欠税情况」。」**
