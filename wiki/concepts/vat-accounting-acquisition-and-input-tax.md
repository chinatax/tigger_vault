# 增值税会计核算：取得资产或接受劳务

## Key Points

### ⚠ 一、「1. 外购货物的核算」——两条路（**按价税合计 vs 按价税分别**）

#### （1）⚠⚠ 「按价税合计记账」的情况（**即进项税额不得抵扣**）

> ⚠⚠ **依《增值税法》第二十二条，「自 2026 年 1 月 1 日起」，纳税人的下列进项税额
> 不得从其销项税额中抵扣**：
> **① 适用「简易计税方法计税项目」对应的进项税额；② 「免征增值税项目」对应的进项税额；
> ③ 「非正常损失项目」对应的进项税额；④ 购进并用于「「集体福利或者个人消费」」的货物、服务、
> 无形资产、不动产对应的进项税额；⑤ 购进并直接用于消费的「「餐饮服务、居民日常服务和娱乐服务」」
> 对应的进项税额；⑥ 「国务院规定的其他」进项税额。**

⚠ **两句配套**：**「纳税人应当凭「「法律、行政法规或者国务院规定的增值税扣税凭证」」
从销项税额中抵扣进项税额」**；⚠ **「此外，「「小规模纳税人」」外购货物或者服务所支付的增值税，
不得抵扣其应纳税额」**。
⚠⚠ **账务后果**：**「对于发生上述事项的外购业务，纳税人所支付的增值税额「「不能在
『应交税费——应交增值税（进项税额）』专栏中核算」」，而是仍按原来会计处理办法核算，
即「「将此增值税额并入外购货物或者服务成本之中」」」**。

⚠ **教材「例 4-1」**：**A 企业外购游艇 5 艘「用于接待客户和职工疗养娱乐用」**——
⚠ **因属「集体福利或个人消费」，其进项税额不得抵扣，故全额计入「固定资产」成本**
（**价款、增值税金与运输费的**具体金额在 OCR 中受损，见 Contradictions 三**）**。

#### （2）⚠⚠ 「按价税分别记账」的情况（**即可抵扣**）

> **「根据税法规定，目前准予抵扣销项税额的扣税凭证，其所列明的税额或计算出来的税额，
> 「「不列入外购货物或应税劳务成本之中」」，而应记入当期『应交税费——应交增值税（进项税额）』
> 专栏，即在账务上要「「按价税分别记账」」，「「这也是增值税作为价外税的最直接体现」」。」**

⚠⚠ **八类具体业务的账务处理（**教材逐一给出，本页按「借方科目 + 关键点」成表**）**：

| # | ⚠ 业务 | ⚠ 账务要点（**教材原句要点**） |
|---|---|---|
| **①** | ⚠ **采购等业务进项税额「允许抵扣」** | **「按应计入相关成本费用或资产的金额，借记『在途物资』或『原材料』『库存商品』『生产成本』『无形资产』『固定资产』『管理费用』等科目，按「「当月已认证」」的可抵扣增值税额，借记『应交税费——应交增值税（进项税额）』科目，按「「当月未认证」」的可抵扣增值税额，借记『应交税费——待认证进项税额』科目，按应付或实际支付的金额，贷记『应付账款』『应付票据』『银行存款』等科目」**；⚠⚠ **退货的处理（**二分**）**：**「如原增值税专用发票「「已作认证」」，应根据税务机关开具的「「红字增值税专用发票」」作相反的会计分录；如原增值税专用发票「「未作认证」」，应将发票退回并作相反的会计分录」** |
| **②** | ⚠⚠ **采购等业务进项税额「不得抵扣」**（**认证前后两步**） | **「用于简易计税方法计税项目、免征增值税项目、集体福利或个人消费等……「「取得增值税专用发票时」」，应借记相关成本费用或资产科目，借记『应交税费——「「待认证进项税额」」』科目，贷记『银行存款』『应付账款』等科目；「「经税务机关认证后」」，应借记相关成本费用或资产科目，贷记『应交税费——应交增值税（「「进项税额转出」」）』科目」** |
| **③** | ⚠⚠ **货物已验收入库但尚未取得扣税凭证** | **「应在月末按「「货物清单或相关合同协议上的价格」」暂估入账，「「不需要将增值税的进项税额暂估入账」」」**；**「下月初，用「「红字」」冲销原暂估入账金额，待取得相关增值税扣税凭证并经认证后」**按正常程序入账 |
| **④** | ⚠ **小规模纳税人采购等业务** | **「小规模纳税人购买物资、服务、无形资产或不动产，「「取得增值税专用发票上注明的增值税应计入相关成本费用或资产，不通过『应交税费——应交增值税』科目核算」」」** |
| **⑤** | ⚠ **买方作为「扣缴义务人」** | **「境外单位或个人在境内发生应税行为，「「以购买方为扣缴义务人」」」**（**国务院规定委托境内代理人申报缴纳的除外**）；**境内一般纳税人购进服务、无形资产或不动产**——**按应计入相关成本费用或资产的金额借记相关科目，按可抵扣的增值税额借记进项税额，按应付或实际支付的金额贷记『应付账款』等科目，「「按应代扣代缴的增值税额，贷记『应交税费——代扣代交增值税』科目」」**；**实际缴纳时——借「应交税费——代扣代交增值税」贷「银行存款」** |
| **⑥** | ⚠ **接受「投资」转入的货物** | **「按照增值税专用发票上注明的增值税额，借记『应交税费——应交增值税（进项税额）』科目，按照确认的投资货物价值，借记『原材料』等科目，按照「「增值税额与货物价值的合计数」」，贷记『实收资本』『股本』等科目」** |
| **⑦** | ⚠ **接受「捐赠」转入的货物** | **「按专用发票上注明的增值税额，借记进项税额科目，按确认的捐赠货物的价值，借记『原材料』等科目，按接受捐赠的非货币资产的「「公允价值」」贷记『营业外收入』科目」** |
| **⑧** | ⚠⚠ **企业「进口」货物** | **「取得海关缴款书后，按照「「已申请稽核但尚未取得稽核相符结果」」的海关缴款书上注明的增值税额，借记『应交税费——「「待抵扣进项税额」」』明细科目，贷记『银行存款』『应付账款』等科目；「「稽核比对相符以及核查后允许抵扣的」」，应借记『应交税费——应交增值税（进项税额）』科目，贷记『应交税费——待抵扣进项税额』科目。经核查「「不得抵扣」」的进项税额，红字借记本科目、红字贷记相关科目」**；**按进口货物应计入采购成本的金额，借记「材料采购」等科目，贷记「银行存款」「应付账款」等科目** |
| **⑨** | ⚠ **购进「免税农产品」** | **「按照购进农产品的「「买价和规定的扣除率」」计算的进项税额，借记进项税额科目，按扣除进项税额后的买价借记『材料采购』等科目，按实际支付的买价和税款，贷记『应付账款』『银行存款』等科目」**；⚠⚠ **「纳税人在购进农产品时，应按照农产品抵扣的一般规定，「「按照 9% 计算抵扣进项税额」」」** |

#### （3）⚠⚠ 「农产品增值税进项税额核定扣除」的三种方法（**财税〔2012〕38 号**）

> ⚠ **适用范围（**教材原句**）**：**「自 2012 年 7 月 1 日起，以购进农产品为原料生产销售
> 「「液体乳及乳制品、酒及酒精、植物油」」的增值税一般纳税人，纳入农产品增值税进项税额
> 核定扣除试点范围，其购进农产品「「无论是否用于生产上述产品」」，
> 增值税进项税额均按照《农产品增值税进项税额核定扣除试点实施办法》的规定抵扣。」**

| # | ⚠ 方法 | ⚠ 依据与公式（**教材原句要点**） |
|---|---|---|
| **A** | ⚠⚠ **投入产出法** | **「参照国家标准、行业标准（包括行业公认标准和行业平均耗用值）确定销售单位数量货物耗用外购农产品的数量（「「农产品单耗数量」」）」**；**公式**：**当期允许抵扣农产品增值税进项税额 ＝（当期农产品耗用数量 × 农产品平均购买单价 × 扣除率）÷（1 + 扣除率）**；⚠ **其中「当期农产品耗用数量 ＝ 当期销售货物数量（「「不含采购除农产品以外的半成品生产的货物数量」」）× 单耗数量」**；⚠ **「平均购买单价是指购买农产品「「期末平均买价」」，「「不包括买价之外单独支付的运费和入库前的整理费用」」」**；**期末平均买价 ＝（期初库存农产品数量 × 期初平均买价 + 当期购进农产品数量 × 当期买价）÷（期初库存农产品数量 + 当期购进农产品数量）** |
| **B** | ⚠⚠ **成本法** | **「依据试点纳税人「「年度会计核算资料」」，计算确定耗用农产品的外购金额占生产成本的比例（「「农产品耗用率」」）」**；**公式**：**当期允许抵扣农产品增值税进项税额 ＝（当期主营业务成本 × 农产品耗用率 × 扣除率）÷（1 + 扣除率）**；⚠ **农产品耗用率 ＝ 上年投入生产的农产品外购金额 ÷ 上年生产成本**；⚠ **「农产品外购金额（含税）「「不包括」」不构成货物实体的农产品（包括「「包装物、辅助材料、燃料、低值易耗品」」等）和在购进农产品之外单独支付的运费、入库前的整理费用」**；⚠⚠ **程序**：**「农产品耗用率由试点纳税人「「向主管税务机关申请核定」」。年度终了，主管税务机关应根据试点纳税人本年实际对当年已抵扣的农产品增值税进项税额进行「「纳税调整」」，重新核定当年的农产品耗用率，并作为「「下一年度」」的农产品耗用率」** |
| **C** | ⚠ **参照法** | **「新办的试点纳税人或者试点纳税人新增产品的，试点纳税人可「「参照所属行业或者生产结构相近的其他试点纳税人」」确定农产品单耗数量或者农产品耗用率」**；⚠⚠ **次年调整**：**「次年，试点纳税人向主管税务机关申请核定当期的……并据此计算确定当年允许抵扣的农产品增值税进项税额，同时「「对上一年增值税进项税额进行调整」」——核定的进项税额「「超过」」实际抵扣的，其差额部分可以「「结转下期继续抵扣」」；核定的进项税额「「低于」」实际抵扣的，其差额部分应按规定「「将进项税额作转出处理」」」** |

⚠ **另两类核定扣除**：
- ⚠ **购进农产品「直接销售」的**：**当期允许抵扣农产品增值税进项税额 ＝（当期销售农产品数量 ÷（1 − 损耗率）× 农产品平均购买单价 × 扣除率）÷（1 + 扣除率）**；**损耗率 ＝ 损耗数量 ÷ 购进数量**；
- ⚠ **购进农产品用于生产经营且「不构成货物实体」的**（**包括包装物、辅助材料、燃料、低值易耗品等**）：**当期允许抵扣农产品增值税进项税额 ＝（当期耗用农产品数量 × 农产品平均购买单价 × 扣除率）÷（1 + 扣除率）**。

⚠⚠ **三个「扣除标准」与「扣除率的取值」**：
**「农产品单耗数量、农产品耗用率和损耗率「「统称为农产品增值税进项税额扣除标准」」」**；
⚠⚠ **「上述「「扣除率为销售货物的适用税率」」」**——**依财政部税务总局海关总署公告 2019 年第 39 号，
自 2019-04-01 起「原适用 16% 税率的，税率调整为 13%；原适用 10% 税率的，税率调整为 9%」，
故：销售货物适用 13% 的，扣除率为 13%；适用 9% 的，扣除率为 9%**。

#### （4）⚠ 「商业零售企业」购进商品业务的账务处理（**售价记账、实物负责制**）

> ⚠ **背景（**教材原句**）**：**「由于商业零售企业库存商品的核算采用「「『售价记账、实物负责制』」」，
> 而且商品的销售收入采用「「『一手交钱一手交货』」」的方式，实行增值税以后，进销业务的核算
> 与其他企业相比有一定的复杂性」**——**「既要保持零售企业多年来形成的比较科学的
> 『售价核算、实物负责制』，又要按照增值税的要求核算进项税额、销项税额和应缴纳的税金」**。

| # | ⚠ 情形 | ⚠ 账务要点（**教材原句要点**） |
|---|---|---|
| **A** | ⚠ **一般购进商品业务** | **「按「「不含税成本」」借记『物资采购』科目，按进项税额借记进项税额科目，按已付的全部款项贷记『银行存款』科目；商品入库时，仍按原来的「「含税售价」」借记『库存商品』科目，按不含税的进价贷记『物资采购』科目，再按「「含税的进销差价」」贷记『商品进销差价』科目」** |
| **B** | ⚠⚠ **进货退出** | **「发生进货退出时，应按商品「「含税零售价」」冲减『库存商品』科目，「「相应调整『商品进销差价』科目」」。同时，还应将「「收回的已付进项税额予以冲销」」」**；⚠⚠ **两笔法的惯例**：**「在实务中，为了真实反映每个供货单位提供商品的质量状况，「「一般将上述一笔会计分录分为两笔进行处理」」」**（**先冲销银行存款/物资采购/进项税额，再冲销商品进销差价/物资采购/库存商品**） |

### ⚠ 二、「2. 接受应税服务的核算」（**三类 + 小规模**）

| # | ⚠ 服务类型 | ⚠ 账务要点（**教材原句要点**） |
|---|---|---|
| **（1）** | ⚠ **加工、修理修配服务** | **「按增值税专用发票上注明的增值税额，借记进项税额科目，按照专用发票上记载的应计入加工、修理修配等货物成本的金额，借记『委托加工物资』等科目；按应付或实付的金额，贷记『银行存款』等科目」** |
| **（2）** | ⚠ **货物运输服务** | **「增值税一般纳税人提供货物运输服务，使用增值税专用发票和增值税普通发票，「「开具发票时应将起运地、到达地、车种车号以及运输货物信息等内容填写在发票备注栏中」」，如内容较多可另附清单」** |
| **（3）** | ⚠⚠ **旅客运输服务（**两条计算口径**）** | ⚠ **① 「铁路旅客运输」进项税额 ＝ 票面金额 ÷（1 + 「「9%」」）× 9%**；⚠⚠ **② 「公路、水路等其他旅客运输」进项税额 ＝ 票面金额 ÷（1 + 「「3%」」）× 3%**；⚠ **「需要说明的是，如果取得的是「「增值税电子普通发票」」，「「可以按照发票上注明的税额来抵扣」」」** |
| **（4）** | ⚠ **小规模纳税人采购等业务** | ⚠ **同「1（2）④」：其专用发票上注明的增值税应计入相关成本费用或资产，不通过「应交税费——应交增值税」科目核算** |

### ⚠⚠ 三、「3. 长期资产允许抵扣进项税额的情形」（**三种情形**）

> ⚠ **「长期资产」的统称（**教材原句**）**：**「纳税人取得「「固定资产、无形资产或者不动产」
> （以下统称长期资产）」**。

| # | ⚠ 情形 | ⚠ 口径（**教材原句要点**） |
|---|---|---|
| **（1）** | ⚠ **专用于「一般计税方法计税项目」** | **「对应的进项税额可以「「全额」」从销项税额中抵扣」** |
| **（2）** | ⚠⚠ **既用于一般计税、又用于「五类不允许抵扣项目」**（**即「混合用途」**） | ⚠⚠ **「属于用作「「混合用途」」的长期资产，「「原值不超过 500 万元」」的单项长期资产，对应的进项税额可以「「全额」」从销项税额中抵扣」**；⚠ **五类不允许抵扣项目（**教材给出的简称**）**：**简易计税方法计税项目、免征增值税项目、不得抵扣非应税交易、集体福利或者个人消费** |
| **（3）** | ⚠⚠ **专用于五类项目「后发生用途改变」** | **「专用于一般计税方法计税项目，或者既用于一般计税方法计税项目、又用于五类不允许抵扣项目的（以下统称混合用途），按照下列公式在「「用途改变的当月」」计算可抵扣进项税额」**：**可抵扣进项税额 ＝ 长期资产对应的进项税额 × 「「净值率」」**；**净值率 ＝（当月期初长期资产净值 ÷ 长期资产原值）× 100%** |

### ⚠ 四、本页的「要点密集区」（**复习提示**）

| 要点 | ⚠ 所指 |
|---|---|
| ⚠⚠ **两条路的分界** | **按价税合计（不得抵扣的六类）vs 按价税分别（可抵扣）** |
| ⚠⚠ **「当月已认证 → 进项税额；当月未认证 → 待认证进项税额」** | **同一笔采购两种借方科目** |
| ⚠⚠ **退货的两分** | **已认证→依红字专票作相反分录；未认证→退回发票作相反分录** |
| ⚠⚠ **不得抵扣的两步走** | **取得专票时先入「待认证进项税额」，认证后再转入成本费用并贷记「进项税额转出」** |
| ⚠ **未取得扣税凭证** | **月末按货物清单或合同价暂估入账（不估进项）；下月初红字冲销** |
| ⚠⚠ **进口货物走「待抵扣进项税额」** | **（与国内采购的「待认证进项税额」是两个不同科目）** |
| ⚠ **购进免税农产品** | **按 9% 计算抵扣（买价 × 扣除率）** |
| ⚠⚠ **农产品核定扣除三法** | **投入产出法（单耗数量）／成本法（耗用率）／参照法（新办或新增产品）** |
| ⚠⚠ **「扣除率＝销售货物的适用税率」** | **13% 或 9%（取决于销售货物适用税率）** |
| ⚠ **零售企业的三个差异** | **不含税成本入「物资采购」；含税售价入「库存商品」；差额入「商品进销差价」** |
| ⚠⚠ **旅客运输两档** | **铁路 9%／公路水路 3%；取得电子普通发票的按票面税额** |
| ⚠⚠ **长期资产的三档** | **专用一般计税→全额；混合用途且原值 ≤500 万→全额；专用后改用途→按净值率** |
