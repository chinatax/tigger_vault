# 税收协定·消极所得（股息、利息、特许权使用费）

## Definition

消极所得（Passive Income）：税收协定下的**股息**（第十条）、**利息**（第十一条）、
**特许权使用费**（第十二条）三项所得。三者的共同结构是
「**居民国与来源国都有征税权，但来源国的征税权被设定了最高税率（限制税率）**」。

⚠ 三条条款**结构同构**，所以最高效的记法是把它们放在一张表里对照；
⚠ 但**各自的定义边界**与**两项特殊规则**（设备租金按 60% 确定税基、技术服务视为技术转让的一部分）
是**只属于某一条**的，不能串。

## Key Points

### 一、⚠ 三条条款的税率对照

| 条款 | 来源国限制税率 | 特殊规则 |
|---|---|---|
| **股息**（第十条） | ⚠ **受益所有人是公司（合伙企业除外）并直接拥有支付股息公司至少 25% 资本** → 不应超过股息总额的 **5%**；**其他情况** → 不应超过 **10%** | 持股比例须在**取得股息前连续 12 个月以内任何时候**均达到 25% |
| **利息**（第十一条） | ⚠ **受益所有人为银行或金融机构** → **7%**；**其他情况** → **10%** | ⚠ **缔约双方政府机构及其拥有的、且不从事商业活动的金融机构或基金**从缔约一方取得的利息**应在该国免税**（免税金融机构在具体协定中**采取列名方式**） |
| **特许权使用费**（第十二条） | ⚠ **不应超过特许权使用费总额的 10%** | ⚠ **使用或有权使用工业、商业、科学设备**而支付的，按**支付总额的 60% 确定税基** |

- ⚠ **「取得股息」的日期**指按**国内法规定该项股息在中国发生纳税义务或扣缴义务的日期**
- ⚠ 三者的优惠税率均以**「受益所有人」身份**为前提，否则按**来源国国内法**征税
  —— 详见 [[beneficial-owner-determination]]

### 二、三个定义的口径

**（一）股息**

- ⚠ 定义：从**股份或非债权关系分享利润的权利**取得的所得，
  以及按照分配利润的公司是其居民的缔约国法律，**视同股份所得同样征税的其他公司权利**取得的所得
- ⚠ **股息支付的范围**：**既包括每年股东会议所决定的利润分配，
  也包括其他货币或具有货币价值的收益分配**，如**红股、红利、清算收入以及变相利润分配**
- ⚠ 股息**还包括缔约国按防止资本弱化的规定调整为股息的「利息」**
- ⚠ **股息与利息的判定**应遵循**实质重于形式**原则：一般情况下**各类债券所得不应视为股息**；
  ⚠ **但如贷款人确实承担债务人公司风险，其利息可被视为股息**。
  判定贷款人是否分担企业风险的**五个因素**：①该贷款**大大超过**企业资本中的其他投资形式，
  并与公司可变现资产**严重不符**；②债权人**将分享公司的任何利润**；
  ③该贷款的偿还**次于**其他贷款人的债权或股息的支付；④**利息的支付水平取决于公司的利润**；
  ⑤贷款合同**没有对具体的偿还日期作出明确规定**
- ⚠ **「资本」的口径**：通常**可视其在公司的出资份额情况**，一般体现为**在注册资本中所占份额**；
  ⚠ 当向公司以**提供贷款或其他形式的出资**产生的所得**已按规定（如防止资本弱化的规则）
  被当作股息处理**时，**这种贷款或出资也将被视为「资本」**

**（二）利息**

- ⚠ 定义：从**各种债权**取得的所得，**不论其有无抵押担保或者是否有权分享债务人的利润**；
  特别是从**公债、债券或者信用债券**取得的所得，**包括其溢价和奖金**
- ⚠⚠ **不属于利息的两类**：①**由于延期支付所处的罚款**不应视为利息；
  ②**债券持有者出售债券发生的盈亏**不属于利息范围
- ⚠ **与贷款业务相关的并附属于债权的所得可认定为利息**；
  ⚠ **对独立发生于债权方以外的、如单独收取的担保费等，原则上不应认定为利息**

**（三）特许权使用费**

- ⚠ 定义：**使用或有权使用**文学、艺术或科学著作（包括**电影影片、无线电或电视广播使用的
  胶片磁带**）的**版权**，**任何计算机软件**，**专利、商标、设计或模型、图纸、秘密配方或秘密程序**
  所支付的作为报酬的各种款项；也包括使用或有权使用**工业、商业、科学设备**
  或**有关工业、商业、科学经验的情报**所支付的作为报酬的各种款项
- ⚠ 四个理解要点：
  1. ⚠ 定义**既包括在有许可的情况下支付的款项，也包括因侵权支付的赔偿款**
  2. ⚠ 也包括使用或有权使用**工业、商业、科学设备**取得的所得（即**设备租金**）；
     ⚠ **但不包括**设备所有权最终转移给用户的有关**融资租赁协议**涉及的支付款项中**被认定为利息的部分**；
     ⚠ **也不包括使用不动产**取得的所得（**适用第六条不动产所得条款**）
  3. ⚠ 「使用或有权使用有关工业、商业、科学**经验的情报**取得的所得」应理解为**专有技术**
     —— 一般指**进行某项产品的生产或工序复制所必需的、未曾公开的、具有专有技术性质的信息或资料**
  4. ⚠⚠ **服务与特许权使用费的界分（三情形）**：
     - ⚠ **不属于**特许权使用费：服务提供方在提供服务过程中**使用了某些专门知识和技术，
       但并不许可这些技术使用权**的服务
     - ⚠ **属于**特许权使用费：服务提供方提供服务**形成的成果属于特许权使用费定义范围**，
       并且**服务提供方仍保有该项成果的所有权**，服务接受方对此成果**仅有使用权**
     - ⚠ **转让或许可专有技术使用权过程中**，技术许可方**派人员提供支持、指导等服务并收取服务费**，
       **无论单独收取还是包括在技术价款中，均应视为特许权使用费**
       —— ⚠ **但如人员服务已构成常设机构**，
       对**归属于常设机构部分**的服务所得应执行**第七条营业利润**条款，
       对提供服务的人员执行**非独立个人劳务**条款
  5. ⚠ **不属于特许权使用费的其余情形**：**单纯货物贸易项下作为售后服务的报酬**、
     **产品保证期内卖方为买方提供服务**所取得的报酬、
     **专门从事工程、管理、咨询等专业服务的机构或个人**提供的相关服务所取得的款项 →
     ⚠ 应作为**劳务活动所得适用第七条营业利润**条款

### 三、⚠ 四条共有的规则

**（一）并入常设机构的利润征税**

- ⚠ 若**受益所有人**是缔约国一方居民，在另一方**拥有常设机构**或**通过固定基地从事独立个人劳务**，
  且**据以支付的股份、债权、权利或财产构成该常设机构或固定基地资产的一部分，
  或与该机构或固定基地有其他方面的实际联系** →
  ⚠ 来源国**可将该所得并入常设机构的利润**予以征税，
  视具体情况适用「**营业利润**」或「**独立个人劳务**」的规定
- ⚠ **除外的反滥用情形**：若常设机构所在国对常设机构取得的股息有**优惠税收待遇**规定，
  股息受益所有人**仅以滥用协定为目的将股份转移**到常设机构的，**不应适用**该规定

**（二）协定待遇的例外情形（来源地判定）**

- ⚠ 一般情况下，**如果支付人（股息为分配利润的公司）为该缔约国居民**，
  应认为该所得**发生在该缔约国**
- ⚠⚠ **例外**：支付人**不论是否为缔约国一方居民**，只要其在该缔约国一方**设有常设机构或者固定基地**，
  且**支付该所得的债务/费用与该常设机构或固定基地有联系并由其负担** →
  ⚠ **该所得应认为发生于该常设机构或固定基地所在缔约国**
  - 例：某**第三国设在中国的常设机构**支付给新加坡居民的利息/特许权使用费，
    在与其有实际联系的情况下，⚠ **应认为发生于中国**，由中国根据协定行使**优先征税权**；
    如新加坡居民为**受益所有人**，则可享受协定待遇

**（三）关联交易适用协定优惠的限定**

- ⚠ 由于**支付人与受益所有人之间或他们与其他人之间的特殊关系**，
  支付的数额**超出支付人与受益所有人没有上述关系所能同意的数额**时，
  ⚠ **优惠税率应仅适用于未提及关系情况下的数额**；
  ⚠ **超出部分仍应按各缔约国的法律征税**（即**超出市场公允价格的部分不得享受协定优惠**）

**（四）反滥用条款**

- ⚠ 如果据以支付该所得的**权利或财产的产生或分配，是由任何人以取得该条款利益为主要目的
  而安排的**，则**不适用**优惠税率规定
- ⚠ 纳税人因该交易或安排而不当享受协定待遇的，**主管税务机关有权进行调整**，
  ⚠ **执行时应考虑我国国内法关于特别纳税调整的有关规定**
- ⚠ **利息反滥用条款的国内法对应**：对应国内税法的**资本弱化特别纳税调整**
  —— 由此，**超过独立交易原则支付的利息以及超过债资比例的利息，均应视为股息处理**
  （见 [[thin-capitalization]]）

### 四、股息的两条专有规则

**（一）持有期间的持股比例**

- ⚠ 适用低税率的股息，应属于符合条件的受益所有人**拥有资本比例达到 25% 以上的期间的利润**所形成的股息
- ⚠⚠ **但为便于执行**（准确跟踪计算会涉及以往多年且频繁变化，特别是上市公司），
  国家税务总局规定：**非居民直接拥有中国居民公司资本比例在取得股息前连续 12 个月以内
  任何时候均至少达到 25%** 的，**可以享受**该协定待遇
- ⚠ **如分配的股息涉及 12 个月以前的企业未分配利润**，
  则**不再考虑**股息受益所有人在**所分配利润所属年度**的持股比例是否满足要求

**（二）股息再分配征税权的划分**

- ⚠ 缔约国一方居民公司**从缔约国另一方取得利润或所得**，
  ⚠ **该缔约国另一方不得对该公司支付的股息征收任何税收，也不得对该公司的未分配利润征税**，
  即使支付的股息或未分配的利润**全部或部分是发生于该缔约国另一方的利润或所得**
- ⚠ **但两项除外**：①**支付给该缔约国另一方居民的股息**；
  ②**据以支付股息的股份与该缔约国另一方的常设机构或固定基地有实际联系**的
- ⚠ 该规定是对**再分配部分的征税权划分**：⚠ 新加坡居民投资于中国居民公司或在中国设立常设机构/固定基地，
  如其对从中国取得的股息或所得**向其中国境外的股东进行再分配**，
  其境外股东取得的这部分所得**无须向中国缴税**；
  ⚠ **但如果该项再分配又支付回中国的居民股东或中国境内机构场所，中国仍有征税权**

### 五、特许权使用费的一条专有规则（技术服务）

- ⚠ 依**国税函〔2010〕46 号**，**转让专有技术使用权涉及的技术服务活动应视为转让技术的一部分**，
  由此产生的所得**属于税收协定特许权使用费范围**
- ⚠ **但**如果技术许可方派遣人员到技术使用方为转让的技术提供服务，
  且**提供服务时间已达到按协定常设机构规定标准、构成了常设机构**的情况下：
  - ⚠ 对**归属于常设机构部分**的服务收入应执行**第七条营业利润**条款
  - ⚠ 对**提供服务的人员**执行**非独立个人劳务**条款
  - ⚠ 对**未构成常设机构或未归属于常设机构**的服务收入**仍按特许权使用费**规定处理
- ⚠ **事先不能确定是否构成常设机构时**：如果技术受让方在合同签订后即支付费用（包括技术服务费），
  可**暂执行特许权使用费条款的规定**；⚠ **待确定构成常设机构且认定有关所得与该常设机构有实际联系后**，
  按协定相关条款对归属常设机构利润征收企业所得税及对相关人员征收个人所得税时，
  ⚠ **应将已按特许权使用费条款规定所做的处理作相应调整**
