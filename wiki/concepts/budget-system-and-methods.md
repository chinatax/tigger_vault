# 全面预算体系与编制方法

## Definition

全面预算体系与编制方法（Budget System and Compilation Methods）：全面预算是企业在一定期间内经营、资本与财务活动的总体安排，由**经营预算**、**资本支出预算**和**财务预算**三部分组成；编制方法则决定预算数据以什么为起点、覆盖什么业务量区间、按什么时间窗口滚动。

考点集中在两处：**各类预算的从属关系与「谁综合性最强」**，以及**六种编制方法两两对比的优缺点归属**。

## Key Points

- **全面预算体系的三个组成部分**（第 30、54 题）：
  - **经营预算**、**资本支出预算**、**财务预算**
  - ⚠ **财务预算的综合性最强**，是预算的**核心**内容（选项「经营预算的综合性最强」错误）
  - **财务预算包括**：现金预算、预计利润表、预计资产负债表、预计现金流量表
  - ⚠ **销售预算不属于财务预算的内容**（销售预算属经营预算）
  - 财务预算的各项指标**依赖于**经营预算和资本支出预算
  - 全面预算体现了预算的**全员、全过程、全部门**的特征
- **现金预算**（第 48 题）：
  - **现金预算是财务预算的核心**
  - **现金余缺** = 预算期内现金收入 − 现金支出
  - 计算某一期间的现金余缺时**应该考虑**的直接因素：**期初现金余额**、**预算期销售现金收入**、**预算期现金支出**
  - ⚠ **不应考虑**：预算期资金筹措与使用（向银行借款、还款、支付利息、短期投资、投资收回等），
    它是**计算出现金余缺之后的下一步骤**才需要考虑的内容
  - ⚠ **不应考虑**：预算期银行借款金额——只有先算出余缺，才能确定是否需要借款
- **六种编制方法（三组对比）**：
  - **增量预算法 vs 零基预算法**
    - **增量预算法**：主张以历史期为基础，**不需要在预算内容上作较大调整**
    - **零基预算法**：**不以**以往期间的费用项目和实际发生的金额为基础，**也不以**历史期的经济活动为基础；
      优点：增强预算透明度，更有利于进行预算控制；
      ⚠ 适用于企业**各项**预算的编制，**特别是不经常发生的预算项目或预算编制基础变化较大的预算项目**
      （第 41 题 D 选项「不适用于不经常发生的预算项目」**错误**——恰恰相反）
  - **固定预算法 vs 弹性预算法**
    - **固定预算法**：可用于**固定费用**预算的编制
    - **弹性预算法**：适用于编制**所有与业务量有关**的预算，实务中主要用于编制**成本费用预算和利润预算**，尤其是**成本费用预算**
    - ⚠ 弹性预算法**不是**用于资产负债预算的编制（第 45 题 C 选项错误）
  - **定期预算法 vs 滚动预算法**
    - **定期预算法**：使预算期间与**会计期间相对应**，便于将实际数与预算数进行对比；
      有利于对预算执行情况进行分析和评价；⚠ **编制工作量较小、成本较低**
      （选项「编制工作量较大、成本较高」是**滚动预算法**的特点）
      ⚠ 不利于前后各个期间的预算衔接，**不能**适应连续不断的业务活动过程的预算管理
    - **滚动预算法**：通过持续滚动预算编制、逐期滚动管理，实现**动态反映市场、建立跨期综合平衡**，
      从而有效指导企业营运，强化预算的决策与控制职能；
      能够灵活应对内外环境的变化，预算编制更贴近预算期企业经济活动需要
  - ⚠ **优点归属混淆**（第 51、55 题）：
    「增强预算编制透明度，有利于进行预算控制」是**零基预算法**的优点；
    「考虑预算期可能的不同业务量水平，更贴近企业经营管理实际情况」是**弹性预算法**的优点。
    二者都**不是**滚动预算法的优点，不要张冠李戴
