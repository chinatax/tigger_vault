# 其他权益工具投资

## Definition

其他权益工具投资（Equity Instrument at FVOCI）：在初始确认时**指定**为以公允价值计量且其变动计入**其他综合收益**的**非交易性权益工具**投资。

它是金融资产四分类中**最封闭**的一类——**不可重分类**，且其价值变动**永不经过损益**（处置差额与累计其他综合收益一律转入留存收益）。这两条合起来，使它成为「为长期持有、不以交易获利为目的」的权益投资的专属通道。

## Key Points

- **指定与撤销**：
  - 在**初始确认时**，企业可以将**非交易性权益工具投资**指定为该类别
  - ⚠ 该指定**一经作出，不得撤销**
- **初始计量**（第 304 题）：
  - 初始确认金额 = 取得该金融资产的**公允价值**（**不包含已宣告但尚未发放的现金股利**）
    **+ 相关交易费用**
  - ⚠ 与交易性金融资产相反——**交易费用计入成本**，而不是计入当期损益
- **后续计量**：
  - 以**公允价值**进行后续计量
  - 公允价值变动计入**其他综合收益**（不经损益）
- **不可重分类**（第 304 题，⚠ 唯一的「不可」类别）：
  - ⚠ **其他权益工具投资与其他金融资产不可以进行重分类**
  - 对比：债权投资与其他债权投资之间可以重分类（见 [[debt-investment-fvoci]]）
- **处置**（第 296 题）：
  - 售价与账面价值的差额，**以及**原计入其他综合收益的累计利得或损失，
    **均转入留存收益**（盈余公积、利润分配——未分配利润）
  - ⚠ **不经过当期损益**
  - 例：以 8000 万元购入（另付交易费用 16 万元），以每股 11 元出售 1000 万股、
    支付交易费用 33 万元
    → 应确认的留存收益 =（11 × 1000 − 33）−（8000 + 16）= **2951 万元**
- **持有期间的现金股利**：
  - 计入**投资收益**
- **转为长期股权投资（权益法）时的处理**（第 315、318 题）：
  - 增资时以「**原股权投资的公允价值** + 新增投资支付对价的公允价值」作为初始投资成本
  - ⚠ 原持有期间因公允价值变动确认的**其他综合收益应转入留存收益**
    （**不是**转入当期损益）
  - ⚠ 应**终止确认**其他权益工具投资
  - 例（第 318 题）：原 10% 股权公允价值 1200 + 新付对价 2540 = 3740 万元；
    原计入其他综合收益的 300 万元转入盈余公积 30、未分配利润 270
- **与其他类别的对比**：初见即指定、费用计入成本、不可重分类、处置转留存收益——
  这四条共同把它与 [[trading-financial-assets]]、[[debt-investment-fvoci]] 区分开
