# 债权投资与摊余成本

## Definition

债权投资与摊余成本（Debt Investment at Amortized Cost）：以**摊余成本**后续计量的债务工具投资，其核心是**实际利率法**——把票面利息与实际利息之间的差额逐期摊销，使账面价值在到期日收敛于面值。

本章一切计算的枢纽是**摊余成本的递推公式**，而该公式随**付息方式**不同而分叉，这是最高频的失分点。

## Key Points

- **初始计量**（第 271 题）：
  - 支付价款中包含的**已到付息期但尚未领取的利息**应**单独确认为应收利息**，
    **不计入**债权投资的入账价值
  - ⚠ **相关税费应计入成本**（不是扣除，也不是计入当期损益）
  - 科目结构：按债券的**面值**借记「债权投资——**成本**」，
    初始入账价值与面值的差额记入「债权投资——**利息调整**」
  - 例：以 1600 万元购入面值 1500 万元债券，其中含已到付息期未领取利息 150 万元
    → 初始入账价值 = 1600 − 150 = **1450 万元**
- **摊余成本的递推公式**（⚠ 按付息方式分两套，最易记错）：
  - **分期付息**（每年年末付息）：年末摊余成本 = 期初摊余成本 ×（1 + 实际利率）**− 票面利息**
  - **到期一次还本付息**：年末摊余成本 = 期初摊余成本 ×（1 + 实际利率）　**（不扣票面利息）**
    - 例：买价 930 + 费用 4 = 934、实际利率 6%、到期一次还本付息
      → 年末账面价值 = 934 × 1.06 = **990.04 万元**
- **投资收益与实际利息**：
  - **投资收益** = 期初摊余成本 × **实际利率**
  - 每期实际利息 = 应计利息（票面利息）+ 利息调整的**折价**摊销额（− **溢价**摊销额）
  - ⚠ **折价**购入时「利息调整」初始在**贷方**，摊销时转入**借方**（反之亦然）
- **持有至到期的累计投资收益**（第 276 题）：
  - 累计投资收益 = **累计应计利息 + 利息调整摊销总额**
  - 例：面值 1800、实际支付 1500 + 相关税费 10 → 入账 1510
    → 累计 = 1800 × 5% × 3 +（1800 − 1510）= 270 + 290 = **560 万元**
- **摊余成本的三个调整项**（第 307 题，⚠ 多选题易错）：
  - 摊余成本 = 初始确认金额经下列调整后的结果：
    - ①扣除**已偿还的本金**
    - ②加上或减去采用**实际利率法**将该初始确认金额与到期日金额之间的差额进行摊销形成的**累计摊销额**
    - ③扣除**累计计提的损失准备**
  - ⚠ **不包括**：**公允价值变动额**、按期支付的**票面利息**
- **与其他金融资产类别的对比**：公允价值计量的三类见 [[trading-financial-assets]]、[[debt-investment-fvoci]]、
  [[equity-instrument-fvoci]]；减值规则见 [[asset-impairment]]
