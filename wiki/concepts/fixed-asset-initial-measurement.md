# 固定资产的初始计量

## Definition

固定资产的初始计量（Fixed Asset Initial Measurement）：确定固定资产入账成本的过程，原则上以**使固定资产达到预定可使用状态前**所发生的一切合理、必要的支出为成本。

判断主线始终是「**这笔支出是否使固定资产达到预定可使用状态**」——是则计入成本，否则计入当期损益或另作存货核算。

## Key Points

- **外购需安装的设备**（第 233、244、249 题）：
  - 入账价值 = **买价 + 运输费 + 装卸费 + 安装人员工资 + 领用材料/产品的成本**（+ 按规定计入的税费）
  - ⚠ **领用自产产品按「成本」而非「计税价格」计入**，但若该产品为应税消费品，
    其**消费税按「计税价格 × 税率」**计算并计入设备成本
    - 例：买价 800 + 运费 10 + 安装人员工资 120 + 自产产品成本 80 + 消费税 100×10% = **1020 万元**
  - ⚠ 领用**原材料**的增值税进项税额若**可抵扣**，**不计入**设备成本
- **一笔款项购入多项没有单独标价的固定资产**（第 235 题）：
  - 按各项固定资产**公允价值的比例**分配总成本
  - ⚠ 各项设备**单独发生**的运输费等直接归属费用，**直接计入**该设备的成本，不参与分摊
  - 例：总价 800 按 280:360:260 分配，Y 设备另加运费 2.4 → 800×360/900 + 2.4 = 322.4 万元
- **分期付款购买（实质上具有融资性质）**（第 242 题）：
  - 固定资产按**购买价款的现值**入账（= 首期付款 + 各期付款 × 年金现值系数）
  - 差额记「**未确认融资费用**」（借方），贷记「**长期应付款**」（尚未支付的总价）
  - 例：总价 150、首付 60、余款 3 期每期 30、利率 10%
    - 借 固定资产 134.607（= 60 + 30×2.4869）、借 未确认融资费用 15.393、贷 长期应付款 90、贷 银行存款 60
- **自行建造**（第 248 题）：
  - **计入**造价：工程物资耗用、人工、满足资本化条件的借款费用
  - ⚠ **不计入**造价：工程领用生产用原材料应负担的**可抵扣增值税**；
    **试车产出产品的成本**（应确认为**存货**或其他相关资产）；
    建造过程中与承包企业发生纠纷而承担的**逾期未付款的利息及违约金**
  - **在建工程完工后已领出的剩余物资退库**：借「工程物资」、贷「在建工程」（冲减造价）
  - 「**在建工程——待摊支出**」科目核算（第 261 题）：**可行性研究费**、
    **建设期间发生的工程物资盘亏净损失**、满足资本化条件的**借款费用**
    - ⚠ 在建工程因**自然灾害**造成的净损失，转入「**营业外支出——非常损失**」，**不通过**待摊支出
    - ⚠ 负荷联合试车产出产品的**销售收入**通过「主营业务收入」核算，不通过待摊支出
- **弃置费用**（第 243、256、263 题）：
  - 预计弃置费用的**现值**计入固定资产成本，同时确认**预计负债**
    - 例：弃置费 10000 万元、20 年后支付、折现率 6% → 预计负债初始 = 10000 × 0.3118 = 3118 万元
  - 各期按弃置费用计算确定的**利息费用计入财务费用**，
    即预计负债期末余额 = 初始金额 ×（1+i）^期数（例：3118 × 1.06² ≈ 3503 万元）
  - 履行弃置义务变动引起预计负债**减少**的，以**固定资产账面价值为限**扣减固定资产成本；
    ⚠ **超过**固定资产账面价值的部分确认为**当期损益**（**不是**资本公积）
  - ⚠ 固定资产的**使用寿命结束**后，预计负债的所有后续变动应在发生时计入**当期损益**
