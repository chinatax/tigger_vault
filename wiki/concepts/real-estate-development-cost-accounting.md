# 房地产开发计税成本核算

## Definition

房地产开发计税成本核算（Taxable Cost Accounting for Real Estate Development）：
房地产开发企业在开发、建造开发产品过程中发生的、**按税收规定应归入某项成本对象**的各项费用的归集与分配规则。

它要解决的是同一个问题的三面：**把钱归到哪个筐**（成本对象的确定）→ **筐里装哪些钱**
（计税成本支出的六项内容）→ **一个筐装不下的钱怎么分**（共同成本的四种分配方法）。
⚠ 与 [[real-estate-development-income-tax]] 是**同一业务的两端**——那边管「收入与完工」，这边管「成本与扣除」。

## Key Points

### 一、成本对象的确定原则（五条）

| 原则 | 含义 |
|---|---|
| **可否销售** | 能对外经营销售的 → **独立**计税成本对象；**不能**对外销售的 → 先作**过渡性**成本对象归集，再摊入能销售的成本对象 |
| **功能区分** | 某组成部分**相对独立**且**具有不同使用功能**时，可作独立成本对象 |
| **定价差异** | 因产品类型或功能不同导致**预期售价存在较大差异** → 分别核算 |
| **成本差异** | 因建筑上存在**明显差异**可能导致建造成本出现较大差异 → 分别核算 |
| **权益区分** | 属于**受托代建**或**多方合作开发**的 → 结合上述原则分别划分 |

- ⚠ 确定成本对象后须出具**专项报告**（含确定原则、依据、共同成本分配原则与方法、开发项目基本情况与开发计划），
  在**开发产品完工当年**企业所得税年度纳税申报时随申报表一并报送
- ⚠ 已报送主管税务机关后**不得随意调整或相互混淆**；确需调整的须就原因、依据与调整前后成本变化
  另出具专项报告，在**调整当年**申报时报送
- ⚠ 成本对象确定**不合理**或共同成本分配方法不合理的 → 税务机关**有权合理调整**；
  不如实或不出具专项报告的 → 按《税收征管法》处理

### 二、计税成本支出的六项内容

| # | 项目 | 范围 |
|---|---|---|
| 1 | **土地征用费及拆迁补偿费** | 土地买价或出让金、**大市政配套费**、**契税**、**耕地占用税**、土地使用费、土地闲置费、**土地变更用途和超面积补缴的地价**及相关税费、拆迁补偿支出、安置及动迁支出、**回迁房建造支出**、农作物补偿费、危房补偿费 |
| 2 | **前期工程费** | 水文地质勘查、测绘规划、设计、可行性研究、筹建、场地通平等前期费用 |
| 3 | **建筑安装工程费** | 开发项目建筑工程费和安装工程费 |
| 4 | **基础设施建设费** | 社区管网工程费（道路、供水、供电、供气、排污、排洪、通信、照明）+ 园林环境工程费（环境卫生、园林绿化） |
| 5 | **公共配套设施费** | 项目内发生的、**独立的、非营利性的**、且**产权属于全体业主**的，或**无偿赠与地方政府、政府公用事业单位**的公共配套设施支出 |
| 6 | **开发间接费** | 直接组织和管理开发项目、**不能归属于特定成本对象**的成本费用性支出——管理人员工资、职工福利费、折旧费、修理费、办公费、水电费、劳动保护费、工程管理费、**周转房摊销**、**项目营销设施建造费** |

### 三、核算程序（五步）

1. 对当期实际发生的各项支出按性质、经济用途、地点、时间整理归类，
   区分**应计入成本对象的成本**与**应在当期税前扣除的期间费用**；同时对**预提费用和待摊费用**计量确认
2. 将应计入成本对象的支出合理划分为**直接成本、间接成本、共同成本**，
   归集分配至**已完工、在建、未建**三类成本对象
3. 对**期前已完工**成本对象应负担的成本费用，按**已销开发产品、未销开发产品、固定资产**分配——
   **已销**部分当期申报扣除，**未销**部分待实际销售时再扣
4. 对**本期已完工**成本对象分类为**开发产品和固定资产**并结算计税成本；开发产品按可售面积算单位工程成本，
   据此计算已销与未销计税成本
5. 对**本期未完工和尚未建造**的成本对象应负担的成本费用，**分别建立明细台账**，待完工后再结算

### 四、计量方法与共同成本分配（四种）

开发产品按**制造成本法**计量核算：**直接成本**和**能分清成本对象的间接成本**直接计入；
**共同成本**和**不能分清负担对象的间接成本**按**受益与配比原则**分配。

| 方法 | 定义 |
|---|---|
| **占地面积法** | 按已动工成本对象占地面积占开发用地总面积比例分配 |
| **建筑面积法** | 按已动工成本对象建筑面积占开发用地总建筑面积比例分配 |
| **直接成本法** | 按期内某一成本对象的直接开发成本占期内全部成本对象直接开发成本比例分配 |
| **预算造价法** | 按期内某一成本对象预算造价占期内全部成本对象预算造价比例分配 |

- ⚠ **分期开发的「两步走」**（占地面积法与建筑面积法均适用）：先按**本期全部成本对象**占开发用地**总面积**
  的比例分配，再按**某一成本对象**占**期内全部成本对象总面积**的比例分配。
  **期内**全部成本对象应负担的占地面积 ＝ 期内开发用地占地面积 − 应由各期成本对象**共同负担**的占地面积
- **具体项目的规定分配法**（⚠ 高频）：
  - **土地成本** → 一般按**占地面积法**；确需结合其他方法的应**商税务机关同意**。
    土地开发同时联结房地产开发的（一次性取得土地分期开发），其土地开发成本经商税务机关同意后
    可先按**土地整体预算成本**分配，待土地整体开发完毕再行调整
  - **单独作为过渡性成本对象核算的公共配套设施开发成本** → **建筑面积法**
  - **借款费用**属于不同成本对象共同负担的 → **直接成本法或预算造价法**
  - 其他成本项目 → **由本企业自行确定**

### 五、以非货币交易方式取得土地使用权的成本

- **换取开发产品为目的**、且换取的开发产品**就是该项土地开发建造的**：
  接受投资时**暂不确认**成本，待**首次分出开发产品**时，按应分出开发产品（含首次及以后应分出）
  的**市场公允价值** + 土地权转移过程应支付的相关税费，确认土地使用权成本
- **换取其他土地开发建造的开发产品**：在**投资交易发生时**按应付出开发产品的市场公允价值 + 相关税费确认
- **以股权形式投资**：在**投资交易发生时**按该项土地使用权的**市场公允价值** + 相关税费确认
- ⚠ 三种情形**如涉及补价**，取得成本均应**加上应支付的补价款或减除应收到的补价款**

### 六、可预提（应付）费用——仅三项

⚠ 除下列三项外，**计税成本均应为实际发生的成本**：

1. **出包工程未最终办理结算而未取得全额发票**的，在证明资料充分的前提下，
   发票不足金额可预提，但**最高不得超过合同总金额的 10%**
2. **公共配套设施尚未建造或尚未完工**的，可按**预算造价**合理预提建造费用
   ——⚠ 须符合「已在售房合同、协议或广告、模型中**明确承诺建造且不可撤销**」或「按法律法规**必须配套建造**」
3. **应向政府上缴但尚未上缴**的**报批报建费用、物业完善费用**可按规定预提
   （物业完善费 = 物业管理基金、公建维修基金或其他专项基金）

### 七、其余规则

- **停车场所的两分**：**单独建造**的停车场所 → 作为**成本对象单独核算**；
  利用**地下基础设施**形成的停车场所 → 作为**公共配套设施**处理
- ⚠ **合法凭据是硬门槛**：结算计税成本时实际发生的支出**应当取得但未取得合法凭据**的，
  **不得计入计税成本**，待实际取得合法凭据时再计入
- **核算终止日**：开发产品完工后，可在**完工年度企业所得税汇算清缴前**选择确定计税成本核算终止日，
  **不得滞后**；已完工开发产品在完工年度**未按规定结算**计税成本的，
  税务机关**有权确定或核定**其计税成本并据此纳税调整
- **配套设施的营利性分流**：
  - **非营利性且产权属于全体业主**，或**无偿赠与地方政府、公用事业单位** → 视为**公共配套设施**，
    建造费用按公共配套设施费处理
  - **营利性**、或**产权归本企业**、或**未明确产权归属**、或**无偿赠与其他单位** → 应**单独核算**成本；
    除房地产开发企业**自用按建造固定资产**处理外，其余**一律按建造开发产品**处理
- **邮电通信、学校、医疗设施**应**单独核算**成本；由房地产开发企业与国家有关业务管理部门、
  单位**合资建设**、完工后**有偿移交**的，对方给予的**经济补偿可直接抵扣该项目的建造成本**，
  抵扣后的差额调整当期应纳税所得额

### 八、成本费用扣除的其余规则

- **可售面积单位工程成本 = 成本对象总成本 ÷ 成本对象总可售面积**
- **已销开发产品的计税成本 = 已实现销售的可售面积 × 可售面积单位工程成本**
- 房地产开发企业发生的**期间费用、已销开发产品计税成本、税金及附加、土地增值税**准予**当期**按规定扣除
- ⚠ **维修费用**：对**尚未出售**的已完工开发产品和按法律法规或合同规定对**已售**开发产品
  （含共用部位、共用设施设备）进行日常维护、保养、修理实际发生的维修费用 → **当期据实扣除**
- **共用部位、共用设施设备维修基金**已计入销售收入的，按规定移交给有关部门、单位时**于移交时扣除**
- ⚠ **银行按揭保证金**：约定本企业为购买方按揭贷款提供担保的，向银行提供的保证金（担保金）
  **不得从销售收入中减除，也不得作为费用当期税前扣除**，但**实际发生损失时可据实扣除**
- **委托境外机构销售**：支付的销售费用（含佣金或手续费）**不超过委托销售收入 10%** 的部分准予据实扣除
- **利息支出的两条路径**：
  - 为建造开发产品借入资金发生的符合税收规定的借款费用，可按企业会计准则规定**归集和分配**；
    其中属于**财务费用**性质的借款费用可**直接在税前扣除**
  - **企业集团或其成员企业统一向金融机构借款**分摊集团内部其他成员企业使用的，借入方
    **凡能出具从金融机构取得借款的证明文件**，可以在使用借款的企业间**合理分摊**利息费用，
    使用借款的房地产开发企业分摊的合理利息准予扣除
- **国家无偿收回土地使用权**形成的损失 → 作为**财产损失**按规定税前扣除
- **开发产品整体报废或毁损**（以成本对象为计量单位）的净损失 → 按规定审核确认后扣除
- ⚠ **转为自用**：开发产品转为自用的，其**实际使用时间累计未超过 12 个月又销售**的，
  **不得在税前扣除折旧费用**
