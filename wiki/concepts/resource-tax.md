# 资源税

## Definition

资源税（Resource Tax）：对我国领域及管辖海域内**开采应税资源**的单位和个人课征的税种，
目的是调节资源级差收入、促进资源节约集约利用。它的征税对象是**资源的开采行为**，
而非资源的销售——因此**进口不征、出口不退**，外购已税产品再销售也不是纳税人。

计征方式上采用**从价为主、从量为辅**的双轨制。

## Key Points

- **纳税人**：在中华人民共和国领域和我国管辖的其他海域**开发应税资源**的单位和个人。
  - ⚠ **进口不征**资源税；**出口也不退**
  - ⚠ **外购**已税产品再销售的，**不属于**资源税纳税人
  - ⚠ 各级行政机关、监察/审判/检察机关及法律法规授权组织依照规定**罚没、收缴**的应税产品，
    因其不属于"开采或生产应税资源"的行为，**不缴纳**资源税
- **征税范围**（五大类）：能源矿产、金属矿产、非金属矿产、水气矿产、盐。
  - ⚠ **不征**：成品油、居民用煤炭制品、自来水
  - ⚠ **不征**：工程建设项目在**批准占地范围内**开采并**直接用于本工程回填**的砂石、粘土等
  - ⚠ **属于**征收范围：天然卤水、凝析油、从原油中分离出的油气田混合轻烃、
    稠油与高凝油、锡土矿原矿、金刚石
  - ⚠ **矿产品 vs 水资源**的分工：**地热、矿泉水和天然卤水按"矿产品"征收资源税**
    （不征水资源税）；**再生水、集蓄雨水、海水及海水淡化水、微咸水**等非常规水
    **不属于**水资源税征税范围
- **计征方式**：**从价计征**（比例税率）或**从量计征**（定额税率）。
  - 可**从价或从量择一**的税目：**地热、石灰岩、其他粘土、砂石、矿泉水、天然卤水**
  - 石灰岩、铜矿、铝土矿等**从价**计征；有色金属中**钨、钼、中重稀土选矿**采用
    固定比例税率，其他选矿适用幅度比例税率

### 教材第六章第一～三节与第六节的系统性补充（2026-09-23）

**（1）概念与三个特点（第一节）**

- **概念**：资源税是以**应税资源为课税对象**，对在**中华人民共和国领域和中华人民共和国管辖的其他海域**
  **开发应税资源的单位和个人**，就其**应税资源销售额或销售数量**为计税依据而征收的一种税。
- **三个特点**（⚠ 皆以《资源税法》的立法为落脚点）：

| # | 特点 | 内涵 |
|---|---|---|
| 1 | **落实税收法定原则** | **2016 年资源税全面从价计征改革**推开以来，相关政策已较为成熟稳定，**将改革成果上升为法律**——制定《资源税法》是**落实税收法定原则**的重要任务与具体体现，有利于提升政策的**科学性、稳定性、权威性** |
| 2 | **完善税收调节机制，促进资源节约高效利用** | ⚠ **立法固化的从价计征制度构建了更为合理的资源收益调节机制，弥补了从量定额机制下「资源税负与矿价不挂钩」的不足**——⚠ **从价计征下资源税负随矿价的升降而自动增减**，规范了资源开发收益分配秩序 |
| 3 | **优化征管操作，提升纳税人办税便利度** | 吸收了税收征管与服务上的有效做法，如**简并了征收期限、简化了纳税申报、强化了部门协同** |

**（2）纳税人（第二节）**

- ⚠ **水资源税的试点授权**：**国务院**根据国民经济和社会发展需要，依照《资源税法》的原则，
  对**取用地表水或者地下水的单位和个人****试点征收水资源税**；
  ⚠ **征收水资源税的，停止征收水资源费**。
- ⚠ ⚠ **中外合作开采油气合同的过渡安排**：**2011 年 11 月 1 日前**已依法订立**中外合作开采陆上、
  海上石油资源合同**的，在该合同**有效期内**，**继续依照国家有关规定缴纳「矿区使用费」，不缴纳资源税**；
  ⚠ **合同期满后，依法缴纳资源税**。
- ⚠ **不缴纳资源税的情形（2 项）**：
  1. **各级行政机关、监察机关、审判机关、检察机关**，以及**法律法规授权的具有管理公共事务职能的
     事业单位和组织**依照国家有关法律法规**罚没、收缴**的资源税应税产品；
  2. ⚠ **工程建设项目在批准占地范围内开采并直接用于本工程回填**的**砂石、粘土等矿产品**
     ——⚠ **因其不属于「开发应税资源」**，不缴纳资源税。

**（3）税目和税率（第三节）**

- ⚠ ⚠ **正列举的规模**：《资源税法》采取**正列举**方式，共设置 **5 个一级税目、17 个二级子税目，
  具体税目有 164 个**；各税目的征税对象包括**原矿或选矿**，**涵盖了所有已经发现的矿种和盐**。
- **五个一级税目与二级子税目**：**能源矿产（7 个子税目）**／**金属矿产（2 个：黑色金属、有色金属）**／
  **非金属矿产（3 类：矿物类、岩石类、宝玉石类）**／**水气矿产（2 个）**／**盐（3 个）**。

**能源矿产（7 子目）的关键归属规则**：

1. **原油**（征税对象为**原矿**）——⚠ **凝析油按原油税目征收**（凝析油 ＝ 在**气田开发**中或
   **油田开发天然气**中因**温度压力变化凝析出来的液相组分**）；
   ⚠ **从开采的原油中分离出的「油气田混合轻烃」按原油税目征收**（界定参照《油气田混合轻烃》**SY/T 7831**）。
2. **天然气、页岩气、天然气水合物**（**原矿**）——⚠ **从开采的天然气中分离出的「油气田混合轻烃」
   按天然气税目征收**。
3. **煤**（**原矿或者选矿**）——⚠⚠ **原矿与选矿的分界**：
   - **按「煤原矿」征收**：开采的**未经加工处理**、或经过**破碎、选矸（矸石直径 50mm 以上）**后的煤炭，
     以及经过**筛选分类**后的**筛选煤、低热值煤**等；
   - **按「煤选矿产品」征收**：通过**洗选、干选、风选**等物理化学工艺**去灰去矸**后生产的
     **精煤、中煤、煤泥**等。
4. **煤成（层）气**（**原矿**）；5. **铀、钍**（**原矿**）；
6. **油页岩、油砂、天然沥青、石煤**（**原矿或者选矿**）；7. **地热**（**原矿**）。

**金属矿产（2 子目）**：

- **黑色金属**：包括**铁、锰、铬、钒和钛**（**原矿或者选矿**）；
- **有色金属**：包括**铜、铅、锌、锡、镍、锑、镁、钴、铋、汞，铝土矿，钨，钼，金、银，
  铂、钯、钌、锇、铱、铑，轻稀土，中重稀土，铍、锂、锆、锶、铷、铯、铌、钽、锗、镓、铟、铊、
  铪、铼、镉、硒、碲**——⚠ ⚠ **其中钨、钼、轻稀土、中重稀土的征税对象是「选矿」，
  其他有色金属矿产的征税对象是「原矿或者选矿」**。
  - ⚠ **轻稀土**：纳税人将开采的**轻稀土原矿**经过**洗选等初加工**过程产出的
    **矿岩型稀土精矿**（包括**氟碳铈矿精矿、独居石精矿以及混合型稀土精矿**等），
    **按轻稀土选矿产品**征收资源税；
  - ⚠ **中重稀土**：纳税人将开采的**离子型稀土原矿**通过**离子交换原理**等工艺生产的
    **稀土料液、碳酸稀土、草酸稀土**和通过**灼烧、氧化**等工艺生产的**混合稀土氧化物**，
    **按中重稀土选矿产品**征收资源税。

**非金属矿产（3 类）**：

- **① 矿物类**（高岭土、石灰岩、磷、石墨、萤石……直至**其他粘土**〔铸型用粘土、砖瓦用粘土、
  陶粒用粘土、水泥配料用粘土/红土/黄土/泥岩、保温材料用粘土〕）；
- **② 岩石类**（大理岩、花岗岩……泥炭、**砂石**）——⚠ **对于无法区分原生岩石矿种的
  粒级成型砂石颗粒，按照「砂石」税目征收资源税**；
- **③ 宝玉石类**（宝石、玉石、宝石级金刚石、玛瑙、黄玉、碧玺）。
- ⚠ **所有非金属矿产的征税对象是「原矿或者选矿」**。

**水气矿产（2 子目）**：①**二氧化碳气、硫化氢气、氦气、氡气**；②**矿泉水**。
⚠ 其征税对象**均为「原矿」**。

**盐（3 子目）**：①**钠盐、钾盐、镁盐和锂盐**（⚠ 征税对象为**选矿**）；②**天然卤水**（**原矿**）；
③**海盐**。
- ⚠ ⚠ **盐类选矿产品的归属**：纳税人将开采的**盐湖卤水、盐井卤水**通过**蒸发结晶法、沉淀法、
  溶剂萃取法、离子交换法、膜分离法**等**物理工艺**生产的**氯化盐、硫酸盐、硝酸盐**等，
  **按「盐类选矿产品」**征收资源税。

**⚠ 尾矿的两条税目归属规则**：

- ⚠ 纳税人**以尾矿为原料对特定矿物组分进行再选回收利用**的，**按「特定矿物组分」对应的税目**征收资源税；
- ⚠ 纳税人**以尾矿为原料进行资源化利用生产粒级成型砂石颗粒**的，**按「砂石」税目**征收资源税。
- ⚠ **相关省、自治区、直辖市依《资源税法》第七条对开采尾矿免征或减征的，从其规定**
  （⚠ 优惠侧见 [[resource-tax-preferences]]）。
- ⚠ **应税资源的具体范围，由《资源税法》所附《资源税税目税率表》确定**（教材表 6-1）。

**税率确定的依据（5 项，本节的程序性核心）**

| # | 规则 |
|---|---|
| 1 | ⚠ ⚠ **幅度税率的确定程序**：《资源税税目税率表》中规定实行**幅度税率**的，其**具体适用税率由省、自治区、直辖市人民政府**统筹考虑该应税资源的**品位、开采条件以及对生态环境的影响**等情况，**在幅度内提出，报同级人民代表大会常务委员会决定，并报全国人民代表大会常务委员会和国务院备案** |
| 2 | ⚠ **征税对象为「原矿或者选矿」的，应当分别确定具体适用税率** |
| 3 | ⚠ **水资源税**根据当地**水资源状况、取用水类型和经济发展**等情况实行**差别税率** |
| 4 | ⚠ **不同税目**未分别核算的**从高**：纳税人开采或者生产**不同税目**应税产品的，应分别核算销售额或销售数量；**未分别核算或者不能准确提供的，从高适用税率** |
| 5 | ⚠ **同一税目下不同税率**未分别核算的**也从高**：开采或者生产**同一税目下适用不同税率**应税产品的，应分别核算；**未分别核算或不能准确提供的，从高适用税率** |

**⚠⚠ 原矿与选矿的计征分界（第 2 项规则的展开，最易错）**：

- ⚠ **按「原矿」计征**：纳税人以**自采原矿**（**经过采矿过程采出后未进行选矿或者加工的矿石**）
  **直接销售**，或者**自用于应当缴纳资源税情形**的；
- ⚠ **按「选矿产品」计征**：纳税人以**自采原矿洗选加工为选矿产品**
  （**通过破碎、切割、洗选、筛分、磨矿、分级、提纯、脱水、干燥等过程形成的产品**，
  包括**富集的精矿**和**研磨成粉、粒级成型、切割成型的原矿加工品**）**销售**，
  或者将**选矿产品自用于应当缴纳资源税情形**的——⚠ ⚠ **在原矿移送环节不缴纳资源税**。

**（4）征收管理（第六节）**

**纳税义务发生时间（按结算方式 5 种）**：

- **一般**：销售应税产品 → **收讫销售款或者取得索取销售款凭据的当日**；
  ⚠ **自用**应税产品 → **移送应税产品的当日**。

| 结算方式 | 纳税义务发生时间 |
|---|---|
| **直接收款** | ⚠ **无论应税产品是否发出**，为**收讫销售款或者取得索取销售款凭据的当日**；⚠ **先开具发票的，为开具发票的当日** |
| **赊销和分期收款** | **合同约定的付款日期的当日**；⚠ **未签订书面合同或者书面合同未确定付款日期的**，为**发出应税产品的当日** |
| **预收货款** | ⚠ **发出应税产品的当日**（⚠ 不是收到预收款当日） |
| **托收承付和委托银行收款** | **发出应税产品并办妥托收手续的当日** |
| ⚠ **委托代销** | ⚠ **收到代销单位销售的「代销清单」的当日** |

**纳税期限**：资源税**按月或者按季**申报缴纳；不能按固定期限计算缴纳的，**可以按次**申报缴纳。
⚠ **按月或按季的 → 自月度或者季度终了之日起 15 日内**申报并缴纳税款；
⚠ **按次的 → 自纳税义务发生之日起 15 日内**申报并缴纳税款。

**纳税地点**：纳税人应当在**矿产品开采地或者海盐生产地**缴纳资源税；
⚠ ⚠ **海上开采的原油和天然气资源税由「海洋石油税务管理机构」征收管理**。
  - 具体计征方式的选择由**省、自治区、直辖市人民政府**提出，报同级人大常委会决定，
    并报全国人大常委会和国务院备案
- **纳税地点**：应税产品的**开采地或者生产地**（海盐为**生产地**）的税务机关。
  ⚠ **海上**开采的原油和天然气资源税由**海洋石油税务管理机构**征收管理。
- **纳税义务发生时间**：
  - 销售应税产品 → 收销售款或取得索取销售款凭据的**当日**
  - **自用**应税产品 → **移送**应税产品的当日
  - **赊销和分期收款** → 合同约定的付款日期当日；**未签订书面合同或未确定付款日期**的 → **发出**应税产品当日；**先开具发票的为开具发票当日**
  - **预收货款** → **发出**应税产品当日（⚠ 不是收到预收款当日）
  - **委托代销** → 收到代销单位**代销清单**的当日
  - ⚠ 用自采应税产品**抵偿债务**属"自用应缴资源税"情形，为**移送当日**（不是协议签订日）
- **申报期限**：**按月或者按季**申报缴纳，自月度或季度**终了之日起 15 日内**；
  **不能按固定期限计算缴纳的，可以按次**申报缴纳。
- **纳税环节的分岔**（易错）：
  - 以自采**原矿直接销售** → 按**原矿**计征，在**销售**环节
  - 以自采**原矿加工为精矿（选矿）销售** → 按**选矿**计征，在**销售**环节；
    **原矿移送时不缴纳**
  - 以自采**原矿直接加工为非应税产品** → 在**原矿移送**环节计征
  - 以自采原矿加工的**精矿连续生产非应税产品** → 在**精矿移送**环节计征
  - ⚠ 以自采原矿**移送切割**生产矿产品，在移送环节**不征收**资源税

> ⚠ **账务视角**（**直接销售的计提；⚠ 自产自用「连续生产不缴、自用于其他方面视同销售（借生产成本·制造费用）」**）见 [[other-taxes-accounting]]。

> ⚠ **申报代办视角**（**同一批税种在「申报表填报」一侧的关注清单**）见 [[pbt-filing-requirements-and-materials]]、[[land-appreciation-tax-filing-judgment]]、[[property-and-urban-land-tax-filing]]、[[resource-and-environmental-tax-filing]]（**《涉税服务实务》第五章第三节批 6，2026-10-08**）——⚠ **三群（实体规则／第三章审核／第五章申报）并存互指、不合并**。
