# 非税收入

## Definition

非税收入（Non-tax Revenue）：**除税收以外**，由各级**国家机关、事业单位、代行政府职能的社会团体
及其他组织**依法利用**国家权力、政府信誉、国有资源（资产）所有者权益**等取得的**各项收入**。
⚠⚠ **不包括社会保险费、住房公积金**（指**计入缴存人个人账户**部分）。

⚠ **本章的分量来自一个体制变化**：根据**党的十九届三中全会**审议通过的
《深化党和国家机构改革方案》以及中共中央办公厅、国务院办公厅出台的
《**国税地税征管体制改革方案**》要求，**非税收入分步划转至税务部门征收**。
⚠⚠ **这意味着我国税务部门职责已从「征税为主」转向「税费皆重」**，
**税务部门的征管工作更广泛地融入国家治理的各个方面**。
—— ⚠ 这是教材本章的**落点**，也是理解本章为何被列入《税法（一）》的关键。

⚠ **本页是「非税收入」的总纲**：承载**第一节 概述**（概念与沿革／四个特点／**三种并列的分类**）。

## Key Points

### 一、概念与沿革（第一节 一）

- ⚠ **前身**：我国非税收入的**前身是「预算外收入」**；
  非税收入管理改革与**财政国库管理制度改革**紧密相连。
- **2004 年**：我国实施**财政国库管理制度改革**，**首次在国家正式文件中提出「非税收入」概念**——
  以此为标志，非税收入**开始取代预算外资金**成为财政管理中的重要概念。
- **2004 年**：财政部发布《**关于加强政府非税收入管理的通知**》（**财综〔2004〕53 号**），
  **首次界定了非税收入概念**。
- **2016 年**：财政部发布《**政府非税收入管理办法**》（**财税〔2016〕33 号**），
  对非税收入的**管理范围、设立、征收、票据、资金和监督管理**等方面进行了规定，
  ⚠ **这是非税收入管理「法制建设」上的重要一步**。
  ⚠⚠ **本章提及的非税收入以该管理办法的规定为准。**

### 二、⚠ 四个特点（第一节 一（二））

> ⚠ **记忆锚点（先记这一句）**：**相对税收的「强制性、无偿性、固定性」，
> 非税收入具有「灵活性、非普遍性、不稳定性、资金使用上的特定性」。**
> ⚠ **两个「性」字对仗：税收是「三性」，非税收入是「四性」。**

| # | 特点 | 含义 |
|---|---|---|
| **1** | **灵活性** | 表现为**形式多样性和时间、标准的灵活**——既可**按受益原则采取收费形式**，也可**以特定项目筹集资金而采取各种基金形式**；⚠ 有的非税收入是**为某一特定活动的需要而在特殊条件下出台的过渡性措施**，一旦完成既定目标，就「**功成身退**」，**具有明显的阶段性和时效性**；⚠ **征收标准及依据多样，地方政府可以根据不同时期本地的实际情况制定不同的标准** |
| **2** | **非普遍性** | ⚠ **总是和社会管理职能结合在一起，有特定的管理对象和征收对象**——以**行政事业性收费**为例，对提供服务和管理的部门来说，其**征收对象具有特定性**，**未接受服务或不在管辖范围的单位和个人不属于征收对象** |
| **3** | **不稳定性** | ⚠ **对特定行为和特定管理对象或在特定的经济形势下征收**，一旦特定行为、特定对象或特定经济条件变化，某项非税收入也会随之变化。⚠ 教材举**两例**：①**随着公民法治意识的增强、违法违规行为减少，相应的罚没收入就会减少**；②**油价调控风险准备金**——**只有在国际市场原油价格低于规定标准时才触发征收条件**，相关收入具有**高度的不确定性** |
| **4** | **资金使用上的特定性** | ⚠ **绝大多数非税收入的设立都有明确的目的**——如**可再生能源发展基金、核电站乏燃料处理处置基金**的相关办法中都明确规定**筹集的资金必须专款专用，实行项目管理** |

> ⚠ **第 1、3 两点的举例极易混**：**「功成身退」在「灵活性」下（讲的是「有期限」）；
> 「触发式征收」在「不稳定性」下（讲的是「有门槛」）。**
> ⚠ **一句话分清**：**灵活性讲「怎么收、收多久」；不稳定性讲「会不会收」。**

### 三、⚠⚠ 三种并列的分类（**本节最易混的一块**）

> ⚠⚠ **先记住三者的「维度」不同、彼此平行**：
> **按管理分类 = 12 类（最权威，出自《政府非税收入管理办法》）；
> 按预算管理分类 = 3 类（列报口径）；按征收依据分类 = 4 类（性质口径）。**
> ⚠ **三者不是层层细分，而是三个不同视角的平行切法**——
> ⚠ **考试常把某一类的名称混入另一类的选项里，故须分别记牢。**

#### （一）按政府对非税收入的管理分类——《政府非税收入管理办法》分为 **12 类**

| # | 类别 | 要点 |
|---|---|---|
| **1** | **行政事业性收费** | **国家机关、事业单位**等**根据法律法规的规定、按照国务院规定程序批准**，在**实施社会公共管理**以及**向公民、法人和其他组织提供特定公共服务**的过程中，**按照规定标准向特定对象**收取的费用 |
| **2** | **政府性基金** | **依照法律、行政法规的规定**，**在一定期限内**向**特定对象**征收、收取或者以其他方式筹集，**专项用于特定公共事业发展**的资金 |
| **3** | **罚没收入** | **执法机关**依据法律、法规和规章，对公民、法人和非法人组织**实施处罚**取得的**罚款、没收款、没收非法财物的变价收入**。⚠ 依《**罚没财物管理办法**》（**财税〔2020〕54 号**）：罚没财物含**罚款、罚金、违法所得、非法财物，没收的保证金、个人财产**等，包括**现金、有价票证、有价证券、动产、不动产和其他财产权利**等 |
| **4** | **国有资源（资产）有偿使用收入** | ⚠ **包括「国有资源有偿使用收入」与「国有资产有偿使用收入」两类，二者不同**——见 [[paid-use-of-state-owned-resources]] |
| **5** | **国有资本收益** | 国家以**所有者身份**依法取得的国有资本投资收益：①**应交利润**（国有独资企业按规定应当上交国家的利润）；②**国有股股利、股息**；③**国有产权转让收入**；④**企业清算收入**；⑤**其他国有资本收益** |
| **6** | **彩票公益金收入** | 按**规定比例**从**彩票发行销售收入**中提取，**专项用于社会福利、体育等社会公益事业**的资金。⚠ 按**政府性基金管理办法**纳入预算，实行「**收支两条线**」管理，**结余结转下年继续使用**，⚠⚠ **不得用于平衡财政一般预算** |
| **7** | **特许经营收入** | 国家依法**特许企业、组织或个人垄断经营某种产品或服务**获得的收入（⚠ 如**免税商品特许经营费**） |
| **8** | **中央银行收入** | 中央银行在**履行中央银行职能、开展各项业务经营**过程中取得的**全部收入**，包括**利息收入、业务收入、其他收入** |
| **9** | **以政府名义接受的捐赠收入** | 以**各级政府、国家机关、实行公务员管理的事业单位、代行政府职能的社会团体以及其他组织**名义接受的**非定向捐赠货币收入**。⚠⚠ **不包括**：**定向捐赠货币收入**、**实物捐赠收入**，以及**以不实行公务员管理的事业单位、不代行政府职能的社会团体、企业、个人或者其他民间组织名义**接受的捐赠收入 |
| **10** | **主管部门集中收入** | 主要指**国家机关、实行公务员管理的事业单位、代行政府职能的社会团体及其他组织集中所属事业单位收入**。⚠ **这部分收入必须经同级财政部门批准** |
| **11** | **政府收入的利息收入** | **税收和非税收入产生的利息收入**，**按照中国人民银行规定计息**，**统一纳入非税收入管理范围** |
| **12** | **其他非税收入** | 除上述 11 项之外的其他非税收入。⚠⚠ **不包括社会保险费、住房公积金**（指计入缴存个人账户部分） |

> ⚠ **「不包括社会保险费、住房公积金」这句话在教材中出现两次**——
> **一次在开头的「非税收入」定义处，一次在第 12 类「其他非税收入」处**。
> ⚠ **不是重复，而是「大前提」与「兜底项的边界」各说一遍。**

#### （二）按**预算管理**分类——**三本预算**

⚠ 从**预算列报**看，我国非税收入项目**分列在三本预算**之中：

| 预算 | 包含的项目 |
|---|---|
| ⚠ **一般公共预算中的非税收入** | ⚠ **专项收入**（⚠ **13 项**：**教育费附加收入、铀产品出售收入、三峡库区移民专项收入、场外核应急准备收入、地方教育附加收入、文化事业建设费收入、残疾人就业保障金收入、教育资金收入、农田水利建设资金收入、森林植被恢复费、水利建设专项收入、油价调控风险准备金收入**和**其他专项收入**）+ **行政事业性收费收入、罚没收入、国有资本经营收入、国有资源（资产）有偿使用收入、捐赠收入、政府住房基金收入和其他收入** |
| **政府性基金预算中的非税收入** | **政府性基金收入**和**专项债务对应项目专项收入**，如**农网还贷资金收入、铁路建设基金收入、国家重大水利工程建设基金收入**等 |
| ⚠ **国有资本经营预算中的非税收入** | ⚠ **「仅」包括国有资本经营收入**——主要是**利润收入、股利和股息收入、产权转让收入、清算收入、其他国有资本经营预算收入** |

#### （三）按**征收依据**分类——**四类**

| # | 依据 | 典型项目与判据 |
|---|---|---|
| **1** | **利用政治权力**取得 | **政府性基金、罚没收入、对政府颁发的证照按照成本收取的工本费**等。⚠ **判据**：**政府政治权力具有公共性和强制性**，根据法律规定，**公民和法人不得将国家赋予的权力当作攫取利益的资源或资产**，**行使政府权力所产生的收入只能是政府财政收入** |
| **2** | **利用国有财产**取得 | ⚠ **国有财产包括国有资产和国有资源**，政府利用国有财产取得的非税收入**主要是国有资源（资产）有偿使用收入** |
| **3** | **凭借政府信誉**取得 | ⚠ **政府信誉是一个国家的无形资产，本质上也具有国有资源的属性**——最常见的是**政府发行彩票收入和接受捐赠收入** |
| **4** | ⚠⚠ **提供准公共服务或公共产品**取得 | ⚠ **本类须再细分，且细分后的两类性质相反**：<br>政府提供的公共服务可分为两类——①**由政府直接生产并向社会和公众提供**；②**由政府向私人部门或第三方机构购买后向社会和公众提供**。<br>⚠ **通常政府提供的纯公共产品是免费的，只有对局部的特定对象提供准公共产品，才基于成本原则收取一定的价款**。<br>⚠⚠ **由此产生的两类收入性质不同**：<br>　**①政府向特定对象「出售其生产的」商品和服务取得的收入 → 属于政府非税收入**（如**公共停车泊位收入**）；<br>　**②政府将从私人部门或第三方机构「购买的」公共服务提供给特定主体而取得的收入 → 不属于政府非税收入** |

> ⚠⚠ **第 4 类的「一分为二」是全节最容易考的辨析**：
> **自己生产再卖的 → 是；买别人的来转手的 → 不是。**
> ⚠ **批判据是「政府是生产者还是转售者」**。
