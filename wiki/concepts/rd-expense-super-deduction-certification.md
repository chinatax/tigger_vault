# 研发费用加计扣除鉴证服务

## Definition

⚠ **本页是《涉税服务实务》第六章《涉税鉴证与纳税情况审查服务》第三节「研发费用加计扣除鉴证服务」**
（书页 371 中–373 中，txt 376 中–378 中）。

> ⚠ **教材原句（业务定义）**：「**研发费用加计扣除鉴证**，是指鉴证人接受委托人委托，依照税收法律法规
> 和相关标准，按照一定的程序和方法，对被鉴证人的**研发费用税前加计扣除的真实性、合法性、合理性和
> 准确性**进行鉴定和证明，并出具鉴证报告的活动」。

⚠⚠ **四个评价维度的界定（教材原句）**：

| ⚠ 维度 | ⚠ 界定 |
|---|---|
| **真实** | **被鉴证人开发新技术、新产品、新工艺的研发活动，以及为获得创新性、创意性、突破性的产品进行创意设计活动及发生的费用支出是客观真实的** |
| **合法** | **被鉴证人发生的研发费用和相关费用支出「核算符合会计准则和相关会计规范」，研发费用和相关费用支出「项目归集方法、金额确定符合税收规定」** |
| **合理** | **被鉴证人「研发项目和创意设计活动合理、符合加计扣除的条件」，费用支出在「不同项目间的归集和分配合理」** |
| **准确** | **费用支出「会计处理和税务处理金额准确无误」** |

⚠ **主体与方式**：**研发费用加计扣除的行为主体是「被鉴证人」**，**属于被鉴证人在企业所得税预缴申报和
汇算清缴时享受的税收优惠事项**，⚠⚠ **应采取「「自行判别、申报享受、相关资料留存备查」」的方式**。

⚠ **边界**：
- ⚠ **通用程序**见 [[tax-certification-basic-provisions]]；
- ⚠ **研发费用加计扣除的实体规则**见 [[research-and-development-expense-super-deduction]]、
  [[cit-audit-research-and-development-expense]]（**第三章审核口径**）；
  **A107012 的 2025 年修订**见 [[cit-filing-return-preparation]]；
- ⚠ **鉴证事项的落点**：**核心是「纳税申报表及相关附表的填写，以及相关资料的整理留存」**。

## Key Points

### 一、⚠ 关注事项的总纲

> ⚠ **教材原句**：**「由于研发费用加计扣除的基础信息来自被鉴证人「日常支出发生的会计核算」，
> 加计扣除过程和结果体现在「研发支出辅助账、辅助账汇总表以及年度纳税申报表主表和相关附表中」，
> 其鉴证业务也应该以「年度纳税申报表主表及其附表，以及研发支出的会计核算的账簿、凭证资料」为核心」**。

### 二、⚠⚠ 「关注事项」（**六项**）

| # | ⚠ 关注项 | ⚠ 内容（**教材原句要点**） |
|---|---|---|
| **（一）** | ⚠⚠ **所属行业是否属于「负面清单行业」** | **是否属于「烟草制造业、住宿和餐饮业、批发和零售业、房地产业、租赁和商务服务业、娱乐业」这「六类」不适用税前加计扣除政策的负面清单行业**——⚠ **「如不属于负面清单行业，则可以继续开展研发费用加计扣除鉴证服务」**（**即这是一个「准入前置判断」**） |
| **（二）** | ⚠ **研发活动与创意设计活动「是否客观真实、是否符合税法规定的加计扣除条件」** | **先判断「是否属于不适用税前加计扣除政策的活动」，如果不属于，则需进一步判断被鉴证人**「是否实际开展了相关活动」；**相关活动是否属于**「为获得**科学与技术新知识**，**创造性运用**科学技术新知识，或**实质性改进**技术、产品（服务）、工艺而持续进行的具有明确目标的**系统性活动**」；⚠⚠ **是否同时符合「有明确创新目标、有系统组织形式和研发结果不确定」三个条件** |
| **（三）** | **会计处理是否规范** | **研发支出会计处理是否符合会计规范；是否按要求设置「研发支出辅助账和辅助账汇总表」；费用支出在不同项目间的归集和分配是否合理** |
| **（四）** | ⚠ **自主研发项目** | **基础资料是否齐全**；**研发活动涉及的**「人员、仪器、设备、无形资产」**是否有必要的「工时记录和工作量记录」**，**是否有按工时或其他合理方法在多个研发项目之间分摊的说明**；**直接投入费用、折旧费用、无形资产摊销费用、新产品设计费、新工艺规程制定费、新药研制的临床试验费、勘探开发技术的现场试验费和其他相关费用**的项目、金额是否真实合理准确 |
| **（五）** | ⚠⚠ **委托研发项目** | **基础资料是否齐全；是否按「实际发生额的 80%」计算加计扣除**；⚠ **「委托关联方开展研发活动的，是否取得受托方研发过程中实际发生的研发项目费用支出明细情况，研发费用的定价是否符合「独立交易原则」」**；⚠ **「委托「境外」进行研发活动签订的技术开发合同，被鉴证人是否到「科技行政主管部门」进行登记，是否有「银行支付凭证和受托方开具的收款凭据」」** |
| **（六）** | ⚠ **合作开发、集中开发项目** | **基础资料是否齐全**；**合作开发项目是否按「各自承担的研发费用」计算加计扣除**；⚠ **集中研发项目发生的费用是否按「权利和义务相一致、费用支出和收益分享相配比」的原则，合理确定研发费用的分摊方法，在受益集团成员企业间进行分摊** |

> ⚠ **教材明示的工作方法**：**「鉴证人可以按照被鉴证人的《研发费用加计扣除优惠明细表》（A107012）
> 的内容和顺序，根据研发支出辅助账及相关会计凭证，对上述项目进行分析判断」**。

### 三、⚠ 鉴证证据

⚠ **取证方式两类**（**同通用途径**）：**直接从委托人／被鉴证人提供的鉴证材料中取证**（**例如 A107012、
研发支出辅助账及其汇总表、财务报表、会计账簿和凭证**）；**或采取审阅、查阅、检查和盘点、询问或函证、
记录等方法取得**（**例如「合同、发票、折旧计算表、工资计算表」等原始凭证，相关人员的陈述和笔录，
科技行政主管部门对项目出具的鉴定意见等**）。

#### ⚠⚠ 「留存备查资料」＝**九项基本鉴证证据（教材逐项列出）**

1. **自主、委托、合作研究开发项目「计划书」和企业有权部门关于自主、委托、合作研究开发项目「立项的决议文件」**；
2. **自主、委托、合作研究开发「专门机构或项目组的编制情况和研发人员名单」**；
3. ⚠ **经「科技行政主管部门登记」的委托、合作研究开发项目的「合同」**；
4. **从事研发活动的人员（包括外聘人员）和用于研发活动的仪器、设备、无形资产的「费用分配说明」
   （包括工作使用情况记录及费用分配计算证据材料）**；
5. **集中研发项目「研发费决算表、集中研发项目费用分摊明细情况表和实际分享收益比例」等资料**；
6. ⚠ **「研发支出」辅助账及汇总表**；
7. ⚠ **「地市级（含）以上科技行政主管部门出具的鉴定意见」（如果取得）**；
8. **创意设计活动相关合同**；
9. **创意设计活动相关费用核算情况的说明**。

### 四、鉴证报告

⚠ **发表结论时应关注**：**被鉴证人研发项目和活动是否真实合理、会计处理和税务处理是否合理合法准确，
作出上述判断的证据是否确实充分，适用法律依据是否准确**；
⚠ **「应以工作底稿为基础，按照《涉税鉴证业务指引（试行）》要求的内容，编制研发费用加计扣除鉴证报告」**——
**「报告的核心是对被鉴证人研发费用加计扣除的「合理性、合法性和准确性」予以评价」**
（⚠ **注意：本目报告的核心评价维度是「三性」，不含「真实性」——真实性已在「业务定义」中作为前置维度**）；
**报告还应按要求进行信息沟通、签字盖章**。
