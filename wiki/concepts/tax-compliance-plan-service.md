# 税务合规计划服务（特点·内容·方法·实施步骤）

## Definition

⚠ **本页是《涉税服务实务》第七章《税务咨询服务》第三节「税务合规计划服务」之
「一、服务及其特点」「二、服务的内容及基本方法」「三、服务的实施步骤」**
（书页 423 中–428 中，txt 428 中–433 中）。
⚠ **该节的「四、案例分析」另立一页**，见 [[tax-compliance-plan-case-investment-vehicle]]（**同批**）。

> ⚠ **教材原句（定义）**：「**税务合规计划**，是指涉税专业服务机构接受委托人委托，指派涉税服务人员
> **为满足委托人特定目标**，依据国家税收政策及其他相关法律、法规和相关规定，提供的
> **「税务合规方案或纳税计划」」**。

⚠ **边界**：**一般税务咨询**见 [[general-tax-consulting-scope-and-methods]] 等（**批 1、批 2**）；
**专业税务顾问**见 [[professional-tax-advisor-service]]（**同批**）；
**第七章总纲／枢纽页**见 [[tax-consulting-service]]。

## Key Points

### 一、⚠ 「税务合规计划服务及其特点」（**四个特点**）

| # | ⚠ 特点 | ⚠ 内容（**教材原句**） |
|---|---|---|
| **1** | ⚠⚠ **「合法性」** | **「税务合规计划方案或纳税计划都应遵循税收法律法规，任何通过「违背税收法律法规或者钻税收法律的空子」实现减轻或逃避的方案，都不是真正意义的税务合规计划方案」**；⚠⚠ **「合法性是税务合规计划服务的「首要考虑因素」，也是税务合规计划服务的「底线」」** |
| **2** | ⚠ **「策划性」**（**两层含义**） | **① 「税务合规计划的「事前性」」**——**「是指税务合规计划先于涉税事项发生之前的『谋定』，是满足委托人特定目标而考虑税收因素的事先规划、设计安排，「这与涉税事项已经发生后寻求解决方法或纠错措施的其他税务咨询服务有着显著差异」」**；**② 「税务合规计划的「选优性」」**——**「指税务合规计划实质上是从多个涉税处理、实现路径等备选方案中，综合考虑各种因素，权衡利弊后，「选择与委托人特定目的最接近的方案」」** |
| **3** | ⚠⚠ **「目的性」** | **「税务合规计划的目的是满足委托人的特定目的，税务合规计划虽然将税收作为重要因素进行考虑，「但不一定以纳税最少或者减轻税收负担作为唯一目标」」**；⚠ **「大多的税务合规计划是基于税收负担最轻的『节税』，但当「税负最低的方案与委托人整体利益、长远规划或者其他特定目的相矛盾时，税负最低方案未必是税务合规计划的最优方案」」** |
| **4** | 「适用性和可操作性」 | **「税务合规计划必须具有适用性和可操作性……必须充分考虑委托人所处「发展阶段、行业地位、发展前景」等各种因素，作出适用于委托人的税收安排或设计，同时也要考虑方案「切实可行，没有重大的实施障碍」」** |

### 二、⚠ 「服务的内容及基本方法」

#### 1. 服务内容（**五个方面，按委托人「特定目的」分**）

**（1）「战略规划」税务合规计划**——**在委托人战略发展和重大经营调整中，充分考虑税收因素**；
**（2）「经营活动」税务合规计划**——**针对日常经营事项的税务处理或日常经营模式变化**；
**（3）「企业重组」税务合规计划**——**对企业收购、分立、合并等企业重组**；
**（4）「投融资」税务合规计划**——**对委托人投资或融资方案，从投融资整体过程多角度考虑**；
**（5）「其他事项」税务合规计划**——**委托人开展其他业务或实施的特定交易事项**。

#### 2. ⚠⚠ 基本方法（**八种**）

> ⚠ **教材原句（本目的总纲）**：**「在不受其他条件制约的情况下，税务合规计划是选择税收负担较轻的方案。
> 因此，税务合规计划的核心是「减轻税收负担」……可以降低税收负担的税务合规计划方法，主要有以下八种」**。

| # | ⚠ 方法 | ⚠ 定义（**教材原句**） |
|---|---|---|
| **（1）** | **不予征税方法** | **「选择国家税收法律法规和规章规定「不予征税」的经营、投资、理财等活动方案减轻税收负担的方法」** |
| **（2）** | **减免税方法** | **「选择……规定可以享受「减税或免税」优惠的经营、投资、理财等活动方案」** |
| **（3）** | **税率或征收率差异方法** | **「根据……规定的「税率差异」，选择「税率或征收率较低」的经营、投资、理财等活动方案」** |
| **（4）** | ⚠ **分割方法** | **「选择能使「计税依据进行分割」的经营、投资、理财等活动方案」**——⚠ **「实现或是「不同税负、税种的计税依据相分离」；或是「分解为不同纳税人或征税对象」，「增大不同计税依据扣除的额度或频度」」** |
| **（5）** | **扣除方法** | **「使……活动的计税依据中「尽量增加可以扣除的项目或金额」」** |
| **（6）** | **抵免方法** | **「使……活动的「已纳税额或相应支出」，在其「应纳税额中予以抵扣」」** |
| **（7）** | **延期纳税方法** | **「将……活动的「当期应纳税额延期缴纳」」** |
| **（8）** | **退税方法** | **「使……活动的相关税款「得到退还」的方法」** |

> ⚠ **教材明示**：**「各种税务合规计划方法也「不是彼此孤立和矛盾的，有时应相互配合、综合运用」」**。

### 三、⚠⚠ 「税务合规计划服务的实施步骤」

> ⚠ **教材原句（七步与五个核心）**：**「实施步骤包括「了解业务目标、制订业务计划、收集项目资料、
> 确定法律依据、测算数据结果、制定合规计划方案、方案综合辩证分析」。其中，
> 「收集项目资料、确定法律依据、测算数据结果、制定合规计划方案、方案综合辩证分析」
> 是实施税务合规计划服务的「核心步骤」」**。

#### （一）收集项目资料

- ⚠ **收集方式**：**「问卷调查、现场访谈与资料采集等方式」**；
- ⚠ **数据信息内容**：**「委托人财务数据、内部管理信息、相关政策法规、行业情况、实操惯例和
  「风险接受程度」等内容」**；
- ⚠⚠ **按「五类」分述「重点关注的要素」**：

| ⚠ 类型 | ⚠ 重点关注（**教材原句**） |
|---|---|
| **战略规划** | **战略目标及策略、组织结构及主营业务**；**收集行业情况、主营业务商业模式、相关政策法规** |
| **经营活动** | **需合规计划的经营活动商业模式、执行部门、活动流程**，收集相关数据 |
| **企业重组** | **拟重组方式、所涉资产产权归属、资产性质、资产构成、交易对价、交易方式、账面价值、市场价值以及交易对象** |
| **融资** | **筹资成本、合法性及其对经营事项的影响** |
| **投资** | **拟交易股权归属、股权性质（现金、实物、无形资产等）、交易对价、交易方式、股权归属公司经营状况、拟交易股权比重、交易对象** |

⚠ **复核与确认**：**「涉税服务人员对所收集的数据及信息进行初步复核及整理，确保项目数据及信息与
服务需求紧密契合，全面准确」**；**「对委托人情况理解不同而导致的分歧，应重新调查或与委托人进行
讨论、确认」**；**「对涉及委托人重要事项及重大经济利益等的资料，可要求委托人签字和盖章确认」**。

#### （二）⚠ 确定法律依据（**政策法规解读的三项内容**）

**（1）「解读相关政策法规内容」**——**「了解、分析有关政策法规的「出台背景、执行对象、执行条件
以及执行流程」」**；
**（2）「分析法规符合性」**——**「对政策法规进行「细化分层」，确定各层政策法规的法定条件，
并提取与服务需求相关的内容进行对照，「分析匹配点与差异点」」**；
**（3）「分析类似案例」**——**「根据案例背景、方案适用条件、执行过程及财税管理部门判定结果等信息，
寻找类似的案例，并与委托人的数据信息及服务需求进行差异分析」**。

> ⚠⚠ **一处与第二节的口径差异（本页要点）**：⚠ **对相关税收法律法规理解不同所导致的分歧**——
> **第二节（专业税务顾问）作「应与「发文机关」沟通确认」**；
> ⚠ **本节的表述是「应向「税务机关」提请确认」，且「在与税务机关进行沟通前，「应告知委托人」，
> 沟通时应注意「对委托人信息保密」」**——⚠ **两处并列照录、不合并**。

#### （三）⚠⚠ 「制定方案和测算数据」——**本目是「税务合规计划的核心内容」**

**1. 「方案制定」**——**「根据委托人的数据信息，结合政策解读结论，「从多方面设计制定」税务合规计划方案」**；
⚠⚠ **「税务合规计划方案应尽可能详细地「分步分点设计」，并须明确提出方案的「前置条件、政策依据、
步骤顺序、实操要领」等」**；⚠ **五类方案各自「重点关注的要素」**：

| ⚠ 类型 | ⚠ 重点关注（**教材原句**） |
|---|---|
| **战略规划** | **战略目标实现路径、营销战略、内部管理模式等要素** |
| **经营活动** | **销售模式、收款模式、货物流转路径、销售目标等要素** |
| **企业重组** | **重组模式、资产构成、交易路径等要素** |
| **融资** | **融资规模、融资方式、融资对象、融资成本等要素** |
| **投资** | **股权原始构成、交易路径、交易对象等要素** |

**2. ⚠⚠ 「数据测算」**——**「设置评价方案的「试算指标、试算参数和试算口径」，形成测算结果，
以便对各个方案进行「量化评价」」**；**「在试算过程中应与委托人沟通试算指标、计算方法、
试算参数与口径，并按照各项对委托人的重要程度有侧重地进行试算与分析」**：
**（1）设置试算指标**——**「应体现税务合规计划方案各方面的成本、效益等，包括对「税收负担、
资金价值、资产与负债变化、实施成本、税务合规计划效益」等」**；
**（2）设置试算参数与口径**——⚠ **「试算参数与口径设置应具有「可比性」，若针对特定税务合规计划方案
采取不同的参数与口径，「需详细提示原因及依据」」**；
**（3）进行试算并形成试算结果**——⚠ **「为试算结果制定「清晰简练的表格样式」，以便委托人可以直观了解
试算结果」**。

#### （四）⚠ 「方案综合辩证分析」（**五个方面**）

> ⚠ **教材原句（本目的定位）**：**「辩证分析是涉税服务人员从多维度评价和分析税务合规计划方案的过程，
> 「体现服务成果的专业、客观及谨慎性」，通过辩证方法展示不同税务合规计划方案的「优势及不足」」**。

**1. 「分析政策适用性」**——**「评价各个方案的适用性，分析其「适用差距及贴合方法」，突出税收政策
适用性的「风险评价」」**；
**2. 「比较试算结果」**——**「以各种试算指标比较不同方案的优劣，科学评价「资金的时间价值、
财务数据与税收成本的关系」」**；
**3. 「比较管理及操作成本」**——**「分析各个方案对委托人的「财务管理、其他业务管理、操作习惯、
内部考核」等事项造成的影响，合理预估各个方案的管理成本和操作难度」**；
**4. 「分析行业特性及业务模式」**——**「从委托人所在行业的经营特点、竞争形势、发展趋势等方面」**；
**5. ⚠ 「分析委托人风险接受程度」**——**「了解、分析委托人「管理层」的风险接受程度，
对方案中存在「政策法规适合性风险」的内容作出评价和提醒，「并以此作为实施取向的重要依据」」**。

⚠ **收尾动作**：**「对综合辩证分析的结果进行归纳整理后，与委托人进行充分的沟通，确保结果与委托人
目标的一致性，「并经委托人认可」」**。

#### （五）⚠ 「确定税务合规计划的关注重点」（**五类**）

**（1）战略规划**→**对分析对象整体影响，方案的不利之处是否导致战略方向偏离或影响现行经营策略**；
**（2）经营活动**→**企业市场、管理成本等影响**；
**（3）企业重组**→**方案执行难度、主管部门意见、与重组目标是否偏离等**；
**（4）融资**→**融资可行性、抵押质押对融资的影响等**；
**（5）投资**→**方案执行难度、对未来二次交易影响等**。

#### （六）⚠⚠ 「税务合规计划服务报告」

⚠ **教材原句**：**「业务成果通常以书面形式的业务报告体现，包括出具「税务合规计划服务报告、
方案分析文档、方案试算底稿」等。其中「税务合规计划服务报告」是综合体现税务合规计划服务成果的
书面报告」**。

⚠ **报告的基本要素**：**「封面、前言、目录、背景、税务合规计划方案、分析比较内容、实施取向以及附件」**；
⚠ **主要内容（四项）**：
**1. 「委托人情况的概括」**——**「提炼出与服务内容直接相关的委托人情况，阐述服务报告的「起草原因和
所要达到的具体目的」」**；
**2. 「与实现税务合规计划有关的政策法规」**——**「列明与服务内容相关政策法规条款，政策条款繁多时
可以对其内容进行归纳后列示」**；
**3. 「提出税务合规计划方案」**——**「列示不同方案下的「主要分析过程、方案实施步骤、优势及不足评价」，
并提出「实施取向」」**；
**4. ⚠ 「风险提示」**——**「对税务合规计划方案的内容、实施取向以及分析过程「列出风险提示」，
提醒报告使用人可能存在的风险和不确定性」**。

## Contradictions

⚠ **本页为新增来源（《涉税服务实务》教材第七章批 3，2026-10-08）**，暂无跨来源分歧。

⚠⚠ **一处「教材前后两节的口径差异」已并列照录（不作合并、不判优劣）**：
**「对相关税收法律法规理解不同所导致的分歧」的处置**——
**第二节（专业税务顾问·专项税务咨询）作「应与「发文机关」沟通确认」**；
**第三节（税务合规计划·确定法律依据）作「应向「税务机关」提请确认」，并加了两条程序约束
（「沟通前应告知委托人」「沟通时应注意对委托人信息保密」）**。
⚠ **教材未说明二者关系（是「同一动作的不同表述」还是「两套并行做法」），**故两处并列照录，
引用时须核对原文**。
