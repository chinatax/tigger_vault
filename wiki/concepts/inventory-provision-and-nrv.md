# 存货跌价准备与可变现净值

## Definition

存货跌价准备与可变现净值（Inventory Provision and NRV）：期末存货按**成本与可变现净值孰低**计量，当可变现净值低于成本时计提跌价准备。

其难点不在公式而在**估计售价的选取**——有合同部分必须用合同价格、无合同部分用市场价格，两者**不可合并计算**；材料存货还须先测试其所生产的产品是否减值。

## Key Points

- **可变现净值的确定**（第 210 题）：
  - 可变现净值 = 存货的**估计售价** − **至完工时估计将要发生的成本** − 估计的**销售费用** − **相关税费**
  - ⚠ 可变现净值**不是**「资产负债表日的售价」，而是上述净额
- **估计售价的选取**（第 187、190、201、229 题，⚠ 最高频的陷阱）：
  - **有合同部分**：以**合同价格**为基础计算可变现净值
  - **无合同部分**：以**市场价格**为基础计算可变现净值
  - ⚠ 两者必须**分别计算、不可合并**——常见错法是先用合同价算全部、再用市价算全部
  - ⚠ **为执行销售合同**而持有的存货，以**产品的合同价格**作为可变现净值的计算基础
  - 采用**计划成本法**核算时，与可变现净值比较的成本应为**调整后的实际成本**
- **材料存货的减值**（第 187、200、229 题）：
  - 材料**专门用于生产**某产品时，应**先判断所生产的产品**是否减值
  - 产品**未**减值 → 材料按**成本**计量，**不计提**跌价准备
  - 产品**已**减值 → 材料按**可变现净值**计量：
    可变现净值 = **产品的估计售价** − 至完工估计将要发生的成本 − 估计的销售费用及相关税费
    - ⚠ 材料的可变现净值**不是**材料自身的市价减去销售材料的税费（除非材料本身用于出售）
- **减值迹象**（第 214 题）：
  - ✅ ①**生产制造**存货所产生的经济利益**流出大于**销售存货产生的经济利益**流入**；
    ②**由于市场需求发生变化**导致存货市场价格低于存货成本；
    ③因**消费者偏好改变**而使市场需求发生变化，导致市场价格逐渐下跌
  - ⚠ 存货市价**波动很大、近期下跌**本身**不构成**减值迹象——须**持续下跌**且在可预见的未来**无回升希望**
  - ⚠ 「市场利率提高导致可收回金额大幅度降低」是**固定资产、无形资产**的减值迹象，**不是**存货的
- **计提与转回**：
  - 计提：对可变现净值低于成本的差额，计入**资产减值损失**，贷记存货跌价准备
  - **转回条件**（须**同时**满足，第 216 题）：
    ①期末存货的可变现净值**高于**成本；②**以前减记存货价值的影响因素已经消失**
    → 在原已计提的跌价准备金额内转回
- **跌价准备的结转与处置**（第 216 题）：
  - **结转销售成本**时，已计提的存货跌价准备**冲减主营业务成本**
  - **非货币性资产交换**换出存货而同时结转的已计提跌价准备，**不冲减**当期资产减值损失
  - **存货盘亏**时，已计提的存货跌价准备**转入待处理财产损溢**
- **确定可变现净值应考虑的因素**（第 218 题）：
  - 以取得的确凿证据为基础，并考虑**持有存货的目的**、**资产负债表日后事项**的影响
  - ⚠ **不包括**取得存货的成本、存货的计划成本
- **三种比较方法**（第 227 题）：
  - **单项比较法**：逐项比较成本与可变现净值，每项取较低数 → 期末价值**最低**
  - **分类比较法**：按存货**类别**比较，每类取较低数 → 居中
  - **总额比较法**：以全部存货的**总成本**与**可变现净值总额**比较，取较低数 → 期末价值**最高**
  - ⚠ 三者的关系：单项 ≤ 分类 ≤ 总额
