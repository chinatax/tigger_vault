# 行政行为

## Definition

行政行为（Administrative Act）：通常指「**行政法律行为**」，即**行政主体实施行政管理和服务活动、
行使行政职权或履行行政服务职能过程中所作出的具有法律意义的、旨在产生某种行政法律效果的行为**。

⚠ 它是行政法的**核心范畴**——行政法的四个侧面（设定权力、规范运用、监督、补救）最终都落到
「行政行为」这个对象上。⚠ 本页覆盖**基本理论**（特征、效力、分类、合法要件、无效撤销废止）
与**两类形态**（抽象行政行为、具体行政行为的诸类型）。

## Key Points

### 一、⚠ 行政行为的五个特征

1. ⚠ **从属法律性** —— ⚠ **行政行为不同于立法行为**：**立法行为是创制法律规范，
   行政行为是执行法律规范**；行政机关虽也可创制行政性规范，但**行政性规范只是从属性规范，
   是为执行法律规范而制定的规范**
2. ⚠ **裁量性** —— ⚠ 立法机关在立法时会给行政机关设定**裁量空间**；
   这是由它的**权力因素（行政裁量权）**的特点所决定的
3. ⚠ **单方意志性** —— ⚠ 行政主体在授权范围内即可**自行决定和直接实施**，
   **一般都无须与行政相对人协商或征得其同意，行政协议行为除外**
   - ⚠ **依申请的行政行为也具单方意志性**：虽以相对人申请为前提，
     但**行政主体是否满足申请，却不取决于相对人的请求**——行政主体**无须与相对人协商**，
     而是根据法律规定的标准和条件，**依法自行决定**是否作出某种行为
4. ⚠ **效力先定性** —— ⚠ **行政行为一经作出，就事先假定其符合法律规定**，
   在被国家有权机关依法宣布为违法无效之前，**对行政机关本身和行政相对人以及其他国家机关
   具有约束力**，任何个人或团体都必须遵守和服从
   - ⚠ **是事先假定，并不意味着行政行为必定正确、合法、不可否定**
   - ⚠ 这种效力先定性**源于行政权行使的目的，是维护公共秩序和公共利益**
5. ⚠ **强制性** —— 以**国家强制力**作为实施的保障；
   ⚠ **但这并不是说所有的行政行为都必须强制实施**，
   只是说行政行为具有**以国家强制力作后盾**以保证其得以实施的性质

### 二、行政行为的内容与四种效力

**（一）四项内容**：①**赋予权益或科以义务**；②**剥夺权益或免除义务**；
③**变更法律地位**；④**确认法律事实与法律地位**

**（二）⚠⚠ 四种效力（易混，注意区分点）**：

| 效力 | 内涵 | 区分要点 |
|---|---|---|
| ⚠ **确定力** | **有效成立的行政行为具有不可争辩力、不可变更性**，即**非依法不得随意变更或撤销** | ⚠ **对行政主体**：非依法定理由和程序**不得随意改变其行为内容，或就同一事项重新作出行为**；⚠ **对行政相对人**：**不得否认行政行为的内容或随意改变行为内容**；⚠ **还意味着除行政主体和相对人以外的国家机关、社会组织和公民，都不得否认或拒绝行政行为所确认的事实和法律关系**<br>⚠ **但不可变更力并不意味着不能变更**——基于**法定事由并经过法定程序**，行政行为**可以依法变更** |
| ⚠ **拘束力** | 行政行为**成立后即对行政主体和行政相对人产生法律上的约束力**，有关人员或组织**必须遵守、服从** | —— |
| ⚠ **公定力** | ⚠ **不论合法还是违法，都推定为合法有效**，相关当事人都应当**先予以遵守和服从** | ⚠ **这是行政效率原则的要求** |
| ⚠ **执行力** | 行政行为**生效后，行政主体依法有权采取一定手段，使行政行为的内容得以实现** | ⚠ 在相对人**拒不履行义务**的情况下，行政行为需要予以**强制执行**；⚠ **但并不是行政行为成立后就必须立即予以执行** |

### 三、⚠ 行政行为的九种分类（八组标准 + 一组特殊）

| 分类 | 标准 | 要点 |
|---|---|---|
| ⚠ **内部 vs 外部** | **适用与效力作用的对象范围** | **内部**：只对**行政组织内部**产生法律效力（如**行政处分**）；**外部**：针对**公民、法人或其他组织**（如**行政处罚、行政强制、行政许可**） |
| ⚠ **抽象 vs 具体** | **对象是否特定** | **抽象**：以**不特定的人或事**为管理对象，制定**具有普遍约束力的规范性文件**（如**税务机关制定税务规范性文件**）；**具体**：针对**特定的人或事**，⚠ **最突出的特点就是对象的特定化和具体化** |
| ⚠ **羁束 vs 裁量** | **受法律规范拘束的程度** | **羁束**：法律法规对**范围、条件、标准、方式、程序**作了**较详细、具体、明确**规定（如税务机关**只能根据法定的征税范围、征税对象以及税种、税目、税率**进行税收征管，**一般没有选择、裁量的余地**）；**裁量**：法律法规仅对**行为目的、行为范围**作原则性规定，将**具体条件、标准、幅度、对象、范围、方式及期限**留给行政主体自行选择决定——⚠ **可以是决定裁量，也可以是效果裁量**（如税务机关作出**行政处罚特别是罚款、核定应纳税额、确定应税所得率**） |
| ⚠ **依职权 vs 依申请** | **是否可以主动作出** | **依职权**：**无须相对人申请**而主动实施（如**行政机关主动公开政府信息、税务机关的征税行为、行政强制行为以及国有土地上房屋征收行为**）；**依申请**：**必须根据相对人申请**才能实施（如**颁发营业执照、颁发经营许可证、依申请公开政府信息**） |
| ⚠ **单方 vs 双方** | **成立时参与意思表示的当事人数目** | **单方**：通过**自己单方意思表示**，无须征得相对人同意（如**行政强制、行政许可、行政处罚**）；**双方**：与相对人**协商达成一致**而成立（如**行政委托、行政协议**）——⚠ **相对人的同意是双方行政行为有效成立的必备条件** |
| ⚠ **要式 vs 非要式** | **是否应当具备一定的法定形式** | **要式**：**必须具备某种法定形式或遵守法定程序**才能成立生效（如税务机关作出行政复议决定应当以《**行政复议决定书**》的形式作出并**加盖该税务机关印章**，**不得以《行政复议事项告知书》等方式作出或者代替**；**强制执行决定应当以书面形式**作出并载明法定事项）；**非要式**：**无须一定方式和程序**（如公安机关对**醉酒驾驶机动车的人采取强制约束**的行为） |
| ⚠ **作为 vs 不作为** | **作为方式表现** | **作为**：以**积极作为**的方式表现（如**行政奖励、行政强制**）；**不作为**：以**消极不作为**的方式表现 |
| ⚠ **授益 vs 损益** | **对相对人是否有利** | **授益**：为相对人**设定权益或免除义务**（如**行政许可、行政给付、行政奖励以及税务机关依法确认或决定减税免税**）；**损益**（也称**负担行政行为／不利行政行为／侵益行政行为**）：对相对人**不利或以某种方式侵夺、减损其权利或利益**<br>⚠ **区分的意义**：由于两者对相对人产生**不同的影响**，故在**撤销与废止时有不同的处理办法** |
| ⚠ **行政立法 vs 行政执法 vs 行政司法** | **行政权作用的表现方式和所形成的法律关系** | **立法**：制定**行政法规、规章以及其他规范性文件**；**执法**：**直接影响**相对人权利义务，或对权利义务的**行使与履行情况监督检查**——包括**行政征收、行政给付、行政许可、行政确认、行政奖励、行政处罚、行政强制、行政监督检查**等；**司法**：作为**第三方**按**准司法程序**审理特定行政争议或民事争议案件并作出裁决——包括**行政调解、行政裁决、行政仲裁、行政复议**等 |

**⚠⚠ 另外两种比较特殊的行政行为（都属于行政诉讼排除范围）**：

- ⚠ **行政终局裁决行为**：**法律规定由行政机关最终裁决**的行政行为
  —— ⚠ **确定了行政机关对于法律规定的特定领域的事项具有最终决定权，而不是由法院作出最终决定**；
  ⚠ **行政相对人不得向法院起诉；法院无权对其合法性予以审查**
- ⚠ **国家行为**：涉及**国家重大利益、具有高度政治性**的行为，一般与**国家的主权**有关
  （如**国防、外交行为**）
  —— ⚠ **相对人不得因不服国家行为而起诉**；
  ⚠ **如因国家行为遭受损失，依法通过国家补偿的途径得到救济**

### 四、⚠ 行政行为的四个合法要件

1. ⚠ **行政行为的主体应当合法**
2. ⚠ **行政行为应当在行政主体的权限范围内实施**
3. ⚠ **行政行为的内容应当合法、适当**
4. ⚠ **行政行为应当符合法定程序**

> ⚠ **提示（与复议、诉讼的衔接）**：从**行政复议审查和司法审查**角度看，
> 行政行为最终是**得到支持**，还是被**撤销、变更、确认违法或者无效**，
> 主要取决于几个方面：**事实证据是否确凿、是否正确适用法律法规等、是否符合法定程序、
> 是否存在超越行政职权或者滥用行政职权以及有无明显不当**。
> ⚠ 实际上，**行政复议法和行政诉讼法的相关规定为判定行政行为是否合法提供了基本标准**。

### 五、⚠⚠ 行政行为的无效、撤销与废止（本考点的经典三分）

| | **无效** | **撤销** | **废止** |
|---|---|---|---|
| **触发情形** | ⚠ **存在重大且明显违法**的 → 属于无效情形 | ⚠ **三种情形**：①**行政行为在合法要件方面有瑕疵**（合法的行政行为具备**主体合法、权限合法、内容合法、程序合法**四要素，**任何行政行为如缺损其中一个或数个要件**即属可撤销）；②**行政行为明显不当**；③**行政行为没有事实依据** | ⚠ **三种情形**：①**所依据的法律、法规、规章等经有权机关修改、废止或撤销**，据此作出的行为如继续实施则与新的法律法规规章政策相抵触，**或因失去其作出依据而废止**；②**所依据的客观情况发生重大变化**，原行为的继续存在**将有损公共利益，同时可能会给公民、法人或者其他组织造成财产损失**；③行政行为**已完成既定的目标、任务，实现了国家的行政管理目的**，从而**没有继续存在的必要** |
| ⚠ **效力起点** | ⚠ **自始无效** | ⚠ **只有在被撤销后才失去效力**（不同于无效） | ⚠ **从行为废止之日起失效** |
| ⚠ **法律后果** | —— | ⚠ **原则上可追溯到行政行为作出之日**；根据法律规定**公共利益需要**或当事人**是否存在过错**等情况，也可以**自被撤销之日起失去法律效力**；⚠ **当事人在撤销决定作出之前要受该行政行为的约束** | ⚠ **行政主体在行为被废止之前通过相应行为已给予相对人的权益不再收回，也不再给予**；⚠ **相对人依原行政行为已履行的义务不能要求行政机关返还利益，但可不再履行义务**；⚠ **因行政行为的废止给相对人造成财产损失的，行政主体应当依法给予补偿** |

**⚠ 撤销的责任分配（两种情形）**：

- ⚠ **因行政主体过错**引起，并且依社会公益的需要又**必须使撤销效力追溯到行为作出之日** →
  **能够恢复原状的应当恢复原状，由此造成行政相对人的一切实际损失应由行政主体予以赔偿**
- ⚠ **因相对人过错，或行政主体与相对人共同过错**所引起的 →
  **撤销的效力通常应追溯到行政行为作出之日**，
  ⚠ **过错方各依自己的过错程度承担相应的行政法律责任，包括赔偿责任**

- ⚠ **我国法律明确规定某种行政行为无效的情况并不多见**，但：
  ⚠《**行政处罚法**》**第 38 条**规定，**行政处罚没有依据**或者**实施主体不具有行政主体资格**的，
  **行政处罚无效**；**违反法定程序构成重大且明显违法**的，**行政处罚无效**
  —— ⚠ 此外，《行政复议法》规定了**确认无效复议决定**，《行政诉讼法》规定了**确认无效判决**

### 六、⚠ 抽象行政行为

- ⚠ **从动态上讲**，指行政主体针对**不特定的人和事**制定具有**普遍约束力的行为规则**的活动；
  ⚠ **从静态上讲**，指制定出来的具有普遍约束力的**行为规则**（也称**行政规范**，
  包括**行政法规、规章、其他行政规范性文件，具有普遍约束力的决定、命令**等）
- ⚠ **作出抽象行政行为的主体主要是有关人民政府及其工作部门**等行政机关
- ⚠ **四个特征**：①**对象的普遍性**（以**普遍的、不特定的人或事**为行为对象）；
  ②**效力的普遍性和持续性**（对某一类人或事具有约束力，**同时带有后及力**，
  不仅适用于当时，而且**适用于将来发生的同类行为或事件**）；③**准立法性**；
  ④⚠⚠ **不可诉性** —— **抽象行政行为一般不能成为行政诉讼的直接审查对象**，
  但某些抽象行政行为依法**可以作为行政复议或者行政诉讼中的「一并」审查对象**

**⚠ 行政立法**：指**有权行政机关依法律规定的权限和程序**制定并颁布有关行政管理事项
**普遍适用的规则**的活动，**包括行政法规和规章**。
⚠ **行政立法既具有行政的性质（一种抽象行政行为），又具有立法的性质（一种准立法行为）**
—— **兼具行政性和立法性**。

- ⚠ **行政立法主体**（依法取得行政立法权、可以制定行政法规或行政规章的国家行政机关）：
  **国务院，国务院各部、各委员会，审计署、中国人民银行、国务院直属机构，
  省、自治区、直辖市人民政府，省、自治区人民政府所在地的市的人民政府，
  国务院批准的较大的市的人民政府，设区的市、自治州的人民政府，
  经济特区所在地的市的人民政府**

### 七、⚠ 具体行政行为的类型（七类）

**（一）行政征收与行政征用**

- ⚠⚠ **行政征收**：**行政主体根据法律规定，以强制方式无偿取得行政相对人财产所有权**的
  一种具体行政行为
  - ⚠ **三个特征**：①是**单方具体行政行为**；②实质在于**以强制方式无偿取得相对人的财产所有权**；
    ③实施必须以相对人**负有行政法上的缴纳义务、财产使用或者国家、社会公共利益的特定需要**为前提
  - ⚠ **内容**：**税收征收、社会保险费与非税收入征收、建设资金征收、管理费征收、
    国有土地上房屋征收**等
  - ⚠ **按发生原因的三分**：①**因使用权**而引起的征收（如**建设资金**的征收）；
    ②**因行政法上的义务**而引起的征收（如**税收征收、社会保险费与非税收入征收、管理费**的征收）；
    ③**因国家或者公共利益的特定需要**而引起的征收（如**国有土地上房屋征收、
    紧急状态下政府及其工作部门作出的财产征收行为**）
- ⚠⚠ **行政征用**：**行政机关为了公共利益需要依法强制性使用**公民、法人或者其他组织的财产
  **并按照规定给予补偿**的行政行为
  - ⚠ **四个特征**：**行政性、权利限制性、强制性以及补偿性**
  - ⚠ **法律依据**：《民法典》**第 117 条、第 245 条**对征用不动产或动产及补偿作出规定；
    《突发公共卫生事件应对法》**第 12 条**对为应对突发事件征用单位和个人财产
    以及**及时返还和补偿**作出规定
  - ⚠⚠ **与行政征收的关键分野**：**征收 → 无偿取得所有权**；
    **征用 → 强制性使用 + 给予补偿**

**（二）⚠ 行政确认**

- ⚠ **定义**：行政主体依法对相对人的**法律地位、法律关系和法律事实**进行**甄别，
  给予确定、认可、证明并予以宣告**的具体行政行为
- ⚠ **特征**：①**是要式行政行为**（**必须以书面形式**，并按照相应的法律规范和一定的技术规范要求作出）；
  ②**有些依申请作出，有些依职权作出**
  - ⚠ **依申请**：**城市房屋出租登记备案、收养登记、增值税一般纳税人登记**等
  - ⚠ **依职权**：**道路交通事故责任认定、火灾事故责任认定**等
- ⚠ **九种主要形式**：**确定、认定、认可、证明、登记、审批、审核、鉴证、行政鉴定**
  （如**颁发土地使用证、婚姻或户籍登记、学历证明、企业性质认定、文化制品合法性鉴证、
  发票真伪鉴定**）
- ⚠ **两种分类**：①**按行为动因** → **依申请**（如**增值税一般纳税人资格认定**）
  与**依职权**（如**道路交通事故责任认定**）；
  ②**按对象** → 对**身份、能力（或资格）、事实、法律关系和权利归属**的确认
  （如**不动产所有权和使用权的行政确认、经营权的行政确认、知识产权的行政确认**）

**（三）行政监督**

- ⚠ **定义**：行政主体依法定职权，对相对人**遵守法律法规规章以及执行行政命令、决定的情况**
  进行**检查、了解、监督**的行政行为
- ⚠ **五个特征**：①**行为主体**是享有行政监督权的国家行政机关或法律、法规授权的组织；
  ②**对象**是作为相对人的公民、法人或其他组织；③**内容**是相对人遵守法律法规规章、
  执行行政命令决定的情况；④**性质**是一种**依职权的、单方的、相对独立的**具体行政行为；
  ⑤**目的**是**防止和纠正**相对人的违法行为
- ⚠ **常见方法**：**审计、检查、调查、查验、检验、勘验、鉴定、登记、统计**等

**（四）行政给付**

- ⚠ **定义**：行政主体对公民在**年老、疾病或丧失劳动能力或其他特殊情况**下，
  依照法律法规规定，**赋予其一定的物质利益或与物质有关的权益**的具体行政行为
- ⚠ **三个特征**：①是**具体行政行为**，**以法律法规为依据**；②**对象是特定的公民**
  （**只对出现了特殊困难和特殊情况的公民个人作出**）；③**内容是赋予被帮助人以一定的物质权益
  或与物质相关的权益**，既可以是**直接的财物**，也可以是**与财物相关的其他利益**
  （如**免费教育、免费治疗**）
- ⚠ **与行政奖励的区别**：⚠ **行政给付的内容不具有精神上和职务上的权益**，
  一般**只有物质上的权益和与物质有关的权益**两部分
- ⚠ **形式**：**退休金、退职金、失业救济金、社会保险金、最低生活保障费、安置、补助、抚恤、
  优待、救灾扶贫**等

**（五）⚠ 行政裁决**

- ⚠ **定义**：**法律授权的特定行政主体**对**平等主体之间**发生的、**与行政管理活动密切相关**的、
  **特定的民事权利归属或者侵权损害纠纷**进行审查，并就**各方责任的承担作出裁断**的具体行政行为
- ⚠ **与行政调解的关系**：二者都是行政机关**履行解决特定民事争议职能**的体现，
  ⚠ **但行政裁决更正式、更具有约束力**
- ⚠ **四个特征**：①**主体是法律授权的特定行政机关**（如**自然资源管理部门、著作权管理部门、
  专利管理部门**），⚠ **但公安机关对公民之间实施人身侵害的治安管理处罚案件没有赔偿数额的裁决权，
  只有调解权**；②**对象是特定的民事纠纷**——⚠ **人民法院审理行政机关对民事争议所作裁决的案件，
  一并审理民事争议的，不另行立案**；③**是行使行政裁决权的活动，具有法律权威性**；
  ④⚠ **是一种可诉的具体行政行为**
- ⚠ **四种类型**：**著作权侵权损害赔偿纠纷的裁决、专利权许可使用费纠纷的裁决、
  土地等自然资源使用权侵权损害赔偿纠纷的裁决、国有资产产权纠纷的裁决**等

**（六）行政奖励**

- ⚠ **是一种授益行政行为**；⚠ **主体限于行政机关**——
  **企业、学校内部及社会团体等根据有关奖励制度实施奖励行为，不属于行政奖励**
- ⚠ **三步程序**：①**申请**（符合法定条件的相对人可向法定机关提出申请，
  也可由行政机关**依法定条件自行确定被奖励人**）；②**审查**（可要求递交资料或组织评审、专家鉴定）；
  ③**颁发**
  - ⚠ **对不予奖励或不按规定予以相应奖励不服的，可以依法提起行政复议或者行政诉讼**
- ⚠ **税务实践中的两类行政奖励**：**对单位和个人向税务机关实名检举税收违法行为并经查实的**，
  按规定给予一定的物质奖励；**对经纳税人自行申请、符合《纳税信用管理办法（试行）》规定的单位，
  授予 A 级纳税人称号**

**（七）⚠ 行政协议**

- ⚠ **定义**（《最高人民法院关于审理行政协议案件若干问题的规定》第 1 条）：
  行政机关为**实现公共利益或者行政管理目标**，**因行使行政职权或者在行使行政职权过程中**，
  与公民、法人或者其他组织**协商订立的具有行政法上权利义务内容的协议**
- ⚠⚠ **五个基本要素**：①**目的要素**（必须是为**公共利益或者实现行政管理目标**）；
  ②**职权职责要素**（必须与**行政职权紧密相连**、与履行行政职责有关）；
  ③**主体要素**（一方是**行政机关**，另一方是**公民、法人或者其他组织**）；
  ④**行为要素**（**协商订立**协议）；⑤**内容要素**（内容主要体现或涉及**行政法上的权利义务**，
  **包括行政主体一方的行政优益权**）
- ⚠⚠ **与民事合同的两点区分**：
  - **形式标准**：行政协议**在主体上具有严格的法定性**——
    **一方主体必须是行政机关或者法律、法规和规章授权的组织**
  - **实质标准**：行政协议的**标的及内容是行政法律关系中的行使行政职权、履行行政职责
    及行政法上的权利和义务，包括行政主体的行政优益权**
- ⚠ **强制执行的两条路径**：
  - ⚠ **约定了强制执行条款**：条件成就而相对人不履行的 →
    **行政机关可以依法直接将行政协议作为执行依据，向人民法院申请强制执行或者依法自行强制执行**
  - ⚠ **未约定强制执行条款**：条件成就的 →
    **行政机关可以作出要求相对人履行协议约定义务的决定**，相对人拒不履行的，
    **行政机关可以该决定为执行依据向人民法院申请强制执行或者依法自行强制执行**
- ⚠ **理论上的两类**：①**管理性行政协议**（本质上是**规定行政管理职权的行使**为内容——
  如**政府特许经营协议**；又如地方政府以**吸引投资、吸引人才**为目的提供优越行政条件，
  与企业事业单位或个人订立的关于**减免税收、简化行政程序**等内容的协议）；
  ②**财产性行政协议**（本质上是行政机关为**提高国有资产的使用效益以及所需货物和服务的采购效益**
  而订立——前者如**矿业权等国有自然资源使用权出让协议、国有土地出让协议**；
  后者如**国家订货合同**）
- ⚠ **常见的行政协议**：**政府特许经营协议、政府投资的保障性住房的租赁或者买卖协议、
  符合规定的政府与社会资本合作协议，以及土地、房屋等征收征用补偿协议**
- ⚠ **入法**：⚠ **《行政复议法》《行政诉讼法》将行政协议争议纳入法定受案范围**
