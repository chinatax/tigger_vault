# 个人所得税纳税审核：公益捐赠扣除

## Definition

⚠ **本页是《涉税服务实务》第三章第三节之「（二）个人所得税的纳税审核方法」的
「5. 捐赠扣除的审核方法」**。

⚠⚠ **本目的两段式结构（**本库归纳**）**：
**前半（（1）–（4））是「「扣除的实体条件」」——渠道·用途·比例·金额确认；
后半（（5））是「「扣除的申报方式」」——在哪种所得中扣、限额多少、顺序如何**，
⚠ **最后以「票据」与「追补扣除」收尾，构成一条完整的「「能不能扣、怎么扣、凭什么扣」」链条。**

⚠ **边界**：
- ⚠ **公益慈善捐赠的个税规则（含 30% 与全额扣除的项目）**见
  [[charitable-donation-individual-tax]]；
- ⚠ **企业所得税侧的捐赠扣除（12% 与 3 年结转）**见 [[corporate-income-tax-deduction-limits]]
  与 [[cit-audit-financial-expense-and-outlays]]——⚠⚠ **两套税种的限额口径不同（30% vs 12%），
  不可混用**。

## Key Points

### ⚠ 一、扣除的「实体条件」（**（1）–（4）**）

| # | ⚠ 审核点（**教材原句要点**） |
|---|---|
| **（1）** | ⚠⚠ **公益性捐赠是否通过了「中国境内非营利性的社会团体、国家机关」**——**「税法规定，只有通过社会团体、国家机关的捐赠才允许从应纳税所得额中扣除。「未经过上述机关、团体的捐赠不得扣除」。」** |
| **（2）** | ⚠ **捐赠款项的「用途」以及捐赠款是否超过允许扣除的「比例」**——**「审核捐赠款是否用于「教育事业、其他公益事业以及遭受自然灾害的地区或贫困地区」，捐赠款是否「在允许扣除的比例之内」。不符合以上条件的，不予在税前扣除。」**；⚠ **「防止纳税人利用公益性捐赠扣除项目少缴纳税款。」** |
| **（3）** | ⚠⚠ **公益性捐赠「超过扣除限额」的部分的处理**——**「应由纳税人「自行负担」，「不得以任何形式抵减应纳税所得额」。」** |
| **（4）** | ⚠⚠ **纳税人发生的公益捐赠支出「金额确认」是否正确（**三类**）**：**① 捐赠「货币性资产」的——按「实际捐赠金额」确定；② 捐赠「股权、房产」的——按「个人持有股权、房产的「财产原值」」确定；③ 捐赠除股权、房产以外的其他「非货币性资产」的——按「非货币性资产的「市场价格」」确定。** |

### ⚠⚠ 二、扣除的「申报方式」（**（5）：居民个人与非居民个人**）

#### A. 居民个人——可在「三类所得」中扣除

> **「居民个人发生的公益捐赠支出可以在「「综合所得」」（工资、薪金所得；劳务报酬所得；
> 稿酬所得；特许权使用费所得）、「「分类所得」」（财产租赁所得、财产转让所得、
> 利息股息红利所得、偶然所得）或「「经营所得」」中扣除。」**

| # | ⚠ 在哪类所得中扣 | ⚠ 口径（**教材原句要点**） |
|---|---|---|
| **a** | ⚠ **在「综合所得」中扣除** | ⚠ **教材给出「综合所得年度汇算应退或应补税额」的完整算式**（**收入额 − 6 万元 − 三险一金等专项扣除 − 子女教育等专项附加扣除 − 依法确定的其他扣除 − 捐赠 × 适用税率 − 速算扣除数 − 当年已预缴税额**）；⚠⚠ **「取得「工资薪金所得」的，可以选择在「「预扣预缴时」」扣除公益捐赠支出，也可以选择在「「年度汇算清缴时」」扣除」**；⚠⚠ **「取得「劳务报酬所得、稿酬所得、特许权使用费所得」的，「预扣预缴时不扣除」公益捐赠支出，「统一在汇算清缴时扣除」」** |
| **b** | ⚠⚠ **在「分类所得」中扣除** | **「发生的公益捐赠支出，可在「「捐赠当月」」取得的分类所得中扣除」**；⚠ **「捐赠当月有多项多次分类所得的，「「应先在其中一项一次分类所得中扣除」」」**；⚠⚠ **「已经在分类所得中扣除的公益捐赠支出，「「不再调整到其他所得中扣除」」」**；⚠⚠ **「取得「全年一次性奖金、股权激励等所得」，且按规定采取「「不并入综合所得而以单独计税方式」」处理的，公益捐赠支出扣除「「比照分类所得的扣除规定」」处理」** |
| **c** | ⚠ **在「经营所得」中扣除** | **可以选择在「预缴税款时」扣除，也可以选择在「汇算清缴时」扣除**；⚠ **个体工商户发生的，在其经营所得中扣除**；⚠⚠ **个人独资企业、合伙企业发生的公益捐赠支出**——**其个人投资者应「按照捐赠年度合伙企业的「分配比例」（个人独资企业分配比例为「100%」）」，计算归属于每一个投资者的公益捐赠支出，个人投资者应将其「「归属的独资·合伙企业公益捐赠支出」」和「本人需要在经营所得扣除的其他公益捐赠支出」合并，在其经营所得中扣除**；⚠⚠ **「但需注意，「「核定征收个人所得税的不扣除公益捐赠支出」」。」** |

⚠ **一处「自主选择权」**：**「居民个人可以根据以上各项所得的收入、公益捐赠支出、适用税率等情况，
「自行决定在综合所得、分类所得、经营所得中扣除公益捐赠支出的顺序」。」**

⚠⚠ **❗〖提示〗（**限额与结转，本目的核心考点**）**：
> **「除允许全额扣除的外，在「综合所得、经营所得」中扣除的，扣除限额分别为
> 「「当年综合所得、当年经营所得应纳税所得额的 30%」」；在「分类所得」中扣除的，
> 扣除限额为「「当月分类所得应纳税所得额的 30%」」。」**
> ⚠ **「取得综合所得、分类所得、经营所得的，在当期一个所得项目扣除不完的公益捐赠支出，
> 可以按规定在其他所得项目中继续扣除。」**

#### B. ⚠ 非居民个人——「按月或按次分项」扣除

> **「非居民个人发生的公益捐赠支出，先在「「按月或者按次分项计算个人所得税」」的各项所得中扣除，
> 未超过其在「「公益捐赠支出发生当月的应纳税所得额 30%」」的部分，可以从其取得的
> 「工资、薪金所得，劳务报酬所得，稿酬所得和特许权使用费所得，利息、股息、红利所得，
> 财产租赁所得，财产转让所得和偶然所得」的应纳税所得额中扣除。
> ⚠「「扣除不完的公益捐赠支出，可以再在经营所得中继续扣除」」。」**

### ⚠ 三、两项「补充规则」

| # | ⚠ 规则（**教材原句要点**） |
|---|---|
| **1** | ⚠ **「追补扣除」**：**「要注意审核纳税人按规定可以在当月的应纳税所得额中扣除公益捐赠支出
  「而未实际扣除」的，「可按规定追补扣除」」** |
| **2** | ⚠⚠ **「扣除次序可自选」**：**「如果纳税人「同时发生」按「30% 扣除」和「全额扣除」的
  公益捐赠支出，纳税人可以「自行选择扣除次序」」** |

### ⚠⚠ 四、捐赠「票据」的审核（**本目的收官段**）

| # | ⚠ 审核点（**教材原句要点**） |
|---|---|
| **1** | ⚠⚠ **「须取得合规捐赠票据」**——**「捐赠票据为「「财政部或省级政府财政部门统一印制、并套印全国统一式样的财政票据监制章」」的《「「公益事业捐赠统一票据」」》；⚠⚠「普通的《非税收入一般缴款书》「「不能再用于」」收取公益捐赠财物」」** |
| **2** | ⚠ **票据的作用**：**「捐赠票据是捐赠人对外捐赠并根据国家有关规定「「申请捐赠款项税前扣除的有效凭证」」，「发生公益捐赠后应及时取得符合规定的捐赠票据方能享受公益捐赠税前扣除政策」」** |
| **3** | ⚠⚠ **「未及时取得票据的处理（**两个期限**）**」：**「若纳税人捐赠不能及时取得捐赠票据，可以「「暂时凭公益捐赠银行支付凭证扣除」」，并向扣缴义务人提供公益捐赠银行支付凭证复印件。纳税人应在「「捐赠之日起 90 日内」」向扣缴义务人补充提供捐赠票据，如果纳税人未按规定提供捐赠票据，「「扣缴义务人应在 30 日内向主管税务机关报告」」」** |
| **4** | ⚠ **单位统一组织捐赠**：**「机关、企事业单位「「统一组织员工」」开展公益捐赠的，纳税人可以凭「「汇总开具的捐赠票据和员工明细单」」扣除」** |
| **5** | ⚠ **全额扣除的备注义务**：**「享受全额税前扣除政策的，在办理个人所得税税前扣除时，需在填写《个人所得税公益慈善事业捐赠扣除明细表》时，在「「备注栏注明『直接捐赠』」」」** |

### ⚠ 五、本页的「要点密集区」（**复习提示**）

| 要点 | ⚠ 所指 |
|---|---|
| ⚠⚠ **两道门：渠道 + 用途** | **只有通过境内非营利性社会团体·国家机关、且用于公益事业的捐赠才可扣除** |
| ⚠⚠ **超限额部分「不得抵减」** | **由纳税人自行负担（⚠ 个税侧无「3 年结转」——与企业所得税 12% + 3 年结转不同）** |
| ⚠⚠ **金额确认三分** | **货币性按实际金额／股权房产按「财产原值」／其他非货币性按「市场价格」** |
| ⚠⚠ **30% 的两个基数** | **综合所得·经营所得→当年应纳税所得额的 30%；分类所得→「当月」分类所得应纳税所得额的 30%** |
| ⚠⚠ **「一个项目扣不完可在其他项目继续扣」** | **但「分类所得已扣的不再调整到其他所得」** |
| ⚠⚠ **工资薪金 vs 其余三项** | **工资薪金可选择预扣预缴或汇算时扣；劳务报酬·稿酬·特许权使用费只在汇算清缴时扣** |
| ⚠ **单独计税所得「比照分类所得」** | **全年一次性奖金、股权激励等单独计税的所得** |
| ⚠⚠ **核定征收不扣捐赠** | **经营所得中扣除的例外** |
| ⚠⚠ **「90 日 / 30 日」** | **补提供票据 90 日；未提供则扣缴义务人 30 日内报告税务机关** |
| ⚠ **《非税收入一般缴款书》不能替代** | **须是《公益事业捐赠统一票据》** |

⚠⚠ **须注意一处「两套税种的限额混用风险」（**非分歧，但极易错**）**：
⚠ **个人所得税侧**——**一般扣除限额为「应纳税所得额的 30%」，超限额部分「自行负担、
不得抵减」（无结转）**；
⚠ **企业所得税侧**——**限额为「年度利润总额的 12%」，超限额部分「准予结转以后 3 年内扣除」**
（见 [[cit-audit-financial-expense-and-outlays]]）。
