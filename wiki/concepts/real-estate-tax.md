# 房产税

## Definition

房产税（Real Estate Tax）：以**房产**为征税对象、按**房产余值**或**租金收入**向产权所有人课征的财产税。
按年征收、分期缴纳，采用**比例税率**。

其技术核心是**"从价还是从租"**的分岔，以及**房产原值的构成**——
⚠ 判断时必须先确定房产的**使用状态**（自用 / 出租 / 投资联营 / 融资租赁），
再据此选择计税依据与税率。

## Key Points

### 一、基本框架

- **计税方法两种**：**从价计征**（依房产余值，税率 **1.2%**）；
  **从租计征**（依租金收入，税率 **12%**）。
- **房产余值** = 房产原值 ×（1 − 扣除比例），扣除比例由**省、自治区、直辖市人民政府**规定。
- **征税范围**：**城市、县城、建制镇和工矿区**的房产——⚠ **不包括农村**。
- ⚠ **不属于"房产"的建筑物**（不缴纳房产税）：**围墙、烟囱、水塔、变电塔、油池油柜、
  酒窖菜窖、酒精池、糖蜜池、室外游泳池、玻璃暖房、砖瓦石灰窑**以及各种油气罐等
  **独立于房屋之外**的建筑物。

### 二、纳税人与计税依据的特殊情形

| 情形 | 纳税人 | 计税依据 |
|---|---|---|
| 产权**出典**的 | **承典人** | 房产余值 |
| 产权**未确定**及租典纠纷未解决的 | **房产代管人或使用人** | — |
| 产权所有人**不在房屋所在地**的 | **房产代管人或使用人** | — |
| 产权属**全民所有**的 | **经营管理单位** | — |
| **融资租赁**的房产 | **承租人** | 房产余值 |
| **投资联营、共担风险**的 | **被投资方** | 房产余值 |
| **投资联营、收取固定收入不承担风险**的 | **出租方（投资人）** | **租金收入** |
| **居民住宅区内业主共有**的经营性房产（自营） | 代管人或使用人 | 房产余值 |
| **居民住宅区内业主共有**的经营性房产（出租） | 代管人或使用人 | 租金收入 |
| 处于**免收租金期间**内的出租房产 | **产权所有人** | **房产原值**（⚠ 仍从价计征） |

### 三、房产原值的构成

- ⚠ **应计入**房产原值：与房屋**不可分割**的各种附属设备或一般不单独计算价值的配套设施——
  **电力、电讯、电缆导线，电梯、升降机，过道、晒台**；
  ⚠ 以及**以房屋为载体、不可随意移动**的附属设备和配套设施——
  **给排水、采暖、消防、中央空调**等——**无论会计上是否单独记账与核算**，都应计入。
- ⚠ **不计入**房产原值：**可移动的家具**；**公共设施**占用的土地价值。
- ⚠ **土地价值**：**宗地容积率低于 0.5** 的，按房产建筑面积的 **2 倍**计算土地面积，
  并据此确定计入房产原值的地价；⚠ 容积率 **≥0.5** 的按地价**全额**计入。
- **地下建筑物**：
  - ⚠ **与地上房屋相连**的地下建筑物，应将地下部分与地上房屋**视为一个整体**，
    按地上房屋建筑物的规定计征
  - **独立**的地下建筑物：**工业用途**房产以房屋原价的 **50%~60%** 作为应税房产原值；
    **商业用途**以原价的 **70%** 作为应税房产原值
  - 具体折算比例由**各省、自治区、直辖市和计划单列市财政和税务部门**在规定幅度内自行确定

### 四、主要免税

- **企业办的各类学校、托儿所、幼儿园**自用的房产
- **国家财政部门拨付事业经费**的单位自用的房产
- **非营利性老年服务机构**自用的房产；**福利性、非营利性**老年服务机构
- **危险房产**：经鉴定毁损不堪居住且**停止使用**后的房产
- **大修停用**：因房屋大修导致**连续停用半年以上**的，在**大修期间免征**
- **按国家规定标准收取住宿费的高校学生公寓**
- **"三北"地区供热企业**为居民供热所使用的厂房
- **被撤销金融机构清算期间**自有的房产
- **为社区提供家政服务的机构**自有并用于提供社区家政服务的房产
- ⚠ **房产税与城镇土地使用税不重复**：两者是**不同税种**，可同时涉及

### 五、纳税义务发生时间（易错）

- **购置新建商品房** → 自房屋**交付使用之次月**起计征
- **购置存量房** → 自办理房屋权属转移、变更登记手续、
  房地产权属登记机关**签发房屋权属证书之次月**起计征
- **出租、出借房产** → 自**交付出租、出借房产之次月**起计征
- **自建房屋** → 自**建成之日的次月**起计征
- **委托施工企业建设的房屋** → 从**办理验收手续之次月**起计征
- **房地产开发企业自用、出租、出借**本企业建造的商品房 → 自**房屋使用或交付之次月**起计征
- **融资租赁** → 由承租人自合同**约定开始日的次月**起；
  ⚠ **合同未约定开始日**的，自**合同签订的次月**起
- **纳税地点**：⚠ 房产**不在同一地方**的，应按房产的**坐落地点分别**向房产所在地税务机关缴纳

### 教材补充（CTA《税法（二）》教材 2026 版第五章）

**（一）⚠ 「房产」的界定与不属房产的建筑物**

- ⚠ **房屋**指有**屋面和围护结构**（有墙或两边有柱），能够**遮风避雨**，
  可供人们在其中生产、工作、学习、娱乐、居住或**储藏物资**的场所
- ⚠⚠ **不属于房产**的（**独立于房屋之外**的建筑物）：
  **围墙、烟囱、水塔、变电塔、油池油柜、酒窖菜窖、酒精池、糖蜜池、室外游泳池、
  玻璃暖房、砖瓦石灰窑以及各种油气罐**等

**（二）⚠ 征税范围的四类区域**

- ⚠ **城市**指经国务院批准设立的市，其征税范围为**市区、郊区和市辖县县城**，
  ⚠ **不包括农村**
- ⚠ **县城**指**未设立建制镇的县人民政府所在地**
- ⚠ **建制镇**指经省、自治区、直辖市人民政府批准设立的建制镇；
  ⚠ **具体的征税范围由各省、自治区、直辖市税务局提出方案，经省级人民政府确定批准后执行，
  并报国家税务总局备案**
- ⚠ **工矿区**指工商业比较发达、人口比较集中、符合国务院规定的建制镇标准，
  但**尚未设立镇建制**的大中型工矿企业所在地；⚠ **开征房产税的工矿区须经省级人民政府批准**

**（三）⚠⚠ 纳税人四类**

1. ⚠ **产权属全民所有**的 → 由**经营管理单位**纳税
2. ⚠⚠ **产权出典**的 → 由**承典人**纳税
   - ⚠ **产权出典**指产权所有人将房屋、生产资料等的产权，**在一定期限内典当给他人使用，
     而取得资金**的一种融资业务；⚠ **典价一般要低于卖价**；
     ⚠ **在房屋出典期间，产权所有人已无权支配房屋**，故由**对房屋具有支配权的承典人**为纳税人
3. ⚠ **产权所有人、承典人不在房屋所在地**的 → 由**房产代管人或者使用人**纳税
4. ⚠ **产权未确定及租典纠纷未解决**的 → **亦由房产代管人或者使用人**纳税
   - ⚠ **租典纠纷**指产权所有人在房产出典和租赁关系上，与承典人、租赁人发生各种争议
     （特别是权利和义务的争议）**悬而未决**的

- ⚠ **外币折算**：以人民币以外的货币为**记账本位币**的外资企业及外籍个人缴纳房产税时，
  应按**缴款上月最后一日**的人民币汇率中间价折合成人民币

**（四）⚠⚠ 三档税率**

| 计税依据 | 税率 |
|---|---|
| **房产计税余值** | ⚠ **1.2%** |
| **房产租金收入** | ⚠ **12%** |
| ⚠ **个人出租住房**（**不区分实际用途**） | ⚠ **4%** |
| ⚠ **企事业单位、社会团体以及其他组织向个人、专业化规模化住房租赁企业出租住房** | ⚠ **减按 4%** |

**（五）⚠ 计税依据的核心规则**

**1. 从价计征（经营自用）**：

- ⚠ **计税余值 = 房产原值 ×（1 − 原值减除比例）**
  —— ⚠ 按房产原值**一次减除 10%–30%** 的损耗价值，**具体减除比例由省级人民政府在
  税法规定的减除幅度内自行确定**
- ⚠ 对依照房产原值计税的房产，**不论是否记载在「固定资产」科目中**，均应按照**房屋原价**计算；
  ⚠ **房屋原价应根据国家有关会计制度规定进行核算**；
  ⚠ 未按国家会计制度规定核算并记载的，应**予以调整或重新评估**；
  ⚠ **没有房产原值**的，应由**房屋所在地的税务机关参考同类房屋的价值核定**
- ⚠ **房产原值包括与房屋不可分割的各种附属设备或一般不单独计算价值的配套设施**：
  **暖气、卫生通风、照明、煤气**等设备；各种**管线**（蒸汽、压缩空气、石油、给水排水等管道
  及电力、电讯、电缆导线）；**电梯、升降机、过道、晒台**等
  - ⚠ **原值计算的起点**：**水管、下水道、暖气管、煤气管**等应从**最近的探视井或三通管起**；
    **电灯网、照明线从进线盒联结管起**
  - ⚠⚠ **以房屋为载体、不可随意移动的附属设备和配套设施**（**给排水、采暖、消防、中央空调、
    电气及智能化楼宇设备**等），**无论在会计核算中是否单独记账与核算，都应计入房产原值**
- ⚠ **更换**附属设备和配套设施的 → 在将其价值计入房产原值时，**可扣减原来相应设备和设施的价值**；
  ⚠ 对其中**易损坏、需要经常更换的零配件**，**更新后不再计入**房产原值，
  **原零配件的原值也不扣除**
- ⚠ **地下建筑**：自 **2006-01-01** 起，凡在房产税征收范围内的**具备房屋功能的地下建筑**，
  包括**与地上房屋相连的地下建筑**以及**完全建在地面以下的建筑、地下人防设施**等，
  **均应当**依照有关规定征收房产税
  - ⚠ 对**与地上房屋相连**的地下建筑（如**地下室、地下停车场、商场的地下部分**等），
    应将**地下部分与地上房屋视为一个整体**，按照**地上房屋建筑**的有关规定计算征收
- ⚠ **免租期间**：对出租房产，租赁双方签订的租赁合同**约定有免收租金期限**的，
  ⚠ **免收租金期间由产权所有人按照房产原值**缴纳房产税
- ⚠⚠ **房产原值包含地价**：对按照房产原值计税的房产，**无论会计上如何核算，
  房产原值均应包含地价**，包括为取得土地使用权支付的价款、开发土地发生的成本费用等
  - ⚠⚠ **容积率低于 0.5** 的 → 按**房产建筑面积的 2 倍**计算土地面积并据此确定计入房产原值的地价
- ⚠ **产权出典**的房产 → 由**承典人依照房产余值**缴纳

**2. 从租计征**：以**租金收入（不含增值税）**为计税依据；
⚠ 房屋的租金收入包括**货币收入和实物收入**；
⚠ **以劳务或其他形式作为报酬抵付房租收入**的 → 应根据**当地同类房屋的租金水平确定租金标准**，
依率计征

**3. ⚠ 投资联营与融资租赁的计税依据（两分）**：

- ⚠ **以房产投资联营、投资者参与投资利润分红、共担风险**的 →
  **按房产余值**作为计税依据
- ⚠ **以房产投资、收取固定收入、不承担联营风险**的 →
  ⚠ **实际上是以联营名义取得房产租金**，应由**出租方按租金收入**计算缴纳
- ⚠ **融资租赁**的房产 → 由**承租人自融资租赁合同约定开始日的次月起**依照**房产余值**缴纳；
  ⚠ **合同未约定开始日**的 → 由承租人**自合同签订的次月起**依照**房产余值**缴纳

**4. 居民住宅区内业主共有的经营性房产**：

- ⚠ 由**实际经营（包括自营和出租）的代管人或使用人**缴纳
- ⚠ **自营**的 → 依照房产原值减除 10%–30% 后的**余值**计征；
  ⚠ **没有房产原值或不能将业主共有房产与其他房产的原值准确划分开**的 →
  由**房产所在地税务机关参照同类房产核定**房产原值
- ⚠ **出租**的 → 依照**租金**计征

**（六）⚠⚠ 自用独立地下建筑的应纳税额（两档折算比例）**

- ⚠ **工业用途房产** → 以**房屋原价的 50%–60%** 作为应税房产原值：
  **应纳房产税税额 = 应税房产原值 ×〔1 −（10%–30%）〕× 1.2%**
- ⚠ **商业和其他用途房产** → 以**房屋原价的 70%–80%** 作为应税房产原值：
  **应纳房产税税额 = 应税房产原值 ×〔1 −（10%–30%）〕× 1.2%**
- ⚠ **房屋原价折算为应税房产原值的具体比例，由各省、自治区、直辖市和计划单列市
  财政和税务部门在上述幅度内自行确定**
- ⚠ **出租**的地下建筑 → 按**出租地上房屋建筑**的有关规定计算征收

**（七）⚠⚠ 纳税义务发生时间（七类，均为「次月」）**

| 情形 | 起算时点 |
|---|---|
| ⚠ **自建**的房屋 | 自**建成之日的次月起**计征 |
| ⚠ **委托施工企业建设**的房屋 | 从**办理验收手续之日的次月起**计征。⚠ **在办理验收手续前已使用或出租、出借**的新建房屋，应**按规定计征** |
| ⚠ **购置新建商品房** | 自**房屋交付使用之次月起** |
| ⚠ **购置存量房** | 自**办理房屋权属转移、变更登记手续，房地产权属登记机关签发房屋权属证书之次月起** |
| ⚠ **出租、出借房产** | 自**交付出租、出借房产之次月起** |
| ⚠ **房地产开发企业自用、出租、出借本企业建造的商品房** | 自**房屋使用或交付之次月起** |

- ⚠ **纳税期限**：房产税**实行按年征收，分期缴纳**，纳税期限由**省级人民政府**规定
- ⚠ **纳税地点**：房产税在**房产所在地**缴纳；⚠ **房产不在同一地方**的，
  应按房产的**坐落地点分别向房产所在地**的税务机关缴纳

**（八）其余三处优惠要点**

- ⚠ **无租使用**其他单位房产的**应税单位和个人** → 依照**房产余值代缴纳**房产税
  —— ⚠ 即**免税单位将房产无租交付应税单位和个人使用，实际使用方应该缴纳**房产税
- ⚠ **房地产开发企业建造的商品房**，在**出售前不征收**房产税；
  ⚠ **但出售前已使用或出租、出借**的商品房**应按规定征收**
- ⚠ **大修停用**：纳税人因房屋**大修导致连续停用半年以上**的，
  在房屋**大修期间免征**房产税；⚠ 免征税额由纳税人在**申报缴纳时自行计算扣除**

### ⚠⚠ 地方口径补充（**安徽，2026-09-29 新增**）

> ⚠ 本节内容为**省级落地实例**——⚠ 教材只写到「**省级人民政府确定**」，
> 本节的数值与批准通道**只适用于安徽**，⚠ **不得外推至他省**。
> ⚠ **上位概念**见 [[local-tax-implementation-authority]]。

**（一）⚠⚠ 原值减除比例 = 30%**（[[anhui-real-estate-tax-implementation-rules]] 第三条）：
**「房产税均按其原值一次减除 30% 后的余值计算」**——⚠ **即安徽取国家幅度（10%–30%）的上限**。

**（二）⚠ 出租房产的计税依据与自用界定**（同件第四条）：
**以租金收入为计税依据**；⚠ **「自用房产」指各该单位办公、业务和生活使用的房产，
不包括出租房产和非本单位业务使用的生产、营业用房**。

**（三）⚠⚠ 「停用房产」的地方减免通道**（同件第六条，⚠ **教材无此表述**）：
**「经房管部门和主管部门鉴定的危房、停止使用的房产和其他纳税确有困难的房产，
经市、县人民政府批准，可减征或免征房产税。」**
⚠⚠ **要件为「经鉴定／停止使用／纳税确有困难」＋「市、县人民政府批准」**——
**并非「空置即免」**（⚠ 该件**通篇无「闲置」二字**）。

**（四）⚠ 地下建筑折算比例的安徽取值**（[[anhui-underground-building-real-estate-tax-2006]]）：
**工业用途 50%、商业和其他用途 70%**（**均为国家幅度的下限**）；
⚠⚠ **但「与地上房屋相连」的地下建筑（含商场的地下部分）并入地上整体计征**；
⚠ **出租的地下建筑**按出租地上房屋同口径。

**（五）⚠ 纳税期限已被统一**：
细则第八条原为「**按年征收，分季或半年分期缴纳，具体纳税期限由市、县税务局确定**」，
⚠⚠ **自 2021-01-01 起由 [[anhui-property-and-behaviour-tax-filing-2020]] 统一为
按季申报、季度终了 15 日内**（⚠ 引用期限时以后者为准）。

**（六）⚠ 效力状态**（[[anhui-provincial-documents-cleanup-2025]]）：
⚠ 安徽细则经 **皖政〔2025〕76 号**修改（改第二条、**删第五条**、改第九条）后**继续有效**；
⚠⚠ **第三条（减除 30%）与第六条（停用房产减免）未在修改之列**——
⚠ **即上述（一）（三）两项仍为现行条文**。

## Contradictions

**⚠ 一、地方与中央的「幅度 vs 取值」关系（**非分歧，属授权落地**）**：

| 事项 | 国家幅度（教材） | ⚠ 安徽取值 | 处置 |
|---|---|---|---|
| **房产原值减除比例** | **10%–30%**（省级在幅度内定） | ⚠⚠ **30%**（上限） | ⚠ 取值落在幅度内，**非冲突**；⚠ 但**引用比例前须先确定适用地区** |
| **自用地下建筑折算比例** | **工业 50%–60%／商业和其他 70%–80%** | ⚠ **工业 50%／商业和其他 70%**（均为下限） | 同上 |

⚠ **处置理由**：两者是**「幅度授权 → 地方取值」**，⚠ **本库两说并列、不裁定**；
⚠ **引用纪律见 [[local-tax-implementation-authority]] 第四节**。

**⚠ 二、⚠ 一处**最易误记的地方规则**（**照录强调**）**：
⚠⚠ **与地上房屋相连的地下建筑**（**含「商场的地下部分」**）
**须并入地上房屋整体计征，不适用折算比例**；
⚠ **出租的地下建筑**按**出租地上房屋**同口径（从租 12%）——
见 [[anhui-underground-building-real-estate-tax-2006]]。

**⚠ 三、⚠ 「停用房产」的地方减免通道（**教材未载、地方有**）**：
⚠ 安徽细则**第六条**规定**「经鉴定危房、停止使用的房产和其他纳税确有困难的房产，
经市、县人民政府批准，可减征或免征房产税」**——
⚠ **本条为地方性批准权限，教材口径中无对应表述**；
⚠⚠ **但须注意：要件是「经鉴定／停止使用／纳税确有困难」＋「市县政府批准」，
⚠ 不是「空置即免」**（见 [[anhui-real-estate-tax-implementation-rules]] 第六条）。
