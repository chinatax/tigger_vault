# 其他税种会计核算

## Definition

⚠ **本页是《涉税服务实务》第四章《涉税会计核算》第四节「其他税种会计核算」**——
**教材在此一节内并列了「「十个税种」」**：
**（一）土地增值税／（二）印花税／（三）契税／（四）房产税／（五）城镇土地使用税／
（六）资源税／（七）环境保护税／（八）城市维护建设税（含教育费附加与地方教育附加）／
（九）车船税（含车辆购置税）／（十）关税**。

⚠⚠ **本节的「一条主线」（**本库归纳**）**：
**每个税种都是「「计提 → 缴纳」」两笔，差异只在「「计提时借哪个科目」」**——
**① 影响损益的税费 → 「「税金及附加」」；② 计入资产成本的税费 → 相应资产科目
（在建工程·固定资产·无形资产·在途物资）；③ 与资产处置相关的 → 「「固定资产清理」」/「「应收账款」」等。**
⚠⚠ **另有一条反复出现的「「可以不通过『应交税费』科目核算」」的分支**
（**印花税·车辆购置税·进口/出口关税·契税**）——⚠ **教材对这些税种都给了「「两条路」」的写法。**

⚠ **边界**：
- ⚠ **各税种的实体规则**见 [[land-appreciation-tax]]、[[stamp-duty]]、[[deed-tax]]、
  [[real-estate-tax]]、[[urban-land-use-tax]]、[[resource-tax]]、[[environmental-protection-tax]] 等；
- ⚠ **「应交税费」「税金及附加」两个科目的界定**见 [[tax-related-account-subjects]]（**同章批 1**）；
- ⚠ **涉税账务调整方法**见 [[tax-accounting-adjustments]]（**同批**）。

## Key Points

### ⚠ 一、（一）土地增值税的核算（**两类企业，路径不同**）

| # | ⚠ 主体 | ⚠ 账务处理（**教材原句要点**） |
|---|---|---|
| **1** | ⚠ **房地产开发企业** | **「计提土地增值税时借记『「「税金及附加」」』科目，贷记『应交税费——应交土地增值税』科目；
实际缴纳时，借记『应交税费——应交土地增值税』科目，贷记『银行存款』等科目」**；⚠⚠ **采取预售方式的**：
**「对在「「项目全部竣工结算前」」转让房地产取得的收入，税务机关「「可以预征」」土地增值税，
纳税人按税法规定「「预缴」」的土地增值税，借记『应交税费——应交土地增值税』科目，
贷记『银行存款』等科目；「「待项目办理完土地增值税清算时」」，借记『税金及附加』科目，
贷记『应交税费——应交土地增值税』科目」**；⚠ **「若收到退回多缴的土地增值税，借记『银行存款』等科目，
贷记『应交税费——应交土地增值税』科目；「「若补缴土地增值税，则作相反的会计分录」」」** |
| **2** | ⚠⚠ **非房地产开发企业** | **「对于「「地上建筑物及其附着物连同国有土地使用权一并转让」」的业务，
「「通过『固定资产清理』等科目核算」」，按转让时应缴纳的土地增值税额，
「「借记『固定资产清理』科目」」，贷记『应交税费——应交土地增值税』科目；
实际缴纳时，借记『应交税费——应交土地增值税』科目，贷记『银行存款』等科目」** |

### ⚠ 二、（二）印花税的核算（**两条路 + 一处「金额较大且分期使用」的处理**）

> ⚠ **为什么有「不走应交税费」的路（**教材原句**）**：**「由于印花税一般情况下是由纳税人
> 「「以购买并一次贴足印花税票方式」」缴纳税款的，因此，「「为了简化处理」」，
> 纳税人缴纳的印花税「「可以不通过『应交税费』科目核算」」」**。

| # | ⚠ 路径 | ⚠ 分录（**教材原句要点**） |
|---|---|---|
| **①** | ⚠ **「不走应交税费」** | **「购买印花税票时，可以「「直接借记『税金及附加』科目，贷记『银行存款』科目」」」** |
| **②** | ⚠⚠ **「一次购买金额较大且分期使用」**（**两条路都适用**） | **「可以先借记『「「预付账款」」』科目，贷记『银行存款』科目；「「待实际使用时」」，
再借记『税金及附加』科目，贷记『预付账款』科目」** |
| **③** | ⚠ **「走应交税费」** | **「企业按应计提的印花税额，借记『税金及附加』等科目，贷记『应交税费——应交印花税』科目；
实际缴纳时，借记『应交税费——应交印花税』科目，贷记『银行存款』科目」**；⚠ **分期使用的**：
**「借『预付账款』贷『银行存款』；待实际使用时，「「借记『税金及附加』、贷记『应交税费——应交印花税』，
「「同时」」借记『应交税费——应交印花税』、贷记『预付账款』」」** |

### ⚠ 三、（三）契税的核算（**三种情形 + 一处「视开发情况而定」**）

| # | ⚠ 情形 | ⚠ 账务处理（**教材原句要点**） |
|---|---|---|
| **1** | ⚠ **购买房屋、建筑物等固定资产的同时获得土地使用权** | **「按应计提的契税，借记『「「在建工程」」』『「「固定资产」」』等科目，贷记『应交税费——应交契税』科目；
实际缴纳时，借记『应交税费——应交契税』科目，贷记『银行存款』科目」**；⚠ **「纳税人「「可以不通过」」
『应交税费——应交契税』科目核算契税」**——**「企业实际缴纳契税时，借记『在建工程』『固定资产』等科目，
贷记『银行存款』科目」** |
| **2** | ⚠ **单独购买土地使用权** | **「借记『「「无形资产」」』科目，贷记『应交税费——应交契税』科目」**；⚠ **同样「可以不通过」
该科目——缴纳时直接「借『无形资产』、贷『银行存款』」** |
| **3** | ⚠⚠ **房地产企业购入的土地使用权** | ⚠⚠ **「「视开发情况而定」」：「如果土地购入后「「就进行开发」」，则作为「「开发成本」」处理；
如果土地购入后「「仅作为土地储备」」，则作为「「无形资产」」处理」** |

### ⚠ 四、（四）（五）房产税与城镇土地使用税的核算

| # | ⚠ 税种 | ⚠ 账务处理 |
|---|---|---|
| **（四）1** | **房产税——经营自用的房屋** | **「按「「从价计征」」计算应缴纳的房产税额，借记『税金及附加』科目，
贷记『应交税费——应交房产税』科目；实际缴纳时，借记『应交税费——应交房产税』科目，
贷记『银行存款』等科目」** |
| **（四）2** | ⚠ **房产税——出租的房屋** | **「按「「从租计征」」计算应缴纳的房产税额」**——**分录同上**（⚠ **两种计征方式的账务处理一致，
差别只在计税依据**） |
| **（五）** | **城镇土地使用税** | **「纳税人计提城镇土地使用税时，借记『税金及附加』科目，贷记『应交税费——应交城镇土地使用税』科目；
实际缴纳时，借记『应交税费——应交城镇土地使用税』科目，贷记『银行存款』等科目」** |

### ⚠ 五、（六）资源税的核算（**两个子项**）

| # | ⚠ 情形 | ⚠ 账务处理（**教材原句要点**） |
|---|---|---|
| **1** | ⚠ **直接销售应税产品** | **「纳税人计提资源税时，借记『税金及附加』科目，贷记『应交税费——应交资源税』科目；
实际缴纳时，借记『应交税费——应交资源税』科目，贷记『银行存款』科目」** |
| **2** | ⚠⚠ **自产自用应税产品** | ⚠ **「自用于「「连续生产应税产品」」的，「「不缴纳」」资源税。「自用于其他方面的，「「视同销售」」，
按规定计提资源税时，「「借记『生产成本』『制造费用』等科目」」，贷记『应交税费——应交资源税』科目；
实际缴纳时，借记『应交税费——应交资源税』科目，贷记『银行存款』科目」** |

### ⚠ 六、（七）环境保护税的核算（**计提与申报缴纳的「时点差」**）

> ⚠ **两步（**教材原句**）**：
> **1.「「每月计算」」环境保护税时，借记『税金及附加』科目，贷记『应交税费——应交环境保护税』科目；**
> **2.「「每个季度结束后申报缴纳」」时，借记『应交税费——应交环境保护税』科目，
> 贷记『银行存款（或现金）』科目」**。

### ⚠ 七、（八）城市维护建设税、教育费附加、地方教育附加的核算（**三项同构**）

⚠ **三者的账务处理「完全同构」（**教材逐项列出**）**：
**「纳税人计提××时，应借记『「「税金及附加」」』『「「固定资产清理」」』等科目，
贷记『应交税费——应交××』科目；实际缴纳××时，应借记『应交税费——应交××』科目，
贷记『银行存款』科目」**；
⚠⚠ **并各自附一句「期末余额的含义」**：**「『应交税费——应交××』科目「「期末贷方余额」」
反映企业「「应缴未缴」」的××」**（**三项皆同**）。
⚠ **三项即**：**城市维护建设税／教育费附加／地方教育附加**。

### ⚠ 八、（九）车船税、车辆购置税的核算

| # | ⚠ 税种 | ⚠ 账务处理（**教材原句要点**） |
|---|---|---|
| **1** | ⚠⚠ **车船税——「「先计提后缴纳」」的情况** | **「纳税人计提车船税时，借记『税金及附加』科目，贷记『应交税费——应交车船税』科目；
实际缴纳车船税时，借记『应交税费——应交车船税』科目，贷记『银行存款』等科目」** |
| **1′** | ⚠⚠ **车船税——「「先缴纳后分摊」」的情况** | **「纳税人缴纳车船税时，「「借记『预付账款』科目，贷记『应交税费——应交车船税』科目，
同时借记『应交税费——应交车船税』科目，贷记『银行存款』科目」；「「以后各期分摊时，
再借记『税金及附加』科目，贷记『预付账款』科目」」」** |
| **2** | ⚠ **车辆购置税** | **「纳税人「「可以不通过」」『应交税费——应交车辆购置税』科目核算……「「借记『固定资产』等科目，
贷记『银行存款』科目」」」**；⚠ **也可以走该科目**——**「企业购置应税车辆或者「「免税、减税车辆因转让、
改变用途等原因不再属于免税、减税范围的」」，按应计提或者补缴的车辆购置税额，
「「借记『固定资产』等科目」」，「「贷记『应交税费——应交车辆购置税』等科目」」；
实际缴纳时，借记『应交税费——应交车辆购置税』科目，贷记『银行存款』科目」** |

### ⚠⚠ 九、（十）关税的核算（**本节的「压轴项」，四个方向**）

#### 1. 进口关税

| # | ⚠ 主体与情形 | ⚠ 账务处理（**教材原句要点**） |
|---|---|---|
| **（1）** | ⚠ **工业企业进口业务** | **「工业企业直接或通过外贸企业从国外进口原材料，对于应缴纳的进口关税，
「「可以不通过『应交税费』科目核算」」，而是将其与「「进口原材料的价款、国外运费、装卸费、
保险费、国内费用」」一并「「直接计入进口原材料的采购成本」」，借记『在途物资』『原材料』等科目，
贷记『银行存款』『应付账款』等科目」**；⚠⚠ **另一情形**：**「企业「「根据同外商签订的加工装配和
补偿贸易合同而引进的国外设备」」，对于应支付的进口关税，「「按规定以企业专用拨款等支付」」。
支付时，借记『「「在建工程——引进设备工程」」』科目，贷记『银行存款』等科目」** |
| **（2）** | ⚠ **商业企业「「自营」」进口** | **「在会计核算上是通过设置『应交税费——应交进口关税』和『「「在途物资」」』科目加以反映的」**——
**「借记『在途物资』科目，贷记『应交税费——应交进口关税』科目；实际缴纳时，借记
『应交税费——应交进口关税』科目，贷记『银行存款』科目」**；⚠ **「对于应缴纳的进口关税，
「「也可不通过」」『应交税费——应交进口关税』科目，「「直接借记『在途物资』科目，
贷记『银行存款』『应付账款』等科目」」」** |
| **⭐** | ⚠⚠ **「代理」进口业务** | ⚠⚠ **「代理进出口业务，对受托方来说，「「一般不垫付货款」」，多以「「收取手续费」」形式
为委托方提供代理服务，因此，「「由于进出口商品而计缴的关税应由委托方缴纳」」，
受托代理进出口业务的一方「「只是代垫或代付关税，日后要与委托方结算」」」**；⚠ **账务**：
**「通过设置『应交税费——应交进口关税』科目来反映，「「其对应科目是『应付账款』『应收账款』
『银行存款』等」」」** |

#### 2. 出口关税

| # | ⚠ 主体与情形 | ⚠ 账务处理（**教材原句要点**） |
|---|---|---|
| **（1）** | ⚠ **工业企业出口** | **「工业企业出口产品「「可不通过」」『应交税费——应交出口关税』科目核算」，而是「「按应缴纳的
出口关税额，缴纳时直接记入『税金及附加』科目的借方」」，『银行存款』『应付账款』等科目的贷方」** |
| **（2）** | ⚠ **商业企业「「自营」」出口** | **「借记『税金及附加』科目，贷记『应交税费——应交出口关税』科目；实际缴纳时，
借记『应交税费——应交出口关税』科目，贷记『银行存款』科目」**；⚠ **「企业「「也可以不通过」」
『应交税费——应交出口关税』科目核算，而是「「直接借记『税金及附加』科目，
贷记『银行存款』科目」」」** |
| **（3）** | ⚠⚠ **商业企业「「代理」」出口** | ⚠ **「代理出口业务是指进出口企业「「代委托方办理对外销售、发运、制单及结汇」」的全过程」**；
**「代理出口企业按计算代缴的出口关税额，「「借记『应收账款』科目」」，贷记『应交税费——
应交出口关税』科目；实际缴纳出口关税时，借记『应交税费——应交出口关税』科目，
贷记『银行存款』科目。「「日后再与委托方结算」」」** |

### ⚠ 十、本页的「要点密集区」（**复习提示**）

| 要点 | ⚠ 所指 |
|---|---|
| ⚠⚠ **「计提借哪个科目」的三分** | **影响损益→「税金及附加」；计入资产成本→在建工程·固定资产·无形资产·在途物资；资产处置相关→「固定资产清理」** |
| ⚠⚠ **土地增值税的两类企业** | **房地产开发企业→「税金及附加」（预缴走「应交税费」借方）；非房地产开发企业→「固定资产清理」** |
| ⚠⚠ **四处「可以不通过应交税费」** | **印花税·车辆购置税·进口（工业）与出口（工业）关税·契税** |
| ⚠⚠ **两处「预付账款」** | **印花税「一次购买金额较大且分期使用」；车船税「先缴纳后分摊」** |
| ⚠ **资源税的「连续生产不缴」** | **自用于连续生产应税产品不缴纳；自用于其他方面视同销售（借生产成本·制造费用）** |
| ⚠⚠ **环境保护税的「月计季缴」** | **每月计算（借税金及附加）、每季度结束后申报缴纳** |
| ⚠ **城建税及两项附加的「同构」** | **三项分录完全同构，均含「期末贷方余额＝应缴未缴」的说明** |
| ⚠⚠ **关税的「代理」两侧** | **进口：受托方一般不垫付货款、关税由委托方缴纳（对应科目为「应付账款」「应收账款」）；出口：代理出口企业借「应收账款」** |
