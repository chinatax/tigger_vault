# 应税交易

## Definition

应税交易（Taxable Transaction）：《增值税法》对增值税课征对象的总称，指
**境内销售货物、服务、无形资产、不动产以及进口货物**。它是增值税的**征税范围总纲**——
任何一笔业务先要过这一关，才谈得上税率、计税依据、优惠。

> ⚠ **术语提示**：旧《增值税暂行条例》称「**应税销售行为**」，现行《增值税法》称「**应税交易**」。
> 两词指同一制度位置，但**引用条款时必须用新法术语**。

## Key Points

- **征税范围的构成**：销售货物 + 销售服务 + 销售无形资产 + 销售不动产 + 进口货物，
  覆盖第一、二、三产业（我国属于"扩展到服务业"这一最完善的类型）。
- **「有偿」的外延**：不仅指从购买方取得**货币**，还包括取得**货物或其他经济利益**。
- **各类别的界定**：
  - **销售货物**——有偿转让货物**所有权**；"货物"包括有形动产、**电力、热力和气体**
  - **销售服务**——有偿提供服务（税目归类见 [[vat-service-tax-item-classification]]）
  - **销售无形资产**——转让无形资产**所有权或者使用权**；包括技术、商标、著作权、商誉、
    自然资源使用权和其他无形资产（含基础设施资产经营权、公共事业特许权、配额、经营权、
    经销权、分销权、代理权、会员权、席位权、网络游戏虚拟道具、域名、名称权、肖像权、冠名权、转会费等）
  - **销售不动产**——转让不动产**所有权**；包括建筑物（住宅、商业营业用房、办公楼等）、
    构筑物（道路、桥梁、隧道、水坝等）
  - **进口货物**——申报进入我国海关境内的货物；判断标准是**是否办理了报关进口手续**
- **按销售不动产征税的三类特殊情形**：转让建筑物的**有限产权或永久使用权**；
  转让**在建**的建筑物或构筑物所有权；转让建筑物或构筑物时**一并转让其所占土地使用权**。
- **境内判定**：见 [[cross-border-tax-policy]]。这是管辖权的第一道关，先于税率适用。
- **结果的三种分流**：正常应税交易 → 征税；**视同应税交易** → 征税（见 [[vat-deemed-taxable-transaction]]）；
  **不属于应税交易** → 不征（见 [[vat-non-taxable-transaction]]）。
