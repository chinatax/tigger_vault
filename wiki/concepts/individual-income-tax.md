# 个人所得税

## Definition

个人所得税（Individual Income Tax）：对个人取得的各项所得课征的税种。我国现行税制属
**混合所得税制**——把**四项劳动性所得**合并为"**综合所得**"按年汇总、超额累进，
其余所得分类征收。它由**预扣预缴 + 汇算清缴**两段构成。

判断任何一道题的**第一步**永远是：**这是居民个人还是非居民个人**、
**这笔所得属于哪个税目**——因为税目决定税率、费用扣除和申报方式。

## Key Points

- **居民个人的判定**（采用**住所标准**与**居住时间标准**，⚠ **不是**户籍、国籍标准）：
  - 在中国境内**有住所**；或
  - **无住所**而一个纳税年度内在中国境内居住**累计满 183 天**
- **居住天数的计算**：无住所个人按**累计停留天数**计算；
  ⚠ 停留当天**满 24 小时**的计入居住天数，**不足 24 小时的不计入**。
  （⚠ 但计算**境内工作天数**时，停留当天不足 24 小时的按**半天**计算——两套口径不同）
- **所得来源地**（不论支付地点是否在境内均为境内所得）：
  ①因任职、受雇、履约等在**中国境内提供劳务**取得的所得；
  ②将财产出租给**承租人在中国境内使用**而取得的所得；
  ③许可各种**特许权在中国境内使用**而取得的所得；
  ④转让**中国境内的不动产**等财产或者**在中国境内转让其他财产**取得的所得；
  ⑤从中国境内企业、事业单位、其他组织以及**居民个人**取得的利息、股息、红利所得。

### 九个税目与税率

| 税目 | 税率 |
|---|---|
| **综合所得**（工资薪金、劳务报酬、稿酬、特许权使用费） | **3%~45%** 七级超额累进 |
| **经营所得** | **5%~35%** 五级超额累进 |
| 利息股息红利所得 | **20%** 比例 |
| 财产租赁所得 | **20%**（⚠ 个人按市场价格出租**居民住房**的**减按 10%**） |
| 财产转让所得 | **20%** 比例 |
| 偶然所得 | **20%** 比例 |

### 汇算清缴的免办情形

纳税人取得综合所得时已依法预缴，且符合下列**之一**的，**无须办理**汇算清缴：
①需补税但综合所得收入**全年不超过 12 万元**；②需补税金额**不超过 400 元**；
③已预缴税额与实际应纳税额**一致**；④符合退税条件但**不申请退税**。

### 全员全额扣缴申报的范围

⚠ **经营所得不在其列**。范围包括：工资薪金所得、劳务报酬所得、稿酬所得、特许权使用费所得、
利息股息红利所得、财产租赁所得、财产转让所得、偶然所得。

### "次"的确定

- **劳务报酬、稿酬、特许权使用费**：一次性收入的以**取得该项收入**为一次；
  同一项目**连续性收入**的以**一个月内**取得的收入为一次
- **财产租赁所得**：以**一个月内**取得的收入为一次
- **利息、股息、红利所得**：以**支付时**取得的收入为一次
- **偶然所得**：以**每次取得**该项收入为一次
- **全年一次性奖金**：包括**年终加薪**、实行**年薪制**和**绩效工资**办法的单位根据考核情况
  兑现的年薪和绩效工资

### 若干特殊所得的归属（易错）

- **出租车驾驶员**：车权属于公司 → **工资薪金所得**；车权属于驾驶员 → **经营所得**
- **承包、承租经营**：缴纳承包费后经营成果归承包人的 → **经营所得**
- **杂志社记者在本社刊物发表文章** → **工资薪金所得**；
  ⚠ **出版社专业作者**翻译小说由该出版社出版 → **稿酬所得**
- **企业向本单位以外**的个人赠送礼品（含**网络红包**）→ **偶然所得**；
  ⚠ **本单位**年会抽奖、有奖竞猜 → **工资薪金所得**
- **个人为单位或他人提供担保**取得的收入 → **偶然所得**
- **特许权的经济赔偿收入** → **特许权使用费所得**
- 作者将作品**手稿原件**拍卖 → **财产转让所得**；⚠ 手稿**复印件**拍卖 → **特许权使用费所得**
- 企业为个人购买办公用小汽车但**未办理车辆过户** → ⚠ **不属于**个人所得，**不征收**

### 教材补充（CTA《税法（二）》教材 2026 版第三节）

**（一）居民个人与非居民个人的判定标准**

- ⚠ **居民个人**：在中国境内**有住所**，或者**无住所而一个纳税年度内在中国境内居住累计满 183 天**
- ⚠ **非居民个人**：在中国境内**无住所又不居住**，或者**无住所而一个纳税年度内居住累计不满 183 天**
- ⚠ 税法所称「**中国境内**」指中国**司法管辖地区**，⚠ **目前还不包括香港、澳门和台湾地区**；
  一个纳税年度指**自公历 1 月 1 日起至 12 月 31 日止**

**1. 住所标准**（⚠ 实为**习惯性住所标准**）

- ⚠ 「在中国境内有住所」指**因户籍、家庭、经济利益关系而在中国境内习惯性居住**
- ⚠ **住所标准在税收上是法律意义上的标准，不是指实际居住或某一特定时期内的居住地**：
  个人因**学习、工作、探亲、旅游**等在中国境外居住的，当其在境外居住的**原因消除之后
  必须回到中国境内居住**——那么即使该纳税人在一个纳税年度内、
  **甚至连续几个纳税年度内都未曾在中国境内居住过 1 天，仍应判定为在中国习惯性居住**

**2. 居住时间标准**

- ⚠ 「居住满 183 天」指在一个纳税年度内在中国境内**累计**居住满 183 天
- ⚠ 自 2019-01-01 起，**取消了原来的「临时离境」规定**——无住所个人在一个纳税年度内
  **无论出境多少次**，只要在境内**累计住满 183 天**即可判定为居民个人
- ⚠ **单日判定规则**：在中国境内停留的当天**满 24 小时**的**计入**中国境内居住天数；
  **不足 24 小时**的**不计入**
- ⚠ 住所标准与居住时间标准是**两个并列性标准**，个人只要**符合或达到其中任何一个**，
  就可以被认定为居民个人
- ⚠ **纳税人识别号**：纳税人有中国公民身份号码的，以**中国公民身份号码**为纳税人识别号；
  没有的，由**税务机关赋予**；扣缴义务人扣缴税款时，纳税人应当向扣缴义务人**提供**纳税人识别号

**（二）纳税义务的范围**

- ⚠ **居民个人**：就来源于中国**境内和境外**的所得，履行**全面纳税义务**
- ⚠ **非居民个人**：只就来源于中国**境内**的所得，履行**有限纳税义务**
- ⚠ 无住所个人的**完整计税规则**（四象限纳税义务、四个收入额公式、数月奖金与股权激励的来源地判定）
  见 [[non-domiciled-individual-tax]]

**（三）所得来源的确定（五项）**

⚠ 除国务院财政、税务主管部门另有规定外，下列所得**不论支付地点是否在中国境内**，
**均为来源于中国境内**的所得：

1. 因**任职、受雇、履约等在中国境内提供劳务**取得的所得
2. 将**财产出租给承租人在中国境内使用**而取得的所得
3. **许可各种特许权在中国境内使用**而取得的所得
4. **转让中国境内的不动产等财产**或者**在中国境内转让其他财产**取得的所得
5. 从**中国境内企业、事业单位、其他组织以及居民个人**取得的**利息、股息、红利**所得

**（四）扣缴义务人**

- ⚠ 个人所得税**以所得人为纳税人**，以**支付所得的单位或个人为扣缴义务人**
- ⚠ 扣缴义务人在向纳税人支付应税款项时，应当依照规定**预扣或者代扣**税款，**按时缴库**，
  并**专项记载备查**
- ⚠ 「**支付**」包括**现金支付、汇拨支付、转账支付和以有价证券、实物以及其他形式**的支付

**（五）应纳税所得额的一般规定**

- ⚠ **计量单位**：以**人民币**为单位；所得为人民币以外货币的，按**办理纳税申报或者扣缴申报的
  上一月最后一日人民币汇率中间价**折合；⚠ **年度终了后办理汇算清缴**的，
  对**已经按月、按季或者按次预缴**税款的外币所得**不再重新折算**；
  对**应当补缴**税款的所得部分，按**上一纳税年度最后一日**人民币汇率中间价折合
- ⚠ **收入金额的确定**：所得为**实物**的按凭证上注明的价格（无凭证或价格明显偏低的
  参照**市场价格**核定）；为**有价证券**的按**票面价格和市场价格**核定；
  为**其他形式经济利益**的参照**市场价格**核定

**⚠ 三项纳税期的分野**（本考点的结构骨架）：

| 纳税期 | 适用所得 |
|---|---|
| **按年计税** | 居民个人的**综合所得、经营所得** |
| **按月计税** | 非居民个人的**工资、薪金所得** |
| **按次计税** | **利息、股息、红利所得，财产租赁所得，偶然所得**，以及非居民个人取得的**劳务报酬所得、稿酬所得、特许权使用费所得** |

**⚠ 「次」的界定**（与既有内容互为补充）：

- **劳务报酬、稿酬、特许权使用费所得**：属于**一次性收入**的以取得该项收入为一次；
  属于**同一项目连续性收入**的以**一个月内**取得的收入为一次
  - ⚠ **广告市场**的三条特别口径：**劳务报酬所得**以纳税人**每参与一项广告**的设计、制作、发布
    所取得的所得为一次；**稿酬所得**以在图书、报刊上**发布一项广告时使用其作品**取得的所得为一次；
    **特许权使用费所得**以**提供一项特许权在一项广告**的设计、制作、发布过程中使用取得的所得为一次
  - ⚠ 上述所得**采取分笔支付**的，应**合并为一次**所得计算纳税
- **财产租赁所得**：以**一个月内**取得的收入为一次
- **利息、股息、红利所得**：以**支付**利息、股息、红利时取得的收入为一次
- **偶然所得**：以**每次取得**该项收入为一次

**（六）应纳税所得额的五类确定方法与税前扣除**

| 所得 | 应纳税所得额 |
|---|---|
| **居民个人综合所得** | 每一纳税年度的**收入额** − **费用 60000 元** − **专项扣除** − **专项附加扣除** − **依法确定的其他扣除** |
| **非居民个人**工资薪金 | **每月收入额 − 费用 5000 元** |
| **经营所得** | 每一纳税年度的**收入总额 − 成本、费用以及损失** |
| **财产租赁所得** | 每次收入**不超过 4000 元**的减除 **800 元**；**4000 元以上**的减除 **20%** |
| **财产转让所得** | **转让财产的收入额 − 财产原值 − 合理费用** |
| **利息、股息、红利所得和偶然所得** | **以每次收入额**为应纳税所得额（⚠ **不扣除任何费用**） |

- ⚠ **综合所得的收入额折算**：劳务报酬、稿酬、特许权使用费所得以**收入减除 20% 的费用**后的余额
  为收入额；⚠ **稿酬所得的收入额减按 70% 计算**（详见 [[comprehensive-income-tax]]）
- ⚠ **三项扣除的范围**：
  - **专项扣除** = 居民个人按国家规定的范围和标准缴纳的**基本养老保险、基本医疗保险、
    失业保险等社会保险费和住房公积金**（即「三险一金」）
  - **专项附加扣除** = **3 岁以下婴幼儿照护、子女教育、继续教育、大病医疗、
    住房贷款利息或者住房租金、赡养老人**（详见 [[special-additional-deductions]]）
  - **依法确定的其他扣除** = 个人缴付符合国家规定的**企业年金、职业年金、个人养老金**，
    个人购买的**商业健康保险、税收递延型商业养老保险**的支出等
    （详见 [[pension-and-insurance-tax-preference]]）
- ⚠ **经营所得与综合所得的费用扣除不重复**：取得经营所得的个人**没有综合所得**的，
  计算其每一纳税年度的应纳税所得额时应当减除**费用 60000 元、专项扣除、专项附加扣除
  以及依法确定的其他扣除**；⚠ **专项附加扣除在办理汇算清缴时减除**
- ⚠ **财产原值的确定**：**有价证券** → 买入价 + 买入时按规定交纳的有关费用；
  **建筑物** → 建造费或者购进价格 + 其他有关费用；**土地使用权** → 取得土地使用权所支付的金额
  + 开发土地的费用 + 其他有关费用；**机器设备、车船** → 购进价格 + 运输费 + 安装费 + 其他有关费用；
  **其他财产** → 参照上述方法。⚠ 未提供完整、准确的原值凭证的，由主管税务机关**核定**
- ⚠ **合理费用**指**卖出财产时按照规定支付的有关税费**

**（七）两处特殊规定**

- ⚠ **两人以上共同取得同一项目收入**的，应当对**每个人**取得的收入**分别**按规定计算纳税
- ⚠ **公益慈善捐赠的扣除**：
  - **限额扣除**：个人将其所得对**教育、扶贫、济困**等公益慈善事业进行捐赠，
    捐赠额**未超过纳税人申报的应纳税所得额 30%** 的部分可以扣除
    —— ⚠ 指通过**中国境内的公益性社会组织、国家机关**进行的捐赠；
    ⚠「应纳税所得额」指**计算扣除捐赠额之前**的应纳税所得额
    （⚠ **2027-12-31 前**，个人**捐赠住房作为公共租赁住房**的公益性捐赠支出同样按 30% 限额扣除）
  - ⚠ **全额扣除的情形已有十项**：①对**公益性青少年活动场所**（含新建）的捐赠；
    ②对**红十字事业**的捐赠；③对**福利性、非营利性老年服务机构**的捐赠；
    ④对**中华健康快车基金会**和**孙冶方经济科学基金会、中华慈善总会、中国法律援助基金会
    和中华见义勇为基金会**的捐赠；⑤对**教育事业**的捐赠；
    ⑥对**宋庆龄基金会、中国福利会、中国残疾人福利基金会、中国扶贫基金会、
    中国煤矿尘肺病治疗基金会、中华环境保护基金会**的捐赠；
    ⑦对**中国老龄事业发展基金会、中国华文教育基金会、中国绿化基金会、中国妇女发展基金会、
    中国关心下一代健康体育基金会、中国生物多样性保护基金会、中国儿童少年基金会
    和中国光彩事业基金会**的捐赠；⑧对**中国医药卫生事业发展基金会**的捐赠；
    ⑨对**中国教育发展基金会**的捐赠；⑩对**地震灾区**的捐赠
- ⚠ **境内外所得的计算规则**：居民个人从境内和境外取得的**综合所得、经营所得**，
  应当**分别合并计算**应纳税额；从境内和境外取得的**其他所得**，应当**分别单独计算**应纳税额

**（八）境外所得税收抵免（个人）**

- ⚠ 居民个人从中国境外取得的所得，可以**从其应纳税额中抵免**已在境外缴纳的个人所得税税额，
  ⚠ 但**抵免额不得超过**该纳税人境外所得依照《个人所得税法》相关规定计算的**应纳税额**
- ⚠ **已在境外缴纳的个人所得税税额** = 居民个人来源于中国境外的所得，
  依照该**所得来源国家（地区）的法律**应当缴纳并且**实际已经缴纳**的所得税税额
- ⚠ **抵免限额**：除国务院财政、税务主管部门另有规定外，
  ⚠ **来源于中国境外一个国家（地区）的综合所得抵免限额、经营所得抵免限额以及其他所得抵免限额
  之和，为来源于该国家（地区）所得的抵免限额**（即**分国**计算）
- ⚠ **超过限额的处理**：实际已缴税额**低于**抵免限额的 → 应在中国**缴纳差额**部分的税款；
  **超过**抵免限额的 → 其超过部分**不得在本纳税年度**应纳税额中抵免，
  但可以在**以后纳税年度**来源于该国家（地区）所得的**抵免限额的余额中补扣**，
  ⚠ **补扣期限最长不得超过 5 年**
- ⚠ **举证**：申请抵免应当提供**境外税务机关出具的税款所属年度的有关纳税凭证**

## Contradictions

### ⚠ 手稿拍卖所得的税目归属（题库与教材口径冲突，2026-09-22 发现）

| 来源 | 主张 |
|---|---|
| [[cta-550-tax-law-2-questions]]（题库） | ⚠ **手稿原件**拍卖 → **财产转让所得**；**手稿复印件**拍卖 → **特许权使用费所得**（按「原件／复印件」二分） |
| [[cta-tax-law-2-textbook]]（教材） | ⚠ **手稿原件或复印件**拍卖 → **均为特许权使用费所得**；只有拍卖**「自己的文字作品手稿原件或复印件之外」**的财产才归**财产转让所得** |

- **冲突点**：**手稿原件**拍卖究竟归哪个税目。题库归**财产转让所得**，教材归**特许权使用费所得**
- ⚠ **本页不裁定、不覆盖**：两个来源各自独立登记如上，实际适用时**以现行有效的规范性文件为准**
- ⚠ 教材在 p190 与 p193 两处**重复表述**同一规则（正文 + 提示框），
  且 p193 的第 4 项规则明确把「手稿原件或复印件」**排除在拍卖财产的财产转让所得之外**，
  内部一致性强；题库表述为单点结论，未给出处
- **关联**：同一问题在 [[individual-income-tax-levying-scope]] 的「八、财产转让所得」
  与「四、特许权使用费所得」两节均有登记
