# 税收协定·财产收益

## Definition

财产收益（Capital Gains）条款（第十三条）：对**转让财产取得的收益**划分来源国与居民国的征税权。
⚠ 条款对**不同类型财产**规定了不同规则，其中**两条关于股权的规则**是考点集中区：

- **转让主要由不动产组成的公司股权**——⚠ **不看持股比例**，只看**不动产占比是否 50% 以上**
- **转让其他公司股权**——⚠ **看持股比例是否达到 25%**

## Key Points

### 一、⚠ 转让主要由不动产组成的公司股权（第四款）

- ⚠ 转让一个公司财产股份的股票取得的收益，**该公司的财产又主要直接或间接由
  位于缔约国一方的不动产所组成**，**可以在不动产所在国征税**
- ⚠ 即：**只要该公司的股份价值的 50% 以上（不含 50%）直接或者间接由位于缔约对方的不动产所构成**，
  则缔约国一方居民转让该公司股份取得的收益，
  ⚠ **无论其持股比例是多少**，**不动产所在国对股份转让收益都有权征税**

**（一）⚠ 50% 的口径与三年测试**

- ⚠ 「公司股份价值 50% 以上直接或间接由位于中国的不动产所组成」指
  **公司股份被转让之前的一段时间内任一时间**，
  被转让股份的公司**直接或间接持有位于中国的不动产价值占公司全部财产价值的比率在 50% 以上**
- ⚠ **具体时间的口径**：协定对具体时间未作规定，**执行中可暂按 3 年处理**
  —— 指**公司股份被转让之前（不含转让当月）的连续 36 个公历月份**
- ⚠ **确认与计价规则**：公司**财产和不动产均应按照当时有效的中国会计制度**
  有关资产（**不考虑负债**）处理的规定进行确认和计价；
  ⚠ **但相关不动产所含土地或土地使用权价值额不得低于按照当时可比相邻或同类地段
  的市场价格计算的数额**
- ⚠ 纳税人**不能按照以上规定进行可靠计算**的，相关资产确认和计价由税务机关**参照以上规定合理估定**
- ⚠ **「不动产」的范围**：均应包括各种**营业用或非营业用房屋等建筑物和土地使用权**，
  以及**附属于不动产的财产**

**（二）⚠⚠ 「间接持有」的穿透计算（本考点最难的一处）**

- ⚠ 执行该款规定时应注意「**间接持有**」问题：**除应考虑被转让公司本身财产构成以外，
  还应注意被转让股份的公司是否有参股其他公司股份及该参股公司的财产价值构成情况**
- ⚠ **教材例题的算法**：新加坡居民公司甲拥有中国居民公司乙 20% 的股份，
  公司乙**财产价值 100**（其中**不动产 40**）；公司乙又持有中国居民公司丙 **80%** 的股份，
  公司丙**财产价值 100**（其中**不动产 90**）
  - ⚠ **财产价值合并**：公司乙直接或间接拥有的财产价值 = **100 + 100 × 80% = 180**
  - ⚠ **不动产价值合并**：**40 + 90 × 80% = 112**
  - ⚠ **不动产比例 = 112 ÷ 180 ≈ 62%** → **超过 50%**
  - ⚠ **结论**：甲转让乙的股份时，**中国拥有征税权**
  - ⚠ 上述举例以**剔除公司乙和丙之间内部交易影响后的数额**为前提

**（三）三处配套结论**

- ⚠ **中国不动产占比 50% 以上的情形有两类**：
  ①新加坡居民拥有中国公司的股份（**或购买在新加坡上市的中国公司的股份**）；
  ②新加坡居民拥有某**中国境外**公司的股份，而**该公司股份价值的 50% 以上直接或间接由位于中国的不动产构成**
  —— ⚠ 两种情形下中国作为**不动产所在国**均拥有征税权
- ⚠⚠ **但须注意**：**如果不动产所在国国内法对此类情形下的转让收益不征税，
  即使协定规定有征税权，也并不意味着不动产所在国一定要征税**
- ⚠ **反滥用**：对**滥用企业组织形式、不是出于真正商业意图，而是以逃避税款或获取优惠的税收待遇
  为目的的间接转让中国公司股份**的情况，
  中国有权根据《中新税收协定》**第二十六条其他规则**的规定**启动反避税调查程序**

### 二、转让其他公司股权（第五款）

- ⚠ 转让**不动产组成的公司股份以外的其他股票**取得的收益，
  该项股票**又相当于参与缔约国一方居民公司 25% 的股权**，**可以在该缔约国一方征税**
- ⚠ **「参与 25% 资本」的三种情形**（国家税务总局 2012 年第 59 号公告）：
  1. ⚠ **该新加坡居民直接参与**该中国居民公司的资本
     —— ⚠ **通过其他名义参与人（含个人、公司和其他实体）**参与中国居民公司资本，
     且该新加坡居民**对于该名义参与人参与的资本享有排他性资本参与利益，
     并实质承担资本参与风险**的，该名义参与人参与的资本**可视同该新加坡居民直接参与**
  2. ⚠ **通过具有 10% 以上（含 10%）直接资本关系的单层或多层公司或其他实体**
     （含单个或多个参与链）**间接参与**
     —— ⚠ 间接参与的资本**按照每一参与链中各公司或其他实体的资本比例乘积计算**
     （例：甲拥有第三国乙 **50%**，乙拥有中国居民丙 **50%** → 甲通过乙间接拥有丙 **25%**）
     - ⚠ 若甲**同时直接拥有**丙 5% 的股份，则转让该 5% 股份时，
       **就应考虑其间接拥有的 25%**，从而达到该款规定的征税条件
     - ⚠ **但如果甲没有直接拥有丙的股份、只是通过乙间接拥有**，
       该款所说的**间接拥有股份的规定并不针对甲转让乙的股份收益问题**（除滥用情形外）
  3. ⚠ **与该新加坡居民具有显著利益关系的关联集团内其他成员**在该中国居民公司
     **直接参与或者通过具有 10% 以上（含 10%）直接资本关系的单层或多层公司或其他实体
     间接参与**的资本
     - ⚠ 间接参与的资本同样**按每一参与链的资本比例乘积计算**；
       ⚠ **但在汇总计算关联集团直接或间接参与总资本份额时，符合规定的每一参与链所参与的
       资本份额不重复计算**
     - ⚠ **「关联集团内成员」的两种界定**：
       ①该新加坡居民**为个人**的 → 与其具有**相同资本参与利益**的个人
       （包括其**配偶、父母及父母以上前辈直系亲属、子女及子女以下后辈直系亲属**）；
       ②该新加坡居民**为公司或其他实体**的 → **直接或间接拥有该新加坡居民 1% 资本**的个人
       （含与其配偶、父母及父母以上前辈直系亲属、子女以及子女以下后辈直系亲属**共同拥有**的情形）、
       公司或其他实体
     - ⚠ **教材例题**：新加坡公司乙直接拥有中国居民丙 20%；
       乙的母公司甲（**1% 控股**）直接拥有丙 **3%**；甲拥有丁 **50%** 股份，
       丁直接拥有丙 **6%**
       → ⚠ 甲为与乙具有显著利益关系的关联集团内成员：
       可计入甲直接持有丙的 **3%**；⚠ 丁为由甲直接拥有 **10% 以上**资本份额的公司，
       还可计入甲通过丁间接拥有丙的 **50% × 6% = 3%**
       → ⚠ **关联集团合计持有丙 = 20% + 3% + 3% = 26%** > 25% → **中国拥有征税权**

- ⚠ **部分协定的差异**：
  - 部分协定还要求「**该收益的收款人在转让行为前的 12 个月内，
    曾经直接或间接拥有该公司至少 25% 的股份**」
  - ⚠ 我国与**一部分国家（地区）**的协定中**则没有单列**对转让其他公司股份取得收益的税务处理规定
  - ⚠ 我国与**捷克、奥地利**的协定规定：**不论控股比例大小，均在被转让股份的公司所在国征税**
  - ⚠ 我国与**阿根廷**的协定规定：缔约国一方居民转让代表另一方公司资本的股份取得的收益，
    **可以在另一方征税**，⚠ **但如果转让人在转让前 365 天内的任一时间直接或间接持有
    该公司至少 25% 的资本，则所征税款不应超过收益的 10%**；**其他情况下不应超过**（另有规定）
  - ⚠ 我国与**墨西哥**的协定规定：转让第二款所述以外的代表缔约国一方居民公司参股的股票取得的收益，
    **可以在该缔约国一方征税**

- ⚠⚠ **两款的分界与其余规则**：
  - ⚠ 在一般情况下（**除滥用情形外**），新加坡居民转让其在中国居民公司或其他法人资本中的
    股份、参股或其他权利取得的收益，如果收益人在**转让行为前的十二个月内
    曾经直接或间接参与被转让公司 25% 的资本**，则**中国有权征税**
  - ⚠ **「直接转让」的限定**：新加坡居民转让中国居民公司或其他法人资本中的股份、参股或其他权利，
    在一般情况下（除滥用情形外）**是指直接转让情形**
  - ⚠ **如果被转让的股份不属于中国居民公司或其他法人资本中的股份、参股或其他权利**，
    **无论被转让股份的公司是否拥有中国居民公司或其他法人资本中的股份、参股或其他权利**，
    **均不适用第五款**，应视具体情形适用第十三条**其他款项**规定

### 三、其余各类财产的征税权

| 财产类型 | 征税权归属 |
|---|---|
| **不动产** | **不动产坐落地**国家 |
| **出售动产**（含存货、商品、商誉、许可权等）的营业性商品销售收益 | ⚠ 通常考虑与**企业利润征税权原则相一致**，由**转让者的居住国**征税 |
| **转让或出售常设机构的营业财产或从事个人独立劳务的固定基地财产** | 由**该财产的所在地国家**征税，即由其**所属常设机构或固定基地所在国** |
| **转让或出售从事国际运输的船舶、飞机** | ⚠ 由于**其位置不易确定**，一般由**船舶、飞机企业的居住国**征税 |
