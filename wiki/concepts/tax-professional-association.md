# 税务师行业协会

## Definition

**中国注册税务师协会**（**China Certified Tax Agents Association**，**CCTAA**，简称**中税协**），
是指**由「中国税务师（注册税务师）和税务师事务所等涉税专业服务机构及其从业人员」
「自愿结成」的「全国性、行业性、非营利性」社会组织**。

⚠ **主体构成（三类会员来源，须记全）**：**税务师（注册税务师）个人 + 税务师事务所等涉税专业服务机构 +
从业人员**。

⚠⚠ **本页的「两级组织」**（**勿混**）：

| 层级 | 名称 | ⚠ 教材中的简称 |
|---|---|---|
| ⚠ **全国级** | **中国注册税务师协会** | ⚠ **中税协** |
| ⚠ **地方级** | **省、自治区、直辖市和计划单列市注册税务师协会** | ⚠ **地方税协** |

⚠⚠ **另有一个「更基层」的层级**：**税务师事务所是「行业自律管理的基层单位」**——
⚠ **故本页的组织链条是「中税协 → 地方税协 → 税务师事务所」三级。**

⚠ **边界**：**「人」见 [[tax-advisor]]**；**「机构」见 [[tax-agent-firm]]**；
⚠ **本页只承载「行业组织」这一侧**（**书页 35–37**）。
⚠ **本页是《涉税服务实务》第一章第三节的第三块**。

## Key Points

### 一、税务机关、税务师行业协会、税务师事务所（税务师）的关系

⚠⚠ **教材给出的四层关系（本项是把「监管—自律」讲清楚的关键）**：

| # | ⚠ 关系 |
|---|---|
| **1** | ⚠⚠ **税务机关「应当加强对税务师行业协会的监督指导」，发挥税务师行业在涉税专业服务行业中的「示范和引领作用」**，**与注册会计师、律师、代理记账等其他相关行业协会建立「工作联系制度」，强化行业自律监督，引导合规诚信经营，促进涉税专业服务行业高质量发展** |
| **2** | ⚠ **税务机关「可以委托行业协会」对涉税专业服务机构提供涉税专业服务的「执业质量进行评价」** |
| **3** | ⚠⚠ **「全国税务师行业协会负责拟制涉税专业服务业务规范，报国家税务总局批准后施行」**——⚠⚠ **即业务规范的「拟制权在协会、批准权在总局」** |
| **4** | ⚠ **税务机关应当严格落实监督管理职责，积极发挥行业协会「自律监督和社会监督」作用**，⚠ **加强对税务师行业「党的建设」的指导** |

### 二、税务师行业协会的职责（**中税协 13 项**）

⚠⚠ **本项条目多、且含党建与行业治理内容，⚠ 建议按「政治与党建 → 行业规划与规范 → 自律与评价 →
考试与人才 → 交流与宣传 → 维权与兜底」六组分组记忆**：

| # | ⚠ 中税协的主要职责 | 组 |
|---|---|---|
| **1** | **认真学习贯彻落实党的路线方针政策和国家发展战略，严格落实主管部门和监管部门工作要求，确保行业建设和发展坚持正确方向** | 政治 |
| **2** | ⚠ **加强行业党的建设**——**建立健全行业基层党组织，以党建带团建、以党建促发展，推进党建与业务深度融合，协同做好统战工作，加强本会会刊、门户网站等「意识形态阵地建设」，增强会员政治素质和业务素质** | 政治 |
| **3** | **参与制定本行业发展规划并组织实施** | 规划 |
| **4** | ⚠⚠ **接受委托拟制涉税专业服务业务规范（准则、规则、指引）** | 规范 |
| **5** | ⚠ **对涉税专业服务机构提供涉税专业服务的「执业质量进行评价」** | 评价 |
| **6** | ⚠ **加强行业自律监督，制定有关「团体标准」**，**督促引导税务师事务所等涉税专业服务机构深化「内部及法人治理」，强化内控监督，依法合规诚信经营** | 自律 |
| **7** | ⚠ **协同税务机关，组织涉税专业服务机构开展税收宣传，提供「公益性税收服务援助」，促进税法遵从，增强社会依法纳税意识** | 宣传 |
| **8** | ⚠⚠ **统一组织和实施全国税务师职业资格考试**，**负责税务师职业资格证书「登记服务工作」**，**建立持有税务师职业资格证书人员的「诚信档案」，并提供查询服务** | 考试与档案 |
| **9** | **开展继续教育、专业培训及「产教融合」等工作，加强行业人才队伍建设，提升会员职业素质和业务能力** | 人才 |
| **10** | **组织业务和其他工作交流，开展税收理论及政策研究，建立完善形式多样的会员学习交流机制，开展与港澳台及国际交流活动** | 交流 |
| **11** | **加强行业对外宣传，开展行业文化建设，树立行业优秀品牌，提升行业社会知名度和社会影响力** | 宣传 |
| **12** | ⚠ **推进行业法治化建设，加强行业内外部协调，向政府及有关部门「反映会员诉求」，拓展会员业务范围，保障会员依法执业，「维护会员合法权益」** | 维权 |
| **13** | **办理法律、行政法规、规章和国家税务总局及有关部门授权或批准的其他事项**（**兜底**） | 兜底 |

⚠ **一处「附条件」的规定**：**业务范围中属于法律、法规等规定须经批准的事项，「依法经批准后开展」。**

### 三、税务师行业自律管理

⚠ **依据（两部文件）**：《**国务院社会团体登记管理条例**》《**中国注册税务师协会章程**》；
⚠ **中税协据此制定了《注册税务师行业自律管理办法（试行）》**。

#### （一）自律管理机构（**三级分工**）

| 层级 | ⚠ 定位 |
|---|---|
| ⚠ **中税协** | **行业自律管理的「统一指导机构」**，负责**全国**注册税务师行业自律建设的**指导、服务、管理和监督** |
| ⚠ **地方税协** | **行业自律管理的「地方组织」**，负责**本地区**注册税务师行业自律建设的**指导、服务、管理和监督** |
| ⚠⚠ **税务师事务所** | **行业自律管理的「基层单位」**——⚠ **在接受中税协、地方税协「指导、服务、管理、监督」的前提下，应当着重实施「自身的管理」** |

#### （二）会员管理

- ⚠ **中税协对会员实行「五项管理」**：**入会登记管理、执业管理、考核管理、培训管理和年检管理**；
- ⚠ **按照本会的会费缴纳办法，向会员收取会费**；
- ⚠ **会员须接受中税协指导、管理，认真履行「缴纳会费义务」**。

#### （三）会员教育

⚠ **两个方向**：
1. ⚠ **思想政治教育**：**加强党的路线、方针、政策教育和人生观、价值观教育，加强法律、诚信、道德和纪律教育**，
   **提高会员的思想政治素质，提高行业信誉和执业水平，营造良好的执业环境**；
2. ⚠ **业务能力教育**：**通过举办教育培训、经验交流、理论研讨等多种形式，从理论和实践上增强会员
   业务知识和专业技能，提高会员的业务素质和执业质量**。

#### （四）行业监督（**三级各自做什么**）

| 层级 | ⚠ 职责 |
|---|---|
| ⚠ **中税协** | **负责组织制订「行规、行约」**；**对地方税协、团体会员、个人会员执行行规、行约情况进行「指导监督」** |
| ⚠ **地方税协** | **组织制订「行规、行约实施办法及相应配套制度」**；**指导、监督会员自律情况** |
| ⚠ **税务师事务所** | **按照行规、行约和实施办法，「建立相应机制，制订具体落实措施」**；**对自律情况进行「定期考评」，实施「自我约束、自我监督、自我管理」** |

#### （五）奖励与惩戒

⚠ **中税协和地方税协「理事会」设立「奖惩委员会」，负责行业的奖励与惩戒事宜。**

> ⚠⚠ **与 [[tax-advisor]] 的区分（易混）**：该页的
> **「约谈→警告→通报批评→公开谴责→取消会员资格」五档**，
> ⚠ **依据是《中国注册税务师协会会员违规行为惩戒办法》，针对「违反职业道德」的自律措施**；
> ⚠ **本处的「奖惩委员会」是「自律管理的组织设置」**——
> ⚠⚠ **两者是「机构」与「措施」的关系；⚠ 且教材只在本处提到「奖惩委员会」，
> 未说明五档措施是否由该委员会作出，引用时勿自行连接。**

### 四、税务师行业涉税专业服务业务规范

⚠⚠ **业务规范的生成链条（本项是「谁定规范」的完整答案）**：

> **在国家税务总局的指导下，中税协依据《涉税专业服务基本准则（试行）》
> 《涉税专业服务职业道德守则（试行）》等制定了涉税专业服务业务规范，
> 自 2009 年起印发了《税务师行业涉税专业服务规范基本指引》等「累计 46 项」业务指引，
> 构建了税务师行业涉税专业服务业务规范（以下简称业务规范）新体系。**

⚠ **业务规范的作用**：**对于「提高税务师行业执业质量，明确法律责任，防范执业风险，
增强税务师行业公信力和影响力」有积极作用。**

#### （一）业务规范的总体要求

⚠⚠ **四项原则 + 一项约束**：**应当遵循涉税专业业务规范，
恪守「合法合理、客观独立、审慎胜任、诚实信用」原则，并「接受税务机关监管」。**

#### （二）业务规范的主要内容

⚠⚠ **业务规范的性质**：**是提供涉税专业服务的「职业道德标准、质量控制标准和业务执行标准」的总称**，
**是各级税务师行业协会实施「自律管理」的重要依据**。

⚠⚠ **业务规范的「七个组成部分」**：

| # | 组成 | ⚠ 说明 |
|---|---|---|
| **①** | **基本指引** | — |
| **②** | **职业道德指引** | — |
| **③** | **质量控制指引** | — |
| **④** | **程序指引** | — |
| **⑤** | **业务指引** | — |
| **⑥** | **具体业务指引** | — |
| **⑦** | **释义** | — |

#### （三）业务规范的制定主体、依据和原则

- ⚠ **制定主体**：**中税协负责「拟制、修订」税务师行业涉税专业服务规范**；
- ⚠ **依据**：**税收法律法规及相关规定**；
- ⚠⚠ **五项原则**：**合法、通用、规范、创新和及时更新**。

#### （四）业务规范的「内在逻辑」（**七个组成部分各自的定义，本项必考**）

| # | 指引 | ⚠ 教材定义 |
|---|---|---|
| **①** | ⚠⚠ **基本指引** | **指导税务师行业提供涉税专业服务的「基本规范」，是「制定涉税专业服务其他指引的基础」**；⚠⚠ **「制定其他指引应当遵循本指引」** |
| **②** | ⚠ **职业道德指引** | **提供涉税专业服务过程中应当遵循的「道德原则、职业纪律、职业操守」等方面的基本规范** |
| **③** | ⚠ **质量控制指引** | **为实现「执业质量目标」而实施的「程序、方法和措施」**（⚠ 见 [[tax-agent-firm]] 的质量控制节） |
| **④** | ⚠ **程序指引** | **从事的各项涉税专业服务业务在业务执行过程中应当遵循的「通用规范」** |
| **⑤** | ⚠⚠ **业务指引** | **《涉税专业服务管理办法（试行）》中确定的「八项涉税专业服务业务」的基本操作规范**——⚠⚠ **具体包括：纳税申报代办、一般税务咨询、专业税务顾问、「税收策划」、涉税鉴证、纳税情况审查、其他税务事项代办和其他税务代理**共八项业务指引 |
| **⑥** | ⚠ **具体业务指引** | **按照「不同税种、行业或者业务种类」制定的，指导具体业务实施的「操作流程和执业标准」** |
| **⑦** | ⚠ **释义** | **对各个指引中某些「条款、词语的内涵和外延」进行的解释和说明**，⚠ **或者根据税收法律法规及相关规定的变化，对指引相关条款作出的「修正或补充规定」** |

#### （五）⚠⚠ 已出台业务规范的「数量结构」（**本项是本节最硬的数字考点，且含一处 OCR 缺陷**）

> ⚠⚠ **教材原文**：**「目前，税务师行业已经出台的业务规范包括
> 基本指引（0 个）、行业指引（4 个）、业务指引（7 个）和具体业务指引（34 个）。」**

| 类别 | ⚠ 教材数字 |
|---|---|

| **行业指引** | **4 个** |
| **业务指引** | ⚠ **7 个**（⚠ 与上文所列「八项业务指引」不符，**照录待核**） |

⚠ **故「基本指引」应为 1 个**，⚠ **这是「库内互证」而非「按比例推补」**（⚠ 详见 Contradictions 节）。

| 位置 | OCR 原文 | ⚠ 本库判定 | ⚠ 互证依据 |
