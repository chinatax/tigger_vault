# 合同成本与合同取得成本

## Definition

合同成本与合同取得成本（Contract Costs）：为取得合同和履行合同而发生的支出的资本化与费用化划分。

判据是「**该支出是否与尚未履行的履约义务相对应**」——**对应得上就资本化**（合同履约成本／合同取得成本），**对应不上就费用化**（当期损益）。

## Key Points

- **应当计入当期损益的四类支出**（第 404 题，⚠ 逐条记忆）：
  - ①**管理费用**（除非这些费用**明确由客户承担**）
  - ②**非正常消耗**的直接材料、直接人工和制造费用（或类似费用）——
    这些支出为履行合同发生，但**未反映在合同价格中**
  - ③与履约义务中**已履行**（包括已全部履行或部分履行）部分相关的支出，
    即该支出与企业**过去的**履约活动相关
  - ④**无法**在尚未履行的与已履行（或已部分履行）的履约义务之间**区分**的相关支出
- **合同取得成本**：
  - 为取得合同发生的**增量成本**（如**取得合同时支付的销售佣金**）
    预期能够收回的 → 确认为「**合同取得成本**」资产
  - ⚠ 「增量成本」的含义是「**不取得合同就不会发生**」的成本
  - ⚠ **无论是否取得合同均会发生的差旅费** → **不计入**合同取得成本，计入当期损益
  - ⚠ 第 404 题 C 选项「取得合同时支付的销售佣金」属**应资本化**的项目，
    故不是「不应计入当期损益」的答案
- **合同履约成本**：
  - 为履行合同发生的、**不属于**其他企业会计准则规范范围、同时满足三个条件的支出 →
    确认为「**合同履约成本**」资产
  - 「**合同履约成本**」科目的**期末余额**计入资产负债表的「**存货**」项目
    - 例（第 408 题）：累计发生 220、按进度结转 180 → 期末余额 **40 万元**，列示于存货项目
- **与收入确认的配合**（第 408 题）：
  - 预收的款项应计入「**合同负债**」而非「预收账款」
  - 按履约进度确认收入时，按**应确认收入额**冲减合同负债
    - 例：合同标的 400、进度 60% → 借「合同负债」**240**、贷「主营业务收入」240
    - 同时借「主营业务成本」180、贷「合同履约成本」180
    - 合同负债期末余额 = 280 − 240 = **40 万元**
