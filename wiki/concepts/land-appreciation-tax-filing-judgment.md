# 土地增值税代理申报的专业判断关注事项

## Definition

⚠ **本页是《涉税服务实务》第五章《纳税申报代办服务》第三节之「一、土地增值税、印花税、契税
纳税申报代办」「「（二）资料收集与专业判断」之 1.（2）土地增值税的专业判断」**

应纳税额」三段铺开**，**扣除项目一段又按成本费用科目逐项展开（A–M）**。

## Key Points

### 一、⚠⚠ 「收入的关注事项」（**A–E**）

| # | ⚠ 关注项 | ⚠ 内容（**教材原句要点**） |
|---|---|---|
| **A** | **是否属于应税收入、应税收入是否与实际相符** | **纳税人是否按照税法规定准确划分「征税行为与不征税行为」**；⚠ **「纳税人已全额开具发票的，按照发票所载金额确认收入；未开具发票或未全额开具发票的，以交易双方签订的销售合同所载的售房金额及其他收益确认收入」**；⚠ **「销售合同所载商品房面积与有关部门实际测量面积不一致，在代理申报前已发生补、退房款的，应在计算土地增值税时予以调整」** |
| **B** | ⚠ **应税收入是否为「不含税」收入** | **清算项目适用「一般计税方法」的，应税收入是否包含增值税销项税额；适用「简易计税方法」的，应税收入是否包含增值税应纳税额** |
| **C** | ⚠ **非直接销售的收入确认** | **开发产品用于「职工福利、奖励、对外投资、分配给股东或投资人、抵偿债务、换取其他单位和个人的非货币性资产」等非直接销售业务的发生情况**；⚠ **「以房换地，在房产移交使用时是否视同销售不动产申报缴纳税款」**。⚠⚠ **非直接销售收入的确定方法和顺序**：**a. 按本企业在同一地区、同一年度销售的同类房地产的平均价格确认；b. 参照当地当年、同类房地产的市场价格或评估价值确认** |
| **D** | **确认收入的真实性、准确性** | **按项目设立的「销售合同台账」的相关内容**；**项目合同签订日期、交付使用日期、预售款确认收入日期、收入金额和成本费用的处理情况**；**销售退回、销售折扣与折让业务是否真实、内容是否完整、手续是否符合规定**，⚠ **重点关注给予「关联方」的销售折扣与折让是否合理**；**以土地使用权投资开发的项目是否按规定进行税务处理**；⚠ **按揭款收入有无申报纳税、有无挂在往来账（如「其他应付款」）不作销售收入申报**；**价格明显偏低的销售合同是否有正当理由** |
| **E** | ⚠ **特殊销售事项处理是否合规** | **「还本」方式销售商品房和以房产补偿给拆迁户时，是否按规定申报纳税**；**将房地产抵债转让给其他单位和个人或被法院拍卖的房产**；**在建工程整体转让**；**以房地产或土地作价入股投资或联营从事房地产开发，或房地产开发企业以其建造的商品房进行投资或联营** |

### 二、⚠⚠ 「扣除项目的关注事项」（**A–M，本页主体**）

#### A. ⚠ 扣除项目是否符合税法规定的「范围」

**取得土地使用权所支付的金额；房地产开发成本（「土地征用及拆迁补偿费、前期工程费、
建筑安装工程费、基础设施费、公共配套设施费、开发间接费用」）；房地产开发费用；
与转让房地产有关的税金；国家规定的其他扣除项目**。

#### B. ⚠ 扣除项目关注的「基本程序和方法」（**九步**）

**① 评价与扣除项目核算相关的内部控制是否存在、有效且一贯遵守；② 获取或编制扣除项目明细表，
并关注与明细账、总账及有关申报表是否一致；③ 关注相关合同、协议和项目概（预）算资料，
并了解其执行情况；④ 关注成本、费用支出项目，特别关注在「增值税一般计税方法」下
增值税进项税额的会计及税务处理是否正确；⑤ 关注扣除项目的记录、归集是否正确，
是否取得合法有效的凭证，会计及税务处理是否正确；⑥ 实地查看、询问调查和核实；
⑦ 剔除不属于申报代办项目所发生的开发成本和费用；⑧ 必要时，利用专家关注扣除项目**。

#### C. ⚠⚠ 各项扣除项目「分配或分摊」的顺序和标准

- ⚠ **能够直接归集**的：**关注是否取得合法、有效的凭证**；
- ⚠ **不能直接归集**的：**关注当期扣除项目「分配标准和口径是否一致」，
  是否按「代理申报项目可售建筑面积占多个项目可售总建筑面积的比例」或其他合理的方法计算确定**；
- ⚠⚠ **三类面积的一致性**：**关注并确认「房地产开发土地面积、建筑面积和可售面积」，
  是否与权属证、房产证、预售证、房屋测绘报告、销售记录、销售合同、有关主管部门的文件等
  载明的面积数据相一致**，**并确定各项扣除项目分摊所使用的分配标准**；
- ⚠⚠ **证据冲突时的处置（教材明示）**：**「如果上述性质相同的三类面积所获取的各项证据发生冲突、
  不能相互印证时，涉税服务人员应当「追加关注程序」，并按照「外部证据比内部证据更可靠」的原则，
  确认适当的面积」**；
- ⚠ **计算扣除项目具体金额时应考虑的因素**：**总成本、单位成本、可售面积、累计已售面积、
  累计已售分摊成本、未售分摊成本（存货）**。

#### D–M. ⚠ 各成本费用项目的关注要点

| ⚠ 项 | ⚠ 关注要点（**教材原句要点**） |
|---|---|
| **D. 取得土地使用权支付金额** | **是否获取合法有效的凭证、口径是否一致**；**同一土地有多个开发项目时「分配方法是否合理、分配比例和具体金额是否正确」**；⚠ **有无计入与取得土地使用权支付金额「无关」的费用**；⚠ **有无将「期间费用」计入**；⚠ **有无「预提」的**；⚠ **有无政府奖励、财政扶持等「返还土地出让金」的情形**；⚠ **有无将「延期支付土地出让金而产生的利息、滞纳金、逾期开发缴纳的土地闲置费」计入**；**比较、分析相同地段、相同期间、相同档次项目，判断是否存在明显异常** |
| **E. 土地征用及拆迁补偿费** | **征地费用、拆迁费用等支出是否真实、合理**；⚠ **支付给个人的拆迁补偿款所需的「拆迁（回迁）合同和签收花名册、转账支付记录」，并与相关账目核对**；**在由政府或者他人已征用和拆迁好的土地上进行开发的相关扣除项目是否按税收规定扣除**；⚠ **支付给回迁户的补差价款是否计入拆迁补偿费；回迁户支付给纳税人的补差价款是否「抵减」本项目拆迁补偿费**；⚠ **其他事项**：**a. 异地安置的房屋「属于自行开发建造的」→ 拆迁补偿费是否按税法规定计入本项目；「属于购入的」→ 是否以实际支付的购房支出计入；b. 货币安置拆迁的 → 是否凭合法有效凭据计入** |
| **F. 前期工程费** | **各项支出是否真实、合理**；⚠ **纳税人是否「虚列」前期工程费、土地开发费用是否按税收规定扣除**；**各项实际支出是否取得合法有效凭证** |
| **G. ⚠ 建筑安装工程费** | ⚠ **出包方式**：**重点关注「完工决算成本与工程概（预）算成本是否存在明显异常」**；**差异较大时应追加下列关注程序**：**a. 从合同管理部门获取施工单位与开发商签订的施工合同，并与相关账目核对；b. 实地查看项目工程情况，必要时向「建筑监理公司」取证；c. ⚠ 关注纳税人是否存在「利用关联方（尤其是各企业适用不同的征收方式、不同税率，不同时段享受税收优惠时）承包或分包工程，增加或减少建筑安装成本造价」的情形**。⚠ **自营方式**：**重点关注施工所发生的「人工费、材料费、机械使用费、其他直接费和管理费」支出是否取得合法有效的凭证、是否按规定进行会计处理和税务处理** |
| **H. 基础设施费** | **是否与代理申报项目有关、是否取得合法有效凭证**；**多个开发项目时是否分项目核算、是否将应计入其他项目的费用计入**；**是否含有其他企业的费用**；**是否含有以明显不合理的金额开具的各类凭证**；**是否将期间费用计入**；**有无预提**；**获取概（预）算资料比较分析**；**应负担各项开发成本是否已按规定分摊**；**分摊和扣除是否符合税法规定** |
| **I. 公共配套设施费** | **公共配套设施的「界定是否准确、产权是否明确」**；（**其余各项与 H 同构**） |
| **J. 开发间接费用** | **是否取得合法有效凭证**；**多个开发项目时是否分项目核算**；**是否含有明显不合理金额的凭证**；**是否将期间费用计入**；**有无预提**；⚠ **纳税人的预提费用是否为管理和组织经营活动而发生的管理费用、是否在本项目中予以剔除**；⚠ **「在计算加计扣除项目基数时，关注是否剔除了已计入开发成本的借款费用」** |
| **K. ⚠ 房地产开发费用** | ⚠ **「关注「应据实列支的财务费用」是否取得合法有效的凭证，「除据实列支的财务费用外的房地产开发费用」是否按规定比例计算扣除」**。⚠ **据实扣除的利息支出，包括**：**a. 据实申报时是否将利息支出「从开发成本中调整至开发费用」；b. 分期开发项目或同时开发多个项目的一般性贷款利息支出，是否「按项目合理分摊」；c. 「利用闲置专项借款对外投资取得的收益」是否「冲减利息支出」；d. 是否超过按「商业银行同类同期贷款利率」计算的金额；「超过贷款期限的罚息」是否扣除；e. 是否剔除「借款手续费、咨询费、顾问费等利息支出以外的费用」** |
| **L. ⚠ 与转让房地产有关的税金** | ⚠ **a.「与转让房地产有关的税金不包括增值税」；b. 纳税人实际缴纳的城市维护建设税、教育费附加，凡能够按代理申报项目准确计算的，「允许据实扣除」；凡不能准确计算的，按该项目预缴时实际缴纳的扣除**；**关注与转让房地产收入有关的「地方教育附加、印花税」扣除是否正确**；⚠⚠ **「对于不属于申报代办范围或者不属于转让房地产时发生的税金及附加，或者按照预售收入（不包括已经结转销售收入部分）计算并缴纳的税金及附加，「不应作为申报代办的扣除项目」」** |
| **M. ⚠⚠ 国家规定的「加计扣除」项目** | **a. 取得土地使用权后「未进行任何形式的开发即转让」的**；**b. 取得土地使用权后「仅进行土地开发（如『七通一平』等）、不建造房屋即转让土地使用权」的**；**c. 取得了房地产产权后「未进行任何实质性的改良或开发即再行转让」的**——⚠ **三项均关注「是否按税收规定计算扣除项目金额，核实有无违反税收规定加计扣除的情形」**；**d. 县级以上人民政府要求房地产开发企业在售房时代收的各项费用**——**关注其代收费用是否计入房价并向购买方一并收取，核实有无将代收费用作为加计扣除的基数**；**e. 取得「在建工程」继续开发支付的成本「可以」加计扣除**；**f. 转让「非住宅类旧房及建筑物」时**；**g. 纳税人「未取得房地产开发资质」的** |

### 三、⚠ 「应纳税额的关注事项」（**A–D**）

| # | ⚠ 情形 | ⚠ 关注内容 |
|---|---|---|
| **A** | **应纳税额的关注事项** | **a. 关注申报代办项目的「收入总额」是否符合税收规定、计算是否正确；b. 关注「扣除金额及其增值额」是否符合税收规定；⚠ 多个开发项目时关注收入与扣除项目金额是否属于「同一项目」；⚠ 同一项目既有普通住宅又有非普通住宅、其他类型房地产的，关注「收入额与扣除项目金额是否分开核算」；⚠⚠ 同一项目「一段时间免税、一段时间征税」的，应当特别关注「收入的实现时间及其扣除项目的配比」；c. 关注「增值额与扣除项目之比」的计算是否正确，并确认适用税率；d. 关注并确认当期应纳税额及应补或应退税额；e. ⚠ 关注「普通标准住宅」的会计核算情况，以及「普通住宅的增值率是否超过 20%」** |
| **B** | ⚠ **预缴税款交易事项** | **a. 开发项目「施工许可证、预售许可证」，关注开发项目「施工时点、预售时点」；b. 预售合同的签订情况，了解预售房款的收取情况；c. 纳税人账面「预收款」的核算，是否存在将销售不动产取得的预售收入在「预收账款」以外的科目核算；d. 以直接支付货币方式收取的预收房款是否计入预收款；e. 是否存在「已符合税法规定的销售不动产收入确认条件、而按预收款进行土地增值税处理」的情形；f. 预征的「计征依据」是否按税法规定「扣减了应预缴的增值税税款」；g. 选择的「预征率」是否正确；h. 取得预收款后是否向主管税务机关预缴税款** |
| **C** | ⚠ **清算后尾盘销售** | **a. 清算时「可扣除项目总额、可售建筑面积」；b. 销售的价格是否合理；c. 扣除项目金额计算是否符合规定；d. 增值额与扣除项目之比的计算是否正确；e. 计算土地增值税适用税率是否正确** |
| **D** | ⚠⚠ **转让旧房及建筑物** | **a. ⚠ 「纳税人是个人的，转让『住宅类』的旧房「暂免征收」土地增值税，转让『非住宅类』旧房及建筑物应按规定缴纳」；b. ⚠ 「纳税人是单位的，转让的旧房「无论住宅类还是非住宅类」，都应按规定缴纳」；c. 转让价款是否符合税法规定；d. 扣除项目金额是否按税法规定计算、有无违反规定加计扣除；e. ⚠ 扣除项目金额是否取得合法有效凭证**——**「原购房发票是否经主管税务机关确认」（种类有营业税发票、增值税普通发票、增值税专用发票）；「是否能够提供原购房契税完税凭证」，「如能提供的，准予作为『与房地产有关税金』予以扣除，但不作为加计 5% 的基数」；「不能提供原购房发票的」，关注是否按税法规定计算扣除项目金额**；**关注纳税人计算土地增值税税款时所选择的税率是否正确** |
