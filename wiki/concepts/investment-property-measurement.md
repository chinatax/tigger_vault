# 投资性房地产的范围与后续计量

## Definition

投资性房地产的范围与后续计量（Investment Property Measurement）：为**赚取租金**或**资本增值**（或两者兼有）而持有的房地产的范围界定，及其两种后续计量模式的选择与规则。

本考点的两条分界线是：**房地产企业的「待售房产」是存货而非投资性房地产**，以及**公允价值模式一旦采用不得改回成本模式**。

## Key Points

- **范围的边界**（第 303 题，⚠ 两处反向陷阱）：
  - ✅ **属于**投资性房地产：
    - **已出租**的投资性房地产租赁期满，**暂时空置但继续用于出租**的
    - **已经营出租**但仍由本企业提供**日常维护**的建筑物
    - **生产企业**持有并准备**增值后转让的土地使用权**
  - ❌ **不属于**：
    - ⚠ **房地产企业**持有并准备**增值后出售**的房屋 → 作为**存货**处理
    - ⚠ 企业出租给**职工居住的宿舍** → 属于企业**自用**的房屋，作为**固定资产**核算
  - 判据：看**持有目的**与**企业性质**——房地产开发企业的房产天然是存货；「出租给谁」也影响定性
- **两种后续计量模式**（第 312、316 题）：

  | 项目 | **成本模式** | **公允价值模式** |
  |---|---|---|
  | 折旧/摊销 | **应当计提** | ⚠ **不计提** |
  | 减值 | 计提，且**一经计提不得转回** | ⚠ **不计提** |
  | 期末计价 | 账面价值 − 折旧摊销 − 减值 | **公允价值变动计入「公允价值变动损益」** |
  | 处置时的结转 | 按**账面价值**借记「**其他业务成本**」 | 同左 |
  | 模式变更 | ⚠ **不得**从公允价值模式变更为成本模式 | 成本模式**可以**变更为公允价值模式（作**会计政策变更**，差额调整**留存收益**） |

  - ⚠ 采用成本模式计量时，**应当计提折旧或进行摊销**（干扰项称「不计提折旧或摊销」）
  - ⚠ 采用成本模式计量时，已计提的减值**持有期间不得转回**
- **公允价值模式的适用范围**：需同时满足「投资性房地产所在地有**活跃的房地产交易市场**」
  以及「能够从市场上取得**同类或类似**房地产的市场价格及其他相关信息」
