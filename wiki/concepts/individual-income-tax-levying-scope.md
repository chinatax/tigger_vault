# 个人所得税征税对象（九项所得）

## Definition

个人所得税征税对象（IIT Levying Scope）：《个人所得税法》列举征税的**九项个人所得**，
以及《个人所得税法实施条例》及相关法规对各项所得的**范围界定**。

⚠ 本页的考点不在税率与计算，而在**边界**——同一笔收入归到哪个税目，
直接决定费用扣除、税率与征管方式。因此每一项都要抓「**它把什么算了进来、又把什么排除出去**」。

## Key Points

### 一、工资、薪金所得

**定义**：个人因**任职或者受雇**而取得的工资、薪金、奖金、年终加薪、劳动分红、津贴、补贴
以及与任职或者受雇有关的其他所得。

- ⚠ 本质是**非独立个人劳动所得**——劳动由他人指定、安排并接受管理，
  劳动者与单位之间存在**雇佣与被雇佣关系**
- ⚠ **年终加薪、劳动分红**不分种类和取得情况，**一律**按「工资、薪金所得」课税；
  奖金指所有**具有工资性质**的奖金（免税奖金另有规定）

**⚠ 不予征税的四项补贴、津贴**（不属于工资、薪金性质，或不属于纳税人本人「工资、薪金所得」项目）：

1. **独生子女补贴**
2. 执行**公务员工资制度**未纳入基本工资总额的**补贴、津贴差额和家属成员的副食品补贴**
3. **托儿补助费**
4. **差旅费津贴、误餐补助**
   —— ⚠ 「误餐补助」指按财政部门规定，个人因公在城区、郊区工作，不能在单位或返回就餐、
   确实需要在外就餐，根据**实际误餐顿数**按标准领取的误餐费；
   **以误餐补助名义发给职工的补助、津贴不包括在内**

**⚠ 六项特殊情形的归属**：

| 情形 | 归属与规则 |
|---|---|
| **出租车驾驶员**单车承包或承租方式运营，从事客货营运取得的收入 | 按「**工资、薪金所得**」计征 |
| **公务用车、通讯补贴收入** | 扣除**一定标准的公务费用**后按「工资、薪金所得」计征。⚠ **按月发放**的并入**当月**；**不按月发放**的**分解到所属月份**并与该月工资合并。⚠ 公务费用扣除标准由**省级税务局**调查测算、报**省级人民政府批准**后确定并报**国家税务总局备案** |
| **科技成果转化现金奖励** | 自 2018-07-01 起，依法批准设立的**非营利性研究开发机构和高等学校**依《促进科技成果转化法》从**职务科技成果转化收入**中给予科技人员的现金奖励，**减按 50%** 计入科技人员**当月**「工资、薪金所得」，⚠ 且该项所得**还需并入综合所得**进行年度汇算。所谓现金奖励指在取得科技成果转化收入**三年（36 个月）内**奖励给科技人员的现金 |
| **单位超标准缴付「三险一金」** | 单位**超过规定比例和标准**为个人缴付的基本养老保险费、基本医疗保险费、失业保险费和住房公积金，**超过部分应并入**个人当期的工资、薪金收入计征 |
| **单位统一购买的商业健康保险** | 应**并入**员工个人工资、薪金所得，**视同个人购买**，允许在当年（月）计算应纳税所得额时税前扣除，**扣除限额 2400 元/年（200 元/月）** |
| **税收递延型商业养老保险的养老金收入** | ⚠ 其中 **25% 免税**，其余 **75% 按 10% 的比例税率**计算缴纳，税款**计入「工资、薪金所得」**项目，由保险机构代扣代缴，⚠ **不需并入综合所得**年度汇算 |

### 二、劳务报酬所得

**定义**：个人从事劳务取得的所得，包括设计、装潢、安装、制图、化验、测试、医疗、法律、会计、
咨询、**讲学**、翻译、审稿、书画、雕刻、影视、录音、录像、**演出、表演**、广告、展览、
技术服务、介绍服务、经纪服务、代办服务以及其他劳务取得的所得。

**⚠ 与工资、薪金所得的分界线**：工资、薪金所得是个人从事**非独立劳动、从任职单位**领取的报酬，
**存在**雇佣与被雇佣关系；劳务报酬所得是个人**独立**从事某种技艺、
**独立提供**某种劳务而取得的所得，**不存在**雇佣关系。

- ⚠ **在校学生**因参与**勤工俭学**活动取得的应税所得 → 按「**劳务报酬所得**」征收
- ⚠ **董事费、监事费的两分**：
  - 个人担任公司董事、监事，**且不在公司任职、受雇**的 → 属劳务报酬性质，按「**劳务报酬所得**」
  - 个人在公司（**包括关联公司**）**任职、受雇**同时兼任董事、监事的 →
    与**个人工资收入合并**，统一按「**工资、薪金所得**」
- ⚠ **兼职**取得的收入 → 按「劳务报酬所得」
- ⚠ **营销业绩奖励性质的旅游**：企业和单位对营销业绩突出人员以**培训班、研讨会、工作考察**等名义
  组织旅游活动，通过**免收差旅费、旅游费**实行的营销业绩奖励（含实物、有价证券等），
  应根据**所发生费用全额**计入营销人员应税所得：
  - 对企业和单位**雇员** → 与当期工资、薪金**合并**，按「工资、薪金所得」
  - 对**其他人员** → 作为当期劳务收入，按「劳务报酬所得」
- ⚠ **广告市场**：个人在广告设计制作、发布过程中提供**名义、形象**取得的所得 → 按「劳务报酬所得」；
  提供**其他劳务**取得的所得 → 视情况分别按劳务报酬、稿酬、特许权使用费等项目征收。
  ⚠ 扣缴义务人为**直接向上述个人支付所得**的广告主、广告经营者、受托从事广告制作的单位和广告发布者；
  ⚠ 扣缴义务人的**本单位人员在广告设计、制作、发布过程中取得的由本单位支付**的所得 →
  按「**工资、薪金所得**」（**不是**劳务报酬）
- ⚠ 不能准确提供或划分名义、形象及劳务所得的纳税人 → 主管税务机关可**参照同类标准核定**应纳税所得额

### 三、稿酬所得

**定义**：个人因其作品以**图书、报刊等形式出版、发表**而取得的所得。
⚠ 作品包括文学作品、书画作品、摄影作品及其他作品；
⚠ **作者去世后，财产继承人取得的遗作稿酬**亦按「稿酬所得」征收。

- ⚠ **任职、受雇于报纸、杂志等单位的记者、编辑等专业人员**，
  因**在本单位的报纸、杂志上发表作品**取得的所得 → 属因任职受雇取得的所得，
  应**与当月工资收入合并**按「工资、薪金所得」征收
- ⚠ **除上述专业人员以外**的其他人员在本单位的报纸、杂志上发表作品取得的所得 →
  按「**稿酬所得**」征收
- ⚠ **出版社的专业作者**撰写、编写或翻译的作品，由**本社以图书形式出版**而取得的稿费收入 →
  按「**稿酬所得**」

### 四、特许权使用费所得

**定义**：个人提供**专利权、商标权、著作权、非专利技术以及其他特许权的使用权**取得的所得。
⚠ **提供著作权的使用权取得的所得，不包括稿酬所得**。

**四项特许权**：①**专利权**（具专有性/独占性、地域性、时间性）；②**商标权**；
③**著作权**（即版权，兼具人身权与财产权性质，含发表权、署名权、修改权、保护权、使用权和获得报酬权）；
④**非专利技术**（专利技术以外的专有技术，多处于保密状态）。

- ⚠ **手稿拍卖**：作者将自己的**文字作品手稿原件或复印件公开拍卖（竞价）**取得的所得，
  属于**提供著作权的使用所得**，应按「**特许权使用费所得**」计征
  （⚠ 而非「财产转让所得」）
- ⚠ 个人取得**特许权的经济赔偿收入** → 按「特许权使用费所得」计征
- ⚠ **剧本使用费**：自 2002-05-01 起，剧本作者从电影、电视剧制作单位取得的剧本使用费，
  **不再区分剧本的使用方是否为其任职单位**，统一按「**特许权使用费所得**」计征

### 五、经营所得

**四种情形**：①**个体工商户**从事生产、经营活动取得的所得，**个人独资企业投资人、
合伙企业的个人合伙人**来源于**境内注册**的个人独资企业、合伙企业生产、经营的所得；
②个人依法从事**办学、医疗、咨询**以及其他有偿服务活动取得的所得；
③个人对**企业、事业单位承包经营、承租经营以及转包、转租**取得的所得；
④个人从事其他生产、经营活动取得的所得。

**⚠ 比照「个体工商户的生产、经营所得」计征的四种情形**：

1. 从事**个体出租车运营**的出租车驾驶员取得的收入
2. 出租车**属个人所有**但**挂靠**出租汽车经营单位或企事业单位、驾驶员向挂靠单位缴纳管理费的，
   或出租汽车经营单位**将出租车所有权转移给驾驶员**的，驾驶员从事客货运营取得的收入
3. 个人从事**彩票代销**业务而取得的所得
4. ⚠ **个人独资企业、合伙企业的个人投资者**以企业资金为**本人、家庭成员及其相关人员**支付
   **与企业生产经营无关的消费性支出**及购买**汽车、住房等财产性支出** →
   视为企业对个人投资者**利润分配**，并入投资者个人的**生产经营所得**

- ⚠ **「四业」不征税**：个体工商户或个人专营**种植业、养殖业、饲养业、捕捞业**的，**不征收**个人所得税；
  ⚠ 但**不属于原农业税、牧业税征税范围**的，应对其所得**计征**；
  ⚠ 同时对**进入各类市场销售自产农产品的农民**取得的所得**暂不征收**；
  ⚠ **兼营**「四业」**且单独核算**的比照办理——属于征收个人所得税的，
  应**与其他行业的生产、经营所得合并**计征；**不能单独核算**的，**就其全部所得**计征
- ⚠ **与生产、经营活动无关的其他应税所得应分开计税**：如对外投资取得的股息 →
  按「**利息、股息、红利所得**」**单独**计征。
  ⚠ 个人独资企业对外投资分回的利息或股息、红利，**不并入企业的收入**，
  而**单独**作为投资者个人取得的利息、股息、红利所得；
  ⚠ 以**合伙企业**名义对外投资分回利息或股息、红利的，应按**相应比例**确定各个投资者的所得

**⚠ 对企事业单位承包经营、承租经营所得的两条路径**：

| 市场主体登记 | 处理 |
|---|---|
| **改变为个体工商户** | 属个体工商户的生产、经营所得 → 按「**个体工商户的生产、经营所得**」计征，⚠ **不再征收企业所得税** |
| **仍为企业** | ⚠ **不论分配方式如何，均应先缴企业所得税**，再就承包承租经营者按合同取得的所得缴个人所得税：<br>①承包、承租人对**经营成果不拥有所有权**，仅按合同取得一定所得 → 按「**工资、薪金所得**」<br>②按合同**只向发包方、出租人缴纳一定费用**，缴纳后经营成果**归其所有** → 按「**对企事业单位承包经营、承租经营所得**」 |

### 六、利息、股息、红利所得

**定义**：个人拥有**债权、股权**而取得的利息、股息、红利所得。⚠ **利息**一般指存款、贷款和债券的利息；
**股息**指按一定比率派发的每股息金；**红利**指超过股息部分的利润、按股派发的红股。

- ⚠ **职工个人以股份形式取得的量化资产**：
  - **仅作为分红依据、不拥有所有权**的企业量化资产 → **不征收**个人所得税
  - 以股份形式取得的量化资产**参与企业分配而获得的股息、红利** → 按「利息、股息、红利所得」计征
- ⚠ **企业购买车辆并将车辆所有权办到股东个人名下** → 实质为对股东的**红利性质的实物分配**，
  按「利息、股息、红利所得」计征
- ⚠ **除个人独资企业、合伙企业以外**的其他企业的个人投资者，以企业资金为本人、家庭成员及其
  相关人员支付**与企业生产经营无关**的消费性支出及购买汽车、住房等财产性支出 →
  视为对个人投资者的**红利分配**，按「**利息、股息、红利所得**」计征
  （⚠ 与上面经营所得的**第 4 种比照情形**形成对照：**独资/合伙 → 经营所得；其他企业 → 利息股息红利**）

### 七、财产租赁所得

**定义**：个人出租**不动产、机器设备、车船以及其他财产**取得的所得。
⚠ 个人取得的**财产转租收入**属于征税范围。
⚠ 纳税义务人**以产权凭证为依据**确定；无产权凭证的由主管税务机关根据实际情况确定；
⚠ **产权所有人死亡、未办理产权继承手续期间**该财产出租而有租金收入的，
**以领取租金的个人**为纳税义务人。

### 八、财产转让所得

**定义**：个人转让**有价证券、股权、合伙企业中的财产份额、不动产、机器设备、车船
以及其他财产**取得的所得。

- ⚠ **股票转让所得**：对个人转让**境内上市公司**的股票转让所得**暂不征收**个人所得税；
  ⚠ 对内地个人投资者通过**沪港通、深港通**投资香港联交所上市股票取得的转让差价所得，
  **自 2019-12-05 至 2027-12-31 暂免征收**
- ⚠ **量化资产股份转让**：对职工个人以股份形式取得的**拥有所有权**的企业量化资产**暂缓征收**；
  待个人**将股份转让**时，就其**转让收入额**减除**个人取得该股份时实际支付的费用支出和
  合理转让费用**后的余额，按「财产转让所得」计征
- **自有住房转让**（两处优惠）：①自 **2026-01-01 至 2027-12-31**，
  出售自有住房并在**出售后 1 年内**重新购房的，**退还**已缴个人所得税（详见
  [[individual-income-tax-preferences]] 与 [[individual-property-income-tax]]）；
  ②对个人转让**自用 5 年以上、并且是家庭唯一生活用房**取得的所得，**继续免征**
- ⚠ **财产拍卖**：个人通过拍卖市场拍卖**除自己的文字作品手稿原件或复印件之外**的财产取得的所得，
  按「财产转让所得」计征
  —— ⚠ **手稿拍卖是唯一的例外**，属「特许权使用费所得」而非「财产转让所得」

### 九、偶然所得

**定义**：个人**得奖、中奖、中彩以及其他偶然性质**的所得。
⚠ **得奖**指参加各种有奖竞赛活动取得名次获得的奖金；**中奖、中彩**指参加有奖活动
（如有奖销售、有奖储蓄或购买彩票），经规定程序抽中、摇中号码而取得的奖金。

**⚠ 按「偶然所得」计征的三类（财政部、税务总局公告 2019 年第 74 号）**：

1. 个人为**单位或他人提供担保**获得收入
2. ⚠ **房屋产权所有人将房屋产权无偿赠与他人**的，**受赠人**因无偿受赠房屋取得的受赠收入
   —— ⚠ **但对当事双方不征收个人所得税**的三种情形：
   ①赠与**配偶、父母、子女、祖父母、外祖父母、孙子女、外孙子女、兄弟姐妹**；
   ②赠与对其**承担直接抚养或者赡养义务**的抚养人或赡养人；
   ③房屋产权所有人**死亡**，依法取得房屋产权的**法定继承人、遗嘱继承人或者受遗赠人**
   - ⚠ **受赠收入的应纳税所得额** = **房地产赠与合同上标明的赠与房屋价值 − 赠与过程中受赠人
     支付的相关税费**
   - ⚠ 合同标明的房屋价值**明显低于市场价格**或**未标明**价值的 →
     税务机关可依据**市场评估价格**或其他合理方式确定
3. ⚠ **企业赠送礼品**：企业在**业务宣传、广告**等活动中**随机**向**本单位以外**的个人赠送礼品
   （**包括网络红包**），以及企业在**年会、座谈会、庆典**等活动中向**本单位以外**的个人赠送礼品，
   个人取得的礼品收入按「偶然所得」计征
   —— ⚠ **除外**：企业赠送的具有**价格折扣或折让性质**的消费券、代金券、抵用券、优惠券等礼品
   - ⚠ **礼品收入的应纳税所得额**：企业赠送的礼品是**自产产品（服务）**的，
     按该产品（服务）的**市场销售价格**确定；是**外购商品（服务）**的，
     按该商品（服务）的**实际购置价格**确定

- ⚠ **兜底条款**：个人取得的所得**难以界定**应纳税所得项目的，由**国务院税务主管部门**确定

## Contradictions

### ⚠ 手稿拍卖所得的税目归属（题库与教材口径冲突，2026-09-22 发现）

- **题库口径**（[[cta-550-tax-law-2-questions]]）：**手稿原件**拍卖 → **财产转让所得**；
  **手稿复印件**拍卖 → **特许权使用费所得**
- **教材口径**（[[cta-tax-law-2-textbook]]）：**手稿原件与复印件**拍卖 → **均为特许权使用费所得**；
  仅当拍卖的是「自己的文字作品手稿原件或复印件**之外**」的财产时才归**财产转让所得**
