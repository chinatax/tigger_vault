# 不属于应税交易的情形

## Definition

不属于应税交易的情形（Non-taxable Transaction）：虽在**外观上**接近应税交易，但法律明定
**不征收增值税**的项目。与「免税」有本质区别——**免税**是"本属应税、但给予优惠"，
**不征税**是"根本不在征税范围内"。区分二者直接影响**进项税额能否抵扣**：
不征税项目对应的进项通常可正常抵扣，免税项目对应的进项通常不得抵扣。

## Key Points

- **法定不征税的情形**：
  1. 员工为**受雇单位或者雇主**提供取得**工资、薪金**的服务
  2. 收取**行政事业性收费、政府性基金**
  3. 依照法律规定被**征收、征用**而取得**补偿**
  4. 取得**存款利息**收入
  5. 其他不属于应税交易的情形
- **明确列举的"其他"情形**：
  - 各党派、共青团、工会、妇联、中科协、青联、台联、侨联收取**党费、团费、会费**，
    以及政府间国际组织收取**会费**——属于**非经营活动**
  - **资产重组**（见下）
- **财政补贴**（自 2020-01-01 起）：与纳税人销售货物、劳务、服务、无形资产、不动产的
  **收入或者数量直接挂钩**的 → **应**按规定计算缴纳增值税；
  其他情形的财政补贴收入 → **不属于**增值税应税收入，**不征收**。
- **资产重组不征税的四个条件**（须**同时**符合）：
  1. 重组标的是**可以相对独立运营的经营业务**
  2. 应将全部或部分**资产，与相关联的对应债权、负债和员工共同组成资产包**一并转让
     ——资产包中应当**同时包括**资产、债权、负债和员工
  3. 具有**合理的商业目的**，且不以减少、免除、推迟缴纳增值税税款或者提前退税、多退税款为主要目的
  4. 转让方属于**一般纳税人**的，接收方也应当属于**一般纳税人**
  符合条件的，涉及的货物、金融商品、无形资产、不动产转让，**不征收增值税**。

## Contradictions

**两份清单只有一项重叠（已记录，不取平均）**：[[freight-and-labour-tax-line-2025]]（题库，旧法）提到的
"不征收增值税项目"为**存款利息、被保险人获得的保险赔付、公积金管理中心代收的住宅专项维修资金**；
本概念来源（教材第三节，新法）列举的是员工服务、行政事业性收费/政府性基金、征收征用补偿、存款利息等。
**两份清单只有"存款利息"重叠**——差异源于**法律体制不同**（旧法附件 2 的列举 vs 新法条款）。
具体以现行《增值税法》及配套规定为准。
