# 涉税鉴证业务概述（基本规定·准备·取证·评价·底稿·报告）

## Definition

⚠ **本页是《涉税服务实务》第六章《涉税鉴证与纳税情况审查服务》**第一节「涉税鉴证业务概述」**
（书页 364–368，txt 369–373）——**即「六目」：一、基本规定；二、鉴证准备；三、证据收集评价；
四、鉴证事项评价；五、工作底稿；六、鉴证报告**。

> ⚠ **教材原句（业务定义）**：「**涉税鉴证业务**是指**鉴证人**接受委托，按照**税收法律法规以及相关规定**，
> 对**被鉴证人涉税事项的合法性、合理性**进行**鉴定和证明**，并**出具书面专业意见**的服务活动」。

⚠⚠ **七类常见鉴证业务（教材列举）**：**企业所得税汇算清缴鉴证、研发费用税前加计扣除鉴证、
企业资产损失税前扣除鉴证、高新技术企业专项认定鉴证、土地增值税清算鉴证、税务司法鉴定、
纳税情况审查服务**和其他涉税事项鉴证。

> ⚠ **教材原句（章导语的「共性与个性」）**：「**各类鉴证业务开展都包含
> 「鉴证准备、证据收集评价、鉴证事项评价、编制工作底稿、出具鉴证报告」等环节，
> 但不同鉴证业务的鉴证证据和关注事项各不相同，具体方法也不一样**」。

⚠ **边界**：
- ⚠⚠ **本页是「鉴证业务的通用程序」**；**各具体鉴证业务**见
  [[cit-annual-settlement-certification]]、[[rd-expense-super-deduction-certification]]、
  [[asset-loss-deduction-certification]]（**批 1**）；
  **高新技术企业认定鉴证、土地增值税清算鉴证、税务司法鉴定、纳税情况审查**见**批 2**；
- ⚠ **本页与题库时代的合集页 [[tax-certification-service]]（**已转为第六章总纲／枢纽页**）的关系**：
  ⚠ **该页记「鉴证与审查在涉税专业服务体系中的定位与独立性要求」，本页记「鉴证业务的程序本体」**。

## Key Points

### 一、⚠⚠ 涉税鉴证业务「基本规定」

#### （一）业务定义与内容

⚠ **见上「Definition」**；**七类常见业务同前**。

#### （二）⚠ 基本要求（**五项**）

| # | ⚠ 要求（**教材原句要点**） |
|---|---|
| **①** | ⚠ **信息报送**：**应当按照《国家税务总局关于采集涉税专业服务基本信息和业务信息有关事项的公告》（国家税务总局公告 2017 年第 49 号）**和**《国家税务总局关于进一步完善涉税专业服务监管制度有关事项的公告》（国家税务总局公告 2019 年第 43 号）**要求，**向税务机关报送《涉税专业服务机构（人员）基本信息采集表》和其他相关信息** |
| **②** | ⚠⚠ **「信任保护原则」与四项「有权终止业务」的情形**：**「税务师事务所及涉税服务人员提供涉税鉴证业务，实行「信任保护原则」」**——**存在以下情形之一的，涉税专业服务机构及涉税服务人员「有权终止业务」**：**a. 委托人违反法律、法规及相关规定的；b. 委托人提供不真实、不完整资料信息的；c. 委托人不按照业务结果进行申报的；d. 其他因委托人原因限制业务实施的情形**。⚠ **「如已完成部分约定业务，应当按照协议约定收取费用，并就已完成事项进行「免责性声明」，由委托人承担相应责任，涉税专业服务机构及涉税服务人员不承担该部分责任」** |
| **③** | ⚠⚠ **「鉴证与代理不相容原则」**：**「承办被鉴证单位「代理服务」的人员，不得承办被鉴证单位的「涉税鉴证业务」」** |
| **④** | **应当遵循《税务师行业涉税专业服务程序指引（试行）》**，**在业务承接、业务计划、业务实施、业务结果等鉴证服务各阶段，充分考虑对执业风险的影响因素，使执业风险降低到可以接受的程度** |
| **⑤** | **中税协在《涉税鉴证业务指引》基础上制定了若干具体鉴证业务指引并修订完善**（**具体内容参看中税协官网「执业规范」**） |

#### （三）⚠ 业务术语（**七个**）

| ⚠ 术语 | ⚠ 定义（**教材原句**） |
|---|---|
| **委托人** | **委托税务师事务所对涉税事项进行鉴证的单位或个人** |
| **鉴证人／受托人** | **接受委托，具有提供涉税鉴证业务资质的涉税专业服务机构及涉税服务人员** |
| **被鉴证人** | **鉴证事项相关的单位或个人；「被鉴证人可以是委托人，也可以是委托人有权指定的第三人」** |
| **使用人** | **使用鉴证结果的单位或个人** |
| **鉴证事项** | **鉴证人评价和证明的对象** |
| **鉴证资料** | **鉴证业务过程中涉及的各类信息载体** |
| **鉴证结果** | **鉴证人执行鉴证项目的最终状态，「包括出具鉴证报告或者终止涉税鉴证业务委托合同等其他情况」** |

#### （四）业务流程

⚠ **主要环节**：**鉴证准备 → 证据收集评价 → 鉴证事项评价 → 工作底稿 → 鉴证报告**。

### 二、⚠ 鉴证准备

- ⚠ **承接前的「四项分析评估」**：**① 委托事项是否属于涉税鉴证业务；② 是否具有承办涉税鉴证业务的
  专业胜任能力；③ 是否可以承担相应的风险；④ 承办人员是否为鉴证人提供了涉税服务；⑤ 其他相关因素**；
- ⚠ **沟通义务**：**应与委托人进行沟通，并对「税务专业术语、鉴证业务范围」等有关事项进行解释，
  「避免双方对鉴证项目的业务性质、责任划分和风险承担的理解产生分歧」**；
- ⚠ **委托协议**：**决定接受委托的，应当与委托人签订涉税鉴证业务委托协议，
  并报送《涉税专业服务协议要素信息采集表》（2017 年第 49 号附件 2，2019 年第 43 号修改）**。
  ⚠ **协议应包括（九项）**：**① 鉴证事项；② 鉴证报告的用途或使用范围；③ 鉴证期限、举证期限；
  ④ 鉴证业务报酬及支付方式；⑤ 委托人或被鉴证人对涉税鉴证业务的配合义务；
  ⑥ 鉴证人利用专家工作的安排；⑦ 委托人、鉴证人或被鉴证人的证明责任；
  ⑧ 责任分担和争议处理方式；⑨ 其他事项**；
- ⚠ **书面承诺**：**「鉴证人可以要求委托人、被鉴证人出具书面文件，承诺声明对其所提供的与鉴证事项相关的
  会计资料、纳税资料及其他相关资料的真实性、合法性负责」**；
- ⚠ **项目负责人**：**「应当指派能够胜任受托涉税鉴证业务的「具有资质」的涉税服务人员作为项目负责人」**；
- ⚠ **业务计划（两类）**：**「根据鉴证事项的复杂程度、风险状况和鉴证期限等情况」制订**——
  ⚠ **「总体业务计划」应当落实工作目标、确定工作策略、安排服务时间、界定业务范围、明确人员组织分工、
  明确必要的沟通环节和程序**；**「具体业务计划」应当确定拟执行的鉴定方案、鉴证程序、时间、步骤、
  方法和具体流程等**；⚠ **计划确定后可「视情况变化作相应调整」**；
- ⚠ **专家工作**：**「项目负责人可以根据业务需要，请求所在税务师事务所内部或外部相关领域的专家协助工作。
  「项目负责人应当对专家工作成果负责」」**。

### 三、⚠⚠ 证据收集评价

#### 1. 证据的范围与类型

- ⚠ **证据范围（三类）**：**时间范围、职权范围、业务范围**；
- ⚠ **证据类型（九类）**：**书证、物证、视听资料、电子数据、证人证言、当事人的陈述、
  鉴定意见、勘验笔录、现场笔录**。

#### 2. ⚠ 取证途径（三类）

**① 委托人配合提供的鉴证材料；② 被鉴证人协助提供的鉴证材料；
③ 鉴证人采取「审阅、查阅、检查和盘点、询问或函证、记录及其他方法」取得的鉴证材料**。

#### 3. ⚠ 证据的三性审查

| ⚠ 审查 | ⚠ 审查要点（**教材原句**） |
|---|---|
| **合法性** | **① 证据是否符合法定形式；② 证据的取得是否符合法律、法规、规章和司法解释的规定；③ 是否有影响证据效力的其他违法情形** |
| **真实性** | **① 证据形成的原因；② 发现证据时的环境；③ 证据是否为原件、原物，复制件、复制品与原件、原物是否相符；④ 「提供证据的人或者证人与被鉴证人是否具有利害关系」；⑤ 影响证据真实性的其他因素** |
| **相关性** | **① 证据与待证事实是否具有证明关系；② 证据与待证事实的关联程度；③ 影响证据关联性的其他因素** |

#### 4. ⚠⚠ 「不得作为鉴证依据」的八类证据材料

⚠ **① 违反法定程序收集的证据材料；② 以「偷拍、偷录和窃听」等手段获取侵害他人合法权益的证据材料；
③ 以「利诱、欺诈、胁迫和暴力」等不正当手段获取的证据材料；④ 无正当事由「超出举证期限」提供的证据材料；
⑤ 无正当理由拒不提供原件、原物，又无其他证据印证，且对方不予认可的证据的复制件、复制品；
⑥ 无法辨明真伪的证据材料；⑦ 「不能正确表达意志的证人」提供的证言；
⑧ 不具备合法性、真实性的其他证据材料**。

> ⚠⚠ **教材明示的责任边界（本页要点）**：**「鉴证人应当取得支持鉴证结果所需的「事实证据」和「法律依据」。
> 鉴证人对鉴证事项合法性的「证明责任」，「不能替代或减轻」委托人或被鉴证人应当承担的
> 「会计责任、纳税申报责任以及其他法律责任」」**。

### 四、⚠⚠ 鉴证事项评价

#### 1. 两类评价要点

| ⚠ 评价 | ⚠ 要点（**教材原句**） |
|---|---|
| **合法性评价要点** | **事实、证据、依据、程序、内容** |
| **合理性评价要点** | **处理行为是否客观、是否符合情理**——**如是否符合「交易常规、会计常规」** |

#### 2. ⚠ 五项「发表鉴证结论时应关注」

| # | ⚠ 关注 | ⚠ 内容 |
|---|---|---|
| **①** | **事实是否清楚** | **被鉴证事项的交易各方、征纳双方、争议各方等当事人对鉴证事项的事实陈述是否基本一致，是否能根据委托方提供的证据查明事实**。⚠ **鉴证事项有关的事实包括「交易处理、会计处理、税务处理」等行为**——**交易处理包括环境事实、业务事实和其他事实；会计处理包括交易事项的确认与计量的会计凭证、会计账簿、财务会计报告等；税务处理包括会计数据信息采集、计税依据、适用税率、纳税调整、纳税申报表或涉税审批备案表填写等** |
| **②** | **证据是否确实充分** | **证据是否已经查证属实并在量上达到足以得出确定结论的程度**；⚠ **「鉴证评价是否能够得出唯一结论，排除合理怀疑」** |
| **③** | ⚠ **适用依据是否正确** | **是否符合《立法法》规定的法律适用原则；是否存在应该用该条款（项目）而用了其他条款（项目）**；⚠ **「适用法律依据要具体到『条、款、项、目』」**；⚠⚠ **常见错误**：**适用已经失效或者尚未生效的依据、应当适用上位法却适用了下位法、引用法律条款错误、遗漏法律条款或者适用法律条款不具体不规范等** |
| **④** | **适用程序是否合法** | **处理税务事项整个过程是否符合法律、法规、规章、规范性文件规定的「主体、权限、内容、方式、步骤、时限、结果」等程序事项** |
| **⑤** | **是否客观、符合情理** | **交易处理、会计处理、税务处理是否客观、具备合理性** |

### 五、⚠ 工作底稿

- ⚠ **编制依据**：《税务师行业涉税专业服务程序指引（试行）》；
- ⚠ **三个目标**：**① 适当记录涉税鉴证业务过程、列明判断过程及其依据、为最终出具鉴证报告提供基础性资料；
  ② 有效收集与整理证据、形成支持鉴证结果的证据链条、证明业务过程符合指引；
  ③ 规范记载业务情况、表明规范化程度并保证执业质量**；
- ⚠ **八项要素**：**鉴证项目名称；被鉴证人名称；鉴证项目所属期间；索引；鉴证过程和结果的记录；
  证据目录；工作底稿编制人签名和编制日期；工作底稿复核人签名和复核日期**；
- ⚠ **台账**：**「应对开展的涉税鉴证业务「逐笔登记台账」，以便在完成业务后向税务机关征管系统
  涉税专业服务管理信息库填报相关信息」**。

### 六、⚠⚠ 鉴证报告

#### 1. 报告的「八项内容」

| # | ⚠ 内容（**教材原句**） |
|---|---|
| **①** | **标题**——⚠ **规范为「鉴证事项 + 鉴证报告」** |
| **②** | **编号**——**按鉴证人业务成果编号规则统一编码并在业务成果首页注明，「全部业务成果均应编号」** |
| **③** | **收件人**——**即鉴证人按照业务委托协议的要求致送报告的对象，「一般指鉴证业务的委托人」；应当载明收件人全称** |
| **④** | **引言**——**应当表明委托人与受托人的责任，对委托事项是否进行鉴证审核以及审核标准、审核原则等进行说明** |
| **⑤** | **鉴证实施情况**——**在业务实施过程中所采用的程序和方法、分析事项、具体步骤、计算过程等** |
| **⑥** | **鉴证结论或鉴证意见**——**最终结果，有明确的意见、建议或结论** |
| **⑦** | ⚠ **签章**——**「应当由实施该项业务的「税务师、注册会计师或律师」签章」** |
| **⑧** | **报告出具日期**——**即完成业务成果外勤工作的日期**；⚠ **附件：鉴证业务说明**（**可根据业务性质和业务需求调整或增减**） |

#### 2. ⚠⚠ 出具与签章的「硬性要求」（教材明示）

- ⚠ **「涉税鉴证业务报告应当在鉴证人完成「内部审批复核程序及签字手续」，加盖鉴证人公章后对外出具」**；
- ⚠⚠ **「在正式出具涉税鉴证业务报告前，项目负责人应与委托人或者被鉴证人就拟出具的报告的有关内容进行沟通」**；
- ⚠⚠ **「涉税鉴证业务报告应由「两个以上」具有涉税鉴证业务资质的涉税服务人员签字」**；
- ⚠ **报告具有特定目的或服务于特定使用人的，应当在报告中予以注明，对报告的用途加以限定和说明**；
- ⚠ **保密义务与三项例外**：**应当对业务记录、业务成果以及知悉的委托人和被鉴证人商业秘密和个人隐私予以保密，
  未经委托人同意不得向第三方泄露**——⚠ **除外情形**：**① 税务机关因行政执法需要进行查阅的；
  ② 涉税专业服务监管部门和行业自律部门因检查执业质量需要进行查阅的；③ 法律、法规规定可以查阅的其他情形**；
- ⚠ **基础资料缺陷的处理**：**「项目负责人认为委托人提供的会计、税收等基础资料缺乏完整性和真实性，
  可能对鉴证项目的预期目的产生重大影响的，「应当在报告中作出适当说明」」**；
- ⚠⚠ **出具后发现新重大事项**：**「如发现新的重大事项足以影响已出具的涉税鉴证业务报告结论，
  应当及时报告鉴证人，作出相应的处理」**；
- ⚠ **留存与报送**：**「涉税鉴证业务报告，应当由委托协议双方留存备查」**；
  ⚠ **其中税收法律、法规及国家税务总局规定报送的，应当向税务机关报送**。

## Contradictions

⚠⚠ **一处「教材 vs 题库」的实质分歧（已显式记录，不静默覆盖）——「部分业务完成后的责任划分」**：

| ⚠ 来源 | ⚠ 表述 |
|---|---|
| **题库侧**（原 [[tax-certification-service]] 的旧记，2026-09-22） | 「如已完成部分约定业务，**完成部分由委托方和涉税专业服务机构「共同承担」相应责任**」 |
| ⚠ **教材侧（本页所据，2026-10-08）** | 「如已完成部分约定业务，应当按照协议约定收取费用，并就已完成事项进行**「免责性声明」，由「委托人承担」相应责任，涉税专业服务机构及涉税服务人员「不承担」该部分责任**」 |

⚠⚠ **两者方向相反**（**「共同承担」 vs 「委托人承担、服务机构不承担」**）。
