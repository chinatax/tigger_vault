# 风险与收益的衡量

## Definition

风险与收益的衡量（Risk and Return Measurement）：对**单项资产**收益水平与风险大小的量化方法。收益用各类收益率刻画，风险则用期望值、标准离差、标准离差率和 β 系数等指标度量。

其核心难点不在计算而在**指标的适用范围**：标准离差是绝对数、只在期望值相同时可比；期望值不同的方案必须改用标准离差率。

## Key Points

- **五类收益率**（第 18 题的辨析对象）：
  - **实际收益率**：已实现或确定可以实现的收益率
  - **必要收益率**：投资者对某资产**合理要求的最低**收益率
    （⚠ 不是「全部投资者对某资产要求的平均收益率」）
  - **预期收益率**：可通过概率加权或历史数据加权平均计算
  - **无风险收益率** = **纯利率**（资金的时间价值）+ **通货膨胀补偿率**
    （⚠ 不能说「无风险收益率即资金的时间价值」——它还含通胀补偿）
  - **风险收益率**：资产持有者因承担该资产的风险而要求的、超过无风险利率的**额外收益**
- **股票收益率的构成**：收益率 = **股利收益率** + **资本利得收益率**
  - 资本利得收益率 =（期末市价 − 期初市价）÷ 期初市价
- **风险的衡量指标**：
  - **期望值**（预期收益率）：代表投资者的**合理预期**，**不能**用来衡量资产的风险
  - **标准离差**（绝对数）：⚠ **只适用于期望值相同**的决策方案之间比较风险程度，**不适用于期望值不同**的两个项目
  - **标准离差率**（相对数）= 标准离差 ÷ 期望值：⚠ 期望值**不同**时必须用它；标准离差率越大，风险越大
  - **离散程度**：资产收益率的各种可能结果与预期收益率的偏差；一般来说离散程度越大，风险越大
- **单项资产的 β 系数**：
  - β = 资产收益率与市场组合收益率的**相关系数** × 资产收益率的**标准差** ÷ 市场投资组合收益率的**标准差**
  - **β = 1**：市场平均收益率增加 1%，该资产收益率也增加 1%
  - **β = 0**：该资产**没有系统风险**（⚠ **不等于没有风险**，仍可能有非系统风险）
  - **β > 1**：所含**系统风险大于**市场组合的风险
  - **β < 1**：所含系统风险小于市场组合的风险
  - ⚠ β 系数**可以为负值**——极个别资产与市场平均收益的变化方向相反，市场平均收益增加时其收益反而减少
  - ⚠ 计算 β 时易错点：由 β 反推市场风险溢酬需借道「风险收益率 = β × 市场风险溢酬」
