# 长期股权投资核算方法的转换

## Definition

长期股权投资核算方法的转换（Changes in Accounting Method）：因**增资**或**减资**导致持股比例跨越控制/重大影响临界点，从而在**成本法、权益法、金融资产**三者之间切换核算方法。

判断的主线是一个**跨界**问题——**跨界就「视同处置再重购」并按公允价值计量，不跨界就按账面价值延续**。

## Key Points

- **六种转换及其规则总表**（第 275、282、317–323 题）：

  | 转换 | 初始投资成本 / 计量基础 | 原有其他综合收益、资本公积的去向 |
  |---|---|---|
  | **成本法 → 权益法**（撤资，仍重大影响） | 剩余股权**追溯调整**为权益法 | 按权益法规则补充确认 |
  | **权益法 → 成本法（非同一控制）** | 原权益法**账面价值** + 新增投资成本 | 不结转 |
  | **权益法 → 成本法（同一控制）** | 被合并方在最终控制方合并报表中的**账面价值 × 持股比例** | ⚠ **不转入投资收益**（题目明示） |
  | **金融资产 → 权益法**（增资） | 原金融资产**公允价值** + 新对价公允价值 | 原为**其他权益工具投资** → 转入**留存收益**；<br>原为**交易性金融资产** → 账面与公允之差计入**投资收益** |
  | **金融资产 → 成本法（非同一控制）** | 原股权投资**公允价值** + 新对价公允价值 | 同上 |
  | **权益法 → 金融资产**（丧失重大影响） | 剩余股权按**公允价值**计量，视同**全部处置再重购** | ⚠ **转入投资收益**（可转损益部分） |

- **成本法 → 权益法的追溯调整三步**（第 317、321 题）：
  - ①**初始投资成本**：剩余股权的原始投资成本 vs 应享有**原投资时点**可辨认净资产公允价值份额
    → 前者**小于**后者时调增长投，差额计入**留存收益**
  - ②**原投资时点至处置当期期初**的净损益份额 → 调整**留存收益**（按 10% 提盈余公积）
  - ③**处置当期期初至处置时点**的净损益份额 → 调整**投资收益**
  - 处置部分的损益 = 处置价款 − **原账面价值 × 处置比例**
  - 例：原投资 3200 取得 60%，出售 30% 得 2600
    → 出售损益 = 2600 − 3200/2 = **1000 万元**；追溯留存收益 = (800 + 1200 − 1000) × 30% = **300 万元**
- **同一控制下多次交易形成企业合并**（第 323 题，⚠ 与其他转换的差异最大）：
  - 初始投资成本 = 被合并方所有者权益在**最终控制方合并财务报表中的账面价值 × 最终持股比例**
  - 差额 = 初始投资成本 −（**原股权账面价值 + 新支付对价账面价值**）→ 调整**资本公积——股本溢价**
    （不足冲减则依次冲减盈余公积、未分配利润）
  - ⚠ 原权益法下确认的**其他综合收益、资本公积、长期股权投资减值准备一并转入**，
    但**不确认投资收益**
  - 例：原 25% 权益法账面价值（含减值准备 250、其他综合收益 150）5000，新付 4000；
    被合并方账面价值 17500 × 55% = 9625
    → 差额 9625 − 9000 = **625 万元**调整资本公积——股本溢价
  - 达到控制后改用**成本法**，账面价值**保持不变**
- **丧失重大影响转为金融资产**（第 320、321、322 题）：
  - ⚠ 视为将长期股权投资**全部处置**，再按公允价值重新购入金融资产
  - 应确认投资收益 =（剩余股权公允价值 + 处置价款）− 原长期股权投资账面价值
    + **原权益法下确认的其他综合收益（可转损益部分）+ 资本公积——其他资本公积**
  - 例：账面价值 2168.4，转让 10% 得 1200、剩余 10% 公允 1200，其他综合收益 60、资本公积 40
    → 投资收益 =（1200 + 1200）− 2168.4 + 60 + 40 = **331.6 万元**
- **增资而原为其他权益工具投资**（第 315 题）：
  - 初始投资成本 = **原股权投资的公允价值 + 新增投资支付对价的公允价值**
  - ⚠ 增资时原持有期间确认的**其他综合收益转入留存收益**（**不是**当期损益）
  - ⚠ 应**终止确认**其他权益工具投资
- **增资时的商誉合并考量**（第 275 题）：
  - 原持股产生的**负商誉**（曾计入营业外收入）与新持股产生的**正商誉**，
    ⚠ **综合考虑后若仍为正商誉，则本次不再调整**长投账面价值
  - 例：原 20% 投资成本 1200 < 份额 1210（负商誉 10）；新 10% 成本 1000 > 份额 700（正商誉 300）
    → 综合考虑正商誉 290，不调整 → 账面价值 = 1200 + 10 + 1000 = **2210 万元**
