# 产品成本的归集与分配

## Definition

产品成本的归集与分配（Product Cost Allocation）：把归集的生产费用在**完工产品**与**月末在产品**之间划分的方法，主要有约当产量比例法、定额比例法、在产品按定额成本计算法。

全部分配方法的共同结构都是「**求分配率 → 乘以完工产品的约当量**」，差异只在**分母口径**——而分母口径正是考点。

## Key Points

- **约当产量比例法**（第 412、432 题）：
  - **直接材料的分摊率口径取决于投料方式**（⚠ 最高频的失分点）：
    - **一次性投入**：分配率 = 直接材料费用 ÷（**完工产品数量 + 在产品数量**）
    - **陆续投入**：分配率 = 直接材料费用 ÷（**完工产品数量 + 在产品约当产量**）
  - **直接人工与制造费用**：一律按**工时定额比例**，分配率 = 费用 ÷（完工产品定额工时 + 在产品约当产量）
  - 例（第 412 题）：完工 400 台、在产品 100 台（完工程度 50%）、材料**一次性投入**；
    费用合计 200 万元（材料 100、人工 45、制造 55）
    - 在产品约当产量 = 100 × 50% = 50
    - 完工产品成本 = 100 × 400/(400+100) +（45+55）× 400/(400+50) = 168.89 万元
    - 单位成本 = 168.89 ÷ 400 = **0.42 万元**
- **多工序在产品的完工率**（第 432 题，⚠ 高频公式）：
  - 某工序在产品完工率 =（**前面各工序工时定额之和 + 本工序工时定额 × 50%**）÷ **总工时定额** × 100%
  - 在各工序内一律按 **50%** 的完工程度计算
  - 例：总工时定额 100 小时（第一工序 40、第二工序 60）；完工 800 件；
    月末在产品 350 件（第一工序 90 件、第二工序 260 件）
    - 第一工序完工率 = 40 × 50% ÷ 100 = **20%**；约当产量 = 90 × 20% = **18 件**
    - 第二工序完工率 =（40 + 60 × 50%）÷ 100 = **70%**；约当产量 = 260 × 70% = 182 件
    - 在产品的**合计约当产量** = 18 + 182 = **200 件**
    - ⚠ 原材料**陆续投入**时，直接材料也按约当产量分配
      月末完工产品直接材料费用 =（300 + 1080）÷（800 + 200）× 800 = **1104 万元**
    - 月末在产品直接人工费用 =（160 + 400）÷（800 + 200）× 200 = **112 万元**
    - 本月完工产品成本 = 1104 +（160 + 120 + 400 + 294）÷（800 + 200）× 800 = **1883.2 万元**
- **定额比例法**（第 402 题）：按**定额消耗量**或**定额工时**比例分配
  - 直接材料分配率 =（期初 + 本期材料费用）÷（完工产品定额消耗量 + 在产品定额消耗量）
  - 直接人工、制造费用分配率 = 费用合计 ÷（完工产品定额工时 + 在产品定额工时）
  - 例：期初在产品（材料 3200、人工 500、制造 300）+ 本月发生（6000、625、600）；
    完工 350 件（每件材料定额 5 千克、工时定额 10 小时）；月末在产品定额消耗量 250 千克、定额工时 1000 小时
    - 材料分配率 =（3200 + 6000）÷（350×5 + 250）= 4.6 → 完工负担 350×5×4.6 = **8050**
    - 人工分配率 =（500 + 625）÷（350×10 + 1000）= 0.25 → 完工负担 **875**
    - 制造费用分配率 =（300 + 600）÷（350×10 + 1000）= 0.2 → 完工负担 **700**
    - 完工产品总成本 = **9625 元**
- **在产品按定额成本计算**（第 420 题）：
  - 在产品定额成本 = Σ（各成本项目的**定额** × 在产品数量）
  - 完工产品成本 = **费用合计 − 在产品定额成本**
  - 例：费用总额 13180；完工 118 件、在产品 30 件；材料费用定额 18 元/件、
    单位定额工时 8 小时、单位工时人工定额 2 元、制造费用定额 1.5 元
    - 在产品定额成本 = 18 × 30 + 8 ×（2 + 1.5）× 30 = 540 + 840 = **1380 元**
    - 完工产品单位成本 =（13180 − 1380）÷ 118 = **100 元**
