# 代办增值税纳税申报手续

## Definition

⚠ **本页是《涉税服务实务》第五章《纳税申报代办服务》第一节之
「一、增值税及附加税费纳税申报代办」的「「（五）代办增值税纳税申报手续」」**
（书页 312，txt 317）——**即申报表填制完成之后、向税务机关办理申报的「收尾动作」：
复核 → 反馈确认 → 签章 → 按期申报 → 异常处置 → 形成业务成果**。

⚠ **边界**：
- ⚠ **本页是「申报环节的程序口径」**；**申报表怎么填**见 [[vat-filing-general-taxpayer-return]]、
  [[vat-filing-general-taxpayer-example]]、[[vat-filing-small-scale-taxpayer-return]]（**同批**）；
  **申报的基本要求与资料**见 [[vat-filing-requirements]]（**批 1**）；
  **资料收集、专业判断与预缴**见 [[vat-filing-data-collection-and-prepayment]]（**批 1**）；
- ⚠ **「申报方式」的通则**见 [[tax-return-filing]]（**第二章**）——⚠ **本页只记增值税代办场景下的具体做法**；

## Key Points

### 一、⚠⚠ 「代办申报手续」的六步动作（**教材原句顺序**）

> ⚠ **教材原句**：「涉税服务人员编制完成增值税及附加税费申报表，经过「「业务质量复核和监控程序」」后，
> 先将委托人的本期相关纳税信息「「反馈至委托人，由委托人确认一致」」，并「「在增值税及附加税费申报表、
> 扣缴税款报告表以及相关文件资料的授权声明中签章」」；再在增值税及附加税费申报表的「「申报人声明」」中，
> 履行由「「税务师事务所签章和承办涉税服务人员签字」」手续后，涉税服务人员在规定的申报期内，
> 及时为委托人向主管税务机关办理增值税纳税申报」。

| # | ⚠ 步 | ⚠ 动作 |
|---|---|---|
| **①** | **业务质量复核和监控** | ⚠ **申报表编制完成后先过质量复核与监控程序** |
| **②** | **反馈委托人** | **将本期相关纳税信息反馈至委托人** |
| **③** | **委托人确认** | **由委托人确认一致** |
| **④** | **授权声明签章** | **在申报表、扣缴税款报告表及相关文件资料的「授权声明」中签章** |
| **⑤** | **申报人声明签章** | ⚠ **在申报表的「申报人声明」中，由「税务师事务所签章」+「承办涉税服务人员签字」** |
| **⑥** | **按期办理申报** | ⚠ **在规定的申报期内，及时向主管税务机关办理增值税纳税申报** |

### 二、⚠ 申报方式与报送要求

- ⚠ **申报方式**：「涉税服务人员根据委托人具体情况确定具体的申报方式，包括
  「「网络申报、上门申报和其他适当的申报方式」」」；
- ⚠ **报送要求**：「应当按照税务机关「「涉税资料清单管理和涉税资料电子化」」的要求，
  报送增值税电子数据信息」；
- ⚠ **按期按责**：「应当按照税法规定的「「申报期限、申报内容」」代理增值税纳税申报，
  报送增值税及附加税费申报表和税务机关要求的其他资料」。

### 三、⚠⚠ 两类「异常」的处置（**代办中的兜底动作**）

| # | ⚠ 触发情形 | ⚠ 处置（**教材原句**） |
|---|---|---|
| **①** | **发现委托人已申报内容需要调整** | **「应当按照税法规定和税务机关要求办理「更正申报」或者「补充申报」」** |
| **②** | **发现税务机关纳税申报平台提示申报信息与财务会计资料比对异常** | **「应当及时「查明原因」，对数据进行分析和处理」** |

> ⚠ **与填制环节的呼应**：⚠ **情形②正是 [[vat-filing-general-taxpayer-return]] 注意事项（3）
> 「申报比对」（税总发〔2017〕124 号）在办理环节的延伸**——⚠ **该处要求「协助纳税人准备
> 引起比对异常情况的说明，以便在税务机关反馈时及时核实，保证税控设备及时解锁」**。

### 四、⚠⚠ 业务成果（**五项**）

> ⚠ **教材原句**：「完成增值税纳税申报代办业务后，形成的业务成果一般包括」：

| # | ⚠ 业务成果 |
|---|---|
| **（1）** | **经双方签字确认的增值税及附加税费申报表、扣缴税款报告表以及相关文件** |
| **（2）** | **经双方约定需出具的增值税纳税申报代办业务报告** |
| **（3）** | **税务机关要求报送的其他纳税资料** |
| **（4）** | **委托人应当留存备查的资料** |
| **（5）** | **其他相关报告** |

> ⚠⚠ **同一份「四目模板」在消费税一侧的实例**（⚠ **文字与 (四) 部分完全一致**）见
> [[excise-filing-data-collection-and-procedure]]（**第五章批 3，2026-10-08**）。
