# 税务师

## Definition

**税务师**（**Tax Advisor**，**TA**），是指**在中华人民共和国境内取得「税务师职业资格证书」，
提供涉税专业服务的专业人员**。

⚠⚠ **一处「slug 与英文名」的留档说明（2026-09-24）**：**本页的 slug 初定为
`tax-service-professionals`，同日经用户裁定改名为 `tax-advisor`**——⚠ **原因是旧 slug 与
总纲页 [[tax-professional-service]] 互为「词序变换」，lint 检查 5 判定 Jaccard = 1.00**
（⚠ **两串仅词序与单复数不同，去复数 s 后词元集完全相同**）。
⚠ **新 slug 取教材自身给出的英文名**——教材第一章载：
**「注册税务师职业资格由『准入类』调整为『水平评价类』，并更名为『税务师』（Tax Advisor，TA）」**。

⚠ **其职业资格的性质**：税务师属于**人力资源社会保障部制定的《国家职业资格目录》中的
「水平评价类」职业资格**——⚠ **注意是「水平评价类」，不是「准入类」**。

⚠ **边界**：
- **本页只承载「人」这一侧**——**税务师的资格取得、权利义务与职业道德**；
- **「机构」见 [[tax-agent-firm]]**（税务师事务所的设立、行政登记与质量控制）；
- **「行业组织」见 [[tax-professional-association]]**（中税协与行业自律）；
- **三者的上位概念、业务范围与行政监管**，分别见
  [[tax-professional-service]]、[[tax-service-administration]]。

⚠ **本页是《涉税服务实务》第一章第三节的第一块**（书页 26–29 ／ txt 31–34 大部分）。

## Key Points

### 一、税务师职业资格考试制度

⚠ **依据**：《**税务师职业资格制度暂行规定**》。

#### （一）考试基本情况

| 项 | 内容 |
|---|---|
| ⚠ **组织制度** | **全国统一大纲、统一命题、统一组织**（**「三统一」**） |
| ⚠ **频次** | **原则上每年举行 1 次** |
| ⚠⚠ **组织实施者** | **中税协**具体负责税务师资格考试的组织、实施工作，**组织成立「税务师职业资格考试专家委员会」**，研究拟定**考试科目、考试大纲、考试试题和考试合格标准** |
| **考试科目** | **5 个**：《税法（Ⅰ）》《税法（Ⅱ）》《涉税服务相关法律》《涉税服务实务》《财务与会计》 |
| ⚠ **单科时长与分值** | **每个科目考试时间为两个半小时**，**成绩满分为 140 分** |
| ⚠⚠ **成绩管理** | **5 年为一个周期的滚动管理办法**——**在连续的 5 个考试年度内参加全部科目的考试并成绩合格，可取得税务师职业资格证书** |

> ⚠ **易混点**：**「5 个科目」与「5 年滚动周期」是两个不同的 5**，勿因数字相同而串记。

#### （二）报考条件

⚠ **前置条件（三项，须同时具备）**：**中华人民共和国公民**；**遵守国家法律、法规，恪守职业道德**；
**具有完全民事行为能力**。

⚠ **并符合下列相应条件之一**（**按「学历门类 × 学历层次」二分**）：

| 学历门类 | 学历层次 | ⚠ 从事经济、法律相关工作的年限要求 |
|---|---|---|
| ⚠ **经济学、法学、管理学** | **大学专科** | **满 2 年** |
| **其他学科门类** | **大学专科** | **满 3 年** |
| ⚠⚠ **经济学、法学、管理学** | **大学本科及以上学历（学位）** | ⚠⚠ **无年限要求**（**取得学历即可**） |
| **其他学科门类** | **大学本科** | **满 1 年** |

> ⚠⚠ **规律**：**「经济学、法学、管理学」三个门类一律优惠一档**——
> **专科由 3 年降为 2 年；本科及以上直接免年限。**

#### （三）免试条件

⚠ **符合报考条件**，**并具备下列条件之一者，可免试相应科目**：

| # | 已评聘的专业技术职务 | ⚠ 附加条件 | 可免试科目 |
|---|---|---|---|
| **1** | ⚠ **经济、审计等高级专业技术职务** | **从事涉税工作满 2 年** | ⚠ **《财务与会计》** |
| **2** | ⚠ **法律高级专业技术职务** | **从事涉税工作满 2 年** | ⚠ **《涉税服务相关法律》** |

> ⚠ **记忆钩子**：**免试哪一科，看的是「已评聘的职务门类」而非「想考什么」**——
> **经济／审计 → 免会计；法律 → 免法律。** 两项**从事涉税工作满 2 年**的要求一致。

#### （四）五个科目的主要内容

⚠ **本项属「科目—内容」的对应记忆**，亦可反推**各科教材的覆盖范围**：

| 科目 | ⚠ 主要内容 |
|---|---|
| **《税法（Ⅰ）》** | **税法基本原理**；**增值税、消费税、城市维护建设税、教育费附加、烟叶税、资源税、车辆购置税、土地增值税、关税、环境保护税**的相关法律法规和规章；**非税收入相关政策** |
| **《税法（Ⅱ）》** | **国际税收**及**企业所得税、个人所得税、印花税、房产税、车船税、契税、城镇土地使用税、耕地占用税、船舶吨税**的相关法律法规和规章 |
| **《涉税服务相关法律》** | **行政法律制度、民商法律制度、刑事监察法律制度**等法律基础理论及**涉税单行法律** |
| **《涉税服务实务》** | **涉税专业服务制度、税务管理、涉税服务业务、各类代理与审核业务、税务咨询与税务顾问**等涉税服务实务方面的专业知识 |
| **《财务与会计》** | **财务与会计方面的业务知识和实际操作知识** |

### 二、税务师的权利和义务

⚠ **教材以「一并列举」的方式给出 8 项**（**前 7 项为具体权利，第 8 项为兜底**）：

| # | ⚠ 内容 | 性质 |
|---|---|---|
| **1** | **依法独立、客观、公正执业受法律保护，不受区域限制**，任何单位和个人不得违法——⚠ **（原文此处 OCR 有脱字，条款未完整收尾）** | 权利 |
| **2** | ⚠ **依照税收法律法规和相关执业规范、标准，通过执行规定的审核鉴别程序，对委托方涉税事项「真实性或者合法性」进行职业判断，提供具有公信力的专业结论** | 权利 |
| **3** | ⚠ **在法律法规及相关规定许可的范围内，对委托方的「经营、投资和理财活动」作出「事先筹划和安排」，为委托方取得合法的税收经济利益** | 权利 |
| **4** | **向税务机关查询税收法律、法规、规章和其他规范性文件** | 权利 |
| **5** | **参加税务机关组织的培训和税收政策研讨**；⚠ **对税收政策存在的问题向税务机关提出意见和修改建议**；⚠ **对税务机关和税务人员的违法、违纪行为提出批评或者向上级主管部门反映** | 权利 |
| **6** | ⚠ **要求委托人提供相关会计、经营等涉税资料（包括「电子数据」），以及其他必要的协助** | 权利 |
| **7** | ⚠ **委托人与税务机关发生涉税争议时，代表委托人与税务机关协商** | 权利 |
| **8** | ⚠ **法律法规及相关规定确定的其他权利和义务**（**兜底条款**） | 兜底 |

### 三、税务师职业道德

#### （一）基本要求

⚠⚠ **定义**：**税务师行业职业道德**，是指**税务师事务所及其涉税服务人员提供涉税专业服务
应当遵守的「职业品德、职业纪律、职业判断、专业胜任能力」等行业规范的总称**。

⚠⚠ **三条基本要求**：
1. **应当恪守「独立、客观、公正、诚信」的原则**；
2. **应当具备和保持应有的「专业胜任能力和职业判断能力」**；
3. **并履行「保密义务」**。

#### （二）职业道德的具体要求（**五个方面**）

⚠⚠ **教材明确：职业道德要求包括「诚信、独立性、客观公正、专业胜任能力、保密义务」五个方面。**
⚠ **本五项与 [[tax-service-administration]] 中《涉税专业服务职业道德守则（试行）》的
「五项执业纪律」为「原则—纪律」两套表述**，**勿混为一谈**（⚠ 见该页第二节（二））。

---

##### 1. 诚信

⚠ **总要求**：**正直自律、诚实守信，规范服务**；⚠ **应当认真履行协议**，
**严格按照税收法律、法规规定的期间、时效与委托人约定的时间，办理委托事项，严格守约，全面履约**。

⚠⚠ **七类禁止行为（「不得」清单，本项是五项中禁止性规定最密的一条）**：

| # | ⚠ 不得为之 |
|---|---|
| **1** | **违反税收法律、行政法规，造成委托人未缴或者少缴税款** |
| **2** | ⚠ **采取「隐瞒、欺诈、贿赂、串通、回扣」等不正当竞争手段承揽业务，损害委托人或他人利益** |
| **3** | **利用服务之便，谋取不正当利益** |
| **4** | ⚠ **以「税务机关和税务人员的名义」敲诈纳税人、扣缴义务人** |
| **5** | ⚠ **向税务机关工作人员行贿，或者指使、诱导委托人行贿** |
| **6** | ⚠ **在业务报告、申请资料或其他信息中，出具「虚假和误导意见」** |
| **7** | ⚠ **联合抬高或压低业务收费**，或**使用不正当手段开展业务** |

⚠ **另外四组义务与约束**：
- ⚠⚠ **拒绝与告知义务**：**委托人委托事项属于法律法规或者职业道德指引「限制或者禁止」的**，
  应当**告知委托人，并提出修改建议或者予以「拒绝」**；
- ⚠ **转委托的限制**：**未经委托人同意，不得将委托人所托事务转托他人办理**；
- ⚠ **内部管理与声誉**：**税务师事务所应当建立和完善内部管理制度**，严格执行相关业务规范；
  涉税服务人员**应当遵守国家法律法规的相关规定，避免任何损害职业声誉的言行**；
  **应当与同行保持良好关系**；
- ⚠⚠ **宣传与客户资源**：**对外宣传时应当实事求是、客观、真实，不得对自身或同行有夸大、贬低、诋毁的言行**；
  **不得利用税务师事务所拥有的客户资源谋取私利**；⚠ **从税务师事务所离职，未经客户或者税务师事务所同意，
  不得私自保留客户资料，不得利用离职税务师事务所拥有的客户资源开展业务**。

⚠⚠ **诚信记录系统（三级分工，易考）**：

| 主体 | ⚠ 职责 |
|---|---|
| ⚠ **中税协** | **通过税务师行业平台，负责「诚信记录系统的建立」和「管理制度制定、日常维护和人员培训」** |
| ⚠ **地方税协**（省、自治区、直辖市和计划单列市注册税务师协会） | **根据中税协制定的相关管理制度，负责诚信记录系统平台信息的「收集、整理、分析和更新」，开展信用调查，并按行业规定披露和使用信用信息**；**同时将信用披露信息向中税协备案** |
| ⚠ **税务师事务所及其涉税服务人员** | **负责向所属地方税协「如实提供」信用信息和相应资料，并对其真实合法性负责** |

⚠ **一处附带义务**：**税务师事务所参与「公开招标」时，应当根据实际情况出具相关信用资料。**

##### 2. ⚠⚠ 独立性（**本页最重要的辨析点**）

⚠⚠ **「实质」与「形式」的双层结构——按业务类型二分**：

| 业务类型 | ⚠ 独立性要求 |
|---|---|
| ⚠⚠ **涉税鉴证、纳税情况审查** | ⚠⚠ **必须从「实质上」保持独立性** |
| ⚠⚠ **纳税申报代办、一般税务咨询、专业税务顾问、税务合规计划、其他税务事项代办、其他税务代理**（**六项**） | ⚠⚠ **应当从「形式上」保持独立性** |

> ⚠⚠ **判据**：**鉴证与审查要「出结论」，故须实质独立；其余六项是「代办与服务」，故只须形式独立。**
> ⚠ **此二分在题库旧记中已出现，教材口径一致**（⚠ 见 Contradictions 节）。

⚠ **三项原则性要求**：
1. **应当遵从税收法律制度**，**当涉税服务与客户利益有冲突时，应当保证涉税专业服务的独立性**；
2. **不因任何利害关系影响涉税专业服务的标准和涉税服务的结果**；
3. ⚠⚠ **「识别—判断—评价—处置」的完整链条**：
   **如果认为存在对独立性有不利影响的因素时，应当「识别、判断和评价」不利影响的严重程度**；
   **如果知悉或有理由相信相关因素对于独立性将产生不利影响，应当采取措施「排除或者消除」该影响因素**；
   ⚠⚠ **如果无法采取适当的措施防范、排除或者消除不利于独立性的影响因素，应当「拒绝接受」涉税专业服务业务委托
   或「终止」提供涉税专业服务**。

⚠⚠ **七项应主动申明并请求回避的「利害关系」**（**本项为高频考点，须按序记忆**）：

| # | 利害关系 |
|---|---|
| **一** | ⚠ **与委托人存在「密切的商业关系」或者涉及「直接的经济利益」** |
| **二** | ⚠ **税务师事务所的「收入过度依赖于」委托人** |
| **三** | ⚠ **承办业务的涉税服务人员「受雇于」该委托人** |
| **四** | ⚠ **税务师事务所受到「解除业务关系的威胁」** |
| **五** | ⚠⚠ **与委托人有「夫妻关系、直系血亲关系、三代以内旁系血亲关系以及近姻亲关系」** |
| **六** | **执业相关法律法规规定的利益冲突关系** |
| **七** | **其他可能影响业务公正执行的情况**（**兜底**） |

⚠ **处置**：**应当主动向所在的税务师事务所说明情况并请求「回避」**。

⚠ **机构层面的配套义务**：**税务师事务所应当严格执行涉税专业服务业务规范，
并制定必要的规章制度，支持和保障其涉税服务人员涉税专业服务的独立性。**

##### 3. 客观公正

⚠ **本项教材拆为「客观」与「公正」两个动作**：

| 动作 | ⚠ 要求 |
|---|---|
| ⚠ **保持客观** | **实事求是，遵守国家法律、法规规定，「基于委托人的业务事实」提供涉税专业服务**；⚠ **「不以个人意志为出发点和目的」，「不因利益冲突、个人偏见或其他因素影响职业判断及职业结论」** |
| ⚠ **保持公正** | **公平正直，遵守国家法律、法规规定，符合正当的社会基本价值取向**，**恪守公认的道德规范要求和《税务师职业道德指引（试行）》的要求** |

⚠⚠ **四条禁止（证据相关占三条）**：
1. **不得伪造证据**；
2. **不得改变证据的内容、形式及属性**；
3. **不得有意忽视证据**；
4. **不得违反涉税专业服务相关业务规范提供服务，出具虚假意见**。

⚠⚠ **一处「终止义务」**：**委托人提供不实资料的，涉税服务人员应当「终止提供涉税服务」。**

---

##### 4. 专业胜任能力

- ⚠ **总要求**：**从事涉税专业服务应当具有相应的税收专业知识和技能**；
- **应当持续了解、及时掌握、准确理解、正确执行国家财会、税收政策和相关规定**；
- ⚠ **应当具有获取专业知识技能和保持应有的专业胜任能力**，**确保为委托人提供具有专业水准的服务**，
  **具备和保持职业判断意识和能力**；
- ⚠ **应当按规定参加「继续教育」**。

---

##### 5. 保密义务

- ⚠ **未经委托人允许，不得向「税务师事务所以外的第三方」泄露其所获取的委托人「隐私和商业秘密」**；
  ⚠⚠ **「国家法律法规另有规定的除外」**；
- ⚠ **不得利用所获取的涉密信息为自己或任何形式的第三方牟取利益**。

#### （三）违反职业道德的惩戒

⚠ **机构侧义务**：**税务师事务所应当主动防止有损职业道德的行为发生；
发现涉税服务人员存在违规行为的，应当及时制止；情节严重者，应当上报所在的地方注册税务师协会。**

⚠⚠ **五档自律管理措施（由轻到重，依《中国注册税务师协会会员违规行为惩戒办法》）**：

> **约谈 → 警告 → 通报批评 → 公开谴责 → 取消会员资格**

⚠⚠ **与「法律责任」的衔接**：**税务师事务所涉税服务人员违反国家法律法规的，
由「中税协或地方税协」提请「行政或司法机关」调查处理**——
⚠ **即行业组织本身不作行政处罚，只作「提请」。**
