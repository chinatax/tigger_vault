# 国际税收征管协作

## Definition

国际税收征管协作（International Tax Enforcement Cooperation）：在开放经济条件下，
税务主管当局为应对**税收征纳双方活动范围不对称**问题、在国家税基国际化情况下**控管国际税源**，
而进行的税收征收与管理合作，主要包括**情报交换、税款追缴和文书送达**。

⚠ 本页覆盖两块内容：**情报交换的六种类型**（我国作为协定缔约国承担的国际义务），
以及 **CRS 金融账户涉税信息自动交换标准**（含 1.0 → 2.0 的升级与并列的 **CARF 加密资产报告框架**）。

## Key Points

### 一、⚠ 国际税收征管协作的三项内容

- ⚠ **情报交换、税款追缴和文书送达**
  - ⚠ **不属于**：税务工作人员国际交流与培训、税收网络信息
- ⚠ **《多边税收征管互助公约》**：我国于 **2013-08-27** 签署，成为该公约的**第 56 个签约方**；
  ⚠ **2015-07-01** 第十二届全国人大常委会第十五次会议**表决通过了批准该公约的提案**

### 二、⚠ 情报交换

- ⚠ **定义**：我国与相关税收协定缔约国家的主管当局，为了**正确执行税收协定及其所涉及税种的
  国内法**而相互交换所需信息的行为
- ⚠ **三条基本规则**：
  - 情报交换在**税收协定规定的权利和义务范围内**进行——我国**既享有取得税收情报的权利，
    也负有向缔约国提供税收情报的义务**
  - ⚠ **情报交换应在税收协定生效并执行以后进行**，
    ⚠ **但税收情报涉及的事项可以溯及税收协定生效并执行之前**
  - ⚠ 情报交换通过税收协定确定的主管当局或其授权代表进行。
    ⚠ **我国主管当局为国家税务总局**；省以下（含省）税务机关**协助**总局负责管理本辖区内的情报交换工作
- ⚠ 我国税务机关**收集、调查或核查处理**税收情报，适用《税收征管法》的有关规定

**⚠⚠ 情报交换的六种类型**：

| 类型 | 含义 |
|---|---|
| ⚠ **专项情报交换** | 缔约国一方主管当局就**国内某一税务案件提出具体问题**，依据税收协定请求另一方提供相关情报协助查证。⚠ 包括**获取、查证或核实公司或个人居民身份，收取或支付价款、费用，转让财产或提供财产的使用**等与纳税有关的情况、资料、凭证 |
| ⚠ **自动情报交换** | 缔约国双方主管当局之间根据约定，**以批量形式自动提供**有关纳税人取得**专项收入**的税收情报。⚠ **专项收入**主要包括**利息、股息、特许权使用费**收入；**工资、薪金，各类津贴、奖金，退休金**收入；**佣金、劳务报酬**收入；**财产收益和经营收入**等 |
| ⚠ **自发情报交换** | 缔约国一方主管当局将在**税收执法过程中获取**的、其认为**有助于另一方主管当局**执行协定及其所涉税种国内法的信息，**主动提供**给另一方 |
| ⚠ **同期税务检查** | 缔约国主管当局之间根据**同期检查协议**，**独立地在各自有效行使税收管辖权的区域内**，对有**共同或相关利益**的纳税人的涉税事项**同时进行检查**，并互相交流或交换检查中获取的税收情报 |
| ⚠ **授权代表访问** | 缔约国双方主管当局根据**授权代表的访问协议**，经双方主管当局同意，**相互间到对方有效行使税收管辖权的区域进行实地访问**，以获取、查证税收情报 |
| ⚠ **行业范围情报交换** | 缔约国双方主管当局**共同对某一行业的运营方式、资金运作模式、价格决定方式及偷税方法等**进行调查、研究和分析，并相互交换有关税收情报 |

**⚠ 情报交换的范围（四个方面）**：
1. ⚠ **国家范围**：包括加入《多边税收征管互助公约》及与我国正式签订含有情报交换条款的
   **税收协定并生效执行**的国家
2. ⚠ **税种范围**：通常涵盖**所有税种**，特别是具有**所得（或财产）性质**的税种
3. ⚠ **人的范围**：包括**所有类型纳税人及相关主体**
4. ⚠ **地域范围**：为**全球范围内**的涉税信息

- ⚠⚠ **情报的诉讼证据效力**：我国从缔约国主管当局获取的税收情报**可以作为税收执法行为的依据，
  并可以在诉讼程序中出示**
  - ⚠ **但作为证据使用时**，税务机关应根据行政诉讼法等法律规定，
    **向法庭申请不在开庭时公开质证**

### 三、⚠ OECD 金融账户涉税信息自动交换（AEOI / CRS）

**（一）发展历程**

- ⚠ 受 **G20** 委托，**2014 年 7 月** OECD 发布《金融账户涉税信息自动交换标准》（**AEOI 标准**），
  由两部分组成：**《主管当局间协议范本》（MCAA）** 和 **《共同申报准则》（CRS）**
  —— 实务中通称 **CRS 1.0**
- ⚠ 2014—2025 年间：**2022 年 8 月**正式通过修订后的《共同申报准则》；
  **2023 年**发布《**加密资产报告框架**及共同申报准则修订版》；
  ⚠ **2025-06-02** OECD 发布 CRS 1.0 整合文本，即 **CRS 2.0**

**（二）⚠ CRS 2.0 的适用范围（四类主体）**

- ⚠ **参与辖区的金融机构**；**应申报辖区税收居民所持有的金融账户**；
  **消极非金融实体的控制人**；**加密资产服务提供商及相关加密资产**
- ⚠ **应申报辖区**指已承诺实施 CRS 并开展信息自动交换的国家或地区
- ⚠ **金融机构**包括**存款机构、托管机构、投资实体、指定保险公司**及其他符合定义的金融实体
- ⚠ **金融账户**包括**存款账户、托管账户、具有现金价值的保险合同或年金合同、
  投资实体中的股权或债权权益**，⚠ **新增电子货币、央行数字货币（CBDC）**
  —— ⚠ **电子货币属于金融账户，而非金融机构**
- ⚠ **应申报人**指**应申报辖区税收居民的个人或实体**、**消极非金融实体的控制人**、
  **持有应报告加密资产的用户**
- ⚠ **控制人**指对实体实施**最终控制**的自然人，包括通过**所有权、表决权或其他方式实际支配**的
  自然人，**需全面穿透识别**
- ⚠ **消极非金融实体（Passive NFE）** 指**主要收入来源于股息、利息、租金、资本利得等
  被动收入**，或**主要持有产生被动收入资产**的非金融实体
  —— ⚠ **空壳公司、无实质经营的离岸实体**均属此类

**（三）⚠ 尽职调查程序（三类账户）**

- ⚠ 金融机构在账户信息（**地址、国籍、居民身份、股权结构**等）**发生变化**时，
  应**重新开展**尽职调查，履行**持续尽职调查义务**；
  ⚠ **账户持有人应在信息变更后 30 日内告知**金融机构；⚠ 对**高风险账户实施定期复核**

| 账户类型 | 尽职调查要求 |
|---|---|
| ⚠ **个人存量账户** | 对**高净值账户（余额 25 万美元）**开展**电子检索和人工核查**，识别非居民标识；对**低净值账户以电子检索为主**，发现非居民标识后进一步核实。⚠ **对双重居民身份必须全面核实，不得仅采信单一居民声明** |
| ⚠ **个人新开账户** | ⚠ **必须要求账户持有人签署税收居民身份自我声明**，并对声明进行**合理性、一致性核验**，可通过**政府数据库交叉验证税号及身份信息**；⚠ **声明不实或信息矛盾的，金融机构不得采信** |
| ⚠ **实体账户** | 要求实体提供税收居民声明及控制人信息；⚠ 对**消极非金融实体**，**强制穿透至全部控制人**，逐一识别其税收居民身份；⚠ **多层嵌套架构需逐层穿透，不得因架构复杂而豁免** |

**（四）⚠ 应申报信息与申报交换**

- ⚠ **应申报的账户信息**：①**姓名、地址、税收居民辖区、纳税人识别号（TIN）、
  出生日期及地点**等身份信息；②**账号、账户余额或期末价值**等账户信息；
  ③**利息、股息、其他收入总额**等收入类信息；④**资产出售或赎回的总收益**（资本利得相关）；
  ⑤**联名账户需申报持有人数量及各自信息**
- ⚠⚠ **双居民的申报规则**：若账户持有人为**两个及以上应申报辖区的税收居民**，
  相关账户信息须**向所有相关辖区分别申报**，
  ⚠ **不再适用加比规则选择单一辖区**
- ⚠ **无须申报的情形**：**政府机构、国际组织、中央银行**等**豁免金融机构账户**，
  **退休金账户、慈善账户**等符合法定豁免条件的账户，**低价值且低风险**的特定账户等
- ⚠ **申报与交换**：按年度收集报送；⚠ **CRS 2.0 首批交换于 2027 年实施**

**（五）⚠ CRS 2.0 的六项核心修订**

1. ⚠ 将**电子货币、央行数字货币（CBDC）纳入金融资产**范畴
2. ⚠ 与**加密资产报告框架（CARF）并行实施**，实现数字资产全覆盖
3. ⚠ 对**消极非金融实体、信托、基金会、多层架构强制全面穿透**，
   完整申报**所有控制人、委托人、受托人、保护人、受益人**等角色信息
4. ⚠ 金融机构**不得仅进行形式审查**，需对自我声明**进行实质核验**，
   对**明显矛盾、虚假声明拒绝采纳**
5. ⚠ **增加申报资本利得、年度总收支、联名账户明细**等内容，提升信息颗粒度
6. ⚠ **部分参与辖区将个人存量账户申报门槛由 25 万美元下调至 10 万美元**，扩大覆盖范围

**（六）⚠ 加密资产报告框架（CARF）**

- ⚠ **适用主体（CASP）**：**加密资产交易所，托管钱包服务商，
  提供兑换、转账、清算、结算服务的机构**
- ⚠ **应报告加密资产**包括**可兑换加密资产、稳定币、加密资产衍生品、
  用于投资或支付的 NFT**，
  ⚠ **排除仅用于消费、娱乐且不可交易的数字资产**
- ⚠ **尽职调查**：对用户开展**身份识别与税收居民身份核验**，收集税收居民声明，
  ⚠ 对**大额交易、非托管钱包转账加强审查**
- ⚠ **应申报信息**：用户身份信息、税收居民辖区、税号，**加密资产年度总价值**，
  **交易总额、转账总额**，**转入非托管钱包的交易记录**，
  与其他加密资产服务提供商之间的划转信息等
- ⚠ **时间表**：**自 2026-01-01 起开始数据采集，2027 年与 CRS 2.0 同步开展首次信息交换**
