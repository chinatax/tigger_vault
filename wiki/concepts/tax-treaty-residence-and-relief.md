# 税收协定·居民条款与协定待遇管理

## Definition

税收协定·居民条款与协定待遇管理（Tax Treaty Residence and Relief）：税收协定的
**居民条款**（第四条，含**加比规则**）决定了**谁能主张协定保护**；
而**协定待遇**的享受方式与后续管理则决定了**怎么享受、被查到时怎么办**。

⚠ 两者是协定制度的**入口与出口**——先按居民条款拿到「缔约对方税收居民」的身份，
再依「**自行判断、申报享受、相关资料留存备查**」的方式享受待遇。

## Key Points

### 一、居民的一般性条款

- ⚠ 我国对外签订的税收协定，对居民的一般性表述为：
  「缔约国一方居民」是指**按照该缔约国法律，由于住所、居所、成立地、管理机构所在地，
  或者其他类似的标准，在该缔约国负有纳税义务的人**，
  并且包括该缔约国及其行政区或地方当局
- ⚠⚠ **但**这一用语**不包括仅因来源于该缔约国的所得或财产收益而在该缔约国负有纳税义务的人**
  —— 即**只排除「仅有来源地纳税义务」的人**

### 二、⚠⚠ 加比规则（个人双重居民身份的解决）

- ⚠ 同一人有可能**同时为缔约国双方居民**。为解决最终居民身份归属，
  税收协定普遍采取「**加比规则**」
- ⚠⚠ **加比规则的使用是有先后顺序的，只有当使用前一标准无法解决问题时，才使用后一标准**：

| 顺序 | 标准 | 判断要点 |
|---|---|---|
| 1 | ⚠ **永久性住所** | 包括**任何形式**的住所（由个人**租用的住宅或公寓、租用的房间**等），⚠ **但该住所必须具有永久性**，即个人**已安排长期居住**，而不是为了某些原因（如**旅游、商务考察**等）临时逗留 |
| 2 | ⚠ **重要利益中心** | 要参考**个人家庭和社会关系、职业、政治、文化和其他活动、营业地点、管理财产所在地**等因素综合评判。⚠ **其中特别注重的是个人的行为**——即个人**一直居住、工作并且拥有家庭和财产的国家**通常为其重要利益中心之所在 |
| 3 | ⚠ **习惯性居处** | ⚠ **两种适用场景**：①个人在**缔约国双方均有永久性住所**且**无法确定重要经济利益中心**所在国；②个人的**永久性住所不在缔约国任何一方**（如不断穿梭于缔约国一方和另一方旅馆之间）<br>⚠ **判定要点**：第一种情况下要注意其在**双方永久性住所的停留时间**，同时还应考虑其在**同一个国家不同地点**停留的时间；第二种情况下要**将此人在一个国家所有的停留时间加总**考虑，**而不问其停留的原因** |
| 4 | ⚠ **国籍** | 如果该个人在缔约国双方**都有或都没有**习惯性居处，应以**该人的国籍**作为判定标准 |
| 5 | ⚠ **相互协商** | 当采用上述标准**依次判断仍然无法确定**其身份时，可由**缔约国双方主管当局按照协定相互协商程序条款**规定的程序，通过相互协商解决 |

### 三、⚠ 公司及其他团体的居民身份判定

- ⚠ **公司及其他团体的双重居民身份冲突协调规则，一般以「实际管理机构」为依据判定**
- ⚠ **实际管理机构所在地**指**实质上作出有关企业整体经营关键性的管理与商业决策之地**，
  ⚠ 通常理解为**最高层人员如董事会作出决策所在地**
- ⚠⚠ **一个实体可以有多个管理机构所在地，但是只能有一个实际管理机构所在地**
- ⚠ 如果公司及其他团体**同时为缔约国双方居民** →
  **应认定其是实际管理机构所在地的居民**
- ⚠ **有些协定没有加比原则**，需要根据协定条款的其他规定（如**根据协商条款**）进行处理
- ⚠ **对「走出去」企业的提示**：要了解**对方国家对于实际管理机构所在地的定义**

### 四、⚠ 无住所个人的协定适用（四类条款）

⚠ 对方税收居民个人**可以按照税收协定及财政部、国家税务总局有关规定享受协定待遇，
也可以选择不享受**协定待遇计算纳税。

**（一）适用受雇所得条款**

| 协定待遇 | 适用条件 | 收入额公式 |
|---|---|---|
| ⚠ **境外受雇所得协定待遇** | 对方税收居民个人**在境外从事受雇活动**取得的受雇所得 | **当月工资薪金收入额 = 当月境内外工资薪金总额 ×（当月工资薪金所属工作期间境内工作天数 ÷ 当月工资薪金所属工作期间公历天数）** |
| ⚠ **境内受雇所得协定待遇** | ⚠ 在税收协定规定的期间内**境内停留天数不超过 183 天**，且所得**不是由境内居民雇主支付或代其支付**，**也不是由雇主在境内常设机构负担** | **当月工资薪金收入额 = 当月境内外工资薪金总额 ×（当月境内支付工资薪金数额 ÷ 当月境内外工资薪金总额）×（当月工资薪金所属工作期间境内工作天数 ÷ 当月工资薪金所属工作期间公历天数）** |

- ⚠ **享受时点**：**无住所居民个人**为对方税收居民个人的 →
  可在**预扣预缴和汇算清缴时**按规定享受；
  **非居民个人**为对方税收居民个人的 → 可在**取得所得时**按规定享受

**（二）适用独立个人劳务或者营业利润条款**

- ⚠ 无住所**居民**个人为对方税收居民个人，其取得的**劳务报酬所得、稿酬所得**
  可享受独立个人劳务或者营业利润协定待遇的 → ⚠ **在预扣预缴和汇算清缴时，可不缴纳**个人所得税
- ⚠ 无住所**非居民**个人为对方税收居民个人，其取得的**劳务报酬所得、稿酬所得**可享受该待遇的
  → ⚠ **在取得所得时可不缴纳**个人所得税

**（三）适用董事费条款（⚠ 三层逻辑）**

- ⚠ 对方税收居民个人为**高管人员**，该个人适用的税收协定**未纳入董事费条款**，
  或者**虽然纳入董事费条款但该个人不适用**董事费条款，
  且该个人取得的高管人员报酬**可享受税收协定受雇所得、独立个人劳务或者营业利润条款规定待遇**的
  → ⚠ 该个人取得的高管人员报酬**可不适用**「无住所个人为高管人员的情形」的规定，
  分别按**适用受雇所得条款、适用独立个人劳务或者营业利润条款**的规定执行
- ⚠ 对方税收居民个人为高管人员，其取得的高管人员报酬**按税收协定董事费条款规定
  可以在境内征收个人所得税**的 →
  ⚠ 应按有关**工资、薪金所得或者劳务报酬所得**规定缴纳个人所得税

**（四）适用特许权使用费或者技术服务费条款**

- ⚠ 可**不纳入综合所得**，在**取得当月**按照**税收协定规定的计税所得额和征税比例**计算应纳税额，
  并预扣预缴税款
- ⚠ **年度汇算清缴时**，该个人取得的**已享受**该协定待遇的所得**不纳入年度综合所得**，
  单独按照税收协定规定的计税所得额和征税比例计算年度应纳税额及补退税额
- ⚠ **非居民个人**为对方税收居民个人的 → 可直接按协定规定的计税所得额和征税比例计算应纳税额

### 五、⚠ 合伙企业及其他类似实体适用税收协定

1. ⚠ **依照中国法律在中国境内成立的**合伙企业，其合伙人为税收协定**缔约对方居民**的，
   该合伙人**在中国负有纳税义务的所得被缔约对方视为其居民的所得的部分**，
   **可以在中国享受协定待遇**
2. ⚠ **依照外国（地区）法律成立的**合伙企业，
   **其实际管理机构不在中国境内、但在中国境内设立机构、场所**的，
   或者**在中国境内未设立机构、场所但有来源于中国境内所得**的，
   **是中国企业所得税的非居民企业纳税人**
   - ⚠ **除税收协定另有规定的以外，只有当该合伙企业是缔约对方居民的情况下，
     其在中国负有纳税义务的所得才能享受协定待遇**
   - ⚠ 该合伙企业按「**自行判断、申报享受、相关资料留存备查**」的方式办理协定待遇相关业务
   - ⚠ **「税收协定另有规定」**指：税收协定规定，**当根据缔约对方国内法，
     合伙企业取得的所得被视为合伙人取得的所得，则缔约对方居民合伙人应就其从合伙企业
     取得所得中分得的相应份额享受协定待遇**

### 六、⚠ 非居民纳税人享受协定待遇的后续管理（自 2020-01-01 起）

- ⚠ **办理方式**：**「自行判断、申报享受、相关资料留存备查」**
  —— 非居民纳税人**自行判断符合**享受协定待遇条件的，
  可在**纳税申报时**，或**通过扣缴义务人在扣缴申报时**，**自行享受**协定待遇，
  同时按规定**归集和留存相关资料备查**，并**接受税务机关后续管理**
- ⚠ **「协定待遇」**中的「协定」**包括税收协定和国际运输协定**
  （国际运输协定包括中国政府签署的**航空协定、海运协定、道路运输协定、汽车运输协定、
  互免国际运输收入税收协议或换函**等）
- ⚠ **「协定待遇」**指按照协定**可以减轻或者免除**按照国内税收法律规定应当履行的
  企业所得税、个人所得税纳税义务
- ⚠ **扣缴义务人**包括**法定扣缴义务人**和《企业所得税法》规定的**指定扣缴义务人**

**（一）⚠ 协定适用和纳税申报责任**

- ⚠ **自行申报的**：应在申报时报送《**非居民纳税人享受协定待遇信息报告表**》并归集留存资料
- ⚠ **源泉扣缴和指定扣缴情况下**：应**如实填写**该报告表，**主动提交给扣缴义务人**，
  并归集和留存备查资料
- ⚠ 扣缴义务人收到后，**确认填报信息完整的**，依国内法规定和协定规定扣缴，
  并**如实将该报告表作为扣缴申报的附表报送**主管税务机关
- ⚠⚠ **非居民纳税人未主动提交或填报信息不完整的 → 扣缴义务人依国内税收法律规定扣缴**

**⚠ 留存备查资料的四类**：
1. 由**协定缔约对方税务主管当局开具**的证明非居民纳税人取得所得的**当年度或上一年度
   税收居民身份**的**税收居民身份证明**
   —— ⚠ 享受税收协定**国际运输条款或国际运输协定待遇**的，
   可**用能够证明符合协定规定身份的证明代替**税收居民身份证明
2. 与取得相关所得有关的**合同、协议、董事会或股东会决议、支付凭证**等权属证明资料
3. 享受**股息、利息、特许权使用费**条款协定待遇的，应留存**证明「受益所有人」身份**的相关资料
4. 非居民纳税人认为能够证明其符合享受协定待遇条件的**其他资料**

- ⚠ **主动补税义务**：发现**不应享受而享受了**协定待遇并少缴或未缴税款的，
  应当**主动**向主管税务机关申报补税
- ⚠ **多缴退还**：可享受但**未享受**协定待遇而多缴税款的，
  可在**税收征管法规定期限内**自行或通过扣缴义务人向主管税务机关**要求退还多缴税款**，
  同时提交备查资料
  —— ⚠ 主管税务机关应当**自接到退还申请之日起 30 日内查实**，
  对符合条件的多缴税款**办理退还手续**

**（二）⚠⚠ 后续管理中三层责任的划分（本考点的难点）**

| 情形 | 责任归属 |
|---|---|
| ⚠ 非居民纳税人、扣缴义务人**均未按要求提供资料**，或**逃避、拒绝、阻挠**税务机关进行后续调查，**致使无法查实**其是否符合条件的 | ⚠ **应视为不符合**享受协定待遇条件 |
| ⚠ 非居民纳税人**不符合条件而享受了**待遇且未缴或少缴税款，**除因扣缴义务人未按规定扣缴申报外** | ⚠ 视为非居民纳税人**未按照规定申报缴纳税款**，依法**追缴税款并追究其延迟纳税责任**；⚠ **在扣缴情况下，税款延迟缴纳期限自扣缴申报享受协定待遇之日起计算** |
| ⚠ 扣缴义务人**未按规定扣缴申报**，或者**未按规定提供相关资料**，发生上述情形的 | ⚠ 依有关规定**追究扣缴义务人责任**，并**责令非居民纳税人限期缴纳**税款 |

- ⚠ **追缴的兜底措施**：非居民纳税人未依法缴纳税款的，
  主管税务机关可依据《企业所得税法》**第三十九条**规定，
  **从该非居民纳税人在中国境内其他收入项目的支付人应付的款项中，追缴**其应纳税款
- ⚠ **报请上级与启动程序**：后续管理或税款退还查实工作中**发现不能准确判定**能否享受协定待遇的 →
  **应当向上级税务机关报告**；⚠ 需要启动**相互协商或情报交换**程序的，按规定启动
- ⚠ 发现需要适用**税收协定主要目的测试条款**或**国内法一般反避税规则**的 → **适用一般反避税相关规定**
- ⚠ 主管税务机关应当对非居民纳税人**不当享受协定待遇情况建立信用档案**，并采取相应后续管理措施
- ⚠ **总原则**：在非居民纳税人享受税收协定待遇管理中，
  **应坚持税收协定优先原则**

### 七、⚠ 《中国税收居民身份证明》的开具管理

**（一）申请开具主体**

- ⚠ 企业或者个人可以就其构成中国税收居民的**任一公历年度**向其主管税务机关申请开具
- ⚠⚠ **三类主体不能申请开具，但另有办理路径**：

| 主体 | 应由谁申请 |
|---|---|
| ⚠ 中国居民企业的**境内、境外分支机构** | ⚠ 由其**中国总机构**向总机构主管税务机关申请开具 |
| ⚠ **境内个体工商户** | ⚠ 由其**中国居民业主**向境内个体工商户**经营管理所在地**主管税务机关申请开具 |
| ⚠ **境内个人独资企业** | ⚠ 由其**中国居民投资人**向境内个人独资企业**经营管理所在地**主管税务机关申请开具 |
| ⚠ **境内合伙企业** | ⚠ 由其**中国居民合伙人**向中国居民合伙人主管税务机关申请开具 |

**（二）申请资料（按目的分流）**

- ⚠ **以享受协定待遇为目的**申请开具的 → 提交**与拟享受协定待遇收入有关的合同、协议、
  董事会或者股东会决议、相关支付凭证**等证明资料
- ⚠ **以非享受协定待遇为目的**申请开具的 → 提交能证明**申请目的真实性**的有关材料
  （如**政府监管部门等出具的需申请人提供《税收居民证明》的正式文书**，
  或者有关法律依据、其他能证明申请目的真实性的材料等）

**（三）办理规则**

- ⚠ **资料齐全**的，主管税务机关应当按规定**受理**；
  ⚠ **资料不齐全**的，**不予受理**，并**一次性告知**申请人应补正内容
- ⚠ 中国居民企业的境内、境外分支机构申请时，如需在**备注栏体现其与境内、境外分支机构关系**，
  提供**总分机构登记注册资料**
