# 房地产开发经营业务的所得税处理

## Definition

房地产开发经营业务的所得税处理（Real Estate Development Tax）：针对房地产开发企业「**先预售、后完工**」的经营特点，对**完工条件**、**收入确认**与**毛利额调整**作出的专门规定。

其关键机制是：预售时按**预计毛利率**预缴，**完工年度**再把「**实际毛利额 − 预计毛利额**」的差额并入当年应纳税所得额——即一次**补差**。

## Key Points

- **依据**：《房地产开发经营业务企业所得税处理办法》（国税发〔2009〕31 号）
- **业务范围**：土地的开发，建造、销售**住宅、商业用房以及其他建筑物、附着物、配套设施**等
  开发产品的一系列经营活动
- **⚠ 视为已经完工的三个条件**（**除土地开发之外**，符合**之一**即可）：
  - ①开发产品**竣工证明材料**已报房地产管理部门**备案**
  - ②开发产品**已开始投入使用**
    （指开始办理开发产品**交付手续**〔包括入住手续〕或已开始**实际投入使用**）
  - ③开发产品**已取得了初始产权证明**
  - ⚠ **无论工程质量是否通过验收合格**，或是否办理完工（竣工）备案手续以及会计决算手续，
    **当开发产品开始投入使用时均应视为已经完工**
- **完工年度的毛利额调整**（本考点的核心机制）：
  - 开发产品已经完工的，应按规定及时**结算开发产品计税成本**
  - 并计算此前以**预售**方式销售开发产品所取得收入的**实际毛利额**
  - 将**实际毛利额与其对应的预计毛利额之间的差额**，计入**当年（完工年度）**应纳税所得额
- **核定征收的限制**：
  - 出现《税收征管法》第三十五条规定情形的，税务机关可对其**以往**应缴的企业所得税
    按**核定征收**方式进行征收管理，并逐步规范
  - ⚠ 但**不得事先确定**房地产开发企业的所得税按核定征收方式进行征收、管理
- **销售收入的税务处理**：
  - **范围**：销售开发产品过程中取得的**全部价款**，包括现金、现金等价物及其他经济利益
  - **代收款项的分流**：房地产开发企业代有关部门、单位和企业收取的各种**基金、费用和附加**等 ——
    - 凡**纳入开发产品价内**或**由企业开具发票**的 → 应**全部确认为销售收入**
    - **未纳入**开发产品价内且**由房地产开发企业之外的其他收取部门、单位开具发票**的 →
      可作为**代收代缴款项**管理
  - **收入实现的确认**：通过正式签订《**房地产销售合同**》或《**房地产预售合同**》取得的收入，
    应确认为销售收入的实现
  - **两种收款方式的确认时点**：

    | 收款方式 | 确认时点 |
    |---|---|
    | **一次性全额收款** | 于**实际收讫价款**或**取得索取价款凭据（权利）之日** |
    | **分期收款** | 按销售合同或协议**约定的价款和付款日**；<br>⚠ **付款方提前付款**的，在**实际付款日**确认 |

- **其余三种收款方式的确认时点**：

  | 收款方式 | 确认时点 |
  |---|---|
  | **银行按揭方式** | 按销售合同或协议**约定的价款**确定收入额；⚠ **首付款**于**实际收到日**确认，<br>**余款**在**银行按揭贷款办理转账之日**确认 |
  | **委托方式** | 见下「委托销售的四种方式」 |
  | **预租** | 新建开发产品在**尚未完工或办理房地产初始登记、取得产权证前**与承租人签订**租赁预约协议**的，<br>自开发产品**交付承租人使用之日**起，出租方取得的**预租价款按租金**确认收入 |

- ⚠ **委托销售的四种方式**（均在**收到受托方已销开发产品清单之日**确认）：

  | 方式 | 确认口径 |
  |---|---|
  | **支付手续费方式** | 按销售合同或协议中**约定的价款**确认 |
  | **视同买断方式** | 属开发企业与购买方签约、或开发企业／受托方／购买方**三方共签**的：<br>约定价格**高于**买断价格 → 按**约定价格**；约定价格**低于**买断价格，或属**受托方与购买方签约**的 → 按**买断价格** |
  | **基价（保底价）+ 超基价分成方式** | 属开发企业与购买方签约、或**三方共签**的：约定价格**高于**基价 → 按**约定价格**（⚠ 支付受托方的**分成额不得直接从销售收入中减除**）；<br>约定价格**低于**基价 → 按**基价**；<br>属**受托方与购买方直接签约**的 → 按**基价加上按规定取得的分成额** |
  | **包销方式** | **包销期内**可根据包销合同约定参照上述第 ① 至 ③ 项确认；<br>⚠ **包销期满后尚未出售**的开发产品，由开发企业根据包销合同或协议**约定的价款和付款方式**确认 |

- ⚠ **视同销售的八种情形与确认顺序**：开发产品用于**捐赠、赞助、职工福利、奖励、对外投资、
  分配给股东或投资人、抵偿债务、换取其他企事业单位和个人的非货币性资产**等行为的，应**视同销售**，
  于**开发产品所有权或使用权转移**，或于**实际取得利益权利**时确认收入（或利润）的实现。
  确认收入（或利润）的**方法与顺序**：
  1. 按本企业**近期或本年度最近月份**同类开发产品**市场销售价格**确定
  2. 由主管税务机关参照当地同类开发产品**市场公允价值**确定
  3. 按开发产品的**成本利润率**确定 —— ⚠ **成本利润率不得低于 15%**，具体比例由主管税务机关确定

### ⚠ 预计计税毛利率（四档）与预计毛利额机制

**销售未完工开发产品的计税毛利率**由各省、自治区、直辖市税务局按下列规定确定：

| 开发项目位置 | 计税毛利率下限 |
|---|---|
| 省、自治区、直辖市和**计划单列市人民政府所在地**城市城区和郊区 | 不得低于 **15%** |
| **地级市**城区及郊区 | 不得低于 **10%** |
| **其他地区** | 不得低于 **5%** |
| ⚠ **经济适用房、限价房和危改房** | 不得低于 **3%** |

- **预缴机制**：销售未完工开发产品取得的收入，应先按**预计计税毛利率**分**季（或月）**
  计算**预计毛利额**，计入**当期**应纳税所得额
- **完工后的补差**：开发产品完工后，应及时**结算计税成本**并计算此前销售收入的**实际毛利额**，
  同时将**实际毛利额与预计毛利额之间的差额**，计入**当年度本项目与其他项目合并计算**的应纳税所得额
- ⚠ **月（季）度预缴申报的填报口径变化**：在《企业所得税月（季）度预缴纳税申报表》中的
  「**特定业务计算的应纳税所得额**」栏次填报 ——
  - **2021 年以前**：填入「按照税收规定的预计计税毛利率计算出的预计毛利额」
  - ⚠ **2021 年第一季度开始**：填入「按照预计计税毛利率计算出的预计毛利额，**扣除实际缴纳
    且在会计核算中未计入当期损益的土地增值税等税金及附加后的金额**」
- ⚠ **年度纳税申报**时，房地产开发企业须出具对该项开发产品**实际毛利额与预计毛利额之间
  差异调整情况的报告**以及税务机关需要的其他相关资料

### 特定事项的税务处理

- **未成立独立法人公司的合作／合资开发**：
  - ⚠ 约定**分配开发产品**的：首次分配时**已结算**计税成本 → 应分配给投资方开发产品的**计税成本
    与其投资额之间的差额**计入当期应纳税所得额；**未结算**计税成本 → 将**投资方的投资额视同销售收入**
    进行相关税务处理
  - ⚠ 约定**分配项目利润**的：开发企业应将该项目形成的**营业利润额并入当期**应纳税所得额
    统一申报缴纳，**不得在税前分配**该项目利润；同时**不能**因接受投资方投资额而在成本中摊销
    或税前扣除相关的**利息支出**。⚠ **投资方**取得该项目的营业利润应**视同股息、红利**处理
- **以换取开发产品为目的、将土地使用权投资其他企业的房地产开发项目**：
  应在**首次取得开发产品时**，将其**分解为转让土地使用权和购入开发产品两项经济业务**处理，
  并按应取得的开发产品（含首次及以后应取得的）的**市场公允价值**计算确认**土地使用权转让所得或损失**
- ⚠ **土地增值税清算涉及企业所得税退税**（自 2016-12-09 起施行）：
  - 因**土地增值税清算**导致**多缴企业所得税**的：清算后**当年汇算清缴出现亏损**且**有后续开发项目**
    （指**正在开发以及中标的**项目）的 → 该亏损按税法规定**向以后年度结转**，用以后年度所得弥补
  - **没有后续开发项目**的 → 可计算该项目因土地增值税原因导致的项目开发**各年度多缴企业所得税税款**
    并申请退税：
    1. 该项目缴纳的**土地增值税总额**，按各年度实现的项目销售收入占整个项目销售收入总额的比例分摊：
       **各年度应分摊的土地增值税 = 土地增值税总额 ×（项目年度销售收入 ÷ 整个项目销售收入总额）**
       —— ⚠ 公式中的销售收入**包括视同销售房地产的收入**，但**不包括**销售的**增值额未超过扣除项目金额
       20% 的普通标准住宅**的销售收入
    2. 各年度应分摊的土地增值税 − 该年度**已经税前扣除**的土地增值税 = 当年应**补充扣除**的土地增值税；
       据此调整当年应纳税所得额并计算当年度应退税款；
       ⚠ 当年已缴税款**不足退税**的，应**作为亏损向以后年度结转**并调整以后年度应纳税所得额
    3. ⚠ **累计退税额不得超过**该项目开发各年度**累计实际缴纳**的企业所得税；
       超过部分作为**项目清算年度产生的亏损**，向以后年度结转
  - 申请退税时应提供**书面材料**说明应退税款的计算过程（土地增值税总额、项目销售收入总额、
    项目年度销售收入额、各年度应分摊与已扣除的土地增值税、各年度适用税率、是否有后续开发项目等）

- **与相关概念的衔接**：本页**只管「收入与完工」**，**成本与扣除**见
  [[real-estate-development-cost-accounting]]；房地产开发企业**转让土地使用权**的增值税与
  土地增值税口径分别见 [[vat-taxable-transaction]] 与 [[land-appreciation-tax]]；
  「预计毛利额」这一机制与会计上按履约进度确认收入的差异，可与
  [[revenue-recognition-five-steps]] 对照理解

> ⚠ **税会差异与账务视角**（**预售的「预计计税毛利率 → 预计毛利额 → 完工后差额调整」；预收账款的账面价值与计税基础不同 → 可抵扣暂时性差异 → 递延所得税资产**）见 [[vat-accounting-real-estate-presale-and-special-adjustments]]。
