# 财产租赁与转让所得（个人所得税）

## Definition

财产租赁与转让所得（Individual Property Income）：个人所得税下按 **20% 比例税率**分类征收的
两类财产性所得，加上同样 20% 的**偶然所得**。三者共同的特点是**不并入综合所得**、
按次或按月单独计税。

⚠ **财产租赁所得**在税务上有一套**独有的四步扣除次序**，且个人出租**居民住房**享受
**减按 10%** 的优惠税率——这两点是与财产转让所得最大的差别。

## Key Points

### 一、财产租赁所得

- **计税单位**：以**一个月内**取得的收入为一次
- ⚠ **税前扣除的次序**（不可颠倒）：
  ①**财产租赁过程中缴纳的税费**；②**向出租方支付的租金**；
  ③由纳税人负担的该出租财产实际开支的**修缮费用**；④**税法规定的费用扣除标准**
- **费用扣除标准**：经上述扣除后的余额，**不足 4000 元**的减除 **800 元**；
  **超过 4000 元**的减除 **20%**
- ⚠ **税率优惠**：个人按市场价格出租**居民住房**取得的所得，**减按 10%** 征收
- ⚠ **房产税**：个人出租住房按 **4%** 税率征收房产税（一般出租为 12%）
- ⚠ **计税起点**：出租房产自**交付出租房产之次月**起计征房产税（不是当月）
- ⚠ **修缮费**：每次扣除以 **800 元**为限，一次扣除不完的**准予在下次**继续扣除
- **转租收入**：个人取得的**财产转租收入**属于财产租赁所得；
  产权所有人死亡、未办理产权继承手续期间出租而有租金收入的，
  以**领取租金的个人**为纳税义务人
- ⚠ **以房屋租金抵偿债务**：属于"**财产租赁所得**"（不是财产转让）
- ⚠ **私营企业**将企业仓库对外出租而获得的租金收入 → 缴纳**企业所得税**（不是个人所得税）

### 二、财产转让所得

- **应纳税所得额** = 转让收入 − 财产原值 − 合理费用
- **财产原值的确定**：
  - 转让**债券**：通常采用"**加权平均法**"确定应予减除的财产原值和合理费用
  - 个人**多次取得同一被投资企业股权**的，转让部分股权时采用"**加权平均法**"确定股权原值
  - 有价证券的原值为**买入价以及买入时按规定缴纳的有关费用**
  - 拍卖物品：**从拍卖行拍得**的 → **拍得该拍卖品实际支付的价款及缴纳的相关税费**；
    **通过商店、画廊等途径购买**的 → 购买该拍卖品时实际支付的价款；
    **通过祖传收藏**的 → **收藏该拍卖品而发生的费用**；
    **通过赠送取得**的 → **受赠该拍卖品时发生的相关税费**
- **住房转让的原值与装修费扣除**：
  - 商品房原值 = 购房款 + 相关税费（含**契税**）
  - ⚠ **装修费用扣除限额**：商品房及其他住房为**房屋原值的 10%**；
    **经济适用房**为**房屋原值的 15%**
  - 经济适用房原值还包括按规定交纳的**土地出让金**
- ⚠ **家庭生活用房免税**：个人转让**自用达 5 年以上**、并且是**唯一**的家庭生活用房取得的所得，**免征**个人所得税
- ⚠ **离婚析产**：因离婚办理房屋产权过户手续分得的房屋，**不缴纳**个人所得税；
  转让离婚析产房屋，符合家庭生活自用 5 年以上唯一住房的可申请免征；
  其财产原值为**房屋初次购置全部原值和相关税费之和 × 转让者占房屋所有权的比例**

### 三、偶然所得

- **企业向本单位以外**的个人赠送礼品（包括**网络红包**），以及在年会、座谈会、庆典等活动
  中向**本单位以外的个人**赠送礼品 → **偶然所得**
  ⚠ 对比：**本单位**员工在年会中获得的有奖竞猜奖品 → **工资、薪金所得**
- **个人为单位或他人提供担保**取得的收入 → **偶然所得**
- **彩票中奖**：⚠ **电脑彩票**以**同一人在同一期同一游戏中获得的全部奖金**为一次中奖收入；
  **即开型彩票**以**一张彩票奖金**作为一次中奖收入；
  一次中奖收入**超过 1 万元**的按偶然所得**全额**计征
- ⚠ **企业赠送礼品**的计税依据：赠品是**自产**产品（服务）的，按**市场销售价格**确定；
  是**外购**商品（服务）的，按**实际购置价格**确定

### 四、拍卖所得的特殊规则

- 个人拍卖**除文字作品原稿及复印件以外**的其他财产 → 以转让收入额减除财产原值和合理费用后的余额，
  按"**财产转让所得**"适用 20% 税率
- ⚠ **不能提供**合法、完整、准确的财产原值凭证的 → 按**转让收入额的 3% 征收率**计算缴纳；
  ⚠ 拍卖品为经文物部门认定的**海外回流文物**的 → 按转让收入额的 **2% 征收率**计算
- ⚠ **代扣代缴**：个人财产拍卖所得应纳的个人所得税，由**拍卖单位**负责代扣代缴，
  并向**拍卖单位所在地**主管税务机关申报

### 教材补充（CTA《税法（二）》教材 2026 版第五节「四、分类所得的计税方法」）

**（一）利息、股息、红利所得**

- ⚠ 以个人**每次取得的收入额**为应纳税所得额，**不得从收入额中扣除任何费用**
- ⚠ 每次收入额指**支付单位或个人每次支付**利息、股息、红利时个人所取得的收入
- ⚠ **派发红股**：股份制企业在分配股息、红利时，以**股票形式**向股东个人支付应得的股息、红利
  （即派发红股），应以**派发红股的股票票面金额**为收入额
- ⚠ **企业为股东购车**：企业购买车辆并将车辆所有权办到**股东个人名下**，
  实质为对股东的**红利性质的实物分配**，按「利息、股息、红利所得」征收；
  ⚠ 考虑到车辆**同时也为企业经营使用**的实际情况，在计算收入额时
  **允许合理减除部分所得**，减除的具体数额由主管税务机关根据车辆的**实际使用情况合理确定**
- ⚠ 适用 **20% 的比例税率**；**应纳税额 = 应纳税所得额（每次收入额）× 适用税率**
- ⚠ **持股期限的差别化待遇**见 [[individual-dividend-differential-tax]]

**（二）财产租赁所得**

- ⚠ **费用减除**：每次收入**不超过 4000 元**，定额减除费用 **800 元**；
  每次收入在 **4000 元以上**，定率减除 **20%** 的费用
- ⚠ **以一个月内取得的收入为一次**
- ⚠ **四项依次扣除**：①财产租赁过程中**缴纳的税费**（⚠ 可持**完税（缴款）凭证**从收入中扣除）；
  ②**向出租方支付的租金**；③由纳税人负担的租赁财产**实际开支的修缮费用**；
  ④**税法规定的费用扣除标准**
  - ⚠ 准予扣除的**修缮费用以每次 800 元为限**；一次扣除不完的，
    **准予在下一次继续扣除，直到扣完为止**
  - ⚠ **转租**：取得转租收入的个人**向房屋出租方支付的租金**，
    **凭房屋租赁合同和合法支付凭据**允许从该项转租收入中税前扣除

> **每次（月）收入不超过 4000 元：应纳税所得额 = 每次（月）收入额 − 准予扣除项目
> − 修缮费用（800 元为限）− 800 元**
>
> **每次（月）收入超过 4000 元：应纳税所得额 =〔每次（月）收入额 − 准予扣除项目
> − 修缮费用（800 元为限）〕×（1 − 20%）**

- ⚠ 适用 **20% 的比例税率**；⚠ **个人按市场价格出租的居民住房取得的所得，
  自 2001-01-01 起暂减按 10% 的税率**征收个人所得税

**（三）财产转让所得**

- ⚠ **应纳税所得额 = 每次收入额 − 财产原值 − 合理费用**
- ⚠ **转让债券**采用「**加权平均法**」确定其应予减除的财产原值和合理费用：

> **一次卖出某一种类债券允许扣除的买入价和费用 =
> （纳税人购进的该种类债券买入价和买进过程中缴纳的税费总和 ÷ 纳税人购进的该种类债券总数量）
> × 一次卖出的该种类债券的数量 + 卖出该种类债券过程中缴纳的税费**

- ⚠ 适用 **20% 的比例税率**；**应纳税额 = 应纳税所得额 × 适用税率**
- ⚠ **个人股权转让**的完整规则见 [[equity-transfer-individual-tax]]
- ⚠ **限售股与新三板股票转让**见 [[individual-equity-incentive-tax]]

**（四）偶然所得**

- ⚠ 以个人**每次取得的收入额**为应纳税所得额，**不扣除任何费用**；
  ⚠ 除有特殊规定外，**每次收入额就是应纳税所得额**，以每次取得该项收入为一次
- ⚠ 适用 **20% 的比例税率**；**应纳税额 = 应纳税所得额（每次收入额）× 适用税率**

**（五）⚠ 个人住房转让所得（国税发〔2006〕108 号，自 2006-08-01 起）**

- ⚠ **转让收入**：以**实际成交价格**为转让收入；⚠ 纳税人申报的成交价格
  **明显低于市场价格且无正当理由**的，征收机关依法有权根据有关信息**核定**其转让收入，
  ⚠ **但必须保证各税种计税价格一致**
- ⚠ **可减除的三项**（凭**原购房合同、发票**等有效凭证，经税务机关审核后）：
  **房屋原值、转让住房过程中缴纳的税金、有关合理费用**

**⚠ 房屋原值的六种口径**：

| 房屋类型 | 房屋原值 |
|---|---|
| **商品房** | 购置该房屋时**实际支付的房价款**及**交纳的相关税费** |
| **自建住房** | 实际发生的**建造费用**及**建造和取得产权时实际交纳的相关税费** |
| **经济适用房**（含集资合作建房、安居工程住房） | 原购房人**实际支付的房价款及相关税费**，以及按规定**交纳的土地出让金**<br>（⚠ 经济适用房价格按**县级（含）以上地方人民政府**规定的标准确定） |
| **已购公有住房** | 原购公有住房**标准面积**按**当地经济适用房价格**计算的房价款 + 原购公有住房**超标准面积实际支付的房价款** + 按规定向**财政部门（或原产权单位）交纳的所得收益及相关税费** |

- ⚠ **已购公有住房**指城镇职工根据国家和**县级（含）以上**人民政府有关城镇住房制度改革政策规定，
  按照**成本价（或标准价）**购买的公有住房

**（六）两项住房优惠（与减免税优惠的衔接）**

- ⚠ **转让自用 5 年以上、并且是家庭唯一生活用房**取得的所得 → **免征**个人所得税
- ⚠ **换购住房退税**（自 **2026-01-01 至 2027-12-31**）：出售自有住房并在**出售后 1 年内**
  在市场重新购买住房的纳税人，对其出售现住房**已缴纳的个人所得税予以退税**
  —— ⚠ **退税比例**：新购住房金额 **≥** 现住房转让金额 → **全部退还**；
  **<** 现住房转让金额 → 按**新购住房金额占现住房转让金额的比例**退还
  - ⚠ **两个条件**：①出售和重新购买的住房应在**同一城市范围内**；
    ②出售自有住房的纳税人与新购住房之间须**直接相关**，
    应为**新购住房产权人或产权人之一**
  （详见 [[individual-income-tax-preferences]]）

### 教材补充之二（p252–256）：住房、受赠、析产、债权与拍卖

**（一）个人住房转让所得（续）**

**⚠ 城镇拆迁安置住房的原值（四种情形）**：

| 情形 | 房屋原值 |
|---|---|
| **房屋拆迁取得货币补偿后购置**房屋 | **购置该房屋实际支付的房价款**及交纳的相关税费 |
| **产权调换**方式 | 《房屋拆迁补偿安置协议》**注明的价款**及交纳的相关税费 |
| **产权调换**且**又取得部分货币补偿** | 《协议》注明的价款及交纳的相关税费 **减去货币补偿后的余额** |
| **产权调换**且**又支付部分货币** | 《协议》注明的价款，**加上所支付的货币**及交纳的相关税费 |

**⚠ 可减除的三项中的后两项口径**：

- ⚠ **转让住房过程中缴纳的税金** = 纳税人在转让住房时**实际缴纳**的城市维护建设税、
  教育费附加、**土地增值税、印花税**等税金
- ⚠ **合理费用** = 纳税人按规定**实际支付**的**住房装修费用、住房贷款利息、手续费、公证费**等
  - ⚠ **装修费用的扣除限额（两档）**：纳税人能提供实际支付装修费用的**税务统一发票**，
    且**发票上所列付款人姓名与转让房屋产权人一致**的，经税务机关审核 →
    ⚠ **已购公有住房、经济适用房：最高扣除限额为房屋原值的 15%**；
    ⚠ **商品房及其他住房：最高扣除限额为房屋原值的 10%**
    - ⚠⚠ **不得重复扣除**：纳税人原购房为**装修房**（合同注明房价款中含有装修费，
      铺装了地板、装配了洁具厨具等）的，**不得再重复扣除**装修费用
  - ⚠ **住房贷款利息**：出售以**按揭贷款**方式购置的住房，其向贷款银行**实际支付**的
    住房贷款利息，**凭贷款银行出具的有效证明据实扣除**
  - ⚠ **手续费、公证费**等：凭**有关部门出具的有效证明据实扣除**
- ⚠⚠ **不能提供原值凭证时的核定**：纳税人未提供完整、准确的房屋原值凭证，
  不能正确计算房屋原值和应纳税额的 → 税务机关可根据《税收征管法》第三十五条的规定
  **核定征税**，即按住房转让收入的**一定比例**核定应纳个人所得税税额；
  ⚠ **具体比例由省级税务局**或其授权的地市级税务局根据所处区域、地理位置、建造时间、
  房屋类型、住房平均价格水平等因素，**在住房转让收入 1%–3% 的幅度内确定**

**（二）个人无偿受赠房屋**

- ⚠ **不征收个人所得税的三种赠与**：①赠与**配偶、父母、子女、祖父母、外祖父母、孙子女、
  外孙子女、兄弟姐妹**；②赠与对其**承担直接抚养或者赡养义务**的抚养人或者赡养人；
  ③房屋产权所有人**死亡**，依法取得房屋产权的**法定继承人、遗嘱继承人或者受遗赠人**
- ⚠ **办理免税手续应提交的资料**：①赠与双方当事人的**有效身份证件**；
  ②属第 ① 项的，还须提供公证机构出具的**赠与人和受赠人亲属关系的公证书（原件）**；
  ③属第 ② 项的，还须提供公证机构出具的**抚养关系或者赡养关系公证书（原件）**，
  或者**乡镇政府或街道办事处出具的**抚养关系或者赡养关系证明
  - ⚠ 税务机关审核资料齐全且填写正确的，在《个人无偿赠与不动产登记表》上**签字盖章后
    复印留存，原件退还提交人**，同时办理个人所得税**不征税手续**
- ⚠ **除上述三种情形以外**的无偿赠与 → **受赠人**取得的受赠所得按「**偶然所得**」项目
  缴纳个人所得税，税率 **20%**
- ⚠ **应纳税所得额 = 房地产赠与合同上标明的赠与房屋价值 − 赠与过程中受赠人支付的相关税费**
  （⚠ 合同标明价值**明显低于市场价格**或**未标明**的，税务机关可依据**市场评估价格**
  或其他合理方式确定）
- ⚠⚠ **受赠人转让受赠房屋**：以其**转让受赠房屋的收入**减除**原捐赠人取得该房屋的实际购置成本**
  以及**赠与和转让过程中受赠人支付的相关税费**后的余额，为受赠人的应纳税所得额
  （⚠ 价格**明显偏低且无正当理由**的，税务机关可依据**市场评估价格**或其他合理方式核定）

**（三）个人转让离婚析产房屋**

- ⚠ 通过**离婚析产**的方式分割房屋产权是夫妻双方对**共同共有财产**的处置，
  个人因离婚办理房屋产权过户手续**分得的房屋，不缴纳**个人所得税
- ⚠ **转让**离婚析产房屋取得的收入，允许扣除其**相应的财产原值和合理费用**后，
  余额按规定税率缴纳
  - ⚠ 相应的**财产原值 = 房屋初次购置全部原值和相关税费之和 × 转让者占房屋所有权的比例**
- ⚠ 符合**家庭生活自用 5 年以上唯一住房**的，**可以申请免征**

**（四）个人购买和处置债权**

- ⚠ 个人通过**招标、竞拍或其他方式**购置债权以后，通过相关**司法或行政程序主张债权**
  而取得的所得 → 按「**财产转让所得**」项目缴纳个人所得税
- ⚠ **「打包」债权只处置部分债权**的，应纳税所得额按以下方式确定：
  1. ⚠ 以**每次处置部分债权的所得**，作为**一次**财产转让所得征税
  2. ⚠ 应税收入按个人取得的**货币资产和非货币资产的评估价值或市场价值的合计数**确定
  3. ⚠ 所处置债权的**成本费用（财产原值）**按公式计算：

> **当次处置债权成本费用 =
> 「打包」债权实际支出（或拍卖机构公布价值）×
> （当次处置债权账面价值 ÷「打包」债权账面价值）**

  4. ⚠ 个人购买和处置债权过程中发生的**拍卖招标手续费、诉讼费、审计评估费以及缴纳的税金**
     等合理税费，**允许扣除**

**（五）个人取得拍卖收入（自 2007-05-01 起）**

- ⚠⚠ **两类财产的税目分流**——⚠ 这一条与题库口径存在**冲突**，见下方 Contradictions：
  - ⚠ **作者将自己的文字作品手稿原件或复印件拍卖**取得的所得 →
    以**转让收入额减除 800 元**（转让收入额 **4000 元以下**）
    或者 **20%**（转让收入额 **4000 元以上**）后的余额为应纳税所得额，
    按「**特许权使用费所得**」项目适用 **20%** 税率
  - ⚠ **个人拍卖除文字作品原稿及复印件外的其他财产** →
    以**转让收入额减除财产原值和合理费用**后的余额为应纳税所得额，
    按「**财产转让所得**」项目适用 **20%** 税率
- ⚠ **转让收入额** = 该项财产**最终拍卖成交价格**
- ⚠ **拍卖财产的财产原值**（⚠ 按取得方式五分）：①通过**商店、画廊**等途径购买的 →
  购买该拍卖品时**实际支付的价款**；②通过**拍卖行拍得**的 → 拍得该拍卖品**实际支付的价款
  及缴纳的相关税费**；③通过**祖传收藏**的 → 为其**收藏该拍卖品而发生的费用**；
  ④通过**赠送**取得的 → 为其**受赠该拍卖品时发生的相关税费**；⑤通过**其他形式**取得的 →
  参照以上原则确定
- ⚠ **拍卖财产过程中缴纳的税金** = 拍卖财产时纳税人实际缴纳的相关税金及附加
- ⚠ **有关合理费用** = 拍卖财产时按规定实际支付的**拍卖费（佣金）、鉴定费、评估费、
  图录费、证书费**等
- ⚠⚠ **不能提供合法、完整、准确的财产原值凭证的核定征收率**：
  - 一般情形 → 按**转让收入额的 3% 征收率**计算缴纳个人所得税
  - ⚠ 拍卖品为经文物部门认定为**海外回流文物**的 → 按**转让收入额的 2% 征收率**计算
  - ⚠ 财产原值凭证**内容填写不规范**，或**一份凭证包括多件拍卖品且无法确认每件对应原值**的 →
    **不得作为**扣除依据，**视为不能提供**，按上述征收率计算
  - ⚠ 能提供合法的**原值凭证但不能提供有关税费凭证**的 →
    **不得按征收率**计算，应当就原值凭证上注明的金额**据实扣除**
- ⚠ **代扣代缴**：个人财产拍卖所得应纳的个人所得税税款，
  由**拍卖单位负责代扣代缴**，并按规定向**拍卖单位所在地**主管税务机关办理纳税申报；
  ⚠ 代扣代缴时应给纳税人**填开完税凭证**，并**详细标明每件拍卖品的名称、
  拍卖成交价格、扣缴税款额**

> ⚠ **审核视角**（**财产转让与财产租赁的查账落点**——受让方七个账户核对、有价证券数量比例公式、租赁所得按对手二分与「房产税 4%」的税率核对）见 [[iit-audit-business-and-property-transfer-income]]、[[iit-audit-other-income-items]]；⚠ **利息·股息红利·租金的扣缴检查**见 [[iit-audit-dividend-interest-rental-income]]。

> ⚠ **账务视角**（**股息利息红利四种支付情形的账务（集资利息→财务费用；现金股利→应付股利）**）见 [[iit-accounting]]。

## Contradictions

### ⚠ 手稿拍卖所得的税目归属（题库与教材口径冲突，2026-09-22 发现）

- **题库口径**（[[cta-550-tax-law-2-questions]]）：**手稿原件**拍卖 → **财产转让所得**；
  **手稿复印件**拍卖 → **特许权使用费所得**

  **均为「特许权使用费所得」**；仅拍卖「**除文字作品原稿及复印件外的其他财产**」时才归
  **财产转让所得**
