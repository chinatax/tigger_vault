# 消费税出口退（免）税

## Definition

消费税出口退（免）税（Consumption Tax Export Refund and Exemption）：对出口应税消费品的
已纳消费税予以退还或免征的制度。它与增值税出口退税**规则不同**——增值税由国家统一承担，
而消费税**随其出口货物所适用的增值税政策分层**：增值税退（免）税则消费税亦退，
增值税免税则消费税只免不退。

## Key Points

- **两条基本路径**（随增值税政策走）：
  - 纳税人出口适用**增值税退（免）税**政策的应税消费品，且属于**购进出口**的货物 →
    适用消费税**出口免税并退税**
  - 纳税人出口适用**增值税免税**政策的应税消费品 → **免征消费税但不退还**其以前环节已征的消费税，
    且**不允许**在内销应税消费品应纳消费税税款中抵扣
- **退税额的计税依据**（**关键限定词：已征且"未"在内销中抵扣**）：
  - **从价定率**计征的 → 计税依据为已征且**未在内销**应税消费品应纳税额中抵扣的**购进出口货物金额**
  - **从量定额**计征的 → 计税依据为已征且**未在内销**应税消费品应纳税额中抵扣的**购进出口货物数量**
  - **复合计征**的 → 按从价定率和从量定额的计税依据**分别确定**
- ⚠ **易错点**：若该类消费品已在内销应纳税额中抵扣过，则不再退还——
  这是"退"与"抵"不能重复享受的体现。
- **金银首饰**：在**零售**环节征税，**出口金银首饰不退**消费税。

### 教材第九节的系统性补充（2026-09-23）

**依据**：《财政部 税务总局关于出口业务增值税和消费税政策的公告》（**财政部 税务总局公告 2026 年第 11 号**）——
⚠ **与增值税出口政策同出一份公告**（见 [[vat-export-tax-refund]]）。

**（1）⚠ 适用范围（三条，与增值税三档一一对应）**

| 出口货物所适用的**增值税**政策 | 相应的**消费税**处理 |
|---|---|
| **退（免）税**政策 | **免征**消费税；⚠ 如果属于**购进或者委托加工收回**出口的货物，**退还前一环节**对其已征的消费税 |
| **免税**政策 | **免征**消费税，但**不退还**以前环节已征的消费税，且**不允许在**内销应税消费品应纳消费税款中**抵扣** |
| ⚠ **征税**政策 | ⚠ **应当按规定缴纳**消费税，**不退还**以前环节已征的消费税，且**不允许在内销**应税消费品应纳消费税款中**抵扣** |

> ⚠ **记忆锚点**：**增值税「免」→消费税「免」；增值税「退」→消费税「退」；增值税「征」→消费税「征」。**
> ⚠ 且**只有「退」这一档才真正退还上一环节已征的消费税**，另两档都**不退也不抵**。

**（2）退（免）税的计税依据（凭证 + 三种计征办法）**

- ⚠ **凭证**：出口货物的消费税应退税额的计税依据，按照购进或者委托加工收回出口货物取得的
  **出口货物消费税专用缴款书**（**消费税专用缴款书**）、**消费税专用缴款书分割单**、
  **代扣代收税款凭证**和**海关进口消费税专用缴款书**确定。
- ⚠ **三种计征办法的计税依据**：

  | 计征办法 | 计税依据 |
  |---|---|
  | **从价定率** | 已征且**未在内销**应税消费品应纳税额中抵扣的购进或委托加工收回出口货物**金额** |
  | **从量定额** | 已征且**未在内销**应税消费品应纳税额中抵扣的购进或委托加工收回出口货物**数量** |
  | **复合计征** | 按从价定率和从量定额的计税依据**分别确定** |

- ⚠ **两类凭证的开具主体（易混）**：
  - 纳税人**直接从生产应税消费品的企业购进**、或者**委托加工收回**货物用于出口的 →
    由**生产应税消费品的企业或者受托企业的主管税务机关**在**征税时**开具**消费税专用缴款书或者
    代扣代收税款凭证**；
  - 将购进或委托加工收回的已征收消费税的货物**销售给其他纳税人出口**的 →
    由**其主管税务机关**开具**消费税专用缴款书分割单**交其他纳税人据以申请退税。

**（3）退（免）税的计算**

| 计征办法 | 应退税额 |
|---|---|
| **从价定率** | **退税计税依据 × 消费税比例税率** |
| **从量定额** | **退税计税依据 × 消费税定额税率** |
| **复合计征** | 按上述两项**分别计算后相加** |

**（4）⚠ 应纳消费税的计算（适用于「出口适用征税政策」的情形）**

| 计征办法 | 应纳消费税额 |
|---|---|
| **从价定率** | **出口应税消费品的销售额 × 消费税比例税率** |
| **从量定额** | **出口应税消费品的数量 × 消费税定额税率** |
| **复合计税** | **出口应税消费品的销售额 × 比例税率 + 出口应税消费品的数量 × 定额税率** |

- ⚠ **销售额的换算**：**出口应税消费品的销售额 ＝ 含增值税的销售额 ÷（1 + 增值税税率或者征收率）**
- ⚠ ⚠ **「含增值税的销售额」的口径**：**为出口货物的离岸价**。
  ——⚠ 即：**出口业务的「含增值税的销售额」就是离岸价（FOB）**，这一定义是本题型的解题起点。
