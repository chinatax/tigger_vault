# 一般税务咨询的实施步骤

## Definition

⚠ **本页是《涉税服务实务》第七章《税务咨询服务》第一节「一般税务咨询服务」之
「「二、一般税务咨询的实施步骤」」**（书页 393 中–395 中，txt 398 上–400 中）。

> ⚠ **教材原句（总纲）**：「一般税务咨询作为专业性涉税服务业务，与其他涉税专业服务业务一样，
> 应当执行**「业务承接、业务计划、归集资料、专业判断、实施办理、反馈结果、业务记录、业务成果」
> 等一般流程**。在具体实施过程中……对具体内容和环节作相应的**简并或调整安排**，
> ⚠ **其中「实施办理」是一般税务咨询服务的「必经流程」」**。

⚠ **边界**：
- ⚠ **服务内容与服务方式**见 [[general-tax-consulting-scope-and-methods]]；
  **案例分析**见 [[general-tax-consulting-cases]]（**同批**）。

## Key Points

### 一、⚠ 「一般税务咨询基本实施步骤」（**七步**）

> **教材原句**：「一般税务咨询的实施，应执行以下基本步骤」：

| # | ⚠ 步 |
|---|---|
| **（1）** | **与委托人签订一般税务咨询业务「委托协议」** |
| **（2）** | **获取或接收委托人咨询的「涉税事项和相关资料」** |
| **（3）** | **对咨询的涉税事项和资料进行「专业判断」** |
| **（4）** | **对咨询的涉税事项作「答复前的准备」** |
| **（5）** | **根据税务咨询方式或委托协议的约定，以适当方式进行「税务咨询回复」** |
| **（6）** | **税务咨询成果的「确认和签署或回执」** |
| **（7）** | **根据委托协议约定，税务咨询事项具体实施情况的「跟踪或反馈」** |

### 二、⚠⚠ 「税收政策适用咨询的实施」（**五个方面**）

> ⚠ **教材原句（本目的定位）**：「**税收政策适用咨询是一般税务咨询服务「最常见、最主要」的涉税事项，
> 也是一般税务咨询服务的「重点」**」。

#### 1. ⚠ 「把握咨询的税务事项实质」

⚠ **教材原句**：「委托人**限于专业水平或政策掌握的限制**，咨询时更多地**描述涉税事项的本身**，
有时**甚至不清楚咨询的事项所指向的具体涉税问题是什么、涉及哪些税种**」——
⚠ **「这就要求涉税服务人员根据委托人的咨询，进行专业分析，「准确把握委托人咨询的指向、目的和用途」，
以便选择适当的咨询方式、作出有针对性的答复」**。

#### 2. 「收集咨询问题相关的税收政策文件」

**「应收集咨询问题相关的「税收法律、法规、行政规章以及规范性文件」——这既是提供正确咨询的保证，
「有时也是必须向咨询人或其他相关人提供的咨询资料」」**；
⚠ **理由**：「国家会对税收政策作出调整……**各级立法部门、政府机构以及税务机关也会根据各自的职能
制定有关税收方面的政策规定和操作办法**」——**故应「全面收集相关的税收政策文件，进行细致分析」**。

#### 3. ⚠⚠ 「分析税收政策适用条款」——**本目是「核心和价值所在」**

> ⚠ **教材原句**：**「根据委托人咨询的税务事项，准确确定相应的税收政策适用条款，
> 是「一般税务咨询服务的核心和价值所在」」**。

⚠⚠ **应按「税法适用原则」找准条款（教材逐条列出）**：
**「法律优位、法律不溯及既往、新法优于旧法、特别法优于普通法、国际法优于国内法、
实体从旧程序从新、程序优于实体」，以及「企业所得税法的实质重于形式」等原则**。

⚠⚠ **分析时应特别注意「三点」**：

| # | ⚠ 注意点（**教材原句**） |
|---|---|
| **（1）** | ⚠ **税收政策适用「时效」**——**「按照法律不溯及既往原则，税收政策一般没有溯及力，即「新问题用新政策、老问题用老政策」」**；⚠⚠ **「在咨询服务时「不能机械地套用新法优于旧法原则」，应根据咨询问题所发生的时间，寻找适用的税收政策条款」** |
| **（2）** | ⚠ **不同税种政策规定的「差异」**——**「有时对同一经营活动来说，不同的税种有着不同的政策规定，应针对咨询所涉及税种的相应税收政策作出答复，「切忌在适用税收政策上张冠李戴」，造成答复错误，误导委托人」** |
| **（3）** | ⚠⚠ **税收政策制定「原则和精神」**——**「因经济形势、业态变化，有时会出现发生的经济业务「没有直接的、明确的税收政策规定」，或者新的经济情况或经营方式已经出现而相应的税收政策尚未颁布的问题，「这也是咨询人最容易提出的咨询问题」」**；⚠ **答复口径**：**「除如实说明税收政策没有明确外，可根据国家制定税收政策的原则和立法精神作出分析，「提出倾向性的意见或操作办法」」** |

#### 4. 「根据需要作必要的沟通说明」

**「为了保证服务质量，必要时还应与「委托人、税务机关或其他相关人员」作进一步沟通说明」**——
**① 对委托人的说明**：**「委托人可能存在表述不全、讲述不清的情况，有时甚至会提出明显不符合法律规定
或经营惯例的问题，涉税服务人员在进行答复时应向委托人说明「政策适用的范围和限定条件，
以及可能产生的变化」」**；
**② 与税务机关的研究探讨**：**「有些问题较为复杂，涉及的税收政策或适用范围不够明显，
在理解或操作中有不统一的做法，涉税服务人员可以在提供咨询前，与税务机关有关部门或人员，
进行研究探讨，努力达成共识」**；
**③ 与相关人员的沟通**：**「委托人所咨询的问题在实施中涉及客户或相关部门的配合，
涉税服务人员也可根据需要与相应的人员进行必要的沟通」**。

#### 5. ⚠ 「确定合适的答复方式」

⚠ **按「问题复杂度」分流（教材原句）**：
- ⚠ **「问题复杂重大、涉及税种较多、操作技术要求高」的咨询问题** →
  **较多采取「书面回复方式」，根据委托协议约定出具专用的「税务咨询服务报告」**；
- ⚠ **「问题简单、政策规定明确、操作难度不大」的咨询问题** →
  **通常采取「口头回复方式」**。

> ⚠ **本页要点（一条可复用的链条）**：**「辨实质 → 收文件 → 定条款 → 作沟通 → 定方式」**——
> ⚠⚠ **其中第 3 步的「三点注意」是全书最集中的一处「税法适用原则」表述**，
> ⚠ **尤其「不能机械地套用新法优于旧法」（时效优先）与「同一经营活动不同税种口径可能不同」
> 两条，是实务中最易踩的两个坑**。
