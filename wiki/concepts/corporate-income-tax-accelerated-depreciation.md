# 固定资产加速折旧与一次性扣除

## Definition

固定资产加速折旧与一次性扣除（Accelerated Depreciation）：企业所得税上**缩短折旧年限**
或**采取加速折旧方法**、以及允许**一次性计入当期成本费用扣除**的税基式优惠。

⚠ 它本质上是**时间性优惠**——只改变扣除的**时点分布**，不改变扣除**总额**。
因此必然产生**税会差异**，调整规则见 [[corporate-income-tax-asset-treatment]]。

## Key Points

### 一、一般性加速折旧（普适规定）

- ⚠ **可采用的固定资产仅两类**：
  1. 由于**技术进步，产品更新换代较快**的固定资产
  2. 常年处于**强震动、高腐蚀**状态的固定资产
- **缩短折旧年限法**：⚠ 最低折旧年限**不得低于规定折旧年限的 60%**
- **加速折旧方法**：可采用**双倍余额递减法**或**年数总和法**
- ⚠ 加速折旧方法**一经确定，一般不得变更**

### 二、特殊性加速折旧（2019-01-01 起）

| 适用对象 | 单位价值门槛 | 优惠 |
|---|---|---|
| **全部制造业**新购进的固定资产 | —— | 可**缩短折旧年限**或采取**加速折旧**方法 |
| **全部制造业的小型微利企业**新购进的**研发和生产经营共用**的仪器、设备 | **不超过 100 万元** | **一次性**计入当期成本费用扣除 |
| 同上 | **超过 100 万元** | 可缩短折旧年限或采取加速折旧方法 |
| **所有行业**企业新购进的**专门用于研发**的仪器、设备 | **不超过 100 万元** | **一次性**计入当期成本费用扣除 |
| 同上 | **超过 100 万元** | 可缩短折旧年限或采取加速折旧方法 |
| **所有行业**企业**持有**的固定资产 | **不超过 5000 元** | **一次性**计入当期成本费用扣除 |

- ⚠ 按上述规定**缩短折旧年限**的，最低折旧年限**不得低于《企业所得税法实施条例》第六十条规定
  折旧年限的 60%**
- ⚠ 企业的固定资产**既符合上述优惠条件、又符合其他加速折旧优惠政策条件**的，
  可由企业**选择其中一项**执行，且**一经选择，不得改变**
- 应将购进固定资产的发票、记账凭证等有关凭证凭据（购入已使用过的固定资产，
  应提供**已使用年限的相关说明**）等资料**留存备查**，并应**建立台账**，
  准确核算**税法与会计差异**情况

### 三、一次性税前扣除政策（单位价值 500 万元）

- 自 **2018-01-01 至 2027-12-31**，企业**新购进**的**设备、器具**，
  单位价值**不超过 500 万元**的 → 允许**一次性**计入当期成本费用扣除，**不再分年度**计算折旧
- ⚠ **设备、器具**是指**除房屋、建筑物以外**的固定资产

**「购进」的口径**：

- ⚠ **包括以货币形式购进或自行建造**；以货币形式购进的**包括购进的使用过的固定资产**
  （「**新购进**」的「新」字只是区别于原已购进的固定资产，**不要求全新**）
- **单位价值确定**：以货币形式购进 → 购买价款 + 相关税费 + 直接归属于使该资产达到预定用途
  发生的其他支出；自行建造 → **竣工结算前**发生的支出

**⚠ 购进时点的确认（三条）**：

| 购进方式 | 时点 |
|---|---|
| 以货币形式购进（**非**分期付款／赊销） | 按**发票开具时间** |
| **分期付款或赊销**方式购进 | 按固定资产**到货时间** |
| **自行建造** | 按**竣工结算时间** |

- ⚠ **扣除时点**：固定资产在**投入使用月份的次月所属年度**一次性税前扣除
  ——与折旧「自投入使用月份的**次月**起计算」保持一致
- ⚠ **税务处理可与会计处理不一致**：会计上是否采用一次性扣除方法**不影响**享受该政策，
  **不需要会计上也同时采取**与税收上相同的折旧方法
- ⚠ **可自行选择，但未选择不得变更**：
  - 企业根据自身生产经营核算需要可**自行选择**是否享受；
    **未选择享受的，以后年度不得再变更**
  - ⚠ 该「不得再变更」是**针对单个固定资产**而言；
    **单个固定资产未选择享受，不影响其他固定资产**选择享受
  - 教材提示的选择考量：一次性扣除会**加大亏损**（受弥补期限限制可能无法弥补）、
    **定期减免税期间**往往不会选择
- **留存备查资料**：固定资产购进时点的资料（发票、到货时间说明、竣工决算情况说明等）、
  固定资产**记账凭证**、核算有关资产**税务处理与会计处理差异的台账**
- ⚠ 购进单位价值**超过 500 万元**的固定资产，仍按普适性规定正常折旧或加速折旧

### 四、海南自由贸易港的特殊规定

自 **2020-01-01 至 2027-12-31**，对在海南自由贸易港设立的企业，
新购置（含自建、自行开发）**固定资产或无形资产**：
单位价值**不超过 500 万元（含）** → 允许**一次性**计入当期成本费用扣除，不再分年度计算折旧和摊销；
**超过 500 万元** → 可缩短折旧、摊销年限或采取加速折旧、摊销的方法。
⚠ 所称**固定资产是指除房屋、建筑物以外**的固定资产。

> ⚠ **审核视角**（**计入制造费用的折旧额异常变化的追查路径**）见 [[cit-audit-manufacturing-cost-and-carryover]]。

> ⚠ **审核视角**（**折旧的审核方法**——五条会计—税法差异的纳税调整、五类常见错弊（未按范围／未按规定选用方法／未按规定确定年限／方法与年限随意变动／净残值随意确定）、两条查账线索）见 [[cit-audit-fixed-asset-depreciation]]。
