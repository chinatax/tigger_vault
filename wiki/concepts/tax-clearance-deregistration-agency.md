# 清税注销代办服务

## Definition

⚠ **本页是《涉税服务实务》第八章《其他税务事项代办服务》第七节「其他税务事项代办服务」之
「「一、清税注销代办服务」」**（书页 452 上–454 中，txt 457 上–459 中）。

> ⚠ **教材原句（服务内容）**：「**清税注销代办业务**，是指税务师事务所接受委托人委托，**在其权限内，
> 以委托人的名义**代为办理**「清税注销登记、清税证明」**等涉税事项代办的服务活动」。

⚠ **边界**：**国际税收代办**见 [[international-tax-affairs-agency-service]]；
**其他代办**见 [[other-tax-matters-agency-service]]（**同批**）。

## Key Points

### 一、基本业务实施程序（**九环节**）

⚠ **「业务承接、业务委派、业务计划、归集资料、「代办准备」、实施办理、反馈结果、业务成果、
业务记录」**——⚠ **注意：本节的第三环节是「代办准备」而非批 1 各节的「专业判断」，且未含
「业务档案管理」**（**照录原文**）。

### 二、⚠⚠ 「资料收集」（**十类，教材逐项列出**）

> ⚠ **教材明示**：**「应当告知委托人，其应当对提供材料的真实性和合法性负责」**；
> **「取得的各项资料为复印件的，均需委托人注明『与原件一致』并签章」**。

| # | ⚠ 资料（**教材原句**） |
|---|---|
| **①** | **「委托人「未启用统一社会信用代码」的，应当取得税务登记证及其副本和其他税务证件」** |
| **②** | **委托人结清应纳税款、多退（免）税款、滞纳金和罚款的相关财务、税务资料** |
| **③** | ⚠ **「委托人涉及企业所得税税种的，应当取得「清算方案、清算报告、《中华人民共和国企业清算所得税申报表》及其附表」」**；**「涉及代扣代缴个人所得税的，应当取得「剩余资产分配方案、剩余财产计算和分配明细表以及申报个人股东剩余财产分配所得的《个人所得税扣缴申报表》」」**；**「已经委托中介机构依法出具税款清算鉴证的，应当取得法定资质中介机构出具的专项报告」等** |
| **④** | **「委托人「领用过发票」的，应当取得「未验旧、未使用的发票」」** |
| **⑤** | **「委托人使用增值税防伪税控设备的，应当取得其「增值税防伪税控设备」」** |
| **⑥** | **清税注销登记代办授权书** |
| **⑦** | **其他按规定应缴回的设备** |
| **⑧** | ⚠ **注销的「依据文件」**：「**被上级主管、董事会决议注销的** → 上级主管部门批复文件或董事会决议复印件；**被市场监督管理机关吊销营业执照的** → 吊销工商营业执照决定复印件；**其他相关部门决议注销文件**」 |
| **⑨** | 委托人主管税务机关要求提供的其他相关资料 |

### 三、⚠ 「关注事项」（**七项**）

**「应当对收集的相关资料进行「专业判断和数据确认」，重点关注下列事项」**：
**① 清税注销资料、设备等是否完整、充分、适当并经委托人确认无误；② 资料信息填写内容是否完整、
数据是否准确，是否符合逻辑关系；③ ⚠ 委托人是否结清「应纳税款、多退（免）税款、滞纳金和罚款、
代扣代缴个人所得税」；④ 委托人「纳税信用等级情况」以及发票管理、税控设备及其使用情况等相关信息；
⑤ 各项申报表、报告表、登记表等资料是否在指定签章位置签章；⑥ 与委托人的沟通记录是否完整、
是否履行了签字确认手续；⑦ 其他应关注的事项**。

⚠ **资料存疑时的处置**：**「应当告知委托人更正、补充或者给予适当的责任提醒。必要时，
可以要求委托人提供「承诺书或者相关说明」」**（⚠ **注意：此处只作「承诺书或者相关说明」，
而批 1 各节作「管理层声明、承诺书或者相关说明」——照录原文**）。

### 四、⚠⚠ 「计划实施」（**十项关注 + 三份「进一步资料」**）

> ⚠ **教材原句**：**「在委托范围内实施清税注销代办业务时，应当关注以下事项」**：

| # | ⚠ 关注事项（**教材原句**） |
|---|---|
| **①** | **清税注销相关政策法规和办税流程，「按委托人类型及税款征收方式、持有的税务证件、涉税事宜办理情况、发票领用情况、实名办税情况等，选择不同的表单和办理程序」** |
| **②** | **委托人提供资料的准确性和完整性** |
| **③** | ⚠ **「委托人应当「结清税款、多退（免）税款、滞纳金、罚款，缴销发票、注销增值税税控系统专用设备并缴回相关设备」」** |
| **④** | ⚠ **「委托人「清算所得」应当依法缴纳和代扣代缴企业所得税、个人所得税」** |
| **⑤** | ⚠⚠ **「委托人「未办理土地增值税清算手续」的，应进行土地增值税清算」** |
| **⑥** | **「委托人是「出口企业」的，应结清「出口退（免）税款」」** |
| **⑦** | **「委托人已在税务机关进行「社会保险费信息登记」的，应办理「注销保险费缴费信息登记」」** |
| **⑧** | ⚠ **「委托人处于「非正常状态」的，「须先解除非正常状态，补办申报纳税手续」」** |
| **⑨** | ⚠ **「委托人处于税务机关实施「特别纳税调查调整期间」的，关注税务机关「调查结案情况」」** |
| **⑩** | 其他应当关注事项 |

⚠⚠ **「进一步资料」（三项）**：**「需要对委托人提供的资料归整核对，整理编制进一步资料，
包括：① 与清税注销登记事项有关的「申报表或申请表」；② 与清税注销登记事项有关的「情况说明」；
③ 其他有关的进一步资料」**。

⚠ **三处程序性要求**：
**① 「应当「现场和委托人访谈，调查情况」，对需明确的问题和尚缺资料，与委托人进行沟通，
提出解决意见，确定问题解决及资料提供的时间安排和联系方式」；
② 「应当按照税务机关「资料报送要求、基本流程、基本规范」，在约定的时间内，备齐代办所需资料
及「委托书、代办人身份证明」」；
③ 「应当提示委托人……如遇税务机关提出需要约见其法定代表人或者其他人员时，「委托人应当配合」」**。

### 五、反馈结果与业务记录

- ⚠ **反馈结果**：**「办结清税注销代办事项后取得的代办结果应当及时转交给委托人。转交时，
  需要填写「确认书」，由税务师事务所与委托人双方经办人签字」**（⚠ **注意：此处是「确认书」，
  而批 1 各节是「代办结果交接表」——照录原文**）；
  **「应当提示纳税人对所有必报资料按照《会计档案管理办法》进行归档管理，对备查资料进行装订和
  妥善保管」**；
- ⚠ **业务记录**：**「应当制定业务工作底稿管理制度；可以根据自身情况，制定清税注销代办业务工作底稿」**；
  **「应当按期对执行清税注销代办业务取得的资料和记录，按照规定进行整理归档」**。

> ⚠⚠ **本页要点（清税注销的「前置条件清单」是本目最有价值的一段）**：
> **关注事项③～⑨ 构成一张「注销前必须结清/解除的事项清单」**：
> **结清税款·多退（免）税·滞纳金·罚款 → 缴销发票 → 注销并缴回税控设备 →
> 清算所得的两税（企业 + 代扣个人）→ 土地增值税清算 →
> 出口退（免）税结清 → 社保费缴费信息注销 → 解除非正常状态 → 特别纳税调查结案**——
> ⚠ **这九项是把「清税注销」从「跑一次手续」变成「一次全面收口」的关键**。
