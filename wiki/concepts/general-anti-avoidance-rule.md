# 一般反避税管理

## Definition

一般反避税管理（General Anti-avoidance Rule, GAAR）：税务机关对企业实施的
**不具有合理商业目的而获取税收利益的避税安排**，依《企业所得税法》**第四十七条**
实施特别纳税调整的制度（《一般反避税管理办法（试行）》，国家税务总局令第 32 号，
**自 2015-02-01 起施行**）。

⚠ **该原则在现行法中是「跨税种」的**：⚠ **《增值税法》也设有同型条款**——
纳税人实施**不具有合理商业目的的安排**而**减少、免除、推迟缴纳增值税税款**，
或者**提前退税、多退税款**的，税务机关可以依照《税收征管法》和有关行政法规的规定**予以调整**。
⚠ **增值税侧的表述比企业所得税侧多出两项**：**「推迟缴纳」**与**「提前退税、多退税款」**
（企业所得税侧的经典表述是「减少或免除」）。

⚠ 它是反避税体系中的**兜底条款**——⚠ **凡属于转让定价、成本分摊、受控外国企业、资本弱化等
其他特别纳税调整范围的，或者属于「受益所有人」、利益限制等税收协定执行范围的，
应当首先适用其他规定**，只有落在这些范围之外的安排才适用一般反避税。

## Key Points

### 〇、增值税侧的同型条款（2026-09-23 补入）

- **规范表述**：纳税人实施**不具有合理商业目的的安排**而**减少、免除、推迟缴纳增值税税款**，
  或者**提前退税、多退税款**的，税务机关可以依照《税收征管法》和有关行政法规的规定**予以调整**。
- ⚠ **两项增值税独有的效果情形**：**①「推迟缴纳」**（企业所得税侧不列此项）；
  **②「提前退税、多退税款」**（针对**出口退税与留抵退税**场景）。
  ⚠ 后者尤其重要——**骗税与「不合理商业目的的提前退税」是两种不同的处理路径**：
  前者走骗税条款（见 [[export-tax-refund-administration]] 的「停止出口退税权」），
  后者走**一般反避税的调整**。
- ⚠ **增值税侧教材只给了这一句**（未如企业所得税侧展开「两个特征」与调整程序）——
  ⚠ 程序性内容**本页不臆造**，以《税收征管法》和相关行政法规为准。

### 一、⚠ 避税安排的两个特征

1. ⚠ 以**获取税收利益为唯一目的或者主要目的**
2. ⚠ 以**形式符合税法规定、但与其经济实质不符**的方式获取税收利益

- ⚠ **「税收利益」**指**减少、免除或者推迟缴纳企业所得税应纳税额**

### 二、⚠ 处理原则与四种调整方法

- ⚠ **处理原则**：税务机关对企业的避税安排应当以**具有合理商业目的和经济实质的类似安排**
  为基准，按照**实质重于形式**的原则实施特别纳税调整
- ⚠ **四种调整方法**：
  1. 对安排的**全部或者部分交易重新定性**
  2. 在税收上**否定交易方的存在**或者将该交易方与其他交易方**视为同一实体**
  3. 对相关**所得、扣除、税收优惠、境外税收抵免等重新定性或者在交易各方间重新分配**
  4. 其他合理方法

### 三、⚠⚠ 与其他政策的衔接（三条，最易考）

1. ⚠ 企业的安排属于**转让定价、成本分摊、受控外国企业、资本弱化**等其他特别纳税调整范围的
   → **应当首先适用其他特别纳税调整相关规定**
2. ⚠ 企业的安排属于「**受益所有人**」、**利益限制**等税收协定执行范围的
   → **应当首先适用税收协定执行的相关规定**
3. ⚠⚠ **不适用一般反避税规定的两类**：
   - **与跨境交易或者支付无关**的安排
   - **涉嫌逃避缴纳税款、逃避追缴欠税、骗税、抗税以及虚开发票等税收违法行为**

### 四、立案程序

- ⚠ 各级税务机关应当结合工作实际，应用各种数据资源——
  如**企业所得税汇算清缴、纳税评估、同期资料管理、对外支付税务管理、股权转让交易管理、
  税收协定执行**等——**及时发现一般反避税案源**
- ⚠⚠ **立案的两级报批**：主管税务机关发现企业存在避税嫌疑的，
  **层报省、自治区、直辖市和计划单列市（「省」）税务机关复核同意后，报税务总局申请立案**
  - ⚠ 省税务机关应当将税务总局形成的**立案申请审核意见转发**主管税务机关
  - ⚠ **税务总局同意立案**的，主管税务机关**实施**一般反避税调查

### 五、⚠ 调查

**（一）可启动一般反避税调查的五种避税安排**

1. **滥用税收优惠**
2. **滥用税收协定**
3. **滥用公司组织形式**
4. **利用避税港避税**
5. 其他不具有合理商业目的的安排

**（二）⚠ 企业的举证义务（60 日 + 延期不超过 30 日）**

- ⚠ 主管税务机关实施调查时应当向被调查企业送达《**税务检查通知书**》
- ⚠ 被调查企业认为其安排**不属于避税安排**的，应当自**收到《税务检查通知书》之日起 60 日内**
  提供下列**七类资料**：
  1. 安排的**背景资料**
  2. 安排的**商业目的**等说明文件
  3. 安排的**内部决策和管理资料**（如**董事会决议、备忘录、电子邮件**等）
  4. 安排涉及的**详细交易资料**（如**合同、补充协议、收付款凭证**等）
  5. 与**其他交易方的沟通信息**
  6. 可以证明其安排**不属于避税安排**的其他资料
  7. 税务机关认为有必要提供的其他资料
- ⚠ **延期**：企业因特殊情况不能按期提供的，可提交**书面延期申请**，经批准可以延期，
  ⚠ **但最长不得超过 30 日**
  - ⚠ **回复时限**：主管税务机关应当自**收到企业延期申请之日起 15 日内**书面回复；
    ⚠ **逾期未回复的，视同税务机关同意**企业的延期申请
- ⚠⚠ **拒绝提供资料的后果**：企业拒绝提供资料的 →
  主管税务机关可以按照《税收征管法》**第三十五条**的规定**进行核定**

**（三）对筹划方与关联方的调查**

- ⚠ 主管税务机关实施调查时，**可以要求为企业筹划安排的单位或者个人（「筹划方」）
  提供有关资料及证明材料**
- ⚠ 涉及向**筹划方、关联方以及与关联业务调查有关的其他企业**调查取证的，
  主管税务机关应当**送达《税务事项通知书》**
- ⚠ **核实方式**：可以采用**现场调查、发函协查和查阅公开信息**等方式核实；
  ⚠ 需取得**境外有关资料**的，可按有关规定**启动税收情报交换程序**，
  或者**通过我驻外机构调查收集**有关信息；
  ⚠ 涉及境外关联方相关资料的，也可以要求企业提供**公证机构的证明**

### 六、争议处理

- ⚠ 被调查企业对主管税务机关作出的**一般反避税调整决定不服**的 →
  可以按照有关法律法规的规定**申请法律救济**
- ⚠⚠ **导致国内双重征税**的 → 由**税务总局统一组织协调解决**
- ⚠⚠ **导致国际双重征税或者不符合税收协定规定征税**的 →
  可以按照税收协定及其相关规定**申请启动相互协商程序**（见 [[special-tax-adjustment]]）

### 七、与相关概念的衔接

- **特别纳税调整**的完整体系（转让定价、受控外国企业、资本弱化、成本分摊、
  预约定价安排、相互协商）见 [[special-tax-adjustment]]
- **间接转让中国应税财产**的立案调查按本页规定执行，见
  [[indirect-transfer-of-china-taxable-property]]
- **受益所有人**的判定（属于协定执行范围，优先适用）见 [[beneficial-owner-determination]]
- **国际避税的手段与避税地类型**见 [[international-tax-enforcement-cooperation]] 与
  [[international-taxation]]
