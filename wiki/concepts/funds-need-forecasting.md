# 资金需要量预测

## Definition

资金需要量预测（Funds Need Forecasting）：在销售预测的基础上，估计企业未来一定期间为完成经营目标所需资金规模的方法。

它服务于筹资决策的起点——先算出「要多少钱」，才谈得上「用哪种方式筹」。实务上有**因素分析法**、**销售百分比法**和**高低点法**三种基本方法，三者的输入变量与适用场景不同，**不能互相替代**。

## Key Points

- **因素分析法**（第 29、52 题）：
  - 公式：资金需要量 =（**基期资金平均占用额** − **不合理资金占用额**）×（1 + 预测期销售增长率）÷（1 + 预测期资金周转速度增长率）
  - 需要考虑的因素：基期资金平均占用额、不合理资金占用额、预测期销售增长率、预测期资金周转速度增长率
  - ⚠ **不包括**最高收入期资金占用量、最低收入期资金占用量、利润留存率
  - ⚠ 资金周转速度增长率在**分母**——周转加速意味着所需资金**减少**
- **销售百分比法**（第 31、35、36、47 题，最高频）：
  - 前提：经营性资产项目与经营性负债项目随销售额变动而呈**正比例**变动，并保持稳定的百分比关系
  - **敏感性资产**（经营性资产）：**库存现金、应收账款、存货**
  - **敏感性负债**（经营性负债）：**应付票据、应付账款**
  - ⚠ **固定资产不属于敏感性资产**——在有足够生产能力、无须追加固定资产投资时，它不随销售额变动
  - ⚠ **短期借款、短期融资券、长期负债等筹资性负债不属于敏感性负债**（只有经营性负债才是）
  - 资金增长额 = 基期销售收入 × 销售增长率 ×（敏感性资产占销售百分比 − 敏感性负债占销售百分比）
  - 外部融资需求量 = 资金增长额 − 预计销售收入 × 销售净利润率 × 利润留存率
  - 销售净利润率与股利支付率（或利润留存率）保持不变是常用假设
- **高低点法**（第 37、42 题）：
  - 模型：资金需要量 **y = a + bx**（a 为不变资金，b 为单位产销量所需变动资金，x 为销售收入）
  - **b** =（最高期资金占用量 − 最低期资金占用量）÷（最高期销售收入 − 最低期销售收入）
  - **a** = 最高期资金占用量 − b × 最高期销售收入
  - ⚠ 注意高低点的选取以**销售收入**为准，不是以资金占用量为准
