# 金融负债与交易性金融负债

## Definition

金融负债与交易性金融负债（Financial Liabilities）：以**交付现金或其他金融资产**为结算方式的负债，与「预计负债、递延收益」等**非金融负债**相对。

两个常考的反直觉点：**预收账款不是金融负债**（结算的是商品而非现金），以及**所有金融负债均不得重分类**。

## Key Points

- **金融负债与非金融负债的边界**（第 348 题）：
  - ✅ **属于**金融负债：短期借款、应付票据、**应付账款**、应付债券、交易性金融负债
  - ⚠ **不属于**：**预收账款**（结算的是商品或服务，不是现金或其他金融资产）
  - **非金融负债**：**预计负债、专项应付款、递延收益、递延所得税负债**
  - 初始确认时应按**公允价值**计量
  - ⚠ **所有金融负债均不得进行重分类**（反直觉但为明规）
- **交易性金融负债的核算**（第 340 题）：
  - 发行时发生的**交易费用** → 借记「**投资收益**」
  - ⚠ 因**企业自身信用风险**变动导致该金融负债公允价值**下降** →
    借记「**交易性金融负债**」、贷记「**其他综合收益**」
    （即自身信用风险的影响**不进损益**）
  - 资产负债表日**单独确认票面利息** → 借记「投资收益」「财务费用」等、
    贷记「交易性金融负债——**应计利息**」
  - **处置**时，其账面余额与实际支付金额的差额 → 计入「**投资收益**」
- **流动负债科目的归属辨析**：
  - **应付票据到期无力支付**（第 336 题）：
    - **银行承兑汇票** → 转入「**短期借款**」
    - **商业承兑汇票** → 转入「**应付账款**」
  - **其他应付款科目核算**（第 349 题）：
    - ✅ 按租赁准则**简化处理的短期租入固定资产**应支付的租金
    - ✅ 代扣的应由**职工个人负担的养老保险费**
    - ✅ **收取的包装物押金**
    - ⚠ 收到的电费发票上载明的应付电费 → 「**应付账款**」
    - ⚠ 交易性金融负债应付的利息 → 单独确认时记「交易性金融负债——**应计利息**」，
      不单独确认时通过「交易性金融负债——公允价值变动」汇总核算
  - **无法支付的应付款项**（债权单位撤销）→ 计入「**营业外收入**」
    （⚠ **不是**「其他收益」）
  - **拟分配的现金股利**（第 336 题）：
    - **董事会或类似机构**通过利润分配方案中**拟分配**的现金股利或利润 → ⚠ **不作账务处理**，
      仅在报表**附注中披露**
    - 经**股东会或类似机构审议批准**后 → 借「利润分配」、贷「**应付股利**」
