# 车船税

## Definition

车船税（Vehicle and Vessel Tax）：对依法应在车船登记管理部门登记的车辆、船舶，
按**定额幅度税率**课征的财产税。⚠ **按年申报，分月计算，一次性缴纳**。

其记忆骨架是**三类计税单位**——**载人按"每辆"、载货按"整备质量每吨"、船舶按"净吨位每吨"**
（游艇例外，按艇身长度每米）。

## Key Points

### 一、计税单位（三类）

| 类别 | 具体车船 | 计税单位 |
|---|---|---|
| **载人** | 摩托车、乘用车、客车 | **每辆** |
| **载货** | 货车（含半挂牵引车、三轮汽车、低速载货汽车）、挂车、专用作业车、轮式专用机械车、客货两用车 | **整备质量每吨** |
| **船舶** | 机动船舶、拖船、非机动驳船 | **净吨位每吨** |
| **游艇** | 游艇 | **艇身长度每米** |

### 二、征税范围

- **属于**：依法应登记的机动车辆与船舶；**半挂牵引车**；**轮式专用机械车**；
  **混凝土泵车、清障车、洒水车、扫路车、高空作业车**（**专用作业车**）；
  **运营货车牵引的挂车**；排量**大于 50 毫升**的两轮/三轮摩托车；
  **长度 ≥5 米**的游艇
- ⚠ **不属于**：
  - **纯电动乘用车**、**电动摩托车**、**电动自行车**
  - **拖拉机**、**地铁列车**
  - **船舶上装备的救生艇筏**和**长度小于 5 米**的艇筏
  - ⚠ **境内单位和个人租入外国籍船舶**的
  - ⚠ **境内单位出租到境外的船舶**（⚠ 但**捕捞、养殖渔船**免征）
- ⚠ **专用作业车**与**专用汽车**的区分：以**载运人员或货物**为主要目的的专用汽车
  （如**救护车**）**不属于**专用作业车。

### 三、税额的特殊计算规则

- ⚠ **挂车**按照**货车税额的 50%** 计算
- ⚠ **拖船、非机动驳船**分别按照**机动船舶税额的 50%** 计算
- ⚠ **拖船**按发动机功率**每 1 千瓦折合净吨位 0.67 吨**计算
- ⚠ **无法提供净吨位证明文件的游艇**，按发动机功率**每千瓦折合净吨位 0.05 吨**计算
- **购置的新车船**：⚠ 购置当年的应纳税额**自纳税义务发生的当月起按月计算**
- **已完税车船被盗抢、报废、灭失**：可凭证明申请退还**自被盗抢、报废、灭失月份起
  至该纳税年度终了期间**的税款；⚠ **失而复得**的，从公安机关出具证明的**当月起**计算缴纳
- **因质量问题退货**：可申请退还**自退货月份起至该纳税年度终了期间**的税款
- ⚠ **转让过户**：已缴纳车船税的车船在**同一纳税年度内**办理转让过户的，
  **不另纳税，也不退税**

### 四、免税与减半

- **免征**：
  - **纯电动商用车、插电式（含增程式）混合动力汽车、燃料电池商用车**
  - **军队、武装警察部队专用**的车船
  - **捕捞、养殖渔船**
  - **警用船舶**
  - **外国驻华使领馆、国际组织驻华代表机构**及其有关人员的车船
  - **经批准临时入境**的外国车船；香港特别行政区、澳门特别行政区、台湾地区的车船
  - ⚠ **应纳税额在人民币 50 元以下**的船舶
  - ⚠ **吨税执照期满后 24 小时内不上下客货**的船舶
  - **非机动船舶（不包括非机动驳船）**
  - 依法不需要在车船登记管理部门登记的**机场、港口内部**行驶或作业车船
    （自《车船税法》实施之日起 **5 年内**免征）
- **减半征收**：⚠ 符合规定标准的**节能乘用车、节能商用车**；
  ⚠ **排量在 1.6 升以下的燃料乘用车**

### 五、征收管理

- ⚠ **纳税义务发生时间**：取得车船**所有权或者管理权的当月**，
  即**购买车船的发票或者其他证明文件所载日期的当月**
- **纳税地点**：办理登记的，为**车船的登记地**；
  ⚠ **不需要办理登记**的车船，为**车船所在地**
- **纳税期限**：**按年申报，分月计算，一次性缴纳**；
  ⚠ 具体申报纳税期限由**省、自治区、直辖市人民政府**规定
- **车辆具体适用税额**由**省、自治区、直辖市人民政府**在《车船税税目税额表》规定的
  税额幅度内确定
- 已缴纳车船税的车船**在同一纳税年度内办理转让过户**的，不另纳税，也不退税
- **扣缴义务人**（保险机构）代收代缴的，纳税地点为**扣缴义务人所在地**

### 教材补充（CTA《税法（二）》教材 2026 版第六章）

**（一）⚠ 征税范围与两处例外**

- ⚠ 车船税的征税范围指在**中华人民共和国境内**属于《车船税法》所附《车船税税目税额表》规定的
  **车辆、船舶**
- ⚠ 车辆、船舶指：①**依法应当在车船登记管理部门登记**的机动车辆和船舶；
  ②**依法不需要在车船登记管理部门登记**的、在**单位内部场所行驶或者作业**的机动车辆和船舶
- ⚠⚠ **两处例外**：**境内单位和个人租入外国籍船舶的，不征收**车船税；
  **境内单位和个人将船舶出租到境外的，应依法征收**车船税
- ⚠ **纳税人**为车船的所有人**或者管理人**；
  ⚠ **管理人**指对车船具有**管理权或者使用权**、**不具有所有权**的单位和个人

**（二）⚠⚠ 税目税额表（定额幅度税率）**

⚠ 税额确定总的原则：**排气量低的车辆税负轻于排气量高的**；**小吨位船舶税负轻于大船舶**。

| 税目 | 计税单位 | 年基准税额 |
|---|---|---|
| ⚠ **乘用车**（按发动机汽缸容量分 **7 档**） | 每辆 | ⚠ **1.0 升（含）以下 60–360 元**；**1.0–1.6 升（含）300–540 元**；**1.6–2.0 升（含）360–660 元**；**2.0–2.5 升（含）660–1200 元**；**2.5–3.0 升（含）1200–2400 元**；**3.0–4.0 升（含）2400–3600 元**；**4.0 升以上 3600–5400 元** |
| ⚠ **客车**（核定载客 **9 人（含）以下**） | 每辆 | **480–1440 元** |
| ⚠ **商用车·客车**（核定载客 **9 人以上，包括电车**） | 每辆 | **480–1440 元** ※ 与上一行同为「每辆」档 |
| ⚠ **商用车·货车**（包括**半挂牵引车、三轮汽车和低速载货汽车**等） | **整备质量每吨** | **16–120 元** |
| ⚠ **挂车** | 整备质量每吨 | ⚠ **按照货车税额的 50% 计算** |
| **专用作业车** | 整备质量每吨 | **16–120 元** |
| **其他车辆**（⚠ **不包括拖拉机**） | 整备质量每吨 | **16–120 元** |
| **轮式专用机械车** | 整备质量每吨 | **36–180 元** |
| **摩托车** | 每辆 | **36–180 元** |
| ⚠ **机动船舶** | **净吨位每吨** | **3–6 元** |
| ⚠ **游艇** | **艇身长度每米** | **600–2000 元** |

- ⚠ **拖船、非机动驳船**分别**按照机动船舶税额的 50%** 计算
- ⚠ **车辆的具体适用税额由省级人民政府**依照《车船税税目税额表》规定的税额幅度和国务院的规定确定；
  ⚠ **船舶的具体适用税额由国务院**在税额幅度内确定
- ⚠ **省级人民政府确定车辆具体适用税额时应遵循的两个原则**：
  ①**乘用车应当依排气量从小到大递增税额**；
  ②**客车应当依照大型（核定载客人数大于或者等于 20 人）、
  中型（核定载客人数大于 9 人且小于 20 人）分别确定**适用税额

**⚠ 机动船舶的四档具体税额**：①**净吨位不超过 200 吨**的 → 每吨 **3 元**；
②**超过 200 吨但不超过 2000 吨**的 → 每吨 **4 元**；③**超过 2000 吨但不超过 10000 吨**的 →
每吨 **5 元**；④**超过 10000 吨**的 → 每吨 **6 元**
- ⚠ **拖船按照发动机功率每 1 千瓦折合净吨位 0.67 吨**计算征收

**⚠ 游艇的五档具体税额**：①**不超过 10 米** → 每米 **600 元**；②**超过 10 米但不超过 18 米** →
每米 **900 元**；③**超过 18 米但不超过 30 米** → 每米 **1300 元**；④**超过 30 米** → 每米 **2000 元**；
⑤**辅助动力帆艇** → 每米 **600 元**
- ⚠ **游艇艇身长度是指游艇的总长**

**（三）⚠ 税目含义中的五处易错**

1. ⚠ **乘用车**指在设计和技术特性上主要用于**载运乘客及随身行李**，
   核定载客人数**包括驾驶员在内不超过 9 人**的汽车
2. ⚠ **商用车**指**除乘用车外**，用于载运乘客、货物的汽车，划分为**客车和货车**
   - ⚠ **客货两用车**（又称**多用途货车**）指在设计和结构上主要用于**载运货物**，
     但在驾驶员座椅后**带有固定或折叠式座椅、可运载 3 人以上乘客**的货车
     → ⚠ **按货车的计税单位和年基准税额**计征
3. ⚠ **挂车**指就其设计和技术特性需由汽车或拖拉机牵引才能正常使用的**一种无动力的道路车辆**
   → ⚠ **按照货车税额的 50%** 计算
4. ⚠ **专用作业车**指在设计和技术特性上用于特殊工作、并装置有专用设备或器具的汽车
   （如**汽车起重机、消防车、混凝土泵车、清障车、高空作业车、洒水车、扫路车**等）
   - ⚠⚠ **以载运人员或货物为主要目的的专用汽车，如救护车，不属于专用作业车**
5. ⚠ **轮式专用机械车**指有特殊结构和专门功能，装有**橡胶车轮可以自行行驶**、
   最高设计车速**大于每小时 20 公里**的轮式工程机械车
- ⚠ **摩托车**指无论采用何种驱动方式，**最高设计车速大于每小时 50 公里**，
  或者使用内燃机、其**排量大于 50 毫升**的两轮或三轮车辆
- ⚠ **船舶**指各类机动、非机动船舶以及其他水上移动装置，
  ⚠ **但船舶上装备的救生艇筏和长度小于 5 米的艇筏除外**
  - ⚠ **游艇**指具备**内置机械推进动力装置**，长度**在 90 米以下**，
    主要用于**游览观光、休闲娱乐、水上体育运动**等活动，
    并应当具有**船舶检验证书和适航证书**的船舶

**（四）⚠ 计税单位的数据来源与尾数处理**

- ⚠ **排气量、整备质量、核定载客人数、净吨位、千瓦、艇身长度**，
  以**车船登记管理部门核发的车船登记证书或者行驶证所载数据**为准
- ⚠⚠ **有尾数的一律按照含尾数的计税单位据实计算**应纳税额；
  ⚠ **计算得出的应纳税额小数点后超过两位的可四舍五入保留两位小数**
- ⚠ **乘用车**以登记证书或行驶证所载的**排气量毫升数**确定税额区间
- ⚠ **依法不需要办理登记、依法应当登记而未办理登记或者不能提供**登记证书、行驶证的 →
  以**车船出厂合格证明或者进口凭证**相应项目标注的技术参数、数据为准；
  ⚠ **不能提供**出厂合格证明或进口凭证的 → 由**主管税务机关参照国家相关标准核定**，
  **没有国家相关标准的参照同类车船核定**

**（五）⚠ 应纳税额的计算与五种退税/不退情形**

- ⚠ **基本公式**：**应纳税额 =（年应纳税额 ÷ 12）× 应纳税月份数**
- ⚠ **纳税义务发生时间** = **取得车船所有权或者管理权的当月**，
  即**购买车船的发票或者其他证明文件所载日期的当月**
  - ⚠ **国内购买的机动车** → 以《**机动车销售统一发票**》所载日期为准
  - ⚠ **进口机动车** → 以《**海关关税专用缴款书**》所载日期为准
  - ⚠ **购买的船舶** → 以**购买船舶的发票或其他证明文件所载日期的当月**为准

**⚠ 五种情形**：

| 情形 | 处理 |
|---|---|
| ⚠ **被盗抢、报废、灭失** | 可凭**有关管理机关出具的证明和完税证明**，向**纳税所在地**主管税务机关申请退还**自被盗抢、报废、灭失月份起至该纳税年度终了**期间的税款 |
| ⚠ **已办理退税的被盗抢车船失而复得** | 应当从**公安机关出具相关证明的当月起**计算缴纳 |
| ⚠ **因质量原因被退回**生产企业或经销商 | 可申请退还**自退货月份起至该纳税年度终了**期间的税款；⚠ **退货月份以退货发票所载日期的当月为准** |
| ⚠ **在同一纳税年度内办理转让过户** | ⚠ **不另纳税，也不退税** |
| ⚠ **购买「交强险」时由扣缴义务人代收代缴** | 凭**注明已收税款信息的交强险保险单**，车辆登记地主管税务机关**不再征收**该纳税年度车船税；⚠ **再次征收的应予退还** |

**（六）⚠ 两条代收代缴路径**

**1. 保险机构代收代缴（机动车）**：

- ⚠ 从事**交强险**业务的保险机构为**机动车车船税的扣缴义务人**，
  应当在**收取保险费时**依法代收车船税，并出具**代收税款凭证**
- ⚠ **代收凭证**：在交强险**保险单以及保费发票**上注明已收税款的信息
- ⚠ **拒收处理**：**不能提供完税凭证或减免税证明、且拒绝扣缴义务人代收代缴**的纳税人 →
  ⚠ **扣缴义务人不得出具保单、保险标志和保费发票**等，同时**报告**主管税务机关处理
- ⚠ **发票开具**：应在**增值税发票备注栏**中注明代收车船税税款信息，
  具体包括**保险单号、税款所属期（详细至月）、代收车船税金额、滞纳金金额、金额合计**等；
  ⚠ 该增值税发票**可作为纳税人缴纳车船税及滞纳金的会计核算原始凭证**
- ⚠ **欠缴税款滞纳金的起算时间**：从**各省、自治区、直辖市人民政府规定的申报纳税期限
  截止日期的次日起**计算

**2. 海事管理机构代征（船舶）**（国家税务总局、交通运输部公告 2013 年第 1 号，自 2013-02-01 起）：

- ⚠ **代征范围**：在**交通运输部直属海事管理机构**登记的应税船舶，
  其车船税由**船籍港所在地的税务机关委托当地海事管理机构代征**
- ⚠ **代征环节**：海事管理机构在**办理船舶登记手续或受理年度船舶登记信息报告时**代征
- ⚠ **计算方法**：**年应纳税额 = 计税单位 × 年基准税额**；
  ⚠ 购置的新船舶：**应纳税额 = 年应纳税额 × 应纳税月份数 ÷ 12**，
  其中 **应纳税月份数 = 12 − 纳税义务发生时间（取月份）+ 1**
- ⚠ **纳税义务发生时间**为纳税人**取得船舶所有权或管理权的当月**，
  以**购买船舶的发票或其他证明文件所载日期的当月**为准
- ⚠ **减免管理**：对**免税和完税**船舶**不代征**；对**减税**船舶根据减免税证明规定的
  **实际年应纳税额**代征
- ⚠ **欠税追缴**：以前年度未缴的，海事管理机构应**代征欠缴税款并代加收滞纳金**
- ⚠ **纳税地点**：**车船的登记地或者车船税扣缴义务人所在地**；
  ⚠ **依法不需要办理登记**的车船 → **车船的所有人或者管理人所在地**
- ⚠ **申报**：车船税**按年申报，分月计算，一次性缴纳**；
  纳税年度为**公历 1 月 1 日至 12 月 31 日**
