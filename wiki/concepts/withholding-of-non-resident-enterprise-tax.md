# 非居民企业源泉扣缴

## Definition

非居民企业源泉扣缴（Withholding of Non-resident Enterprise Tax）：对**在中国境内未设立机构、场所**，
或者**虽设立机构、场所但取得的所得与其所设机构、场所没有实际联系**的非居民企业，
其来源于中国境内的所得，**由支付人作为扣缴义务人**在**每次支付或到期应支付时**
从支付款项中扣缴企业所得税的制度
（国家税务总局公告 2017 年第 37 号）。

⚠ 与设立机构场所一侧的「自行申报」相对，本类的特点是**「消极所得 + 收入全额 + 源泉扣缴」**。
⚠ 两处最值钱的细节：**应纳税所得额的口径**（股息利息特许权**收入全额**、
财产转让**收入全额减财产净值**）与**含税收入的反算公式**。

## Key Points

### 一、应纳税所得额的三种口径

- ⚠ **股息、红利等权益性投资收益和利息、租金、特许权使用费所得** →
  ⚠ **以收入全额**为应纳税所得额
- ⚠ **转让财产所得** → ⚠ **以收入全额减除财产净值后的余额**为应纳税所得额
- ⚠ **其他所得** → **参照前两项规定的方法**计算
- ⚠ **「收入全额」**指非居民企业向支付人收取的**全部价款和价外费用**
- ⚠ 非居民企业取得上述所得，在计算缴纳企业所得税时，
  应以**不含增值税的收入全额**作为应纳税所得额

**⚠ 股权转让所得的三层口径（高频）**：

- ⚠ 转让财产所得**包含转让股权等权益性投资资产**（「股权」）所得
- **股权转让所得应纳税所得额 = 股权转让收入 − 股权净值**
- ⚠ **股权转让收入**指股权转让人转让股权**所收取的对价**，包括**货币形式和非货币形式**的各种收入
- ⚠⚠ **股权净值 = 取得该股权的计税基础**
  - 计税基础是**股权转让人投资入股时向中国居民企业实际支付的出资成本**，
    或**购买该项股权时向该股权的原转让人实际支付的股权受让成本**
  - ⚠ 股权在持有期间发生**减值或者增值**、按国务院财政税务主管部门规定**可以确认损益**的，
    **股权净值应进行相应调整**
  - ⚠⚠ **不得扣除**被投资企业**未分配利润等股东留存收益**中按该项股权所可能分配的金额
  - ⚠ **多次投资或收购的同项股权被部分转让**的 →
    **从该项股权全部成本中按照转让比例计算**确定被转让股权对应的成本
  - ⚠ **教材例题**：三次投资合计持有 40%（100 + 200 + 400 = **700 万元**），
    转让 30% → 转让比例 = **30% ÷ 40% = 75%** → 对应成本 = **700 × 75% = 525 万元**

### 二、⚠ 外币折算的三种情形

扣缴义务人支付或者到期应支付的款项**以人民币以外的货币支付或计价**的：

| 情形 | 折算汇率 |
|---|---|
| ⚠ **扣缴义务人扣缴**企业所得税的 | 按**扣缴义务发生之日**人民币汇率中间价折算；⚠ **扣缴义务发生之日为相关款项实际支付或者到期应支付之日** |
| ⚠ 取得收入的非居民企业在**主管税务机关责令限期缴纳税款前自行申报**缴纳的 | 按**填开税收缴款书之日前一日**人民币汇率中间价折算 |
| ⚠ 主管税务机关**责令**其限期缴纳的 | 按**主管税务机关作出限期缴税决定之日前一日**人民币汇率中间价折算 |

- ⚠ **财产转让收入或财产净值**以外币计价的：**先按上述三种情形折算**，
  再计算财产转让所得应纳税所得额
- ⚠⚠ **计价货币的确定**：财产净值或财产转让收入的**计价货币按照取得或转让财产时
  实际支付或收取的计价币种确定**
  - ⚠ **原计价币种停止流通并启用新币种**的，按照**新旧货币市场转换比例**转换为新币种后计算
  - ⚠ **教材例题**：第一次出资 **100 万美元**（当时 1:8.6），第二次投资 **50 万欧元**（当时 1:8.9）；
  2022-01-10 以 **2000 万元人民币**转让（当日 1 美元 = 6.6、1 欧元 = 7.2）→
  ⚠ **财产净值 = 100 × 6.6 + 50 × 7.2 = 1020 万元**（⚠ **按转让当日的汇率折算每个币种**）
  → 应纳税所得额 = 2000 − 1020 = **980 万元**

### 三、⚠⚠ 含税收入的反算公式（合同约定由扣缴义务人承担税款时）

- ⚠ 扣缴义务人与非居民企业签订与《企业所得税法》第三条第三款规定的所得有关的业务合同时，
  **凡合同中约定由扣缴义务人实际承担应纳税款的**，
  **应将非居民企业取得的不含税所得换算为含税所得**计算并解缴应扣税款

> **含税收入 − 应扣缴的增值税 − 应扣缴的预提所得税 = 合同金额**
>
> **应扣缴的增值税 = 含税收入 ÷（1 + 增值税适用税率）× 增值税适用税率**
>
> **应扣缴的预提所得税 = 含税收入 ÷（1 + 增值税适用税率）× 预提所得税税率**
>
> ⚠ 整理后：
> **含税收入 = 合同金额 ÷〔1 − 增值税适用税率 ÷（1 + 增值税适用税率）
> − 预提所得税税率 ÷（1 + 增值税适用税率）〕**

- ⚠ **实务提示**：未在我国设立机构、场所的非居民企业，为我国境内单位提供**贷款服务、
  租赁服务、专利特许**，转让我国境内的**除企业股权外的动产或不动产**，
  一般会**要求支付人承担一切税费，合同仅列明税后收入** ——
  接受服务方在扣缴时**需要先将税后收入换算为含税收入**

### 四、扣缴义务发生时间与解缴

- ⚠ 税款由扣缴义务人在**每次支付或到期应支付时**，从支付或到期应支付的款项中扣缴
- ⚠ **解缴时限**：扣缴义务人应当自**扣缴义务发生之日起 7 日内**向
  **扣缴义务人所在地**主管税务机关**申报和解缴**代扣税款
- ⚠ **扣缴义务人所在地主管税务机关为扣缴义务人所得税主管税务机关**

**⚠⚠ 到期应支付而未支付的四种处理**（国家税务总局公告 2011 年第 24 号第一条）：

1. ⚠ 签订与利息、租金、特许权使用费等所得有关的合同或协议，
   **未按约定日期支付**上述所得款项，或者**变更或修改合同延期支付**，
   **但已计入企业当期成本、费用，并在企业所得税年度纳税申报中作税前扣除**的 →
   **应在企业所得税年度纳税申报时**代扣代缴
2. ⚠ 到期未支付的所得款项**不是一次性计入当期成本费用**，
   而是**计入相应资产原价或企业筹办费**，在该类资产**投入使用或开始生产经营后分期摊入**
   成本费用、**分年度**在企业所得税税前扣除的 →
   ⚠ **应在企业计入相关资产的年度纳税申报时就上述所得全额**代扣代缴
3. ⚠ 企业在**合同或协议约定的支付日期之前**支付上述所得款项的 →
   **应在实际支付时**代扣代缴
4. ⚠ **股息、红利等权益性投资收益**的**扣缴义务发生之日为实际支付之日**

**⚠ 分期收款方式下的成本收回顺序**：

- ⚠ 非居民企业采取**分期收款**方式取得应源泉扣缴所得税的**同一项转让财产所得**的，
  其**分期收取的款项可先视为收回以前投资财产的成本**，
  ⚠ **待成本全部收回后，再计算并扣缴**应扣税款
  - ⚠ **教材例题**：成本 **500 万元**，转让价 **1000 万元**，分三期支付 **300 / 400 / 300**：
    ⚠ 第一期 300 万 → **全部视为收回成本**；
    ⚠ 第二期 400 万 → 其中 **200 万为收回剩余成本**，**其余 200 万作为转让收益**计缴；
    ⚠ 第三期 300 万 → **全部作为转让收益**计缴

### 五、⚠ 扣缴义务人未扣缴时的处理链条

- ⚠ 扣缴义务人**未依法扣缴或无法履行**扣缴义务的 →
  ⚠ **取得所得的非居民企业**应当向**所得发生地**主管税务机关**自行申报缴纳**未扣缴税款
- ⚠ 非居民企业未申报的 → 税务机关可**责令限期缴纳**；
  ⚠ **在责令限期缴纳前自行申报缴纳**的，**视为已按期缴纳税款**
- ⚠ **多个所得发生地**的：非居民企业自行申报时**可以选择一地办理**；
  ⚠ 受理申报地主管税务机关应在**受理申报后 5 个工作日内**，
  向扣缴义务人所在地和同一项所得其他发生地主管税务机关发送
  《**非居民企业税务事项联络函**》
- ⚠ **扣缴义务人应扣未扣**的：由**扣缴义务人所在地**主管税务机关责令**补扣**，
  并依法追究扣缴义务人责任；⚠ **需要向纳税人追缴税款的，由所得发生地主管税务机关依法执行**
- ⚠ **追缴措施**：①责令该非居民企业**限期申报缴纳**；
  ②收集查实该非居民企业在境内**其他收入项目及其支付人**的信息，
  并向该其他项目支付人发出《税务事项通知书》，**从其他收入项目款项中依照法定程序追缴**
  欠缴税款及应缴的滞纳金

**⚠⚠ 「已扣未解缴」与「应扣未扣」的界分**：款项**已由扣缴义务人实际支付、
但未在规定期限内解缴**应扣税款，**具有以下情形之一**的，
应作为**「税款已扣但未解缴」**处理：

1. 扣缴义务人**已明确告知收款人已代扣**税款的
2. **已在财务会计处理中单独列示**应扣税款的
3. **已在其纳税申报中单独扣除或开始单独摊销扣除**应扣税款的
4. 其他证据证明已代扣税款的

⚠ **除上述情形外**，应当源泉扣缴的税款**未在规定期限内解缴入库**的，
**均作为「应扣未扣」**税款处理。

### 六、⚠ 所得发生地主管税务机关的确定（四类）

| 所得类型 | 所得发生地 |
|---|---|
| ⚠ **不动产转让所得** | **不动产所在地**税务机关 |
| ⚠ **权益性投资资产转让所得** | **被投资企业**的所得税主管税务机关 |
| ⚠ **股息、红利等权益性投资所得** | **分配所得企业**的所得税主管税务机关 |
| ⚠ **利息所得、租金所得、特许权使用费所得** | **负担、支付所得的单位或个人**的所得税主管税务机关 |

### 七、⚠ 四类特殊所得的税务处理（2011 年第 24 号）

**（一）担保费**

- ⚠ 非居民企业取得来源于中国境内的**担保费**，应按照《企业所得税法》对**利息所得规定的税率**
  计算缴纳企业所得税
- ⚠ **「来源于中国境内的担保费」**指中国境内企业、机构或个人在**借贷、买卖、货物运输、
  加工承揽、租赁、工程承包**等经济活动中，接受非居民企业提供的担保所支付或负担的担保费
  或相同性质的费用
- ⚠⚠ **例外**：我国企业接受贷款时，**由外国金融机构提供担保**，
  对外国金融机构取得的**担保费收入暂不征收预提所得税**
- ⚠ 如果外国企业的担保**与其在我国境内设立的机构、场所有实际联系**的，
  则应**并入机构、场所的营业利润**征收企业所得税

**（二）土地使用权转让所得**

- ⚠ 非居民企业在中国境内**未设立机构、场所**而转让中国境内土地使用权，
  或者虽设立机构、场所但**取得的土地使用权转让所得与其所设机构、场所没有实际联系**的 →
  应以其取得的**土地使用权转让收入总额减除计税基础后的余额**作为应纳税所得额，
  并由扣缴义务人在支付时代扣代缴

**（三）融资租赁**

- ⚠ 在中国境内**未设立机构、场所**的非居民企业，以**融资租赁方式**将设备、物件等
  租给中国境内企业使用，**租赁期满后设备、物件所有权归中国境内企业**
  （包括租赁期满后**作价转让**给中国境内企业）的 →
  ⚠ 应以**租赁费（包括租赁期满后作价转让给中国境内企业的价款）扣除设备、物件价款后的余额**，
  作为**贷款利息所得**计算缴纳企业所得税，由中国境内企业在支付时代扣代缴

**（四）出租不动产租金**

- ⚠ 非居民企业出租位于中国境内的房屋、建筑物等不动产，
  对**未在中国境内设立机构、场所进行日常管理**的 →
  以其取得的**租金收入全额**计算缴纳企业所得税，由中国境内的**承租人在每次支付或
  到期应支付时**代扣代缴
- ⚠⚠ **若非居民企业委派人员在中国境内或者委托中国境内其他单位或个人对不动产进行日常管理**的 →
  **应视为其在中国境内设立机构、场所**，应在税法规定的期限内**自行申报**缴纳企业所得税

### 八、⚠ 国际税收协定与国内税法的关系（两条原则）

- ⚠ **国际税收协定只是规定税收管辖权分配关系**——如营业利润，
  按协定规定**只有构成常设机构才在来源国负有纳税义务**，
  但**具体的损益计算、费用扣除、适用税率，甚至申报期限及罚则**等则**按国内税法规定处理**
- ⚠⚠ **不一致时的两条原则**：
  1. ⚠ **首先是税收协定优先原则** —— 《企业所得税法》**第五十八条**规定，
     中华人民共和国政府同外国政府订立的有关税收的协定与该法有不同规定的，**依照协定的规定办理**
  2. ⚠ **其次是优惠孰优原则** —— 如果**国内税法规定优于**税收协定，
     **一般情况下按国内税法规定执行**。例：我国与某些国家签订的税收协定**股息限制税率高于 10%** 的，
     仍按国内税法规定**减按 10% 的税率**执行
- ⚠ **受益所有人的适用**：计算扣缴非居民企业应纳税额时，
  如果该非居民企业属于我国与其所在国签署的协定规定的「**受益所有人**」，
  则**适用税收协定相关条款规定的税率**；
  ⚠ 如**不属于**受益所有人，**或者**我国与该非居民企业所在国**没有签署税收协定**，
  则适用《企业所得税法》及其实施条例等法律法规规定的税率
  （见 [[beneficial-owner-determination]]）
