# 高新技术企业认定专项鉴证服务

## Definition

⚠ **本页是《涉税服务实务》第六章《涉税鉴证与纳税情况审查服务》第五节「高新技术企业认定专项鉴证服务」**
（书页 378 末–380，txt 383 末–385）。

> ⚠ **教材原句（业务定义）**：「**高新技术企业认定专项鉴证**，是指鉴证人接受委托，依照税收法律法规
> 和相关标准，按照一定的程序和方法，对**被鉴证人的「高新技术产品（服务）收入占比」、
> 「企业研究开发费用占比」数据**的**真实性、合法性**进行鉴定和证明，并出具鉴证报告的活动」。
> ⚠ **其中「真实」是指**「被鉴证人高新技术产品（服务）收入和总收入的所有交易事项客观真实；
> 被鉴证人的研究开发活动客观真实」；⚠ **「合法」是指**「被鉴证人高新技术产品（服务）收入、总收入、
> 研究开发费用的**界定和**相关会计处理符合法律法规的规定」。

⚠ **三方界定**：**被鉴证人**是高新技术企业认定的行为主体；**鉴证人**是受托提供鉴证服务的
涉税专业服务机构及人员；**被鉴证人可以是委托人，也可以是委托人有权指定的第三人**；
⚠ **鉴证事项**是**鉴证人鉴证和证明的高新技术企业认定申报事项**，
**具体是「被鉴证人研究开发费用结构明细表及占比、高新技术产品（服务）收入明细表及占比」**。

⚠ **边界**：
- ⚠ **通用程序**见 [[tax-certification-basic-provisions]]；
- ⚠ **高新技术企业的「税收优惠」侧**见 [[high-tech-enterprise-tax-preference]]——
  ⚠ **本页是「认定专项鉴证」，该页是「税率优惠实体规则」**，**两页并存互指、不合并**；
- ⚠ **研发费用加计扣除鉴证**（**相邻的鉴证业务，口径可对照**）见
  [[rd-expense-super-deduction-certification]]。

## Key Points

### 一、⚠⚠ 业务口径与「定义群」（**本目的概念基础**）

| ⚠ 术语 | ⚠ 定义（**教材原句**） |
|---|---|
| **高新技术产品（服务）收入** | **企业通过研发和相关技术创新活动，取得的「产品（服务）收入」与「技术性收入」的总和**；⚠ **对企业取得上述收入发挥核心支持作用的技术应属于《国家重点支持的高新技术领域》规定的范围**；⚠ **技术性收入包括「技术转让收入、技术服务收入和接受委托研究开发收入」** |
| **总收入** | **收入总额减去不征税收入** |
| **研究开发费用** | **企业用于研究开发活动的费用** |
| **研究开发活动** | ⚠ **为获得「科学与技术（不包括社会科学、艺术或人文学）」新知识，创造性运用科学技术新知识，或实质性改进技术、产品（服务）、工艺而持续进行的「具有明确目标」的活动**——⚠ **「不包括企业对产品（服务）的常规性升级或对某项科研成果直接应用等活动（如直接采用新的材料、装置、产品、服务、工艺或知识等）」** |
| ⚠ **研究开发费用的归集范围（八类）** | **人员人工费用、直接投入费用、折旧费用与长期待摊费用、无形资产摊销费用、设计费用、装备调试费用与试验费用、委托外部研究开发费用、其他费用** |
| **高新技术产品（服务）收入占比** | **高新技术产品（服务）收入 ÷ 同期总收入** |
| ⚠ **研究开发费用占比** | **企业「近 3 个会计年度」（实际经营期不满 3 年的按实际经营时间计算）的研究开发费用总额 ÷ 同期销售收入总额** |

### 二、⚠⚠ 「关注事项」（**三项**）

| # | ⚠ 关注项 | ⚠ 内容（**教材原句要点**） |
|---|---|---|
| **1** | ⚠⚠ **是否符合高新技术企业的「基本条件」（六项）** | **① 是否属于「中国境内居民企业」，是否「成立 1 年以上」；② 是否通过「自主研发、受让、受赠和并购等方式」获得对其主要产品（服务）在技术上发挥核心支持作用的「知识产权的所有权」；③ 对其主要产品（服务）发挥核心支持作用的技术是否属于《国家重点支持的高新技术领域》规定的范围；④ 从事研发和相关技术创新活动的「科技人员占其当年职工总数的比例是否大于等于 10%」；⑤ 「创新能力评价」是否达到相应要求；⑥ 「申请认定前一年内是否发生重大安全、重大质量事故或严重环境违法行为」** |
| **2** | **会计核算是否合法合规** | **高新技术产品（服务）收入统计口径是否合法准确、收入项目是否客观真实、收入金额是否真实准确；「收入总额和不征税收入」是否按照《企业所得税法》及其实施条例的规定计算** |
| **3** | **研发活动与研发费用** | **研发活动是否客观真实、合理合法；是否按要求设立「研究开发费用辅助核算账目」、研发支出是否建立专门的内控制度；研发支出是否客观真实；研发费用「归集范围」是否合理合法、核算是否合法准确** |

> ⚠⚠ **与「研发费用加计扣除鉴证」的关键差别（本页要点）**：
> **加计扣除鉴证的第一关是「六类负面清单行业」**（**准入判断**）；
> ⚠ **高新技术企业认定鉴证的第一关是「六项基本条件」**（**含成立年限、知识产权所有权、
> 科技人员占比 ≥10%、创新能力评价**）——⚠ **两个鉴证业务的「准入轴」不同，不可互套**。

### 三、⚠ 鉴证证据（**五类**）

⚠ **取证方式**：**① 直接从委托人／被鉴证人提供的鉴证材料中取证**（**例如营业执照复印件、
知识产权证书、科研项目立项证明、科技成果转化材料、高新技术产品（服务）的关键技术和技术指标的具体说明、
财务会计报告、研发费用辅助账等**）；**② 采取审阅、查阅、检查和盘点、询问或函证、记录等方法**。

⚠⚠ **主要包括以下证据（五项）**：

| # | ⚠ 证据（**教材原句**） |
|---|---|
| **1** | **高新技术产品（服务）收入「会计核算资料」**——**包括但不限于「相关凭证、账簿、收款凭证」；高新技术产品（服务）收入相关的「交易合同」** |
| **2** | ⚠ **「近 1 个会计年度」的企业所得税年度纳税申报表中，记录「收入总额和不征税收入」相关的资料；不征税收入取得的相关拨款文件、会计核算资料** |
| **3** | **企业总经理办公会或董事会关于研究开发项目「立项的决议文件」；研究开发项目计划书和研究开发费预算；研究开发专门机构或项目组的编制情况和专业人员名单；委托、合作研究开发项目的合同或协议；研究开发项目向科技等部门备案的相关资料或向查新部门查新的相关资料；研究开发项目的效用情况说明、研究成果报告等资料** |
| **4** | **研究开发项目当年研究开发费用发生情况归集表；研究开发费用辅助核算账目、相关凭证及明细表等财务核算资料；用于研发活动的「仪器、设备和软件、专利权、非专利技术等无形资产的清册」** |
| **5** | ⚠ **「近 3 个会计年度」的企业所得税年度纳税申报表中，记录「主营业务收入与其他业务收入」相关的资料** |

### 四、鉴证报告

⚠ **发表结论时应关注**：**被鉴证人的高新技术产品（服务）收入占比、企业研究开发费用占比数据的
真实性、合法性；作出上述判断的证据是否确实充分，适用法律依据是否准确**；
⚠ **「应以工作底稿为基础，按照《涉税鉴证业务指引（试行）》要求的内容，编制高新技术企业认定
专项鉴证报告」**——**「报告的核心是对被鉴证人高新技术产品（服务）收入占比、
企业研究开发费用占比予以评价」**；**报告应按要求进行信息沟通、签字盖章**。
