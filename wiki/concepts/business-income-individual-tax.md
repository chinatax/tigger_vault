# 经营所得（个人所得税）

## Definition

经营所得（个人所得税）：个体工商户、个人独资企业投资人、合伙企业的个人合伙人、
承包承租经营者等取得的所得，适用 **5%~35% 五级超额累进税率**。
⚠ 它与"**企业所得税**"是两套完全不同的制度——**个体工商户、个人独资企业、合伙企业本身
不缴企业所得税，由业主/投资人/合伙人缴个人所得税**。

其独特之处在于**"业主的工资不能扣"**——与公司制下"工资作为费用扣除"正好相反。

## Key Points

### 纳税人与基本规则

- **纳税人**：个体工商户业主、**个人独资企业**投资人、**合伙企业**的个人合伙人、
  承包承租经营者（缴纳承包费后经营成果归承包人的）。
  > ⚠ **入口指针**：本页讲的是**这三类主体如何缴纳个人所得税**；
  > **三类主体自身的组织形式与责任规则**见 [[sole-proprietorship-law]]（个人独资企业）与
  > [[partnership-enterprise-law]]（合伙企业）。⚠ **「个人独资企业」一词的主属页面是前者**，
  > 故本页**不将该词声明为别名**（依 aliases 语义规则，跨领域共用术语只留在主属页面）。
- ⚠ **个人独资企业以投资者为纳税人**；
  ⚠ 持有**权益性投资**的个人独资企业、合伙企业，**一律采用查账征收**方式计征个人所得税。
- ⚠ 个体工商户、个人独资企业、合伙企业**本身不是企业所得税纳税人**。
- **个体工商户年应纳税所得额不超过 200 万元**的部分，**减半**征收个人所得税。

### 不得扣除与特殊扣除

- ⚠ **业主/投资者的工资不得扣除**（合伙企业支付给合伙人的工资同样不得直接扣除）
- ⚠ 个体工商户用于**个人和家庭的支出**不得扣除
- ⚠ 个体工商户**缴纳的个人所得税税款**不得税前扣除
- ⚠ 个体工商户**代其从业人员或者他人负担的税款**不得扣除
- ⚠ **计提的各种准备金**不得扣除
- ✅ **合同违约金**可以扣除；✅ **向从业人员实际支付的工资**可以扣除；
  ✅ **出售固定资产发生的支出**可以扣除
- ⚠ **个人独资企业的生产经营费用与其家庭生活费用无法划分的，一律不得税前扣除**；
  （对比：**个体工商户**生产经营与个人、家庭生活**混用难以分清**的费用，
  其 **40% 视为与生产经营有关**，准予扣除）

### 业主本人的"三项经费"与补充保险（特别规则）

个体工商户业主本人向当地工会组织缴纳的**工会经费**、实际发生的**职工福利费**、
**职工教育经费**支出，以**当地（地级市）上年度社会平均工资的 3 倍**为计算基数，
分别在 **2%**（工会经费）、**14%**（职工福利费）、**2.5%**（职工教育经费）的标准内据实扣除。
- ⚠ 业主本人缴纳的**补充养老保险费、补充医疗保险费**，以**同一基数**在不超过
  **5%** 标准内据实扣除。

### 对外投资分回的所得（易错）

- ⚠ **个人独资企业、合伙企业对外投资分回的利息或股息、红利**，
  **不并入**企业的收入，应**单独**作为投资者个人取得的**利息、股息、红利所得**，
  按 **20%** 计税。
- 对比：**除个人独资企业、合伙企业以外的其他企业**的个人投资者，
  从企业借款年度终了后不归还又未用于生产经营 → **利息、股息、红利所得**；
  **个人独资企业、合伙企业**的个人投资者同样情形 → **经营所得**。

### 兴办两个及以上企业

- 投资者兴办两个或两个以上企业的，年度终了后汇算清缴时应**汇总**其投资兴办的所有企业的
  经营所得作为应纳税所得额，**以此确定适用税率**，计算出全年应纳税额后，
  再按各企业所得**占比**分别计算各企业应纳税额和应补缴税额。
- ⚠ 各企业的**年度经营亏损不能跨企业弥补**。
- ⚠ 投资者本人的**费用扣除标准**（6 万元等），由投资者**选择在其中一个**企业的
  生产经营所得中扣除。

### 减除费用的归属

- 取得经营所得的个人，**没有综合所得**的，计算每一纳税年度应纳税所得额时应当减除
  **费用 6 万元**、专项扣除、专项附加扣除以及依法确定的其他扣除；
  ⚠ **专项附加扣除在办理汇算清缴时**减除。
- 纳税人当年**同时取得综合所得和经营所得**的，可在综合所得**或**经营所得中申报减除，
  ⚠ **但不得重复申报减除**。

### 核定征收

- 核定征收可采用**定额征收、核定应税所得率征收**以及其他合理方式
- ⚠ 实行核定征税的**合伙企业投资者，不能享受**个人所得税的优惠政策
- ⚠ **查账征税方式改为核定征税方式后，在查账征税方式下认定的年度经营亏损
  未弥补完的部分，不得再继续弥补**
- ⚠ 纳税人依照国家有关规定**应当设置但未设置账簿**的，应采取核定征收
- 企业经营**多业**的，根据其**主营项目**确定适用的应税所得率

### 合伙创投企业与天使投资个人的优惠

- **合伙创投企业**：合伙人可按照对初创科技型企业**投资额的 70%** 抵扣从合伙创投企业分得的所得
  （分得所得不足抵扣的，以实际分得所得为限）
- **天使投资个人**：采取股权投资方式直接投资于初创科技型企业**满 2 年**的，
  可按**投资额的 70%** 抵扣转让该股权取得的应纳税所得额
- ⚠ **创投企业核算方式**：选择按**单一投资基金**核算的，个人合伙人从该基金应分得的
  **股权转让所得按 20%** 税率；选择按**年度所得整体**核算的，按**经营所得**项目计税。
  ⚠ 选择后 **3 年内不能变更**；⚠ 选择按单一投资基金核算的应在**完成备案的 30 日内**
  向主管税务机关进行核算方式备案，**未按规定备案的视同**选择按年度所得整体核算。
- ⚠ 享受创业投资企业税收优惠的投资，**仅限于**通过向被投资初创科技型企业**直接支付现金方式**
  取得的股权投资，**不包括受让其他股东的存量股权**。
- **初创科技型企业的条件**：①中国境内（不含港澳台）注册成立、实行查账征收的居民企业；
  ②接受投资时**从业人数不超过 300 人**，其中大学本科以上学历的不低于 **30%**；
  **资产总额和年销售收入均不超过 5000 万元**；③**设立时间不超过 5 年（60 个月）**；
  ④接受投资时及之后 **2 年内未在境内外证券交易所上市**；
  ⑤接受投资当年及下一纳税年度**研发费用总额占成本费用支出比例不低于 20%**。

### 教材补充（CTA《税法（二）》教材 2026 版第五节）

**（一）个体工商户的计税基本规定**

> **应纳税所得额 = 该纳税年度收入总额 − 成本 − 费用 − 税金 − 损失 − 其他支出
> − 允许弥补的以前年度亏损**

- ⚠ 以**权责发生制**为原则：属于当期的收入和费用，**不论款项是否收付**均作为当期；
  不属于当期的，**即使款项已经在当期收付**也不作为当期（财政部、国家税务总局另有规定的除外）
- ⚠ 因**纳税年度中间开业、合并、注销**及其他原因导致实际经营期**不足 1 年**的，
  以其**实际经营期**为 1 个纳税年度
- ⚠ **五项要素的口径**：
  - **收入总额** = 销售货物收入、提供劳务收入、转让财产收入、利息收入、租金收入、
    接受捐赠收入、其他收入（⚠ 其他收入含**资产溢余收入、逾期一年以上的未退包装物押金收入、
    确实无法偿付的应付款项、已作坏账损失处理后又收回的应收款项、债务重组收入、补贴收入、
    违约金收入、汇兑收益**等）
  - **成本** = 各种**直接支出**和**分配计入成本的间接费用**（销售成本、销货成本、业务支出及其他耗费）
  - **费用** = **销售费用、管理费用和财务费用**（已经计入成本的有关费用除外）
  - **税金** = 除**个人所得税和允许抵扣的增值税**以外的各项税金及其附加
  - **损失** = 固定资产和存货的盘亏、毁损、报废损失，转让财产损失，坏账损失，
    自然灾害等不可抗力因素造成的损失及其他损失
    —— ⚠ 减除**责任人赔偿和保险赔款**后的余额，**参照企业资产损失税前扣除的规定**扣除；
    ⚠ 已作为损失处理的资产以后年度**又全部或部分收回**时，应当**计入收回当期**的收入
  - **其他支出** = 与生产经营活动有关的、合理的支出
- ⚠ **收益性支出与资本性支出的分流**：收益性支出在**发生当期直接扣除**；
  资本性支出应当**分期扣除或者计入有关资产成本**，不得在发生当期直接扣除
- ⚠⚠ **与企业所得税的两处关键差异**（教材特意提示）：
  - **特许权使用费收入**和**股息、红利等权益性投资收益**属于**企业所得税**的应税收入，
    ⚠ **但不属于**个体工商户经营所得的应税收入
  - ⚠ 个体工商户**业主的工资、薪金支出不得**税前扣除；
    而**企业所得税**下企业支付给投资者个人的**合理工资准予扣除**

**（二）⚠ 个体工商户不得税前扣除的八项支出**

①**个人所得税税款**；②**税收滞纳金**；③**罚金、罚款和被没收财物**的损失；
④**不符合扣除规定的捐赠**支出；⑤**赞助支出**（与生产经营活动无关的各种**非广告性质**支出）；
⑥**用于个人和家庭的支出**；⑦**与取得生产经营收入无关**的其他支出；
⑧国家税务总局规定不准扣除的支出。

**（三）扣除项目及标准（⚠ 与企业所得税对照记忆）**

| 项目 | 个体工商户的口径 |
|---|---|
| **业主工资** | ⚠ **不得**税前扣除；**从业人员**的合理工资薪金**准予**扣除 |
| **社会保险费** | 为**业主和从业人员**缴纳的基本养老、基本医疗、失业、生育、工伤保险费和住房公积金，按规定的范围和标准**准予**扣除 |
| **补充养老、补充医疗保险** | ⚠ 为**从业人员**缴纳的，分别在**不超过从业人员工资总额 5%** 标准内据实扣除；<br>⚠ **业主本人**缴纳的，以**当地（地级市）上年度社会平均工资的 3 倍**为计算基数，分别在**不超过该基数 5%** 标准内据实扣除 |
| **商业保险费** | ⚠ 除为**特殊工种从业人员**支付的**人身安全保险费**及财政部、国家税务总局规定可扣除的其他商业保险费外，**业主本人或为从业人员支付的商业保险费不得扣除** |
| **借款费用** | 合理的、**不需要资本化**的借款费用准予扣除；为购置、建造固定资产、无形资产和**经过 12 个月以上建造**才能达到预定可销售状态的存货发生借款的，购置建造期间的合理借款费用应**资本化** |
| **利息支出** | ①向**金融企业**借款的利息支出；②向**非金融企业和个人**借款的利息支出**不超过按金融企业同期同类贷款利率计算的数额**的部分 |
| **汇兑损失** | 货币交易中以及纳税年度终了时将外币货币性资产、负债按**期末即期人民币汇率中间价**折算产生的汇兑损失（**已计入有关资产成本的除外**） |
| **工会经费、职工福利费、职工教育经费** | 分别在**工资、薪金总额的 2%、14%、2.5%** 的标准内据实扣除<br>⚠ **职工教育经费**超出规定比例当期不能扣除的数额，**准予在以后纳税年度结转扣除**<br>⚠ **业主本人**的这三项，以**当地（地级市）上年度社会平均工资的 3 倍**为计算基数，在上述比例内据实扣除 |
| **业务招待费** | 按**实际发生额的 60%** 扣除，但**最高不得超过当年销售（营业）收入的 5‰**<br>⚠ 业主**自申请营业执照之日起至开始生产经营之日止**发生的业务招待费，按**实际发生额的 60%** 计入**开办费** |
| **广告费和业务宣传费** | 不超过当年销售（营业）收入 **15%** 的部分据实扣除；**超过部分准予在以后纳税年度结转扣除** |
| **代负担的税款** | ⚠ 代其**从业人员或者他人**负担的税款**不得**税前扣除 |
| **摊位费、行政性收费、协会会费** | 按**实际发生数额**扣除 |
| **租赁费** | **经营租赁**按**租赁期限均匀**扣除；**融资租赁**按规定构成融资租入固定资产价值的部分应**提取折旧**分期扣除 |
| **财产保险费** | 按规定缴纳的**准予**扣除 |
| **劳动保护支出** | 合理的**准予**扣除 |
| **开办费** | ⚠ 自**申请营业执照之日起至开始生产经营之日止**发生的符合规定的费用（除为取得固定资产、无形资产的支出，以及应计入资产价值的汇兑损益、利息支出外），**可以选择**在开始生产经营的**当年一次性扣除**，也可**自生产经营月份起在不短于 3 年期限内摊销扣除**，⚠ **一经选定不得改变**。「开始生产经营之日」为取得**第一笔销售（营业）收入**的日期 |
| **公益性捐赠** | 通过**公益性社会团体或县级以上人民政府及其部门**用于《公益事业捐赠法》规定的公益事业的捐赠，**不超过其应纳税所得额 30%** 的部分可据实扣除；⚠ **除另有规定外，直接对受益人的捐赠不得扣除** |
| **研发费用** | 研究开发新产品、新技术、新工艺所发生的**开发费用**，以及研究开发新产品、新技术而购置**单台价值在 10 万元以下**的测试仪器和试验性装置的**购置费** → **准予直接扣除**；⚠ **单台价值在 10 万元以上（含）**的测试仪器和试验性装置，**按固定资产管理，不得在当期直接扣除** |

- ⚠ **混用费用的扣减比例**：个体工商户生产经营活动中应当分别核算生产经营费用和个人、家庭费用；
  ⚠ **生产经营与个人、家庭生活混用难以分清的费用，其 40% 视为与生产经营有关费用，准予扣除**
- ⚠ **亏损弥补**：纳税年度发生的亏损准予**向以后年度结转**，用以后年度的生产经营所得弥补，
  但**结转年限最长不得超过 5 年**
- ⚠ **资产的税务处理参照企业所得税**相关法律法规和政策规定执行
- ⚠ **两处或两处以上经营机构**的，**选择并固定向其中一处**经营机构所在地主管税务机关申报缴纳
  - ⚠⚠ **补记（2026-10-09，来源 [[multiple-sole-proprietorships-xinhua]]）**：
    **「同一人名下多家**个人独资企业**」的经营所得「不能分开独立计税」**——
    ⚠ **法理**：**个人独资企业不具有法人资格，其经营所得归属于投资者个人**，
    **故年度必须汇总全部经营所得、统一计算缴纳个人所得税，不得人为降低应纳税额**
    （上海财经大学公共政策与治理研究院院长**田志伟**）。
    ⚠ **真实案例**：**党迎凤**成立的多家个人独资企业，**2021—2023 年通过虚列成本、
    虚假纳税申报人为降低应纳税所得额，少缴个人所得税 274.02 万元**
    （**2026-06-05 税务部门集中曝光**）。
    ⚠ **申报链条与「两段式」顺序**见 [[iit-filing-annual-declaration]] §三（C）。
- ⚠ **预缴与汇算**：按月或按季**预缴**（月度或季度终了后 **15 日内**报送纳税申报表预缴税款），
  在取得所得的**次年 3 月 31 日前**办理年度汇算清缴
  - **全年应纳税额 = 全年应纳税所得额 × 适用税率 − 速算扣除数**
  - **汇算清缴应补（退）税额 = 全年应纳税额 − 全年累计已预缴税额**

**（四）⚠ 个人独资企业与合伙企业的三处特别规则**

**1. 投资者的费用扣除**

- ⚠ **投资者的工资不得在税前直接扣除**，但可按规定的标准扣除费用
- ⚠ 自 2019-01-01 起，取得经营所得的投资者**没有综合所得**的，
  计算其每一纳税年度的应纳税所得额时，应当减除**费用 60000 元、专项扣除、专项附加扣除
  以及依法确定的其他扣除**（⚠ **专项附加扣除在办理汇算清缴时减除**）
- ⚠ 纳税人**当年同时取得综合所得和经营所得**的，可在**综合所得或经营所得中申报减除**
  上述项目，⚠ **但不得重复申报减除**
- ⚠ **投资者兴办两个或两个以上企业的**，其**费用扣除标准由投资者选择在其中一个企业**的
  生产经营所得中扣除

**2. ⚠ 投资者及其家庭的生活费用的特殊规则（与企业「混用」规则不同）**

- ⚠ **投资者及其家庭发生的生活费用不允许在税前扣除**
- ⚠ **投资者及其家庭的生活费用与企业生产经营费用混合在一起且难以划分的，
  全部视为投资者个人及其家庭发生的生活费用，不允许在税前扣除**
  —— ⚠ **注意与个体工商户的对照**：个体工商户混用难以分清的，**40% 准予扣除**；
  **独资/合伙企业投资者混用的，全额不得扣除**
- ⚠ 企业生产经营和投资者及其家庭生活**共用的固定资产**，难以划分的，
  由主管税务机关根据企业的生产经营类型、规模等具体情况，**核定准予扣除的折旧费用的数额或比例**

**3. 扣除与亏损弥补的其余规定**

- ⚠ 企业向**从业人员**实际支付的合理工资薪金**允许**据实扣除
- ⚠ 缴拨的**工会经费、职工福利费、职工教育经费**分别在工资薪金总额 **2%、14%、2.5%** 标准内据实扣除
- ⚠ **业务招待费**按实际发生额的 **60%** 扣除，最高不超过当年销售（营业）收入的 **5‰**
- ⚠ **广告费和业务宣传费**不超过当年销售（营业）收入 **15%** 的部分据实扣除，
  **超过部分准予在以后纳税年度结转扣除**
- ⚠ **企业计提的各种准备金不得扣除**
- ⚠ **亏损弥补**：企业的年度亏损允许用**本企业下一年度**的生产经营所得弥补，
  不足弥补的可**逐年延续弥补**，但**最长不得超过 5 年**；
  ⚠ **投资者兴办两个或两个以上企业的，企业的年度经营亏损不能跨企业弥补**；
  ⚠ **实行查账征税方式的个人独资企业和合伙企业改为核定征税方式后，
  在查账征税方式下认定的年度经营亏损未弥补完的部分，不得再继续弥补**

**（五）⚠ 权益性投资经营所得一律查账征收（自 2022-01-01 起）**

- ⚠ 持有**股权、股票、合伙企业财产份额等权益性投资**的**个人独资企业、合伙企业**
  （「独资合伙企业」），**一律适用查账征收方式**计征个人所得税
- ⚠ 独资合伙企业应自持有上述权益性投资之日起 **30 日内**主动向税务机关**报送**持有权益性投资的情况；
  ⚠ 政策实施前**已持有**的，应当在 **2022-01-30 前**报送
- ⚠ 税务机关接到**核定征收**独资合伙企业报送持有权益性投资情况的，
  **调整其征收方式为查账征收**
- ⚠ **未如实报送**的，依据《税收征管法》相关规定处理

**（六）对企事业单位承包、承租经营所得**

- ⚠ **应纳税所得额 = 个人承包、承租经营收入总额 − 每月费用扣除标准 5000 元 × 实际承包或承租月数**
  - **收入总额**指纳税人按承包、承租经营合同规定**分得的经营利润**，
    以及个人**按月或按次**从所承包的企事业单位取得的**工资、薪金性质**的所得
- ⚠ **应纳税额 = 应纳税所得额 × 适用税率 − 速算扣除数**（⚠ 适用**五级超额累进税率**）
- ⚠ 纳税人在一个年度内**分次取得**承包、承租经营所得的，应在**每次取得后预缴税款**，
  **年终汇算清缴**，多退少补
- ⚠ **不足 12 个月**的，应以其**实际承包、承租经营的月份数**为一个纳税年度计算纳税

**（七）⚠ 核定征收（个人独资企业与合伙企业）**

- ⚠ **核定征收的范围**（有下列情形**之一**）：①企业依照国家有关规定**应当设置但未设置账簿**的；
  ②企业**虽设置账簿，但账目混乱**或者成本资料、收入凭证、费用凭证残缺不全，**难以查账**的；
  ③纳税人发生纳税义务，**未按照规定的期限办理纳税申报**，经税务机关责令限期申报，
  **逾期仍不申报**的
- ⚠ **核定征收方式**包括**定额征收、核定应税所得率征收**及其他合理的征收方式
- ⚠ **应纳所得税税额 = 应纳税所得额 × 适用税率**；
  **应纳税所得额 = 收入总额 × 应税所得率**，或 **成本费用支出额 ÷（1 − 应税所得率）× 应税所得率**
- ⚠ 企业**经营多业**的，无论其经营项目是否单独核算，
  均应根据其**主营项目**确定其适用的应税所得率
- ⚠ **实行核定征税的投资者不能享受个人所得税的优惠政策**
- ⚠ **各行业应税所得率幅度**（教材表 2—7）：工业、商业、交通运输业 **5%–20%**；
  建筑业、房地产开发业 **7%–20%**；饮食服务业 **7%–25%**；娱乐业 **20%–40%**；其他行业 **10%–30%**

**（八）查账征收下兴办多个企业的汇总计算**

- ⚠ 投资者兴办两个或两个以上企业且**性质全部是独资**的，年度终了后汇算清缴时：
  **应纳税所得额 = Σ各个企业的经营所得**；
  **应纳税额 = 应纳税所得额 × 税率 − 速算扣除数**；
  ⚠ **本企业应纳税额 = 应纳税额 × 本企业的经营所得 ÷ Σ各个企业的经营所得**；
  **本企业应补缴的税额 = 本企业应纳税额 − 本企业预缴的税额**

**（九）其余两处**

- ⚠ **残疾人员**投资兴办或参与投资兴办个人独资企业和合伙企业的，
  其取得的生产经营所得符合各省、自治区、直辖市人民政府规定的减征条件的，
  经本人申请、主管税务机关审核批准，可按规定的范围和幅度**减征**个人所得税
  —— ⚠ **实行核定征收的个人投资者除外**
- ⚠ **实际经营期不足 1 年**的，以**实际经营期**为 1 个纳税年度
- ⚠ **关联交易管理**：企业与其关联企业之间的业务往来应按**独立企业之间的业务往来**收取或支付
  价款、费用；不按此办理而**减少其应纳税所得额**的，主管税务机关**有权进行合理调整**

**（十）⚠ 创业投资企业个人合伙人的两种核算方式（执行至 2027-12-31）**

⚠ 创投企业**可以选择**按**单一投资基金核算**或者按**创投企业年度所得整体核算**两种方式之一，
对其**个人合伙人**来源于创投企业的所得计算个人所得税：

| 核算方式 | 个人合伙人的计税 |
|---|---|
| ⚠ **按单一投资基金核算** | 从该基金应分得的**股权转让所得和股息红利所得**，按 **20% 税率**计算缴纳 |
| ⚠ **按年度所得整体核算** | 从创投企业取得的所得，按「**经营所得**」项目、以 **5%–35%** 的五级超额累进税率计算缴纳 |

- ⚠ **单一投资基金核算的具体方法**：
  - **股权转让所得**：单个投资项目按**年度股权转让收入扣除对应股权原值和转让环节合理费用**
    后的余额计算（股权原值与合理费用的确定**参照股权转让所得个人所得税的有关政策**）；
    ⚠ **单一投资基金的股权转让所得按一个纳税年度内不同投资项目的所得和损失相互抵减后的余额**计算
    —— ⚠ **余额小于零的，该基金年度股权转让所得按零计算，且不能跨年结转**
  - ⚠ 纳税人按**应从基金年度股权转让所得中分得的份额**计算应纳税额，
    由创投企业**在次年 3 月 31 日前代扣代缴**
  - **股息红利所得**：以**来源于所投资项目分配的股息、红利收入以及其他固定收益类证券等收入的全额**
    计算；⚠ 由创投企业**按次代扣代缴**
  - ⚠⚠ **不得扣除的支出**：除上述可扣除的成本、费用外，
    **单一投资基金发生的包括投资基金管理人的管理费和业绩报酬在内的其他支出，不得在核算时扣除**
  - ⚠ 单一投资基金核算方法**仅适用于计算创投企业个人合伙人的应纳税额**
- ⚠ **年度所得整体核算**：以每一纳税年度的**收入总额减除成本、费用以及损失**后，
  计算应分配给个人合伙人的所得；⚠ **年度核算亏损的，准予按规定向以后年度结转**
  - ⚠ 按「经营所得」计税的个人合伙人**没有综合所得**的，可**依法减除基本减除费用、
    专项扣除、专项附加扣除以及国务院确定的其他扣除**；
    ⚠ **从多处取得经营所得的，应汇总计算、只减除一次**上述费用和扣除
- ⚠ **70% 抵扣**：符合规定条件的，创投企业个人合伙人可以按照**被转让项目对应投资额的 70%**
  抵扣其可从创投企业应分得的**经营所得**（或从基金年度**股权转让所得**中分得的份额）后再计算应纳税额
  —— ⚠ **单一投资基金核算下当期不足抵扣的，不得向以后年度结转**
  （⚠ 与年度整体核算下**可结转**形成对照）
- ⚠⚠ **一经选择 3 年内不能变更**；⚠ 选择按单一投资基金核算的，
  应当在**完成备案的 30 日内**向主管税务机关**核算方式备案**；
  ⚠ **未按规定备案的，视同选择按年度所得整体核算**
- ⚠ 选择一种核算方式**满 3 年需要调整**的，应当在**满 3 年的次年 1 月 31 日前**重新备案

**（十一）律师事务所从业人员**

- ⚠ 律师个人出资兴办的**独资和合伙性质的律师事务所**的年度经营所得，
  自 2000-01-01 起**停止征收企业所得税**，作为**出资律师的个人经营所得**，
  比照「**个体工商户的生产、经营所得**」计征个人所得税
  —— ⚠ **计算其经营所得时，出资律师本人的工资、薪金所得不得扣除**
- ⚠ **合伙制**律师事务所应将年度经营所得**全额**作为基数，
  按**出资比例或事先约定的比例**计算各合伙人应分配的所得
- ⚠ 支付给**雇员**（包括律师及行政辅助人员，**但不包括律师事务所的投资者**）的所得 →
  按「**工资、薪金所得**」项目征收
- ⚠ **雇员律师按比例分成的**：律师事务所**不负担**律师办理案件支出的费用（交通费、资料费、
  通讯费及聘请人员等费用）的，律师当月的**分成收入**按规定扣除**办理案件支出的费用**后，
  余额与律师事务所发给的**工资合并**，按「工资、薪金所得」计征
  - ⚠ **扣除标准**由各省级税务局在**律师当月分成收入的 30% 比例内**确定
- ⚠ **兼职律师**从律师事务所取得工资薪金性质的所得，代扣代缴时**不再减除**税法规定的**费用扣除标准**，
  以**收入全额**（取得分成收入的为扣除办案支出费用后的余额）**直接确定适用税率**；
  ⚠ 兼职律师应于**次月 7 日内**自行向主管税务机关申报两处或两处以上取得的工资薪金所得，
  **合并计算缴纳**
- ⚠ 律师以**个人名义再聘请**其他人员为其工作而支付的报酬 → 由该律师按「**劳务报酬所得**」
  项目负责**代扣代缴**
- ⚠ 律师从**接受法律事务服务的当事人**处取得**法律顾问费或其他酬金**等收入 →
  应**并入**其从律师事务所取得的其他收入
- ⚠ 律师个人承担的按律师协会规定参加的**业务培训费用**，**可据实扣除**

**（十二）建筑安装业从业人员**

- ⚠ **纳税人**：从事建筑安装业并取得个人所得的**工程承包人、个体工商户及其他个人**
- ⚠ **应税项目的三分**：
  - ⚠ 建筑安装业各项工程作业**实行承包经营**的，对承包人取得的所得**分两种情况**：
    **经营成果归承包人个人所有**的，或按承包合同规定**将一部分经营成果留归承包人**的 →
    按「**对企事业单位承包经营、承租经营所得**」项目征税；
    ⚠ 对承包人以**其他方式**取得的所得 → 按「**工资、薪金所得**」
  - ⚠ 从事建筑安装业的**个体工商户**和**未领取营业执照**承揽工程作业的建筑安装队和个人，
    以及建筑安装企业实行个人承包后**市场主体登记改变为个体经济性质**的 →
    按「**个体工商户的生产、经营所得**」计征
  - ⚠ 其他人员取得的所得 → 分别按「**工资、薪金所得**」和「**劳务报酬所得**」计征
- ⚠ **异地工程作业人员的征管（四条）**：
  1. 总承包企业、分承包企业**派驻跨省异地工程项目**的管理人员、技术人员和其他工作人员
     在异地工作期间的工资薪金所得个人所得税 → 由总承包、分承包企业**代扣代缴**
     并向**工程作业所在地**税务机关申报缴纳
  2. 通过**劳务派遣公司**聘用劳务人员跨省异地工作期间的工资薪金所得个人所得税 →
     由**劳务派遣公司代扣代缴**并向**工程作业所在地**税务机关申报缴纳
  3. ⚠ 跨省异地施工单位应就其所支付的工程作业人员工资薪金所得，
     向工程作业所在地税务机关办理**全员全额扣缴明细申报**；
     ⚠ **凡实行全员全额扣缴明细申报的，工程作业所在地税务机关不得核定征收**个人所得税
  4. ⚠ **不得重复征税**：总承包、分承包企业和劳务派遣公司**机构所在地**税务机关
     不得对异地工程作业人员**已纳税**工资薪金所得重复征税；两地税务机关应加强沟通协调
- ⚠ **纳税保证金**：对**未领取营业执照**承揽建筑安装工程作业的单位和个人，
  主管税务机关可根据其**工程规模**，责令其缴纳一定数额的**纳税保证金**；
  ⚠ 按期结清税款的**退还**；**逾期未结清**的，**以纳税保证金抵缴应纳税款和滞纳金**
- ⚠ **核定征收**：对**未设立会计账簿**，或者**不能准确、完整进行会计核算**的单位和个人，
  主管税务机关可根据其**工程规模、工程承包合同（协议）价款和工程完工进度**等情况，
