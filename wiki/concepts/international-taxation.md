# 国际税收

## Definition

国际税收（International Taxation）：两个或两个以上国家因**对同一纳税人的同一所得同时行使税收管辖权**
而产生的税收分配关系。它产生的**基础是"国家间对商品服务、所得、财产课税的制度差异"**。

其知识骨架是三个问题：**谁有权征税**（税收管辖权）、**这笔所得来自哪国**（所得来源地判定）、
**这家外国企业在本国有无"落点"**（常设机构）。

## Key Points

### 一、税收管辖权

- **三类**：**收入来源地管辖权、居民管辖权、公民管辖权**（⚠ 不含"国家管辖权"）。
- ⚠ **我国企业所得税**选择**地域管辖权和居民管辖权的双重标准**（不是单一标准，也不是三重标准）。
- **法人居民身份的判定标准（四个）**：
  - **注册地标准**——以**美国、加拿大**等国为代表
  - **实际管理和控制中心所在地标准**——以**英国、爱尔兰、德国、意大利、瑞士、新加坡**等为代表
  - **总机构所在地标准**
  - **控股权标准**
- **自然人居民身份的判定标准（三个）**：**法律标准**、**停留时间标准**、**住所标准**。
- **加比规则（tie-breaker）**——判定个人居民身份的**顺序**：
  ①**永久性住所** → ②**重要利益中心** → ③**习惯性居处** → ④**国籍** → ⑤**缔约国双方协商**
  - ⚠ 在双方**均有永久性住所**且**无法确定重要经济利益中心**所在国 → 采用**习惯性居处**标准
  - ⚠ 在双方**均有习惯性居处** → 采用**国籍**标准

### 二、常设机构

- ⚠ **判定经营所得来源地**的国际通行标准是**常设机构标准**（OECD 范本与 UN 范本均采用）。
- **构成常设机构**：管理机构、营业机构、办事机构；**作业场所**；**工厂**（含电器工厂）；
  **开采自然资源的场所**；提供劳务的场所；从事建筑、安装、装配、修理、勘探等**工程作业的场所**
  （⚠ 工程性常设机构以持续时间**6 个月以上**为界）；**分支机构**。
- ⚠ **不构成常设机构**：**仅供交付货物的仓库**（仅承担储存和交付的单一功能，
  不涉及核心经营环节）；⚠ 代理人活动**仅限于准备性或辅助性**范围（仓储、展览、采购、信息收集）。
- **代理型常设机构**：
  - **非独立代理人**（构成常设机构）——**有权代表被代理企业参与企业合同的制定、
    以该企业名义签订合同**；⚠ **常年委托**境内公司代表其签署购销合同的也构成
  - **独立代理人**（不构成）——**专门从事代理业务**；**不仅为某一个企业代理业务**，
    也为其他企业提供代理服务
- ⚠ **停留天数的计算**：以该企业派其雇员为实施服务项目**第一次抵达中国之日**起至
  **完成并交付服务项目之日**止为**计算期间**；应按**所有雇员**为同一项目提供劳务
  **不同时期**在境内连续或累计停留的时间掌握；
  ⚠ **同一时间段内的同一批人员的工作不分别计算**（不按人数累积）。

### 三、常设机构利润的确定

| 环节 | 方法 |
|---|---|
| **利润范围的确定** | **归属法**和**引力法**（国际公认） |
| **利润的计算** | **利润分配法**和**利润核定法** |

- **利润分配法**：按**企业总利润的一定比例**确定其设在非居住国的常设机构所得
- **利润核定法**：常设机构所在国可按常设机构的**营业收入额核定利润**，
  或按**经费支出额推算利润**

### 四、各类所得的来源地判定标准

| 所得类型 | 判定标准 |
|---|---|
| 经营所得 | **常设机构标准** |
| **非独立个人劳务所得** | **停留期间标准** + **所得支付者标准** |
| **董事费** | **所得支付地标准** |
| 艺术家、运动员 | **演出活动所在地标准** |
| 国际运输船舶/飞机上受雇人员报酬 | 由**从事该项运输的企业为其居民的国家**征税 |
| 转让不动产 | **不动产坐落地国家** |
| **出售动产收益** | 由**转让者的居住国**征税 |
| 转让常设机构的营业财产 | 由该项**财产的所在地国家** |
| 出售独立劳务固定基地财产 | 由**固定基地所在国** |
| ⚠ 转让公司股票 | 来源地确定在国际税收实践中**存在较大分歧** |

### 五、国际避税与反避税

- **国际避税的主要手段**：利用**转让定价**、避免或转换**税收居民身份**、利用**资本弱化**、
  滥用**税收协定**（⚠ **利用税收饶让不属于**避税手段）。
- **国际避税地的类型**：①**不征收**任何所得税和一般财产税的国家或地区；
  ②所得税仅实行**地域管辖权**的国家或地区；③对国内一般公司征收正常所得税，
  但对**某些特定种类的公司提供特殊税收优惠**的国家或地区。
  ⚠ 征收所得税但**税率较高**的**不属于**避税地（应为**税率较低**）。
- **国际税法原则**：**优先征税原则、独占征税原则、税收分享原则、无差异原则**
  （⚠ **单一课税原则不属于**）。
- **国际税收征管协作（合作）形式**：**情报交换、税款追缴、文书送达**
  （⚠ 税务工作人员国际交流与培训、税收网络信息**不属于**）。
  - **情报交换的类型**：**专项、自动、自发**情报交换，以及**同期税务检查、
    授权代表访问、行业范围情报交换**

### 教材补充（CTA《税法（二）》教材 2026 版第一、二节）

**（一）国际税收的概念与跨境交易的两分**

- ⚠ **国际税收**是一国对**跨国纳税人的跨境所得和交易活动**课税的法律、法规的总称
- ⚠ 四个常见的国际税收问题：**国际重复征税、国际双重不征税、国际避税与反避税、国际税收合作**
- ⚠ 跨境交易按**资本或资源的输入输出**角度分为两类：
  - ⚠ **「出境交易」**= 资本或资源**从本国输出到外国**的交易 → 主要涉及对**居民纳税人的境外所得**征税
  - ⚠ **「入境交易」**= 资本或资源**从某外国输入到本国**的交易 → 主要涉及对**非居民纳税人的境内所得**征税
  - ⚠ 一国（**居民国**）对境外所得的征税，**就是另一国（**来源国**）对非居民的征税**
- ⚠ 国际税收包括**所得税、增值税、关税、财产税以及各种特别的税费**，
  其中**所得税中对居民纳税人的境外所得和对非居民纳税人的境内所得征税**的法律法规，
  是一国国际税收**最主要的方面**
- ⚠ **国际税收的实质**是**国家之间的税收分配关系和税收合作关系**

**（二）⚠ 国际税法四原则的内涵**（题库已有名称，此处补内容）

| 原则 | 内涵 |
|---|---|
| **优先征税原则** | 确定将某项课税客体**归属于来源国**，由**来源国优先行使征税权**。⚠ 国际税收实践中通常**偏重运用来源地原则**，因为对一个国家而言采取来源地原则**更直接、更有效**；⚠ **如果不承认收入来源地的国家优先征税，就无法对跨国纳税人在其他国家取得的收益予以课税** |
| **独占征税原则** | 签订协定时将某项税收客体**排他性地归属于某一国**，由该国**单独**行使征税权。⚠ 一般是将征税项目归属于**收入来源国或纳税人居住国**，另一国**不再行使**征税权。例：**营业所得**通常规定只能由**缔约国一方独占征税**；**退休金**通常只能由**居住国或支付国**征税 |
| **税收分享原则** | 将某些课税客体**划归缔约国双方共同征税**。⚠ 会导致一些矛盾（如投资所得的征税权既可归居住国也可归来源国，**这会导致双重征税**）；⚠ 为解决这些矛盾，规定**各行使征税权的国家必须降低征税的适用税率**，以利于共同征收 |
| **无差异原则** | 对外国纳税人和本国纳税人**实行平等对待**，使两者在**征收范围、税率和税收负担**方面保持**基本一致**。⚠ **并不意味着绝对平等**；⚠ 在**税制结构大体一致**的国家之间可促进资本自由流动，但**在税制结构差异较大**的国家**很难**起到这一作用。⚠ **发达国家多实行无差异原则**并作为本国制定涉外税制的基本原则；**发展中国家多根据本国实际情况、在不违背国际惯例的前提下**确定对本国有利的涉外税收原则 |

**（三）税收管辖权的概念与两类连接因素**

- ⚠ **税收管辖权**是一国政府在征税方面的**主权**，表现在**有权决定对哪些人征税、征何种税、
  征多少税及如何征税**
- ⚠ 行使的前提是**纳税人或征税对象与本国主权存在某种属人或属地性质的连接因素**：
  - ⚠ **属人性质的连接因素** = **税收居所**（纳税人与征税国之间存在以**某种人身隶属关系**
    为特征的法律事实）
    - **自然人**：主要依据个人在征税国境内是否**拥有住所、居所或具有征税国的国籍**
    - **法人**：主要依据法人是否在征税国**注册成立**，或**总机构、管理中心是否设在**征税国境内
  - ⚠ **属地性质的连接因素** = **来源地**（征税对象与之存在**经济上来源关系**的国家（地区）），
    包括**所得来源地和各类财产的存在地**
- ⚠ **所得分为四类**：**营业利润、投资所得、劳务所得和财产所得**
  —— ⚠ **不同性质的所得需要根据不同的标准确定其来源地**

**（四）税收管辖权的三分类与重叠**

| 管辖权 | 依据的原则 | 内容 |
|---|---|---|
| **收入来源地管辖权**（又称**地域管辖权**） | **属地**原则 | 根据纳税人的**所得和财产价值是否来源于本国境内**行使征税权，**而不论纳税人是否为本国的公民或居民** |
| **居民管辖权** | **属人**原则 | 一国政府对**本国居民来自世界范围的全部所得和财产**行使征税权。⚠ 行使的关键是**确定纳税人的居民身份**；⚠ **被大多数国家所采用** |
| **公民管辖权**（又称**国籍税收管辖权**） | —— | 一国政府对**具有本国国籍者**在世界范围内取得的所得和拥有的财产行使征税权。⚠ **公民不仅包括个人，也包括团体、企业或公司** |

- ⚠⚠ **税收管辖权重叠是国际重复征税问题产生的主要原因**，其**三种形式**：
  ①**收入来源地管辖权与居民管辖权的重叠**；②**居民管辖权与居民管辖权的重叠**；
  ③**收入来源地管辖权与收入来源地管辖权的重叠**

**（五）⚠ 约束居民管辖权的国际惯例（补充细节）**

**自然人居民身份的三种标准**：

- ⚠ **法律标准**（也称**意愿标准**）：纳税人在某一国家内有**居住主观意愿**的即为该国居民
  —— 凡在一国有**不定期居住意愿**，并**依法取得入境护照、移民签证和各种居留证明**的外国侨民，
  都属于该国居民
- ⚠ **住所标准**（也称**户籍标准**）：纳税人凡在某一国家内拥有**永久性住所或习惯性居所**的即为该国居民
  - ⚠ **住所**指一个人**以久住的意思而居住的某一处所**，又称**永久性住所**，
    具有**永久性和稳定性**特点，**但不能反映出一个人真正的活动场所**
  - ⚠ **多数国家主要根据当事人在本国是否定居或习惯性居住的事实**，
    并结合当事人的**家庭（配偶、子女）所在地、经济利益中心、经济活动中心**作为判定住所的标准
  - ⚠ **「经济利益中心」**指能够给当事人带来**主要投资收益**的**不动产、专利或特许权**等财产的所在地；
    **「经济活动中心」**指当事人的**主要职业或就业活动**的所在地
  - ⚠ **居所**指**无久住的意思而暂时居住**的处所，又称**习惯性住所**；
    ⚠ **一个人可以同时有几处居所**；⚠ **在无住所或住所无从查考的情况下，可视居所为住所**；
    ⚠ 一些国家的税法将居所称为「**财政住所**」
- ⚠ **停留时间标准**：任何个人在一国境内**居住或停留达到一定时间以上**即成为该国居民
  - ⚠ 采用这一标准的主要以**中国、日本、英国、法国、德国、瑞士、印度**等国为代表
  - ⚠ 各国规定的停留时间**有的是 183 天，有的是 365 天**
  - ⚠ **在停留时间计算上的两点差别**：①**连续计算还是累计计算**；
    ②**按纳税年度计算还是按任何 12 个月计算**
    - ⚠ **按纳税年度计算**：以自然人**一个纳税年度内**居住在一国境内的时间为准
      —— ⚠ **如果一个人在某国累计居住时间虽然达到了规定时间，但却分跨两个纳税年度，
      而且在任何纳税年度均未达到规定时间，则不能将其认定为该国的居民纳税人**
    - ⚠ **按任何 12 个月计算**：指自然人在**任何 12 个月**中在本国停留的天数达到法定时间的，
      就是本国的居民纳税人

**法人居民身份的四个标准**（⚠ 与题库同，此处补**学理对比**）：

- ⚠ **注册地标准**（也称**法律标准**）：优点**便于识别**（法人的注册登记地**只能有一个**），
  ⚠ **缺点是容易产生法律规避现象**；以**美国、加拿大**为代表
- ⚠ **实际管理和控制中心所在地标准**：以**英国、爱尔兰、德国、意大利、瑞士、
  阿根廷、埃及、新加坡、印度尼西亚、马来西亚、以色列**等国为代表
  - ⚠ **「管理和控制中心」主要指法人的董事会或股东大会会议的场所**，
    是一个**事实上的概念，不同于法人的日常经营管理机构**
- ⚠ **总机构所在地标准**：以**日本、法国**为代表
  - ⚠ **「总机构」是负责管理和控制法人的全部日常经营业务、并统一核算法人盈亏的中心机构**
    （如各类**总公司、总厂或总店**）
  - ⚠⚠ **两标准的学理对比**：与**实际管理和控制中心**相比，
    **总机构所在地标准强调法人组织结构主体的重要性**，
    而**实际管理和控制中心所在地标准强调法人权力中心的重要性**；
    ⚠ **总机构所在地比较容易确定，但法人可以通过改变总机构所在地实现居民身份的变更**
- ⚠ **控股权标准**（也称**资本控制标准**）：**控制公司表决权的股东是哪一国的居民**，
  就确定该公司是哪一国的法人居民

**（六）⚠ 约束收入来源地管辖权的国际惯例（分所得类型）**

**1. 经营所得**——两种判定标准：

- ⚠ **常设机构标准**：⚠ **OECD 范本与 UN 范本均采用**，使常设机构标准成为
  **各国普遍接受的判定经营所得来源地的标准**
- ⚠ **交易地点标准**：**英美法系国家**比较侧重以交易地点判定，包括**合同的签约地、
  货物的生产地、交付地、货款的支付地**等

**2. 劳务所得**——分**独立劳务所得**、**非独立劳务所得**与**其他劳务所得**：

- ⚠ **独立劳务所得**（自由职业者从事专业劳务或其他独立性活动取得的报酬）
  —— ⚠ 一般多采用**劳务提供地标准**，具体有**三种**：
  ①**固定基地标准**（在非居住国设有**经常使用的固定基地**如诊疗所、事务所等）；
  ②**停留期间标准**（在一个纳税年度内停留**连续或累计达到一定天数，一般为 183 天**）；
  ③**所得支付者标准**（报酬**由某国居民或设在该国境内的常设机构支付或负担**）
- ⚠ **非独立劳务所得**——国际上通常采用**两种标准**：
  ①**停留期间标准**（⚠ 各国规定并不一致，**有的按 183 天，有的实行 90 天规定**）；
  ②**所得支付者标准**（⚠ **符合条件的标准之一即可**确定报酬所得来源于另一国境内）
- ⚠ **其他劳务所得**：
  - ⚠ **董事费**：国际上通行的做法是**按照所得支付地标准**确认
    **支付董事费的公司所在国**有权征税
    —— ⚠ **一国居民作为另一国居民公司的董事成员或其他高级管理人员，
    不管这类人员属于哪国居民、在境内停留的时间长短以及实际劳务活动发生在哪一国**，
    其所取得的董事费或其他类似报酬所得，**都应确定为来源于该董事会的公司所在国**
  - ⚠ **演员、艺术家和运动员**：⚠ **既不同于独立劳动者要停留一定时间以上，
    也不同于非独立劳动者必须受雇于人**（其演出时间很短，所得往往来自门票收入）
    → ⚠ **对此类所得并不按独立劳务所得和非独立劳务所得处理**，
    而是**不论该项所得是否归属演员、艺术家和运动员个人，
    均由活动所在国行使收入来源地管辖权征税**

**3. 投资所得**（利息、股息、特许权使用费）——三种标准：

- ⚠ **权利提供地标准**：应由**提供收取利息、股息、特许权使用费等权利的居民所在国**行使征税权
  —— ⚠ **该标准反映了居住国或国籍国的利益**
- ⚠ **权利使用地标准**（**又称投资所得支付地标准**）：权利在哪个国家使用即来源于哪个国家
  —— ⚠ **该标准代表着非居住国的利益**
- ⚠ **双方分享征税权利**：按**利益共享原则**合理划分双方征税权，
  ⚠ **对非居住国征税的最高额做出限制**，以便给权利提供方所在国行使征税权留有余地
  - ⚠ **但如果股息、利息、特许权使用费是通过常设机构取得的**，
    应当**纳入该常设机构的营业利润中，按一般的企业所得税税率征税**
  - ⚠ **对没有通过设立常设机构获得的这类投资所得**，
    一般都由**收入来源地所在国按其毛收入征收一笔较低的预提所得税**

**4. 不动产所得**：⚠ 以**不动产的所在地或坐落地**为判定标准

**5. 财产转让所得**：⚠ 分四种情形（见上「各类所得的来源地判定标准」表）

**6. 遗产继承所得**：⚠ **凡以不动产或有形动产为代表的**，
**以其物质形态的存在国为遗产所在地**；
⚠ **凡以股票或债权为代表的**，则**以其发行者或债务人的居住国为遗产所在地**

**（七）⚠ 常设机构利润确定的四种方法（教材口径）**

- ⚠ **归属法**（⚠ 也称**实际所得法**，**已得到国际公认**）：
  常设机构所在国**只能以归属于该常设机构的营业利润**为课税范围，
  **不能扩大到**对该常设机构所依附的对方国家企业来源于其国内的营业利润
  —— ⚠ 各国都将常设机构作为一个**独立的机构或企业**，要求其按**正常交易方式**与总机构往来，
  即按「**独立核算原则**」计算营业利润
  - ⚠ **OECD 范本注释**指出：可归属于该常设机构的利润应是——
    **考虑到常设机构与企业其他部门所分别履行的功能、使用的资产和承担的风险，
    假定常设机构作为一个相同或类似情况下从事相同或类似活动的独立分设企业，
    所预期可能获得的利润**
  - ⚠⚠ **将常设机构视为独立分设实体时**：
    **即使作为一个整体的企业没有利润，也可能有归属于常设机构的利润**；
    **反之，即使企业整体上有利润，也可能导致没有可归属于常设机构的利润**
- ⚠ **引力法**：常设机构所在国**除以归属该常设机构的营业利润为课税范围以外**，
  对**并不通过该常设机构、但经营的业务与该常设机构经营相同或同类取得的所得**，
  也要**归属该常设机构中合并征税**
  - ⚠ **优点**：扩大常设机构所在国的征税范围，**有助于防止跨国纳税人利用国际税负差别进行避税**
  - ⚠ **缺点**：具体执行上存在困难（**来源国很难控制和掌握非居民企业未通过常设机构
    自行开展的营业活动及取得的相应利润**）
  - ⚠⚠ **引力法在当前国际税收协定实践中已经被弃之不用**
- ⚠ **利润分配法**：按**企业总利润的一定比例**确定其设在非居住国的常设机构所得
  —— ⚠ **适用于无营业利润的常设机构**：有些常设机构**只办理接洽、通信联络等事宜，
  并不从事营业**，因此**并无营业利润，只有费用损失**
  - ⚠ 理由是：**既然有费用发生，就必有相应的收入和营业利润，
    只不过该项营业利润是包括在外国总机构账内、没有直接体现在常设机构账上**
  - ⚠ 这种做法目前**已为西欧一些国家所接受**
- ⚠ **利润核定法**：常设机构所在国按该常设机构的**营业收入额核定利润**
  或按**经费支出额推算利润**

**（八）⚠ OECD 范本 2025-11-19 更新版（三大领域）**

⚠ 2025 年 11 月 19 日，OECD 发布《关于对所得和财产避免双重征税的协定范本（2017）》
**更新版**，主要针对**跨境远程办公及自然资源开采的常设机构认定、转让定价与利息扣除规则**
三大领域调整：

- ⚠ **A. 跨境远程办公的常设机构认定**：
  - ⚠ **一是引入 50% 时间门槛测试**：在**任意 12 个月期间**，如果企业雇员或代理人
    在**其住所或其他相关场所（如家庭办公室）**的工作时间**占其为企业工作总时间的比例低于 50%**，
    则**该场所通常不构成常设机构**
  - ⚠ **二是商业理由测试**（**适用于工作时间占比不低于 50% 的情形**）：
    若**设立或使用场所的目的直接有助于企业开展业务**（如便于雇员接触**关键客户、项目资源
    或特定市场**），则**构成商业理由**；
    若主要出于**保留人才、降低办公成本、个人便利**等**管理性原因**，
    或相关业务接触具有**零散性、附带性**，则**不构成商业理由**
- ⚠ **B. 新增自然资源开采的替代性条款**：
  - **一是**针对**自然资源（石油、天然气和矿产）开采活动**，**降低构成常设机构的门槛**，
    明确非居民企业在一国**运营超过双边约定的期限**后，则构成常设机构
  - **二是**明确**区分专业服务（如地质勘探、工程咨询）与一般服务（如物流、维护）**；
    提供**两种可选适用范围**：**「仅限离岸」**（适用于在缔约国**领海或专属经济区内**的
    开采自然资源活动）和**「合并离岸与在岸」**（同时适用于**离岸及缔约国领土内**的活动）

### 六、金融账户涉税信息自动交换（CRS）

- **属于金融机构**的：**托管机构、存款机构、投资实体、指定保险公司**
  ⚠ **电子货币属于金融账户，而非金融机构**。
- **无须申报的账户**：**国际组织账户、中央银行账户、政府机构账户、退休金账户**；
  ⚠ **低价值且低风险的**特定账户无须申报（"高价值且高风险"则**不是**无须申报）。

### 七、双支柱方案（BEPS 2.0）

- **支柱一**：主要包括**金额 A 规则**和**金额 B 规则**；用于解决**市场辖区征税权的不平衡问题**。
  - 适用：年合并营业收入 **200 亿欧元以上**且**税前利润率超过 10%** 的跨国企业集团
  - 分配：跨国企业集团的部分超额利润，即**超过合并收入 10% 的集团合并利润的 25%**，
    分配给其销售产品和提供服务的辖区
  - ⚠ **不适用**：**采掘业、受监管的金融业**
- **支柱二**：主要包括**全球反税基侵蚀规则**和**应税规则**；
  确保跨国企业集团的合并收入在各个辖区**至少承担 15% 的税负**。
  - ⚠ **应税规则**针对利息、特许权使用费等费用支付，确保此类费用支付的**名义税率不低于 9%**
  - ⚠ **数字服务税不属于**有效税额
