# 房产税与城镇土地使用税纳税审核

## Definition

⚠ **本页是《涉税服务实务》第三章第三节之「三、其他税种的纳税审核方法」的
「（二）房产税、城镇土地使用税的审核方法」**，含其下两个目：
**1. 房产税纳税审核方法** 与 **2. 城镇土地使用税纳税审核方法**。

⚠⚠ **两税的审核共性（**本库原文的定性**）**：
> ⚠ **「房产税的会计核算比较简单，纳税审核的「「针对性较强」」，税务师在开展纳税审核工作时，
> 应主要核查「「有关合同和会计账户，征免界限的划分，适用税率、幅度税额的确定」」等问题。」**

⚠ **边界**：
- ⚠ **房产税的征税范围·计税依据·税率**见 [[real-estate-tax]]；
  **城镇土地使用税**见 [[urban-land-use-tax]]；
- ⚠ **本页是本批的收尾页**，⚠ **同批另两页为 [[land-appreciation-tax-audit]]、
  [[stamp-duty-and-deed-tax-audit]]。**

## Key Points

### ⚠ 一、房产税纳税审核方法

⚠ **总述（**教材原句**）**：**「房产税以房屋为征税对象，按照房屋的「「计税余值」」或
「「出租房屋的租金」」为计税依据，向「「产权所有人」」征收，
纳税审核的「「重点范围应是房屋原值和租金收入」」。」**

#### （1）⚠⚠ 「自用房产」的审核（**四条**）

| # | ⚠ 审核点（**教材原句要点**） |
|---|---|
| **①** | **「审核「「房产的原值是否真实」」，有无「「少报、瞒报」」的现象」**——**「审核『固定资产』账簿中房屋的「「造价或原价」」是否真实、完整，「「有无分解记账」」的情况」** |
| **②** | ⚠⚠ **改扩建的加计**：**「要注意纳税人对原有房屋进行「「改建、扩建」」的，「「是否按规定增加其房屋原值」」，「「有无将其改建、扩建支出列入大修理范围处理」」的情况」** |
| **③** | ⚠⚠ **在建工程挂账**：**「审核纳税人『在建工程』明细账，「「看有无已完工交付使用的房产继续挂账，未及时办理转账手续、少计房产原值」」的情况」** |
| **④** | ⚠ **账外房产**：**「必要时「「要深入实地查看」」，「「看企业是否有账外房产」」」** |

#### （2）⚠ 「出租房产」的审核（**三条**）

| # | ⚠ 审核点（**教材原句要点**） |
|---|---|
| **①** | **「审核『其他业务收入』等账户和「「房屋租赁合同及租赁费用结算凭证」」，核实房产租金收入，「「审核有无出租房屋不申报纳税」」的问题」** |
| **②** | ⚠⚠ **三种「隐瞒租金」的手法**：**「审核有无「「签订经营合同隐瞒租金收入」」，或「「以物抵租少报租金收入」」，或将「「房租收入计入营业收入未缴房产税」」的问题」** |
| **③** | ⚠ **无租使用与私有房产**：**「审核有无「「无租使用房屋」」，或租用「「免税单位和个人私有房产」」的问题」** |

#### 教材「例 3-13」——出租房产未计缴房产税

⚠ **案情（**金额多处残缺**）**：**税务师受托审核某企业房产税缴纳情况：
从「「固定资产明细账」」查实企业有「「房屋 11 幢」」，合计原值（**金额 OCR 残缺**）；
再查对「「『应交税费——应交房产税』账户的应缴税金」」，「「复核计算无误，税款亦已入库」」。
⚠⚠ 「但是，审核『「「其他业务收入」」』账户，发现有笔固定资产「「出租收入（金额残缺）」」，
核查原始凭证，「「这笔收入是出租一幢房屋的经营租金收入，没有计算房产税」」」。**

⚠⚠ **本例的方法论价值（**教材借例演示的「查账路径」**）**：
① ⚠ **「账簿内部的应缴数与已入库数都无误」不能证明没有漏税**——
**必须回到「「其他业务收入」」端去找「有没有应纳未纳的应税行为」**；
② ⚠ **「出租的固定资产未在固定资产账中（OCR 残缺）」——即「「无原值可依、须按租金从租计征」」**，
**这正是自用（从价）与出租（从租）两条计税依据的分岔点**。

⚠ **税务师的处理**：**「应补缴的房产税 ＝（出租收入）× 适用税率」**
（**从租计征，⚠ 教材原式中的税率与金额均在 OCR 中受损，见 Contradictions 二**），
**并作相关调账分录**。

#### （3）⚠ 「应纳税额」的审核（**三条 + 一条列支口径**）

| # | ⚠ 审核点（**教材原句要点**） |
|---|---|
| **①** | ⚠⚠ **征免界限的划分**：**「各免税单位的「「自用房产与生产、经营用房产、出租房产」」的划分，「「免税单位房产与下属单位房产」」的划分是否明确，其划分方法是否正确，以及「「免税房产在改变用途转为应税房产后是否按规定申报纳税」」」**；⚠ **「在需要时，检查其申报的「「房产使用情况与实际用途是否相符」」」** |
| **②** | ⚠⚠ **纳税期限**：**「审核房产税计算纳税的期限——对于「「新建、改造、翻建」」的房屋，「「已办理验收手续，或未办理验收手续已经使用的，是否按规定期限申报纳税」」，「「有无拖延纳税期限而少计税额」」的问题」** |
| **③** | ⚠ **申报表核对与原值评估**：**「审核「「财产和行为税纳税申报表」」，核实「「计税依据和适用税率的计算是否正确」」；对于「「固定资产账户未记载的房产原值，或房产原值明显不合理的」」，应提议纳税人「「按有关程序进行评估」」，以保证计税依据的准确完整」** |
| **④** | ⚠ **列支口径**：**「企业缴纳的房产税应在「「『税金及附加』」」中列支」** |

### ⚠⚠ 二、城镇土地使用税纳税审核方法

⚠ **总述（**教材原句**）**：**「城镇土地使用税以纳税人「「实际占用土地面积」」为计税依据，
按照当地政府根据国务院制定颁布的条例和「「省、自治区、直辖市人民政府规定的年税额幅度」」
确定的「「适用税额」」计算征收。」**
⚠ **审核重点**：**「纳税人实际占用土地的面积、「「减免税土地面积」」、适用单位税额
以及税款计算缴纳等问题」**。

#### （1）⚠⚠ 「应税土地面积」的审核（**三种确定方式，按「有无测定/证书」分层**）

> **「应税土地面积是纳税人实际占用土地的面积，它是计算城镇土地使用税的「「直接依据」」。」**

| # | ⚠ 情形 | ⚠ 应税土地面积的确定（**教材原句**） |
|---|---|---|
| **①** | ⚠ **已由省、自治区、直辖市人民政府指定的单位组织测定土地面积的** | **「以「「实际测定的土地面积」」为应税土地面积」** |
| **②** | ⚠ **未经省、自治区、直辖市人民政府指定的单位组织测定的** | **「以「「政府部门核发的土地使用证书」」确认的土地面积为应税土地面积」** |
| **③** | ⚠ **尚未核发土地使用证书的** | **「暂以纳税人「「据实申报」」的土地面积为应税土地面积」** |

⚠⚠ **比对方法（**教材原句**）**：**「检查时，应将「「财产和行为税纳税申报表中填报的应税土地面积」」
与「「实际测定的土地面积、土地使用证书确认的土地面积、『固定资产』明细账中记载的土地面积」」
相核对，看其是否相符。」**

#### （2）⚠ 「减免税土地面积」的审核

| # | ⚠ 审核点（**教材原句要点**） |
|---|---|
| **①** | **「应「「严格掌握」」城镇土地使用税的减免税规定，对纳税人「「新征用的耕地面积」」，可依据「「土地管理机关批准征地的文件」」来确定」** |
| **②** | **「对「「开山填海整治的土地和改造的废弃土地」」，可依据「「土地管理机关出具的证明文件」」来确定」** |
| **③** | ⚠⚠ **「另外，要审核是否将「「免税土地用于出租」」，或者「「多报免税土地面积」」的问题」** |

#### （3）「应纳税额」的审核

> **「根据「「土地位置和用途」」，对照当地人民政府对本地区土地划分的「「等级及单位税额」」，
> 审核纳税人「「适用单位税额是否正确」」。」**
> ⚠ **「在此基础上，「「进一步复核财产和行为税纳税申报表和有关完税凭证」」，
> 审核纳税人「「应纳税款的计算正确与否，税款是否及时申报缴纳入库」」。」**

#### 教材「例 3-14」——运输公司城镇土地使用税「一刀切」错误

⚠ **案情（**金额多处残缺**）**：**审核某运输公司某年度城镇土地使用税情况。
「「该公司有两个（地块）」」**：**一在「「市区」」（占地**金额残缺**平方米），
按市政府规定该地段每平方米年应纳税额（**金额残缺**）；
一在「「市郊」」（占地**金额残缺**平方米），按市政府规定该地段每平方米年应纳税额（**金额残缺**）。
⚠⚠ **「该公司申报纳税时，「「全按每平方米年应纳税额 0.8 元计算」」。」**

⚠⚠ **本例的方法论价值（**教材借例演示**）**：
① ⚠⚠ **典型错弊是「「不分地段、一律适用同一单位税额」」**——**即未按「土地等级」区分适用税额**；
② ⚠ **处理**：**「经审核，要求该公司纠正，计算补缴该年度城镇土地使用税」**（**金额 OCR 残缺**）；
③ ⚠⚠ **两条账务路径（**按是否跨年度分岔**）**：
**当年内**——**借：税金及附加　贷：应交税费——应交城镇土地使用税**；
**跨年度审核**——**借：「「以前年度损益调整」」　贷：应交税费——应交城镇土地使用税**
（⚠ **与 [[cit-audit-financial-expense-and-outlays]] 中「查补上年税款走『以前年度损益调整』」
的口径一致**）。

### ⚠ 三、本页的「要点密集区」（**复习提示**）

| 要点 | ⚠ 所指 |
|---|---|
| ⚠⚠ **自用房产四条** | **原值真实（有无分解记账）／改扩建须增原值而非作大修理／在建工程已完工不得继续挂账／账外房产须实地查看** |
| ⚠⚠ **出租房产三种隐瞒手法** | **签订经营合同隐瞒租金／以物抵租少报租金／房租收入计入营业收入未缴房产税** |
| ⚠ **「无租使用」与「免税单位私有房产」** | **出租房产审核的另两处落点** |
| ⚠⚠ **例 3-13 的教训** | **应缴数与入库数都对的，仍可能有漏税——要回到「其他业务收入」找应税行为** |
| ⚠⚠ **征免界限的两类划分** | **免税单位「自用 vs 生产经营 vs 出租」／「免税单位 vs 下属单位」；且改用途后须申报** |
| ⚠ **「先验收或先使用」的纳税期限** | **新建、改造、翻建的房屋** |
| ⚠⚠ **应税土地面积的「三级确定」** | **测定优先 → 证书次之 → 据实申报兜底；并须与申报表、固定资产明细账四面核对** |
| ⚠⚠ **免税土地的两个落点** | **新征用耕地凭「批准征地文件」／开山填海与废弃土地凭「土地管理机关证明」；且不得用于出租、不得多报** |
| ⚠⚠ **两个税的「列支口径」** | **房产税在「税金及附加」列支；城镇土地使用税同样经「税金及附加」（跨年度查补则走「以前年度损益调整」）** |

> ⚠ **申报代办视角**（**房产税·城镇土地使用税的申报代办：四条资料收集与专业判断要领、申报期限授权省级**）见 [[property-and-urban-land-tax-filing]]（**第五章第三节批 6，2026-10-08**）——⚠ **两页并存互指、不合并**。
