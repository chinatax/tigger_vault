# 投资性房地产的转换与处置

## Definition

投资性房地产的转换与处置（Investment Property Conversion and Disposal）：投资性房地产与自用房地产、存货之间的相互转换，以及处置时的损益结转。

转换差额的去向是本册**规则最密、最容易记反**的一处。可以用一句话收束：**只有「非投资性房地产 → 公允价值模式投资性房地产」且公允价值大于账面价值时才计入其他综合收益，其余一律公允价值变动损益**。

## Key Points

- **转换差额去向总表**（第 283、292、306、311、316 题）：

  | 转换方向 | 差额去向 |
  |---|---|
  | **自用房地产 → 公允价值模式投资性房地产** | 公允价值**大于**账面价值 → **其他综合收益**<br>公允价值**小于**账面价值 → **公允价值变动损益** |
  | **存货 → 公允价值模式投资性房地产** | 公允价值**大于**账面价值 → **其他综合收益**<br>公允价值**小于**账面价值 → **公允价值变动损益** |
  | **公允价值模式投资性房地产 → 自用房地产** | 一律 **公允价值变动损益** |
  | **公允价值模式投资性房地产 → 存货** | 一律 **公允价值变动损益** |
  | **成本模式下的转换**（任何方向） | ⚠ **直接按账面价值结转，完全不考虑公允价值** |
  | **成本模式 → 公允价值模式**（模式变更，非转换） | ⚠ 作**会计政策变更**处理，差额调整**留存收益** |

  - 为什么要设「其他综合收益」这个例外：防止企业通过「自用转投资性房地产」**在转换日即虚增当期利润**
- **转换日的账务结构**（第 311 题，⚠ 转换日**不确认**「投资性房地产——公允价值变动」）：
  - **存货 → 公允价值模式投资性房地产**：
    - 借「投资性房地产——**成本**」【转换日**公允价值**】
    - 借「**存货跌价准备**」【冲减原跌价准备】
    - 贷「**开发产品**」【账面余额】
    - 差额贷「**其他综合收益**」（公允价值大于账面价值时）
    - 例：开发产品账面余额 1300、跌价准备 120、转换日公允价值 1580
      → 借投资性房地产——成本 1580、借存货跌价准备 120、贷开发产品 1300、贷其他综合收益 **400**
  - **自用房地产 → 公允价值模式投资性房地产**：
    - 借「投资性房地产——成本」【公允价值】、借「累计折旧」
    - 差额：公允价值**小于**账面价值 → 借记「**公允价值变动损益**」；
      公允价值**大于**账面价值 → 贷记「**其他综合收益**」
    - 例：固定资产原值 6000、累计折旧 2000、转换日公允价值 7500
      → 入账价值 **7500 万元**，计入**其他综合收益** 3500 万元（**不是**当期损益）
- **处置投资性房地产**（第 292、293 题）：
  - 原计入**其他综合收益**的金额转入「**其他业务成本**」
    （⚠ 不是转入利润分配——未分配利润，也不是公允价值变动损益）
  - **对利润总额的影响**须把四个部分加全：
    租金收入 + 转让收入 − 转让成本 + **转换日确认的其他综合收益转入损益的金额** − 相关费用
    - 例（第 293 题）：出租日转换确认其他综合收益 = 17000 −（18000 − 3500）= 2500
      → 2023 年影响 = 200 × 3 + 17500 − 16800 + 2500 − 500 = **3300 万元**
- **转换为投资性房地产后对营业利润的影响**（第 301 题，⚠ 注意区分「营业利润」与「利润总额」）：
  - 转换**前**的折旧（计入管理费用）+ 转换**后**的公允价值变动 + 转换差额 + 租金收入（其他业务收入）
  - 例：固定资产账面 2886.4、转换日公允价值 2000
    → 影响营业利润 =（2000 − 2886.4）−（转换后半年折旧 211.2 + 租金 200）+（2550 − 2000）
    = **−347.6 万元**
  - ⚠ 自用转公允价值模式投资性房地产后**不再计提折旧**（上式中 211.2 为**转换前**半年计提的）
