# 承租人的会计处理

## Definition

承租人的会计处理（Lessee Accounting）：承租人在租赁期开始日确认「**使用权资产**」与「**租赁负债**」，并在租赁期内分别计提折旧与确认利息费用。

两条主线：**租赁付款额包含哪些项**（决定租赁负债的规模），以及**使用权资产的成本构成与折旧期间**（决定折旧额）。

## Key Points

- **使用权资产的成本构成**（第 443、454 题，四项）：
  - ①**租赁负债的初始计量金额**
  - ②在租赁期开始日或之前**支付的租赁付款额**；存在**租赁激励**的，应**扣除**已享受的租赁激励相关金额
  - ③承租人发生的**初始直接费用**
  - ④承租人为**拆卸及移除**租赁资产、**复原**租赁资产所在场地或将租赁资产**恢复**至租赁条款约定状态
    预计将发生的成本
  - ⚠ **不直接影响**使用权资产成本的项目：**承租资产的公允价值**（第 443 题的答案）
  - ⚠ 第④项成本的**现值**应当贷记「**预计负债**」科目，**不确认租赁负债**（第 454 题纠正项）
- **租赁负债的初始计量**：
  - 租赁负债 = **租赁期开始日尚未支付的租赁付款额的现值**
- **租赁付款额的五项内容**（第 451、464 题）：
  - ①**固定付款额及实质固定付款额**（存在租赁激励的，**扣除**租赁激励相关金额）
  - ②**取决于指数或比率**的可变租赁付款额（初始计量时按租赁期开始日的指数或比率确定）
  - ③**购买选择权的行权价格**（前提：合理确定承租人将**行使**该选择权）
  - ④承租人行使**终止租赁选择权**需支付的款项（前提：租赁期反映出承租人将行使该选择权）
  - ⑤根据承租人提供的**担保余值**预计应支付的款项
  - ⚠ **不包括**：
    - 取决于**未来销售收入**等**非指数或比率**的可变租赁付款额
    - 承租人发生的**初始直接费用**（它影响使用权资产成本，不影响租赁付款额）
- **租赁负债的后续计量**（第 456 题）：
  - 支付租赁付款额时 → **减少**租赁负债的账面金额
  - 确认租赁负债的**利息**时 → **增加**租赁负债的账面金额（按**固定的周期性利率**计算）
  - ⚠ 承租人**收回租赁保证金**时 → 应当冲减「**其他应收款**」的账面金额（**不是**租赁负债）
  - ⚠ 对租赁负债重新计量时，若**使用权资产账面价值已调减至零**但租赁负债仍需进一步调减的，
    承租人应当将剩余金额计入「**当期损益**」（**不是**其他综合收益）
- **重新计量租赁负债时的折现率选择**（第 459、464 题，⚠ 只有两种情形用修订后折现率）：

  | 情形 | 折现率 |
  |---|---|
  | 与**浮动利率**挂钩的可变租赁付款额因浮动利率变动而变动 | **修订后的折现率** |
  | 发生**承租人可控范围内的重大变化**，导致其**改变意图**（是否行使购买/终止选择权） | **修订后的折现率** |
  | **担保余值**预计的应付金额发生变动 | **原折现率** |
  | **实质固定付款额**发生变动 | **原折现率** |
  | 用于确定租赁付款额的**指数或比率**（浮动利率除外）发生变动 | **原折现率** |

- **使用权资产的后续计量**（第 454 题）：
  - ⚠ 承租人**只能采用成本模式**对使用权资产进行后续计量
    （即以成本减累计折旧及累计减值损失），**不能采用公允价值模式**
  - **折旧期间**：
    - 承租人能够**合理确定**租赁期届满时**取得租赁资产所有权**的 →
      应当在租赁资产**剩余使用寿命**内计提折旧
    - 否则 → 应当在**租赁期**内计提折旧
- **可变租赁付款额**（第 464 题）：
  - **非取决于指数或比率**的可变租赁付款额，**实际发生时计入当期损益**
    （例：按销售额 2% 计算的租金 24 万元 → 借「主营业务成本」24、贷「银行存款」24）
- **计算示例**（第 464 题）：年租金 120 万元、5 年、担保余值 100 万元、初始直接费用 5 万元、
  租赁激励 1.7 万元、增量借款利率 4%
  - 租赁负债 = 120 ×（P/A,4%,5）= 120 × 4.4518 = **534.22 万元**
  - 使用权资产 = 534.22 + 5 − 1.7 = **537.52 万元**
  - 2024 年利息费用 = 534.22 × 4% = **21.37 万元**
  - 年折旧额 = 537.52 ÷ 5 = **107.5 万元**
  - 担保余值由「预计不低于 100」变为「预计 80」（**折现率不变**）→ 重新计量后的租赁负债
    = 120 ×（P/A,4%,4）+（100 − 80）×（P/F,4%,4）= 120 × 3.6299 + 20 × 0.8548 ≈ **453 万元**
