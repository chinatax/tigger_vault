# 吉林省税务：引导「一人公司」走稳合规路

> ⚠ **来源说明**：**国家税务总局吉林省税务局网站「工作动态」栏目**转载的《中国税务报》报道，
> **索引号 11220200MB15075407/2026-02041**、**发文日期 2026-08-28**、**发布时间 2026-08-28 16:10**。
> ⚠ **体裁定位**：**税务部门工作动态报道**——⚠ **所述做法（风险防范指引、名单筛选、智能预警）
> 均为吉林省一省的征管举措**，⚠ **不是全国统一规定，不得作为普遍口径引用**。

## Summary

吉林省税务部门针对「一人公司」**前置引导、政策辅导、风险防控**的工作报道。

⚠ **本件的库内价值有两处**：① **官方口径对「一人公司」的定义与风险清单**（征管视角）；
② ⚠⚠ **本批 8 篇中唯一提及「社保」的一篇**——补上了 QUERY 缺口之外的一小块。

## Key Points

### 一、官方对「一人公司（OPC）」的界定

- ⚠ **「一人公司」（OPC，One Person Company）：即个人借助 AI 工具，
  独立完成从产品设计研发到市场投放的全链路商业闭环，实现「单人成军」的创业方式**。
- ⚠ **经营特征**：**经营结构简单，创业者兼具股东、法定代表人、财务、运营等多重身份**，
  **一般采用线上线下双渠道混合经营模式**——**给公司的财税规范化管理带来挑战**。

### 二、⚠ 公私混用：官方认定的后果

- **典型表现**：**用个人支付宝、微信收取货款**——**是不少一人经营主体创业初期的常见问题**。
- ⚠⚠ **双重后果**：**「一旦公司无法清晰证明公司财产和个人财产相互独立，就要对公司债务承担连带责任。
  在税务管理上也会被认定为隐匿收入、偷逃税款。」**
  ⚠ 详见 [[commingling-of-corporate-and-personal-property]]。

### 三、⚠ 吉林省的「一人公司」税务风险防范指引

- ⚠ **列明公私账户混用可能导致的无限连带责任等法律条款**；
- ⚠ **逐条解析「一人公司」年度财务审计、股权转让的规范要求**；
- ⚠ **指导企业合规列支成本**，**确保货物流、资金流、发票流、合同流「四流一致」**，
  **帮助初创主体搭建规范的成本核算框架**。

### 四、⚠ 社保缴纳（本批唯一的社保内容）

- ⚠⚠ **口径**：**「『一人公司』给股东缴社保，关键要看公司有没有实际经营、
  股东本人有没有在其他单位参保。」**（松原市长岭县税务局社会保险和非税收入股）
- ⚠ **做法**：**筛选出已办理「一人公司」注册但未参保的法定代表人名单**，
  **派出业务骨干走进公司、坐到工位**，**面对面讲解政策规定，帮助企业梳理账目**，
  **引导经营者主动缴纳社保**。
- ⚠ **库内一般口径**见 [[social-insurance-premiums]]；⚠ **本节为业务问答口径，未展开法条**。

### 五、⚠ 税务部门在前置辅导中实际发现的高频问题（含一个具名示例）

以**通化市医全通（通化）科技发展有限公司**（医疗数字化系统开发企业）为例，
税务部门发现其存在：

- ⚠ **与医疗机构款项往来不清**；
- ⚠⚠ **技术服务费收入确认时点模糊**；
- ⚠ **费用归集口径混乱**；
- ⚠⚠ **研发耗材与日常支出边界模糊**。

⚠ **辅导处置**：**逐条厘清技术开发、运维服务的税率适用边界**，
**将全部经营收入纳入对公账户规范管理**，**补齐申报链条、明确费用归集标准**，
**建立起清晰的收入台账和费用分类体系**。

> ⚠ **体裁提示**：⚠⚠ **此处的企业名称与负责人姓名来自公开报道**
> （通化市医全通（通化）科技发展有限公司负责人张满达），
> ⚠ **本库照录报道原文，不代表对该企业的任何评价**；
> ⚠ **报道未称其被立案查处，只称「税务部门前置辅导中发现」**。

### 六、⚠ 「以数治税」的智能风险预警（省级做法）

- ⚠ 针对「一人公司」**轻资产、快迭代、线上收支分散**的业务特征，
  **吉林省税务局利用税收大数据建立智能风险预警机制**；
- ⚠ **识别对象**：**纳税申报、发票开具、研发核算归集不规范等风险疑点**；
- ⚠ **目标**：**风险早预警、辅导早介入**。
- ⚠⚠ **省局负责人表述**：**「聚焦公私财产混同、资金往来不规范、申报不实等突出涉税风险，
  实施精准分类监管」**——⚠ **这是本批唯一由税务部门直接列出的
「一人公司三类突出涉税风险」清单**（**公私财产混同 / 资金往来不规范 / 申报不实**）。
