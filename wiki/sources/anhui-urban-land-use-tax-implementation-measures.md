# 安徽省城镇土地使用税实施办法

> ⚠ **来源说明**：本件为**省政府规章**——
> **1989-02-10 省人民政府令第 3 号发布**，**2002-03-12 第一次修订**，
> **2007-10-24 安徽省人民政府令第 205 号第二次修订**（本页所据为第二次修订版）。
> 全文取自**中国政府网·国家规章库**（来源标注为安徽省人民政府网站）。
> ⚠ `raw_file` 指向带来源题注的整理正文；正式引用请核对现行有效规章文本。

## Summary

安徽省就《中华人民共和国城镇土地使用税暂行条例》制定的**地方实施办法**，共 **11 条**，
把国家条例落到**本省的纳税人、计税面积、税额幅度、分等程序、减免与征管**六个方面。

⚠ 其**库内价值**同样在于**授权落地**：教材（[[cta-tax-law-2-textbook]]）对城镇土地使用税
只写到「**省级政府在幅度内确定适用税额幅度、市县政府分等报批**」，
本件是**该两级程序在安徽的规范表述**；⚠ 而**具体的等级与每平米年税额，本件不载**——
由市县另行制定报批（安徽实例见 [[hefei-urban-land-use-tax-grades-2023]]）。

⚠ **本件发表于 2007-10-24，距今已超过 2 年，部分结论可能已过时。**
⚠ **未取得官方立档 PDF 原件**（页面为政府网公布的规章全文）；正式引用请核对现行文本。

## Key Points

- ⚠ **计税依据**（第三条）：**以纳税人实际占用的土地面积为计税依据，依照规定税额计算征收**；
  ⚠ **面积确定的两级顺位**：**以县级以上人民政府核发的土地使用证书所确认的面积为先**；
  **尚未核发证书的，以纳税人据实申报并经地方税务机关核实的面积为准**
  （⚠ 与教材口径的「测定→证书→据实申报」三级顺位相比，本件**未见「指定单位组织测定」一档**，
  ⚠ **此处存疑、照录不推补**，见 Contradictions）。
- ⚠⚠ **税额四级幅度**（第四条）：**大城市 1.5–30 元／中等城市 1.2–24 元／
  小城市 0.9–18 元／县城、建制镇、工矿区 0.6–12 元**（每平方米·年）；
  ⚠ 大中小城市划分**按《城市规划法》规定执行**（⚠ 教材口径为**城区常住人口**标准——
  ⚠ 两者**表述不同，照录并见 Contradictions**）。
- ⚠⚠ **两级分等程序**（第五条）：**「市、县人民政府应当根据实际情况，将本地区土地划分为若干等级，
  在省人民政府确定的税额幅度内，制定相应的适用税额标准，报省人民政府批准后执行。」**
- ⚠ **重点贫困县的降幅上限**（第五条）：**「国务院和省人民政府批准的重点贫困县土地使用税的
  适用税额标准可以适当降低，但降低额不得超过本办法第四条规定最低税额的 30%。」**
- ⚠ **减免**（第六条）：**「土地使用税的减免，按照《条例》的规定执行」**——
  ⚠ **本件不另设地方减免事项**（⚠ 与房产税侧细则第六条形成对照：**土地使用税无「停用土地」类减免**）。
- ⚠ **纳税期限**（第八条）：**「土地使用税按年计算，分期缴纳，具体缴纳期限由市、县地方税务机关确定。」**
  ⚠⚠ **该条已被 [[anhui-property-and-behaviour-tax-filing-2020]] 统一为按季申报**（2021-01-01 起）。
- ⚠ **征收管理**（第九条）：依照**《税收征收管理法》**、《条例》和本办法执行。
- ⚠ **施行与衔接**（第十条、第十一条）：**自 2007 纳税年度起按《条例》与本办法计算缴纳**；
  **本办法自 1989-01-01 起施行，各地各部门制定的土地使用费办法同时废止**。
